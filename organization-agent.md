# HackTricks organization guide

## Principles

- Give a reusable mechanism one substantive home. Service, platform, and tool entry points should retain their distinct prerequisites and link directly to the relevant heading, not duplicate a full procedure.
- Prefer headings in an existing coherent chapter when variants share mechanism and reader task; keep separate chapters when transport, prerequisite, or task changes. Page size alone does not justify a split or merge.
- Main HackTricks owns general security techniques; HackTricks Cloud owns provider/service/IAM-specific pivots. Use verified public URLs for cross-book links.
- A removed Markdown chapter needs a whole-page mdBook redirect in `book.toml`. Update current local links; historical fragments are out of scope. Preserve unique content before deleting a source.
- Recheck these paths and pending PR overlap before relying on this guide. This is a guide to the current target clone and draft organization, not a claim that this dry-run proposal has merged.

## Researcher entry points

- Remote Windows host with service-creation rights, SMB/RPC, or staged executable → Lateral Movement / SCM service execution; search SCMR, PsExec, SMBExec, WinExec, SharpMove. POSIX CPU timer race → Binary Exploitation / Linux kernel; search CVE-2025-38352, `CONFIG_POSIX_CPU_TIMERS_TASK_WORK`, IRQ expiry, `timer_delete`, ptrace/waitpid, UAF, Chronomaly.
- Exposed board pads/debug headers, serial console, memory chip, leakage, or glitchable signals → Hardware/Physical Access / Hardware Hacking. RFID/NFC badges, sub-GHz remotes, infrared, BLE, LoRaWAN, or iButton → adjacent Radio Hacking.
- OT asset → Industrial Control Systems / OT for process constraints; Network Services / Modbus, OPC UA, or BACnet for protocol specifics. Locked Android device/acquired image → Basic Forensic Methodology / Android Forensics; Android app testing → Mobile Pentesting.
- Guest-controlled network, display, storage, or shared folders → Binary Exploitation / VM Escape. Discovered SOAP/REST/GraphQL endpoint → Pentesting Web / Web API Pentesting. HTTP `401`/`403`, alternate methods, proxy headers, path normalization → Pentesting Web / HTTP 401/403 Authorization Bypasses. Unknown behavior of an HTTP response/request header → Pentesting Web / Special HTTP Headers.
- LFI plus PHP multipart upload → Web / File Inclusion / temporary-file uploads; older PHP filter-triggered worker crashes are the segmentation-fault variant there.
