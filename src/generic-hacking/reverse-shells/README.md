## Strumenti shell generati automaticamente

Diversi strumenti web e da riga di comando possono generare payload bind- e reverse-shell per diversi interpreti e sistemi operativi:

- **reverse-shell.sh** e **revshells.com** forniscono generatori di payload basati su browser.<sup>[[1]](#references)[[2]](#references)</sup>
- **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen** e **rsg** generano payload dalla riga di comando o tramite un'interfaccia locale.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- **xc** è un reverse shell multipiattaforma di piccole dimensioni per Linux e Windows.<sup>[[7]](#references)</sup>
- **pyminifier** non è un generatore di shell, ma può minimizzare o offuscare payload Python quando questa trasformazione è utile.<sup>[[6]](#references)</sup>
