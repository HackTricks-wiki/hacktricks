## Εργαλεία shell που δημιουργούνται αυτόματα

Αρκετά web και command-line helpers μπορούν να δημιουργήσουν bind- και reverse-shell payloads για διαφορετικούς interpreters και λειτουργικά συστήματα:

- Τα **reverse-shell.sh** και **revshells.com** παρέχουν generators payloads μέσω browser.<sup>[[1]](#references)[[2]](#references)</sup>
- Τα **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen** και **rsg** δημιουργούν payloads μέσω command line ή τοπικού interface.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- Το **xc** είναι ένα μικρό cross-platform reverse shell για Linux και Windows.<sup>[[7]](#references)</sup>
- Το **pyminifier** δεν είναι shell generator, αλλά μπορεί να κάνει minify ή obfuscate Python payloads όταν αυτός ο μετασχηματισμός είναι χρήσιμος.<sup>[[6]](#references)</sup>
