## Automatisch generierte Shell-Tools

Mehrere Web- und Kommandozeilen-Tools können Bind- und Reverse-Shell-Payloads für verschiedene Interpreter und Betriebssysteme generieren:

- **reverse-shell.sh** und **revshells.com** bieten browserbasierte Payload-Generatoren.<sup>[[1]](#references)[[2]](#references)</sup>
- **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen** und **rsg** generieren Payloads über die Kommandozeile oder eine lokale Benutzeroberfläche.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- **xc** ist eine kleine plattformübergreifende Reverse-Shell für Linux und Windows.<sup>[[7]](#references)</sup>
- **pyminifier** ist kein Shell-Generator, kann aber Python-Payloads minimieren oder verschleiern, wenn diese Umwandlung sinnvoll ist.<sup>[[6]](#references)</sup>
