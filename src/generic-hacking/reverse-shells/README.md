## Otomatik oluşturulan shell araçları

Çeşitli web ve command-line yardımcıları, farklı interpreter'lar ve işletim sistemleri için bind- ve reverse-shell payload'ları oluşturabilir:

- **reverse-shell.sh** ve **revshells.com**, browser tabanlı payload generator'ları sağlar.<sup>[[1]](#references)[[2]](#references)</sup>
- **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen** ve **rsg**, command line veya local interface üzerinden payload'lar oluşturur.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- **xc**, Linux ve Windows için küçük, cross-platform bir reverse shell'dir.<sup>[[7]](#references)</sup>
- **pyminifier** bir shell generator değildir; ancak bu dönüşüm kullanışlı olduğunda Python payload'larını küçültebilir veya obfuscate edebilir.<sup>[[6]](#references)</sup>
