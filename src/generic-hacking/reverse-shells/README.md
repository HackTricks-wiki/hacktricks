## Automatycznie generowane narzędzia shell

Kilka narzędzi webowych i command-line może generować payloady bind- i reverse-shell dla różnych interpreterów i systemów operacyjnych:

- **reverse-shell.sh** oraz **revshells.com** udostępniają generatory payloadów działające w przeglądarce.<sup>[[1]](#references)[[2]](#references)</sup>
- **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen** oraz **rsg** generują payloady z command line lub za pomocą lokalnego interfejsu.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- **xc** to mały, cross-platformowy reverse shell dla Linux i Windows.<sup>[[7]](#references)</sup>
- **pyminifier** nie jest generatorem shelli, ale może zmniejszać lub obfuskować payloady Python, gdy taka transformacja jest przydatna.<sup>[[6]](#references)</sup>
