## Outomaties-gegenereerde shell tools

Verskeie web- en command-line-hulpmiddels kan bind- en reverse-shell payloads vir verskillende interpreters en bedryfstelsels genereer:

- **reverse-shell.sh** en **revshells.com** verskaf blaaiergebaseerde payload generators.<sup>[[1]](#references)[[2]](#references)</sup>
- **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen**, en **rsg** genereer payloads vanaf die command line of ’n plaaslike interface.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- **xc** is ’n klein cross-platform reverse shell vir Linux en Windows.<sup>[[7]](#references)</sup>
- **pyminifier** is nie ’n shell generator nie, maar kan Python-payloads minify of obfuscate wanneer daardie transformasie nuttig is.<sup>[[6]](#references)</sup>
