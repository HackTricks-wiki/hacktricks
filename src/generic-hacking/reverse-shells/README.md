## Outils de shell générés automatiquement

Plusieurs outils web et en ligne de commande peuvent générer des payloads de bind shell et de reverse shell pour différents interpréteurs et systèmes d’exploitation :

- **reverse-shell.sh** et **revshells.com** proposent des générateurs de payloads accessibles depuis un navigateur.<sup>[[1]](#references)[[2]](#references)</sup>
- **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen** et **rsg** génèrent des payloads depuis la ligne de commande ou une interface locale.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- **xc** est un reverse shell multiplateforme léger pour Linux et Windows.<sup>[[7]](#references)</sup>
- **pyminifier** n’est pas un générateur de shell, mais peut minifier ou obfusquer des payloads Python lorsque cette transformation est utile.<sup>[[6]](#references)</sup>
