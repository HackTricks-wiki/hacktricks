## Ferramentas de shell geradas automaticamente

Vários auxiliares web e de linha de comando podem gerar payloads de bind- e reverse-shell para diferentes interpretadores e sistemas operacionais:

- **reverse-shell.sh** e **revshells.com** fornecem geradores de payloads baseados em navegador.<sup>[[1]](#references)[[2]](#references)</sup>
- **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen** e **rsg** geram payloads pela linha de comando ou por uma interface local.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- **xc** é um reverse shell pequeno e multiplataforma para Linux e Windows.<sup>[[7]](#references)</sup>
- **pyminifier** não é um gerador de shell, mas pode minificar ou ofuscar payloads Python quando essa transformação for útil.<sup>[[6]](#references)</sup>
