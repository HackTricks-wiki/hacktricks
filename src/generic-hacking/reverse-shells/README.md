## Automatisch generierte Shell-Tools

Mehrere webbasierte und kommandozeilenbasierte Helfer können Bind- und Reverse-Shell-Payloads für verschiedene Interpreter und Betriebssysteme generieren:

- **reverse-shell.sh** und **revshells.com** stellen browserbasierte Payload-Generatoren bereit.<sup>[[1]](#references)[[2]](#references)</sup>
- **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen** und **rsg** generieren Payloads über die Kommandozeile oder eine lokale Benutzeroberfläche.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- **xc** ist eine kleine plattformübergreifende Reverse-Shell für Linux und Windows.<sup>[[7]](#references)</sup>
- **pyminifier** ist kein Shell-Generator, kann Python-Payloads jedoch minimieren oder obfuskieren, wenn diese Transformation nützlich ist.<sup>[[6]](#references)</sup>
