## Автоматично згенеровані інструменти для shell

Декілька веб- і командних інструментів можуть генерувати bind- і reverse-shell payloads для різних інтерпретаторів та операційних систем:

- **reverse-shell.sh** і **revshells.com** надають генератори payloads, що працюють у браузері.<sup>[[1]](#references)[[2]](#references)</sup>
- **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen** і **rsg** генерують payloads з командного рядка або через локальний інтерфейс.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- **xc** — це невеликий кросплатформний reverse shell для Linux і Windows.<sup>[[7]](#references)</sup>
- **pyminifier** не є генератором shell, але може мінімізувати або обфускувати Python payloads, коли таке перетворення є корисним.<sup>[[6]](#references)</sup>
