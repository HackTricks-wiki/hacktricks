## 자동 생성 shell 도구

여러 웹 및 command-line helper가 다양한 interpreter와 operating system을 위한 bind- 및 reverse-shell payload를 생성할 수 있습니다:

- **reverse-shell.sh** 및 **revshells.com**은 브라우저 기반 payload generator를 제공합니다.<sup>[[1]](#references)[[2]](#references)</sup>
- **Shellerator**, **ShellPop**, **ShellReverse**, **Reverse Shell Generator**, **revshellgen**, **rsg**는 command line 또는 로컬 interface에서 payload를 생성합니다.<sup>[[3]](#references)[[4]](#references)[[5]](#references)[[8]](#references)[[9]](#references)[[10]](#references)</sup>
- **xc**는 Linux 및 Windows용 작은 cross-platform reverse shell입니다.<sup>[[7]](#references)</sup>
- **pyminifier**는 shell generator는 아니지만, 해당 변환이 유용한 경우 Python payload를 minify하거나 obfuscate할 수 있습니다.<sup>[[6]](#references)</sup>
