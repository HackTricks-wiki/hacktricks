# Індикатори підвищення привілеїв через сеанс SUSE та службу дисків

## Авторизація SSH-сеансу через PAM

CVE-2025-6018 впливала на конфігурації PAM у SUSE 15, у яких стек автентифікації SSH завантажував `pam_env` до того, як стек сеансу завантажував `pam_systemd`. Коли `pam_env` читав файл `.pam_environment` користувача, той міг задати значення `XDG_SEAT` і `XDG_VTNR`, через які Polkit вважав SSH-сеанс фізично активним. У результаті віддаленому користувачеві могла стати доступною дія з параметром `allow_active=yes`. Це змінює авторизацію сеансу, але саме по собі не гарантує доступу root. SUSE виправила типову поведінку читання середовища користувача в `pam` і розміщення модуля, яке генерує `pam-config`.<sup>[[1]](#references)[[2]](#references)</sup>

Перевірте фактичний ланцюжок підключень `/etc/pam.d/sshd`, порядок `pam_env.so` і `pam_systemd.so`, а також наявність явного параметра `user_readenv=1`. Виправлений пакет `pam` змінює типову поведінку, але явний параметр усе ще може вмикати читання середовища користувача. Новіший пакет `pam-config` не гарантує, що локально змінений або застарілий стек PAM було згенеровано повторно. Перевірте версію пакета постачальника та фактичну конфігурацію.<sup>[[1]](#references)[[2]](#references)</sup>

## Шлях через службу дисків для активного користувача

CVE-2025-6019 була шляхом підвищення привілеїв у `libblockdev`, доступним через `udisks2`: під час зміни розміру XFS файлову систему, надану зловмисником, можна було тимчасово змонтувати без очікуваного обмеження `nosuid`. Для цього потрібні доступна служба UDisks D-Bus, підтримка зміни розміру XFS, відповідна дія Polkit, доступна виклику, та вразливий пакет бібліотеки. CVE-2025-6018 — це один зі способів отримати сеанс активного користувача, але користувач, який уже має активний сеанс, може скористатися шляхом через службу дисків окремо.<sup>[[3]](#references)</sup>

Для пасивної перевірки перегляньте метадані служби UDisks, політику `org.freedesktop.udisks2.modify-device`, `xfs_growfs` та встановлений пакет `libbd_fs2`. SUSE вказує версію `libbd_fs2` `2.26-150400.3.5.1` як виправлену для openSUSE Leap 15.6; конкретна виправлена версія залежить від продукту. Наявність політики та пакета — це лише зачіпки, а не доказ того, що виклик може монтувати пристрій або змінювати його розмір. Під час переліку не змінюйте точки монтування та не викликайте методи D-Bus.<sup>[[3]](#references)</sup>
