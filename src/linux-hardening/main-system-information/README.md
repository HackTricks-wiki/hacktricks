# Основна інформація про систему

Перш ніж вибирати техніку локального підвищення привілеїв, перевірте ядро хоста, файлову систему, привілейовані допоміжні програми та доступні шляхи виходу. [Контрольний список підвищення привілеїв](linux-privilege-escalation-checklist.md) містить стислий порядок дій.

- [Оцінка вразливостей ядра та доступність під час виконання](kernel-vulnerability-assessment.md) допомагає перевірити відповідність збірки, доступність і активні засоби захисту.
- [Модулі ядра та зловживання modprobe](kernel-modules-and-modprobe.md) охоплює завантаження модулів і вразливість шляхів до допоміжних програм.
- [Зловживання командами sudo](sudo-command-abuse.md) розглядає способи, якими делеговані команди можуть порушувати межі привілеїв.
- [Символічні та жорсткі посилання, файлові дескриптори](filesystem-links-and-file-descriptors.md) охоплює перенаправлення шляхів, а також успадковані чи видалені відкриті файли.
- [Файлова система, inode та відновлення](filesystem-inodes-and-recovery.md) пояснює особливості роботи файлової системи, корисні під час розслідування.
- [Контрольний список: підвищення привілеїв у Linux](linux-privilege-escalation-checklist.md) містить перевірки хоста та посилання на докладніші матеріали.
- [Вихід із jail](escaping-from-limited-bash.md) охоплює обмежені оболонки та ізольовані середовища.
- [Матеріали про ядро/LPE/CVE](kernel-lpe-cves/README.md) об’єднують спеціалізовані описи локального підвищення привілеїв і вразливостей.
