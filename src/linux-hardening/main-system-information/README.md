# Κύριες πληροφορίες συστήματος

{{#include ../../banners/hacktricks-training.md}}

Εξετάστε τον kernel του host, το σύστημα αρχείων, τα προνομιούχα βοηθητικά προγράμματα και τις διαθέσιμες διαδρομές διαφυγής πριν επιλέξετε τεχνική τοπικής κλιμάκωσης προνομίων. Η [λίστα ελέγχου κλιμάκωσης προνομίων](linux-privilege-escalation-checklist.md) παρέχει μια συνοπτική σειρά ενεργειών.

- Η [αξιολόγηση ευπαθειών του kernel και η έκθεση κατά τον χρόνο εκτέλεσης](kernel-vulnerability-assessment.md) ελέγχει την εφαρμοσιμότητα στο build, την προσβασιμότητα και τα ενεργά μέτρα μετριασμού.
- Οι [μονάδες kernel και η κατάχρηση του modprobe](kernel-modules-and-modprobe.md) καλύπτουν τη φόρτωση μονάδων και την έκθεση των διαδρομών βοηθητικών προγραμμάτων.
- Η [κατάχρηση εντολών sudo](sudo-command-abuse.md) εξετάζει τρόπους με τους οποίους οι εντολές που έχουν ανατεθεί μπορούν να παραβιάσουν τα όρια προνομίων.
- Οι [συμβολικοί σύνδεσμοι, οι hard links και οι περιγραφείς αρχείων](filesystem-links-and-file-descriptors.md) καλύπτουν την ανακατεύθυνση διαδρομών, καθώς και τα αρχεία που έχουν κληρονομηθεί ή διαγραφεί ενώ παραμένουν ανοιχτά.
- Το [σύστημα αρχείων, τα inodes και η ανάκτηση](filesystem-inodes-and-recovery.md) εξηγεί τη συμπεριφορά του συστήματος αρχείων που είναι χρήσιμη κατά τη διερεύνηση.
- Η [λίστα ελέγχου: κλιμάκωση προνομίων στο Linux](linux-privilege-escalation-checklist.md) παραθέτει ελέγχους του host και συνδέσμους προς πιο αναλυτικό υλικό.
- Η [διαφυγή από jails](escaping-from-limited-bash.md) καλύπτει περιορισμένα shells και περιορισμένα περιβάλλοντα.
- Το [υλικό για Kernel/LPE/CVE](kernel-lpe-cves/README.md) συγκεντρώνει στοχευμένες αναλύσεις τοπικής κλιμάκωσης προνομίων και ευπαθειών.
