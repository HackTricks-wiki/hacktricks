# Κύριες πληροφορίες συστήματος

{{#include ../../banners/hacktricks-training.md}}

Εξετάστε τον πυρήνα, το σύστημα αρχείων, τα βοηθητικά προγράμματα με προνόμια και τις διαθέσιμες διαδρομές διαφυγής του host πριν επιλέξετε τεχνική τοπικής κλιμάκωσης προνομίων. Η [λίστα ελέγχου κλιμάκωσης προνομίων](linux-privilege-escalation-checklist.md) παρέχει μια συνοπτική σειρά ενεργειών.

- Η [αξιολόγηση ευπαθειών του πυρήνα και η έκθεση κατά τον χρόνο εκτέλεσης](kernel-vulnerability-assessment.md) ελέγχει την εφαρμοσιμότητα της έκδοσης, τη δυνατότητα πρόσβασης και τα ενεργά μέτρα μετριασμού.
- Οι [μονάδες πυρήνα και η κατάχρηση του modprobe](kernel-modules-and-modprobe.md) καλύπτουν τη φόρτωση μονάδων και την έκθεση διαδρομών βοηθητικών προγραμμάτων.
- Η [κατάχρηση εντολών sudo](sudo-command-abuse.md) εξετάζει τρόπους με τους οποίους οι εκχωρημένες εντολές μπορούν να παραβιάσουν τα όρια προνομίων.
- Οι [συμβολικοί και σκληροί σύνδεσμοι και οι περιγραφείς αρχείων](filesystem-links-and-file-descriptors.md) καλύπτουν την ανακατεύθυνση διαδρομών, καθώς και τα κληρονομημένα αρχεία ή τα αρχεία που έχουν διαγραφεί ενώ παραμένουν ανοιχτά.
- Τα [συστήματα αρχείων, τα inodes και η ανάκτηση](filesystem-inodes-and-recovery.md) εξηγούν τη συμπεριφορά των συστημάτων αρχείων που είναι χρήσιμη κατά τη διερεύνηση.
- Η [λίστα ελέγχου: κλιμάκωση προνομίων στο Linux](linux-privilege-escalation-checklist.md) απαριθμεί ελέγχους για τον host και παραπέμπει σε αναλυτικότερο υλικό.
- Η [διαφυγή από jails](escaping-from-limited-bash.md) καλύπτει περιορισμένα κελύφη και περιβάλλοντα.
- Το [υλικό για Kernel/LPE/CVE](kernel-lpe-cves/README.md) συγκεντρώνει στοχευμένες αναλύσεις τοπικής κλιμάκωσης προνομίων και ευπαθειών.
