# Основна інформація про систему

Перш ніж вибирати техніку локального підвищення привілеїв, перевірте ядро хоста, файлову систему, привілейовані допоміжні програми та доступні способи виходу з обмежень. [Контрольний список підвищення привілеїв](linux-privilege-escalation-checklist.md) містить стислий порядок дій.

- [Оцінювання вразливостей ядра та доступність під час виконання](kernel-vulnerability-assessment.md) перевіряє застосовність до збірки, доступність і активні засоби захисту.
- [Модулі ядра та зловживання modprobe](kernel-modules-and-modprobe.md) розглядає завантаження модулів і доступність шляхів до допоміжних програм.
- [Зловживання командами Sudo](sudo-command-abuse.md) розглядає способи, якими делеговані команди можуть перетинати межі привілеїв.
- [Символічні та жорсткі посилання, а також файлові дескриптори](filesystem-links-and-file-descriptors.md) охоплює перенаправлення шляхів і успадковані або видалені, але відкриті файли.
- [Файлова система, inode та відновлення](filesystem-inodes-and-recovery.md) пояснює особливості роботи файлових систем, корисні під час розслідування.
- [Контрольний список: підвищення привілеїв у Linux](linux-privilege-escalation-checklist.md) містить перевірки хоста та посилання на докладніші матеріали.
- [Вихід із jail](escaping-from-limited-bash.md) розглядає обмежені оболонки та середовища.
- [Матеріали про Kernel/LPE/CVE](kernel-lpe-cves/README.md) об’єднують спеціалізовані описи локального підвищення привілеїв і вразливостей.
