# Цікаві файли та дозволи

{{#include ../../banners/hacktricks-training.md}}

Власник файлу, доступ на запис, параметри монтування та привілеї виконання можуть змінити фактичні можливості локального користувача. Спершу визначте цільовий файл або шлях виконання, а потім скористайтеся відповідною сторінкою:

- [SUID, SGID, ACL і конфіденційні файли](suid-sgid-and-acl-triage.md) містить початковий порядок дій для аналізу привілеїв виконання та прихованих дозволів доступу.
- [Довільний запис у файли від імені root](write-to-root.md) описує, як використати запис у привілейовані шляхи для підвищення привілеїв.
- [Linux capabilities](linux-capabilities.md) пояснює capabilities процесів і файлів.
- [Зловживання SUID-спільними бібліотеками та компонувальником](suid-shared-library-and-linker-abuse.md) охоплює динамічне завантаження привілейованими бінарними файлами.
- [Приклад підвищення привілеїв через `ld.so`](ld.so.conf-example.md) розглядає випадок із конфігурацією компонувальника.
- [Помилкова конфігурація NFS `no_root_squash` і `no_all_squash`](nfs-no_root_squash-misconfiguration-pe.md) охоплює зіставлення ідентифікаторів у віддаленій файловій системі.
- [Трюки з підстановкою масок](wildcards-spare-tricks.md) охоплює розгортання аргументів у привілейованих командах.
- [SELinux](selinux.md) пояснює застосування політик і відповідні кроки аналізу.
