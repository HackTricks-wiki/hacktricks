# Ενδιαφέροντα αρχεία και δικαιώματα

{{#include ../../banners/hacktricks-training.md}}

Η ιδιοκτησία αρχείων, η πρόσβαση εγγραφής, οι επιλογές προσάρτησης και τα δικαιώματα εκτέλεσης μπορούν να αλλάξουν την αποτελεσματική πρόσβαση ενός τοπικού χρήστη. Ξεκινήστε εντοπίζοντας το αρχείο-στόχο ή τη διαδρομή εκτέλεσης και, στη συνέχεια, ανατρέξτε στη σχετική σελίδα:

- [SUID, SGID, ACLs και ευαίσθητα αρχεία](suid-sgid-and-acl-triage.md) παρέχει μια αρχική ροή εργασιών για δικαιώματα εκτέλεσης και κρυφές παραχωρήσεις πρόσβασης.
- [Arbitrary file write to root](write-to-root.md) περιγράφει πώς οι εγγραφές σε διαδρομές με προνόμια μπορούν να αξιοποιηθούν για κλιμάκωση προνομίων.
- [Linux capabilities](linux-capabilities.md) εξηγεί τις δυνατότητες ανά διεργασία και ανά αρχείο.
- [Κατάχρηση shared library και linker μέσω SUID](suid-shared-library-and-linker-abuse.md) καλύπτει τη δυναμική φόρτωση γύρω από δυαδικά αρχεία με προνόμια.
- [Παράδειγμα κλιμάκωσης προνομίων με `ld.so`](ld.so.conf-example.md) εξετάζει μια περίπτωση ρύθμισης παραμέτρων του linker.
- [Λανθασμένη ρύθμιση NFS `no_root_squash` και `no_all_squash`](nfs-no_root_squash-misconfiguration-pe.md) καλύπτει την αντιστοίχιση ταυτοτήτων σε απομακρυσμένα συστήματα αρχείων.
- [Wildcard spare tricks](wildcards-spare-tricks.md) καλύπτει την επέκταση ορισμάτων σε εντολές με προνόμια.
- [SELinux](selinux.md) εξηγεί την επιβολή πολιτικών και τα σχετικά βήματα διερεύνησης.
