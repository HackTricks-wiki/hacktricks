# Цікаві файли та дозволи

{{#include ../../banners/hacktricks-training.md}}

Власник файлу, доступ на запис, параметри монтування та права на виконання можуть впливати на доступ, який має локальний користувач. Спочатку визначте цільовий файл або шлях виконання, а потім скористайтеся відповідною сторінкою:

- [SUID, SGID, ACL та конфіденційні файли](suid-sgid-and-acl-triage.md) описує початковий порядок дій для перевірки прав на виконання та прихованих дозволів доступу.
- [Довільний запис у файли від імені root](write-to-root.md) пояснює, як використати запис у привілейовані шляхи для підвищення привілеїв.
- [Linux capabilities](linux-capabilities.md) пояснює capabilities для процесів і файлів.
- [Зловживання SUID, спільними бібліотеками та linker](suid-shared-library-and-linker-abuse.md) розглядає динамічне завантаження під час запуску привілейованих бінарних файлів.
- [Приклад підвищення привілеїв через `ld.so`](ld.so.conf-example.md) розглядає випадок із конфігурацією linker.
- [Неправильна конфігурація NFS `no_root_squash` і `no_all_squash`](nfs-no_root_squash-misconfiguration-pe.md) розглядає зіставлення ідентифікаторів у віддаленій файловій системі.
- [Трюки з підстановочними символами](wildcards-spare-tricks.md) розглядає розгортання аргументів у привілейованих командах.
- [SELinux](selinux.md) пояснює застосування політик і відповідні етапи дослідження.
