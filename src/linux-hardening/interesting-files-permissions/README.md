# Ενδιαφέροντα αρχεία και δικαιώματα

{{#include ../../banners/hacktricks-training.md}}

Η ιδιοκτησία αρχείων, η πρόσβαση εγγραφής, οι επιλογές προσάρτησης και τα δικαιώματα εκτέλεσης μπορούν να επηρεάσουν την πρόσβαση που έχει ένας τοπικός χρήστης. Ξεκινήστε εντοπίζοντας το αρχείο-στόχο ή τη διαδρομή εκτέλεσης και, στη συνέχεια, συμβουλευτείτε τη σχετική σελίδα:

- [SUID, SGID, ACL και ευαίσθητα αρχεία](suid-sgid-and-acl-triage.md) παρέχει μια αρχική ροή εργασίας για δικαιώματα εκτέλεσης και κρυφές παραχωρήσεις πρόσβασης.
- [Αυθαίρετη εγγραφή αρχείων ως root](write-to-root.md) περιγράφει πώς η εγγραφή σε προνομιούχες διαδρομές μπορεί να οδηγήσει σε κλιμάκωση δικαιωμάτων.
- [Linux capabilities](linux-capabilities.md) εξηγεί τις δυνατότητες ανά διεργασία και ανά αρχείο.
- [Κατάχρηση shared library και linker με SUID](suid-shared-library-and-linker-abuse.md) καλύπτει τη δυναμική φόρτωση γύρω από προνομιούχα binaries.
- [Παράδειγμα κλιμάκωσης δικαιωμάτων με `ld.so`](ld.so.conf-example.md) εξετάζει μια περίπτωση ρύθμισης παραμέτρων του linker.
- [Εσφαλμένη ρύθμιση NFS `no_root_squash` και `no_all_squash`](nfs-no_root_squash-misconfiguration-pe.md) καλύπτει την αντιστοίχιση ταυτοτήτων σε απομακρυσμένα συστήματα αρχείων.
- [Κόλπα με wildcards](wildcards-spare-tricks.md) καλύπτει την επέκταση ορισμάτων σε προνομιούχες εντολές.
- [SELinux](selinux.md) εξηγεί την επιβολή πολιτικών και τα σχετικά βήματα διερεύνησης.
