# Ενδιαφέροντα αρχεία και δικαιώματα

{{#include ../../banners/hacktricks-training.md}}

Η ιδιοκτησία αρχείων, η πρόσβαση εγγραφής, οι επιλογές προσάρτησης και τα δικαιώματα εκτέλεσης μπορούν να αλλάξουν την αποτελεσματική πρόσβαση ενός τοπικού χρήστη. Ξεκινήστε εντοπίζοντας το αρχείο-στόχο ή τη διαδρομή εκτέλεσης και, στη συνέχεια, συμβουλευτείτε τη σχετική σελίδα:

- [SUID, SGID, ACLs και ευαίσθητα αρχεία](suid-sgid-and-acl-triage.md) παρέχει μια αρχική ροή εργασίας για δικαιώματα εκτέλεσης και κρυφές παραχωρήσεις πρόσβασης.
- [Αυθαίρετη εγγραφή αρχείων ως root](write-to-root.md) περιγράφει πώς η εγγραφή σε διαδρομές με αυξημένα δικαιώματα μπορεί να αξιοποιηθεί για κλιμάκωση δικαιωμάτων.
- [Linux capabilities](linux-capabilities.md) εξηγεί capabilities ανά διεργασία και ανά αρχείο.
- [Κατάχρηση SUID shared library και linker](suid-shared-library-and-linker-abuse.md) καλύπτει τη δυναμική φόρτωση γύρω από δυαδικά αρχεία με αυξημένα δικαιώματα.
- [Παράδειγμα κλιμάκωσης δικαιωμάτων με `ld.so`](ld.so.conf-example.md) εξετάζει μια περίπτωση ρύθμισης παραμέτρων του linker.
- [Εσφαλμένη ρύθμιση `no_root_squash` και `no_all_squash` στο NFS](nfs-no_root_squash-misconfiguration-pe.md) καλύπτει την αντιστοίχιση ταυτοτήτων σε απομακρυσμένα συστήματα αρχείων.
- [Κόλπα με wildcards](wildcards-spare-tricks.md) καλύπτει την επέκταση ορισμάτων σε εντολές με αυξημένα δικαιώματα.
- [SELinux](selinux.md) εξηγεί την επιβολή πολιτικών και τα σχετικά βήματα διερεύνησης.
