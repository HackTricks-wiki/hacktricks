# Цікаві файли та дозволи

{{#include ../../banners/hacktricks-training.md}}

Власник файлу, права на запис, параметри монтування та привілеї виконання можуть змінити фактичні можливості локального користувача. Спершу визначте цільовий файл або шлях виконання, а потім скористайтеся відповідною сторінкою:

- [SUID, SGID, ACL та чутливі файли](suid-sgid-and-acl-triage.md) пропонує початковий порядок дій для перевірки привілеїв виконання та прихованих дозволів доступу.
- [Довільний запис у файл від імені root](write-to-root.md) описує, як запис у привілейовані шляхи можна використати для підвищення привілеїв.
- [Можливості Linux](linux-capabilities.md) пояснює можливості для процесів і файлів.
- [Зловживання SUID зі спільними бібліотеками та компонувальником](suid-shared-library-and-linker-abuse.md) описує динамічне завантаження навколо привілейованих бінарних файлів.
- [Приклад підвищення привілеїв через `ld.so`](ld.so.conf-example.md) розглядає випадок із конфігурацією компонувальника.
- [Неправильна конфігурація NFS `no_root_squash` і `no_all_squash`](nfs-no_root_squash-misconfiguration-pe.md) охоплює зіставлення ідентифікаторів у віддалених файлових системах.
- [Трюки з підстановкою символів-замінників](wildcards-spare-tricks.md) розглядає розгортання аргументів у привілейованих командах.
- [SELinux](selinux.md) пояснює застосування політик і відповідні кроки розслідування.
