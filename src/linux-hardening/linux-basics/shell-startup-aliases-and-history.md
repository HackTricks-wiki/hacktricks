# Εκκίνηση του shell, aliases και ιστορικό

{{#include ../../banners/hacktricks-training.md}}

Μια εντολή του shell μπορεί να συμπεριφέρεται διαφορετικά από το εκτελέσιμο αρχείο με το ίδιο όνομα, αν ένα alias, μια συνάρτηση, ένα αρχείο εκκίνησης ή μια μεταβλητή περιβάλλοντος αλλάζει τον τρόπο εκτέλεσής της. Ελέγξτε τα παραπάνω προτού εμπιστευτείτε την έξοδο μιας εντολής ή υποθέσετε ότι ένα script χρησιμοποιεί το ίδιο PATH με μια διαδραστική συνεδρία.

## Επιθεώρηση του τρέχοντος shell

```bash
printf '%s\n' "$SHELL" "$PATH"
type -a ls sudo curl 2>/dev/null
alias
command -V python3
history | tail -50
```

Τα `type` και `command -V` αποκαλύπτουν αν ένα όνομα αντιστοιχεί σε alias, συνάρτηση, ενσωματωμένη εντολή ή αρχείο. Τα `command -v` και `which` ενδέχεται να μην εμφανίζουν την ίδια πληροφορία για τα aliases και τις συναρτήσεις. Το ιστορικό του shell μπορεί να αποκαλύψει εντολές ή διαπιστευτήρια, αλλά μπορεί να είναι ελλιπές, απενεργοποιημένο ή να παραμένει στη μνήμη μέχρι να τερματιστεί η συνεδρία.

## Ελέγξτε τα αρχεία εκκίνησης και ιστορικού

```bash
ls -la ~/.bashrc ~/.bash_profile ~/.profile ~/.zshrc ~/.zprofile ~/.bash_history ~/.zsh_history 2>/dev/null
ls -ld /etc/profile /etc/profile.d /etc/bash.bashrc 2>/dev/null
printenv HISTFILE HISTSIZE HISTCONTROL BASH_ENV ENV 2>/dev/null
```

Ένα αρχείο εκκίνησης στο οποίο μπορεί να γράψει ένας χρήστης μπορεί να εκτελέσει εντολές κατά την επόμενη εκκίνηση ενός shell. Ένα αρχείο εκκίνησης σε όλο το σύστημα ή ένα αρχείο εκκίνησης προνομιούχου χρήστη είναι πιο ευαίσθητο, αν μπορεί να το τροποποιήσει ένας λογαριασμός με λιγότερα προνόμια. Το μη διαδραστικό Bash μπορεί επίσης να διαβάσει το αρχείο που ορίζεται από το `BASH_ENV`· η σελίδα [μεταβλητές περιβάλλοντος](linux-environment-variables.md#bash_env--env) εξηγεί αυτή τη συμπεριφορά και άλλα hooks διερμηνέων. Επαληθεύστε ποια αρχεία διαβάζει το πραγματικό shell για συνεδρίες σύνδεσης, διαδραστικές και μη διαδραστικές, πριν ισχυριστείτε ότι υπάρχει διαδρομή persistence.

Εξετάστε επίσης τα αρχεία που γίνονται source από ένα καθολικό αρχείο εκκίνησης. Για παράδειγμα, ένα κυριολεκτικό `source /opt/app/venv/bin/activate` στο `/etc/bash.bashrc` εκτελεί το αρχείο ενεργοποίησης ως κώδικα shell, όταν ένα shell διαβάζει πράγματι αυτό το αρχείο εκκίνησης. Εξετάστε το αρχείο ενεργοποίησης, τα δικαιώματα του symlink και των γονικών καταλόγων, καθώς και τα ACL· ένας χρήστης με λιγότερα προνόμια μπορεί να επηρεάσει ένα προνομιούχο shell μόνο αν αυτό το shell ή μια προνομιούχα εργασία κάνει αργότερα source το αρχείο. Αν η πρόσβαση εγγραφής εξαρτάται από το `sudoedit`, επαληθεύστε πρώτα τον ακριβή κανόνα sudoers και το εγκατεστημένο πακέτο sudo με τις διορθώσεις του προμηθευτή· μια συμβολοσειρά έκδοσης upstream από μόνη της δεν αποδεικνύει [έκθεση σε injection ορισμάτων του sudoedit](../main-system-information/linux-privilege-escalation-checklist.md#sudo-and-suid-commands).

Ελέγξτε το ιστορικό, τα dotfiles και τα αντίγραφα ασφαλείας για secrets, όπως περιγράφεται στην ενότητα [χρήστες και συνεδρίες](../user-information/user-and-session-triage.md). Αν ένα προνομιούχο script επιλύει εντολές βάσει ονόματος, συνδυάστε αυτόν τον έλεγχο με τις [οδηγίες για PATH hijacking](linux-environment-variables.md#path).
