- [FreeIPA pentesting](freeipa-pentesting.md) behandelt Identity-Management-Deployments.
- [Logstash](logstash.md) behandelt dienstspezifische Angriffsflächen.
- [Splunk-LPE und Persistenz](splunk-lpe-and-persistence.md) behandelt lokale Privilegienerweiterungs- und Persistenzpfade in Splunk-Deployments.
- [Missbrauch von Node Inspector und CEF-Debugger](electron-cef-chromium-debugger-abuse.md) behandelt offengelegte Debugging-Schnittstellen.
- [Umgehung der Authentifizierung und Syscall-Hooks in Android-Rooting-Framework-Managern](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) behandelt diesen spezialisierten Linux-basierten Software-Stack.
