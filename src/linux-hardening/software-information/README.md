# Informacje o oprogramowaniu

{{#include ../../banners/hacktricks-training.md}}

Zainstalowane oprogramowanie dodaje do hosta Linux mechanizmy uwierzytelniania, interfejsy zarządzania i zachowania specyficzne dla usług. Zidentyfikuj zainstalowany komponent i jego uprawnienia, a następnie zapoznaj się z odpowiednią stroną:

- [Lokalne usługi WWW i uwierzytelniania](local-web-and-auth-services.md) opisuje hostowe powierzchnie ataku związane z WWW, proxy, PAM, LDAP, pocztą i CI.
- [Bazy danych i materiały poufne](databases-and-secret-material.md) omawia lokalne punkty końcowe DB, konfiguracje aplikacji, magazyny kluczy i tokeny.
- [PAM: Pluggable Authentication Modules](pam-pluggable-authentication-modules.md) omawia moduły uwierzytelniania i konfigurację systemu Linux.
- [Pentesting FreeIPA](freeipa-pentesting.md) omawia wdrożenia zarządzania tożsamością.
- [Logstash](logstash.md) omawia powierzchnie ataku specyficzne dla tej usługi.
- [LPE i utrzymywanie dostępu w Splunk](splunk-lpe-and-persistence.md) omawia ścieżki lokalnej eskalacji uprawnień i utrzymywania dostępu we wdrożeniach Splunk.
- [Nadużycia inspektora Node i debuggera CEF](electron-cef-chromium-debugger-abuse.md) omawia dostępne interfejsy debugowania.
- [Obejście uwierzytelniania menedżera frameworków rootowania Androida i przechwytywanie wywołań systemowych](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) omawia ten wyspecjalizowany stos oprogramowania oparty na systemie Linux.
