# ソフトウェア情報

{{#include ../../banners/hacktricks-training.md}}

インストール済みソフトウェアは、Linuxホストに認証フック、管理インターフェース、サービス固有の動作を追加します。インストール済みのコンポーネントとその権限を特定し、関連するページを確認してください。

- [ローカルのWebサービスと認証サービス](local-web-and-auth-services.md)では、ホスト側のWeb、プロキシ、PAM、LDAP、メール、CIの攻撃対象領域を説明します。
- [データベースとシークレット情報](databases-and-secret-material.md)では、ローカルDBエンドポイント、アプリケーション設定、キーストア、トークンを扱います。
- [PAM: Pluggable Authentication Modules](pam-pluggable-authentication-modules.md)では、Linuxの認証モジュールと設定を説明します。
- [FreeIPAのpentesting](freeipa-pentesting.md)では、ID管理の導入環境を扱います。
- [Logstash](logstash.md)では、サービス固有の攻撃対象領域を説明します。
- [SplunkのLPEと永続化](splunk-lpe-and-persistence.md)では、Splunk環境におけるローカル権限昇格と永続化の経路を説明します。
- [Node inspectorとCEF debuggerの悪用](electron-cef-chromium-debugger-abuse.md)では、公開されたデバッグインターフェースを扱います。
- [Android rooting-framework managerの認証バイパスとsyscallフック](../../mobile-pentesting/android-app-pentesting/android-rooting-frameworks-manager-auth-bypass-syscall-hook.md)では、すでにroot化されたAndroidデバイスでのローカルなアプリからrootへの権限昇格を扱います。Android固有の前提条件については、Mobile Pentestingのページを参照してください。
