# Informacije o softveru

{{#include ../../banners/hacktricks-training.md}}

Instalirani softver dodaje Linux hostu mehanizme za autentifikaciju, interfejse za upravljanje i ponašanje specifično za određene servise. Utvrdite koja je komponenta instalirana i koje su njene privilegije, a zatim pregledajte odgovarajuću stranicu:

- [Lokalni web i servisi za autentifikaciju](local-web-and-auth-services.md) obuhvata web, proxy, PAM, LDAP, poštu i CI površine na hostu.
- [Baze podataka i tajni podaci](databases-and-secret-material.md) obuhvata lokalne DB krajnje tačke, konfiguracije aplikacija, skladišta ključeva i tokene.
- [PAM: priključivi moduli za autentifikaciju](pam-pluggable-authentication-modules.md) obuhvata Linux module za autentifikaciju i konfiguraciju.
- [FreeIPA pentesting](freeipa-pentesting.md) obuhvata implementacije za upravljanje identitetima.
- [Logstash](logstash.md) obuhvata površine napada specifične za servis.
- [LPE i održavanje pristupa u Splunk-u](splunk-lpe-and-persistence.md) obuhvata lokalne puteve eskalacije i održavanja pristupa u Splunk implementacijama.
- [Zloupotreba Node inspector-a i CEF debugger-a](electron-cef-chromium-debugger-abuse.md) obuhvata izložene interfejse za otklanjanje grešaka.
- [Zaobilaženje autentifikacije menadžera Android rooting framework-a i syscall hooks](../../mobile-pentesting/android-app-pentesting/android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) obuhvata eskalaciju sa lokalne aplikacije na root privilegije na već root-ovanim Android uređajima; preduslovi specifični za Android opisani su u odeljku Mobile Pentesting.
