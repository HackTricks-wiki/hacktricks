# सॉफ़्टवेयर जानकारी

{{#include ../../banners/hacktricks-training.md}}

इंस्टॉल किया गया सॉफ़्टवेयर Linux host में authentication hooks, management interfaces और service-specific व्यवहार जोड़ता है। इंस्टॉल किए गए component और उसके privileges की पहचान करें, फिर संबंधित पेज देखें:

- [स्थानीय वेब और authentication सेवाएँ](local-web-and-auth-services.md) host-side web, proxy, PAM, LDAP, mail और CI surfaces का विवरण देता है।
- [Databases और secret material](databases-and-secret-material.md) local DB endpoints, application configs, key stores और tokens को कवर करता है।
- [PAM: Pluggable Authentication Modules](pam-pluggable-authentication-modules.md) Linux authentication modules और configuration को कवर करता है।
- [FreeIPA pentesting](freeipa-pentesting.md) identity-management deployments को कवर करता है।
- [Logstash](logstash.md) service-specific attack surfaces को कवर करता है।
- [Splunk LPE और persistence](splunk-lpe-and-persistence.md) Splunk deployments में local escalation और persistence paths को कवर करता है।
- [Node inspector और CEF debugger abuse](electron-cef-chromium-debugger-abuse.md) exposed debugging interfaces को कवर करता है।
- [Android rooting framework manager auth bypass और syscall hooks](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) उस specialized Linux-based software stack को कवर करता है।
