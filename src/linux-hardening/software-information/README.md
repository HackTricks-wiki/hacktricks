El software instalado agrega hooks de autenticación, interfaces de administración y comportamientos específicos de los servicios a un host Linux. Identifica el componente instalado y sus privilegios; después, consulta la página correspondiente:

- [Servicios web locales y de autenticación](local-web-and-auth-services.md) describe las superficies de web, proxy, PAM, LDAP, correo y CI del host.
- [Bases de datos y material secreto](databases-and-secret-material.md) cubre endpoints de bases de datos locales, configuraciones de aplicaciones, almacenes de claves y tokens.
- [PAM: módulos de autenticación conectables](pam-pluggable-authentication-modules.md) cubre los módulos de autenticación de Linux y su configuración.
- [Pentesting de FreeIPA](freeipa-pentesting.md) cubre los despliegues de gestión de identidades.
- [Logstash](logstash.md) cubre las superficies de ataque específicas del servicio.
- [LPE y persistencia en Splunk](splunk-lpe-and-persistence.md) cubre las vías de escalada local y persistencia en despliegues de Splunk.
- [Abuso de Node inspector y del depurador CEF](electron-cef-chromium-debugger-abuse.md) cubre las interfaces de depuración expuestas.
- [Bypass de autenticación del gestor de frameworks de rooting de Android y hooks de syscall](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) cubre esa pila de software especializada basada en Linux.
