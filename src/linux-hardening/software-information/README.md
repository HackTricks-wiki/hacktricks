# सॉफ़्टवेयर की जानकारी

{{#include ../../banners/hacktricks-training.md}}

इंस्टॉल किया गया सॉफ़्टवेयर Linux होस्ट में authentication hooks, management interfaces और service-specific व्यवहार जोड़ता है। इंस्टॉल किए गए component और उसके privileges की पहचान करें, फिर संबंधित पेज देखें:

- [होस्ट पर चलने वाली web और authentication services](local-web-and-auth-services.md) में होस्ट-साइड web, proxy, PAM, LDAP, mail और CI surfaces का विवरण है।
- [Databases और secret material](databases-and-secret-material.md) में स्थानीय DB endpoints, application configs, key stores और tokens शामिल हैं।
- [PAM: Pluggable Authentication Modules](pam-pluggable-authentication-modules.md) में Linux authentication modules और configuration का विवरण है।
- [FreeIPA pentesting](freeipa-pentesting.md) में identity-management deployments का विवरण है।
- [Logstash](logstash.md) में service-specific attack surfaces का विवरण है।
- [Splunk LPE और persistence](splunk-lpe-and-persistence.md) में Splunk deployments में स्थानीय privilege escalation और persistence के रास्तों का विवरण है।
- [Node inspector और CEF debugger का दुरुपयोग](electron-cef-chromium-debugger-abuse.md) में exposed debugging interfaces का विवरण है।
- [Android rooting-framework manager authentication bypass और syscall hooks](../../mobile-pentesting/android-app-pentesting/android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) में पहले से rooted Android devices पर स्थानीय app-to-root escalation का विवरण है; Android-विशिष्ट prerequisites, Mobile Pentesting के साथ दिए गए हैं।
