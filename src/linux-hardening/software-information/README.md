# Інформація про програмне забезпечення

{{#include ../../banners/hacktricks-training.md}}

Встановлене програмне забезпечення додає до Linux-хоста механізми автентифікації, інтерфейси керування та специфічну для служб поведінку. Визначте встановлений компонент і його привілеї, а потім перегляньте відповідну сторінку:

- [Локальні вебслужби та служби автентифікації](local-web-and-auth-services.md) описує вебслужби, проксі, PAM, LDAP, пошту й CI на хості.
- [Бази даних і секретні дані](databases-and-secret-material.md) охоплює локальні кінцеві точки БД, конфігурації застосунків, сховища ключів і токени.
- [PAM: модулі підключної автентифікації](pam-pluggable-authentication-modules.md) описує модулі автентифікації Linux і їхню конфігурацію.
- [Pentesting FreeIPA](freeipa-pentesting.md) охоплює розгортання систем керування ідентифікацією.
- [Logstash](logstash.md) описує специфічні для служби поверхні атаки.
- [LPE і закріплення в Splunk](splunk-lpe-and-persistence.md) охоплює способи локального підвищення привілеїв і закріплення в розгортаннях Splunk.
- [Зловживання Node inspector і налагоджувачем CEF](electron-cef-chromium-debugger-abuse.md) описує відкриті інтерфейси налагодження.
- [Обхід автентифікації менеджера фреймворків рутування Android і перехоплення syscall](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) описує цей спеціалізований програмний стек на базі Linux.
