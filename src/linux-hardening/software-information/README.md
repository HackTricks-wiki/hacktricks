# सॉफ़्टवेयर की जानकारी

{{#include ../../banners/hacktricks-training.md}}

इंस्टॉल किया गया सॉफ़्टवेयर Linux host में authentication hooks, management interfaces और service-विशिष्ट व्यवहार जोड़ता है। इंस्टॉल किए गए component और उसके privileges की पहचान करें, फिर संबंधित पेज देखें:

- [स्थानीय web और authentication सेवाएँ](local-web-and-auth-services.md) host-side web, proxy, PAM, LDAP, mail और CI surfaces का मानचित्र देता है।
- [Databases और secret सामग्री](databases-and-secret-material.md) स्थानीय DB endpoints, application configs, key stores और tokens को कवर करता है।
- [PAM: Pluggable Authentication Modules](pam-pluggable-authentication-modules.md) Linux authentication modules और configuration को कवर करता है।
- [FreeIPA pentesting](freeipa-pentesting.md) identity-management deployments को कवर करता है।
- [Logstash](logstash.md) service-विशिष्ट attack surfaces को कवर करता है।
- [Splunk LPE और persistence](splunk-lpe-and-persistence.md) Splunk deployments में स्थानीय privilege escalation और persistence paths को कवर करता है।
- [Node inspector और CEF debugger का दुरुपयोग](electron-cef-chromium-debugger-abuse.md) exposed debugging interfaces को कवर करता है।
- [Android rooting framework manager auth bypass और syscall hooks](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) उस विशेष Linux-आधारित software stack को कवर करता है।
