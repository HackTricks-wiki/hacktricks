# Інформація про програмне забезпечення

{{#include ../../banners/hacktricks-training.md}}

Встановлене програмне забезпечення додає до Linux-хоста механізми автентифікації, інтерфейси керування та поведінку, специфічну для служб. Визначте встановлений компонент і його привілеї, а потім перегляньте відповідну сторінку:

- [Локальні вебслужби та служби автентифікації](local-web-and-auth-services.md) описує вебслужби, проксі, PAM, LDAP, пошту та CI на хості.
- [Бази даних і секретні дані](databases-and-secret-material.md) охоплює локальні кінцеві точки БД, конфігурації застосунків, сховища ключів і токени.
- [PAM: Pluggable Authentication Modules](pam-pluggable-authentication-modules.md) описує модулі автентифікації Linux і їхню конфігурацію.
- [Тестування FreeIPA на проникнення](freeipa-pentesting.md) охоплює розгортання систем керування ідентифікацією.
- [Logstash](logstash.md) описує специфічні для служби поверхні атаки.
- [Підвищення привілеїв і закріплення в Splunk](splunk-lpe-and-persistence.md) охоплює шляхи локального підвищення привілеїв і закріплення в розгортаннях Splunk.
- [Зловживання Node inspector і налагоджувачем CEF](electron-cef-chromium-debugger-abuse.md) описує доступні інтерфейси налагодження.
- [Обхід автентифікації менеджера фреймворку рутування Android і перехоплення системних викликів](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) охоплює цей спеціалізований стек програмного забезпечення на базі Linux.
