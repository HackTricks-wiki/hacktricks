El software instalado añade hooks de autenticación, interfaces de gestión y comportamientos específicos de los servicios a un host Linux. Identifica el componente instalado y sus privilegios; después, consulta la página correspondiente:

- [Servicios web locales y de autenticación](local-web-and-auth-services.md) describe las superficies del host relacionadas con web, proxy, PAM, LDAP, correo y CI.
- [Bases de datos y material secreto](databases-and-secret-material.md) abarca endpoints de DB locales, configuraciones de aplicaciones, almacenes de claves y tokens.
- [PAM: módulos de autenticación conectables](pam-pluggable-authentication-modules.md) describe los módulos de autenticación y la configuración de Linux.
- [Pentesting de FreeIPA](freeipa-pentesting.md) abarca implementaciones de gestión de identidades.
- [Logstash](logstash.md) describe superficies de ataque específicas del servicio.
- [LPE y persistencia en Splunk](splunk-lpe-and-persistence.md) abarca vías de escalada local y persistencia en implementaciones de Splunk.
- [Abuso del inspector de Node y del debugger de CEF](electron-cef-chromium-debugger-abuse.md) describe interfaces de depuración expuestas.
- [Auth bypass del gestor de frameworks de rooting de Android y hooks de syscall](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) abarca esa pila de software especializada basada en Linux.
