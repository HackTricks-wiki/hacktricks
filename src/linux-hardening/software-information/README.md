# Informacje o oprogramowaniu

{{#include ../../banners/hacktricks-training.md}}

Zainstalowane oprogramowanie dodaje do hosta Linux mechanizmy uwierzytelniania, interfejsy zarządzania i zachowania specyficzne dla usług. Zidentyfikuj zainstalowany komponent i jego uprawnienia, a następnie zapoznaj się z odpowiednią stroną:

- [Lokalne usługi webowe i uwierzytelniania](local-web-and-auth-services.md) opisuje hostowe powierzchnie ataku związane z serwerami webowymi, proxy, PAM, LDAP, pocztą i CI.
- [Bazy danych i materiały poufne](databases-and-secret-material.md) omawia lokalne punkty końcowe DB, konfiguracje aplikacji, magazyny kluczy i tokeny.
- [PAM: moduły uwierzytelniania](pam-pluggable-authentication-modules.md) omawia moduły uwierzytelniania Linux i ich konfigurację.
- [Pentesting FreeIPA](freeipa-pentesting.md) omawia wdrożenia systemów zarządzania tożsamością.
- [Logstash](logstash.md) omawia powierzchnie ataku charakterystyczne dla usługi.
- [LPE i utrwalanie w Splunk](splunk-lpe-and-persistence.md) omawia lokalne ścieżki eskalacji uprawnień i utrwalania w środowiskach Splunk.
- [Nadużywanie Node inspector i debuggera CEF](electron-cef-chromium-debugger-abuse.md) omawia ujawnione interfejsy debugowania.
- [Obejście uwierzytelniania w menedżerach frameworków rootowania Androida i hooki syscall](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) omawia ten wyspecjalizowany stos oprogramowania oparty na Linux.
