# Інформація про програмне забезпечення

{{#include ../../banners/hacktricks-training.md}}

Встановлене програмне забезпечення додає до Linux-хоста механізми автентифікації, інтерфейси керування та поведінку, специфічну для певних служб. Визначте встановлений компонент і його привілеї, а потім перегляньте відповідну сторінку:

- [Локальні вебслужби та служби автентифікації](local-web-and-auth-services.md) описує вебслужби, проксі, PAM, LDAP, пошту та CI на хості.
- [Бази даних і секретні дані](databases-and-secret-material.md) охоплює локальні кінцеві точки DB, конфігурації застосунків, сховища ключів і токени.
- [PAM: модулі підключної автентифікації](pam-pluggable-authentication-modules.md) описує модулі автентифікації Linux і конфігурацію.
- [Пентестинг FreeIPA](freeipa-pentesting.md) охоплює розгортання систем керування ідентифікацією.
- [Logstash](logstash.md) описує поверхні атак, специфічні для цієї служби.
- [LPE та закріплення в Splunk](splunk-lpe-and-persistence.md) охоплює шляхи локального підвищення привілеїв і закріплення в розгортаннях Splunk.
- [Зловживання налагоджувачами Node inspector і CEF](electron-cef-chromium-debugger-abuse.md) описує відкриті інтерфейси налагодження.
- [Обхід автентифікації менеджера Android-фреймворків рутування та syscall hooks](../../mobile-pentesting/android-app-pentesting/android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) описує локальне підвищення привілеїв від застосунку до root на вже рутованих пристроях Android; передумови, специфічні для Android, описані в розділі Mobile Pentesting.
