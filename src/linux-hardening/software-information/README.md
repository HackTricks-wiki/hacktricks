# 소프트웨어 정보

{{#include ../../banners/hacktricks-training.md}}

설치된 소프트웨어는 Linux 호스트에 인증 훅, 관리 인터페이스, 서비스별 동작을 추가합니다. 설치된 구성 요소와 해당 권한을 확인한 다음 관련 페이지를 살펴보세요.

- [로컬 웹 및 인증 서비스](local-web-and-auth-services.md)는 호스트 측 웹, 프록시, PAM, LDAP, 메일, CI 공격 표면을 다룹니다.
- [데이터베이스 및 비밀 정보](databases-and-secret-material.md)는 로컬 DB 엔드포인트, 애플리케이션 설정, 키 저장소, 토큰을 다룹니다.
- [PAM: Pluggable Authentication Modules](pam-pluggable-authentication-modules.md)는 Linux 인증 모듈과 설정을 다룹니다.
- [FreeIPA pentesting](freeipa-pentesting.md)은 ID 관리 배포 환경을 다룹니다.
- [Logstash](logstash.md)는 서비스별 공격 표면을 다룹니다.
- [Splunk LPE 및 지속성](splunk-lpe-and-persistence.md)은 Splunk 배포 환경의 로컬 권한 상승 및 지속성 경로를 다룹니다.
- [Node inspector 및 CEF debugger 악용](electron-cef-chromium-debugger-abuse.md)은 노출된 디버깅 인터페이스를 다룹니다.
- [Android rooting framework manager 인증 우회 및 syscall 훅](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md)은 해당 특수 Linux 기반 소프트웨어 스택을 다룹니다.
