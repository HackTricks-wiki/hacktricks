# ソフトウェア情報

{{#include ../../banners/hacktricks-training.md}}

インストール済みソフトウェアは、Linuxホストに認証フック、管理インターフェース、サービス固有の動作を追加します。インストールされているコンポーネントとその権限を特定し、関連するページを確認してください。

- [ローカルWebサービスと認証サービス](local-web-and-auth-services.md)では、ホスト側のWeb、プロキシ、PAM、LDAP、メール、CIの攻撃対象領域を解説します。
- [データベースと秘密情報](databases-and-secret-material.md)では、ローカルDBエンドポイント、アプリケーション設定、キーストア、トークンを解説します。
- [PAM: Pluggable Authentication Modules](pam-pluggable-authentication-modules.md)では、Linuxの認証モジュールと設定を解説します。
- [FreeIPA pentesting](freeipa-pentesting.md)では、ID管理のデプロイを解説します。
- [Logstash](logstash.md)では、サービス固有の攻撃対象領域を解説します。
- [SplunkのLPEと永続化](splunk-lpe-and-persistence.md)では、Splunkのデプロイにおけるローカル権限昇格と永続化の経路を解説します。
- [Node inspectorとCEF debuggerの悪用](electron-cef-chromium-debugger-abuse.md)では、公開されたデバッグインターフェースを解説します。
- [Android rooting framework managerの認証バイパスとsyscallフック](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md)では、Linuxベースのこの特殊なソフトウェアスタックを解説します。
