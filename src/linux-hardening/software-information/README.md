# ソフトウェア情報

{{#include ../../banners/hacktricks-training.md}}

インストール済みソフトウェアは、Linux ホストに認証フック、管理インターフェース、サービス固有の動作を追加します。インストールされているコンポーネントとその権限を特定し、該当するページを確認してください。

- [ローカル Web サービスと認証サービス](local-web-and-auth-services.md)では、ホスト側の Web、プロキシ、PAM、LDAP、メール、CI の攻撃対象を取り上げます。
- [データベースと秘密情報](databases-and-secret-material.md)では、ローカル DB エンドポイント、アプリケーション設定、キーストア、トークンを取り上げます。
- [PAM: Pluggable Authentication Modules](pam-pluggable-authentication-modules.md)では、Linux の認証モジュールと設定を取り上げます。
- [FreeIPA pentesting](freeipa-pentesting.md)では、ID 管理のデプロイを取り上げます。
- [Logstash](logstash.md)では、サービス固有の攻撃対象を取り上げます。
- [Splunk の LPE と永続化](splunk-lpe-and-persistence.md)では、Splunk のデプロイにおけるローカル権限昇格と永続化の経路を取り上げます。
- [Node inspector と CEF debugger の悪用](electron-cef-chromium-debugger-abuse.md)では、公開されたデバッグインターフェースを取り上げます。
- [Android rooting framework manager の認証バイパスと syscall フック](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md)では、Linux ベースの特殊なソフトウェアスタックを取り上げます。
