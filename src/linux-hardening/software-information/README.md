# Información del software

{{#include ../../banners/hacktricks-training.md}}

El software instalado añade mecanismos de autenticación, interfaces de administración y comportamientos específicos de los servicios a un host Linux. Identifica el componente instalado y sus privilegios; después, consulta la página correspondiente:

- [Servicios web locales y de autenticación](local-web-and-auth-services.md) cubre las superficies del host relacionadas con web, proxy, PAM, LDAP, correo y CI.
- [Bases de datos y material secreto](databases-and-secret-material.md) cubre endpoints de bases de datos locales, configuraciones de aplicaciones, almacenes de claves y tokens.
- [PAM: módulos de autenticación conectables](pam-pluggable-authentication-modules.md) cubre los módulos de autenticación de Linux y su configuración.
- [Pentesting de FreeIPA](freeipa-pentesting.md) cubre las implementaciones de gestión de identidades.
- [Logstash](logstash.md) cubre las superficies de ataque específicas del servicio.
- [LPE y persistencia en Splunk](splunk-lpe-and-persistence.md) cubre las vías de escalada local y persistencia en implementaciones de Splunk.
- [Abuso del inspector de Node y del depurador de CEF](electron-cef-chromium-debugger-abuse.md) cubre las interfaces de depuración expuestas.
- [Elusión de autenticación del gestor de frameworks de rooting de Android y hooks de syscall](../../mobile-pentesting/android-app-pentesting/android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) cubre la escalada local de la aplicación a root en dispositivos Android que ya tienen acceso root; los requisitos previos específicos de Android se encuentran en Pentesting móvil.
