# Informacje o oprogramowaniu

{{#include ../../banners/hacktricks-training.md}}

Zainstalowane oprogramowanie dodaje do hosta Linux mechanizmy uwierzytelniania, interfejsy zarządzania i zachowania specyficzne dla usług. Zidentyfikuj zainstalowany komponent i jego uprawnienia, a następnie zapoznaj się z odpowiednią stroną:

- [Lokalne usługi webowe i uwierzytelniania](local-web-and-auth-services.md) opisują lokalne powierzchnie ataku związane z usługami webowymi, proxy, PAM, LDAP, pocztą i CI.
- [Bazy danych i materiały poufne](databases-and-secret-material.md) opisują lokalne endpointy DB, konfiguracje aplikacji, magazyny kluczy i tokeny.
- [PAM: moduły uwierzytelniania podłączane dynamicznie](pam-pluggable-authentication-modules.md) opisuje moduły uwierzytelniania Linux i ich konfigurację.
- [Pentesting FreeIPA](freeipa-pentesting.md) opisuje wdrożenia zarządzania tożsamością.
- [Logstash](logstash.md) opisuje powierzchnie ataku specyficzne dla usługi.
- [LPE i persistence w Splunk](splunk-lpe-and-persistence.md) opisuje lokalne ścieżki eskalacji uprawnień i persistence w środowiskach Splunk.
- [Nadużycia Node inspector i debuggera CEF](electron-cef-chromium-debugger-abuse.md) opisuje ujawnione interfejsy debugowania.
- [Obejście uwierzytelniania w menedżerze frameworka rootowania Androida i syscall hooks](../../mobile-pentesting/android-app-pentesting/android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) opisuje lokalną eskalację z aplikacji do roota na już zrootowanych urządzeniach Android; wymagania wstępne specyficzne dla Androida opisano w sekcji Mobile Pentesting.
