# Відомості про програмне забезпечення

{{#include ../../banners/hacktricks-training.md}}

Встановлене програмне забезпечення додає до хоста Linux хуки автентифікації, інтерфейси керування та специфічну для служб поведінку. Визначте встановлений компонент і його привілеї, а потім перегляньте відповідну сторінку:

- [Локальні вебслужби та служби автентифікації](local-web-and-auth-services.md) описує вебслужби на хості, проксі, PAM, LDAP, пошту та CI.
- [Бази даних і секретні дані](databases-and-secret-material.md) охоплює локальні кінцеві точки БД, конфігурації застосунків, сховища ключів і токени.
- [PAM: модулі підключення автентифікації](pam-pluggable-authentication-modules.md) охоплює модулі автентифікації Linux і конфігурацію.
- [Пентестинг FreeIPA](freeipa-pentesting.md) охоплює розгортання систем керування ідентифікацією.
- [Logstash](logstash.md) описує специфічні для служби поверхні атаки.
- [Підвищення привілеїв і закріплення в Splunk](splunk-lpe-and-persistence.md) охоплює шляхи локального підвищення привілеїв і закріплення в розгортаннях Splunk.
- [Зловживання Node inspector і налагоджувачем CEF](electron-cef-chromium-debugger-abuse.md) охоплює відкриті інтерфейси налагодження.
- [Обхід автентифікації менеджера фреймворків root-доступу Android і хуки системних викликів](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) охоплює цей спеціалізований стек програмного забезпечення на базі Linux.
