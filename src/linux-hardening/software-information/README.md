# Πληροφορίες λογισμικού

{{#include ../../banners/hacktricks-training.md}}

Το εγκατεστημένο λογισμικό προσθέτει hooks αυθεντικοποίησης, διεπαφές διαχείρισης και συμπεριφορά ειδική για κάθε υπηρεσία σε έναν Linux host. Εντοπίστε το εγκατεστημένο στοιχείο και τα προνόμιά του και, στη συνέχεια, εξετάστε τη σχετική σελίδα:

- [Τοπικές υπηρεσίες web και αυθεντικοποίησης](local-web-and-auth-services.md) χαρτογραφεί τις επιφάνειες web, proxy, PAM, LDAP, mail και CI στην πλευρά του host.
- [Βάσεις δεδομένων και μυστικά δεδομένα](databases-and-secret-material.md) καλύπτει τοπικά endpoints DB, ρυθμίσεις εφαρμογών, αποθήκες κλειδιών και tokens.
- [PAM: Αρθρωτές μονάδες αυθεντικοποίησης](pam-pluggable-authentication-modules.md) καλύπτει τις μονάδες αυθεντικοποίησης Linux και τη ρύθμισή τους.
- [Pentesting του FreeIPA](freeipa-pentesting.md) καλύπτει εγκαταστάσεις διαχείρισης ταυτοτήτων.
- [Logstash](logstash.md) καλύπτει επιφάνειες επίθεσης ειδικές για την υπηρεσία.
- [LPE και persistence στο Splunk](splunk-lpe-and-persistence.md) καλύπτει τοπικά μονοπάτια κλιμάκωσης και persistence σε εγκαταστάσεις Splunk.
- [Κατάχρηση του Node inspector και του CEF debugger](electron-cef-chromium-debugger-abuse.md) καλύπτει εκτεθειμένες διεπαφές αποσφαλμάτωσης.
- [Παράκαμψη αυθεντικοποίησης και hooks syscall σε manager rooting framework Android](../../mobile-pentesting/android-app-pentesting/android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) καλύπτει την τοπική κλιμάκωση από app σε root σε ήδη rooted συσκευές Android· οι ειδικές για Android προϋποθέσεις βρίσκονται στην ενότητα Mobile Pentesting.
