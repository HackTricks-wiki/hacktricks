# Informacje o oprogramowaniu

{{#include ../../banners/hacktricks-training.md}}

Zainstalowane oprogramowanie dodaje do hosta Linux mechanizmy uwierzytelniania, interfejsy zarządzania i zachowania specyficzne dla usług. Zidentyfikuj zainstalowany komponent i jego uprawnienia, a następnie zapoznaj się z odpowiednią stroną:

- [Lokalne usługi WWW i uwierzytelniania](local-web-and-auth-services.md) opisuje usługi WWW, proxy, PAM, LDAP, pocztę i CI działające po stronie hosta.
- [Bazy danych i materiały poufne](databases-and-secret-material.md) omawia lokalne endpointy baz danych, konfiguracje aplikacji, magazyny kluczy i tokeny.
- [PAM: wymienne moduły uwierzytelniania](pam-pluggable-authentication-modules.md) omawia moduły uwierzytelniania Linux i ich konfigurację.
- [Pentesting FreeIPA](freeipa-pentesting.md) omawia wdrożenia systemów zarządzania tożsamością.
- [Logstash](logstash.md) omawia powierzchnie ataku charakterystyczne dla tej usługi.
- [LPE i utrzymywanie dostępu w Splunk](splunk-lpe-and-persistence.md) omawia ścieżki lokalnej eskalacji uprawnień i utrzymywania dostępu we wdrożeniach Splunk.
- [Nadużycia Node Inspector i debuggera CEF](electron-cef-chromium-debugger-abuse.md) omawia ujawnione interfejsy debugowania.
- [Obejście uwierzytelniania menedżera frameworków rootowania Androida i przechwytywanie syscalli](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) omawia ten wyspecjalizowany stos oprogramowania oparty na Linux.
