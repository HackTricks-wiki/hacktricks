O software instalado adiciona hooks de autenticação, interfaces de gerenciamento e comportamentos específicos de serviços a um host Linux. Identifique o componente instalado e seus privilégios e, em seguida, consulte a página relevante:

- [Serviços locais de web e autenticação](local-web-and-auth-services.md) mapeia superfícies de web, proxy, PAM, LDAP, e-mail e CI no host.
- [Bancos de dados e material secreto](databases-and-secret-material.md) aborda endpoints de bancos de dados locais, configurações de aplicativos, keystores e tokens.
- [PAM: módulos de autenticação conectáveis](pam-pluggable-authentication-modules.md) aborda módulos de autenticação do Linux e suas configurações.
- [Pentesting do FreeIPA](freeipa-pentesting.md) aborda implantações de gerenciamento de identidade.
- [Logstash](logstash.md) aborda superfícies de ataque específicas do serviço.
- [LPE e persistência no Splunk](splunk-lpe-and-persistence.md) aborda caminhos de escalonamento local e persistência em implantações do Splunk.
- [Abuso do Node inspector e do depurador CEF](electron-cef-chromium-debugger-abuse.md) aborda interfaces de depuração expostas.
- [Bypass de autenticação do gerenciador de frameworks de rooting do Android e hooks de syscall](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) aborda essa pilha especializada de software baseada em Linux.
