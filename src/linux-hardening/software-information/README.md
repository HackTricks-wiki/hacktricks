# Πληροφορίες λογισμικού

{{#include ../../banners/hacktricks-training.md}}

Το εγκατεστημένο λογισμικό προσθέτει hooks ελέγχου ταυτότητας, διεπαφές διαχείρισης και συμπεριφορά ειδική για κάθε υπηρεσία σε έναν host Linux. Εντοπίστε το εγκατεστημένο στοιχείο και τα προνόμιά του και, στη συνέχεια, εξετάστε τη σχετική σελίδα:

- [Τοπικές υπηρεσίες web και ελέγχου ταυτότητας](local-web-and-auth-services.md) χαρτογραφεί επιφάνειες web, proxy, PAM, LDAP, mail και CI στην πλευρά του host.
- [Βάσεις δεδομένων και μυστικό υλικό](databases-and-secret-material.md) καλύπτει τοπικά endpoints DB, ρυθμίσεις εφαρμογών, key stores και tokens.
- [PAM: Pluggable Authentication Modules](pam-pluggable-authentication-modules.md) καλύπτει τα modules ελέγχου ταυτότητας Linux και τις ρυθμίσεις τους.
- [Pentesting του FreeIPA](freeipa-pentesting.md) καλύπτει υλοποιήσεις διαχείρισης ταυτοτήτων.
- [Logstash](logstash.md) καλύπτει επιφάνειες επίθεσης ειδικές για την υπηρεσία.
- [LPE και persistence στο Splunk](splunk-lpe-and-persistence.md) καλύπτει τοπικές διαδρομές κλιμάκωσης και persistence σε υλοποιήσεις Splunk.
- [Κατάχρηση του Node inspector και του CEF debugger](electron-cef-chromium-debugger-abuse.md) καλύπτει εκτεθειμένες διεπαφές debugging.
- [Παράκαμψη ελέγχου ταυτότητας και hooks syscall σε διαχειριστές Android rooting frameworks](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md) καλύπτει αυτήν την εξειδικευμένη στοίβα λογισμικού που βασίζεται στο Linux.
