# ソフトウェア情報

{{#include ../../banners/hacktricks-training.md}}

インストールされているソフトウェアは、Linux ホストに認証フック、管理インターフェース、サービス固有の動作を追加します。インストールされているコンポーネントとその権限を特定し、関連するページを確認してください。

- [ローカル Web サービスと認証サービス](local-web-and-auth-services.md)では、ホスト側の Web、プロキシ、PAM、LDAP、メール、CI の攻撃対象領域を解説します。
- [データベースとシークレット情報](databases-and-secret-material.md)では、ローカル DB エンドポイント、アプリケーション設定、キーストア、トークンを扱います。
- [PAM: プラグ可能認証モジュール](pam-pluggable-authentication-modules.md)では、Linux の認証モジュールと設定を解説します。
- [FreeIPA pentesting](freeipa-pentesting.md)では、ID 管理環境を扱います。
- [Logstash](logstash.md)では、サービス固有の攻撃対象領域を解説します。
- [Splunk の LPE と永続化](splunk-lpe-and-persistence.md)では、Splunk 環境でのローカル権限昇格と永続化の経路を扱います。
- [Node inspector と CEF debugger の悪用](electron-cef-chromium-debugger-abuse.md)では、公開されているデバッグインターフェースを扱います。
- [Android rooting framework manager の認証バイパスと syscall hooks](android-rooting-frameworks-manager-auth-bypass-syscall-hook.md)では、Linux ベースの特殊なソフトウェアスタックを扱います。
