# Πληροφορίες χρήστη

{{#include ../../banners/hacktricks-training.md}}

Η ταυτότητα χρήστη, η συμμετοχή σε ομάδες και τα διαπιστευτήρια που έχουν ανατεθεί καθορίζουν σε ποιους πόρους μπορεί να έχει πρόσβαση μια διεργασία. Ελέγξτε την ενεργή ταυτότητα και τις συμπληρωματικές ομάδες πριν διερευνήσετε τις παρακάτω διαδρομές πρόσβασης.

- [Χρήστες, συνεδρίες και τεχνουργήματα διαπιστευτηρίων](user-and-session-triage.md) καλύπτει την απαρίθμηση λογαριασμών, τις ενεργές συνδέσεις, τα τεχνουργήματα SSH και κελύφους, καθώς και τις αποθήκες διαπιστευτηρίων.
- [Πραγματικά, ενεργά και αποθηκευμένα αναγνωριστικά χρήστη](euid-ruid-suid.md) εξηγεί τις αλλαγές ταυτότητας γύρω από προγράμματα SUID και την εκτέλεση διεργασιών.
- [Ενδιαφέρουσες ομάδες για κλιμάκωση προνομίων στο Linux](interesting-groups-linux-pe/README.md) καλύπτει την πρόσβαση που παρέχεται μέσω ομάδων, συμπεριλαμβανομένων των LXD/LXC.
- [Εκμετάλλευση SSH forwarding agent](ssh-forward-agent-exploitation.md) εξετάζει τους κινδύνους από προωθημένα διαπιστευτήρια SSH.
- [Linux Active Directory](linux-active-directory.md) καλύπτει υπολογιστές που είναι συνδεδεμένοι σε περιβάλλον AD.
