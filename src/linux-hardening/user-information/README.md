# Informacije o korisnicima

{{#include ../../banners/hacktricks-training.md}}

Identitet korisnika, članstvo u grupama i delegirani akreditivi određuju kojim resursima proces može da pristupi. Proverite efektivni identitet i dopunske grupe pre nego što istražite navedene putanje pristupa.

- [Korisnici, sesije i artefakti akreditiva](user-and-session-triage.md) obuhvata enumeraciju naloga, aktivne prijave, SSH i shell artefakte, kao i skladišta akreditiva.
- [Stvarni, efektivni i sačuvani ID-ovi korisnika](euid-ruid-suid.md) objašnjava promene identiteta u vezi sa SUID programima i izvršavanjem procesa.
- [Zanimljive grupe za eskalaciju privilegija na Linuxu](interesting-groups-linux-pe/README.md) obuhvata pristup dodeljen članstvom u grupama, uključujući LXD/LXC.
- [Eksploatacija SSH forwarding agenta](ssh-forward-agent-exploitation.md) razmatra rizike prosleđenih SSH akreditiva.
- [Linux Active Directory](linux-active-directory.md) obuhvata hostove pridružene AD okruženju.
