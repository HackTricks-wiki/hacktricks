- [SSH forwarding agent exploitation](ssh-forward-agent-exploitation.md) ondersoek risiko's van aangestuurde SSH-geloofsbriewe.
- [Linux Active Directory](linux-active-directory.md) dek gashere wat aan 'n AD-omgewing gekoppel is.
