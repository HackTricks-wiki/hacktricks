# Informacije o korisniku

{{#include ../../banners/hacktricks-training.md}}

Identitet korisnika, članstvo u grupama i delegirani akreditivi određuju kojim resursima proces može da pristupi. Proverite efektivni identitet i dodatne grupe pre nego što istražite načine pristupa u nastavku.

- [Korisnici, sesije i artefakti akreditiva](user-and-session-triage.md) obuhvata enumeraciju naloga, aktivne prijave, SSH i shell artefakte i skladišta akreditiva.
- [Stvarni, efektivni i sačuvani ID-ovi korisnika](euid-ruid-suid.md) objašnjava promene identiteta povezane sa SUID programima i izvršavanjem procesa.
- [Zanimljive grupe za eskalaciju privilegija u Linuxu](interesting-groups-linux-pe/README.md) obuhvata pristup dodeljen članstvom u grupama, uključujući LXD/LXC.
- [Eksploatacija SSH prosleđivanja agenta](ssh-forward-agent-exploitation.md) razmatra rizike prosleđenih SSH akreditiva.
- [Linux Active Directory](linux-active-directory.md) obuhvata hostove pridružene AD okruženju.
