# Інформація про користувачів

{{#include ../../banners/hacktricks-training.md}}

Ідентичність користувача, членство в групах і делеговані облікові дані визначають, до яких ресурсів може отримати доступ процес. Перед дослідженням наведених нижче шляхів доступу перевірте ефективну ідентичність і додаткові групи.

- [Користувачі, сеанси та артефакти облікових даних](user-and-session-triage.md) охоплює перерахування облікових записів, активні входи, артефакти SSH і shell, а також сховища облікових даних.
- [Реальні, ефективні та збережені ідентифікатори користувача](euid-ruid-suid.md) пояснює зміну ідентичності під час роботи програм SUID і виконання процесів.
- [Цікаві групи для підвищення привілеїв у Linux](interesting-groups-linux-pe/README.md) охоплює доступ, наданий через членство в групах, зокрема LXD/LXC.
- [Експлуатація агента переадресації SSH](ssh-forward-agent-exploitation.md) розглядає ризики, пов’язані з переадресованими обліковими даними SSH.
- [Linux Active Directory](linux-active-directory.md) охоплює хости, приєднані до середовища AD.
