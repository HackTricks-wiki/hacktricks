# Benutzerinformationen

{{#include ../../banners/hacktricks-training.md}}

Benutzeridentität, Gruppenzugehörigkeit und delegierte Zugangsdaten bestimmen, auf welche Ressourcen ein Prozess zugreifen kann. Überprüfen Sie die effektive Identität und ergänzenden Gruppen, bevor Sie die folgenden Zugriffspfade untersuchen.

- [Benutzer, Sitzungen und Zugangsdaten-Artefakte](user-and-session-triage.md) behandelt die Kontoaufzählung, aktive Anmeldungen, SSH- und Shell-Artefakte sowie Zugangsdaten-Speicher.
- [Reale, effektive und gespeicherte Benutzer-IDs](euid-ruid-suid.md) erklärt Identitätsänderungen im Zusammenhang mit SUID-Programmen und der Prozessausführung.
- [Interessante Gruppen für die Linux-Privilege-Escalation](interesting-groups-linux-pe/README.md) behandelt durch Gruppen gewährten Zugriff, einschließlich LXD/LXC.
- [Ausnutzung des SSH-Forwarding-Agenten](ssh-forward-agent-exploitation.md) untersucht Risiken durch weitergeleitete SSH-Zugangsdaten.
- [Linux Active Directory](linux-active-directory.md) behandelt Hosts, die in eine AD-Umgebung eingebunden sind.
