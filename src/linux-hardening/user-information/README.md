# Benutzerinformationen

{{#include ../../banners/hacktricks-training.md}}

Benutzeridentität, Gruppenmitgliedschaft und delegierte Anmeldedaten bestimmen, auf welche Ressourcen ein Prozess zugreifen kann. Prüfen Sie die effektive Identität und ergänzenden Gruppen, bevor Sie die folgenden Zugriffspfade untersuchen.

- [Benutzer, Sitzungen und Anmeldedaten-Artefakte](user-and-session-triage.md) behandelt die Auflistung von Konten, aktive Anmeldungen, SSH- und Shell-Artefakte sowie Anmeldedatenspeicher.
- [Reale, effektive und gespeicherte Benutzer-IDs](euid-ruid-suid.md) erklärt Identitätswechsel bei SUID-Programmen und der Prozessausführung.
- [Interessante Gruppen für die Linux-Privilege-Escalation](interesting-groups-linux-pe/README.md) behandelt durch Gruppen gewährten Zugriff, einschließlich LXD/LXC.
- [Ausnutzung von SSH-Forwarding-Agenten](ssh-forward-agent-exploitation.md) untersucht Risiken durch weitergeleitete SSH-Anmeldedaten.
- [Linux Active Directory](linux-active-directory.md) behandelt Hosts, die einer AD-Umgebung beigetreten sind.
