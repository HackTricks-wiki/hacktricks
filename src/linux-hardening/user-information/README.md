# Інформація про користувача

{{#include ../../banners/hacktricks-training.md}}

Ідентичність користувача, членство в групах і делеговані облікові дані визначають, до яких ресурсів може отримати доступ процес. Перш ніж досліджувати наведені нижче шляхи доступу, перевірте ефективну ідентичність і додаткові групи.

- [Користувачі, сеанси та артефакти облікових даних](user-and-session-triage.md) охоплює перерахування облікових записів, активні входи, артефакти SSH і shell, а також сховища облікових даних.
- [Реальні, ефективні та збережені ідентифікатори користувачів](euid-ruid-suid.md) пояснює зміни ідентичності під час роботи програм SUID і виконання процесів.
- [Цікаві групи для підвищення привілеїв у Linux](interesting-groups-linux-pe/README.md) охоплює доступ, наданий через групи, зокрема LXD/LXC.
- [Експлуатація пересилання SSH-агента](ssh-forward-agent-exploitation.md) розглядає ризики пересланих облікових даних SSH.
- [Active Directory у Linux](linux-active-directory.md) охоплює хости, приєднані до середовища AD.
