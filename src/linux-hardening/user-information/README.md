# Πληροφορίες χρήστη

{{#include ../../banners/hacktricks-training.md}}

Η ταυτότητα χρήστη, η συμμετοχή σε ομάδες και τα διαπιστευτήρια που έχουν εκχωρηθεί καθορίζουν τους πόρους στους οποίους μπορεί να αποκτήσει πρόσβαση μια διεργασία. Ελέγξτε την ενεργή ταυτότητα και τις συμπληρωματικές ομάδες πριν διερευνήσετε τις παρακάτω διαδρομές πρόσβασης.

- [Χρήστες, συνεδρίες και τεχνουργήματα διαπιστευτηρίων](user-and-session-triage.md) καλύπτει την απαρίθμηση λογαριασμών, τις ενεργές συνδέσεις, τα τεχνουργήματα SSH και shell, καθώς και τα αποθετήρια διαπιστευτηρίων.
- [Πραγματικά, ενεργά και αποθηκευμένα ID χρήστη](euid-ruid-suid.md) εξηγεί τις αλλαγές ταυτότητας κατά τη χρήση προγραμμάτων SUID και την εκτέλεση διεργασιών.
- [Ενδιαφέρουσες ομάδες για privilege escalation σε Linux](interesting-groups-linux-pe/README.md) καλύπτει την πρόσβαση που παρέχεται μέσω ομάδων, συμπεριλαμβανομένων των LXD/LXC.
- [Εκμετάλλευση agent forwarding SSH](ssh-forward-agent-exploitation.md) εξετάζει τους κινδύνους από προωθημένα διαπιστευτήρια SSH.
- [Linux Active Directory](linux-active-directory.md) καλύπτει τους hosts που είναι συνδεδεμένοι σε περιβάλλον AD.
