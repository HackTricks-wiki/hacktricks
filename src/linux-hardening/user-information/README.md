# Informacje o użytkownikach

{{#include ../../banners/hacktricks-training.md}}

Tożsamość użytkownika, członkostwo w grupach i delegowane poświadczenia określają, do jakich zasobów może uzyskać dostęp proces. Przed sprawdzeniem poniższych ścieżek dostępu zweryfikuj efektywną tożsamość i grupy uzupełniające.

- [Użytkownicy, sesje i artefakty poświadczeń](user-and-session-triage.md) obejmuje enumerację kont, aktywne logowania, artefakty SSH i powłoki oraz magazyny poświadczeń.
- [Rzeczywiste, efektywne i zapisane identyfikatory użytkownika](euid-ruid-suid.md) wyjaśnia zmiany tożsamości związane z programami SUID i wykonywaniem procesów.
- [Interesujące grupy w kontekście eskalacji uprawnień w systemie Linux](interesting-groups-linux-pe/README.md) omawia dostęp przyznawany przez członkostwo w grupach, w tym LXD/LXC.
- [Wykorzystywanie agenta przekazywanego przez SSH](ssh-forward-agent-exploitation.md) omawia ryzyko związane z przekazywanymi poświadczeniami SSH.
- [Linux Active Directory](linux-active-directory.md) omawia hosty dołączone do środowiska AD.
