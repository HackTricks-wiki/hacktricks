- [Analiza lokalnej sieci i gniazd](local-network-and-socket-triage.md) omawia usługi loopback, gniazda Unix i sieci kontenerów.
- [Socket command injection](socket-command-injection.md) omawia polecenia przyjmowane przez udostępnione lokalne gniazda.
- [Cisco vManage](cisco-vmanage.md) opisuje cel związany z konkretnym produktem i powiązane kontrole.
