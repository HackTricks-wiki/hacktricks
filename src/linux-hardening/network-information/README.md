# Netzwerkinformationen

Lokale Listener, Unix-Sockets und netzwerkseitig erreichbare Software können Angriffsflächen offenlegen, die bei einem externen Scan unsichtbar bleiben. Beginne mit den lauschenden Diensten des Hosts und dem Prozess, dem jeder Endpunkt gehört.

- [Traffic-Capture-, Firewall- und Egress-Triage](traffic-capture-and-firewall-egress.md) behandelt Packet-Capture, Filterung, Proxys und Verbindungstests.
- [Triage lokaler Netzwerke und Sockets](local-network-and-socket-triage.md) behandelt Loopback-Dienste, Unix-Sockets und Container-Netzwerke.
- [Socket command injection](socket-command-injection.md) behandelt Befehle, die über exponierte lokale Sockets angenommen werden.
- [Cisco vManage](cisco-vmanage.md) dokumentiert ein produktspezifisches Ziel und zugehörige Prüfungen.
