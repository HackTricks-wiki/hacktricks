# Πληροφορίες δικτύου

{{#include ../../banners/hacktricks-training.md}}

Οι τοπικές υπηρεσίες ακρόασης, τα Unix sockets και το λογισμικό που εκτίθεται στο δίκτυο ενδέχεται να αποκαλύπτουν διαδρομές που δεν είναι ορατές σε εξωτερική σάρωση. Ξεκινήστε εξετάζοντας τις υπηρεσίες που ακούν στον host και τη διεργασία που κατέχει κάθε endpoint.

- [Διαλογή καταγραφής κίνησης, firewall και εξερχόμενης κίνησης](traffic-capture-and-firewall-egress.md) καλύπτει την καταγραφή πακέτων, το φιλτράρισμα, τους proxies και τους ελέγχους συνδεσιμότητας.
- [Διαλογή τοπικού δικτύου και sockets](local-network-and-socket-triage.md) καλύπτει υπηρεσίες loopback, Unix sockets και δίκτυα container.
- [Socket command injection](socket-command-injection.md) καλύπτει εντολές που γίνονται δεκτές μέσω εκτεθειμένων τοπικών sockets.
- [Cisco vManage](cisco-vmanage.md) τεκμηριώνει έναν στόχο συγκεκριμένου προϊόντος και τους σχετικούς ελέγχους.
