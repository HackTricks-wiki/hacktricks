# Інформація про мережу

{{#include ../../banners/hacktricks-training.md}}

Локальні слухачі, Unix-сокети та програмне забезпечення, доступне через мережу, можуть відкривати шляхи, невидимі під час зовнішнього сканування. Почніть зі служб, що прослуховують з’єднання на хості, і процесу, якому належить кожна кінцева точка.

- [Збір мережевого трафіку, брандмауер і перевірка вихідного трафіку](traffic-capture-and-firewall-egress.md) охоплює захоплення пакетів, фільтрацію, проксі та перевірку з’єднань.
- [Перевірка локальної мережі та сокетів](local-network-and-socket-triage.md) охоплює служби loopback, Unix-сокети та мережі контейнерів.
- [Ін’єкція команд через сокет](socket-command-injection.md) охоплює команди, що приймаються через відкриті локальні сокети.
- [Cisco vManage](cisco-vmanage.md) описує специфічну для продукту ціль і відповідні перевірки.
