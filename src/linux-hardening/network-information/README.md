# Мережева інформація

- [Захоплення трафіку, firewall і первинний аналіз вихідного трафіку](traffic-capture-and-firewall-egress.md) охоплює захоплення пакетів, фільтрацію, проксі та перевірки з’єднання.
- [Первинний аналіз локальної мережі та сокетів](local-network-and-socket-triage.md) охоплює служби loopback, Unix sockets і мережі контейнерів.
- [Ін’єкція команд через сокети](socket-command-injection.md) охоплює команди, що приймаються через відкриті локальні сокети.
- [Cisco vManage](cisco-vmanage.md) описує специфічну для продукту ціль і пов’язані перевірки.
