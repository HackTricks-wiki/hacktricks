# ネットワーク情報

ローカルで待ち受けるサービス、Unix ソケット、ネットワークに接続するソフトウェアは、外部スキャンでは確認できない経路を露呈することがあります。まず、ホストの待ち受けサービスと各エンドポイントを所有するプロセスを確認しましょう。

- [トラフィックキャプチャ、ファイアウォール、egress のトリアージ](traffic-capture-and-firewall-egress.md)では、パケットキャプチャ、フィルタリング、プロキシ、接続テストを扱います。
- [ローカルネットワークとソケットのトリアージ](local-network-and-socket-triage.md)では、loopback サービス、Unix ソケット、コンテナネットワークを扱います。
- [ソケットコマンドインジェクション](socket-command-injection.md)では、公開されたローカルソケット経由で受け付けられるコマンドを扱います。
- [Cisco vManage](cisco-vmanage.md)では、製品固有のターゲットと関連する確認事項について説明します。
