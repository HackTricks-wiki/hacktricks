# Мережева інформація

{{#include ../../banners/hacktricks-training.md}}

Локальні служби, що прослуховують порти, сокети Unix і програми, доступні з мережі, можуть відкривати шляхи, невидимі під час зовнішнього сканування. Спершу перевірте служби, що прослуховують порти на хості, і процес, якому належить кожна кінцева точка.

- [Захоплення трафіку, брандмауер і аналіз вихідного трафіку](traffic-capture-and-firewall-egress.md) охоплює захоплення пакетів, фільтрацію, проксі та тести підключення.
- [Аналіз локальної мережі та сокетів](local-network-and-socket-triage.md) охоплює служби loopback, сокети Unix і мережі контейнерів.
- [Ін’єкція команд через сокети](socket-command-injection.md) охоплює команди, що приймаються через доступні локальні сокети.
- Щоб отримати початковий доступ до пристроїв Cisco SD-WAN Manager, див. [підвищення привілеїв у vManage](../../network-services-pentesting/cisco-sd-wan-manager-local-privilege-escalation.md); його CLI ConfD, REST API та шляхи імпорту, що належать root, відрізняються від загального аналізу сокетів.
