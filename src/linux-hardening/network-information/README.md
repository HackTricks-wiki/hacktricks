# Πληροφορίες δικτύου

Οι τοπικοί listeners, τα Unix sockets και το λογισμικό με πρόσβαση στο δίκτυο ενδέχεται να εκθέτουν διαδρομές που δεν είναι ορατές σε εξωτερική σάρωση. Ξεκινήστε με τις υπηρεσίες που ακούν στον host και τη διεργασία που κατέχει κάθε endpoint.

- [Ανάλυση κίνησης, firewall και εξερχόμενης κίνησης](traffic-capture-and-firewall-egress.md) καλύπτει την καταγραφή πακέτων, το φιλτράρισμα, τους proxies και τους ελέγχους συνδεσιμότητας.
- [Ανάλυση τοπικού δικτύου και socket](local-network-and-socket-triage.md) καλύπτει υπηρεσίες loopback, Unix sockets και δίκτυα containers.
- [Socket command injection](socket-command-injection.md) καλύπτει εντολές που γίνονται δεκτές μέσω εκτεθειμένων τοπικών sockets.
- [Cisco vManage](cisco-vmanage.md) τεκμηριώνει έναν συγκεκριμένο στόχο προϊόντος και σχετικούς ελέγχους.
