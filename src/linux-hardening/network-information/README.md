- [Capture du trafic, firewall et triage de l’egress](traffic-capture-and-firewall-egress.md) couvre la capture de paquets, le filtrage, les proxies et les tests de connectivité.
- [Triage du réseau local et des sockets](local-network-and-socket-triage.md) couvre les services loopback, les sockets Unix et les réseaux de conteneurs.
- [Socket command injection](socket-command-injection.md) couvre les commandes acceptées via des sockets locaux exposés.
- [Cisco vManage](cisco-vmanage.md) documente une cible spécifique à ce produit et les vérifications associées.
