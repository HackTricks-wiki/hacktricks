- [Análisis de la red local y los sockets](local-network-and-socket-triage.md) abarca los servicios loopback, los sockets Unix y las redes de contenedores.
- [Inyección de comandos mediante sockets](socket-command-injection.md) abarca los comandos aceptados a través de sockets locales expuestos.
- [Cisco vManage](cisco-vmanage.md) documenta un objetivo específico del producto y las comprobaciones relacionadas.
