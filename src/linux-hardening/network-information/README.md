- [Przechwytywanie ruchu, zapora sieciowa i analiza ruchu wychodzącego](traffic-capture-and-firewall-egress.md) obejmuje przechwytywanie pakietów, filtrowanie, proxy i testy łączności.
- [Analiza sieci lokalnej i gniazd](local-network-and-socket-triage.md) obejmuje usługi loopback, gniazda Unix i sieci kontenerów.
- [Socket command injection](socket-command-injection.md) opisuje polecenia przyjmowane przez udostępnione gniazda lokalne.
- [Cisco vManage](cisco-vmanage.md) opisuje cel związany z konkretnym produktem i powiązane kontrole.
