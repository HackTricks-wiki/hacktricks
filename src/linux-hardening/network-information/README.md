# Мережева інформація

{{#include ../../banners/hacktricks-training.md}}

Локальні служби, що прослуховують порти, Unix-сокети та програмне забезпечення, доступне з мережі, можуть відкривати шляхи, непомітні під час зовнішнього сканування. Почніть зі служб, що прослуховують порти на хості, та процесу, якому належить кожна кінцева точка.

- [Захоплення трафіку, firewall і аналіз вихідного трафіку](traffic-capture-and-firewall-egress.md) охоплює захоплення пакетів, фільтрацію, проксі та тести підключення.
- [Аналіз локальної мережі та сокетів](local-network-and-socket-triage.md) охоплює служби loopback, Unix-сокети та мережі контейнерів.
- [Ін’єкція команд через сокети](socket-command-injection.md) охоплює команди, що приймаються через відкриті локальні сокети.
- [Cisco vManage](cisco-vmanage.md) описує ціль для конкретного продукту та пов’язані перевірки.
