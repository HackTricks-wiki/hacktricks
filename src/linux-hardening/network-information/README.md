# 네트워크 정보

로컬 리스너, Unix 소켓, 네트워크에 노출된 소프트웨어는 외부 스캔으로는 보이지 않는 경로를 드러낼 수 있습니다. 호스트의 리스닝 서비스와 각 엔드포인트를 소유한 프로세스부터 확인하세요.

- [트래픽 캡처, 방화벽 및 이그레스 트리아지](traffic-capture-and-firewall-egress.md)는 패킷 캡처, 필터링, 프록시 및 연결 테스트를 다룹니다.
- [로컬 네트워크 및 소켓 트리아지](local-network-and-socket-triage.md)는 루프백 서비스, Unix 소켓 및 컨테이너 네트워크를 다룹니다.
- [Socket command injection](socket-command-injection.md)은 노출된 로컬 소켓을 통해 전달되는 명령을 다룹니다.
- [Cisco vManage](cisco-vmanage.md)는 특정 제품과 관련 검사 항목을 설명합니다.
