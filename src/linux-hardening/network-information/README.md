- [Capture de trafic, pare-feu et analyse de la sortie réseau](traffic-capture-and-firewall-egress.md) couvre la capture de paquets, le filtrage, les proxys et les tests de connectivité.
- [Analyse du réseau local et des sockets](local-network-and-socket-triage.md) couvre les services loopback, les sockets Unix et les réseaux de conteneurs.
- [Socket command injection](socket-command-injection.md) couvre les commandes acceptées via des sockets locaux exposés.
- [Cisco vManage](cisco-vmanage.md) présente une cible propre à un produit et les vérifications associées.
