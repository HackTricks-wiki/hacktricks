# Καταγραφή κίνησης, Firewall και διαλογή εξερχόμενης κίνησης

{{#include ../../banners/hacktricks-training.md}}

Αφού εντοπίσετε [τοπικές υπηρεσίες ακρόασης και Unix sockets](local-network-and-socket-triage.md), ελέγξτε ποιες διεπαφές μεταφέρουν την κίνησή τους και ποιοι κανόνες firewall ή proxy επηρεάζουν την προσβασιμότητά τους. Μια υπηρεσία προσβάσιμη μόνο μέσω loopback μπορεί να μεταφέρει ευαίσθητες HTTP κεφαλίδες, ακόμη κι αν δεν είναι προσβάσιμη από άλλον host.

## Ελέγξτε τα δικαιώματα καταγραφής και επιλέξτε διεπαφή

```bash
ip -br addr
ip route
getcap "$(command -v dumpcap)" 2>/dev/null
tcpdump -D 2>/dev/null
```

Το `dumpcap` μπορεί να διαθέτει δυνατότητες καταγραφής πακέτων ακόμη κι όταν ο τρέχων χρήστης δεν έχει πρόσβαση μέσω sudo. Ελέγξτε τις πραγματικές δυνατότητες του εκτελέσιμου αρχείου και τα δικαιώματα της ομάδας. Περιορίστε την καταγραφή στην ελάχιστη χρήσιμη διεπαφή, διάρκεια και φίλτρο· μια καταγραφή μπορεί να περιέχει διαπιστευτήρια ή προσωπικά δεδομένα.

```bash
sudo tcpdump -i lo -s 0 -w /tmp/loopback.pcap 'tcp port 8080'
tshark -r /tmp/loopback.pcap -Y 'http.request' -T fields -e ip.src -e http.host -e http.request.uri
tcpflow -r /tmp/loopback.pcap 2>/dev/null
```

`tcpflow` ανασυνθέτει plaintext TCP streams· το `tshark` μπορεί να φιλτράρει και να εξάγει πεδία από ένα capture. Για TLS traffic, η αποκρυπτογράφηση απαιτεί endpoint keys ή έναν υποστηριζόμενο client που έχει ρυθμιστεί για `SSLKEYLOGFILE` πριν από τη σύνδεση. Η [σελίδα διαλογής τοπικού δικτύου και socket](local-network-and-socket-triage.md#tls-key-logging) παρουσιάζει αυτή τη διαδικασία. Μην αντιμετωπίζετε ένα κρυπτογραφημένο capture ως αναγνώσιμο plaintext.

Τα αποθηκευμένα artifacts περιστατικών μπορούν να αλλάξουν αυτή την εκτίμηση. Ένα [Linux core dump είναι εικόνα της μνήμης μιας διεργασίας](https://man7.org/linux/man-pages/man5/core.5.html), στην οποία μπορεί να διατηρείται ένα session key· αν ένα αναγνώσιμο dump και ένα packet capture προέρχονται από την ίδια διεργασία και session, ένας αναλυτής ενδέχεται να μπορεί να αποκρυπτογραφήσει εκείνη την κίνηση. Καταγράψτε πρώτα τις διαδρομές και τα permissions των artifacts και, στη συνέχεια, επαληθεύστε ξεχωριστά την ταυτότητα της διεργασίας, τον χρόνο του capture, το πρωτόκολλο και τη μορφή του key. Η αποκρυπτογραφημένη κίνηση ή ένα ανακτημένο archive αποτελούν ένδειξη πιθανής αποκάλυψης, όχι απόδειξη πρόσβασης σε λογαριασμό άλλου ατόμου: τυχόν μερικό υλικό SSH key πρέπει πρώτα να ανασυντεθεί, να αντιστοιχιστεί με το αντίστοιχο public key και να γίνει αποδεκτό από την πολιτική SSH αυτού του λογαριασμού. Αποφύγετε να εμφανίζετε περιεχόμενα core ή payloads capture σε εξόδους ευρείας απαρίθμησης.

## Εντοπισμός επιπέδων firewall

```bash
sudo nft list ruleset 2>/dev/null
sudo iptables-save 2>/dev/null
sudo ufw status verbose 2>/dev/null
sudo firewall-cmd --list-all 2>/dev/null
```

`nftables` και `iptables` μπορεί να είναι διαθέσιμα μέσω wrappers της διανομής, όπως το UFW ή το firewalld. Διαβάστε τους ενεργούς κανόνες και την αποθηκευμένη διαμόρφωση του wrapper· ένας κανόνας που εμφανίζεται σε μία αναπαράσταση μπορεί να έχει δημιουργηθεί από άλλο εργαλείο. Ελέγξτε τη διεπαφή, την κατεύθυνση, την πηγή, τον προορισμό, το πρωτόκολλο, τη θύρα και την κατάσταση σύνδεσης πριν αποδώσετε τον αποκλεισμό μιας υπηρεσίας σε συγκεκριμένο κανόνα. Δείτε το [nftables rule review](local-network-and-socket-triage.md#nftables-review-and-authorized-rule-changes) για ένα συγκεκριμένο παράδειγμα.

## Δοκιμή εξερχόμενης κίνησης και συμπεριφοράς proxy

```bash
ip route get 1.1.1.1
getent hosts example.com
curl -I --connect-timeout 3 https://example.com/
printenv http_proxy https_proxy all_proxy no_proxy 2>/dev/null
```

Διαχωρίστε την αποτυχία DNS από την αποτυχία TCP, TLS ή proxy. Ελέγξτε τον συγκεκριμένο προορισμό και το πρωτόκολλο που σχετίζονται με την αξιολόγηση· η προσβασιμότητα μέσω ICMP δεν σημαίνει ότι επιτρέπεται το TCP ή το UDP. Αν έχει ρυθμιστεί proxy, συγκρίνετε το προβλεπόμενο αίτημα μέσω proxy με το ίδιο αίτημα προς τον ίδιο στόχο, εφαρμόζοντας τους σχετικούς κανόνες `no_proxy`. Μια τοπική προώθηση θύρας μπορεί επίσης να καταστήσει μια υπηρεσία loopback διαθέσιμη από αλλού, οπότε ελέγξτε τους ενεργούς listeners και τα SSH tunnels όταν η εικόνα του firewall και η παρατηρούμενη έκθεση δεν συμφωνούν.
