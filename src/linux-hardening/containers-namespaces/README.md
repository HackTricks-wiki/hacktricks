# Контейнери та простори імен

{{#include ../../banners/hacktricks-training.md}}

Контейнер — це процес Linux, який виконується з налаштуваннями ізоляції та привілеїв. Оцінюйте середовище виконання, змонтовані ресурси хоста, надані можливості та налаштування просторів імен у сукупності. У [огляді безпеки контейнерів](container-security/README.md) пояснено ці рівні та наведено посилання на кожен із засобів керування ними.

- У матеріалі про [підвищення привілеїв через Containerd (`ctr`)](containerd-ctr-privilege-escalation.md) розглянуто доступ до інтерфейсу керування containerd.
- У матеріалі про [підвищення привілеїв через RunC](runc-privilege-escalation.md) розглянуто специфічні для середовища виконання методи підвищення привілеїв.
- У розділі про [безпеку контейнерів](container-security/README.md) пояснено середовища виконання, відкриті API, ризики образів, чутливі монтування, привілейовані контейнери, оцінювання безпеки та засоби захисту, як-от простори імен, seccomp і обов’язковий контроль доступу.
