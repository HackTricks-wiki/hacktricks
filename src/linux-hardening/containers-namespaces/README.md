# Контейнери та простори імен

{{#include ../../banners/hacktricks-training.md}}

Контейнер — це процес Linux, що працює з конфігурацією ізоляції та привілеїв. Оцінюйте середовище виконання, змонтовані ресурси хоста, надані capabilities і налаштування просторів імен разом. [Огляд безпеки контейнерів](container-security/README.md) пояснює ці рівні та містить посилання на кожен із засобів контролю.

- [Підвищення привілеїв через Containerd (`ctr`)](containerd-ctr-privilege-escalation.md) зосереджене на доступі до інтерфейсу керування containerd.
- [Підвищення привілеїв через RunC](runc-privilege-escalation.md) охоплює матеріали про підвищення привілеїв, специфічні для середовища виконання.
- [Безпека контейнерів](container-security/README.md) пояснює середовища виконання, відкриті API, ризики образів, чутливі монтування, привілейовані контейнери, оцінювання та засоби захисту, як-от простори імен, seccomp і обов'язковий контроль доступу.
