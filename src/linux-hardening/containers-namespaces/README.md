# Контейнери та простори імен

{{#include ../../banners/hacktricks-training.md}}

Контейнер — це процес Linux, запущений із певними налаштуваннями ізоляції та привілеїв. Оцінюйте середовище виконання, змонтовані ресурси хоста, надані capabilities і налаштування просторів імен у сукупності. У [огляді безпеки контейнерів](container-security/README.md) описано ці рівні та наведено посилання на відповідні засоби контролю.

- [Containerd (`ctr`) privilege escalation](containerd-ctr-privilege-escalation.md) присвячено доступу до інтерфейсу керування containerd.
- [RunC privilege escalation](runc-privilege-escalation.md) містить матеріали про ескалацію привілеїв, специфічні для середовища виконання.
- [Безпека контейнерів](container-security/README.md) пояснює середовища виконання, відкриті API, ризики образів, чутливі монтування, привілейовані контейнери, оцінювання та засоби захисту, як-от простори імен, seccomp і обов’язковий контроль доступу.
