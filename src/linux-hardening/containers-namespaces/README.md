# Kontena na Namespaces

{{#include ../../banners/hacktricks-training.md}}

Kontena ni mchakato wa Linux unaoendeshwa kwa usanidi wa utenganishaji na ruhusa. Tathmini runtime, rasilimali za host zilizowekwa, uwezo uliotolewa na mipangilio ya namespace kwa pamoja. [Muhtasari wa usalama wa kontena](container-security/README.md) unaeleza tabaka hizi na kuunganisha kila udhibiti.

- [Containerd (`ctr`) privilege escalation](containerd-ctr-privilege-escalation.md) inaangazia ufikiaji wa kiolesura cha usimamizi cha containerd.
- [RunC privilege escalation](runc-privilege-escalation.md) inaeleza mbinu za escalation zinazohusiana na runtime.
- [Usalama wa kontena](container-security/README.md) unaeleza runtimes, API zilizo wazi, hatari za image, mount nyeti, kontena zenye ruhusa za juu, tathmini na ulinzi kama namespaces, seccomp na udhibiti wa lazima wa ufikiaji.
