# Посилення безпеки Linux

{{#include ../banners/hacktricks-training.md}}

Використовуйте цей розділ, щоб досліджувати хости Linux, розуміти межі привілеїв і перевіряти засоби контролю, які обмежують локальний доступ. Для загальної оцінки почніть із [основ Linux](linux-basics/README.md) і [контрольного списку підвищення привілеїв](main-system-information/linux-privilege-escalation-checklist.md), а потім перейдіть до відповідної теми нижче.

- [Основи Linux](linux-basics/README.md): методологія підвищення привілеїв, корисні команди, змінні середовища та способи обходу обмежень.
- [Основна інформація про систему](main-system-information/README.md): ядро, модулі, sudo, поведінка файлової системи, ізольовані середовища та контрольний список підвищення привілеїв.
- [Інформація про користувачів](user-information/README.md): ідентифікатори користувачів Linux, групи, пересилання SSH-агента та інтеграція з Active Directory.
- [Цікаві файли та дозволи](interesting-files-permissions/README.md): доступні для запису шляхи, capabilities, поведінка SUID, NFS, розгортання шаблонів і SELinux.
- [Інформація про мережу](network-information/README.md): локальні служби, сокети та приклади експлуатації, пов’язані з мережею.
- [Інформація про програмне забезпечення](software-information/README.md): модулі автентифікації та специфічні для застосунків поверхні атаки.
- [Процеси, crontab, systemd і D-Bus](processes-crontab-systemd-dbus/README.md): заплановане виконання та міжпроцесна взаємодія.
- [Контейнери та простори імен](containers-namespaces/README.md): середовища виконання, межі ізоляції та посилення безпеки контейнерів.
- [Постексплуатація](post-exploitation/README.md): пошук облікових даних, закріплення та подальші методи на рівні хоста.
