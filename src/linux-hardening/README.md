# Посилення захисту Linux

{{#include ../banners/hacktricks-training.md}}

Використовуйте цей розділ для дослідження хостів Linux, розуміння меж привілеїв і перевірки засобів контролю, що обмежують локальний доступ. Для загальної оцінки почніть з [основ Linux](linux-basics/README.md) і [контрольного списку підвищення привілеїв](main-system-information/linux-privilege-escalation-checklist.md), а потім перейдіть до відповідної теми нижче.

- [Основи Linux](linux-basics/README.md): методологія підвищення привілеїв, корисні команди, змінні середовища та обхід обмежень.
- [Основна інформація про систему](main-system-information/README.md): ядро, модулі, sudo, поведінка файлової системи, ізольовані середовища та контрольний список підвищення привілеїв.
- [Інформація про користувачів](user-information/README.md): ідентифікатори Linux, групи, пересилання агента SSH та інтеграція з Active Directory.
- [Цікаві файли та права доступу](interesting-files-permissions/README.md): доступні для запису шляхи, capabilities, поведінка SUID, NFS, розгортання шаблонів і SELinux.
- [Інформація про мережу](network-information/README.md): локальні служби, сокети та приклади експлуатації, пов’язані з мережею.
- [Інформація про програмне забезпечення](software-information/README.md): модулі автентифікації та специфічні для застосунків поверхні атаки.
- [Процеси, crontab, systemd і D-Bus](processes-crontab-systemd-dbus/README.md): заплановане виконання та міжпроцесна взаємодія.
- [Контейнери та простори імен](containers-namespaces/README.md): середовища виконання, межі ізоляції та посилення захисту контейнерів.
- [Post-exploitation](post-exploitation/README.md): пошук облікових даних, закріплення та подальші методи на рівні хоста.
