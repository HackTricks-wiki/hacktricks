# Διεργασίες, Crontab, Systemd και D-Bus

{{#include ../../banners/hacktricks-training.md}}

Οι προγραμματισμένες εργασίες και η επικοινωνία μεταξύ διεργασιών μπορούν να εκτελέσουν κώδικα με διαφορετικά προνόμια από αυτά του καλούντος. Πριν από τη δοκιμή, ελέγξτε τον κάτοχο, την εντολή και τα εγγράψιμα δεδομένα εισόδου μιας υπηρεσίας ή εργασίας.

- Η ενότητα [Απαρίθμηση διεργασιών και διαδρομές υπηρεσιών](process-enumeration-and-service-paths.md) καλύπτει τα δέντρα διεργασιών, τα αρχεία χρόνου εκτέλεσης και τις αλυσίδες εκτέλεσης systemd.
- Η ενότητα [Cron jobs και χρονιστές systemd](cron-and-systemd-timers.md) καλύπτει τον εντοπισμό προγραμματισμένων εργασιών και τα εγγράψιμα δεδομένα εισόδου.
- Η ενότητα [Απαρίθμηση D-Bus και κλιμάκωση προνομίων μέσω command injection](d-bus-enumeration-and-command-injection-privilege-escalation.md) καλύπτει τον δίαυλο μηνυμάτων και τις μεθόδους προνομιούχων υπηρεσιών.
- Η ενότητα [Payloads προς εκτέλεση](payloads-to-execute.md) συγκεντρώνει payloads που μπορούν να χρησιμοποιηθούν όταν έχει εντοπιστεί μια διαδρομή εκτέλεσης.

Για μια ευρύτερη επισκόπηση των cron jobs και των υπηρεσιών systemd, χρησιμοποιήστε τη [λίστα ελέγχου κλιμάκωσης προνομίων Linux](../main-system-information/linux-privilege-escalation-checklist.md).
