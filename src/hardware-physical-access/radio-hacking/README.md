# Радіохакінг

{{#include ../../banners/hacktricks-training.md}}

Тестування безпеки радіозв’язку досліджує, як пристрій передає, приймає та інтерпретує бездротові сигнали. Програмно-визначене радіо (SDR) допомагає виявити сигнал, записати синфазні та квадратурні (I/Q) відліки, а також перевірити демодуляцію й декодування без прив’язки до спеціалізованого обладнання для конкретного протоколу.<sup>[[1]](#references)</sup>

Практичний процес полягає у визначенні частотного діапазону й ширини каналу, захопленні сигналів кількох відомих дій пристрою, порівнянні отриманих сигналів, а потім визначенні модуляції та структури пакетів. Перевіряйте повторне відтворення або передачу сигналу лише в ізольованому середовищі та на частотах і обладнанні, для яких ви маєте дозвіл. Сторінки цього розділу охоплюють RFID, NFC, субгігагерцовий радіозв’язок, інфрачервоний зв’язок, BLE та пов’язані інструменти.<sup>[[1]](#references)</sup>

## Знайдіть потрібний інтерфейс

- Для перепустки або контактного ключа почніть із [типів тегів RFID/NFC та атак](pentesting-rfid.md), [робочих процесів Proxmark3](proxmark-3.md) або [ключів iButton і 1-Wire](ibutton.md). [Посібник Flipper Zero](flipper-zero/README.md) містить посилання на дії для відповідних інтерфейсів.
- Для сигналу пульта дистанційного керування скористайтеся матеріалами про [субгігагерцовий RF і кодові послідовності зі змінним кодом](sub-ghz-rf.md) або [інфрачервоні протоколи та атаки](infrared.md).
- Для пристроїв поблизу та датчиків скористайтеся матеріалами про [BLE-рекламу, GATT і тестування mesh](pentesting-ble-bluetooth-low-energy.md) або [безпеку LPWAN/LoRaWAN](low-power-wide-area-network.md).
- Для захоплених або невідомих RF-сигналів скористайтеся [аналізом сигналів у SigDigger](../hardware-hacking/radio.md#sigdigger) або [фреймворком FISSURE](fissure-the-rf-framework.md).
