# Радіохакінг

{{#include ../../banners/hacktricks-training.md}}

Тестування безпеки радіозв’язку вивчає, як пристрій передає, приймає та інтерпретує бездротові сигнали. Програмно-визначене радіо (SDR) допомагає знайти сигнал, записати синфазні/квадратурні (I/Q) відліки й перевірити демодуляцію та декодування без прив’язки до спеціалізованого обладнання для конкретного протоколу.<sup>[[1]](#references)</sup>

Практичний процес: визначте діапазон частот і ширину каналу, зафіксуйте кілька відомих дій пристрою, порівняйте отримані сигнали, а потім визначте тип модуляції та структуру пакетів. Перевіряйте повторне відтворення або передавання лише в ізольованому середовищі та на частотах і обладнанні, для роботи з якими маєте дозвіл. У цьому розділі розглянуто RFID, NFC, радіозв’язок нижче 1 ГГц, інфрачервоний зв’язок, BLE та пов’язані інструменти.<sup>[[1]](#references)</sup>

## Знайдіть відповідний інтерфейс

- Для пропуску або контактного ключа почніть із [типів і атак на RFID/NFC-мітки](pentesting-rfid.md), [процесів роботи з Proxmark3](proxmark-3.md) або [ключів iButton і 1-Wire](ibutton.md). У [посібнику з Flipper Zero](flipper-zero/README.md) наведено посилання на дії для конкретних інтерфейсів.
- Для сигналу пульта дистанційного керування використовуйте [радіочастоти нижче 1 ГГц і код з перемінним значенням](sub-ghz-rf.md) або [інфрачервоні протоколи й атаки](infrared.md).
- Для пристроїв і датчиків поблизу використовуйте [тестування BLE-реклами, GATT і mesh-мереж](pentesting-ble-bluetooth-low-energy.md) або [безпеку LPWAN/LoRaWAN](low-power-wide-area-network.md).
- Для записаних або невідомих радіосигналів використовуйте [аналіз сигналів у SigDigger](../hardware-hacking/radio.md#sigdigger) або [фреймворк FISSURE](fissure-the-rf-framework.md).
- Інформацію про низхідні канали супутникових терміналів див. у розділі [ін’єкція сигналу прямого каналу VSAT](vsat-forward-link-injection.md).
