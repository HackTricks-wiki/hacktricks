# Hacking Ραδιοεπικοινωνιών

{{#include ../../banners/hacktricks-training.md}}

Οι δοκιμές ασφάλειας ραδιοεπικοινωνιών εξετάζουν τον τρόπο με τον οποίο μια συσκευή εκπέμπει, λαμβάνει και ερμηνεύει ασύρματα σήματα. Ένα software-defined radio (SDR) μπορεί να βοηθήσει στον εντοπισμό ενός σήματος, στην καταγραφή δειγμάτων εντός φάσης/τετραγωνικής συνιστώσας (I/Q) και στη δοκιμή αποδιαμόρφωσης και αποκωδικοποίησης, χωρίς να απαιτείται εξειδικευμένο υλικό για συγκεκριμένα πρωτόκολλα.<sup>[[1]](#references)</sup>

Μια πρακτική ροή εργασίας είναι να εντοπίσετε τη ζώνη συχνοτήτων και το εύρος καναλιού, να καταγράψετε διάφορες γνωστές ενέργειες της συσκευής, να συγκρίνετε τα σήματα που προκύπτουν και, στη συνέχεια, να προσδιορίσετε τη διαμόρφωση και τη δομή των πακέτων. Δοκιμάστε αναπαραγωγή ή μετάδοση μόνο σε απομονωμένο περιβάλλον και σε συχνότητες και εξοπλισμό για τους οποίους έχετε εξουσιοδότηση. Οι σελίδες αυτής της ενότητας καλύπτουν RFID, NFC, ραδιοεπικοινωνίες sub-GHz, υπέρυθρες, BLE και σχετικά εργαλεία.<sup>[[1]](#references)</sup>

## Βρείτε την κατάλληλη διεπαφή

- Για μια κάρτα πρόσβασης ή ένα κλειδί επαφής, ξεκινήστε με τους [τύπους ετικετών RFID/NFC και τις επιθέσεις](pentesting-rfid.md), τις [ροές εργασίας Proxmark3](proxmark-3.md) ή τα [κλειδιά iButton και 1-Wire](ibutton.md). Ο [οδηγός Flipper Zero](flipper-zero/README.md) παραπέμπει στις ενέργειες που αφορούν τη συγκεκριμένη διεπαφή.
- Για ένα σήμα τηλεχειριστηρίου, δείτε τις [ραδιοσυχνότητες sub-GHz και τους κυλιόμενους κωδικούς](sub-ghz-rf.md) ή τα [πρωτόκολλα και τις επιθέσεις υπερύθρων](infrared.md).
- Για κοντινές συσκευές και αισθητήρες, δείτε τις [δοκιμές BLE advertising, GATT και mesh](pentesting-ble-bluetooth-low-energy.md) ή την [ασφάλεια LPWAN/LoRaWAN](low-power-wide-area-network.md).
- Για καταγεγραμμένα ή άγνωστα σήματα RF, χρησιμοποιήστε την [ανάλυση σημάτων SigDigger](../hardware-hacking/radio.md#sigdigger) ή το [framework FISSURE](fissure-the-rf-framework.md).
