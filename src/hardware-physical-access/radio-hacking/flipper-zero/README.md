# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Flipper Zero is ’n draagbare hardeware-multigereedskap wat die volgende vermoëns ondersteun:<sup>[[1]](#references)</sup>

- **Ontvang, neem ondersteunde radioseine op en speel dit weer af:** [**Sub-GHz**](fz-sub-ghz.md)
- **Lees, neem ondersteunde NFC-kaarte op en emuleer hulle:** [**NFC**](fz-nfc.md)
- **Lees, neem ondersteunde 125 kHz-etikette op en emuleer hulle:** [**125 kHz RFID**](fz-125khz-rfid.md)
- **Lees, neem infrarooi seine op en stuur hulle uit:** [**Infrarooi**](fz-infrared.md)
- **Lees, neem ondersteunde iButtons op en emuleer hulle:** [**iButton**](../ibutton.md)
- **Tree op as ’n BadUSB-toestel**
- **Tree op as ’n U2F-sekuriteitsleutel**
- **Laat toepassings en speletjies soos Snake loop**

Sien die Awesome Flipper Zero-versameling vir firmware, toepassings, databasisse en ander hulpbronne wat deur die gemeenskap onderhou word.<sup>[[2]](#references)</sup>
