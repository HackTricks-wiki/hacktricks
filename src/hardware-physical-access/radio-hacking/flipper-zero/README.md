# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Flipper Zero — це портативний апаратний мультитул із такими можливостями:<sup>[[1]](#references)</sup>

- **Приймати, захоплювати та відтворювати підтримувані радіосигнали:** [**Sub-GHz**](fz-sub-ghz.md)
- **Зчитувати, захоплювати та емулювати підтримувані NFC-картки:** [**NFC**](fz-nfc.md)
- **Зчитувати, захоплювати та емулювати підтримувані мітки 125 kHz:** [**125 kHz RFID**](fz-125khz-rfid.md)
- **Зчитувати, захоплювати та передавати інфрачервоні сигнали:** [**Інфрачервоний зв’язок**](fz-infrared.md)
- **Зчитувати, захоплювати та емулювати підтримувані iButton:** [**iButton**](../ibutton.md)
- **Працювати як пристрій BadUSB**
- **Працювати як ключ безпеки U2F**
- **Запускати застосунки та ігри, наприклад Snake**

Колекцію Awesome Flipper Zero з прошивками, застосунками, базами даних та іншими ресурсами, які підтримує спільнота, дивіться тут.<sup>[[2]](#references)</sup>
