# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Flipper Zero एक पोर्टेबल hardware multitool है, जो निम्नलिखित क्षमताओं को सपोर्ट करता है:<sup>[[1]](#references)</sup>

- **सपोर्टेड radio signals प्राप्त करना, कैप्चर करना और फिर से चलाना:** [**Sub-GHz**](fz-sub-ghz.md)
- **सपोर्टेड NFC cards पढ़ना, कैप्चर करना और emulate करना:** [**NFC**](fz-nfc.md)
- **सपोर्टेड 125 kHz tags पढ़ना, कैप्चर करना और emulate करना:** [**125 kHz RFID**](fz-125khz-rfid.md)
- **Infrared signals पढ़ना, कैप्चर करना और transmit करना:** [**Infrared**](fz-infrared.md)
- **सपोर्टेड iButtons पढ़ना, कैप्चर करना और emulate करना:** [**iButton**](../ibutton.md)
- **BadUSB device के रूप में काम करना**
- **U2F security key के रूप में काम करना**
- **Snake जैसे applications और games चलाना**

Community द्वारा मेंटेन किए गए firmware, applications, databases और अन्य संसाधनों के लिए, Awesome Flipper Zero collection देखें।<sup>[[2]](#references)</sup>
