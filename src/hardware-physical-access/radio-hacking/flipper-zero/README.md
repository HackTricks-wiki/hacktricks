# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Flipper Zeroは、次の機能に対応したポータブルなハードウェアマルチツールです。<sup>[[1]](#references)</sup>

- **対応する無線信号の受信、キャプチャ、再生:** [**Sub-GHz**](fz-sub-ghz.md)
- **対応するNFCカードの読み取り、キャプチャ、エミュレート:** [**NFC**](fz-nfc.md)
- **対応する125 kHzタグの読み取り、キャプチャ、エミュレート:** [**125 kHz RFID**](fz-125khz-rfid.md)
- **赤外線信号の読み取り、キャプチャ、送信:** [**赤外線**](fz-infrared.md)
- **対応するiButtonの読み取り、キャプチャ、エミュレート:** [**iButton**](../ibutton.md)
- **BadUSBデバイスとして動作**
- **U2Fセキュリティキーとして動作**
- **Snakeなどのアプリケーションやゲームを実行**

コミュニティがメンテナンスするファームウェア、アプリケーション、データベース、その他のリソースについては、Awesome Flipper Zeroコレクションをご覧ください。<sup>[[2]](#references)</sup>
