# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Flipper Zero는 다음 기능을 지원하는 휴대용 하드웨어 멀티툴입니다:<sup>[[1]](#references)</sup>

- **지원되는 무선 신호 수신, 캡처 및 재생:** [**Sub-GHz**](fz-sub-ghz.md)
- **지원되는 NFC 카드 읽기, 캡처 및 에뮬레이션:** [**NFC**](fz-nfc.md)
- **지원되는 125 kHz 태그 읽기, 캡처 및 에뮬레이션:** [**125 kHz RFID**](fz-125khz-rfid.md)
- **적외선 신호 읽기, 캡처 및 전송:** [**Infrared**](fz-infrared.md)
- **지원되는 iButton 읽기, 캡처 및 에뮬레이션:** [**iButton**](../ibutton.md)
- **BadUSB 장치로 작동**
- **U2F 보안 키로 작동**
- **Snake와 같은 애플리케이션 및 게임 실행**

커뮤니티에서 관리하는 펌웨어, 애플리케이션, 데이터베이스 및 기타 리소스는 Awesome Flipper Zero 컬렉션을 참조하세요.<sup>[[2]](#references)</sup>
