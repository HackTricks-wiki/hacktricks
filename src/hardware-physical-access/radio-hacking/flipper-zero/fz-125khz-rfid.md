## Ενέργειες

### Ανάγνωση

Χρησιμοποιήστε την επιλογή **Read** για να καταγράψετε τα δεδομένα του tag. Μετά από επιτυχή ανάγνωση, το Flipper Zero μπορεί να εξομοιώσει το αποθηκευμένο tag.<sup>[[1]](#references)</sup>

> [!WARNING]
> Ορισμένοι readers ενδοεπικοινωνίας προσπαθούν να εντοπίσουν εγγράψιμα αντίγραφα tags στέλνοντας μια εντολή εγγραφής πριν από την ανάγνωση. Η εξομοίωση από το Flipper Zero δεν παρέχει πρόσβαση στην εγγράψιμη μνήμη του tag με τον ίδιο τρόπο.<sup>[[1]](#references)</sup>

### Μη αυτόματη προσθήκη

Μπορείτε να εισαγάγετε μη αυτόματα τα δεδομένα του tag στο Flipper Zero, να τα αποθηκεύσετε και έπειτα να τα εξομοιώσετε.<sup>[[1]](#references)</sup>

#### ID στις κάρτες

Μερικές φορές, ολόκληρο ή μέρος του ID μιας κάρτας είναι τυπωμένο στην εξωτερική της πλευρά.

- **EM Marin**

Για παράδειγμα, η εικονιζόμενη κάρτα EM-Marin εμφανίζει τα τρία τελευταία από τα πέντε byte του ID της. Αν δεν είναι δυνατή η ανάγνωση του tag, τα δύο byte που λείπουν μπορούν να βρεθούν με brute-force.

- **HID**

Αντίστοιχα, η εικονιζόμενη κάρτα HID εμφανίζει μόνο δύο από τα τρία byte του ID της.

### Εξομοίωση/Εγγραφή

Μετά την ανάγνωση ενός tag ή τη μη αυτόματη εισαγωγή του ID του, το Flipper Zero μπορεί να εξομοιώσει το αποθηκευμένο διαπιστευτήριο. Για υποστηριζόμενα εγγράψιμα tags, μπορεί επίσης να εγγράψει τα αποθηκευμένα δεδομένα σε συμβατή κάρτα.<sup>[[1]](#references)</sup>
