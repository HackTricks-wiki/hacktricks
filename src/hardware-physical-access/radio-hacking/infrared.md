## 赤外線の仕組み <a href="#how-the-infrared-port-works" id="how-the-infrared-port-works"></a>

**赤外線は人間の目には見えません**。IRの波長は**0.7～1000ミクロン**です。家庭用リモコンはデータ送信にIR信号を使い、波長0.75～1.4ミクロンの範囲で動作します。リモコン内のマイクロコントローラーが、赤外線LEDを特定の周波数で点滅させ、デジタル信号をIR信号に変換します。

IR信号の受信には**フォトレシーバー**を使います。フォトレシーバーは**IR光を電圧パルスに変換**し、これらはすでに**デジタル信号**です。通常、受信機の内部には**暗色の光学フィルター**があり、**目的の波長だけを通過させて**ノイズを除去します。<sup>[[1]](#references)</sup>

### IRプロトコルの種類 <a href="#variety-of-ir-protocols" id="variety-of-ir-protocols"></a>

IRプロトコルは、次の3つの要素が異なります。<sup>[[1]](#references)</sup>

- ビットのエンコード方式
- データ構造
- 搬送波周波数 — 多くの場合、36～38 kHzの範囲

#### ビットのエンコード方式 <a href="#bit-encoding-ways" id="bit-encoding-ways"></a>

**1. パルス間隔エンコード**

パルス間の空白の長さを変調してビットをエンコードします。パルス自体の幅は一定です。

<figure><img src="../../images/image (295).png" alt=""><figcaption></figcaption></figure>

**2. パルス幅エンコード**

パルス幅を変調してビットをエンコードします。パルスの後に続く空白の幅は一定です。

<figure><img src="../../images/image (282).png" alt=""><figcaption></figcaption></figure>

**3. 位相エンコード**

Manchester encodingとも呼ばれます。論理値は、パルス列と空白の間の遷移方向によって決まります。「空白からパルス列」は論理「0」、「パルス列から空白」は論理「1」を表します。

<figure><img src="../../images/image (634).png" alt=""><figcaption></figcaption></figure>

**4. 上記方式の組み合わせや、その他の特殊な方式**

> [!TIP]
> 複数の種類のデバイスで使える**汎用規格を目指している**IRプロトコルもあります。よく知られているのはRC5とNECです。残念ながら、最も有名だからといって**最も一般的とは限りません**。私の周囲では、NECリモコンは2台だけ見かけましたが、RC5リモコンは一度も見かけませんでした。
>
> メーカーは、同じ種類のデバイス（たとえばTVボックス）でも、独自のIRプロトコルを使いたがります。そのため、異なる会社のリモコンや、同じ会社の異なるモデルのリモコンは、同じ種類の他のデバイスを操作できないことがあります。

### IR信号を調べる

リモコンのIR信号の波形を確認するには、オシロスコープを使うのが最も確実です。オシロスコープは受信信号を復調したり反転したりせず、そのまま表示します。これはテストやデバッグに役立ちます。NEC IRプロトコルを例に、期待される信号を説明します。<sup>[[1]](#references)</sup>

<figure><img src="../../images/image (235).png" alt=""><figcaption></figcaption></figure>

通常、エンコードされたパケットの先頭にはプリアンブルがあります。これによって受信機はゲインや背景レベルを判断できます。Sharpなど、プリアンブルのないプロトコルもあります。

その後、データが送信されます。データ構造、プリアンブル、ビットのエンコード方式は、プロトコルごとに決まっています。

**NEC IRプロトコル**には短いコマンドとリピートコードが含まれ、ボタンが押されている間、リピートコードが送信されます。コマンドとリピートコードは、どちらも先頭に同じプリアンブルがあります。

NECの**コマンド**は、プリアンブルに加えて、アドレスバイトとコマンド番号バイトで構成されます。これらの値をもとにデバイスは実行する処理を判断します。送信の整合性を確認するため、アドレスバイトとコマンド番号バイトは反転した値とともに重複して送信されます。コマンドの末尾には追加のストップビットがあります。

**リピートコード**では、プリアンブルの後に「1」が続きます。これはストップビットです。

**論理「0」と「1」**には、NECはパルス間隔エンコードを使います。まずパルス列が送信され、その後に続く一時停止の長さによってビット値が決まります。

### エアコン

他のリモコンとは異なり、**エアコンは押されたボタンのコードだけを送信するのではありません**。ボタンを押すと、**情報全体も送信**し、**エアコン本体とリモコンの同期を保ちます**。\
これにより、設定温度が20ºCのエアコンを一方のリモコンで21ºCに上げた後、温度設定がまだ20ºCの別のリモコンを使ってさらに温度を上げた際に、エアコンが21ºCではなく22ºCになるはずのところを、再び21ºCに「上げて」しまうことを防げます。<sup>[[1]](#references)</sup>

### Smart-TV / セットトップボックスの乗っ取り（EvilScreen）

近年の研究（EvilScreen、2022）では、赤外線とBluetoothまたはWi-Fiを組み合わせた**マルチチャネルリモコンを悪用して、最新のsmart-TVを完全に乗っ取れる**ことが実証されました。この攻撃では、高い権限を持つIRサービスコードと認証済みBluetoothパケットを連鎖させ、チャネル分離を回避して、物理的なアクセスなしに任意のアプリの起動、マイクの有効化、または工場出荷時設定へのリセットを可能にします。ISO/IEC 27001準拠をうたうSamsungのモデルを含む、異なるベンダーの主流TV 8機種で脆弱性が確認されました。対策には、ベンダーによるファームウェアの修正、または未使用のIR受信機の完全な無効化が必要です。<sup>[[2]](#references)</sup>

### IR LEDによるエアギャップ環境からのデータ窃取（aIR-Jumperファミリー）

防犯カメラには、**夜間撮影用のIR LED**が搭載されていることがよくあります。aIR-Jumperのプロトタイプでは、マルウェアがこれらのLEDを制御することで、数十メートル離れた場所にある外部カメラに向け、**監視カメラ1台あたり最大20 bit/sで窓越しに秘密情報を窃取**できることが示されました。逆方向では、数百メートルから数キロメートルの距離で、**100 bit/sを超える速度**での侵入が実証されました。<sup>[[3]](#references)</sup>光は可視光スペクトル外にあるため、運用者が気づかない可能性があります。対策には次のものがあります。

* 機密性の高い場所ではIR LEDを物理的に遮蔽または取り外す
* カメラのLEDのデューティ比とファームウェアの整合性を監視する
* 窓や監視カメラにIRカットフィルターを設置する

攻撃者は強力なIRプロジェクターを使って、安全でないカメラにデータを点滅送信し、ネットワークへコマンドを**侵入させる**こともできます。

### Flipper Zero 1.0による長距離ブルートフォースと拡張プロトコル

Firmware 1.0（2024年9月）では、ユニバーサルリモコンのライブラリが拡張され、microSDから赤外線アセットファイルを動的に読み込めるようになりました。<sup>[[4]](#references)</sup>学習機能とユニバーサルリモコン機能を使って、近くのTVやエアコンに対して、既知のコマンドを再生したり試したりできます。到達距離は送信機、光学系、周囲光、受信機に大きく左右されるため、外付けIRハードウェアで延長できますが、固定の距離を想定すべきではありません。

## ツールと実践例 <a href="#tooling" id="tooling"></a>

### ハードウェア

* **Flipper Zero** – 学習、リプレイ、辞書ブルートフォースの各モードを備えたポータブルトランシーバー（上記を参照）。
* **Arduino / ESP32** + IR LED / TSOP38xx受信機 – 安価なDIYアナライザー／送信機。`Arduino-IRremote`ライブラリと組み合わせて使用します（v4.xは40以上のプロトコルに対応）。
* **ロジックアナライザー**（Saleae/FX2）– プロトコルが不明な場合に、生のタイミングをキャプチャします。
* **IRブラスター搭載スマートフォン**（例：Xiaomi）– 手軽な現場テストに便利ですが、到達距離は限られます。

### ソフトウェア

* **`Arduino-IRremote`** – 活発に保守されているC++ライブラリ：<sup>[[5]](#references)</sup>
  ```cpp
  #include <IRremote.hpp>
  void setup(){ IrSender.begin(3); }
  void loop(){
    IrSender.sendNEC(0x00, 0x10, 0); // address, command, repeats
    delay(5000);
  }
  ```
* **IRscrutinizer / AnalysIR** – raw captureをインポートし、プロトコルを自動識別してPronto/Arduinoコードを生成するGUIデコーダー。
* **LIRC / ir-keytable (Linux)** – コマンドラインからIRを受信・送信する:
  ```bash
  sudo ir-keytable -p nec,rc5 -t   # live-dump decoded scancodes
  irsend SEND_ONCE samsung KEY_POWER
  ```

## Defensive Measures <a href="#defense" id="defense"></a>

* 公共スペースに設置されたデバイスでIR受信機が不要な場合は、無効化するか覆う。
* smart-TVとリモコン間で*ペアリング*または暗号学的チェックを徹底し、特権的な「サービス」コードを分離する。
* 機密区域の周囲にIRカットフィルターまたは連続波検出器を設置し、光学的な covert channel を遮断する。
* 制御可能なIR LEDを備えたカメラ/IoT機器のファームウェアの完全性を監視する。
