# Fault Injection Attacks

{{#include ../../banners/hacktricks-training.md}}

Το Fault injection—που συχνά αποκαλείται **glitching** στον τομέα της ασφάλειας υλικού—διαταράσσει σκόπιμα τη λειτουργία μιας συσκευής, ώστε να εκτελέσει έναν εσφαλμένο υπολογισμό. Ένα χρήσιμο σφάλμα μπορεί να παρακάμψει μια εντολή, να αλλοιώσει δεδομένα, να παρακάμψει έναν έλεγχο ασφαλείας ή να παράγει εσφαλμένη κρυπτογραφική έξοδο, από την οποία μπορούν να εξαχθούν μυστικές πληροφορίες.<sup>[[1]](#references)</sup>

Οι συνήθεις τεχνικές χειρίζονται την τάση τροφοδοσίας ή το ρολόι, προκαλούν ηλεκτρομαγνητικές παρεμβολές ή χρησιμοποιούν οπτική διέγερση ή διέγερση με λέιζερ.<sup>[[1]](#references)</sup> Διαφέρουν ως προς την ακρίβεια και την επεμβατικότητά τους, αλλά οι επιτυχημένες δοκιμές συνήθως απαιτούν μια επαναλήψιμη σκανδάλη και συστηματικές σαρώσεις ως προς τον χρονισμό, το πλάτος παλμού και την ένταση. Ξεκινήστε με μια σταθερή γραμμή βάσης, καταγράψτε ξεχωριστά τις επανεκκινήσεις και τις αλλοιωμένες εξόδους και αλλάζετε μία παράμετρο κάθε φορά.<sup>[[2]](#references)</sup>
