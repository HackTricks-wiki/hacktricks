# Серійний номер macOS

{{#include ../../../banners/hacktricks-training.md}}

## Основна інформація

Не слід вважати, що кожен Mac має серійний номер із 12 символів, який можна розшифрувати. Старіший формат Apple містив інформацію про виробництво та конфігурацію, але у 2021 році Apple почала впроваджувати рандомізовані серійні номери в нових продуктах. Рандомізований формат не розкриває відомості про виробництво або конфігурацію.<sup>[[1]](#references)</sup>

### Застарілий формат із 12 символів

Для багатьох пристроїв, виготовлених із 2010 року до переходу на рандомізований формат, формат із 12 символів досі може надавати корисні відомості для інвентаризації:<sup>[[3]](#references)</sup>

- Символи 1–3 визначають місце виробництва.
- Символи 4–5 кодують півріччя та тиждень виробництва.
- Символи 6–8 розрізняють пристрої, виготовлені в одному місці та в один час.
- Символи 9–12 визначають код моделі або конфігурації.

Наприклад, `C02L13ECF8J2` відповідає цій застарілій структурі. Підтримувані спільнотою таблиці відповідності заводів містять такі префікси: `FC`, `F`, `XA`, `XB`, `QP` і `G8` для розташувань у Сполучених Штатах; `RN` для Мексики; `CK` для Корка; `VM` для розташування Foxconn у Чехії; `SG` або `E` для Сінгапуру; `MB` для Малайзії; `PT` або `CY` для Кореї; а також `EE`, `QT` або `UV` для Тайваню. Численні префікси, зокрема `FK`, `F1`, `F2`, `W8`, `DL`, `DM`, `DN`, `YM`, `7J`, `1C`, `4H`, `WQ`, `F7`, `C0`, `C3` і `C7`, пов'язують із виробничими об'єктами в Китаї; `RM` пов'язують із відновленими пристроями.<sup>[[3]](#references)</sup>

Коди дат у четвертому символі проходять від `C` (перше півріччя 2010 року) до `Z` (друге півріччя 2019 року), після чого послідовність повторно використовується. У п'ятому символі цифри `1`–`9` позначають тижні 1–9, а літери `C`–`Y`, за винятком голосних і `S`, позначають тижні 10–27; якщо четвертий символ позначає друге півріччя року, потрібно додати 26.<sup>[[3]](#references)</sup>

Ці таблиці відповідності корисні для початкового аналізу застарілих пристроїв, але не є достовірним доказом походження, віку або автентичності. Підтвердьте результат за допомогою інвентаризаційних даних Apple.

Для надійної ідентифікації отримайте серійний номер із пристрою та скористайтеся сервісом Apple для перевірки покриття або технічних характеристик замість спроб визначити модель за позиціями символів.<sup>[[2]](#references)</sup>

### Отримання серійного номера

Графічний інтерфейс відображає його в меню **Apple > Про цей Mac**.<sup>[[2]](#references)</sup> У shell будь-яка з наведених нижче команд зчитує серійний номер платформи:
```bash
system_profiler SPHardwareDataType | awk -F ': ' '/Serial Number/ {print $2}'
ioreg -rd1 -c IOPlatformExpertDevice | awk -F '"' '/IOPlatformSerialNumber/ {print $4}'
```
Сприймайте серійний номер як ідентифікатор, а не як автентифікатор: підтверджуйте пристрій через відповідний робочий процес інвентаризації Apple або MDM, перш ніж ухвалювати рішення щодо enrollment або права власності.
