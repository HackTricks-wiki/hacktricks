# macOS Serial Number

## 基本情報

2010年以降に製造されたAppleデバイスのシリアル番号は、**12個の英数字**で構成されており、各セグメントが特定の情報を示しています。

- **最初の3文字**: **製造場所**を示します。
- **4文字目と5文字目**: 製造された**年と週**を示します。
- **6文字目から8文字目**: 各デバイスの**一意の識別子**として機能します。
- **最後の4文字**: **モデル番号**を示します。

例えば、シリアル番号 **C02L13ECF8J2** はこの構造に従っています。

### **製造場所（最初の3文字）**

特定のコードは、特定の工場を表します。

- **FC, F, XA/XB/QP/G8**: アメリカ国内のさまざまな場所。
- **RN**: メキシコ。
- **CK**: アイルランド、コーク。
- **VM**: チェコ共和国、Foxconn。
- **SG/E**: シンガポール。
- **MB**: マレーシア。
- **PT/CY**: 韓国。
- **EE/QT/UV**: 台湾。
- **FK/F1/F2, W8, DL/DM, DN, YM/7J, 1C/4H/WQ/F7**: 中国国内のさまざまな場所。
- **C0, C3, C7**: 中国国内の特定の都市。
- **RM**: 整備済みデバイス。

### **製造年（4文字目）**

この文字は「C」（2010年の前半を表す）から「Z」（2019年の後半を表す）まで変化し、それぞれ異なる文字が各半年の期間を示します。

### **製造週（5文字目）**

数字の1-9は、1週目から9週目に対応します。母音および「S」を除く英字のC-Yは、10週目から27週目を表します。年の後半については、この数値に26を加えます。
