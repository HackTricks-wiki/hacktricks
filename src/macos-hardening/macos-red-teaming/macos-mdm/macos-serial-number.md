# Серійний номер macOS

## Основна інформація

Пристрої Apple, випущені після 2010 року, мають серійні номери, що складаються з **12 буквено-цифрових символів**, кожен сегмент містить певну інформацію:

- **Перші 3 символи**: вказують на **місце виробництва**.
- **Символи 4 і 5**: позначають **рік і тиждень виробництва**.
- **Символи з 6-го по 8-й**: є **унікальним ідентифікатором** кожного пристрою.
- **Останні 4 символи**: визначають **номер моделі**.

Наприклад, серійний номер **C02L13ECF8J2** відповідає цій структурі.

### **Місця виробництва (перші 3 символи)**

Певні коди відповідають конкретним заводам:

- **FC, F, XA/XB/QP/G8**: різні місця у США.
- **RN**: Мексика.
- **CK**: Корк, Ірландія.
- **VM**: Foxconn, Чехія.
- **SG/E**: Сінгапур.
- **MB**: Малайзія.
- **PT/CY**: Корея.
- **EE/QT/UV**: Тайвань.
- **FK/F1/F2, W8, DL/DM, DN, YM/7J, 1C/4H/WQ/F7**: різні місця в Китаї.
- **C0, C3, C7**: окремі міста в Китаї.
- **RM**: відновлені пристрої.

### **Рік виробництва (4-й символ)**

Цей символ змінюється від 'C' (що позначає першу половину 2010 року) до 'Z' (друга половина 2019 року), причому різні літери позначають різні піврічні періоди.

### **Тиждень виробництва (5-й символ)**

Цифри 1–9 відповідають тижням 1–9. Літери C–Y (за винятком голосних і 'S') позначають тижні 10–27. Для другої половини року до цього числа додається 26.
