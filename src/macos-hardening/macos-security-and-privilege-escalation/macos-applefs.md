## Ιδιόκτητο Σύστημα Αρχείων της Apple (APFS)

Το **Apple File System (APFS)** είναι ένα σύγχρονο σύστημα αρχείων που σχεδιάστηκε για να αντικαταστήσει το Hierarchical File System Plus (HFS+). Η ανάπτυξή του προέκυψε από την ανάγκη για **βελτιωμένη απόδοση, ασφάλεια και αποδοτικότητα**.

Ορισμένες αξιοσημείωτες δυνατότητες του APFS περιλαμβάνουν:<sup>[[1]](#references)</sup>

1. **Κοινή χρήση χώρου**: Το APFS επιτρέπει σε πολλαπλούς τόμους να **μοιράζονται τον ίδιο υποκείμενο ελεύθερο αποθηκευτικό χώρο** σε μία μόνο φυσική συσκευή. Αυτό επιτρέπει αποδοτικότερη αξιοποίηση του χώρου, καθώς οι τόμοι μπορούν να αυξάνονται και να μειώνονται δυναμικά χωρίς να απαιτείται χειροκίνητη αλλαγή μεγέθους ή επαναδιαμέριση.
1. Αυτό σημαίνει ότι, σε σύγκριση με τα παραδοσιακά partitions σε δίσκους, **στο APFS διαφορετικά partitions (τόμοι) μοιράζονται όλο τον χώρο του δίσκου**, ενώ ένα κανονικό partition είχε συνήθως σταθερό μέγεθος.
2. **Στιγμιότυπα**: Το APFS υποστηρίζει τη **δημιουργία snapshots**, τα οποία είναι **μόνο για ανάγνωση**, χρονικά στιγμιότυπα του συστήματος αρχείων. Τα snapshots επιτρέπουν αποδοτικά backups και εύκολη επαναφορά του συστήματος, καθώς καταναλώνουν ελάχιστο επιπλέον αποθηκευτικό χώρο και μπορούν να δημιουργηθούν ή να επανέλθουν γρήγορα.
3. **Κλώνοι**: Το APFS μπορεί να **δημιουργεί clones αρχείων ή καταλόγων που μοιράζονται τον ίδιο αποθηκευτικό χώρο** με το αρχικό στοιχείο, μέχρι να τροποποιηθεί είτε το clone είτε το αρχικό αρχείο. Αυτή η δυνατότητα παρέχει έναν αποδοτικό τρόπο δημιουργίας αντιγράφων αρχείων ή καταλόγων χωρίς διπλασιασμό του απαιτούμενου αποθηκευτικού χώρου.
4. **Κρυπτογράφηση**: Το APFS υποστηρίζει **εγγενώς κρυπτογράφηση ολόκληρου του δίσκου**, καθώς και κρυπτογράφηση ανά αρχείο και ανά κατάλογο, ενισχύοντας την ασφάλεια των δεδομένων σε διαφορετικές περιπτώσεις χρήσης.
5. **Προστασία από καταρρεύσεις**: Το APFS χρησιμοποιεί ένα **σχήμα μεταδεδομένων copy-on-write που διασφαλίζει τη συνέπεια του συστήματος αρχείων** ακόμη και σε περιπτώσεις ξαφνικής διακοπής ρεύματος ή καταρρεύσεων του συστήματος, μειώνοντας τον κίνδυνο καταστροφής δεδομένων.

Συνολικά, το APFS προσφέρει ένα πιο σύγχρονο, ευέλικτο και αποδοτικό σύστημα αρχείων για συσκευές Apple, με έμφαση στη βελτιωμένη απόδοση, αξιοπιστία και ασφάλεια.
```bash
diskutil list # Get overview of the APFS volumes
```
