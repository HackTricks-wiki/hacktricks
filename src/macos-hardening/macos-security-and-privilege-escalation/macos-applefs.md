## Пропрієтарна файлова система Apple (APFS)

**Apple File System (APFS)** — це сучасна файлова система, розроблена для заміни Hierarchical File System Plus (HFS+). Її розробка була зумовлена потребою в **підвищенні продуктивності, безпеки та ефективності**.

Серед помітних функцій APFS:<sup>[[1]](#references)</sup>

1. **Спільне використання простору**: APFS дозволяє кільком томам **спільно використовувати одне й те саме вільне сховище** на одному фізичному пристрої. Це забезпечує ефективніше використання простору, оскільки томи можуть динамічно збільшуватися та зменшуватися без потреби в ручній зміні розміру або повторному розбитті на розділи.
1. Це означає, що порівняно з традиційними розділами на дисках, **в APFS різні розділи (томи) спільно використовують увесь дисковий простір**, тоді як звичайний розділ зазвичай мав фіксований розмір.
2. **Знімки**: APFS підтримує **створення знімків**, які є **доступними лише для читання** екземплярами файлової системи в певний момент часу. Знімки забезпечують ефективне резервне копіювання та просте відновлення попереднього стану системи, оскільки потребують мінімального додаткового сховища й можуть швидко створюватися або відновлюватися.
3. **Клони**: APFS може **створювати клони файлів або каталогів, які спільно використовують те саме сховище**, що й оригінал, доки клон або оригінальний файл не буде змінено. Ця функція забезпечує ефективний спосіб створення копій файлів або каталогів без дублювання простору сховища.
4. **Шифрування**: APFS **вбудовано підтримує повнодискове шифрування**, а також шифрування окремих файлів і каталогів, підвищуючи безпеку даних у різних сценаріях використання.
5. **Захист від збоїв**: APFS використовує **схему метаданих copy-on-write, яка забезпечує узгодженість файлової системи** навіть у разі раптового вимкнення живлення або аварійного завершення роботи системи, зменшуючи ризик пошкодження даних.

Загалом APFS є сучаснішою, гнучкішою та ефективнішою файловою системою для пристроїв Apple, орієнтованою на підвищення продуктивності, надійності та безпеки.
```bash
diskutil list # Get overview of the APFS volumes
```
