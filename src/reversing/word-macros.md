### Junk Code

Дуже часто трапляється **junk code, який ніколи не використовується**, щоб ускладнити reverse engineering макросу.\
Наприклад, на наступному зображенні видно, як використовується умова `If`, яка ніколи не буде істинною, для виконання непотрібного та марного коду.

### Macro Forms

За допомогою функції **GetObject** можна отримати дані з форм макросу. Це можна використовувати для ускладнення аналізу. Нижче наведено зображення форми макросу, яка використовується для **приховування даних усередині текстових полів** (текстове поле може приховувати інші текстові поля):
