### Junk Code

Είναι πολύ συνηθισμένο να βρίσκουμε **junk code που δεν χρησιμοποιείται ποτέ**, ώστε να γίνεται πιο δύσκολη η αντίστροφη ανάλυση του macro.\
Για παράδειγμα, στην ακόλουθη εικόνα μπορείτε να δείτε ότι χρησιμοποιείται μια συνθήκη If που δεν πρόκειται ποτέ να είναι αληθής, για την εκτέλεση κάποιου junk και άχρηστου κώδικα.

### Macro Forms

Χρησιμοποιώντας τη συνάρτηση **GetObject**, είναι δυνατή η λήψη δεδομένων από τις φόρμες του macro. Αυτό μπορεί να χρησιμοποιηθεί για να δυσκολέψει την ανάλυση. Ακολουθεί μια εικόνα μιας φόρμας macro που χρησιμοποιείται για **την απόκρυψη δεδομένων μέσα σε text boxes** (ένα text box μπορεί να κρύβει άλλα text boxes):
