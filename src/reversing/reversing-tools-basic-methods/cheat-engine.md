# Cheat Engine

{{#include ../../banners/hacktricks-training.md}}

Το [**Cheat Engine**](https://www.cheatengine.org/downloads.php) είναι ένα χρήσιμο πρόγραμμα για να βρίσκετε πού αποθηκεύονται σημαντικές τιμές στη μνήμη ενός εκτελούμενου game και να τις αλλάζετε.\
Όταν το κατεβάσετε και το εκτελέσετε, θα εμφανιστεί ένα **tutorial** για τον τρόπο χρήσης του εργαλείου. Αν θέλετε να μάθετε να το χρησιμοποιείτε, συνιστάται ιδιαίτερα να το ολοκληρώσετε.<sup>[[3]](#references)</sup>

## Τι αναζητάτε;

![Cheat Engine - Τι αναζητάτε;: Τι αναζητάτε;](<../../images/image (762).png>)

Αυτό το εργαλείο είναι πολύ χρήσιμο για να βρίσκετε **πού αποθηκεύεται κάποια τιμή** (συνήθως ένας αριθμός) **στη μνήμη** ενός προγράμματος.\
**Συνήθως οι αριθμοί** αποθηκεύονται σε μορφή **4bytes**, αλλά μπορείτε επίσης να τους βρείτε σε μορφές **double** ή **float**, ή μπορεί να θέλετε να αναζητήσετε κάτι **διαφορετικό από αριθμό**. Για αυτόν τον λόγο, πρέπει να βεβαιωθείτε ότι **επιλέγετε** αυτό που θέλετε να **αναζητήσετε**:

![Cheat Engine - Τι αναζητάτε;: Συνήθως οι αριθμοί αποθηκεύονται σε μορφή 4bytes, αλλά μπορείτε επίσης να τους βρείτε σε μορφές double ή float, ή μπορεί να θέλετε να αναζητήσετε κάτι...](<../../images/image (324).png>)

Μπορείτε επίσης να ορίσετε **διαφορετικούς τύπους** **αναζητήσεων**:

![Cheat Engine - Τι αναζητάτε;: Μπορείτε επίσης να ορίσετε διαφορετικούς τύπους αναζητήσεων](<../../images/image (311).png>)

## Τροποποίηση της τιμής

Αφού **βρείτε** πού βρίσκεται η **τιμή** που **αναζητάτε** (περισσότερα σχετικά με αυτό στα επόμενα βήματα), μπορείτε να την **τροποποιήσετε** κάνοντας διπλό κλικ πάνω της και έπειτα διπλό κλικ στην τιμή της:

![Hotkeys - Τροποποίηση της τιμής: Αφού βρείτε πού βρίσκεται η τιμή που αναζητάτε (περισσότερα σχετικά με αυτό στα επόμενα βήματα), μπορείτε να την τροποποιήσετε κάνοντας διπλό κλικ πάνω της και έπειτα διπλό κλικ...](<../../images/image (563).png>)

Και τέλος, **επιλέγοντας το πλαίσιο** ώστε να ολοκληρωθεί η τροποποίηση στη μνήμη:

![Hotkeys - Τροποποίηση της τιμής: Και τέλος, επιλέγοντας το πλαίσιο ώστε να ολοκληρωθεί η τροποποίηση στη μνήμη](<../../images/image (385).png>)

Η **αλλαγή** στη **μνήμη** θα **εφαρμοστεί** αμέσως (σημειώστε ότι, μέχρι το game να χρησιμοποιήσει ξανά αυτή την τιμή, η τιμή **δεν θα ενημερωθεί στο game**).

## Αναζήτηση της τιμής

Ας υποθέσουμε ότι υπάρχει μια σημαντική τιμή (όπως η ζωή του χαρακτήρα σας) που θέλετε να αυξήσετε και ότι αναζητάτε αυτή την τιμή στη μνήμη.

### Μέσω γνωστής αλλαγής

Αν υποθέσουμε ότι αναζητάτε την τιμή 100, **εκτελείτε μια σάρωση** αναζητώντας αυτή την τιμή και βρίσκετε πολλές αντιστοιχίες:

![Αναζήτηση της τιμής - Μέσω γνωστής αλλαγής: Αν υποθέσουμε ότι αναζητάτε την τιμή 100, εκτελείτε μια σάρωση αναζητώντας αυτή την τιμή και βρίσκετε πολλές αντιστοιχίες](<../../images/image (108).png>)

Έπειτα, κάνετε κάτι ώστε η **τιμή να αλλάξει**, **σταματάτε** το game και **εκτελείτε μια επόμενη σάρωση**:

![Αναζήτηση της τιμής - Μέσω γνωστής αλλαγής: Έπειτα, κάνετε κάτι ώστε η τιμή να αλλάξει, σταματάτε το game και εκτελείτε μια επόμενη σάρωση](<../../images/image (684).png>)

Το Cheat Engine θα αναζητήσει τις **τιμές** που **μεταβλήθηκαν από 100 στη νέα τιμή**. Συγχαρητήρια, **βρήκατε** τη **διεύθυνση** της τιμής που αναζητούσατε και τώρα μπορείτε να την τροποποιήσετε.\
_Αν εξακολουθούν να υπάρχουν πολλές τιμές, κάντε κάτι για να τροποποιήσετε ξανά αυτή την τιμή και εκτελέστε άλλο ένα "next scan" για να φιλτράρετε τις διευθύνσεις._

![Μέσω γνωστής αλλαγής - Άγνωστη τιμή, γνωστή αλλαγή: Έπειτα, κάντε την τιμή να αλλάξει, υποδείξτε πώς άλλαξε η τιμή (στην περίπτωσή μου μειώθηκε κατά 1) και εκτελέστε μια επόμενη σάρωση](<../../images/image (371).png>)

### Τυχαία διεύθυνση μνήμης - Εύρεση του code

Μέχρι τώρα μάθαμε πώς να βρίσκουμε μια διεύθυνση που αποθηκεύει μια τιμή, αλλά είναι πολύ πιθανό **σε διαφορετικές εκτελέσεις του game η διεύθυνση να βρίσκεται σε διαφορετικά σημεία της μνήμης**. Ας δούμε λοιπόν πώς μπορούμε να βρίσκουμε πάντα αυτή τη διεύθυνση.

Χρησιμοποιώντας ορισμένα από τα κόλπα που αναφέρθηκαν, βρείτε τη διεύθυνση όπου το τρέχον game αποθηκεύει τη σημαντική τιμή. Έπειτα (σταματώντας το game, αν θέλετε), κάντε **δεξί κλικ** στη **διεύθυνση** που βρήκατε και επιλέξτε "**Find out what accesses this address**" ή "**Find out what writes to this address**":

![Άγνωστη τιμή, γνωστή αλλαγή - Τυχαία διεύθυνση μνήμης - Εύρεση του code: Χρησιμοποιώντας ορισμένα από τα κόλπα που αναφέρθηκαν, βρείτε τη διεύθυνση όπου το τρέχον game αποθηκεύει τη σημαντική τιμή. Έπειτα...](<../../images/image (1067).png>)

Η **πρώτη επιλογή** είναι χρήσιμη για να γνωρίζετε ποια **τμήματα** του **code** **χρησιμοποιούν** αυτή τη **διεύθυνση** (κάτι χρήσιμο και για άλλους σκοπούς, όπως το να **γνωρίζετε πού μπορείτε να τροποποιήσετε τον code** του game).\
Η **δεύτερη επιλογή** είναι πιο **συγκεκριμένη** και θα είναι πιο χρήσιμη σε αυτή την περίπτωση, καθώς μας ενδιαφέρει να γνωρίζουμε **από πού εγγράφεται αυτή η τιμή**.

Αφού επιλέξετε μία από αυτές τις επιλογές, ο **debugger** θα **συνδεθεί** στο πρόγραμμα και θα εμφανιστεί ένα νέο **κενό παράθυρο**. Τώρα, **παίξτε** το **game** και **τροποποιήστε** αυτή την **τιμή** (χωρίς να επανεκκινήσετε το game). Το **παράθυρο** θα πρέπει να **γεμίσει** με τις **διευθύνσεις** που **τροποποιούν** την **τιμή**:

![Άγνωστη τιμή, γνωστή αλλαγή - Τυχαία διεύθυνση μνήμης - Εύρεση του code: Αφού επιλέξετε μία από αυτές τις επιλογές, ο debugger θα συνδεθεί στο πρόγραμμα και θα εμφανιστεί ένα νέο κενό παράθυρο...](<../../images/image (91).png>)

Τώρα που βρήκατε τη διεύθυνση που τροποποιεί την τιμή, μπορείτε να **τροποποιήσετε τον code όπως θέλετε** (το Cheat Engine σάς επιτρέπει να τον τροποποιήσετε πολύ γρήγορα σε NOPs):

![Άγνωστη τιμή, γνωστή αλλαγή - Τυχαία διεύθυνση μνήμης - Εύρεση του code: Τώρα που βρήκατε τη διεύθυνση που τροποποιεί την τιμή, μπορείτε να τροποποιήσετε τον code όπως θέλετε (το Cheat Engine...](<../../images/image (1057).png>)

Έτσι, μπορείτε πλέον να τον τροποποιήσετε ώστε ο code να μην επηρεάζει τον αριθμό σας ή να τον επηρεάζει πάντα θετικά.

## Προηγμένες δυνατότητες στο Cheat Engine 7.x (2023-2025)

Το Cheat Engine συνεχίζει να εξελίσσεται από την έκδοση 7.0 και έχουν προστεθεί αρκετές δυνατότητες ποιότητας ζωής και *offensive-reversing*, οι οποίες είναι εξαιρετικά χρήσιμες κατά την ανάλυση σύγχρονου software (και όχι μόνο games!). Παρακάτω θα βρείτε έναν **πολύ συνοπτικό οδηγό πεδίου** για τις προσθήκες που πιθανότατα θα χρησιμοποιήσετε περισσότερο σε red-team/CTF εργασίες.<sup>[[1]](#references)</sup>

### Βελτιώσεις του Pointer Scanner 2
* Οι επιλογές `Pointers must end with specific offsets` και το νέο slider **Deviation** (≥7.4) μειώνουν σημαντικά τα false positives όταν εκτελείτε rescan μετά από update. Χρησιμοποιήστε το μαζί με multi-map comparison (`.PTR` → *Compare results with other saved pointer map*) για να αποκτήσετε έναν **ανθεκτικό base-pointer** μέσα σε λίγα λεπτά.
* Συντόμευση bulk-filter: μετά το πρώτο scan πατήστε `Ctrl+A → Space` για να επιλέξετε τα πάντα και, στη συνέχεια, `Ctrl+I` (invert) για να αποεπιλέξετε τις διευθύνσεις που απέτυχαν στο rescan.

### Ultimap 3 – Intel PT tracing
*Από την 7.5, το παλιό Ultimap υλοποιήθηκε ξανά πάνω στο **Intel Processor-Trace (IPT)**.* Αυτό σημαίνει ότι μπορείτε πλέον να καταγράφετε **κάθε branch που εκτελεί ο στόχος** **χωρίς single-stepping** (μόνο σε user-mode, επομένως δεν θα ενεργοποιεί τα περισσότερα anti-debug gadgets).
```
Memory View → Tools → Ultimap 3 → check «Intel PT»
Select number of buffers → Start
```
Μετά από λίγα δευτερόλεπτα σταματήστε την καταγραφή και **right-click → Save execution list to file**. Συνδυάστε τις διευθύνσεις των branches με μια συνεδρία `Find out what addresses this instruction accesses` για να εντοπίσετε εξαιρετικά γρήγορα τα hotspots του game logic με υψηλή συχνότητα.

### Πρότυπα `jmp` / auto-patch του 1 byte
Η έκδοση 7.5 εισήγαγε ένα *one-byte* JMP stub (0xEB), το οποίο εγκαθιστά έναν SEH handler και τοποθετεί ένα INT3 στην αρχική θέση. Δημιουργείται αυτόματα όταν χρησιμοποιείτε **Auto Assembler → Template → Code Injection** σε instructions που δεν μπορούν να τροποποιηθούν με ένα relative jump 5 byte. Αυτό επιτρέπει “tight” hooks μέσα σε packed ή size-constrained routines.

### Stealth σε επίπεδο kernel με DBVM (AMD & Intel)
Το *DBVM* είναι ο ενσωματωμένος Type-2 hypervisor του CE. Οι πρόσφατες εκδόσεις πρόσθεσαν επιτέλους **AMD-V/SVM support**, ώστε να μπορείτε να εκτελείτε `Driver → Load DBVM` σε hosts Ryzen/EPYC. Το DBVM σάς επιτρέπει να:
1. Δημιουργείτε hardware breakpoints που δεν είναι ορατά σε ελέγχους Ring-3/anti-debug.
2. Διαβάζετε/εγγράφετε pageable ή προστατευμένες περιοχές μνήμης του kernel, ακόμη και όταν ο user-mode driver είναι απενεργοποιημένος.
3. Εκτελείτε VM-EXIT-less bypasses επιθέσεων χρονισμού, π.χ. να κάνετε query το `rdtsc` από τον hypervisor.

**Tip:** Το DBVM θα αρνηθεί να φορτωθεί όταν είναι ενεργοποιημένο το HVCI/Memory-Integrity στα Windows 11 → απενεργοποιήστε το ή εκκινήστε ένα dedicated VM-host.

### Remote / cross-platform debugging με **ceserver**
Το CE πλέον περιλαμβάνει ένα πλήρες rewrite του *ceserver* και μπορεί να συνδεθεί μέσω TCP σε targets **Linux, Android, macOS & iOS**. Ένα δημοφιλές fork ενσωματώνει το *Frida* για συνδυασμό dynamic instrumentation με το GUI του CE – ιδανικό όταν χρειάζεται να κάνετε patch σε Unity ή Unreal games που εκτελούνται σε τηλέφωνο:
```
# on the target (arm64)
./ceserver_arm64 &
# on the analyst workstation
adb forward tcp:52736 tcp:52736   # (or ssh tunnel)
Cheat Engine → "Network" icon → Host = localhost → Connect
```
Για το Frida bridge, δείτε το `bb33bb/frida-ceserver` στο GitHub.<sup>[[2]](#references)</sup>

### Άλλα αξιοσημείωτα εργαλεία
* **Patch Scanner** (MemView → Tools) – εντοπίζει μη αναμενόμενες αλλαγές κώδικα σε εκτελέσιμες ενότητες· χρήσιμο για malware analysis.
* **Structure Dissector 2** – σύρετε μια διεύθυνση → `Ctrl+D` και, στη συνέχεια, επιλέξτε *Guess fields* για αυτόματη αξιολόγηση C-structures.
* **.NET & Mono Dissector** – βελτιωμένη υποστήριξη παιχνιδιών Unity· καλέστε μεθόδους απευθείας από την CE Lua console.
* **Big-Endian custom types** – scan/edit με αντίστροφη σειρά byte (χρήσιμο για console emulators και buffers πακέτων δικτύου).
* **Autosave & tabs** για παράθυρα AutoAssembler/Lua, καθώς και `reassemble()` για επανεγγραφή εντολών πολλών γραμμών.

### Σημειώσεις εγκατάστασης και OPSEC (2024-2025)
* Ο επίσημος installer περιλαμβάνει **ad-offers** του InnoSetup (`RAV` κ.λπ.). Κάντε **πάντα κλικ στο *Decline*** *ή κάντε compile από τον πηγαίο κώδικα* για να αποφύγετε PUPs. Τα AVs θα εξακολουθούν να επισημαίνουν το `cheatengine.exe` ως *HackTool*, κάτι που είναι αναμενόμενο.
* Οι σύγχρονοι anti-cheat drivers (EAC/Battleye, ACE-BASE.sys, mhyprot2.sys) εντοπίζουν την window class του CE ακόμη και όταν έχει μετονομαστεί. Εκτελείτε το αντίγραφο για reversing **μέσα σε disposable VM** ή αφού απενεργοποιήσετε το network play.
* Αν χρειάζεστε μόνο user-mode πρόσβαση, επιλέξτε **`Settings → Extra → Kernel mode debug = off`** για να αποφύγετε τη φόρτωση του unsigned driver του CE, ο οποίος μπορεί να προκαλέσει BSOD στα Windows 11 24H2 με Secure-Boot.
