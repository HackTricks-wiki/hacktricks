# Cheat Engine

{{#include ../../banners/hacktricks-training.md}}

Το [**Cheat Engine**](https://www.cheatengine.org/downloads.php) είναι ένα χρήσιμο πρόγραμμα για να βρίσκετε πού αποθηκεύονται σημαντικές τιμές στη μνήμη ενός running game και να τις αλλάζετε.\
Όταν το κατεβάσετε και το εκτελέσετε, θα εμφανιστεί ένα **tutorial** σχετικά με τον τρόπο χρήσης του tool. Αν θέλετε να μάθετε πώς να χρησιμοποιείτε το tool, συνιστάται ιδιαίτερα να το ολοκληρώσετε.

## Code injection ασφαλές ως προς τη relocation με AOB signatures

Ένα script που κάνει hook στο `game.exe+123456` μπορεί να σταματήσει να λειτουργεί μετά από ASLR ή software update. Ένα **Array of Bytes (AOB) signature** εντοπίζει την instruction από τον περιβάλλοντα machine code. Χρησιμοποιήστε το `aobscanmodule` για να περιορίσετε την αναζήτηση σε ένα module. Κάντε τη signature αρκετά μεγάλη ώστε να επιστρέφει ένα μόνο match. Χρησιμοποιήστε wildcard για relocation bytes, διευθύνσεις και άλλα bytes που μπορεί να αλλάξουν. Μην κάνετε wildcard ολόκληρη την instruction που χρειάζεται να επαναφέρετε.<sup>[[4]](#references)</sup>

Στο Memory View, επιλέξτε την instruction και χρησιμοποιήστε **Tools → Auto Assemble → Template → AOB Injection**. Το block `[DISABLE]` που δημιουργείται είναι σημαντικό. Πρέπει να επαναφέρει κάθε byte που αντικαταστάθηκε και να αποδεσμεύσει το allocation.<sup>[[4]](#references)</sup>

<details>
<summary>Minimal x64 AOB injection skeleton</summary>
```asm
[ENABLE]
aobscanmodule(INJECT,game.exe,F3 0F 11 83 A0 00 00 00 48 8B)
alloc(newmem,1024,INJECT)
label(return)
registersymbol(INJECT)
newmem:
movss [rbx+000000A0],xmm0
jmp return
INJECT:
jmp newmem
nop
nop
nop
return:
[DISABLE]
INJECT:
db F3 0F 11 83 A0 00 00 00
unregistersymbol(INJECT)
dealloc(newmem)
```
</details>

Πριν ενεργοποιήσετε το script, επαληθεύστε τα εξής:

1. Το AOB επιστρέφει **μία** διεύθυνση. Αν επιστρέφει περισσότερες, προσθέστε σταθερές instructions και στις δύο πλευρές.
2. Το jump αντικαθιστά ολοκληρωμένες instructions. Μην διαχωρίζετε ποτέ μια instruction.
3. Το allocated cave είναι προσβάσιμο από το generated jump. Σε x64, μια far allocation μπορεί να χρειάζεται jump 14 bytes.
4. Ο injected κώδικας διατηρεί τα registers, τα flags και το stack alignment που αναμένει η αρχική function.
5. Το disable block επαναφέρει τα ακριβή αρχικά bytes. Δοκιμάστε αρκετές φορές το enable και το disable πριν αποθηκεύσετε το table.

## Αξιόπιστο pointer workflow

Ένα pointer που βρέθηκε σε ένα run είναι μόνο υποψήφιο. Δημιουργήστε pointer maps σε αρκετές νέες εκτελέσεις και κάντε rescan έναντι όλων. Κάντε restart το target μεταξύ των captures, ώστε να αλλάζουν το ASLR και οι heap allocations. Προτιμήστε paths των οποίων το base είναι module ή άλλο stable symbol. Απορρίψτε paths που λειτουργούν μόνο με ένα save, level ή object instance.

Το φίλτρο **the pointer must end with specific offsets** και η επιλογή deviation του μπορούν να διατηρήσουν χρήσιμα paths όταν ένα κοντινό field μετακινείται μεταξύ builds. Η release 7.5 πρόσθεσε επίσης αυτόν τον έλεγχο deviation. Είναι φίλτρο και όχι απόδειξη ότι ένα pointer chain είναι stable.<sup>[[1]](#references)</sup>

Όταν ένα structure μετακινείται πολύ συχνά για pointer scanning, κάντε hook την instruction που το προσπελαύνει. Καταγράψτε το live object pointer από ένα register σε ένα allocated symbol. Αυτό είναι συχνά πιο αξιόπιστο για entity lists και managed objects.

## Tracing code αντί για scanning values

Χρησιμοποιήστε το **Find out what writes to this address** όταν η value τροποποιείται άμεσα. Χρησιμοποιήστε το **Find out what accesses this address** όταν χρειάζεστε το owning object ή όταν το write γίνεται μέσω copied data. Ενεργοποιήστε μόνο μία action στο target. Έπειτα συγκρίνετε το hit count και την κατάσταση των registers.

Το **Ultimap 2** χρησιμοποιεί Intel Processor Trace σε υποστηριζόμενες Intel CPUs. Καταγράφει το executed control flow με λιγότερη διακοπή από το stepping κάθε instruction. Κάντε filter για κώδικα που εκτελέστηκε ενώ συνέβαινε η ενδιαφέρουσα action και αφαιρέστε κώδικα που εκτελέστηκε επίσης κατά τη διάρκεια ενός idle capture. Το Intel PT δεν είναι stealth feature. Το target μπορεί ακόμη να ανιχνεύσει το tracing, τις αλλαγές στο timing ή το ίδιο το Cheat Engine.<sup>[[1]](#references)</sup>

Το Cheat Engine 7.5 πρόσθεσε επίσης ένα Intel PT interface που παρέχεται από τα Windows. Το παλαιότερο DBVM-backed Ultimap mode και το Intel PT mode έχουν διαφορετικές απαιτήσεις hardware και OS. Μην υποθέτετε ότι μια CPU με δυνατότητα DBVM υποστηρίζει Intel PT.<sup>[[1]](#references)</sup>

## Επιλογή debugger και breakpoint

Επιλέξτε τον λιγότερο παρεμβατικό debugger που λειτουργεί:

- Ο **Windows debugger** είναι απλός, αλλά δημιουργεί κανονικά debug events. Οι anti-debugging checks μπορούν να τον ανιχνεύσουν.
- Ο **VEH debugger** χειρίζεται τα breakpoints μέσω ενός vectored exception handler. Παρακάμπτει ορισμένους βασικούς debugger checks, αλλά δεν είναι αόρατος.
- Τα **Hardware breakpoints** δεν τροποποιούν τα instruction bytes, αλλά το x86/x64 παρέχει μόνο μικρό αριθμό slots στα debug registers.
- Τα **Software breakpoints** αντικαθιστούν ένα byte με `INT3`. Ανιχνεύονται εύκολα και μπορεί να συγκρουστούν με integrity checks.
- Ο **DBVM debugger** μεταφέρει ορισμένες operations κάτω από το guest OS. Έχει πολύ περισσότερα privileges και μπορεί να προκαλέσει crash στο host αν ρυθμιστεί λανθασμένα.

Το Cheat Engine 7.5 μπορεί να χρησιμοποιήσει one-byte jump βασισμένο σε exception handler και `INT3` όταν δεν υπάρχει αρκετός χώρος για ένα κανονικό relative jump. Αντιμετωπίστε το όπως ένα software breakpoint. Επαληθεύστε το exception flow και μην υποθέτετε ότι παρακάμπτει anti-tamper checks.<sup>[[1]](#references)</sup>

Το DBVM είναι hypervisor και όχι γενικός διακόπτης invisibility. Χρησιμοποιήστε το μόνο σε disposable lab. Μην εκθέτετε το control interface του σε untrusted code. Τα kernel anti-cheat και endpoint products μπορεί ακόμη να ανιχνεύσουν τον driver, την κατάσταση του hypervisor ή την τροποποιημένη memory.

## Managed runtimes και πρόσφατες δυνατότητες 7.6/7.7

Για Mono, IL2CPP, .NET και Java targets, προτιμήστε τα runtime metadata αντί για blind scans, όταν είναι διαθέσιμα. Ανοίξτε το **Mono → Activate mono features** ή το αντίστοιχο runtime information window. Εντοπίστε πρώτα την class, το field ή τη method. Έπειτα χρησιμοποιήστε το native disassembly όταν η managed method γίνει JIT-compiled.

Η σειρά 7.6 πρόσθεσε το `AOBSCANEX` για signatures μόνο σε executable memory, ένα `gdbserver` debugger interface, Java metadata inspection, ταχύτερη IL2CPP enumeration και μια pointer-scan επιλογή που αγνοεί το upper pointer byte που χρησιμοποιείται από το ARM memory tagging. Η σειρά 7.7 πρόσθεσε native Linux builds, `HOOK`/`UNHOOK`, `aobscanfunction`, καλύτερο generic Mono method lookup, βελτιωμένη υποστήριξη PDB structures και βασικό Unreal Engine structure dissection.<sup>[[3]](#references)</sup>

Αυτές οι προσθήκες επιτρέπουν ένα χρήσιμο workflow:

1. Επιλύστε μια managed method ή static field από τα metadata.
2. Κάντε trace ή disassemble τον native κώδικα που παρήχθη για αυτήν τη method.
3. Χρησιμοποιήστε `AOBSCANEX` ή `aobscanfunction` για να εντοπίσετε ένα stable executable signature.
4. Δημιουργήστε ένα reversible hook. Διατηρήστε τις αρχικές instructions και επικυρώστε το disable path.
5. Ελέγξτε ξανά το signature μετά από κάθε target update. Ένα επιτυχές match δεν εγγυάται ότι η surrounding logic εξακολουθεί να έχει την ίδια σημασία.

## Remote targets με `ceserver`

Το `ceserver` εκθέτει process enumeration, memory access και debugging στο Cheat Engine GUI. Τα official builds καλύπτουν Linux και Android. Εκτελέστε στο target την αντίστοιχη architecture και συνδεθείτε μέσω της καρτέλας **Network**. Στο Android, η προώθηση του default port αποφεύγει την έκθεσή του στο network:<sup>[[3]](#references)</sup>
```bash
adb push ceserver_arm64 /data/local/tmp/ceserver
adb shell 'su -c "chmod 700 /data/local/tmp/ceserver && /data/local/tmp/ceserver"'
adb forward tcp:52736 tcp:52736
```
Το τρίτου μέρους `frida-ceserver` bridge μπορεί να παρέχει ένα interface συμβατό με το Cheat Engine για iOS targets. Δεν είναι το επίσημο `ceserver` και οι υποστηριζόμενες λειτουργίες του ενδέχεται να διαφέρουν.<sup>[[2]](#references)</sup>

Υποθέστε ότι το protocol παρέχει πρόσβαση επιπέδου debugger. Συνδέστε το σε loopback ή τοποθετήστε το πίσω από ένα SSH/ADB tunnel. Ποτέ μην εκθέτετε το TCP 52736 σε μη αξιόπιστο δίκτυο. Σταματήστε τον server όταν ολοκληρωθεί η session.

## Ασφάλεια λειτουργίας

Κάντε attach μόνο σε software που σας ανήκει ή για το οποίο έχετε εξουσιοδότηση να κάνετε test. Μην εκτελείτε το Cheat Engine παράλληλα με ένα online game ή production endpoint. Οι εγγραφές μνήμης, ο injected κώδικας, οι drivers και το DBVM μπορούν να προκαλέσουν crash ή corruption στο target.<sup>[[3]](#references)</sup>

Κατεβάζετε builds από το επίσημο site ή κάντε compile το published source. Τα security products συχνά ταξινομούν τους memory editors, τους debuggers και τους drivers τους ως hack tools. Μην απενεργοποιείτε συνολικά την προστασία του host. Χρησιμοποιήστε ένα dedicated VM ή lab host και επαληθεύστε το artifact πριν το εκτελέσετε.<sup>[[3]](#references)</sup>
