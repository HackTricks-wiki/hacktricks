# Επιθέσεις Fault Injection

{{#include ../../banners/hacktricks-training.md}}

Οι επιθέσεις Fault Injection περιλαμβάνουν την εισαγωγή εξωτερικής διαταραχής σε ηλεκτρονικά κυκλώματα με σκοπό την επιρροή της συμπεριφοράς τους, με αποτέλεσμα την αποκάλυψη πληροφοριών ή ακόμη και την παράκαμψη ορισμένων περιορισμών του κυκλώματος. Αυτές οι επιθέσεις ανοίγουν πολλές δυνατότητες για την επίθεση σε ηλεκτρονικά κυκλώματα. Η συγκεκριμένη επίθεση αναφέρεται επίσης ως glitching ηλεκτρονικών κυκλωμάτων.

Υπάρχουν πολλές μέθοδοι και μέσα για την εισαγωγή σφάλματος σε ένα ηλεκτρονικό κύκλωμα.
