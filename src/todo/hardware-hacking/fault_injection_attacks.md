# Fault Injection Attacks

{{#include ../../banners/hacktricks-training.md}}

Fault injection навмисно порушує роботу пристрою під час його функціонування, змушуючи його виконувати неправильне обчислення. Корисна помилка може пропустити інструкцію, пошкодити дані, обійти перевірку безпеки або створити помилковий криптографічний результат, з якого можна отримати секретну інформацію.<sup>[[1]](#references)</sup>

Поширені методи змінюють напругу живлення або тактовий сигнал, створюють електромагнітні перешкоди або використовують оптичну чи лазерну стимуляцію.<sup>[[1]](#references)</sup> Їхня точність і рівень інвазивності відрізняються, але успішне тестування зазвичай потребує повторюваного тригера та систематичного перебору значень часу, тривалості імпульсу й інтенсивності. Починайте зі стабільного базового стану, окремо записуйте скидання та некоректні результати й змінюйте лише один параметр за раз.<sup>[[2]](#references)</sup>
