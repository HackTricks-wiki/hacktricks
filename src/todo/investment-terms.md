## 現物取引

これは取引を行う最も基本的な方法です。**asset の数量と、購入または売却したい価格を指定**でき、その価格に達すると取引が実行されます。

通常は、取引を現在の価格でできるだけ速く実行するために、**現在の市場価格**を使用することもできます。

**Stop Loss - Limit**: 数量と購入または売却する asset の価格を指定し、さらに、指定した価格に達した場合に購入または売却するための下限価格を指定することもできます（損失を止めるため）。

## Futures

future とは、2者が**将来、固定価格で何かを取得する**ことに合意する契約です。例えば、6か月後に1 bitcoinを70,000ドルで売却する契約などです。

当然、6か月後の bitcoin の価値が80,000ドルであれば、売り手は損をし、買い手は利益を得ます。6か月後の bitcoin の価値が60,000ドルであれば、逆のことが起こります。

ただし、これは例えば、商品を生産しており、コストを支払うために一定の価格で販売できるという保証を必要とする企業にとって有用です。また、将来の価格が高くなる場合でも、何かを固定価格で確保したい企業にも有用です。

一方、取引所では通常、利益を得るために使用されます。

* 「Long position」とは、価格が上昇すると予想して賭けることを意味します
* 一方、「short position」とは、価格が下落すると予想して賭けることを意味します

### Futures による Hedging <a href="#mntl-sc-block_7-0" id="mntl-sc-block_7-0"></a>

ファンドマネージャーが一部の株式が下落すると懸念している場合、bitcoin や S\&P 500 futures contracts などの asset に対して short position を取ることがあります。これは、asset を購入または保有し、それらを将来、より高い価格で売却する契約を結ぶことに似ています。

価格が下落した場合、ファンドマネージャーは asset をより高い価格で売却できるため利益を得ます。asset の価格が上昇した場合、マネージャーはその利益を得られませんが、asset は引き続き保有できます。

### Perpetual Futures

**これは無期限に継続する「futures」です**（契約終了日がありません）。例えば crypto exchanges では非常によく見られ、crypto の価格に基づいて futures への参加や退出を行えます。

この場合、利益と損失はリアルタイムで発生する可能性があります。価格が1%上昇すれば1%の利益となり、価格が1%下落すれば1%の損失となります。

### レバレッジ付き Futures

**Leverage** により、より少ない資金で市場におけるより大きな position を管理できます。基本的には、実際に保有している資金だけをリスクにさらしながら、保有資金を大幅に超える金額を「賭ける」ことができます。

例えば、BTC/USDT で100ドル、50x leverage の future position を開いた場合、価格が1%上昇すると、初期投資の1x50 = 50%（50ドル）の利益を得ることになります。したがって、資金は150ドルになります。\
しかし、価格が1%下落すると、資金の50%（この場合は59ドル）を失います。価格が2%下落すると、賭けた資金をすべて失います（2x50 = 100%）。

したがって、leveraging により賭ける金額を管理しながら、利益と損失を拡大できます。

## Futures と Options の違い

futures と options の主な違いは、買い手にとって契約の実行が任意であることです。買い手は契約を実行するかどうかを決められます（通常は利益が得られる場合にのみ実行します）。買い手が option を使用したい場合、売り手は売却しなければなりません。\
ただし、買い手は option を開くために売り手へ手数料を支払います（そのため、より大きなリスクを負っているように見える売り手は、最初から一定の利益を得ます）。

### 1. **義務と権利:**

* **Futures:** futures contract を購入または売却すると、将来の日付に特定の価格で asset を購入または売却する**拘束力のある契約**を結ぶことになります。買い手と売り手の両方が、有効期限に契約を履行する**義務**を負います（それ以前に契約を終了しない限り）。
* **Options:** options では、特定の価格で、特定の有効期限まで、またはその時点で asset を購入（**call option** の場合）または売却（**put option** の場合）する**権利を持ちますが、義務はありません**。**買い手**には実行する option があり、買い手が option の行使を決定した場合、**売り手**は取引を履行する義務を負います。

### 2. **リスク:**

* **Futures:** 買い手と売り手は契約を完了する義務を負うため、両者が**無制限のリスク**を負います。リスクは、合意した価格と有効期限日における市場価格との差額です。
* **Options:** 買い手のリスクは、option の購入に支払った**premium**に限定されます。市場が option holder に有利な方向へ動かなかった場合、買い手は option をそのまま期限切れにできます。しかし、option の**売り手**（writer）は、市場が大きく不利な方向へ動いた場合、無制限のリスクを負います。

### 3. **コスト:**

* **Futures:** 買い手と売り手の両者が取引を完了する義務を負うため、position を保有するために必要な margin を除き、前払いのコストはありません。
* **Options:** 買い手は option を行使する権利を得るために、**option premium**を前払いで支払う必要があります。この premium は本質的に option のコストです。

### 4. **利益の可能性:**

* **Futures:** 利益または損失は、有効期限日における市場価格と契約で合意した価格との差額に基づきます。
* **Options:** 買い手は、市場が premium の支払額を超える分だけ strike price を上回る有利な方向へ動いた場合に利益を得ます。売り手は、option が行使されなければ premium を保持することで利益を得ます。
