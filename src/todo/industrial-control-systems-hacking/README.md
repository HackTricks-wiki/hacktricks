# 工业控制系统 Hacking

{{#include ../../banners/hacktricks-training.md}}

## 关于本节

本节介绍工业控制系统（ICS）的组件、架构、协议和安全评估方法。ICS 属于更广泛的运营技术（OT）领域：用于监控物理过程或促使物理过程发生变化的可编程系统和设备。常见示例包括监控与数据采集（SCADA）系统、分布式控制系统（DCS）和可编程逻辑控制器（PLC）。<sup>[[1]](#references)</sup>

这些环境中的安全工作必须考虑不同于传统 IT 的要求，包括过程安全、可靠性、可用性、确定性运行和设备生命周期。即使某项安全控制在技术上有效，如果会干扰物理过程，也可能并不适用。因此，测试和修复工作应与系统所有者及运维人员协调进行。<sup>[[1]](#references)</sup>

## 评估重点

首先了解受控过程、系统边界、网络拓扑、资产、数据流、信任关系和外部连接。同类设备在不同站点可能承担不同功能，因此应避免假设某一部署的架构或影响模型适用于其他部署。<sup>[[1]](#references)</sup>

在可能的情况下，优先采用被动发现和现有工程文档。任何主动扫描或利用都应遵循经批准的测试计划，其中应定义安全限制、维护窗口、恢复流程和停止条件。评估发现的问题时，应同时考虑其网络安全影响以及对物理过程可能造成的影响。<sup>[[1]](#references)</sup>

相同的架构知识也可支持资产清单、网络分段、监控、事件响应和基于风险的漏洞管理等防御活动。<sup>[[1]](#references)</sup>
