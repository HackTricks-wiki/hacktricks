## 이 섹션에 대하여

이 섹션에서는 산업 제어 시스템과 관련된 모든 내용을 다루며, 산업 제어 시스템의 개념과 다양한 보안 문제를 악용하는 방법론을 포함합니다.

산업 제어 시스템은 한 국가의 경제 발전에 산업이 필수적이기 때문에 어디에나 존재합니다. 그러나 이러한 ICS는 업데이트하기 어렵고 이 분야의 발전도 더딥니다. 따라서 이곳에서 보안 결함이 발견되는 일은 흔합니다. 이 환경에서 사용되는 대부분의 프로토콜과 표준은 90년대에 개발되었으며, 현재의 공격 시나리오와 비교하면 기능이 크게 부족합니다.

이러한 시스템이 손상되면 막대한 비용이 발생할 수 있고, 최악의 경우 인명 피해까지 발생할 수 있으므로 시스템을 보호하는 것이 중요해졌습니다. 산업 제어 시스템 보안을 이해하려면 시스템 내부 구조를 파악해야 합니다.

산업 제어 시스템은 정해진 표준에 따라 설치되므로 각 구성 요소를 파악하면 제어 시스템의 다른 모든 메커니즘을 서로 연결하는 데 도움이 됩니다. PLC와 SCADA 시스템 같은 장치의 설치 방식은 산업마다 다르므로 정보 수집이 중요합니다.

산업 제어 시스템은 때때로 복잡할 수 있으므로 무엇이든 수행하려면 많은 인내심이 필요합니다. 공격을 계획하고 exploit을 개발하기 전에 프로빙과 정찰을 수행하는 것이 핵심입니다.

이러한 기법은 공격을 방어하고 산업 제어 시스템에 대한 blue teaming을 수행하는 데에도 사용할 수 있습니다.
