## このセクションについて

このセクションでは、産業用制御システムに関する概念や、システム内に存在するさまざまなセキュリティ問題を利用してハッキングするための手法について説明します。

産業は国家の経済発展に不可欠であるため、産業用制御システムはあらゆる場所で利用されています。しかし、これらのICSは更新が難しく、この分野では技術の進歩もあまりありません。そのため、ここでセキュリティ上の欠陥が見つかることは珍しくありません。ここで使用されているプロトコルや標準の多くは1990年代に開発されたものであり、現在の攻撃シナリオと比較すると機能が大幅に限られています。

これらのシステムを破壊すると多大な損害が発生し、最悪の場合には人命が失われる可能性もあるため、システムを安全に保護することが重要になっています。産業用制御システムのセキュリティを理解するには、その内部構造を知る必要があります。

産業用制御システムは定められた標準に従って導入されるため、各コンポーネントを把握することで、制御システム内の他のすべてのメカニズムを相互接続しやすくなります。PLCやSCADAシステムなどのデバイスの導入方法は業界によって異なるため、情報収集が重要です。

産業用制御システムは複雑になる場合があり、そのため、何かを行うには多くの忍耐が必要です。攻撃の計画やexploitの開発を行う前に、プロービングと偵察を実施することが重要です。

これらの手法は、攻撃への防御や産業用制御システムのblue teamingにも利用できます。
