## 关于本节

本节涵盖工业控制系统的全部内容，包括相关概念，以及利用其中各种安全问题进行 Hacking 的方法论。

工业控制系统无处不在，因为工业对一个国家的经济发展至关重要。但这些 ICS 难以更新，该领域取得的进步也较少。因此，这里经常可以发现安全漏洞。这里使用的大多数协议和标准都是在 90 年代开发的，与当前的攻击场景相比，功能要少得多。

保护这些系统已经变得十分重要，因为破坏它们可能造成巨额损失，最坏情况下甚至会导致人员伤亡。要理解工业控制系统安全，必须了解其内部结构。

由于工业控制系统按照既定标准安装，了解每个组件将有助于在控制系统中互连其他机制。PLCs 和 SCADA 系统等设备在不同行业中的安装方式各不相同，因此信息收集至关重要。

工业控制系统有时可能非常复杂，因此开展任何操作都需要极大的耐心。在规划攻击和开发 exploits 之前，关键在于进行探测和 reconnaissance。

这些技术也可以用于防御攻击，以及对工业控制系统进行 blue teaming。
