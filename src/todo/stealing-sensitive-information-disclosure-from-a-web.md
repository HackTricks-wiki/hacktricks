# Kuiba Taarifa Nyeti Zilizofichuliwa kutoka kwenye Web

{{#include ../banners/hacktricks-training.md}}

Ikiwa wakati fulani utapata **ukurasa wa Web unaokuonyesha taarifa nyeti kulingana na session yako**: Labda unaakisi cookies, au unaonyesha maelezo ya kuchapisha au CC, au taarifa nyingine yoyote nyeti, unaweza kujaribu kuziiba.\
Hapa ninawasilisha njia kuu unazoweza kujaribu kutumia kufanikisha hilo:

- [**CORS bypass**](../pentesting-web/cors-bypass.md): Ikiwa unaweza kupita vichwa vya CORS utaweza kuiba taarifa kwa kutuma Ajax request kwa ukurasa hasidi.
- [**XSS**](../pentesting-web/xss-cross-site-scripting/index.html): Ukipata vulnerability ya XSS kwenye ukurasa unaweza kuitumia vibaya kuiba taarifa.
- [**Danging Markup**](../pentesting-web/dangling-markup-html-scriptless-injection/index.html): Ikiwa huwezi kuingiza tags za XSS bado unaweza kuiba taarifa kwa kutumia tags nyingine za kawaida za HTML.
- [**Clickjaking**](../pentesting-web/clickjacking.md): Ikiwa hakuna ulinzi dhidi ya attack hii, unaweza kumhadaa mtumiaji akutumie data nyeti (mfano [hapa](https://medium.com/bugbountywriteup/apache-example-servlet-leads-to-61a2720cac20)).<sup>[[1]](#references)</sup>
