## Executar e treinar modelos localmente

### [**Hugging Face Transformers**](https://github.com/huggingface/transformers)

Hugging Face Transformers é uma das bibliotecas open-source mais populares para usar, treinar e implantar LLMs como GPT, BERT e muitos outros. Ela oferece um ecossistema abrangente que inclui modelos pré-treinados, datasets e integração contínua com o Hugging Face Hub para fine-tuning e implantação.

### [**LangChain**](https://github.com/langchain-ai/langchain)

LangChain é um framework projetado para criar aplicações com LLMs. Ele permite que desenvolvedores conectem modelos de linguagem a fontes de dados externas, APIs e bancos de dados. LangChain fornece ferramentas para prompt engineering avançado, gerenciamento do histórico de conversas e integração de LLMs em workflows complexos.

### [**LitGPT**](https://github.com/Lightning-AI/litgpt)

LitGPT é um projeto desenvolvido pela Lightning AI que utiliza o framework Lightning para facilitar o treinamento, o fine-tuning e a implantação de modelos baseados em GPT. Ele se integra perfeitamente a outras ferramentas da Lightning AI, fornecendo workflows otimizados para lidar com modelos de linguagem em grande escala, com desempenho e escalabilidade aprimorados.

### [**LitServe**](https://github.com/Lightning-AI/LitServe)

**Descrição:**\
LitServe é uma ferramenta de implantação da Lightning AI projetada para implantar modelos de AI de forma rápida e eficiente. Ela simplifica a integração de LLMs em aplicações em tempo real, fornecendo recursos de serving escaláveis e otimizados.

### [**Axolotl**](https://github.com/axolotl-ai-cloud/axolotl)

Axolotl é uma plataforma baseada em cloud projetada para simplificar a implantação, o dimensionamento e o gerenciamento de modelos de AI, incluindo LLMs. Ela oferece recursos como dimensionamento automatizado, monitoramento e integração com diversos cloud services, facilitando a implantação de modelos em ambientes de produção sem exigir um gerenciamento extensivo da infraestrutura.

## Testar modelos online

### [**Hugging Face**](https://huggingface.co/)

**Hugging Face** é uma plataforma e comunidade líder em machine learning, particularmente conhecida por seu trabalho em processamento de linguagem natural (NLP). Ela fornece ferramentas, bibliotecas e recursos que facilitam o desenvolvimento, o compartilhamento e a implantação de modelos de machine learning.\
Ela oferece várias seções, como:

* **Modelos**: Um vasto repositório de **modelos de machine learning pré-treinados**, onde os usuários podem navegar, baixar e integrar modelos para diversas tarefas, como geração de texto, tradução, reconhecimento de imagens e muito mais.
* **Datasets:** Uma **coleção abrangente de datasets** usados para treinar e avaliar modelos. Ela facilita o acesso a diversas fontes de dados, permitindo que os usuários encontrem e utilizem dados para seus projetos específicos de machine learning.
* **Spaces:** Uma plataforma para hospedar e compartilhar **aplicações interativas de machine learning** e demos. Ela permite que desenvolvedores **mostrem** seus modelos em ação, criem interfaces fáceis de usar e colaborem com outras pessoas compartilhando demos ao vivo.

## [**TensorFlow Hub**](https://www.tensorflow.org/hub) **e** [**Kaggle**](https://www.kaggle.com/)

**TensorFlow Hub** é um repositório abrangente de módulos reutilizáveis de machine learning desenvolvidos pelo Google. Seu foco é facilitar o compartilhamento e a implantação de modelos de machine learning, especialmente aqueles criados com TensorFlow.

* **Módulos:** Uma vasta coleção de modelos pré-treinados e componentes de modelos, onde os usuários podem navegar, baixar e integrar módulos para tarefas como classificação de imagens, embeddings de texto e muito mais.
* **Tutoriais:** Guias passo a passo e exemplos que ajudam os usuários a entender como implementar e ajustar modelos usando o TensorFlow Hub.
* **Documentação:** Guias abrangentes e referências de API que ajudam os desenvolvedores a utilizar efetivamente os recursos do repositório.

## [**Replicate**](https://replicate.com/home)

**Replicate** é uma plataforma que permite aos desenvolvedores executar modelos de machine learning na cloud por meio de uma API simples. Seu foco é tornar os modelos de ML facilmente acessíveis e implantáveis, sem a necessidade de uma configuração extensa da infraestrutura.

* **Modelos:** Um repositório de modelos de machine learning contribuídos pela comunidade, onde os usuários podem navegar, experimentar e integrar modelos em suas aplicações com o mínimo de esforço.
* **Acesso à API:** APIs simples para executar modelos, permitindo que os desenvolvedores implantem e dimensionem modelos facilmente em suas próprias aplicações.
