## Запуск і навчання моделей локально

### [**Hugging Face Transformers**](https://github.com/huggingface/transformers)

Hugging Face Transformers — одна з найпопулярніших open-source бібліотек для використання, навчання та розгортання LLMs, таких як GPT, BERT та багато інших. Вона пропонує комплексну екосистему, що включає попередньо навчені моделі, датасети та безшовну інтеграцію з Hugging Face Hub для fine-tuning і розгортання.

### [**LangChain**](https://github.com/langchain-ai/langchain)

LangChain — це framework, призначений для створення застосунків із LLMs. Він дає змогу розробникам підключати мовні моделі до зовнішніх джерел даних, API та баз даних. LangChain надає інструменти для advanced prompt engineering, керування історією розмов і інтеграції LLMs у складні workflow.

### [**LitGPT**](https://github.com/Lightning-AI/litgpt)

LitGPT — це проєкт, розроблений Lightning AI, який використовує framework Lightning для спрощення навчання, fine-tuning і розгортання моделей на основі GPT. Він безшовно інтегрується з іншими інструментами Lightning AI, надаючи оптимізовані workflow для роботи з великомасштабними мовними моделями з підвищеною продуктивністю та масштабованістю.

### [**LitServe**](https://github.com/Lightning-AI/LitServe)

**Опис:**\
LitServe — це інструмент розгортання від Lightning AI, призначений для швидкого та ефективного розгортання AI-моделей. Він спрощує інтеграцію LLMs у застосунки реального часу, надаючи масштабовані та оптимізовані можливості serving.

### [**Axolotl**](https://github.com/axolotl-ai-cloud/axolotl)

Axolotl — це cloud-based платформа, призначена для спрощення розгортання, масштабування та керування AI-моделями, зокрема LLMs. Вона пропонує такі функції, як автоматичне масштабування, моніторинг та інтеграція з різними cloud-сервісами, що спрощує розгортання моделей у production-середовищах без потреби в значному керуванні інфраструктурою.

## Спроба моделей онлайн

### [**Hugging Face**](https://huggingface.co/)

**Hugging Face** — провідна платформа та спільнота для machine learning, особливо відома своєю роботою у сфері natural language processing (NLP). Вона надає інструменти, бібліотеки та ресурси, які спрощують розробку, поширення та розгортання machine learning-моделей.\
Вона пропонує кілька розділів, зокрема:

* **Models**: Великий репозиторій **попередньо навчених machine learning-моделей**, де користувачі можуть переглядати, завантажувати та інтегрувати моделі для різних завдань, таких як генерація тексту, переклад, розпізнавання зображень тощо.
* **Datasets:** Комплексна **колекція датасетів**, що використовуються для навчання й оцінювання моделей. Вона забезпечує легкий доступ до різноманітних джерел даних, даючи змогу користувачам знаходити та використовувати дані для власних machine learning-проєктів.
* **Spaces:** Платформа для розміщення та поширення **інтерактивних machine learning-застосунків** і демо. Вона дає розробникам змогу **демонструвати** свої моделі в роботі, створювати зручні інтерфейси та співпрацювати з іншими, поширюючи live-демо.

## [**TensorFlow Hub**](https://www.tensorflow.org/hub) **&** [**Kaggle**](https://www.kaggle.com/)

**TensorFlow Hub** — це комплексний репозиторій повторно використовуваних machine learning-модулів, розроблених Google. Він зосереджений на спрощенні поширення та розгортання machine learning-моделей, особливо створених за допомогою TensorFlow.

* **Modules:** Велика колекція попередньо навчених моделей і компонентів моделей, де користувачі можуть переглядати, завантажувати та інтегрувати модулі для таких завдань, як класифікація зображень, text embedding тощо.
* **Tutorials:** Покрокові інструкції та приклади, які допомагають користувачам зрозуміти, як реалізовувати та fine-tune моделі за допомогою TensorFlow Hub.
* **Documentation:** Комплексні посібники та API-довідники, які допомагають розробникам ефективно використовувати ресурси репозиторію.

## [**Replicate**](https://replicate.com/home)

**Replicate** — це платформа, яка дає розробникам змогу запускати machine learning-моделі у cloud через простий API. Вона зосереджена на забезпеченні легкого доступу до ML-моделей і їх розгортанні без потреби в складному налаштуванні інфраструктури.

* **Models:** Репозиторій machine learning-моделей, наданих спільнотою, де користувачі можуть переглядати, випробовувати та інтегрувати моделі у свої застосунки з мінімальними зусиллями.
* **API Access:** Прості API для запуску моделей, які дають розробникам змогу легко розгортати та масштабувати моделі у власних застосунках.
