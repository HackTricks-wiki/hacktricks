# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Flipper Zero to przenośny multitool sprzętowy obsługujący następujące funkcje:<sup>[[1]](#references)</sup>

- **Odbieranie, przechwytywanie i odtwarzanie obsługiwanych sygnałów radiowych:** [**Sub-GHz**](fz-sub-ghz.md)
- **Odczytywanie, przechwytywanie i emulowanie obsługiwanych kart NFC:** [**NFC**](fz-nfc.md)
- **Odczytywanie, przechwytywanie i emulowanie obsługiwanych tagów 125 kHz:** [**RFID 125 kHz**](fz-125khz-rfid.md)
- **Odczytywanie, przechwytywanie i transmitowanie sygnałów podczerwieni:** [**Podczerwień**](fz-infrared.md)
- **Odczytywanie, przechwytywanie i emulowanie obsługiwanych iButtonów:** [**iButton**](../ibutton.md)
- **Działanie jako urządzenie BadUSB**
- **Działanie jako klucz bezpieczeństwa U2F**
- **Uruchamianie aplikacji i gier, takich jak Snake**

Firmware, aplikacje, bazy danych i inne zasoby utrzymywane przez społeczność można znaleźć w kolekcji Awesome Flipper Zero.<sup>[[2]](#references)</sup>
