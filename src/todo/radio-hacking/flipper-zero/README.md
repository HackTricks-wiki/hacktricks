# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Flipper Zero एक portable hardware multitool है, जो निम्नलिखित capabilities को support करता है:<sup>[[1]](#references)</sup>

- **Supported radio signals को receive, capture और replay करें:** [**Sub-GHz**](fz-sub-ghz.md)
- **Supported NFC cards को read, capture और emulate करें:** [**NFC**](fz-nfc.md)
- **Supported 125 kHz tags को read, capture और emulate करें:** [**125 kHz RFID**](fz-125khz-rfid.md)
- **Infrared signals को read, capture और transmit करें:** [**Infrared**](fz-infrared.md)
- **Supported iButtons को read, capture और emulate करें:** [**iButton**](../ibutton.md)
- **BadUSB device के रूप में कार्य करें**
- **U2F security key के रूप में कार्य करें**
- **Snake जैसे applications और games चलाएं**

Community-maintained firmware, applications, databases और अन्य resources के लिए Awesome Flipper Zero collection देखें।<sup>[[2]](#references)</sup>
