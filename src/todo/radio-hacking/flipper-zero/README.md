[**Flipper Zero**](https://flipperzero.one/) では、以下ができます：

- **無線周波数のListen/Capture/Replay:** [**Sub-GHz**](fz-sub-ghz.md)
- **NFCカードのRead/Capture/Emulate:** [**NFC**](fz-nfc.md)
- **125kHzタグのRead/Capture/Emulate:** [**125kHz RFID**](fz-125khz-rfid.md)
- **赤外線信号のRead/Capture/Send:** [**Infrared**](fz-infrared.md)
- **iButtonのRead/Capture/Emulate:** [**iButton**](../ibutton.md)
- **Bad USBとして使用**
- **セキュリティキー（U2F）として使用**
- **Snakeをプレイ**

**Flipper Zeroに関するその他のリソース：** [**https://github.com/djsime1/awesome-flipperzer**](https://github.com/djsime1/awesome-flipperzero)
