# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Το Flipper Zero είναι ένα φορητό hardware multitool που υποστηρίζει τις ακόλουθες δυνατότητες:<sup>[[1]](#references)</sup>

- **Λήψη, καταγραφή και επανάληψη υποστηριζόμενων radio signals:** [**Sub-GHz**](fz-sub-ghz.md)
- **Ανάγνωση, καταγραφή και emulation υποστηριζόμενων καρτών NFC:** [**NFC**](fz-nfc.md)
- **Ανάγνωση, καταγραφή και emulation υποστηριζόμενων tags 125 kHz:** [**125 kHz RFID**](fz-125khz-rfid.md)
- **Ανάγνωση, καταγραφή και μετάδοση infrared signals:** [**Infrared**](fz-infrared.md)
- **Ανάγνωση, καταγραφή και emulation υποστηριζόμενων iButtons:** [**iButton**](../ibutton.md)
- **Λειτουργία ως συσκευή BadUSB**
- **Λειτουργία ως κλειδί ασφαλείας U2F**
- **Εκτέλεση εφαρμογών και παιχνιδιών, όπως το Snake**

Για firmware, εφαρμογές, databases και άλλους πόρους που συντηρούνται από την κοινότητα, δείτε τη συλλογή Awesome Flipper Zero.<sup>[[2]](#references)</sup>
