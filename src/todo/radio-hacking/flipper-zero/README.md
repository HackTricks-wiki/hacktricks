# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Flipper Zero — це портативний апаратний мультитул, який підтримує такі можливості:<sup>[[1]](#references)</sup>

- **Приймання, захоплення та повторне відтворення підтримуваних радіосигналів:** [**Sub-GHz**](fz-sub-ghz.md)
- **Зчитування, захоплення та емуляція підтримуваних NFC-карт:** [**NFC**](fz-nfc.md)
- **Зчитування, захоплення та емуляція підтримуваних тегів 125 кГц:** [**125 kHz RFID**](fz-125khz-rfid.md)
- **Зчитування, захоплення та передавання інфрачервоних сигналів:** [**Infrared**](fz-infrared.md)
- **Зчитування, захоплення та емуляція підтримуваних iButtons:** [**iButton**](../ibutton.md)
- **Робота як пристрій BadUSB**
- **Робота як ключ безпеки U2F**
- **Запуск застосунків та ігор, таких як Snake**

Для прошивок, застосунків, баз даних та інших ресурсів, які підтримує спільнота, дивіться колекцію Awesome Flipper Zero.<sup>[[2]](#references)</sup>
