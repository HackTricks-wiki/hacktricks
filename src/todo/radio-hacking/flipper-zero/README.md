# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Με το [**Flipper Zero**](https://flipperzero.one/) μπορείτε να:

- **Ακούτε/Καταγράφετε/Επαναλαμβάνετε ραδιοσυχνότητες:** [**Sub-GHz**](fz-sub-ghz.md)
- **Διαβάζετε/Καταγράφετε/Προσομοιώνετε κάρτες NFC:** [**NFC**](fz-nfc.md)
- **Διαβάζετε/Καταγράφετε/Προσομοιώνετε tags 125kHz:** [**125kHz RFID**](fz-125khz-rfid.md)
- **Διαβάζετε/Καταγράφετε/Στέλνετε σήματα Infrared:** [**Infrared**](fz-infrared.md)
- **Διαβάζετε/Καταγράφετε/Προσομοιώνετε iButtons:** [**iButton**](../ibutton.md)
- **Το χρησιμοποιείτε ως Bad USB**
- **Το χρησιμοποιείτε ως security key (U2F)**
- **Παίζετε Snake**

**Άλλοι πόροι για το Flipper Zero στο** [**https://github.com/djsime1/awesome-flipperzer**](https://github.com/djsime1/awesome-flipperzero)
