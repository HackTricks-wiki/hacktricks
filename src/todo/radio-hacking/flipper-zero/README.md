# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Flipper Zero 是一款便携式硬件多功能工具，支持以下功能：<sup>[[1]](#references)</sup>

- **接收、捕获并重放受支持的无线电信号：** [**Sub-GHz**](fz-sub-ghz.md)
- **读取、捕获并模拟受支持的 NFC 卡：** [**NFC**](fz-nfc.md)
- **读取、捕获并模拟受支持的 125 kHz 标签：** [**125 kHz RFID**](fz-125khz-rfid.md)
- **读取、捕获并传输红外信号：** [**Infrared**](fz-infrared.md)
- **读取、捕获并模拟受支持的 iButtons：** [**iButton**](../ibutton.md)
- **充当 BadUSB 设备**
- **充当 U2F 安全密钥**
- **运行 Snake 等应用程序和游戏**

有关社区维护的固件、应用程序、数据库和其他资源，请参阅 Awesome Flipper Zero 集合。<sup>[[2]](#references)</sup>
