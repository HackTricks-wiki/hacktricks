# Flipper Zero

{{#include ../../../banners/hacktricks-training.md}}

Flipper Zero는 다음 기능을 지원하는 휴대용 hardware multitool입니다:<sup>[[1]](#references)</sup>

- **지원되는 radio signal 수신, 캡처 및 replay:** [**Sub-GHz**](fz-sub-ghz.md)
- **지원되는 NFC card 읽기, 캡처 및 에뮬레이션:** [**NFC**](fz-nfc.md)
- **지원되는 125 kHz tag 읽기, 캡처 및 에뮬레이션:** [**125 kHz RFID**](fz-125khz-rfid.md)
- **infrared signal 읽기, 캡처 및 전송:** [**Infrared**](fz-infrared.md)
- **지원되는 iButton 읽기, 캡처 및 에뮬레이션:** [**iButton**](../ibutton.md)
- **BadUSB device로 동작**
- **U2F security key로 동작**
- **Snake와 같은 application 및 game 실행**

커뮤니티에서 유지 관리하는 firmware, application, database 및 기타 resource는 Awesome Flipper Zero collection을 참조하세요.<sup>[[2]](#references)</sup>
