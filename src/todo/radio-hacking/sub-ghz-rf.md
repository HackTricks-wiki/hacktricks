## Гаражні двері

Пристрої відкривання гаражних дверей зазвичай працюють у діапазоні частот 300–190 MHz, найпоширенішими з яких є 300 MHz, 310 MHz, 315 MHz і 390 MHz. Цей частотний діапазон часто використовується для пристроїв відкривання гаражних дверей, оскільки він менш завантажений, ніж інші діапазони частот, і менш схильний до перешкод від інших пристроїв.

## Автомобільні двері

Більшість автомобільних key fob працюють на частоті **315 MHz або 433 MHz**. Це радіочастоти, які використовуються в різних сферах. Основна відмінність між цими частотами полягає в тому, що 433 MHz має більший радіус дії, ніж 315 MHz. Це означає, що 433 MHz краще підходить для застосувань, які потребують більшого радіуса дії, наприклад для remote keyless entry.\
У Європі зазвичай використовується частота 433,92 MHz, а в США та Японії — 315 MHz.<sup>[[1]](#references)</sup>

## Захист Rolling Codes

Автоматичні пристрої відкривання гаражних дверей зазвичай використовують бездротовий пульт для відкривання та закривання гаражних дверей. Пульт **надсилає радіочастотний (RF) сигнал** пристрою відкривання гаражних дверей, який активує двигун для відкривання або закривання дверей.

Хтось може використати пристрій, відомий як code grabber, щоб перехопити RF-сигнал і записати його для подальшого використання. Це називається **replay attack**. Щоб запобігти такому типу атаки, багато сучасних пристроїв відкривання гаражних дверей використовують безпечніший метод шифрування, відомий як система **rolling code**.

**RF-сигнал зазвичай передається з використанням rolling code**, тобто код змінюється під час кожного використання. Це **ускладнює** можливість для когось **перехопити** сигнал і **використати** його для отримання **несанкціонованого** доступу до гаража.

У системі rolling code пульт і пристрій відкривання гаражних дверей мають **спільний алгоритм**, який **генерує новий код** щоразу під час використання пульта. Пристрій відкривання гаражних дверей реагуватиме лише на **правильний код**, що значно ускладнює отримання несанкціонованого доступу до гаража лише шляхом захоплення коду.

### **Missing Link Attack**

По суті, потрібно прослуховувати натискання кнопки й **захопити сигнал, поки пульт перебуває поза зоною дії** пристрою (наприклад, автомобіля або гаража). Потім потрібно підійти до пристрою та **використати захоплений код для його відкривання**.<sup>[[2]](#references)</sup>

### Full Link Jamming Attack

Зловмисник може **заглушити сигнал поблизу автомобіля або приймача**, щоб **приймач фактично не почув код**, а після цього можна просто **захопити й повторно передати** код, коли глушіння припинено.<sup>[[2]](#references)</sup>

У певний момент жертва використає **ключі, щоб замкнути автомобіль**, але до того часу атака вже **запише достатню кількість кодів "закрити двері"**, які, можливо, можна буде повторно передати для відкривання дверей (може знадобитися **зміна частоти**, оскільки деякі автомобілі використовують однакові коди для відкривання та закривання, але прослуховують обидві команди на різних частотах).

> [!WARNING]
> **Глушіння працює**, але його помітно: якщо **людина, яка замикає автомобіль, просто перевірить двері**, щоб переконатися, що вони замкнені, вона помітить, що автомобіль залишився незамкненим. Крім того, якщо вона знатиме про такі атаки, то може навіть звернути увагу на те, що двері ніколи не видавали **звуку замикання** або що **фари автомобіля** не блимнули після натискання кнопки «замкнути».

### **Code Grabbing Attack ( aka ‘RollJam’ )**

Це більш **прихована техніка Jamming**. Зловмисник заглушить сигнал, тому коли жертва спробує замкнути двері, це не спрацює, але зловмисник **запише цей код**. Потім жертва **спробує знову замкнути автомобіль**, натиснувши кнопку, і автомобіль **запише цей другий код**.<sup>[[2]](#references)[[4]](#references)</sup>\
Одразу після цього **зловмисник може надіслати перший код**, і **автомобіль замкнеться** (жертва вважатиме, що його замкнуло друге натискання). Потім зловмисник зможе **надіслати другий викрадений код, щоб відкрити** автомобіль (якщо **код "закрити автомобіль" також можна використати для його відкривання**). Може знадобитися зміна частоти (оскільки деякі автомобілі використовують однакові коди для відкривання та закривання, але прослуховують обидві команди на різних частотах).

Зловмисник може **глушити приймач автомобіля, але не власний приймач**, оскільки якщо приймач автомобіля прослуховує, наприклад, широкосмуговий діапазон 1 MHz, зловмисник не буде **глушити** точну частоту, яку використовує пульт, а **близьку частоту в цьому спектрі**, тоді як **приймач зловмисника прослуховуватиме менший діапазон**, у якому він зможе прослухати сигнал пульта **без сигналу глушіння**.

> [!WARNING]
> Інші реалізації, описані у специфікаціях, показують, що **rolling code є частиною** загального коду, що надсилається. Наприклад, код, що надсилається, є **24-бітним ключем**, де перші **12 бітів — це rolling code**, наступні **8 бітів — команда** (наприклад, замикання або відмикання), а останні 4 — **контрольна сума**. Транспортні засоби з такою реалізацією також природно вразливі, оскільки зловмиснику достатньо замінити сегмент rolling code, щоб мати змогу **використовувати будь-який rolling code на обох частотах**.

> [!CAUTION]
> Зверніть увагу: якщо жертва надішле третій код, поки зловмисник надсилає перший, перший і другий коди стануть недійсними.

### Alarm Sounding Jamming Attack

Під час тестування aftermarket rolling code системи, встановленої на автомобілі, **надсилання одного й того самого коду двічі** негайно **активувало сигналізацію** та іммобілайзер, створюючи унікальну можливість для **denial of service**. Парадоксально, але способом **вимкнення сигналізації** та іммобілайзера було **натиснути** кнопку **пульта**, що надавало зловмиснику можливість **безперервно виконувати DoS attack**. Або можна поєднати цю атаку з **попередньою**, щоб отримати більше кодів, оскільки жертва захоче якнайшвидше припинити атаку.<sup>[[2]](#references)</sup>
