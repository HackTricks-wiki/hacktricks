## Garage Doors

Пульти керування гаражними воротами зазвичай працюють у діапазоні частот 300-190 МГц, найпоширенішими з яких є 300 МГц, 310 МГц, 315 МГц і 390 МГц. Цей діапазон частот часто використовується для пультів гаражних воріт, оскільки він менш завантажений, ніж інші діапазони, і менш схильний до перешкод від інших пристроїв.

## Car Doors

Більшість автомобільних key fob працюють на частотах **315 МГц або 433 МГц**. Обидві є радіочастотами та використовуються в різних застосунках. Основна відмінність між цими частотами полягає в тому, що 433 МГц має більший радіус дії, ніж 315 МГц. Це означає, що 433 МГц краще підходить для застосунків, які потребують більшого радіуса дії, наприклад remote keyless entry.\
У Європі зазвичай використовується частота 433,92 МГц, а у США та Японії — 315 МГц.<sup>[[1]](#references)</sup>

## Rolling Codes Protection

Автоматичні пульти гаражних воріт зазвичай використовують wireless remote control для відкривання та закривання гаражних воріт. Remote control **надсилає радіочастотний (RF) сигнал** до механізму гаражних воріт, який активує двигун для відкривання або закривання воріт.

Хтось може використати пристрій, відомий як code grabber, щоб перехопити RF-сигнал і записати його для подальшого використання. Це називається **replay attack**. Щоб запобігти такому типу атаки, багато сучасних механізмів гаражних воріт використовують надійніший метод шифрування, відомий як система **rolling code**.

**RF-сигнал зазвичай передається з використанням rolling code**, тобто код змінюється під час кожного використання. Це **ускладнює** можливість **перехопити** сигнал і **використати** його для отримання **несанкціонованого** доступу до гаража.

У системі rolling code remote control і механізм гаражних воріт мають **спільний алгоритм**, який **генерує новий код** щоразу, коли використовується remote. Механізм гаражних воріт реагуватиме лише на **правильний код**, що значно ускладнює отримання несанкціонованого доступу до гаража простим захопленням коду.

### **Missing Link Attack**

По суті, потрібно прослуховувати натискання кнопки та **захопити сигнал, поки remote перебуває поза зоною дії** пристрою (наприклад, автомобіля або гаража). Потім потрібно підійти до пристрою та **використати захоплений код, щоб відкрити його**.<sup>[[2]](#references)</sup>

### Full Link Jamming Attack

Зловмисник може **заглушити сигнал поблизу автомобіля або receiver**, щоб **receiver фактично не почув код**, а коли це станеться, можна просто **захопити та відтворити** код після припинення глушіння.

У певний момент жертва використає **ключі, щоб замкнути автомобіль**, але до цього атака вже **запише достатню кількість кодів «закрити двері»**, які, можливо, можна буде повторно надіслати для відкривання дверей (може знадобитися **зміна частоти**, оскільки деякі автомобілі використовують однакові коди для відкривання та закривання, але прослуховують обидві команди на різних частотах).

> [!WARNING]
> **Jamming працює**, але його помітно: якщо **людина, яка замикає автомобіль, просто перевірить двері**, щоб переконатися, що вони замкнені, вона помітить, що автомобіль розблокований. Крім того, якщо вона знає про такі атаки, то може навіть звернути увагу, що двері ніколи не видавали **звуку замикання**, або що **фари автомобіля** не блимнули після натискання кнопки «lock».

### **Code Grabbing Attack ( aka ‘RollJam’ )**

Це більш **прихована техніка Jamming**. Зловмисник заглушить сигнал, тому коли жертва спробує замкнути двері, це не спрацює, але зловмисник **запише цей код**. Потім жертва **спробує знову замкнути автомобіль**, натиснувши кнопку, і автомобіль **запише цей другий код**.\
Одразу після цього **зловмисник може надіслати перший код**, і **автомобіль замкнеться** (жертва подумає, що його замкнуло друге натискання). Потім зловмисник зможе **надіслати другий викрадений код, щоб відкрити** автомобіль (за умови, що **код «закрити автомобіль» також можна використати для його відкривання**). Може знадобитися зміна частоти (оскільки деякі автомобілі використовують однакові коди для відкривання та закривання, але прослуховують обидві команди на різних частотах).<sup>[[3]](#references)[[2]](#references)</sup>

Зловмисник може **заглушити receiver автомобіля, але не свій receiver**, оскільки якщо receiver автомобіля прослуховує, наприклад, широкосмуговий діапазон 1 МГц, зловмисник не **заглушатиме** точну частоту, яку використовує remote, а **близьку частоту в цьому спектрі**, тоді як **receiver зловмисника прослуховуватиме вужчий діапазон**, у якому він зможе прослухати сигнал remote **без сигналу перешкод**.

> [!WARNING]
> Інші реалізації, описані у specifications, показують, що **rolling code є частиною** загального коду, який надсилається. Наприклад, код, що надсилається, є **24-бітним ключем**, де перші **12 бітів — rolling code**, наступні **8 бітів — команда** (наприклад, lock або unlock), а останні 4 — **checksum**. Автомобілі з такою реалізацією також природно вразливі, оскільки зловмиснику достатньо замінити сегмент rolling code, щоб мати змогу **використовувати будь-який rolling code на обох частотах**.

> [!CAUTION]
> Зверніть увагу: якщо жертва надішле третій код, поки зловмисник надсилає перший, перший і другий коди стануть недійсними.

### Alarm Sounding Jamming Attack

Під час тестування aftermarket-системи rolling code, встановленої в автомобілі, **надсилання одного й того самого коду двічі** негайно **активувало alarm** та immobiliser, створюючи унікальну можливість для **denial of service**. Парадоксально, вимкнути alarm та immobiliser можна було, **натиснувши** кнопку **remote**, що надавало зловмиснику можливість **безперервно виконувати DoS attack**. Або можна поєднати цю атаку з **попередньою, щоб отримати більше кодів**, оскільки жертва захоче якнайшвидше припинити атаку.<sup>[[2]](#references)</sup>
