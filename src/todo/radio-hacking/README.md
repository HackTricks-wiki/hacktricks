# Radio Hacking

{{#include ../../banners/hacktricks-training.md}}

Η δοκιμή ασφάλειας ραδιοεπικοινωνιών εξετάζει τον τρόπο με τον οποίο μια συσκευή μεταδίδει, λαμβάνει και ερμηνεύει ασύρματα σήματα. Ένα software-defined radio (SDR) μπορεί να βοηθήσει στον εντοπισμό ενός σήματος, στην καταγραφή δειγμάτων in-phase/quadrature (I/Q) και στη δοκιμή αποδιαμόρφωσης και αποκωδικοποίησης χωρίς να απαιτείται η χρήση hardware συγκεκριμένου πρωτοκόλλου.<sup>[[1]](#references)</sup>

Μια πρακτική ροή εργασίας είναι να προσδιορίσετε τη ζώνη συχνοτήτων και το εύρος καναλιού, να καταγράψετε αρκετές γνωστές ενέργειες της συσκευής, να συγκρίνετε τα σήματα που προκύπτουν και, στη συνέχεια, να προσδιορίσετε τη διαμόρφωση και τη δομή των packets. Δοκιμάστε replay ή transmission μόνο σε απομονωμένο περιβάλλον και σε συχνότητες και εξοπλισμό για τους οποίους έχετε εξουσιοδότηση. Οι σελίδες αυτής της ενότητας καλύπτουν RFID, NFC, sub-GHz radio, infrared, BLE και σχετικά εργαλεία.<sup>[[1]](#references)</sup>
