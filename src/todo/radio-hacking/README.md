# Radio Hacking

{{#include ../../banners/hacktricks-training.md}}

Тестування безпеки радіозв'язку досліджує, як пристрій передає, приймає та інтерпретує бездротові сигнали. Програмно визначуване радіо (SDR) може допомогти виявити сигнал, записати синфазні/квадратурні (I/Q) відліки та перевірити демодуляцію й декодування без прив'язки до спеціалізованого апаратного забезпечення протоколу.<sup>[[1]](#references)</sup>

Практичний процес полягає у визначенні частотного діапазону та ширини каналу, захопленні кількох відомих дій пристрою, порівнянні отриманих сигналів і подальшому визначенні модуляції та структури пакетів. Перевіряйте replay або передавання лише в ізольованому середовищі та на частотах і обладнанні, для яких ви маєте дозвіл. Сторінки цього розділу охоплюють RFID, NFC, sub-GHz радіозв'язок, інфрачервоний зв'язок, BLE та пов'язані інструменти.<sup>[[1]](#references)</sup>
