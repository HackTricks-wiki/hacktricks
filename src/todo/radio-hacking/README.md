# Hacking de radio

{{#include ../../banners/hacktricks-training.md}}

Las pruebas de seguridad de radio examinan cómo un dispositivo transmite, recibe e interpreta señales inalámbricas. Una radio definida por software (SDR) puede ayudar a localizar una señal, registrar muestras en fase/cuadratura (I/Q) y probar la demodulación y decodificación sin depender de hardware específico del protocolo.<sup>[[1]](#references)</sup>

Un flujo de trabajo práctico consiste en identificar la banda de frecuencia y el ancho de canal, capturar varias acciones conocidas del dispositivo, comparar las señales resultantes y, después, determinar la modulación y la estructura de los paquetes. Prueba la reproducción o transmisión únicamente en un entorno aislado y en frecuencias y equipos para los que tengas autorización. Las páginas de esta sección cubren RFID, NFC, radio sub-GHz, infrarrojos, BLE y herramientas relacionadas.<sup>[[1]](#references)</sup>
