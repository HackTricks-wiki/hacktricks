## Data Breach Search Engines

- [greynoise](https://viz.greynoise.io/) - IP、Tag、CVE、vpn、dns などを検索
- [Dehashed](https://www.dehashed.com/) - メールアドレスが何らかのデータベースで leak しているか検索できます。
- [HaveIbeenPwned?](https://haveibeenpwned.com/) - メールアドレスが data breach に含まれているか確認
- [ScamSearch](https://scamsearch.io/) - 電話番号、メールアドレス、プロフィールを検索し、詐欺師かどうかを確認。
- [Intelligence X](https://intelx.io/) - Intelligence X は検索エンジンおよびデータアーカイブです。· 検索は selector を使用して行います。selector には、メールアドレス、ドメイン、URL、IP などの具体的な検索語を指定できます。
- [spycloud](https://portal.spycloud.com/endpoint/enriched-stats/[YOUR-MAIL]) - YOUR-MAIL に自分のメールアドレスを入力します。
- [weleakinfo](https://weleakinfo.io/) - We Leak Info - Dehashed Database の leak を検索。
- [breachdirectory](https://breachdirectory.org/) - メールアドレスまたはユーザー名が侵害されているか確認
- [leakcheck](https://leakcheck.io/) - 認証情報が侵害されているか確認
- [Findemail.io](https://findemail.io/) - 指定した企業のメールアドレスを検索。
- [LibraryOfLeaks](https://search.libraryofleaks.org) - leak した文書、企業、人、database などを検索
- [LeakRadar](https://leakradar.io/) - 20億件以上のプレーンテキスト形式の infostealer 認証情報を横断検索。メールアドレス、ドメイン、metadata のクエリ、monitoring、API に対応
- [InfoStealers](https://infostealers.info/en/info) - darknet に公開された infostealer log を index 化し、security team、investigator、researcher、digital forensics professional が検索・活用できるようにします。
- [Leak-Lookup](https://leak-lookup.com/) - 3,000以上の database から30億件を超えるレコードを検索できる data breach search engine。
- [BreachDirectory](https://breachdirectory.org/) - data breach によって認証情報が侵害されているか確認。
- [Scylla.so](https://scylla.so/) - Community-driven な database breach search engine。
- [Leaked.domains](https://leaked.domains/) - ドメインに関連する leak した認証情報とデータを検索。
- [WhiteIntel](https://whiteintel.io/) - threat intelligence 向けの dark web data leak search engine。
- [PSBDMP](https://psbdmp.ws/) - Pastebin dump の検索および monitoring platform。


## Tools to enumerate data leaks

- [Leaker](https://github.com/vflame6/leaker) - 10個の breach database を同時に検索する Passive leak enumeration CLI tool。
