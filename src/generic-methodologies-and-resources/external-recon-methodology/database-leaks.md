## Data Breach 搜索引擎

- [GreyNoise Visualizer](https://viz.greynoise.io/) - 查询 IP 和 CIDR，并通过 tags、CVE 和 metadata 查询 scanner 活动。<sup>[[1]](#references)</sup>
- [DeHashed](https://www.dehashed.com/) - 通过用户名、email 地址、IP 地址和其他 selectors 搜索暴露的数据；还提供 monitoring 和 API。<sup>[[2]](#references)</sup>
- [Have I Been Pwned?](https://haveibeenpwned.com/) - 检查 email 地址是否出现在已知 data breaches 或 paste records 中；还提供 notifications 和 API。<sup>[[3]](#references)</sup>
- [ScamSearch](https://scamsearch.io/) - 通过 profile picture、email、username、phone number、crypto address 或 website 搜索已报告的 scammer records。<sup>[[4]](#references)</sup>
- [Intelligence X](https://intelx.io/) - 在已索引的 sources 中搜索 email 地址、domains、URLs、IPs 和 CIDRs 等 selectors。<sup>[[5]](#references)</sup>
- [SpyCloud](https://spycloud.com/check-your-exposure/) - 检查 business email 或 domain 是否存在暴露的 credentials、受 infostealer 感染的 identities 和被盗的 session cookies。<sup>[[6]](#references)</sup>
- [WeLeakInfo](https://weleakinfo.io/) - 使用 domains、names、emails、IDs、phones、IPs、URLs 或 hashes 搜索 leaked databases。<sup>[[7]](#references)</sup>
- [BreachDirectory](https://breachdirectory.org/) - 检查你的 email 或 username 是否已被 compromized。
- [LeakCheck](https://leakcheck.io/) - 搜索暴露的 email、username、phone、hash 或 domain 数据，并 monitoring 新条目。<sup>[[8]](#references)</sup>
- [Findemail.io](https://findemail.io/) - 查找指定公司的 email 地址。
- [Library of Leaks](https://search.libraryofleaks.org/) - 搜索公开 documents、companies 和 people，包括 leak datasets。<sup>[[9]](#references)</sup>
- [LeakRadar](https://leakradar.io/) - 通过 email、domain 或 raw string 搜索 leaked credentials，并 monitoring 新的暴露数据。<sup>[[10]](#references)</sup>
- [InfoStealers](https://infostealers.info/en/info) - 搜索来自受感染设备的 infostealer logs，并 monitoring 新数据。<sup>[[11]](#references)</sup>
- [Leak-Lookup](https://leak-lookup.com/) - 跨 data breaches 搜索，并 monitoring credential exposure。<sup>[[12]](#references)</sup>
- [Scylla.so](https://scylla.so/) - 社区驱动的 database breach 搜索引擎。
- [Leaked.domains](https://leaked.domains/) - 通过 domain、email、username、password、IP 和其他 selectors 搜索 leaked credentials 及相关 records。<sup>[[13]](#references)</sup>
- [WhiteIntel](https://whiteintel.io/) - Monitoring dark web 活动、credential leaks、infostealer 数据和 brand mentions。<sup>[[14]](#references)</sup>
- [PSBDMP](https://psbdmp.ws/) - Pastebin dump 搜索和 monitoring 平台。

## 用于枚举 data leaks 的工具

- [Leaker](https://github.com/vflame6/leaker) - 被动式 leak discovery CLI，可按 email、username、domain、keyword 或 phone 搜索多个 online sources。<sup>[[15]](#references)</sup>
