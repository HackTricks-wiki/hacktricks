## 数据泄露搜索引擎

- [greynoise](https://viz.greynoise.io/) - 搜索 IP、Tags、CVE、vpn、dns...
- [Dehashed](https://www.dehashed.com/) - 如果你的邮箱出现在某些数据库的 leak 中，可以搜索你的邮箱。
- [HaveIbeenPwned?](https://haveibeenpwned.com/) - 检查你的邮箱地址是否出现在数据泄露中
- [ScamSearch](https://scamsearch.io/) - 搜索电话号码、邮箱和个人资料，以确认对方是否是骗子。
- [Intelligence X](https://intelx.io/) - Intelligence X 是一个搜索引擎和数据存档。· 搜索使用 selectors，即特定搜索词，例如邮箱地址、域名、URL、IP 等。
- [spycloud](https://portal.spycloud.com/endpoint/enriched-stats/[YOUR-MAIL]) - 将你的邮箱填写到 YOUR-MAIL 中。
- [weleakinfo](https://weleakinfo.io/) - We Leak Info - 已 leak 的 Dehashed 数据库，搜索 leak。
- [breachdirectory](https://breachdirectory.org/) - 检查你的邮箱或用户名是否已被泄露
- [leakcheck](https://leakcheck.io/) - 查明你的凭据是否已被泄露
- [Findemail.io](https://findemail.io/) - 查找指定公司的邮箱地址。
- [LibraryOfLeaks](https://search.libraryofleaks.org) - 搜索 leak 文档、公司、人员、数据库等
- [LeakRadar](https://leakradar.io/) - 即时搜索超过 20 亿条纯文本信息窃取器凭据；支持邮箱、域名、元数据查询、监控和 API
- [InfoStealers](https://infostealers.info/en/info) - 对暴露于 darknet 的 infostealer 日志建立索引，使安全团队、调查人员、研究人员和数字取证专业人员能够搜索并采取行动。
- [Leak-Lookup](https://leak-lookup.com/) - 数据泄露搜索引擎，包含来自 3000 多个数据库的超过 30 亿条记录。
- [BreachDirectory](https://breachdirectory.org/) - 检查你的凭据是否已在数据泄露中被泄露。
- [Scylla.so](https://scylla.so/) - 社区驱动的数据库泄露搜索引擎。
- [Leaked.domains](https://leaked.domains/) - 搜索与域名相关的已 leak 凭据和数据。
- [WhiteIntel](https://whiteintel.io/) - 用于威胁情报的 dark web 数据 leak 搜索引擎。
- [PSBDMP](https://psbdmp.ws/) - Pastebin dump 搜索和监控平台。


## 用于枚举数据 leak 的工具

- [Leaker](https://github.com/vflame6/leaker) - 被动 leak 枚举 CLI 工具，可同时搜索 10 个 breach 数据库。
