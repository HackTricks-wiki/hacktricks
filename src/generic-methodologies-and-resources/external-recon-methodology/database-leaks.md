# Database leaks

## Пошукові системи Data Breach

- [GreyNoise Visualizer](https://viz.greynoise.io/) - Пошук IP-адрес і CIDR, а також запитів щодо активності сканерів за тегами, CVE та метаданими.<sup>[[1]](#references)</sup>
- [DeHashed](https://www.dehashed.com/) - Пошук exposed data за іменами користувачів, email-адресами, IP-адресами та іншими селекторами; також доступні моніторинг і API.<sup>[[2]](#references)</sup>
- [Have I Been Pwned?](https://haveibeenpwned.com/) - Перевірка, чи присутня email-адреса у відомих data breaches або paste-записах; також доступні сповіщення й API.<sup>[[3]](#references)</sup>
- [ScamSearch](https://scamsearch.io/) - Пошук записів про шахраїв за зображенням профілю, email, іменем користувача, номером телефону, crypto-адресою або вебсайтом.<sup>[[4]](#references)</sup>
- [Intelligence X](https://intelx.io/) - Пошук селекторів, таких як email-адреси, домени, URL, IP-адреси та CIDR, серед indexed sources.<sup>[[5]](#references)</sup>
- [SpyCloud](https://spycloud.com/check-your-exposure/) - Перевірка робочої email-адреси або домену на наявність exposed credentials, identities, інфікованих infostealer, і викрадених session cookies.<sup>[[6]](#references)</sup>
- [WeLeakInfo](https://weleakinfo.io/) - Пошук у leaked databases за доменами, іменами, email, ID, телефонами, IP-адресами, URL або хешами.<sup>[[7]](#references)</sup>
- [BreachDirectory](https://breachdirectory.org/) - Перевірка, чи була скомпрометована ваша email-адреса або ім’я користувача.
- [LeakCheck](https://leakcheck.io/) - Пошук exposed data за email, іменем користувача, телефоном, хешем або доменом і моніторинг нових записів.<sup>[[8]](#references)</sup>
- [Findemail.io](https://findemail.io/) - Пошук email-адрес для певної компанії.
- [Library of Leaks](https://search.libraryofleaks.org/) - Пошук публічних документів, компаній і людей, зокрема leak datasets.<sup>[[9]](#references)</sup>
- [LeakRadar](https://leakradar.io/) - Пошук leaked credentials за email, доменом або raw string і моніторинг нових exposures.<sup>[[10]](#references)</sup>
- [InfoStealers](https://infostealers.info/en/info) - Пошук infostealer logs з інфікованих пристроїв і моніторинг нових даних.<sup>[[11]](#references)</sup>
- [Leak-Lookup](https://leak-lookup.com/) - Пошук у data breaches і моніторинг credential exposure.<sup>[[12]](#references)</sup>
- [Scylla.so](https://scylla.so/) - Community-driven пошукова система для database breaches.
- [Leaked.domains](https://leaked.domains/) - Пошук leaked credentials і пов’язаних записів за доменом, email, іменем користувача, паролем, IP-адресою та іншими селекторами.<sup>[[13]](#references)</sup>
- [WhiteIntel](https://whiteintel.io/) - Моніторинг активності в dark web, credential leaks, infostealer data і згадок про бренд.<sup>[[14]](#references)</sup>
- [PSBDMP](https://psbdmp.ws/) - Платформа для пошуку й моніторингу dump-файлів Pastebin.

## Інструменти для перерахування data leaks

- [Leaker](https://github.com/vflame6/leaker) - CLI для пасивного виявлення leaks, який виконує пошук у кількох online sources за email, іменем користувача, доменом, ключовим словом або номером телефону.<sup>[[15]](#references)</sup>
