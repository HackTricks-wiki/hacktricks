# Διαρροές Database

## Μηχανές αναζήτησης παραβιάσεων δεδομένων

- [GreyNoise Visualizer](https://viz.greynoise.io/) - Αναζητήστε IPs και CIDRs και ελέγξτε τη δραστηριότητα scanners με βάση tags, CVEs και metadata.<sup>[[1]](#references)</sup>
- [DeHashed](https://www.dehashed.com/) - Αναζητήστε εκτεθειμένα δεδομένα με usernames, διευθύνσεις email, διευθύνσεις IP και άλλα κριτήρια· διατίθενται επίσης monitoring και API.<sup>[[2]](#references)</sup>
- [Have I Been Pwned?](https://haveibeenpwned.com/) - Ελέγξτε αν μια διεύθυνση email εμφανίζεται σε γνωστά data breaches ή paste records· διατίθενται επίσης ειδοποιήσεις και API.<sup>[[3]](#references)</sup>
- [ScamSearch](https://scamsearch.io/) - Αναζητήστε καταγεγραμμένα στοιχεία scammers με βάση profile picture, email, username, αριθμό τηλεφώνου, crypto address ή website.<sup>[[4]](#references)</sup>
- [Intelligence X](https://intelx.io/) - Αναζητήστε κριτήρια όπως διευθύνσεις email, domains, URLs, IPs και CIDRs σε indexed sources.<sup>[[5]](#references)</sup>
- [SpyCloud](https://spycloud.com/check-your-exposure/) - Ελέγξτε ένα εταιρικό email ή domain για εκτεθειμένα credentials, identities μολυσμένα από infostealers και κλεμμένα session cookies.<sup>[[6]](#references)</sup>
- [WeLeakInfo](https://weleakinfo.io/) - Αναζητήστε leaked databases χρησιμοποιώντας domains, ονόματα, emails, IDs, τηλέφωνα, IPs, URLs ή hashes.<sup>[[7]](#references)</sup>
- [BreachDirectory](https://breachdirectory.org/) - Ελέγξτε αν το email ή το username σας έχει παραβιαστεί.
- [LeakCheck](https://leakcheck.io/) - Αναζητήστε εκτεθειμένα δεδομένα email, username, τηλεφώνου, hash ή domain και παρακολουθήστε για νέες καταχωρίσεις.<sup>[[8]](#references)</sup>
- [Findemail.io](https://findemail.io/) - Βρείτε διευθύνσεις email για μια συγκεκριμένη εταιρεία.
- [Library of Leaks](https://search.libraryofleaks.org/) - Αναζητήστε δημόσια έγγραφα, εταιρείες και άτομα, συμπεριλαμβανομένων leak datasets.<sup>[[9]](#references)</sup>
- [LeakRadar](https://leakradar.io/) - Αναζητήστε leaked credentials με βάση email, domain ή raw string και παρακολουθήστε για νέες εκθέσεις.<sup>[[10]](#references)</sup>
- [InfoStealers](https://infostealers.info/en/info) - Αναζητήστε infostealer logs από μολυσμένες συσκευές και παρακολουθήστε νέα δεδομένα.<sup>[[11]](#references)</sup>
- [Leak-Lookup](https://leak-lookup.com/) - Αναζητήστε σε data breaches και παρακολουθήστε την έκθεση credentials.<sup>[[12]](#references)</sup>
- [Scylla.so](https://scylla.so/) - Community-driven μηχανή αναζήτησης database breaches.
- [Leaked.domains](https://leaked.domains/) - Αναζητήστε leaked credentials και σχετικά records με βάση domain, email, username, password, IP και άλλα κριτήρια.<sup>[[13]](#references)</sup>
- [WhiteIntel](https://whiteintel.io/) - Παρακολουθήστε δραστηριότητα στο dark web, credential leaks, infostealer data και αναφορές σε brands.<sup>[[14]](#references)</sup>
- [PSBDMP](https://psbdmp.ws/) - Πλατφόρμα αναζήτησης και monitoring dumps του Pastebin.

## Εργαλεία για την απαρίθμηση data leaks

- [Leaker](https://github.com/vflame6/leaker) - Passive leak discovery CLI που αναζητά σε πολλαπλές online sources με βάση email, username, domain, keyword ή τηλέφωνο.<sup>[[15]](#references)</sup>
