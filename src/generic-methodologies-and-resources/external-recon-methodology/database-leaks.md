# Database leak

## Data Breach 搜索引擎

- [GreyNoise Visualizer](https://viz.greynoise.io/) - 查询 IP 和 CIDR，并通过 tags、CVE 和 metadata 查询 scanner 活动。<sup>[[1]](#references)</sup>
- [DeHashed](https://www.dehashed.com/) - 根据用户名、电子邮件地址、IP 地址和其他筛选条件搜索暴露数据；同时提供 monitoring 和 API。<sup>[[2]](#references)</sup>
- [Have I Been Pwned?](https://haveibeenpwned.com/) - 检查电子邮件地址是否出现在已知 data breach 或 paste 记录中；同时提供 notifications 和 API。<sup>[[3]](#references)</sup>
- [ScamSearch](https://scamsearch.io/) - 根据头像、电子邮件、用户名、电话号码、crypto 地址或网站搜索已报告的 scammer 记录。<sup>[[4]](#references)</sup>
- [Intelligence X](https://intelx.io/) - 在已索引的数据源中搜索电子邮件地址、域名、URL、IP 和 CIDR 等筛选条件。<sup>[[5]](#references)</sup>
- [SpyCloud](https://spycloud.com/check-your-exposure/) - 检查企业电子邮件或域名是否存在暴露的 credentials、被 infostealer 感染的身份信息和被盗的 session cookies。<sup>[[6]](#references)</sup>
- [WeLeakInfo](https://weleakinfo.io/) - 使用域名、姓名、电子邮件、ID、电话号码、IP、URL 或 hashes 搜索 leaked databases。<sup>[[7]](#references)</sup>
- [BreachDirectory](https://breachdirectory.org/) - 检查你的电子邮件或用户名是否已被 compromise。
- [LeakCheck](https://leakcheck.io/) - 搜索暴露的电子邮件、用户名、电话号码、hash 或域名数据，并 monitoring 新条目。<sup>[[8]](#references)</sup>
- [Findemail.io](https://findemail.io/) - 查找指定公司的电子邮件地址。
- [Library of Leaks](https://search.libraryofleaks.org/) - 搜索 public documents、公司和人员，包括 leak datasets。<sup>[[9]](#references)</sup>
- [LeakRadar](https://leakradar.io/) - 根据电子邮件、域名或原始字符串搜索 leaked credentials，并 monitoring 新的暴露数据。<sup>[[10]](#references)</sup>
- [InfoStealers](https://infostealers.info/en/info) - 搜索来自受感染设备的 infostealer logs，并 monitoring 新数据。<sup>[[11]](#references)</sup>
- [Leak-Lookup](https://leak-lookup.com/) - 跨 data breach 搜索并 monitoring credential exposure。<sup>[[12]](#references)</sup>
- [Scylla.so](https://scylla.so/) - 社区驱动的 database breach 搜索引擎。
- [Leaked.domains](https://leaked.domains/) - 根据域名、电子邮件、用户名、密码、IP 和其他筛选条件搜索 leaked credentials 及相关记录。<sup>[[13]](#references)</sup>
- [WhiteIntel](https://whiteintel.io/) - Monitoring dark web 活动、credential leaks、infostealer 数据和品牌提及。<sup>[[14]](#references)</sup>
- [PSBDMP](https://psbdmp.ws/) - Pastebin dump 搜索和 monitoring 平台。

## Tools to enumerate data leaks

- [Leaker](https://github.com/vflame6/leaker) - Passive leak discovery CLI，可根据电子邮件、用户名、域名、关键词或电话搜索多个在线数据源。<sup>[[15]](#references)</sup>
