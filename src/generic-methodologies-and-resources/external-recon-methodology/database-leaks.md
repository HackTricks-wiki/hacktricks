## Data Breach Search Engines

- [GreyNoise Visualizer](https://viz.greynoise.io/) - Look up IPs and CIDRs, and query scanner activity by tags, CVEs, and metadata.<sup>[[1]](#references)</sup>
- [DeHashed](https://www.dehashed.com/) - Search exposed data by usernames, email addresses, IP addresses, and other selectors; monitoring and an API are also available.<sup>[[2]](#references)</sup>
- [Have I Been Pwned?](https://haveibeenpwned.com/) - Check whether an email address appears in known data breaches or paste records; notifications and an API are also available.<sup>[[3]](#references)</sup>
- [ScamSearch](https://scamsearch.io/) - Search reported scammer records by profile picture, email, username, phone number, crypto address, or website.<sup>[[4]](#references)</sup>
- [Intelligence X](https://intelx.io/) - Search selectors such as email addresses, domains, URLs, IPs, and CIDRs across indexed sources.<sup>[[5]](#references)</sup>
- [SpyCloud](https://spycloud.com/check-your-exposure/) - Check a business email or domain for exposed credentials, infostealer-infected identities, and stolen session cookies.<sup>[[6]](#references)</sup>
- [WeLeakInfo](https://weleakinfo.io/) - Search leaked databases using domains, names, emails, IDs, phones, IPs, URLs, or hashes.<sup>[[7]](#references)</sup>
- [BreachDirectory](https://breachdirectory.org/) - Check if your email or username was compromised.
- [LeakCheck](https://leakcheck.io/) - Search for exposed email, username, phone, hash, or domain data and monitor for new entries.<sup>[[8]](#references)</sup>
- [Findemail.io](https://findemail.io/) - Find email addresses for a given company.
- [Library of Leaks](https://search.libraryofleaks.org/) - Search public documents, companies, and people, including leak datasets.<sup>[[9]](#references)</sup>
- [LeakRadar](https://leakradar.io/) - Search leaked credentials by email, domain, or raw string and monitor for new exposures.<sup>[[10]](#references)</sup>
- [InfoStealers](https://infostealers.info/en/info) - Search infostealer logs from infected devices and monitor new data.<sup>[[11]](#references)</sup>
- [Leak-Lookup](https://leak-lookup.com/) - Search across data breaches and monitor credential exposure.<sup>[[12]](#references)</sup>
- [Scylla.so](https://scylla.so/) - Community-driven database breach search engine.
- [Leaked.domains](https://leaked.domains/) - Search leaked credentials and related records by domain, email, username, password, IP, and other selectors.<sup>[[13]](#references)</sup>
- [WhiteIntel](https://whiteintel.io/) - Monitor dark-web activity, credential leaks, infostealer data, and brand mentions.<sup>[[14]](#references)</sup>
- [PSBDMP](https://psbdmp.ws/) - Pastebin dump search and monitoring platform.

## Tools to enumerate data leaks

- [Leaker](https://github.com/vflame6/leaker) - Passive leak discovery CLI that searches multiple online sources by email, username, domain, keyword, or phone.<sup>[[15]](#references)</sup>
