# Outils et ressources tiers

{{#include ../banners/hacktricks-training.md}}

Cette page rassemble des outils et services tiers ; elle ne constitue pas une méthodologie de test recommandée. Vérifiez l’état de maintenance de chaque projet et utilisez les outils uniquement sur des systèmes que vous êtes autorisé à évaluer ; l’OWASP Web Security Testing Guide fournit un point de départ structuré pour planifier des tests web.<sup>[[1]](#references)</sup>
