# Tools und Ressourcen von Drittanbietern

{{#include ../banners/hacktricks-training.md}}

Diese Seite enthält eine Sammlung von Tools und Diensten von Drittanbietern und ist keine empfohlene Testmethodik. Überprüfe den Wartungsstatus jedes Projekts und verwende Tools nur auf Systemen, zu deren Prüfung du berechtigt bist. Der OWASP Web Security Testing Guide bietet einen strukturierten Ausgangspunkt für die Planung von Webtests.<sup>[[1]](#references)</sup>
