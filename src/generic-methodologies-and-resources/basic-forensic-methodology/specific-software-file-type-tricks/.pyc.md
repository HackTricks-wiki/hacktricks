## Από μεταγλωττισμένο Binary σε .pyc

Από ένα μεταγλωττισμένο **ELF** binary μπορείτε να **λάβετε το .pyc** με:<sup>[[1]](#references)</sup>
```bash
pyi-archive_viewer <binary>
# The list of python modules will be given here:
[(0, 230, 311, 1, 'm', 'struct'),
(230, 1061, 1792, 1, 'm', 'pyimod01_os_path'),
(1291, 4071, 8907, 1, 'm', 'pyimod02_archive'),
(5362, 5609, 13152, 1, 'm', 'pyimod03_importers'),
(10971, 1473, 3468, 1, 'm', 'pyimod04_ctypes'),
(12444, 816, 1372, 1, 's', 'pyiboot01_bootstrap'),
(13260, 696, 1053, 1, 's', 'pyi_rth_pkgutil'),
(13956, 1134, 2075, 1, 's', 'pyi_rth_multiprocessing'),
(15090, 445, 672, 1, 's', 'pyi_rth_inspect'),
(15535, 2514, 4421, 1, 's', 'binary_name'),
...

? X binary_name
to filename? /tmp/binary.pyc
```
Σε ένα μεταγλωττισμένο **python exe binary** μπορείτε να **get the .pyc** εκτελώντας:<sup>[[1]](#references)</sup>
```bash
python pyinstxtractor.py executable.exe
```
## Από .pyc σε κώδικα python

Για τα δεδομένα **.pyc** ("compiled" python), θα πρέπει αρχικά να προσπαθήσετε να **εξαγάγετε** τον **αρχικό** κώδικα **python**:<sup>[[1]](#references)</sup>
```bash
uncompyle6 binary.pyc  > decompiled.py
```
**Βεβαιωθείτε** ότι το binary έχει την **επέκταση** "**.pyc**" (διαφορετικά το uncompyle6 δεν θα λειτουργήσει)

Κατά την εκτέλεση του **uncompyle6**, ενδέχεται να εμφανιστούν τα **ακόλουθα σφάλματα**:

### Σφάλμα: Unknown magic number 227
```bash
/kali/.local/bin/uncompyle6 /tmp/binary.pyc
Unknown magic number 227 in /tmp/binary.pyc
```
Για να το διορθώσετε, πρέπει να **προσθέσετε τον σωστό magic number** στην αρχή του παραγόμενου αρχείου.

Οι **magic numbers διαφέρουν ανάλογα με την έκδοση της Python**. Για να βρείτε τον magic number της **Python 3.8**, πρέπει να **ανοίξετε ένα τερματικό Python 3.8** και να εκτελέσετε:
```
>> import imp
>> imp.get_magic().hex()
'550d0d0a'
```
Ο **magic number** σε αυτήν την περίπτωση για το python3.8 είναι **`0x550d0d0a`** και, για να διορθώσετε αυτό το σφάλμα, θα χρειαστεί να **προσθέσετε** στην **αρχή** του **.pyc file** τα ακόλουθα bytes: `0x0d550a0d000000000000000000000000`

**Μόλις** προσθέσετε αυτό το magic header, το **σφάλμα θα πρέπει να διορθωθεί.**

Έτσι θα εμφανίζεται ένα σωστά προστιθέμενο **.pyc python3.8 magic header**:
```bash
hexdump 'binary.pyc' | head
0000000 0d55 0a0d 0000 0000 0000 0000 0000 0000
0000010 00e3 0000 0000 0000 0000 0000 0000 0000
0000020 0700 0000 4000 0000 7300 0132 0000 0064
0000030 0164 006c 005a 0064 0164 016c 015a 0064
```
### Error: Γενικά σφάλματα κατά το Decompiling

**Άλλα σφάλματα**, όπως: `class 'AssertionError'>; co_code should be one of the types (<class 'str'>, <class 'bytes'>, <class 'list'>, <class 'tuple'>); is type <class 'NoneType'>` μπορεί να εμφανιστούν.

Αυτό πιθανότατα σημαίνει ότι **δεν έχεις προσθέσει σωστά** τον magic number ή ότι δεν έχεις **χρησιμοποιήσει** τον **σωστό magic number**, επομένως **βεβαιώσου ότι χρησιμοποιείς τον σωστό** (ή δοκίμασε έναν νέο).

Έλεγξε την προηγούμενη τεκμηρίωση σφαλμάτων.

## Automatic Tool

Το [**python-exe-unpacker tool**](https://github.com/countercept/python-exe-unpacker) λειτουργεί ως συνδυασμός αρκετών εργαλείων διαθέσιμων από την community, σχεδιασμένων για να βοηθούν researchers στο unpacking και decompiling εκτελέσιμων γραμμένων σε Python, και συγκεκριμένα όσων έχουν δημιουργηθεί με py2exe και pyinstaller. Περιλαμβάνει YARA rules για να εντοπίζει αν ένα εκτελέσιμο βασίζεται σε Python και επιβεβαιώνει το εργαλείο δημιουργίας.<sup>[[4]](#references)</sup>

### ImportError: File name: 'unpacked/malware_3.exe/**pycache**/archive.cpython-35.pyc' doesn't exist

Ένα συνηθισμένο πρόβλημα αφορά ένα incomplete Python bytecode file, το οποίο προκύπτει από τη **διαδικασία unpacking με unpy2exe ή pyinstxtractor** και στη συνέχεια **αποτυγχάνει να αναγνωριστεί από το uncompyle6 λόγω ενός αριθμού έκδοσης Python bytecode που λείπει**. Για την αντιμετώπιση αυτού του προβλήματος, προστέθηκε μια επιλογή prepend, η οποία προσθέτει τον απαραίτητο αριθμό έκδοσης Python bytecode, διευκολύνοντας τη διαδικασία decompiling.<sup>[[4]](#references)</sup>

Παράδειγμα του προβλήματος:
```python
# Error when attempting to decompile without the prepend option
test@test: uncompyle6 unpacked/malware_3.exe/archive.py
Traceback (most recent call last):
...
ImportError: File name: 'unpacked/malware_3.exe/__pycache__/archive.cpython-35.pyc' doesn't exist
```

```python
# Successful decompilation after using the prepend option
test@test:python python_exe_unpack.py -p unpacked/malware_3.exe/archive
[*] On Python 2.7
[+] Magic bytes are already appended.

# Successfully decompiled file
[+] Successfully decompiled.
```
## Ανάλυση python assembly

Αν δεν κατάφερες να εξαγάγεις τον python "original" κώδικα ακολουθώντας τα προηγούμενα βήματα, τότε μπορείς να προσπαθήσεις να **εξαγάγεις** το **assembly** (αλλά **δεν είναι ιδιαίτερα περιγραφικό**, οπότε **προσπάθησε** να εξαγάγεις **ξανά** τον original κώδικα).Στο [εδώ](https://bits.theorem.co/protecting-a-python-codebase/) βρήκα έναν πολύ απλό κώδικα για να κάνεις **disassemble** το δυαδικό _.pyc_ (καλή τύχη στην κατανόηση της ροής του κώδικα).<sup>[[3]](#references)</sup> Αν το _.pyc_ προέρχεται από python2, χρησιμοποίησε python2:

<details>
<summary>Disassemble ένα .pyc</summary>
```python
>>> import dis
>>> import marshal
>>> import struct
>>> import imp
>>>
>>> with open('hello.pyc', 'r') as f:  # Read the binary file
...     magic = f.read(4)
...     timestamp = f.read(4)
...     code = f.read()
...
>>>
>>> # Unpack the structured content and un-marshal the code
>>> magic = struct.unpack('<H', magic[:2])
>>> timestamp = struct.unpack('<I', timestamp)
>>> code = marshal.loads(code)
>>> magic, timestamp, code
((62211,), (1425911959,), <code object <module> at 0x7fd54f90d5b0, file "hello.py", line 1>)
>>>
>>> # Verify if the magic number corresponds with the current python version
>>> struct.unpack('<H', imp.get_magic()[:2]) == magic
True
>>>
>>> # Disassemble the code object
>>> dis.disassemble(code)
1           0 LOAD_CONST               0 (<code object hello_world at 0x7f31b7240eb0, file "hello.py", line 1>)
3 MAKE_FUNCTION            0
6 STORE_NAME               0 (hello_world)
9 LOAD_CONST               1 (None)
12 RETURN_VALUE
>>>
>>> # Also disassemble that const being loaded (our function)
>>> dis.disassemble(code.co_consts[0])
2           0 LOAD_CONST               1 ('Hello  {0}')
3 LOAD_ATTR                0 (format)
6 LOAD_FAST                0 (name)
9 CALL_FUNCTION            1
12 PRINT_ITEM
13 PRINT_NEWLINE
14 LOAD_CONST               0 (None)
17 RETURN_VALUE
```

## PyInstaller raw marshal και Pyarmor v9 static unpack workflow

- **Εξαγωγή embedded marshal blobs**: `pyi-archive_viewer sample.exe` και export raw objects (π.χ. ένα αρχείο με όνομα `vvs`). Το PyInstaller αποθηκεύει bare marshal streams που ξεκινούν με `0xe3` (TYPE_CODE με FLAG_REF) αντί για πλήρη αρχεία `.pyc`. Προσθέστε το σωστό **16-byte `.pyc header** (magic για την έκδοση του embedded interpreter + μηδενισμένα timestamp/size), ώστε οι decompilers να τα αποδέχονται. Για την Python 3.11.5 μπορείτε να πάρετε το magic μέσω `imp.get_magic().hex()` και να το προσαρμόσετε με `dd`/`printf` πριν από το marshal payload.<sup>[[2]](#references)</sup>
- **Decompile με version-aware tools**: `pycdc -c -v 3.11.5 vvs.pyc > vvs.py` ή PyLingual. Αν χρειάζεται μόνο partial code, μπορείτε να διατρέξετε το AST (π.χ. με `ast.NodeVisitor`) για να εξαγάγετε συγκεκριμένα arguments/constants.
- **Ανάλυση του Pyarmor v9 header** για ανάκτηση των crypto parameters: signature `PY<license>` στο `0x00`, Python major/minor στα `0x09/0x0a`, protection type `0x09` όταν είναι ενεργοποιημένο το **BCC** (`0x08` διαφορετικά), ELF start/end offsets στα `0x1c/0x38` και το 12-byte AES-CTR nonce χωρισμένο στα `0x24..0x27` και `0x2c..0x33`. Το ίδιο pattern επαναλαμβάνεται μετά το embedded ELF.
- **Λάβετε υπόψη τα Pyarmor-modified code objects**: το `co_flags` έχει ενεργοποιημένο το bit `0x20000000` και ένα επιπλέον length-prefixed field. Απενεργοποιήστε το CPython `deopt_code()` κατά το parsing, ώστε να αποφύγετε decryption failures.
- **Εντοπισμός encrypted code regions**: το bytecode περιβάλλεται από `LOAD_CONST __pyarmor_enter_*__` … `LOAD_CONST __pyarmor_exit_*__`. Κάντε decrypt το enclosed blob με AES-128-CTR χρησιμοποιώντας το runtime key (π.χ. `273b1b1373cf25e054a61e2cb8a947b8`). Προκύψτε το per-region nonce κάνοντας XOR το payload-specific 12-byte XOR key (από το Pyarmor runtime) με τα 12 bytes στο `__pyarmor_exit_*__` marker. Μετά το decryption, μπορεί επίσης να δείτε `__pyarmor_assert_*__` (encrypted strings) και `__pyarmor_bcc_*__` (compiled dispatch targets).
- **Decrypt των Pyarmor “mixed” strings**: τα constants με πρόθεμα `0x81` είναι AES-128-CTR encrypted (το plaintext χρησιμοποιεί `0x01`). Χρησιμοποιήστε το ίδιο key και το runtime-derived string nonce (π.χ. `692e767673e95c45a1e6876d`) για να ανακτήσετε long string constants.
- **Χειρισμός BCC mode**: το Pyarmor `--enable-bcc` κάνει compile πολλές functions σε companion ELF και αφήνει Python stubs που καλούν `__pyarmor_bcc_*__`. Κάντε map αυτά τα constants σε ELF symbols με εργαλεία όπως το `bcc_info.py` και, στη συνέχεια, κάντε decompile/analyze το ELF στα reported offsets (π.χ. `__pyarmor_bcc_58580__` → `bcc_180` στο offset `0x4e70`).


## Python σε Executable

Για να ξεκινήσουμε, θα σας δείξουμε πώς μπορούν να γίνουν compile τα payloads σε py2exe και PyInstaller.<sup>[[1]](#references)</sup>

### Για τη δημιουργία payload με χρήση του py2exe:

1. Εγκαταστήστε το py2exe package από το [http://www.py2exe.org/](http://www.py2exe.org)
2. Για το payload (σε αυτή την περίπτωση, θα το ονομάσουμε hello.py), χρησιμοποιήστε ένα script όπως αυτό στο Figure 1. Η επιλογή “bundle_files” με την τιμή 1 θα κάνει bundle τα πάντα, συμπεριλαμβανομένου του Python interpreter, σε ένα exe.
3. Μόλις το script είναι έτοιμο, εκτελέστε την εντολή “python setup.py py2exe”. Αυτό θα δημιουργήσει το executable, όπως ακριβώς στο Figure 2.
```python
from distutils.core import setup
import py2exe, sys, os

sys.argv.append('py2exe')

setup(
options = {'py2exe': {'bundle_files': 1}},
#windows = [{'script': "hello.py"}],
console = [{'script': "hello.py"}],
zipfile = None,
)
```

### Για τη δημιουργία ενός payload χρησιμοποιώντας το PyInstaller:

1. Εγκαταστήστε το PyInstaller χρησιμοποιώντας το pip (`pip install pyinstaller`).
2. Μετά από αυτό, θα εκτελέσουμε την εντολή “pyinstaller –onefile hello.py” (υπενθυμίζεται ότι το ‘hello.py’ είναι το payload μας). Αυτό θα πακετάρει τα πάντα σε ένα εκτελέσιμο αρχείο.
