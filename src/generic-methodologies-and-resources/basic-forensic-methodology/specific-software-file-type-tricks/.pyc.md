# Descompilar binários Python compilados (exe, elf) - Recuperar de .pyc


## De binário compilado para .pyc

A partir de um **executável compilado pelo PyInstaller** (incluindo um executável **ELF**), você pode inspecionar e extrair módulos Python incorporados com:<sup>[[6]](#references)</sup>
```bash
pyi-archive_viewer <binary>
# The list of python modules will be given here:
[(0, 230, 311, 1, 'm', 'struct'),
(230, 1061, 1792, 1, 'm', 'pyimod01_os_path'),
(1291, 4071, 8907, 1, 'm', 'pyimod02_archive'),
(5362, 5609, 13152, 1, 'm', 'pyimod03_importers'),
(10971, 1473, 3468, 1, 'm', 'pyimod04_ctypes'),
(12444, 816, 1372, 1, 's', 'pyiboot01_bootstrap'),
(13260, 696, 1053, 1, 's', 'pyi_rth_pkgutil'),
(13956, 1134, 2075, 1, 's', 'pyi_rth_multiprocessing'),
(15090, 445, 672, 1, 's', 'pyi_rth_inspect'),
(15535, 2514, 4421, 1, 's', 'binary_name'),
...

? X binary_name
to filename? /tmp/binary.pyc
```
Para um **executável criado com PyInstaller**, extraia seu bytecode Python incorporado com:<sup>[[1]](#references)</sup>
```bash
python pyinstxtractor.py executable.exe
```
## De .pyc para código Python

Depois de obter um arquivo **.pyc**, tente descompilá-lo de volta para o código-fonte Python com:<sup>[[1]](#references)</sup>
```bash
uncompyle6 binary.pyc  > decompiled.py
```
**Certifique-se** de que o binário tenha a **extensão** "**.pyc**" (caso contrário, o uncompyle6 não funcionará)

Ao executar o **uncompyle6**, você poderá encontrar os **seguintes erros**:

### Erro: Número mágico desconhecido 227
```bash
/kali/.local/bin/uncompyle6 /tmp/binary.pyc
Unknown magic number 227 in /tmp/binary.pyc
```
Para corrigir isso, adicione no início o magic number correspondente à versão do Python que produziu o bytecode.

Os magic numbers variam conforme a versão do Python. Em um terminal **Python 3.8**, execute:
```
>> import imp
>> imp.get_magic().hex()
'550d0d0a'
```
Para Python 3.8, preceda com a sequência de quatro bytes **`55 0d 0d 0a`**, seguida por 12 bytes nulos, para criar o cabeçalho de 16 bytes **.pyc**.<sup>[[7]](#references)</sup>

Tente novamente o **uncompyle6** após adicionar o cabeçalho.<sup>[[1]](#references)</sup>

É assim que ficará um **magic header do .pyc python3.8** adicionado corretamente:
```bash
hexdump 'binary.pyc' | head
0000000 0d55 0a0d 0000 0000 0000 0000 0000 0000
0000010 00e3 0000 0000 0000 0000 0000 0000 0000
0000020 0700 0000 4000 0000 7300 0132 0000 0064
0000030 0164 006c 005a 0064 0164 016c 015a 0064
```
### Erro: Erros genéricos de descompilação

**Outros erros**, como: `class 'AssertionError'>; co_code should be one of the types (<class 'str'>, <class 'bytes'>, <class 'list'>, <class 'tuple'>); is type <class 'NoneType'>`, podem aparecer.

Isso provavelmente significa que você **não adicionou corretamente** o número mágico ou que não **usou** o **número mágico correto**. Portanto, **certifique-se de usar o correto** (ou tente um novo).

Consulte a documentação do erro anterior.

## Ferramenta automática

A [**python-exe-unpacker tool**](https://github.com/countercept/python-exe-unpacker) combina scripts auxiliares para desempacotar e descompilar executáveis Python criados com py2exe ou PyInstaller. Suas regras YARA identificam executáveis Python e distinguem esses packers.<sup>[[5]](#references)</sup>

### ImportError: File name: 'unpacked/malware_3.exe/**pycache**/archive.cpython-35.pyc' doesn't exist

Quando o desempacotamento deixa um arquivo de bytecode sem seus bytes mágicos do Python, use a opção prepend da ferramenta para adicioná-los antes da descompilação.<sup>[[1]](#references)[[5]](#references)</sup>

Exemplo do problema:
```python
# Error when attempting to decompile without the prepend option
test@test: uncompyle6 unpacked/malware_3.exe/archive.py
Traceback (most recent call last):
...
ImportError: File name: 'unpacked/malware_3.exe/__pycache__/archive.cpython-35.pyc' doesn't exist
```

```python
# Successful decompilation after using the prepend option
test@test:python python_exe_unpack.py -p unpacked/malware_3.exe/archive
[*] On Python 2.7
[+] Magic bytes are already appended.

# Successfully decompiled file
[+] Successfully decompiled.
```
## Analisando o assembly do Python

Se a descompilação falhar, desmonte o objeto de código marshaled como alternativa. Use a versão do interpretador que produziu o bytecode (Python 2 para arquivos **.pyc** do Python 2).<sup>[[4]](#references)</sup>

```python

>>> import marshal
>>> import struct
>>> import imp
>>>
>>> with open('hello.pyc', 'rb') as f:  # Read the binary file
...     magic = f.read(4)
...     timestamp = f.read(4)
...     code = f.read()
...
>>>
>>> # Unpack the structured content and un-marshal the code
>>> magic = struct.unpack('<H', magic[:2])
>>> timestamp = struct.unpack('<I', timestamp)

True
```

## Workflow estático de unpack de raw marshal do PyInstaller e Pyarmor v9

O workflow a seguir tem como alvo raw marshal payloads do PyInstaller protegidos com Pyarmor v9.<sup>[[3]](#references)</sup>

- **Extrair blobs marshal incorporados**: `pyi-archive_viewer sample.exe` e exportar os objetos raw (por exemplo, um arquivo chamado `vvs`). O PyInstaller armazena streams marshal puros que começam com `0xe3` (TYPE_CODE com FLAG_REF), em vez de arquivos `.pyc` completos. Prepend o **header `.pyc` de 16 bytes** correto (magic da versão do interpretador incorporado + timestamp/tamanho zerados) para que os decompilers os aceitem. Para Python 3.11.5, você pode obter o magic com `imp.get_magic().hex()` e fazer o patch usando `dd`/`printf` antes do payload marshal.
- **Decompilar com ferramentas compatíveis com a versão**: `pycdc -c -v 3.11.5 vvs.pyc > vvs.py` ou PyLingual. Se apenas parte do código for necessária, você pode percorrer a AST (por exemplo, `ast.NodeVisitor`) para extrair argumentos/constantes específicos.
- **Analisar o header do Pyarmor v9** para recuperar os parâmetros criptográficos: assinatura `PY<license>` em `0x00`, major/minor do Python em `0x09/0x0a`, campo de tipo de proteção em `0x14` (`0x09` com **BCC**, `0x08` caso contrário), offsets de início/fim do ELF em `0x1c/0x38` e o nonce AES-CTR de 12 bytes dividido entre `0x24..0x27` e `0x2c..0x33`. O mesmo padrão se repete após o ELF incorporado.
- **Considerar os code objects modificados pelo Pyarmor**: `co_flags` tem o bit `0x20000000` definido e um campo adicional prefixado por tamanho. Desabilite `deopt_code()` do CPython durante o parsing para evitar falhas de descriptografia.
- **Identificar regiões de código criptografadas**: o bytecode é envolvido por `LOAD_CONST __pyarmor_enter_*__` … `LOAD_CONST __pyarmor_exit_*__`. Descriptografe o blob contido com AES-128-CTR usando a runtime key (por exemplo, `273b1b1373cf25e054a61e2cb8a947b8`). Derive o nonce específico da região fazendo XOR da chave XOR de 12 bytes específica do payload (obtida do Pyarmor runtime) com os 12 bytes do marcador `__pyarmor_exit_*__`. Após a descriptografia, você também poderá encontrar `__pyarmor_assert_*__` (strings criptografadas) e `__pyarmor_bcc_*__` (compiled dispatch targets).
- **Descriptografar strings “mixed” do Pyarmor**: constantes prefixadas com `0x81` são criptografadas com AES-128-CTR (o plaintext usa `0x01`). Use a mesma chave e o nonce de string derivado do runtime (por exemplo, `692e767673e95c45a1e6876d`) para recuperar constantes de string longas.
- **Lidar com o modo BCC**: o Pyarmor `--enable-bcc` compila muitas funções em um ELF companion e deixa stubs Python que chamam `__pyarmor_bcc_*__`. Mapeie essas constantes para símbolos ELF com ferramentas como `bcc_info.py` e, em seguida, faça o decompile/analyze do ELF nos offsets informados (por exemplo, `__pyarmor_bcc_58580__` → `bcc_180` no offset `0x4e70`).<sup>[[2]](#references)[[3]](#references)[[8]](#references)</sup>


## Python para Executable

Estes exemplos mostram como empacotar um script Python com py2exe ou PyInstaller.<sup>[[1]](#references)</sup>

### Para criar um payload usando py2exe:

1. Instale o [py2exe](http://www.py2exe.org/).
2. Crie um payload `hello.py` e use um setup script como o seguinte. Definir `bundle_files` como `1` inclui o interpretador Python no aplicativo.
3. Execute `python setup.py py2exe` para criar o executable.
```python
from distutils.core import setup
import py2exe, sys, os

sys.argv.append('py2exe')

setup(
options = {'py2exe': {'bundle_files': 1}},
#windows = [{'script': "hello.py"}],
console = [{'script': "hello.py"}],
zipfile = None,
)
```
