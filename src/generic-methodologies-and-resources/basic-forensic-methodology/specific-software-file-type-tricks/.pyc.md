# Descompilar binarios de Python compilados (exe, elf) - Recuperar desde .pyc


## De un binario compilado a .pyc

Desde un ejecutable creado con **PyInstaller** (incluido un ejecutable **ELF**), puedes inspeccionar y extraer módulos de Python integrados con:<sup>[[6]](#references)</sup>
```bash
pyi-archive_viewer <binary>
# The list of python modules will be given here:
[(0, 230, 311, 1, 'm', 'struct'),
(230, 1061, 1792, 1, 'm', 'pyimod01_os_path'),
(1291, 4071, 8907, 1, 'm', 'pyimod02_archive'),
(5362, 5609, 13152, 1, 'm', 'pyimod03_importers'),
(10971, 1473, 3468, 1, 'm', 'pyimod04_ctypes'),
(12444, 816, 1372, 1, 's', 'pyiboot01_bootstrap'),
(13260, 696, 1053, 1, 's', 'pyi_rth_pkgutil'),
(13956, 1134, 2075, 1, 's', 'pyi_rth_multiprocessing'),
(15090, 445, 672, 1, 's', 'pyi_rth_inspect'),
(15535, 2514, 4421, 1, 's', 'binary_name'),
...

? X binary_name
to filename? /tmp/binary.pyc
```
Para un **ejecutable creado con PyInstaller**, extrae su bytecode de Python incrustado con:<sup>[[1]](#references)</sup>
```bash
python pyinstxtractor.py executable.exe
```
## De .pyc a código Python

Una vez que tengas un archivo **.pyc**, intenta descompilarlo de nuevo a código fuente de Python con:<sup>[[1]](#references)</sup>
```bash
uncompyle6 binary.pyc  > decompiled.py
```
**Asegúrate** de que el binario tenga la **extensión** "**.pyc**" (si no, uncompyle6 no funcionará)

Al ejecutar **uncompyle6**, podrías encontrar los **siguientes errores**:

### Error: Unknown magic number 227
```bash
/kali/.local/bin/uncompyle6 /tmp/binary.pyc
Unknown magic number 227 in /tmp/binary.pyc
```
Para corregir esto, antepone el número mágico correspondiente a la versión de Python que generó el bytecode.

Los números mágicos varían según la versión de Python. En una terminal de **Python 3.8**, ejecuta:
```
>> import imp
>> imp.get_magic().hex()
'550d0d0a'
```
Para Python 3.8, antepone la secuencia de cuatro bytes **`55 0d 0d 0a`** seguida de 12 bytes cero para crear la cabecera de 16 bytes **.pyc**.<sup>[[7]](#references)</sup>

Vuelve a ejecutar **uncompyle6** después de añadir la cabecera.<sup>[[1]](#references)</sup>

Así se verá una **cabecera magic de python3.8 .pyc** añadida correctamente:
```bash
hexdump 'binary.pyc' | head
0000000 0d55 0a0d 0000 0000 0000 0000 0000 0000
0000010 00e3 0000 0000 0000 0000 0000 0000 0000
0000020 0700 0000 4000 0000 7300 0132 0000 0064
0000030 0164 006c 005a 0064 0164 016c 015a 0064
```
### Error: Errores genéricos de decompilación

Pueden aparecer **otros errores**, como: `class 'AssertionError'>; co_code should be one of the types (<class 'str'>, <class 'bytes'>, <class 'list'>, <class 'tuple'>); is type <class 'NoneType'>`.

Probablemente significa que **no has añadido correctamente** el número mágico o que no has **usado** el **número mágico correcto**, así que asegúrate de **usar el correcto** (o prueba con uno nuevo).

Consulta la documentación del error anterior.

## Herramienta automática

La [**python-exe-unpacker tool**](https://github.com/countercept/python-exe-unpacker) combina scripts auxiliares para desempaquetar y decompilar ejecutables de Python creados con py2exe o PyInstaller. Sus reglas de YARA identifican ejecutables de Python y distinguen esos packers.<sup>[[5]](#references)</sup>

### ImportError: File name: 'unpacked/malware_3.exe/**pycache**/archive.cpython-35.pyc' doesn't exist

Cuando el desempaquetado deja un archivo de bytecode sin sus bytes mágicos de Python, usa la opción prepend de la herramienta para añadirlos antes de decompilar.<sup>[[1]](#references)[[5]](#references)</sup>

Ejemplo del problema:
```python
# Error when attempting to decompile without the prepend option
test@test: uncompyle6 unpacked/malware_3.exe/archive.py
Traceback (most recent call last):
...
ImportError: File name: 'unpacked/malware_3.exe/__pycache__/archive.cpython-35.pyc' doesn't exist
```

```python
# Successful decompilation after using the prepend option
test@test:python python_exe_unpack.py -p unpacked/malware_3.exe/archive
[*] On Python 2.7
[+] Magic bytes are already appended.

# Successfully decompiled file
[+] Successfully decompiled.
```
## Analizar el ensamblado de Python

Si la decompilación falla, desensambla el objeto de código serializado como alternativa. Usa la versión del intérprete que produjo el bytecode (Python 2 para archivos **.pyc** de Python 2).<sup>[[4]](#references)</sup>

>>> import struct

...     magic = f.read(4)

>>> # Unpack the structured content and un-marshal the code

## Flujo de unpacking estático de raw marshal de PyInstaller y Pyarmor v9

El siguiente flujo está dirigido a raw marshal payloads de PyInstaller protegidos con Pyarmor v9.<sup>[[3]](#references)</sup>

- **Extraer los blobs marshal incrustados**: `pyi-archive_viewer sample.exe` y exportar los objetos raw (por ejemplo, un archivo llamado `vvs`). PyInstaller almacena streams marshal sin formato que comienzan con `0xe3` (TYPE_CODE con FLAG_REF) en lugar de archivos `.pyc` completos. Anteponer el **header `.pyc` de 16 bytes** correcto (magic de la versión del intérprete incrustado + timestamp/tamaño puestos a cero) para que los decompilers los acepten. Para Python 3.11.5 puedes obtener el magic mediante `imp.get_magic().hex()` y modificarlo con `dd`/`printf` antes del marshal payload.
- **Decompilar con herramientas conscientes de la versión**: `pycdc -c -v 3.11.5 vvs.pyc > vvs.py` o PyLingual. Si solo necesitas parte del código, puedes recorrer el AST (por ejemplo, `ast.NodeVisitor`) para extraer argumentos/constantes específicos.
- **Analizar el header de Pyarmor v9** para recuperar los parámetros criptográficos: la firma `PY<license>` en `0x00`, la versión major/minor de Python en `0x09/0x0a`, el campo de tipo de protección en `0x14` (`0x09` con **BCC**, `0x08` en caso contrario), los offsets de inicio/final del ELF en `0x1c/0x38`, y el nonce AES-CTR de 12 bytes dividido entre `0x24..0x27` y `0x2c..0x33`. El mismo patrón se repite después del ELF incrustado.
- **Tener en cuenta los code objects modificados por Pyarmor**: `co_flags` tiene establecido el bit `0x20000000` y un campo adicional precedido por su longitud. Deshabilita `deopt_code()` de CPython durante el parsing para evitar fallos de descifrado.
- **Identificar las regiones de código cifradas**: el bytecode está envuelto por `LOAD_CONST __pyarmor_enter_*__` … `LOAD_CONST __pyarmor_exit_*__`. Descifra el blob contenido con AES-128-CTR usando la runtime key (por ejemplo, `273b1b1373cf25e054a61e2cb8a947b8`). Deriva el nonce por región haciendo XOR entre la clave XOR específica del payload de 12 bytes (del runtime de Pyarmor) y los 12 bytes del marcador `__pyarmor_exit_*__`. Después del descifrado, también puedes encontrar `__pyarmor_assert_*__` (strings cifrados) y `__pyarmor_bcc_*__` (compiled dispatch targets).
- **Descifrar los strings “mixed” de Pyarmor**: las constantes con prefijo `0x81` están cifradas con AES-128-CTR (el plaintext usa `0x01`). Utiliza la misma clave y el string nonce derivado del runtime (por ejemplo, `692e767673e95c45a1e6876d`) para recuperar constantes de strings largas.
- **Gestionar el modo BCC**: Pyarmor `--enable-bcc` compila muchas funciones en un ELF complementario y deja stubs de Python que llaman a `__pyarmor_bcc_*__`. Asocia esas constantes con símbolos del ELF usando herramientas como `bcc_info.py`; después, decompila/analiza el ELF en los offsets indicados (por ejemplo, `__pyarmor_bcc_58580__` → `bcc_180` en el offset `0x4e70`).<sup>[[2]](#references)[[3]](#references)[[8]](#references)</sup>


## Python a Executable

Estos ejemplos muestran cómo empaquetar un script de Python con py2exe o PyInstaller.<sup>[[1]](#references)</sup>

### Para crear un payload usando py2exe:

1. Instala [py2exe](http://www.py2exe.org/).
2. Crea un payload `hello.py` y utiliza un setup script como el siguiente. Establecer `bundle_files` en `1` empaqueta el intérprete de Python con la aplicación.
3. Ejecuta `python setup.py py2exe` para crear el ejecutable.
```python
from distutils.core import setup
import py2exe, sys, os

sys.argv.append('py2exe')

setup(
options = {'py2exe': {'bundle_files': 1}},
#windows = [{'script': "hello.py"}],
console = [{'script': "hello.py"}],
zipfile = None,
)
```
