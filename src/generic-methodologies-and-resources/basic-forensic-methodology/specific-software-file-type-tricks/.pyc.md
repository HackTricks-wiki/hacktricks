# Derlenmiş Python ikili dosyalarını (exe, elf) decompile etme - .pyc dosyasından geri alma


## Derlenmiş İkili Dosyadan .pyc Dosyasına

**PyInstaller-built executable** dosyasından (**ELF** executable dosyası dahil), gömülü Python modüllerini şu araçla inceleyebilir ve çıkarabilirsiniz:<sup>[[6]](#references)</sup>
```bash
pyi-archive_viewer <binary>
# The list of python modules will be given here:
[(0, 230, 311, 1, 'm', 'struct'),
(230, 1061, 1792, 1, 'm', 'pyimod01_os_path'),
(1291, 4071, 8907, 1, 'm', 'pyimod02_archive'),
(5362, 5609, 13152, 1, 'm', 'pyimod03_importers'),
(10971, 1473, 3468, 1, 'm', 'pyimod04_ctypes'),
(12444, 816, 1372, 1, 's', 'pyiboot01_bootstrap'),
(13260, 696, 1053, 1, 's', 'pyi_rth_pkgutil'),
(13956, 1134, 2075, 1, 's', 'pyi_rth_multiprocessing'),
(15090, 445, 672, 1, 's', 'pyi_rth_inspect'),
(15535, 2514, 4421, 1, 's', 'binary_name'),
...

? X binary_name
to filename? /tmp/binary.pyc
```
Bir **PyInstaller-built executable** için, gömülü Python bytecode'unu şu komutla çıkarın:<sup>[[1]](#references)</sup>
```bash
python pyinstxtractor.py executable.exe
```
## .pyc'den Python koduna

Bir **.pyc** dosyanız olduğunda, şu araçla Python kaynak koduna geri decompile etmeyi deneyin:<sup>[[1]](#references)</sup>
```bash
uncompyle6 binary.pyc  > decompiled.py
```
**Binary dosyanın** **uzantısının** "**.pyc**" olduğundan emin olun (aksi takdirde uncompyle6 çalışmayacaktır)

**uncompyle6** çalıştırılırken **aşağıdaki hatalarla** karşılaşabilirsiniz:

### Hata: Bilinmeyen magic number 227
```bash
/kali/.local/bin/uncompyle6 /tmp/binary.pyc
Unknown magic number 227 in /tmp/binary.pyc
```
Bunu düzeltmek için bytecode'u oluşturan Python sürümüne ait magic number'ı başa ekleyin.

Magic number'lar Python sürümüne göre değişir. Bir **Python 3.8** terminalinde şunu çalıştırın:
```
>> import imp
>> imp.get_magic().hex()
'550d0d0a'
```
Python 3.8 için, 16 baytlık **.pyc** header'ı oluşturmak üzere dört baytlık **`55 0d 0d 0a`** dizisinin başına 12 sıfır baytı ekleyin.<sup>[[7]](#references)</sup>

Header'ı ekledikten sonra **uncompyle6** komutunu yeniden deneyin.<sup>[[1]](#references)</sup>

Doğru şekilde eklenmiş **.pyc python3.8 magic header** şu şekilde görünecektir:
```bash
hexdump 'binary.pyc' | head
0000000 0d55 0a0d 0000 0000 0000 0000 0000 0000
0000010 00e3 0000 0000 0000 0000 0000 0000 0000
0000020 0700 0000 4000 0000 7300 0132 0000 0064
0000030 0164 006c 005a 0064 0164 016c 015a 0064
```
### Hata: Genel hataların decompile edilmesi

Şu tür **diğer hatalar** da ortaya çıkabilir: `class 'AssertionError'>; co_code should be one of the types (<class 'str'>, <class 'bytes'>, <class 'list'>, <class 'tuple'>); is type <class 'NoneType'>`

Bu muhtemelen magic number'ı **doğru şekilde eklemediğiniz** veya **doğru magic number'ı kullanmadığınız** anlamına gelir; bu nedenle **doğru olanı kullandığınızdan emin olun** (veya yeni bir tane deneyin).

Önceki hata belgelerine bakın.

## Otomatik Araç

[**python-exe-unpacker tool**](https://github.com/countercept/python-exe-unpacker), py2exe veya PyInstaller ile oluşturulmuş Python executable'larını unpacking ve decompile etmek için yardımcı script'leri bir araya getirir. YARA kuralları Python executable'larını tanımlar ve bu packer'ları birbirinden ayırır.<sup>[[5]](#references)</sup>

### ImportError: File name: 'unpacked/malware_3.exe/**pycache**/archive.cpython-35.pyc' doesn't exist

Unpacking işlemi Python magic bytes'ları olmadan bir bytecode dosyası bıraktığında, decompile işleminden önce bunları eklemek için aracın prepend seçeneğini kullanın.<sup>[[1]](#references)[[5]](#references)</sup>

Sorunun örneği:
```python

```

```python

test@test:python python_exe_unpack.py -p unpacked/malware_3.exe/archive
```

## Python assembly'sini analiz etme

Decompilation başarısız olursa, yedek olarak marshaled code object'i disassemble edin. Bytecode'u oluşturan interpreter sürümünü kullanın (Python 2 **.pyc** dosyaları için Python 2).<sup>[[4]](#references)</sup>

<details>
<summary>Bir .pyc dosyasını disassemble etme</summary>
```python
>>> import dis
>>> import marshal
>>> import struct
>>> import imp
>>>
>>> with open('hello.pyc', 'rb') as f:  # Read the binary file
...     magic = f.read(4)
...     timestamp = f.read(4)
...     code = f.read()
...
>>>
>>> # Unpack the structured content and un-marshal the code
>>> magic = struct.unpack('<H', magic[:2])
>>> timestamp = struct.unpack('<I', timestamp)
>>> code = marshal.loads(code)
>>> magic, timestamp, code
((62211,), (1425911959,), <code object <module> at 0x7fd54f90d5b0, file "hello.py", line 1>)
>>>
>>> # Verify if the magic number corresponds with the current python version
>>> struct.unpack('<H', imp.get_magic()[:2]) == magic
True
>>>
>>> # Disassemble the code object
>>> dis.disassemble(code)
1           0 LOAD_CONST               0 (<code object hello_world at 0x7f31b7240eb0, file "hello.py", line 1>)
3 MAKE_FUNCTION            0
6 STORE_NAME               0 (hello_world)
9 LOAD_CONST               1 (None)
12 RETURN_VALUE
>>>
>>> # Also disassemble that const being loaded (our function)
>>> dis.disassemble(code.co_consts[0])
2           0 LOAD_CONST               1 ('Hello  {0}')
3 LOAD_ATTR                0 (format)
6 LOAD_FAST                0 (name)
9 CALL_FUNCTION            1
12 PRINT_ITEM
13 PRINT_NEWLINE
14 LOAD_CONST               0 (None)
17 RETURN_VALUE
```

## PyInstaller raw marshal ve Pyarmor v9 static unpack workflow

Aşağıdaki workflow, Pyarmor v9 ile korunan PyInstaller raw marshal payload'larını hedefler.<sup>[[3]](#references)</sup>

- **Embedded marshal blob'larını extract edin**: `pyi-archive_viewer sample.exe` kullanın ve raw object'leri (ör. `vvs` adlı bir dosya) export edin. PyInstaller, tam `.pyc` dosyaları yerine `0xe3` (`TYPE_CODE` with `FLAG_REF`) ile başlayan bare marshal stream'leri depolar. Decompiler'ların kabul etmesi için doğru **16-byte `.pyc` header**'ını (embedded interpreter version için magic + sıfırlanmış timestamp/size) prepend edin. Python 3.11.5 için magic değerini `imp.get_magic().hex()` ile alabilir ve marshal payload'dan önce `dd`/`printf` kullanarak patch edebilirsiniz.
- **Version-aware tool'larla decompile edin**: `pycdc -c -v 3.11.5 vvs.pyc > vvs.py` veya PyLingual kullanın. Yalnızca kısmi code gerekiyorsa belirli argument/constant'ları almak için AST'yi (ör. `ast.NodeVisitor`) gezebilirsiniz.
- **Pyarmor v9 header'ını parse ederek crypto parameter'larını kurtarın**: `0x00` konumundaki `PY<license>` signature'ı, `0x09/0x0a` konumlarındaki Python major/minor değerlerini, `0x14` konumundaki protection-type field'ını (`**BCC**` ile `0x09`, aksi durumda `0x08`), `0x1c/0x38` konumlarındaki ELF start/end offset'lerini ve `0x24..0x27` ile `0x2c..0x33` aralıklarına bölünmüş 12-byte AES-CTR nonce'u bulun. Aynı pattern embedded ELF'den sonra da tekrarlanır.
- **Pyarmor-modified code object'lerini hesaba katın**: `co_flags` içinde `0x20000000` biti set edilmiştir ve length-prefixed ek bir field bulunur. Decryption failure'larını önlemek için parsing sırasında CPython `deopt_code()` işlevini devre dışı bırakın.
- **Encrypted code region'larını belirleyin**: bytecode, `LOAD_CONST __pyarmor_enter_*__` … `LOAD_CONST __pyarmor_exit_*__` ile sarılır. İçerilen blob'u runtime key'i (ör. `273b1b1373cf25e054a61e2cb8a947b8`) kullanarak AES-128-CTR ile decrypt edin. Her region için nonce'u, payload-specific 12-byte XOR key'i (Pyarmor runtime'dan) `__pyarmor_exit_*__` marker'ındaki 12 byte ile XOR'layarak türetin. Decryption sonrasında `__pyarmor_assert_*__` (encrypted string'ler) ve `__pyarmor_bcc_*__` (compiled dispatch target'ları) da görebilirsiniz.
- **Pyarmor “mixed” string'lerini decrypt edin**: `0x81` ile prefix'lenen constant'lar AES-128-CTR ile encrypted'dır (plaintext `0x01` kullanır). Uzun string constant'ları kurtarmak için aynı key'i ve runtime'dan türetilen string nonce'unu (ör. `692e767673e95c45a1e6876d`) kullanın.
- **BCC mode'u ele alın**: Pyarmor `--enable-bcc`, birçok function'ı companion ELF'e compile eder ve Python stub'larını `__pyarmor_bcc_*__` çağıracak şekilde bırakır. Bu constant'ları `bcc_info.py` gibi tooling ile ELF symbol'lerine map edin, ardından bildirilen offset'lerdeki ELF'i decompile/analyze edin (ör. `__pyarmor_bcc_58580__` → `bcc_180`, `0x4e70` offset'inde).<sup>[[2]](#references)[[3]](#references)[[8]](#references)</sup>


## Python'dan Executable'a

Bu örnekler bir Python script'ini py2exe veya PyInstaller ile nasıl package edeceğinizi gösterir.<sup>[[1]](#references)</sup>

### py2exe kullanarak payload oluşturmak için:

1. [py2exe](http://www.py2exe.org/) kurun.
2. Bir `hello.py` payload'ı oluşturun ve aşağıdaki gibi bir setup script'i kullanın. `bundle_files` değerinin `1` olarak ayarlanması Python interpreter'ını application ile birlikte bundle eder.
3. Executable'ı oluşturmak için `python setup.py py2exe` çalıştırın.
```python
from distutils.core import setup
import py2exe, sys, os

sys.argv.append('py2exe')

setup(
options = {'py2exe': {'bundle_files': 1}},
#windows = [{'script': "hello.py"}],
console = [{'script': "hello.py"}],
zipfile = None,
)
```
