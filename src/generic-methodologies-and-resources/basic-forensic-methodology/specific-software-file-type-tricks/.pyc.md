# Dekompajliranje kompajliranih Python binarnih datoteka (exe, elf) - Preuzimanje iz .pyc


## Od kompajlirane binarne datoteke do .pyc

Iz **PyInstaller-built executable** datoteke (uključujući **ELF** izvršnu datoteku), možete pregledati i izdvojiti ugrađene Python module pomoću:<sup>[[6]](#references)</sup>
```bash
pyi-archive_viewer <binary>
# The list of python modules will be given here:
[(0, 230, 311, 1, 'm', 'struct'),
(230, 1061, 1792, 1, 'm', 'pyimod01_os_path'),
(1291, 4071, 8907, 1, 'm', 'pyimod02_archive'),
(5362, 5609, 13152, 1, 'm', 'pyimod03_importers'),
(10971, 1473, 3468, 1, 'm', 'pyimod04_ctypes'),
(12444, 816, 1372, 1, 's', 'pyiboot01_bootstrap'),
(13260, 696, 1053, 1, 's', 'pyi_rth_pkgutil'),
(13956, 1134, 2075, 1, 's', 'pyi_rth_multiprocessing'),
(15090, 445, 672, 1, 's', 'pyi_rth_inspect'),
(15535, 2514, 4421, 1, 's', 'binary_name'),
...

? X binary_name
to filename? /tmp/binary.pyc
```
Za **izvršnu datoteku izgrađenu pomoću PyInstaller-a**, izdvojite ugrađeni Python bajtkod pomoću:<sup>[[1]](#references)</sup>
```bash
python pyinstxtractor.py executable.exe
```
## Od .pyc do python koda

Kada imate **.pyc** datoteku, pokušajte da je dekompajlirate nazad u Python izvorni kod pomoću:<sup>[[1]](#references)</sup>
```bash
uncompyle6 binary.pyc  > decompiled.py
```
**Uverite se** da binarni fajl ima **ekstenziju** "**.pyc**" (u suprotnom, uncompyle6 neće raditi)

Tokom izvršavanja **uncompyle6** možete naići na **sledeće greške**:

### Greška: Nepoznat magic number 227
```bash
/kali/.local/bin/uncompyle6 /tmp/binary.pyc
Unknown magic number 227 in /tmp/binary.pyc
```
Da biste ovo popravili, dodajte magic number za Python verziju koja je proizvela bytecode na početak.

Magic numbers se razlikuju u zavisnosti od Python verzije. U terminalu **Python 3.8** pokrenite:
```
>> import imp
>> imp.get_magic().hex()
'550d0d0a'
```
Za Python 3.8, dodajte sekvencu od četiri bajta **`55 0d 0d 0a`**, a zatim 12 nultih bajtova, kako biste kreirali zaglavlje od 16 bajtova za **.pyc**.<sup>[[7]](#references)</sup>

Ponovo pokušajte sa **uncompyle6** nakon dodavanja zaglavlja.<sup>[[1]](#references)</sup>

Ovako će izgledati ispravno dodato **.pyc python3.8 magic header**:
```bash
hexdump 'binary.pyc' | head
0000000 0d55 0a0d 0000 0000 0000 0000 0000 0000
0000010 00e3 0000 0000 0000 0000 0000 0000 0000
0000020 0700 0000 4000 0000 7300 0132 0000 0064
0000030 0164 006c 005a 0064 0164 016c 015a 0064
```
### Greška: Decompiling generičkih grešaka

**Druge greške**, poput: `class 'AssertionError'>; co_code should be one of the types (<class 'str'>, <class 'bytes'>, <class 'list'>, <class 'tuple'>); is type <class 'NoneType'>` mogu se pojaviti.

To verovatno znači da **niste ispravno dodali** magic number ili da niste **koristili** **ispravan magic number**, zato se uverite da koristite **ispravan** (ili pokušajte sa novim).

Proverite prethodnu dokumentaciju o greškama.

## Automatski alat

[**python-exe-unpacker tool**](https://github.com/countercept/python-exe-unpacker) kombinuje pomoćne skripte za raspakivanje i decompiling Python izvršnih datoteka kreiranih pomoću py2exe ili PyInstaller. Njegova YARA pravila identifikuju Python izvršne datoteke i razlikuju te packere.<sup>[[5]](#references)</sup>

### ImportError: File name: 'unpacked/malware_3.exe/**pycache**/archive.cpython-35.pyc' doesn't exist

Kada raspakivanje ostavi bytecode datoteku bez njenih Python magic bytes, koristite opciju prepend ovog alata da biste ih dodali pre decompilinga.<sup>[[1]](#references)[[5]](#references)</sup>

Primer problema:

## PyInstaller raw marshal i Pyarmor v9 static unpack workflow

Sledeći workflow cilja PyInstaller raw marshal payloads zaštićene pomoću Pyarmor v9.<sup>[[3]](#references)</sup>

- **Extract embedded marshal blobs**: `pyi-archive_viewer sample.exe` i export raw objekata (npr. fajla pod nazivom `vvs`). PyInstaller skladišti bare marshal streams koji počinju sa `0xe3` (TYPE_CODE sa FLAG_REF), umesto kompletnih `.pyc` fajlova. Dodajte odgovarajuće **16-byte `.pyc` header** (magic za verziju embedded interpreter-a + timestamp/size postavljene na nulu) kako bi ih decompiler-i prihvatili. Za Python 3.11.5 možete preuzeti magic pomoću `imp.get_magic().hex()` i patch-ovati ga pomoću `dd`/`printf` pre marshal payload-a.
- **Decompile with version-aware tools**: `pycdc -c -v 3.11.5 vvs.pyc > vvs.py` ili PyLingual. Ako je potreban samo deo koda, možete proći kroz AST (npr. `ast.NodeVisitor`) kako biste izvukli određene argumente/konstante.
- **Parse the Pyarmor v9 header** da biste povratili crypto parameters: signature `PY<license>` na `0x00`, Python major/minor na `0x09/0x0a`, protection-type field na `0x14` (`0x09` sa **BCC**, `0x08` u suprotnom), ELF start/end offsets na `0x1c/0x38` i 12-byte AES-CTR nonce podeljen između `0x24..0x27` i `0x2c..0x33`. Isti obrazac se ponavlja nakon embedded ELF-a.
- **Account for Pyarmor-modified code objects**: `co_flags` ima postavljen bit `0x20000000` i dodatno length-prefixed polje. Onemogućite CPython `deopt_code()` tokom parsing-a da biste izbegli decryption failures.
- **Identify encrypted code regions**: bytecode je obuhvaćen sa `LOAD_CONST __pyarmor_enter_*__` … `LOAD_CONST __pyarmor_exit_*__`. Decrypt-ujte obuhvaćeni blob pomoću AES-128-CTR i runtime key-ja (npr. `273b1b1373cf25e054a61e2cb8a947b8`). Izvedite per-region nonce XOR-ovanjem payload-specific 12-byte XOR key-ja (iz Pyarmor runtime-a) sa 12 bytes u `__pyarmor_exit_*__` marker-u. Nakon decrypt-ovanja možete takođe videti `__pyarmor_assert_*__` (encrypted strings) i `__pyarmor_bcc_*__` (compiled dispatch targets).
- **Decrypt Pyarmor “mixed” strings**: konstante sa prefiksom `0x81` su AES-128-CTR encrypted (plaintext koristi `0x01`). Koristite isti key i runtime-derived string nonce (npr. `692e767673e95c45a1e6876d`) da biste povratili duge string konstante.
- **Handle BCC mode**: Pyarmor `--enable-bcc` kompajlira mnoge funkcije u companion ELF i ostavlja Python stubs koji pozivaju `__pyarmor_bcc_*__`. Mapirajte te konstante na ELF symbols pomoću alata kao što je `bcc_info.py`, a zatim decompile/analyze-ujte ELF na prijavljenim offset-ima (npr. `__pyarmor_bcc_58580__` → `bcc_180` na offset-u `0x4e70`).<sup>[[2]](#references)[[3]](#references)[[8]](#references)</sup>


## Python to Executable

Ovi primeri pokazuju kako da packaging-ujete Python script pomoću py2exe ili PyInstaller.<sup>[[1]](#references)</sup>

### To create a payload using py2exe:

1. Instalirajte [py2exe](http://www.py2exe.org/).
2. Kreirajte `hello.py` payload i koristite setup script kao što je sledeći. Postavljanje opcije `bundle_files` na `1` bundluje Python interpreter sa aplikacijom.
3. Pokrenite `python setup.py py2exe` da biste kreirali executable.
```python
from distutils.core import setup
import py2exe, sys, os

sys.argv.append('py2exe')

setup(
options = {'py2exe': {'bundle_files': 1}},
#windows = [{'script': "hello.py"}],
console = [{'script': "hello.py"}],
zipfile = None,
)
```

### Za kreiranje payload-a koristeći PyInstaller:

1. Instalirajte PyInstaller: `pip install pyinstaller`.
2. Napravite izvršnu datoteku u jednom fajlu pomoću `pyinstaller --onefile hello.py`.
