## Από Compiled Binary σε .pyc

Από ένα **PyInstaller-built executable** (συμπεριλαμβανομένου ενός **ELF** executable), μπορείτε να επιθεωρήσετε και να εξαγάγετε ενσωματωμένα Python modules με:<sup>[[6]](#references)</sup>
```bash
pyi-archive_viewer <binary>
# The list of python modules will be given here:
[(0, 230, 311, 1, 'm', 'struct'),
(230, 1061, 1792, 1, 'm', 'pyimod01_os_path'),
(1291, 4071, 8907, 1, 'm', 'pyimod02_archive'),
(5362, 5609, 13152, 1, 'm', 'pyimod03_importers'),
(10971, 1473, 3468, 1, 'm', 'pyimod04_ctypes'),
(12444, 816, 1372, 1, 's', 'pyiboot01_bootstrap'),
(13260, 696, 1053, 1, 's', 'pyi_rth_pkgutil'),
(13956, 1134, 2075, 1, 's', 'pyi_rth_multiprocessing'),
(15090, 445, 672, 1, 's', 'pyi_rth_inspect'),
(15535, 2514, 4421, 1, 's', 'binary_name'),
...

? X binary_name
to filename? /tmp/binary.pyc
```
Για ένα **PyInstaller-built executable**, εξαγάγετε το ενσωματωμένο Python bytecode με:<sup>[[1]](#references)</sup>
```bash
python pyinstxtractor.py executable.exe
```
## Από .pyc σε κώδικα Python

Μόλις αποκτήσετε ένα αρχείο **.pyc**, δοκιμάστε να το απομεταγλωττίσετε ξανά σε πηγαίο κώδικα Python με:<sup>[[1]](#references)</sup>
```bash
uncompyle6 binary.pyc  > decompiled.py
```
**Βεβαιωθείτε** ότι το binary έχει την **επέκταση** "**.pyc**" (διαφορετικά, το uncompyle6 δεν πρόκειται να λειτουργήσει)

Κατά την εκτέλεση του **uncompyle6**, ενδέχεται να εμφανιστούν τα **ακόλουθα σφάλματα**:

### Σφάλμα: Άγνωστος magic number 227
```bash
/kali/.local/bin/uncompyle6 /tmp/binary.pyc
Unknown magic number 227 in /tmp/binary.pyc
```
Για να το διορθώσετε, προσθέστε στην αρχή τον magic number για την έκδοση Python που παρήγαγε το bytecode.

Οι magic numbers διαφέρουν ανάλογα με την έκδοση Python. Σε ένα τερματικό **Python 3.8**, εκτελέστε:
```
>> import imp
>> imp.get_magic().hex()
'550d0d0a'
```
Για την Python 3.8, προσθέστε στην αρχή την ακολουθία τεσσάρων byte **`55 0d 0d 0a`**, ακολουθούμενη από 12 byte με τιμή μηδέν, για να δημιουργήσετε την κεφαλίδα **.pyc** των 16 byte.<sup>[[7]](#references)</sup>

Εκτελέστε ξανά το **uncompyle6** μετά την προσθήκη της κεφαλίδας.<sup>[[1]](#references)</sup>

Έτσι θα εμφανίζεται μια σωστά προστιθέμενη **.pyc python3.8 magic header**:
```bash
hexdump 'binary.pyc' | head
0000000 0d55 0a0d 0000 0000 0000 0000 0000 0000
0000010 00e3 0000 0000 0000 0000 0000 0000 0000
0000020 0700 0000 4000 0000 7300 0132 0000 0064
0000030 0164 006c 005a 0064 0164 016c 015a 0064
```
### Σφάλμα: Απομεταγλώττιση γενικών σφαλμάτων

**Άλλα σφάλματα**, όπως: `class 'AssertionError'>; co_code should be one of the types (<class 'str'>, <class 'bytes'>, <class 'list'>, <class 'tuple'>); is type <class 'NoneType'>` μπορεί να εμφανιστούν.

Αυτό πιθανότατα σημαίνει ότι **δεν προσθέσατε σωστά** τον magic number ή ότι δεν **χρησιμοποιήσατε** τον **σωστό magic number**, επομένως βεβαιωθείτε ότι χρησιμοποιείτε τον σωστό (ή δοκιμάστε έναν νέο).

Ελέγξτε την τεκμηρίωση του προηγούμενου σφάλματος.

## Automatic Tool

Το [**python-exe-unpacker tool**](https://github.com/countercept/python-exe-unpacker) συνδυάζει βοηθητικά scripts για unpacking και απομεταγλώττιση Python executables που δημιουργήθηκαν με py2exe ή PyInstaller. Οι κανόνες YARA εντοπίζουν Python executables και διακρίνουν αυτούς τους packers.<sup>[[5]](#references)</sup>

### ImportError: File name: 'unpacked/malware_3.exe/**pycache**/archive.cpython-35.pyc' doesn't exist

Όταν το unpacking αφήνει ένα αρχείο bytecode χωρίς τα Python magic bytes του, χρησιμοποιήστε την επιλογή prepend του tool για να τα προσθέσετε πριν από την απομεταγλώττιση.<sup>[[1]](#references)[[5]](#references)</sup>

Παράδειγμα του προβλήματος:
```python
# Error when attempting to decompile without the prepend option

Traceback (most recent call last):
...
ImportError: File name: 'unpacked/malware_3.exe/__pycache__/archive.cpython-35.pyc' doesn't exist
```

```python
# Successful decompilation after using the prepend option
test@test:python python_exe_unpack.py -p unpacked/malware_3.exe/archive
```

## Ανάλυση python assembly

Αν η αποσυμπίληση αποτύχει, κάντε disassemble το marshaled code object ως εναλλακτική λύση. Χρησιμοποιήστε την έκδοση του interpreter που δημιούργησε το bytecode (Python 2 για αρχεία **.pyc** της Python 2).<sup>[[4]](#references)</sup>

<details>
<summary>Κάντε disassemble ένα .pyc</summary>
```python
>>> import dis
>>> import marshal
>>> import struct
>>> import imp
>>>
>>> with open('hello.pyc', 'rb') as f:  # Read the binary file
...     magic = f.read(4)
...     timestamp = f.read(4)
...     code = f.read()
...
>>>
>>> # Unpack the structured content and un-marshal the code
>>> magic = struct.unpack('<H', magic[:2])
>>> timestamp = struct.unpack('<I', timestamp)
>>> code = marshal.loads(code)
>>> magic, timestamp, code
((62211,), (1425911959,), <code object <module> at 0x7fd54f90d5b0, file "hello.py", line 1>)
>>>
>>> # Verify if the magic number corresponds with the current python version
>>> struct.unpack('<H', imp.get_magic()[:2]) == magic
True
>>>
>>> # Disassemble the code object
>>> dis.disassemble(code)
1           0 LOAD_CONST               0 (<code object hello_world at 0x7f31b7240eb0, file "hello.py", line 1>)
3 MAKE_FUNCTION            0
6 STORE_NAME               0 (hello_world)
9 LOAD_CONST               1 (None)
12 RETURN_VALUE
>>>
>>> # Also disassemble that const being loaded (our function)
>>> dis.disassemble(code.co_consts[0])
2           0 LOAD_CONST               1 ('Hello  {0}')
3 LOAD_ATTR                0 (format)
6 LOAD_FAST                0 (name)
9 CALL_FUNCTION            1
12 PRINT_ITEM
13 PRINT_NEWLINE
14 LOAD_CONST               0 (None)
17 RETURN_VALUE
```
</details>

## PyInstaller raw marshal και Pyarmor v9 static unpack workflow

Το ακόλουθο workflow στοχεύει σε PyInstaller raw marshal payloads που προστατεύονται με Pyarmor v9.<sup>[[3]](#references)</sup>

- **Extract embedded marshal blobs**: `pyi-archive_viewer sample.exe` και export raw objects (π.χ. ένα αρχείο με όνομα `vvs`). Το PyInstaller αποθηκεύει bare marshal streams που ξεκινούν με `0xe3` (TYPE_CODE με FLAG_REF), αντί για πλήρη αρχεία `.pyc`. Πρόσθεσε το σωστό **16-byte `.pyc` header** (magic για την έκδοση του embedded interpreter + μηδενισμένα timestamp/size), ώστε οι decompilers να τα αποδέχονται. Για Python 3.11.5 μπορείς να πάρεις το magic μέσω `imp.get_magic().hex()` και να το κάνεις patch με `dd`/`printf` πριν από το marshal payload.
- **Decompile με version-aware tools**: `pycdc -c -v 3.11.5 vvs.pyc > vvs.py` ή PyLingual. Αν χρειάζεται μόνο partial code, μπορείς να διασχίσεις το AST (π.χ. με `ast.NodeVisitor`) για να εξαγάγεις συγκεκριμένα arguments/constants.
- **Parse το Pyarmor v9 header** για να ανακτήσεις crypto parameters: signature `PY<license>` στο `0x00`, Python major/minor στα `0x09/0x0a`, το protection-type field στο `0x14` (`0x09` με **BCC**, `0x08` διαφορετικά), τα ELF start/end offsets στα `0x1c/0x38` και το 12-byte AES-CTR nonce χωρισμένο στα `0x24..0x27` και `0x2c..0x33`. Το ίδιο pattern επαναλαμβάνεται μετά το embedded ELF.
- **Account για Pyarmor-modified code objects**: το `co_flags` έχει ενεργοποιημένο το bit `0x20000000` και ένα επιπλέον length-prefixed field. Απενεργοποίησε το CPython `deopt_code()` κατά το parsing, ώστε να αποφύγεις decryption failures.
- **Identify encrypted code regions**: το bytecode περικλείεται από `LOAD_CONST __pyarmor_enter_*__` … `LOAD_CONST __pyarmor_exit_*__`. Κάνε decrypt το enclosed blob με AES-128-CTR χρησιμοποιώντας το runtime key (π.χ. `273b1b1373cf25e054a61e2cb8a947b8`). Παράγαγε το per-region nonce κάνοντας XOR το payload-specific 12-byte XOR key (από το Pyarmor runtime) με τα 12 bytes του `__pyarmor_exit_*__` marker. Μετά το decryption, μπορεί επίσης να δεις `__pyarmor_assert_*__` (encrypted strings) και `__pyarmor_bcc_*__` (compiled dispatch targets).
- **Decrypt τα Pyarmor “mixed” strings**: constants με prefix `0x81` είναι AES-128-CTR encrypted (το plaintext χρησιμοποιεί `0x01`). Χρησιμοποίησε το ίδιο key και το runtime-derived string nonce (π.χ. `692e767673e95c45a1e6876d`) για να ανακτήσεις long string constants.
- **Handle BCC mode**: το Pyarmor `--enable-bcc` κάνει compile πολλές functions σε companion ELF και αφήνει Python stubs που καλούν `__pyarmor_bcc_*__`. Κάνε map αυτά τα constants σε ELF symbols με tooling όπως το `bcc_info.py` και στη συνέχεια κάνε decompile/analyze το ELF στα reported offsets (π.χ. `__pyarmor_bcc_58580__` → `bcc_180` στο offset `0x4e70`).<sup>[[2]](#references)[[3]](#references)[[8]](#references)</sup>


## Python σε Executable

Αυτά τα examples δείχνουν πώς να κάνεις package ένα Python script με py2exe ή PyInstaller.<sup>[[1]](#references)</sup>

### Για τη δημιουργία payload με py2exe:

1. Εγκατάστησε το [py2exe](http://www.py2exe.org/).
2. Δημιούργησε ένα `hello.py` payload και χρησιμοποίησε ένα setup script όπως το ακόλουθο. Η ρύθμιση του `bundle_files` σε `1` κάνει bundle τον Python interpreter μαζί με την application.
3. Εκτέλεσε `python setup.py py2exe` για να δημιουργήσεις το executable.
```python
from distutils.core import setup
import py2exe, sys, os

sys.argv.append('py2exe')

setup(
options = {'py2exe': {'bundle_files': 1}},
#windows = [{'script': "hello.py"}],
console = [{'script': "hello.py"}],
zipfile = None,
)
```
