## Từ binary đã biên dịch sang .pyc

Từ một **executable được tạo bằng PyInstaller** (bao gồm cả executable **ELF**), bạn có thể kiểm tra và trích xuất các module Python được nhúng bằng:<sup>[[6]](#references)</sup>

```bash
pyi-archive_viewer <binary>
# The list of python modules will be given here:
[(0, 230, 311, 1, 'm', 'struct'),
 (230, 1061, 1792, 1, 'm', 'pyimod01_os_path'),
 (1291, 4071, 8907, 1, 'm', 'pyimod02_archive'),
 (5362, 5609, 13152, 1, 'm', 'pyimod03_importers'),
 (10971, 1473, 3468, 1, 'm', 'pyimod04_ctypes'),
 (12444, 816, 1372, 1, 's', 'pyiboot01_bootstrap'),
 (13260, 696, 1053, 1, 's', 'pyi_rth_pkgutil'),
 (13956, 1134, 2075, 1, 's', 'pyi_rth_multiprocessing'),
 (15090, 445, 672, 1, 's', 'pyi_rth_inspect'),
 (15535, 2514, 4421, 1, 's', 'binary_name'),
...

? X binary_name
to filename? /tmp/binary.pyc
```

Đối với **tệp thực thi được tạo bằng PyInstaller**, hãy trích xuất bytecode Python được nhúng trong đó bằng:<sup>[[1]](#references)</sup>

```bash
python pyinstxtractor.py executable.exe
```

## Từ .pyc về mã Python

Sau khi có tệp **.pyc**, hãy thử dịch ngược nó thành mã nguồn Python bằng cách sau:<sup>[[1]](#references)</sup>

```bash
uncompyle6 binary.pyc  > decompiled.py
```

**Hãy đảm bảo** binary có **phần mở rộng** "**.pyc**" (nếu không, uncompyle6 sẽ không hoạt động)

### Lỗi: Magic number không xác định 227

```bash
/kali/.local/bin/uncompyle6 /tmp/binary.pyc
Unknown magic number 227 in /tmp/binary.pyc
```

Để khắc phục, hãy thêm magic number của phiên bản Python đã tạo ra bytecode vào đầu tệp.

Magic number thay đổi tùy theo phiên bản Python. Trong terminal **Python 3.8**, hãy chạy:

```
>> import imp
>> imp.get_magic().hex()
'550d0d0a'
```

Với Python 3.8, thêm chuỗi bốn byte **`55 0d 0d 0a`** vào đầu, tiếp theo là 12 byte 0 để tạo header **.pyc** dài 16 byte.<sup>[[7]](#references)</sup>

Thử lại **uncompyle6** sau khi thêm header.<sup>[[1]](#references)</sup>

Đây là cách một **magic header .pyc python3.8** được thêm chính xác sẽ hiển thị:

```bash
hexdump 'binary.pyc' | head
0000000 0d55 0a0d 0000 0000 0000 0000 0000 0000
0000010 00e3 0000 0000 0000 0000 0000 0000 0000
0000020 0700 0000 4000 0000 7300 0132 0000 0064
0000030 0164 006c 005a 0064 0164 016c 015a 0064
```

### Lỗi: Giải mã ngược gặp lỗi chung

**Các lỗi khác** như: `class 'AssertionError'>; co_code should be one of the types (<class 'str'>, <class 'bytes'>, <class 'list'>, <class 'tuple'>); is type <class 'NoneType'>` có thể xuất hiện.

Điều này có thể có nghĩa là bạn **chưa thêm đúng** magic number hoặc chưa **sử dụng** **magic number chính xác**, vì vậy hãy **đảm bảo bạn sử dụng đúng magic number** (hoặc thử một magic number mới).

Xem tài liệu về lỗi trước đó.

## Công cụ tự động

[**python-exe-unpacker tool**](https://github.com/countercept/python-exe-unpacker) kết hợp các script hỗ trợ giải nén và decompile các tệp thực thi Python được tạo bằng py2exe hoặc PyInstaller. Các quy tắc YARA của công cụ này nhận diện tệp thực thi Python và phân biệt các packer đó.<sup>[[5]](#references)</sup>

### ImportError: File name: 'unpacked/malware_3.exe/**pycache**/archive.cpython-35.pyc' doesn't exist

Khi quá trình giải nén tạo ra tệp bytecode không có magic bytes của Python, hãy dùng tùy chọn prepend của công cụ để thêm chúng trước khi decompile.<sup>[[1]](#references)[[5]](#references)</sup>

Ví dụ về lỗi này:

```python
# Error when attempting to decompile without the prepend option
test@test: uncompyle6 unpacked/malware_3.exe/archive.py
Traceback (most recent call last):
...
ImportError: File name: 'unpacked/malware_3.exe/__pycache__/archive.cpython-35.pyc' doesn't exist
```

```python
# Successful decompilation after using the prepend option
test@test:python python_exe_unpack.py -p unpacked/malware_3.exe/archive
[*] On Python 2.7
[+] Magic bytes are already appended.

# Successfully decompiled file
[+] Successfully decompiled.
```

## Phân tích assembly Python

Nếu quá trình dịch ngược thất bại, hãy tháo rời code object đã marshal như một phương án dự phòng. Sử dụng phiên bản interpreter đã tạo ra bytecode (Python 2 đối với các file **.pyc** của Python 2).<sup>[[4]](#references)</sup>

<details>
<summary>Tháo rời một file .pyc</summary>

```python
>>> import dis
>>> import marshal
>>> import struct
>>> import imp
>>>
>>> with open('hello.pyc', 'rb') as f:  # Read the binary file
...     magic = f.read(4)
...     timestamp = f.read(4)
...     code = f.read()
...
>>>
>>> # Unpack the structured content and un-marshal the code
>>> magic = struct.unpack('<H', magic[:2])
>>> timestamp = struct.unpack('<I', timestamp)
>>> code = marshal.loads(code)
>>> magic, timestamp, code
((62211,), (1425911959,), <code object <module> at 0x7fd54f90d5b0, file "hello.py", line 1>)
>>>
>>> # Verify if the magic number corresponds with the current python version
>>> struct.unpack('<H', imp.get_magic()[:2]) == magic
True
>>>
>>> # Disassemble the code object
>>> dis.disassemble(code)
  1           0 LOAD_CONST               0 (<code object hello_world at 0x7f31b7240eb0, file "hello.py", line 1>)
              3 MAKE_FUNCTION            0
              6 STORE_NAME               0 (hello_world)
              9 LOAD_CONST               1 (None)
             12 RETURN_VALUE
>>>
>>> # Also disassemble that const being loaded (our function)
>>> dis.disassemble(code.co_consts[0])
  2           0 LOAD_CONST               1 ('Hello  {0}')
              3 LOAD_ATTR                0 (format)
              6 LOAD_FAST                0 (name)
              9 CALL_FUNCTION            1
             12 PRINT_ITEM
             13 PRINT_NEWLINE
             14 LOAD_CONST               0 (None)
             17 RETURN_VALUE
```

</details>

## Quy trình giải nén tĩnh PyInstaller raw marshal và Pyarmor v9

Quy trình sau đây nhắm đến các raw marshal payload được Pyinstaller bảo vệ bằng Pyarmor v9.<sup>[[3]](#references)</sup>

- **Trích xuất các marshal blob được nhúng**: `pyi-archive_viewer sample.exe` và xuất các object thô (ví dụ: một file có tên `vvs`). PyInstaller lưu các luồng marshal thuần bắt đầu bằng `0xe3` (TYPE_CODE với FLAG_REF), thay vì các file `.pyc` đầy đủ. Thêm vào đầu luồng **header `.pyc` 16 byte** phù hợp (magic của phiên bản interpreter được nhúng + timestamp/size bằng 0) để decompiler chấp nhận. Với Python 3.11.5, bạn có thể lấy magic bằng `imp.get_magic().hex()` và vá nó bằng `dd`/`printf` trước marshal payload.
- **Decompile bằng công cụ nhận biết phiên bản**: `pycdc -c -v 3.11.5 vvs.pyc > vvs.py` hoặc PyLingual. Nếu chỉ cần một phần code, bạn có thể duyệt AST (ví dụ: `ast.NodeVisitor`) để trích xuất các argument/constant cụ thể.
- **Phân tích header Pyarmor v9** để khôi phục các tham số crypto: signature `PY<license>` tại `0x00`, phiên bản Python major/minor tại `0x09/0x0a`, trường protection-type tại `0x14` (`0x09` với **BCC**, `0x08` nếu không), offset bắt đầu/kết thúc ELF tại `0x1c/0x38`, và nonce AES-CTR 12 byte được chia giữa `0x24..0x27` và `0x2c..0x33`. Cùng một cấu trúc lặp lại sau ELF được nhúng.
- **Xử lý các code object bị Pyarmor sửa đổi**: `co_flags` có bit `0x20000000` được đặt và một trường có tiền tố độ dài được thêm vào. Tắt CPython `deopt_code()` trong lúc phân tích để tránh lỗi giải mã.
- **Xác định các vùng code được mã hóa**: bytecode được bao quanh bởi `LOAD_CONST __pyarmor_enter_*__` … `LOAD_CONST __pyarmor_exit_*__`. Giải mã blob bên trong bằng AES-128-CTR với runtime key (ví dụ: `273b1b1373cf25e054a61e2cb8a947b8`). Tạo nonce cho từng vùng bằng cách XOR payload-specific 12-byte XOR key (từ Pyarmor runtime) với 12 byte trong marker `__pyarmor_exit_*__`. Sau khi giải mã, bạn cũng có thể thấy `__pyarmor_assert_*__` (các string được mã hóa) và `__pyarmor_bcc_*__` (các đích dispatch đã biên dịch).
- **Giải mã các string “mixed” của Pyarmor**: các constant có tiền tố `0x81` được mã hóa bằng AES-128-CTR (plaintext dùng `0x01`). Dùng cùng key và string nonce được suy ra từ runtime (ví dụ: `692e767673e95c45a1e6876d`) để khôi phục các string constant dài.
- **Xử lý chế độ BCC**: Pyarmor `--enable-bcc` biên dịch nhiều function sang ELF đi kèm và để lại các Python stub gọi `__pyarmor_bcc_*__`. Ánh xạ các constant này sang ELF symbol bằng công cụ như `bcc_info.py`, sau đó decompile/phân tích ELF tại các offset được báo cáo (ví dụ: `__pyarmor_bcc_58580__` → `bcc_180` tại offset `0x4e70`).<sup>[[2]](#references)[[3]](#references)[[8]](#references)</sup>


## Python sang Executable

Các ví dụ này minh họa cách đóng gói một Python script bằng py2exe hoặc PyInstaller.<sup>[[1]](#references)</sup>

### Tạo payload bằng py2exe:

1. Cài đặt [py2exe](http://www.py2exe.org/).
2. Tạo payload `hello.py` và dùng một setup script như sau. Đặt `bundle_files` thành `1` sẽ đóng gói Python interpreter cùng ứng dụng.
3. Chạy `python setup.py py2exe` để tạo executable.

```python
from distutils.core import setup
import py2exe, sys, os

sys.argv.append('py2exe')

setup(
    options = {'py2exe': {'bundle_files': 1}},
    #windows = [{'script': "hello.py"}],
  console = [{'script': "hello.py"}],
    zipfile = None,
)
```

### Để tạo payload bằng PyInstaller:
