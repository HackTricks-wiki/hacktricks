## Kutoka .pyc hadi msimbo wa python

Kwa data ya **.pyc** ("compiled" python) unapaswa kuanza kujaribu **extract** **original** **python** code:<sup>[[1]](#references)</sup>
```bash
uncompyle6 binary.pyc  > decompiled.py
```
**Hakikisha** kwamba binary ina **extension** "**.pyc**" (ikiwa haina, uncompyle6 haitafanya kazi)

Wakati wa kutekeleza **uncompyle6**, unaweza kupata **hitilafu zifuatazo**:

### Hitilafu: Unknown magic number 227
```bash
/kali/.local/bin/uncompyle6 /tmp/binary.pyc
Unknown magic number 227 in /tmp/binary.pyc
```
Ili kurekebisha hili, unahitaji **kuongeza magic number sahihi** mwanzoni mwa faili lililotengenezwa.

**Magic numbers hutofautiana kulingana na toleo la python**, ili kupata magic number ya **python 3.8** utahitaji **kufungua terminal ya python 3.8** na kutekeleza:
```
>> import imp
>> imp.get_magic().hex()
'550d0d0a'
```
**magic number** katika hali hii kwa python3.8 ni **`0x550d0d0a`**, hivyo, ili kurekebisha kosa hili utahitaji **kuongeza** mwanzoni mwa **.pyc file** bytes zifuatazo: `0x0d550a0d000000000000000000000000`

**Mara** tu unapokuwa **umeongeza** magic header hiyo, **kosa linapaswa kuwa limerekebishwa.**

Hivi ndivyo **.pyc python3.8 magic header** iliyoongezwa kwa usahihi itakavyoonekana:
```bash
hexdump 'binary.pyc' | head
0000000 0d55 0a0d 0000 0000 0000 0000 0000 0000
0000010 00e3 0000 0000 0000 0000 0000 0000 0000
0000020 0700 0000 4000 0000 7300 0132 0000 0064
0000030 0164 006c 005a 0064 0164 016c 015a 0064
```
### Error: Decompiling generic errors

**Other errors** kama vile: `class 'AssertionError'>; co_code should be one of the types (<class 'str'>, <class 'bytes'>, <class 'list'>, <class 'tuple'>); is type <class 'NoneType'>` zinaweza kutokea.

Huenda hii inamaanisha kwamba **hujaongeza kwa usahihi** magic number au kwamba **hukutumia** **magic number sahihi**, kwa hivyo **hakikisha unatumia iliyo sahihi** (au jaribu mpya).

Angalia nyaraka za kosa lililotangulia.

## Automatic Tool

[**python-exe-unpacker tool**](https://github.com/countercept/python-exe-unpacker) hutumika kama mchanganyiko wa tools kadhaa zinazopatikana kwa jamii, zilizoundwa kusaidia watafiti kufanya unpacking na decompiling ya executables zilizoandikwa kwa Python, hasa zilizoundwa kwa kutumia py2exe na pyinstaller. Inajumuisha YARA rules za kutambua ikiwa executable inategemea Python na kuthibitisha tool iliyotumika kuiunda.<sup>[[4]](#references)</sup>

### ImportError: File name: 'unpacked/malware_3.exe/**pycache**/archive.cpython-35.pyc' doesn't exist

Tatizo la kawaida linalokumbana nalo linahusisha faili ya Python bytecode isiyokamilika inayotokana na **unpacking process kwa kutumia unpy2exe au pyinstxtractor**, ambayo baadaye **hushindwa kutambuliwa na uncompyle6 kwa sababu ya kukosekana kwa nambari ya toleo la Python bytecode**. Ili kushughulikia hili, chaguo la prepend limeongezwa, ambalo huambatanisha nambari ya toleo la Python bytecode inayohitajika na kurahisisha mchakato wa decompiling.<sup>[[4]](#references)</sup>

Mfano wa tatizo hilo:
```python
# Error when attempting to decompile without the prepend option
test@test: uncompyle6 unpacked/malware_3.exe/archive.py
Traceback (most recent call last):
...
ImportError: File name: 'unpacked/malware_3.exe/__pycache__/archive.cpython-35.pyc' doesn't exist
```

```python
# Successful decompilation after using the prepend option
test@test:python python_exe_unpack.py -p unpacked/malware_3.exe/archive
[*] On Python 2.7
[+] Magic bytes are already appended.

# Successfully decompiled file
[+] Successfully decompiled.
```
## Kuchanganua assembly ya Python

Ikiwa hukuweza kutoa msimbo wa "asili" wa Python kwa kufuata hatua zilizotangulia, basi unaweza kujaribu **kutoa** **assembly** (lakini **haina maelezo mengi**, kwa hivyo **jaribu** tena kutoa msimbo wa asili). Katika [hapa](https://bits.theorem.co/protecting-a-python-codebase/) nilipata msimbo rahisi sana wa **disassemble** binary ya _.pyc_ (bahati njema kuelewa mtiririko wa msimbo).<sup>[[3]](#references)</sup> Ikiwa _.pyc_ imetoka kwa python2, tumia python2:

<details>
<summary>Disassemble a .pyc</summary>
```python
>>> import dis
>>> import marshal
>>> import struct
>>> import imp
>>>
>>> with open('hello.pyc', 'r') as f:  # Read the binary file
...     magic = f.read(4)
...     timestamp = f.read(4)
...     code = f.read()
...
>>>
>>> # Unpack the structured content and un-marshal the code
>>> magic = struct.unpack('<H', magic[:2])
>>> timestamp = struct.unpack('<I', timestamp)
>>> code = marshal.loads(code)
>>> magic, timestamp, code
((62211,), (1425911959,), <code object <module> at 0x7fd54f90d5b0, file "hello.py", line 1>)
>>>
>>> # Verify if the magic number corresponds with the current python version
>>> struct.unpack('<H', imp.get_magic()[:2]) == magic
True
>>>
>>> # Disassemble the code object
>>> dis.disassemble(code)

>>> # Also disassemble that const being loaded (our function)
```

## PyInstaller raw marshal & Pyarmor v9 static unpack workflow

- **Extract embedded marshal blobs**: Tumia `pyi-archive_viewer sample.exe` na export raw objects (kwa mfano, file yenye jina `vvs`). PyInstaller huhifadhi bare marshal streams zinazoanza na `0xe3` (TYPE_CODE yenye FLAG_REF) badala ya full `.pyc` files. Ongeza **16-byte `.pyc` header** sahihi (magic ya embedded interpreter version + timestamp/size zilizo zerowa) ili decompilers zikubali. Kwa Python 3.11.5 unaweza kupata magic kwa `imp.get_magic().hex()` na kuipatch kwa `dd`/`printf` kabla ya marshal payload.<sup>[[2]](#references)</sup>
- **Decompile with version-aware tools**: Tumia `pycdc -c -v 3.11.5 vvs.pyc > vvs.py` au PyLingual. Ikiwa unahitaji partial code pekee, unaweza kutembea kwenye AST (kwa mfano, `ast.NodeVisitor`) ili kuchukua arguments/constants maalum.
- **Parse the Pyarmor v9 header** ili kurejesha crypto parameters: signature `PY<license>` kwenye `0x00`, Python major/minor kwenye `0x09/0x0a`, protection type `0x09` wakati **BCC** imewezeshwa (`0x08` vinginevyo), ELF start/end offsets kwenye `0x1c/0x38`, na 12-byte AES-CTR nonce iliyogawanywa kati ya `0x24..0x27` na `0x2c..0x33`. Pattern hiyo hiyo hurudiwa baada ya embedded ELF.
- **Account for Pyarmor-modified code objects**: `co_flags` ina bit `0x20000000` iliyowekwa na extra length-prefixed field. Disable CPython `deopt_code()` wakati wa parsing ili kuepuka decryption failures.
- **Identify encrypted code regions**: bytecode imefungwa na `LOAD_CONST __pyarmor_enter_*__` … `LOAD_CONST __pyarmor_exit_*__`. Decrypt enclosed blob kwa AES-128-CTR ukitumia runtime key (kwa mfano, `273b1b1373cf25e054a61e2cb8a947b8`). Derive per-region nonce kwa ku-XOR payload-specific 12-byte XOR key (kutoka Pyarmor runtime) na bytes 12 zilizo kwenye `__pyarmor_exit_*__` marker. Baada ya decryption, unaweza pia kuona `__pyarmor_assert_*__` (encrypted strings) na `__pyarmor_bcc_*__` (compiled dispatch targets).
- **Decrypt Pyarmor “mixed” strings**: constants zenye prefix `0x81` ni AES-128-CTR encrypted (plaintext hutumia `0x01`). Tumia key hiyo hiyo na runtime-derived string nonce (kwa mfano, `692e767673e95c45a1e6876d`) ili kurejesha long string constants.
- **Handle BCC mode**: Pyarmor `--enable-bcc` hukompile functions nyingi kuwa companion ELF na huacha Python stubs zinazomuita `__pyarmor_bcc_*__`. Map constants hizo kwa ELF symbols ukitumia tooling kama `bcc_info.py`, kisha decompile/analyze ELF kwenye offsets zilizoripotiwa (kwa mfano, `__pyarmor_bcc_58580__` → `bcc_180` kwenye offset `0x4e70`).


## Python hadi Executable

Kuanza, tutakuonyesha jinsi payloads zinavyoweza kukompilewa katika py2exe na PyInstaller.<sup>[[1]](#references)</sup>

### Kuunda payload kwa kutumia py2exe:

1. Install py2exe package kutoka [http://www.py2exe.org/](http://www.py2exe.org)
2. Kwa payload (katika hali hii, tutaiita hello.py), tumia script kama ilivyo kwenye Figure 1. Option “bundle_files” yenye value ya 1 ita-bundle kila kitu, ikiwemo Python interpreter, ndani ya exe moja.
3. Script ikiwa tayari, tutatoa command “python setup.py py2exe”. Hii itaunda executable, kama ilivyo kwenye Figure 2.
```python
from distutils.core import setup
import py2exe, sys, os

sys.argv.append('py2exe')

setup(
options = {'py2exe': {'bundle_files': 1}},
#windows = [{'script': "hello.py"}],
console = [{'script': "hello.py"}],
zipfile = None,
)
```
