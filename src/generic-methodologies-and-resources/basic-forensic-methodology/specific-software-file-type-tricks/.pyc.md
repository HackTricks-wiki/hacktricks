## Derlenmiş ikili dosyadan .pyc'ye

Bir **ELF** derlenmiş ikili dosyasından **.pyc** dosyasını şu şekilde elde edebilirsiniz:<sup>[[1]](#references)</sup>
```bash
pyi-archive_viewer <binary>
# The list of python modules will be given here:
[(0, 230, 311, 1, 'm', 'struct'),
(230, 1061, 1792, 1, 'm', 'pyimod01_os_path'),
(1291, 4071, 8907, 1, 'm', 'pyimod02_archive'),
(5362, 5609, 13152, 1, 'm', 'pyimod03_importers'),
(10971, 1473, 3468, 1, 'm', 'pyimod04_ctypes'),
(12444, 816, 1372, 1, 's', 'pyiboot01_bootstrap'),
(13260, 696, 1053, 1, 's', 'pyi_rth_pkgutil'),
(13956, 1134, 2075, 1, 's', 'pyi_rth_multiprocessing'),
(15090, 445, 672, 1, 's', 'pyi_rth_inspect'),
(15535, 2514, 4421, 1, 's', 'binary_name'),
...

? X binary_name
to filename? /tmp/binary.pyc
```
Derlenmiş bir **python exe binary** içinde **.pyc** dosyasını şu komutu çalıştırarak elde edebilirsiniz:<sup>[[1]](#references)</sup>
```bash
python pyinstxtractor.py executable.exe
```
## .pyc'den python koduna

**.pyc** verileri ("derlenmiş" python) için **orijinal** **python** **kodunu** **çıkarmayı** denemeye başlamalısınız:<sup>[[1]](#references)</sup>
```bash
uncompyle6 binary.pyc  > decompiled.py
```
**Emin olun** binary dosyanın **uzantısı** "**.pyc**" olsun (aksi takdirde uncompyle6 çalışmayacaktır)

**uncompyle6** çalıştırılırken **aşağıdaki hatalarla** karşılaşabilirsiniz:

### Hata: Bilinmeyen magic number 227
```bash
/kali/.local/bin/uncompyle6 /tmp/binary.pyc
Unknown magic number 227 in /tmp/binary.pyc
```
Bunu düzeltmek için oluşturulan dosyanın başına **doğru magic number** değerini **eklemeniz** gerekir.

**Magic number değerleri Python sürümüne göre değişir**; **Python 3.8** için magic number değerini almak üzere bir **Python 3.8** terminali açıp şunu çalıştırmanız gerekir:
```
>> import imp
>> imp.get_magic().hex()
'550d0d0a'
```
Bu durumda python3.8 için **magic number** **`0x550d0d0a`** değeridir; bu hatayı düzeltmek için **.pyc file** dosyasının **başına** aşağıdaki byte'ları **eklemeniz** gerekir: `0x0d550a0d000000000000000000000000`

Bu **magic header**'ı **ekledikten sonra** **error** düzeltilmiş olmalıdır.

Doğru şekilde eklenmiş **.pyc python3.8 magic header** şu şekilde görünecektir:
```bash
hexdump 'binary.pyc' | head
0000000 0d55 0a0d 0000 0000 0000 0000 0000 0000
0000010 00e3 0000 0000 0000 0000 0000 0000 0000
0000020 0700 0000 4000 0000 7300 0132 0000 0064
0000030 0164 006c 005a 0064 0164 016c 015a 0064
```
### Hata: Genel decompile hataları

`class 'AssertionError'>; co_code should be one of the types (<class 'str'>, <class 'bytes'>, <class 'list'>, <class 'tuple'>); is type <class 'NoneType'>` gibi **diğer hatalar** da görünebilir.

Bu muhtemelen magic number'ı **doğru şekilde eklemediğiniz** veya **doğru magic number'ı kullanmadığınız** anlamına gelir; bu nedenle **doğru olanı kullandığınızdan emin olun** (veya yeni bir tane deneyin).

Önceki hata belgelerine bakın.

## Otomatik Araç

[**python-exe-unpacker tool**](https://github.com/countercept/python-exe-unpacker), Python ile yazılmış, özellikle py2exe ve pyinstaller kullanılarak oluşturulmuş executable'ları unpacking ve decompiling işleminde araştırmacılara yardımcı olmak üzere tasarlanmış, topluluk tarafından kullanılabilen çeşitli araçların birleşimi olarak görev yapar. Bir executable'ın Python tabanlı olup olmadığını belirlemek ve oluşturma aracını doğrulamak için YARA kurallarını içerir.<sup>[[4]](#references)</sup>

### ImportError: File name: 'unpacked/malware_3.exe/**pycache**/archive.cpython-35.pyc' doesn't exist

Karşılaşılan yaygın bir sorun, **unpy2exe veya pyinstxtractor ile unpacking işlemi** sonucunda Python bytecode dosyasının eksik kalması ve bunun ardından **eksik bir Python bytecode version number nedeniyle uncompyle6 tarafından tanınamamasıdır**. Bunu düzeltmek için, gerekli Python bytecode version number'ı ekleyen ve decompiling sürecini kolaylaştıran bir prepend seçeneği eklenmiştir.<sup>[[4]](#references)</sup>

Soruna örnek:
```python
# Error when attempting to decompile without the prepend option
test@test: uncompyle6 unpacked/malware_3.exe/archive.py
Traceback (most recent call last):
...
ImportError: File name: 'unpacked/malware_3.exe/__pycache__/archive.cpython-35.pyc' doesn't exist
```

```python
# Successful decompilation after using the prepend option
test@test:python python_exe_unpack.py -p unpacked/malware_3.exe/archive
[*] On Python 2.7
[+] Magic bytes are already appended.

# Successfully decompiled file
[+] Successfully decompiled.
```
## Python assembly'sini analiz etme

Önceki adımları izleyerek Python "original" kodunu **extract** edemediyseniz, **assembly**'yi **extract** etmeyi deneyebilirsiniz (ancak **çok açıklayıcı değildir**, bu nedenle original kodu yeniden **extract** etmeyi **deneyin**). [Burada](https://bits.theorem.co/protecting-a-python-codebase/) _.pyc_ binary dosyasını **disassemble** etmek için çok basit bir kod buldum (kod akışını anlamada bol şans).<sup>[[3]](#references)</sup> _.pyc_ Python2'den geliyorsa python2 kullanın:

<details>
<summary>Bir .pyc dosyasını disassemble etme</summary>
```python
>>> import dis
>>> import marshal
>>> import struct
>>> import imp
>>>
>>> with open('hello.pyc', 'r') as f:  # Read the binary file
...     magic = f.read(4)
...     timestamp = f.read(4)
...     code = f.read()
...
>>>
>>> # Unpack the structured content and un-marshal the code
>>> magic = struct.unpack('<H', magic[:2])
>>> timestamp = struct.unpack('<I', timestamp)
>>> code = marshal.loads(code)
>>> magic, timestamp, code
((62211,), (1425911959,), <code object <module> at 0x7fd54f90d5b0, file "hello.py", line 1>)
>>>
>>> # Verify if the magic number corresponds with the current python version
>>> struct.unpack('<H', imp.get_magic()[:2]) == magic
True
>>>
>>> # Disassemble the code object
>>> dis.disassemble(code)

>>>
>>> # Also disassemble that const being loaded (our function)
```

## PyInstaller raw marshal ve Pyarmor v9 static unpack workflow

- **Extract embedded marshal blobs**: `pyi-archive_viewer sample.exe` kullanın ve raw objects öğelerini dışa aktarın (örneğin `vvs` adlı bir dosya). PyInstaller, tam `.pyc` dosyaları yerine `0xe3` (`TYPE_CODE` with `FLAG_REF`) ile başlayan bare marshal streams saklar. Decompiler araçlarının bunları kabul etmesi için doğru **16-byte `.pyc` header** bilgisini ekleyin (embedded interpreter version için magic + sıfırlanmış timestamp/size). Python 3.11.5 için magic bilgisini `imp.get_magic().hex()` ile alabilir ve marshal payload öncesine `dd`/`printf` kullanarak ekleyebilirsiniz.<sup>[[2]](#references)</sup>
- **Decompile with version-aware tools**: `pycdc -c -v 3.11.5 vvs.pyc > vvs.py` veya PyLingual kullanın. Yalnızca kısmi code gerekiyorsa belirli arguments/constants öğelerini almak için AST üzerinde (örneğin `ast.NodeVisitor`) dolaşabilirsiniz.
- **Parse the Pyarmor v9 header** to recover crypto parameters: `0x00` konumundaki `PY<license>` signature, `0x09/0x0a` konumlarındaki Python major/minor sürümü, **BCC** etkin olduğunda `0x09` olan protection type (`aksi durumda `0x08`), `0x1c/0x38` konumlarındaki ELF start/end offsets ve `0x24..0x27` ile `0x2c..0x33` aralıklarına bölünmüş 12-byte AES-CTR nonce. Aynı pattern embedded ELF sonrasında da tekrarlanır.
- **Account for Pyarmor-modified code objects**: `co_flags` içinde `0x20000000` biti set edilmiştir ve length-prefixed ek bir field bulunur. Decryption failures oluşmasını önlemek için parsing sırasında CPython `deopt_code()` işlevini devre dışı bırakın.
- **Identify encrypted code regions**: bytecode, `LOAD_CONST __pyarmor_enter_*__` … `LOAD_CONST __pyarmor_exit_*__` ile sarılır. İçerilen blob'u runtime key kullanarak AES-128-CTR ile decrypt edin (örneğin `273b1b1373cf25e054a61e2cb8a947b8`). Her region için nonce değerini, payload-specific 12-byte XOR key'i (Pyarmor runtime'dan) `__pyarmor_exit_*__` marker'ındaki 12 byte ile XOR'layarak türetin. Decryption sonrasında ayrıca `__pyarmor_assert_*__` (encrypted strings) ve `__pyarmor_bcc_*__` (compiled dispatch targets) görebilirsiniz.
- **Decrypt Pyarmor “mixed” strings**: `0x81` ile başlayan constants, AES-128-CTR ile encrypted durumdadır (plaintext `0x01` kullanır). Uzun string constants öğelerini kurtarmak için aynı key'i ve runtime-derived string nonce'u (örneğin `692e767673e95c45a1e6876d`) kullanın.
- **Handle BCC mode**: Pyarmor `--enable-bcc`, birçok function'ı companion ELF'e compile eder ve Python stubs bırakarak `__pyarmor_bcc_*__` çağrıları yapar. Bu constants öğelerini `bcc_info.py` gibi tooling kullanarak ELF symbols ile eşleyin, ardından bildirilen offsets konumlarındaki ELF'i decompile/analyze edin (örneğin `__pyarmor_bcc_58580__` → `bcc_180`, offset `0x4e70`).

## Python to Executable

Başlangıç olarak payload'ların py2exe ve PyInstaller ile nasıl compile edilebileceğini göstereceğiz.<sup>[[1]](#references)</sup>

### To create a payload using py2exe:

1. [http://www.py2exe.org/](http://www.py2exe.org) adresindeki py2exe package'ını install edin.
2. Payload için (bu örnekte dosya adını hello.py olarak belirleyeceğiz), Figure 1'deki gibi bir script kullanın. Değeri 1 olan “bundle_files” seçeneği, Python interpreter da dahil olmak üzere her şeyi tek bir exe içinde bundle eder.
3. Script hazır olduğunda “python setup.py py2exe” komutunu çalıştırın. Bu işlem, Figure 2'de gösterildiği gibi executable dosyasını oluşturur.
```python
from distutils.core import setup
import py2exe, sys, os

sys.argv.append('py2exe')

setup(
options = {'py2exe': {'bundle_files': 1}},
#windows = [{'script': "hello.py"}],
console = [{'script': "hello.py"}],
zipfile = None,
)
```

### PyInstaller kullanarak bir payload oluşturmak için:

1. PyInstaller'ı pip kullanarak yükleyin (`pip install pyinstaller`).
2. Ardından “pyinstaller –onefile hello.py” komutunu çalıştıracağız (`hello.py` dosyasının payload'ımız olduğunu unutmayın). Bu, her şeyi tek bir executable içinde paketler.
