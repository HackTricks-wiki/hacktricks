## Kutoka .pyc hadi msimbo wa Python

Ukishapata faili la **.pyc**, jaribu kulirudisha kuwa msimbo chanzi wa Python kwa kulifanyia decompile ukitumia:<sup>[[1]](#references)</sup>
```bash
uncompyle6 binary.pyc  > decompiled.py
```
**Hakikisha** kwamba binary ina **extension** "**.pyc**" (ikiwa haina, uncompyle6 haitafanya kazi)

Unapotumia **uncompyle6**, unaweza kukumbana na **errors zifuatazo**:

### Error: Unknown magic number 227
```bash
/kali/.local/bin/uncompyle6 /tmp/binary.pyc
Unknown magic number 227 in /tmp/binary.pyc
```
Ili kurekebisha hili, weka magic number ya toleo la Python lililotengeneza bytecode mwanzoni.

Magic numbers hutofautiana kulingana na toleo la Python. Katika terminal ya **Python 3.8**, endesha:
```
>> import imp
>> imp.get_magic().hex()
'550d0d0a'
```
Kwa Python 3.8, weka mwanzoni mfuatano wa baiti nne **`55 0d 0d 0a`** ukifuatiwa na baiti 12 zenye thamani sifuri ili kuunda header ya **.pyc** yenye baiti 16.<sup>[[7]](#references)</sup>

Jaribu tena **uncompyle6** baada ya kuongeza header.<sup>[[1]](#references)</sup>

Hivi ndivyo **.pyc python3.8 magic header** iliyoongezwa kwa usahihi itakavyoonekana:
```bash
hexdump 'binary.pyc' | head
0000000 0d55 0a0d 0000 0000 0000 0000 0000 0000
0000010 00e3 0000 0000 0000 0000 0000 0000 0000
0000020 0700 0000 4000 0000 7300 0132 0000 0064
0000030 0164 006c 005a 0064 0164 016c 015a 0064
```
### Hitilafu: Hitilafu za jumla za Decompiling

**Hitilafu nyingine** kama: `class 'AssertionError'>; co_code should be one of the types (<class 'str'>, <class 'bytes'>, <class 'list'>, <class 'tuple'>); is type <class 'NoneType'>` zinaweza kutokea.

Huenda hii inamaanisha kwamba **hujaongeza kwa usahihi** magic number au kwamba **hujatumia** **magic number sahihi**, kwa hiyo **hakikisha unatumia sahihi** (au jaribu mpya).

Angalia nyaraka za hitilafu iliyotangulia.

YARA rules zake hutambua Python executables na kutofautisha packers hao.<sup>[[5]](#references)</sup>

## Kuchanganua python assembly

Ikiwa decompilation itashindikana, disassemble code object iliyomarshaliwa kama njia mbadala. Tumia toleo la interpreter lililotengeneza bytecode (Python 2 kwa faili za **.pyc** za Python 2).<sup>[[4]](#references)</sup>

<details>
<summary>Disassemble a .pyc</summary>
```python
>>> import dis
>>> import marshal
>>> import struct
>>> import imp
>>>
>>> with open('hello.pyc', 'rb') as f:  # Read the binary file
...     magic = f.read(4)
...     timestamp = f.read(4)
...     code = f.read()
...
>>>
>>> # Unpack the structured content and un-marshal the code
>>> magic = struct.unpack('<H', magic[:2])
>>> timestamp = struct.unpack('<I', timestamp)
>>> code = marshal.loads(code)
>>> magic, timestamp, code
((62211,), (1425911959,), <code object <module> at 0x7fd54f90d5b0, file "hello.py", line 1>)
>>>
>>> # Verify if the magic number corresponds with the current python version
>>> struct.unpack('<H', imp.get_magic()[:2]) == magic
True
>>>
>>> # Disassemble the code object
>>> dis.disassemble(code)
1           0 LOAD_CONST               0 (<code object hello_world at 0x7f31b7240eb0, file "hello.py", line 1>)
3 MAKE_FUNCTION            0
6 STORE_NAME               0 (hello_world)
9 LOAD_CONST               1 (None)
12 RETURN_VALUE
>>>
>>> # Also disassemble that const being loaded (our function)
>>> dis.disassemble(code.co_consts[0])
2           0 LOAD_CONST               1 ('Hello  {0}')
3 LOAD_ATTR                0 (format)
6 LOAD_FAST                0 (name)
9 CALL_FUNCTION            1
12 PRINT_ITEM
13 PRINT_NEWLINE
14 LOAD_CONST               0 (None)
17 RETURN_VALUE
```
</details>

## PyInstaller raw marshal & Pyarmor v9 static unpack workflow

Workflow ifuatayo inalenga PyInstaller raw marshal payloads zilizolindwa na Pyarmor v9.<sup>[[3]](#references)</sup>

- **Extract embedded marshal blobs**: `pyi-archive_viewer sample.exe` na export raw objects (kwa mfano, file inayoitwa `vvs`). PyInstaller huhifadhi bare marshal streams zinazoanza na `0xe3` (TYPE_CODE yenye FLAG_REF) badala ya full `.pyc` files. Ongeza **16-byte `.pyc` header** sahihi (magic ya embedded interpreter version + timestamp/size zilizowekwa kuwa sifuri) mwanzoni ili decompilers ziweze kuzikubali. Kwa Python 3.11.5, unaweza kupata magic kwa `imp.get_magic().hex()` na kuipatch kwa `dd`/`printf` kabla ya marshal payload.
- **Decompile with version-aware tools**: `pycdc -c -v 3.11.5 vvs.pyc > vvs.py` au PyLingual. Ikiwa unahitaji partial code pekee, unaweza kutembea kwenye AST (kwa mfano, `ast.NodeVisitor`) ili kuchukua arguments/constants mahususi.
- **Parse the Pyarmor v9 header** ili kurejesha crypto parameters: signature `PY<license>` katika `0x00`, Python major/minor katika `0x09/0x0a`, protection-type field katika `0x14` (`0x09` ikiwa na **BCC**, `0x08` vinginevyo), ELF start/end offsets katika `0x1c/0x38`, na 12-byte AES-CTR nonce iliyogawanywa kati ya `0x24..0x27` na `0x2c..0x33`. Pattern hiyo hiyo hurudiwa baada ya embedded ELF.
- **Account for Pyarmor-modified code objects**: `co_flags` ina bit `0x20000000` iliyowekwa na extra length-prefixed field. Disable CPython `deopt_code()` wakati wa parsing ili kuepuka decryption failures.
- **Identify encrypted code regions**: bytecode imefungwa na `LOAD_CONST __pyarmor_enter_*__` … `LOAD_CONST __pyarmor_exit_*__`. Decrypt blob iliyomo ndani kwa AES-128-CTR ukitumia runtime key (kwa mfano, `273b1b1373cf25e054a61e2cb8a947b8`). Derive per-region nonce kwa kufanya XOR ya payload-specific 12-byte XOR key (kutoka kwa Pyarmor runtime) na bytes 12 zilizo katika `__pyarmor_exit_*__` marker. Baada ya decryption, unaweza pia kuona `__pyarmor_assert_*__` (encrypted strings) na `__pyarmor_bcc_*__` (compiled dispatch targets).
- **Decrypt Pyarmor “mixed” strings**: constants zilizo na prefix `0x81` ni AES-128-CTR encrypted (plaintext hutumia `0x01`). Tumia key hiyo hiyo na runtime-derived string nonce (kwa mfano, `692e767673e95c45a1e6876d`) ili kurejesha long string constants.
- **Handle BCC mode**: Pyarmor `--enable-bcc` hukompile functions nyingi kuwa companion ELF na kuacha Python stubs zinazoita `__pyarmor_bcc_*__`. Map constants hizo kwa ELF symbols ukitumia tools kama `bcc_info.py`, kisha decompile/analyze ELF katika offsets zilizoripotiwa (kwa mfano, `__pyarmor_bcc_58580__` → `bcc_180` katika offset `0x4e70`).<sup>[[2]](#references)[[3]](#references)[[8]](#references)</sup>


## Python hadi Executable

Mifano hii inaonyesha jinsi ya kupackage Python script kwa py2exe au PyInstaller.<sup>[[1]](#references)</sup>

### Kuunda payload kwa kutumia py2exe:

1. Install [py2exe](http://www.py2exe.org/).
2. Create `hello.py` payload na utumie setup script kama ilivyo hapa chini. Kuweka `bundle_files` kuwa `1` hubundle Python interpreter pamoja na application.
3. Run `python setup.py py2exe` ili kuunda executable.
```python
from distutils.core import setup
import py2exe, sys, os

sys.argv.append('py2exe')

setup(
options = {'py2exe': {'bundle_files': 1}},
#windows = [{'script': "hello.py"}],
console = [{'script': "hello.py"}],
zipfile = None,
)
```
