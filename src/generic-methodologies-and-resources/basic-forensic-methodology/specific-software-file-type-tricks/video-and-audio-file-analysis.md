# Аналіз відео- та аудіофайлів

**Маніпуляції з аудіо- та відеофайлами** є основою **forensics challenges у CTF**, де для приховування або виявлення секретних повідомлень використовуються **стеганографія** та аналіз метаданих. Такі інструменти, як **[mediainfo](https://mediaarea.net/en/MediaInfo)** і **`exiftool`**, необхідні для перевірки метаданих файлів і визначення типів вмісту.<sup>[[1]](#references)</sup>

Для аудіозавдань **[Audacity](http://www.audacityteam.org/)** є одним із найкращих інструментів для перегляду хвильових форм і аналізу спектрограм, що важливо для виявлення тексту, закодованого в аудіо. **[Sonic Visualiser](http://www.sonicvisualiser.org/)** наполегливо рекомендується для детального аналізу спектрограм. **Audacity** дає змогу маніпулювати аудіо, наприклад сповільнювати або відтворювати треки у зворотному напрямку, щоб виявити приховані повідомлення. **[Sox](http://sox.sourceforge.net/)** — утиліта командного рядка, яка чудово підходить для конвертації та редагування аудіофайлів.<sup>[[1]](#references)</sup>

Маніпуляція **Least Significant Bits (LSB)** є поширеною технікою в аудіо- та відеостеганографії, що використовує блоки фіксованого розміру в медіафайлах для непомітного вбудовування даних. **[Multimon-ng](http://tools.kali.org/wireless-attacks/multimon-ng)** корисний для декодування повідомлень, прихованих у вигляді **DTMF tones** або **коду Морзе**.<sup>[[1]](#references)</sup>

Відеозавдання часто передбачають роботу з контейнерними форматами, які об'єднують аудіо- та відеопотоки. **[FFmpeg](http://ffmpeg.org/)** є основним інструментом для аналізу та обробки таких форматів і здатний демультиплексувати та відтворювати вміст. Для розробників **[ffmpy](http://ffmpy.readthedocs.io/en/latest/examples.html)** інтегрує можливості FFmpeg у Python для розширеної взаємодії за допомогою скриптів.<sup>[[1]](#references)</sup>

Цей набір інструментів підкреслює універсальність, необхідну в CTF challenges, де учасники повинні застосовувати широкий спектр методів аналізу та обробки, щоб виявляти приховані дані в аудіо- та відеофайлах.
