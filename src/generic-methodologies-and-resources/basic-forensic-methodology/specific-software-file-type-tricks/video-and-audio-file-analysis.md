# Аналіз відео- та аудіофайлів

{{#include ../../../banners/hacktricks-training.md}}

**Маніпуляція аудіо- та відеофайлами** є основою **CTF forensic challenges**, де для приховування або виявлення секретних повідомлень використовуються **steganography** та аналіз метаданих. Такі інструменти, як **[mediainfo](https://mediaarea.net/en/MediaInfo)** і **`exiftool`**, необхідні для перевірки метаданих файлів та визначення типів вмісту.<sup>[[1]](#references)</sup>

Для аудіозавдань **[Audacity](http://www.audacityteam.org/)** є одним із найкращих інструментів для перегляду хвильових форм і аналізу спектрограм, що допомагає виявляти текст, закодований в аудіо. Для детального аналізу спектрограм настійно рекомендується **[Sonic Visualiser](http://www.sonicvisualiser.org/)**. **Audacity** дає змогу маніпулювати аудіо, зокрема сповільнювати або відтворювати треки у зворотному напрямку для виявлення прихованих повідомлень. **[Sox](http://sox.sourceforge.net/)**, утиліта командного рядка, чудово підходить для конвертації та редагування аудіофайлів.<sup>[[1]](#references)</sup>

Маніпуляція **Least Significant Bits (LSB)** є поширеною технікою аудіо- та відеостеганографії, яка використовує фрагменти медіафайлів фіксованого розміру для непомітного вбудовування даних. **[Multimon-ng](http://tools.kali.org/wireless-attacks/multimon-ng)** корисний для декодування повідомлень, прихованих у вигляді **DTMF tones** або **Morse code**.<sup>[[1]](#references)</sup>

Відеозавдання часто передбачають роботу з контейнерними форматами, які об'єднують аудіо- та відеопотоки. **[FFmpeg](http://ffmpeg.org/)** є основним інструментом для аналізу та маніпуляції такими форматами, підтримуючи демультиплексування та відтворення вмісту. Для розробників **[ffmpy](http://ffmpy.readthedocs.io/en/latest/examples.html)** інтегрує можливості FFmpeg у Python для розширеної взаємодії за допомогою скриптів.<sup>[[1]](#references)</sup>

Цей набір інструментів підкреслює універсальність, необхідну в CTF challenges, де учасники мають застосовувати широкий спектр методів аналізу та маніпуляції, щоб виявляти приховані дані в аудіо- та відеофайлах.
