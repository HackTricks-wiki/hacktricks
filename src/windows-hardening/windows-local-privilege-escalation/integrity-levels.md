## Επίπεδα ακεραιότητας

Στα Windows Vista και σε νεότερες εκδόσεις, όλα τα προστατευμένα στοιχεία διαθέτουν μια ετικέτα **επιπέδου ακεραιότητας**. Αυτή η ρύθμιση εκχωρεί κυρίως ένα επίπεδο ακεραιότητας "medium" σε αρχεία και κλειδιά registry, εκτός από συγκεκριμένους φακέλους και αρχεία στα οποία ο Internet Explorer 7 μπορεί να κάνει write με επίπεδο ακεραιότητας low. Η προεπιλεγμένη συμπεριφορά είναι οι διεργασίες που ξεκινούν από standard users να έχουν επίπεδο ακεραιότητας medium, ενώ οι υπηρεσίες συνήθως λειτουργούν σε επίπεδο ακεραιότητας system. Μια ετικέτα ακεραιότητας high προστατεύει τον root κατάλογο.

Ένας βασικός κανόνας είναι ότι τα objects δεν μπορούν να τροποποιηθούν από διεργασίες με χαμηλότερο επίπεδο ακεραιότητας από το επίπεδο του object. Τα επίπεδα ακεραιότητας είναι:

- **Untrusted**: Αυτό το επίπεδο προορίζεται για διεργασίες με anonymous logins. Παράδειγμα: Chrome
- **Low**: Χρησιμοποιείται κυρίως για αλληλεπιδράσεις στο internet, ειδικά στο Protected Mode του Internet Explorer, επηρεάζοντας τα associated αρχεία και τις διεργασίες, καθώς και συγκεκριμένους φακέλους όπως το **Temporary Internet Folder**. Οι διεργασίες με επίπεδο ακεραιότητας low αντιμετωπίζουν σημαντικούς περιορισμούς, όπως عدم πρόσβαση write στο registry και περιορισμένη δυνατότητα write στο user profile.
- **Medium**: Το προεπιλεγμένο επίπεδο για τις περισσότερες δραστηριότητες, εκχωρείται σε standard users και objects χωρίς συγκεκριμένα επίπεδα ακεραιότητας. Ακόμη και τα μέλη της ομάδας Administrators λειτουργούν σε αυτό το επίπεδο από προεπιλογή.
- **High**: Προορίζεται για administrators, επιτρέποντάς τους να τροποποιούν objects σε χαμηλότερα επίπεδα ακεραιότητας, συμπεριλαμβανομένων εκείνων που βρίσκονται στο ίδιο το επίπεδο high.
- **System**: Το υψηλότερο operational επίπεδο για τον Windows kernel και τις core services, απρόσιτο ακόμη και στους administrators, διασφαλίζοντας την προστασία ζωτικών λειτουργιών του συστήματος.
- **Installer**: Ένα μοναδικό επίπεδο που βρίσκεται πάνω από όλα τα άλλα, επιτρέποντας σε objects αυτού του επιπέδου να κάνουν uninstall οποιοδήποτε άλλο object.

Μπορείτε να βρείτε το επίπεδο ακεραιότητας μιας διεργασίας χρησιμοποιώντας το **Process Explorer** από το **Sysinternals**, ανοίγοντας τα **properties** της διεργασίας και προβάλλοντας την καρτέλα "**Security**":

### Επίπεδα ακεραιότητας στο File-system

Ένα object μέσα στο file-system μπορεί να απαιτεί ένα **minimum επίπεδο ακεραιότητας** και, αν μια διεργασία δεν διαθέτει αυτό το επίπεδο ακεραιότητας, δεν θα μπορεί να αλληλεπιδράσει με αυτό.\
Για παράδειγμα, ας **δημιουργήσουμε ένα κανονικό αρχείο από μια console standard user και ας ελέγξουμε τα permissions**:
```
echo asd >asd.txt
icacls asd.txt
asd.txt BUILTIN\Administrators:(I)(F)
DESKTOP-IDJHTKP\user:(I)(F)
NT AUTHORITY\SYSTEM:(I)(F)
NT AUTHORITY\INTERACTIVE:(I)(M,DC)
NT AUTHORITY\SERVICE:(I)(M,DC)
NT AUTHORITY\BATCH:(I)(M,DC)
```
Τώρα, ας εκχωρήσουμε ένα ελάχιστο integrity level **High** στο αρχείο. Αυτό **πρέπει να γίνει από μια κονσόλα** που εκτελείται ως **administrator**, καθώς μια **regular κονσόλα** θα εκτελείται σε επίπεδο Medium Integrity και **δεν θα επιτρέπεται** να εκχωρήσει επίπεδο High Integrity σε ένα object:
```
icacls asd.txt /setintegritylevel(oi)(ci) High
processed file: asd.txt
Successfully processed 1 files; Failed processing 0 files

C:\Users\Public>icacls asd.txt
asd.txt BUILTIN\Administrators:(I)(F)
DESKTOP-IDJHTKP\user:(I)(F)
NT AUTHORITY\SYSTEM:(I)(F)
NT AUTHORITY\INTERACTIVE:(I)(M,DC)
NT AUTHORITY\SERVICE:(I)(M,DC)
NT AUTHORITY\BATCH:(I)(M,DC)
Mandatory Label\High Mandatory Level:(NW)
```
Εδώ είναι που τα πράγματα αποκτούν ενδιαφέρον. Μπορείτε να δείτε ότι ο χρήστης `DESKTOP-IDJHTKP\user` έχει **FULL privileges** στο αρχείο (στην πραγματικότητα, αυτός ήταν ο χρήστης που δημιούργησε το αρχείο), ωστόσο, λόγω του ελάχιστου integrity level που έχει υλοποιηθεί, δεν θα μπορεί πλέον να τροποποιήσει το αρχείο, εκτός αν εκτελείται μέσα σε ένα High Integrity Level (σημειώστε ότι θα μπορεί να το διαβάσει):
```
echo 1234 > asd.txt
Access is denied.

del asd.txt
C:\Users\Public\asd.txt
Access is denied.
```
> [!TIP]
> **Επομένως, όταν ένα αρχείο έχει ένα ελάχιστο επίπεδο ακεραιότητας, για να το τροποποιήσετε πρέπει να εκτελείστε τουλάχιστον σε αυτό το επίπεδο ακεραιότητας.**

### Επίπεδα ακεραιότητας σε Binaries

Δημιούργησα ένα αντίγραφο του `cmd.exe` στη διεύθυνση `C:\Windows\System32\cmd-low.exe` και του όρισα **χαμηλό επίπεδο ακεραιότητας από μια κονσόλα administrator:**
```
icacls C:\Windows\System32\cmd-low.exe
C:\Windows\System32\cmd-low.exe NT AUTHORITY\SYSTEM:(I)(F)
BUILTIN\Administrators:(I)(F)
BUILTIN\Users:(I)(RX)
APPLICATION PACKAGE AUTHORITY\ALL APPLICATION PACKAGES:(I)(RX)
APPLICATION PACKAGE AUTHORITY\ALL RESTRICTED APP PACKAGES:(I)(RX)
Mandatory Label\Low Mandatory Level:(NW)
```
Τώρα, όταν εκτελώ το `cmd-low.exe`, θα **εκτελείται υπό χαμηλό επίπεδο ακεραιότητας** αντί για μεσαίο:

![Επίπεδα ακεραιότητας στο σύστημα αρχείων - Επίπεδα ακεραιότητας σε binaries: Τώρα, όταν εκτελώ το cmd-low.exe, θα εκτελείται υπό χαμηλό επίπεδο ακεραιότητας αντί για μεσαίο](<../../images/image (313).png>)

Για τους περίεργους, αν αντιστοιχίσετε υψηλό επίπεδο ακεραιότητας σε ένα binary (`icacls C:\Windows\System32\cmd-high.exe /setintegritylevel high`), δεν θα εκτελεστεί αυτόματα με υψηλό επίπεδο ακεραιότητας (αν το καλέσετε από ένα μεσαίο επίπεδο ακεραιότητας --από προεπιλογή-- θα εκτελεστεί υπό μεσαίο επίπεδο ακεραιότητας).

### Επίπεδα ακεραιότητας σε Processes

Δεν έχουν όλα τα αρχεία και οι φάκελοι ένα ελάχιστο επίπεδο ακεραιότητας, **όμως όλα τα processes εκτελούνται υπό ένα επίπεδο ακεραιότητας**. Και, παρόμοια με ό,τι συνέβη στο σύστημα αρχείων, **αν ένα process θέλει να γράψει μέσα σε ένα άλλο process, πρέπει να έχει τουλάχιστον το ίδιο επίπεδο ακεραιότητας**. Αυτό σημαίνει ότι ένα process με χαμηλό επίπεδο ακεραιότητας δεν μπορεί να ανοίξει ένα handle με πλήρη πρόσβαση σε ένα process με μεσαίο επίπεδο ακεραιότητας.

Λόγω των περιορισμών που αναφέρθηκαν σε αυτήν και στην προηγούμενη ενότητα, από άποψη ασφάλειας, συνιστάται πάντα **να εκτελείτε ένα process στο χαμηλότερο δυνατό επίπεδο ακεραιότητας**.
