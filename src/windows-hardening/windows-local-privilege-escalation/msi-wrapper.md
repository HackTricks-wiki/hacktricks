# MSI Wrapper

{{#include ../../banners/hacktricks-training.md}}

Baixe a versão gratuita do aplicativo em [https://www.exemsi.com/documentation/getting-started/](https://www.exemsi.com/download/), execute-o e faça o wrap do binário "malicious" nele.\
Observe que você pode fazer o wrap de um "**.bat**" se **quiser apenas** **executar** **linhas de comando (em vez de cmd.exe, selecione o arquivo .bat)**
