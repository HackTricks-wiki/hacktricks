# MSI Wrapper

{{#include ../../banners/hacktricks-training.md}}

Κατεβάστε τη δωρεάν έκδοση της εφαρμογής από το [https://www.exemsi.com/documentation/getting-started/](https://www.exemsi.com/download/), εκτελέστε την και κάντε wrap το "malicious" binary σε αυτήν.\
Σημειώστε ότι μπορείτε να κάνετε wrap ένα "**.bat**" αν **θέλετε απλώς** να **εκτελείτε** **γραμμές εντολών (αντί για cmd.exe επιλέξτε το αρχείο .bat)**

(Παρακαλούμε σημειώστε ότι αν προσπαθήσετε να κάνετε pack το δικό σας binary, θα μπορείτε να τροποποιήσετε αυτές τις τιμές)

Από εδώ, απλώς κάντε κλικ στα **κουμπιά next** και στο τελευταίο **κουμπί build**, και το installer/wrapper σας θα δημιουργηθεί.
