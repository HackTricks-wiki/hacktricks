## यह कैसे काम करता है

**RDPexec** का अर्थ Remote Desktop Protocol (RDP) के माध्यम से login करने के बाद remote system पर commands execute करना है। RDP एक remote graphical interface प्रदान करता है और सामान्यतः target host पर authorized account की आवश्यकता होती है।<sup>[[1]](#references)</sup>
