## Fonctionnement

**RDPexec** désigne l’exécution de commandes sur un système distant après s’y être connecté via le Remote Desktop Protocol (RDP). RDP fournit une interface graphique distante et nécessite normalement un compte autorisé sur l’hôte cible.<sup>[[1]](#references)</sup>
