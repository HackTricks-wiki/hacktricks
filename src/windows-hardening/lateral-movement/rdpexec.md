## Funktionsweise

**RDPexec** bezeichnet das Ausführen von Befehlen auf einem Remote-System nach der Anmeldung über das Remote Desktop Protocol (RDP). RDP stellt eine grafische Remote-Oberfläche bereit und erfordert normalerweise ein autorisiertes Konto auf dem Zielhost.<sup>[[1]](#references)</sup>

Hintergrundinformationen zur RDP-Enumeration, -Konfiguration und zu Angriffstechniken finden Sie unter:
