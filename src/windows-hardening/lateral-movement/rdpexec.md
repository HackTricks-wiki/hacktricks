## Cómo funciona

**RDPexec** se refiere a la ejecución de comandos en un sistema remoto después de iniciar sesión mediante Remote Desktop Protocol (RDP). RDP proporciona una interfaz gráfica remota y normalmente requiere una cuenta autorizada en el host de destino.<sup>[[1]](#references)</sup>
