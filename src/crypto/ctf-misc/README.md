# Crypto CTF Misc

{{#include ../../banners/hacktricks-training.md}}

Збірка сторінок, які часто трапляються в crypto challenges, але не вписуються чітко в інші розділи.

## Езотеричні мови

### Technique

Використовуйте це, коли crypto task насправді полягає у виконанні програми esolang, а потім декодуванні її виводу.

Якщо challenge надає код, який не схожий на стандартну мову:

- Визначте esolang (загугліть характерний токен).
- Використайте online interpreter або Docker image.
- Якщо вивід дивний, після виконання перевірте наявність багаторівневого кодування або стиснення.
