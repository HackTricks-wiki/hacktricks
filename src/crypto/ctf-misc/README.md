# Κρυπτογραφία CTF: Διάφορα

{{#include ../../banners/hacktricks-training.md}}

Αυτή η ενότητα συγκεντρώνει τεχνικές που εμφανίζονται σε προκλήσεις κρυπτογραφίας, αλλά δεν εντάσσονται εύκολα στις υπόλοιπες κατηγορίες.

## Εσωτεριστικές γλώσσες

### Τεχνική

Χρησιμοποιήστε αυτή τη ροή εργασίας όταν μια πρόκληση απαιτεί την εκτέλεση ενός προγράμματος σε εσωτεριστική γλώσσα και την αποκωδικοποίηση της εξόδου του.

Αν μια πρόκληση σάς δίνει κώδικα που δεν μοιάζει με συνηθισμένη γλώσσα:

- Αναγνωρίστε τη γλώσσα αναζητώντας ένα χαρακτηριστικό token ή μια ακολουθία εντολών.
- Χρησιμοποιήστε έναν online interpreter ή ένα Docker image.
- Αν η έξοδος είναι παράξενη, αναζητήστε επιπλέον επίπεδα κωδικοποίησης ή συμπίεσης μετά την εκτέλεση.

Ένα χρήσιμο ευρετήριο γλωσσών είναι το wiki Esolang.<sup>[[1]](#references)</sup>
