## Linguaggi esoterici

### Tecnica

Usa questo workflow quando una challenge richiede di eseguire un programma scritto in un linguaggio esoterico e decodificarne l'output.

Se una challenge ti fornisce codice che non sembra scritto in un linguaggio standard:

- Identifica il linguaggio cercando un token distintivo o una sequenza di istruzioni.
- Usa un interprete online o un'immagine Docker.
- Se l'output è strano, cerca eventuali livelli di codifica o compressione applicati dopo l'esecuzione.

Un utile indice di linguaggi è la wiki Esolang.<sup>[[1]](#references)</sup>
