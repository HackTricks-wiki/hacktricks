## Linguagens esotéricas

### Técnica

Use este fluxo de trabalho quando um desafio exigir executar um programa em uma linguagem esotérica e decodificar sua saída.

Se um desafio fornecer código que não se parece com uma linguagem convencional:

- Identifique a linguagem pesquisando um token ou uma sequência de instruções característicos.
- Use um interpretador online ou uma imagem Docker.
- Se a saída for estranha, procure codificação ou compressão em camadas após a execução.

Um índice útil de linguagens é o wiki Esolang.<sup>[[1]](#references)</sup>
