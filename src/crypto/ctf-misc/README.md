## 奇特语言

### 技术

当挑战要求运行奇特语言程序并解码其输出时，可使用以下流程。

如果挑战给出的代码看起来不像常见语言：

- 搜索具有辨识度的标记或指令序列，以识别该语言。
- 使用在线解释器或 Docker 镜像。
- 如果输出看起来很奇怪，请检查执行后是否还经过分层编码或压缩。

Esolang wiki 是一个实用的语言索引。<sup>[[1]](#references)</sup>
