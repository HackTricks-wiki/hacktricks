## Esoteric languages

### 技术

当 crypto 任务实际上是：运行一个 esolang 程序，然后解码其输出时，使用此方法。

如果挑战给出的代码看起来不像标准语言：

- 识别该 esolang（Google 一个具有独特特征的 token）。
- 使用在线解释器或 Docker image。
- 如果输出内容很奇怪，请在执行后查找分层编码或压缩。
