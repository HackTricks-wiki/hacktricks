## Езотеричні мови

### Техніка

Скористайтеся цим алгоритмом, якщо завдання вимагає запустити програму езотеричною мовою та декодувати її вивід.

Якщо в завданні наведено код, який не схожий на код стандартною мовою:

- Визначте мову за характерним токеном або послідовністю інструкцій.
- Скористайтеся онлайн-інтерпретатором або Docker-образом.
- Якщо вивід дивний, перевірте, чи не застосовано після виконання багатошарове кодування або стиснення.
