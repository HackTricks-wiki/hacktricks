# Διάφορα Crypto CTF

Αυτή η ενότητα συγκεντρώνει τεχνικές που εμφανίζονται σε προκλήσεις κρυπτογραφίας, αλλά δεν εντάσσονται εύκολα στις υπόλοιπες κατηγορίες.

## Εσωτερικές γλώσσες

### Τεχνική

Χρησιμοποιήστε αυτή τη ροή εργασίας όταν μια πρόκληση απαιτεί την εκτέλεση ενός προγράμματος σε εσωτερική γλώσσα και την αποκωδικοποίηση της εξόδου του.

Αν μια πρόκληση σάς δίνει κώδικα που δεν μοιάζει με κώδικα κάποιας συνηθισμένης γλώσσας:

- Αναγνωρίστε τη γλώσσα αναζητώντας ένα χαρακτηριστικό token ή μια ακολουθία εντολών.
- Χρησιμοποιήστε έναν online interpreter ή ένα Docker image.
- Αν η έξοδος είναι περίεργη, αναζητήστε πρόσθετα επίπεδα κωδικοποίησης ή συμπίεσης μετά την εκτέλεση.

Ένας χρήσιμος κατάλογος γλωσσών είναι το Esolang wiki.<sup>[[1]](#references)</sup> Για συνηθισμένα επίπεδα κωδικοποίησης και συμπίεσης, χρησιμοποιήστε τη [ροή εργασιών Crypto CTF](../ctf-workflow/). Αν το στοιχείο υποδεικνύει αόρατο κείμενο και όχι εκτελέσιμη σύνταξη, δείτε τη [στεγανογραφία κειμένου](../../stego/text/).

### Εξαγωγή προφορτωμένης κατάστασης interpreter

Αν μια πρόκληση δέχεται κώδικα σε εσωτερική γλώσσα και τον εκτελεί σε έναν **custom interpreter**, εξετάστε την αρχική του μνήμη, το stack και τις εντολές εξόδου προτού αντιμετωπίσετε τον κώδικα ως γρίφο αποκωδικοποίησης. Όταν ο interpreter προφορτώνει ένα μυστικό σε ένα Befunge stack, ένα σύντομο πρόγραμμα μπορεί να αφαιρέσει από το stack και να εκτυπώσει τα υπάρχοντα bytes χωρίς να χρειάζεται να τα υπολογίσει. Αυτό απαιτεί έλεγχο του κώδικα που εκτελείται και ένα opcode εξόδου· δεν λειτουργεί σε έναν κανονικό, κενό interpreter. Σε μια πρόκληση Befunge, η παρακάτω είσοδος εξέπεμπε επανειλημμένα χαρακτήρες από ένα flag που είχε προφορτωθεί στο stack με την αντίστροφη σειρά.<sup>[[2]](#references)[[3]](#references)</sup>

```befunge
>,<
```

`>` ξεκινά την εκτέλεση προς τα δεξιά, το `,` αφαιρεί ένα στοιχείο και εκτυπώνει έναν χαρακτήρα, ενώ το `<` στέλνει τον δείκτη εντολών πίσω στο `,`. Ελέγξτε τη συμπεριφορά του custom interpreter σε περίπτωση υποχείλισης και ως προς το όριο εντολών: η αναφερόμενη υλοποίηση σταματά όταν εξαντληθεί η στοίβα ή μετά από 1.024 εντολές. Αν το μυστικό δεν βρίσκεται απευθείας στη στοίβα, εξετάστε άλλες αρχικοποιημένες καταστάσεις και διαθέσιμες εντολές εξόδου/ανάγνωσης αντί να υποθέσετε τυπική σημασιολογία Befunge.<sup>[[3]](#references)[[4]](#references)</sup>
