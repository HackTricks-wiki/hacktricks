## Езотеричні мови

### Техніка

Використовуйте цей алгоритм, коли завдання потребує запуску програми езотеричною мовою та декодування її виводу.

Якщо в завданні надано код, який не схожий на код стандартною мовою:

- Визначте мову, виконавши пошук за характерним токеном або послідовністю інструкцій.
- Використайте онлайн-інтерпретатор або Docker image.
- Якщо вивід має дивний вигляд, після виконання перевірте наявність багаторівневого кодування або стиснення.
