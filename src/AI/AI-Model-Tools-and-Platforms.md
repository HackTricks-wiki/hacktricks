## Запуск і навчання моделей локально

### [**Hugging Face Transformers**](https://github.com/huggingface/transformers)

Hugging Face Transformers — це бібліотека з відкритим кодом для завантаження, навчання та обслуговування попередньо навчених моделей для роботи з текстом, зображеннями, аудіо, відео та мультимодальними задачами. Моделі й набори даних розміщуються окремо на Hugging Face Hub.<sup>[[1]](#references)</sup>

### [**LangChain**](https://github.com/langchain-ai/langchain)

LangChain — це фреймворк для створення застосунків і агентів на основі моделей, що підтримує формування промптів, керування історією розмов і станом, інструменти, пошук і отримання даних, а також інтеграції з моделями, API та базами даних.<sup>[[2]](#references)</sup>

#### Перевірка відновлення серіалізованих об’єктів LangChain

Якщо застосунок приймає **структуровані** дані користувача або вивід моделі, перевірте, чи зберігаються вкладені словники в `metadata`, `additional_kwargs`, `response_metadata`, збереженій історії чату або потоці виконання. LangChain використовує словники з тегом `lc` як серіалізовані об’єкти. У вразливих циклах перетворення `dumps()`/`dumpd()` → `load()`/`loads()` словник, контрольований зловмисником, може бути відновлений як об’єкт фреймворку замість того, щоб залишитися даними. Безпосереднє завантаження недовіреного маніфесту також небезпечне; звичайний рядок, який ніколи не розбирається як словник, не відповідає цій передумові.<sup>[[10]](#references)[[11]](#references)</sup>

Для авторизованого тестування надішліть безпечний canary, сформований як конструктор, **у вигляді вкладеного JSON-об’єкта**, а не рядка, і перевірте, чи містить подальша історія або потік об’єкт `AIMessage`, а не початковий словник:<sup>[[11]](#references)</sup>

```json
{"lc":1,"type":"constructor","id":["langchain_core","messages","ai","AIMessage"],"kwargs":{"content":"serialization-canary"}}
```

Перевірте `RunnableWithMessageHistory`, `astream_log()` і `astream_events(version="v1")` під час фактичного використання. Успішне відновлення об’єкта може отруїти подальшу історію чату; ширші списки дозволених об’єктів можуть створювати інші довірені класи, конструктори яких мають побічні ефекти. Не прирівнюйте це до необмеженого виконання pickle. Початкову ваду обходу виправлено в `langchain-core` 0.3.81/1.2.5, а пізніше виправлення широкого списку дозволених об’єктів і маркера секретів увійшло до версій 0.3.85/1.3.3. Для недовірених маніфестів використовуйте актуальну версію та обмежте `allowed_objects` класами повідомлень або явним безпечним списком, встановивши `secrets_from_env=False`.<sup>[[10]](#references)[[11]](#references)[[12]](#references)</sup> Для [мапування меж довіри агента](AI-Agent-Security-Methodology.md) відрізняйте це від [RCE під час завантаження файлу моделі](AI-Models-RCE.md).

### [**LitGPT**](https://github.com/Lightning-AI/litgpt)

LitGPT надає зрозумілі реалізації та робочі процеси командного рядка для попереднього навчання, донавчання, оцінювання та розгортання підтримуваних мовних моделей.<sup>[[3]](#references)</sup>

### [**LitServe**](https://github.com/Lightning-AI/LitServe)

**Опис:**\
LitServe — це фреймворк для обслуговування моделей від Lightning AI, призначений для надання API інференсу з пакетною обробкою, потоковою передачею, прискоренням і масштабуванням.<sup>[[4]](#references)</sup>

### [**Axolotl**](https://github.com/axolotl-ai-cloud/axolotl)

Axolotl — це фреймворк із відкритим кодом для постнавчання та донавчання, керований конфігурацією YAML. Він підтримує такі методи, як повне донавчання, LoRA/QLoRA, оптимізація переваг і навчання на кількох GPU; сам по собі це не платформа для хмарного розгортання.<sup>[[5]](#references)</sup>

## Спробуйте моделі онлайн

### [**Hugging Face**](https://huggingface.co/)

**Hugging Face** — провідна платформа та спільнота у сфері машинного навчання, відома насамперед своєю роботою в галузі обробки природної мови (NLP). Вона надає інструменти, бібліотеки та ресурси, що спрощують розробку, поширення та розгортання моделей машинного навчання.\
Hub містить кілька відповідних розділів:<sup>[[6]](#references)</sup>

* **Models**: Великий репозиторій **попередньо навчених моделей машинного навчання**, у якому користувачі можуть переглядати, завантажувати й інтегрувати моделі для різних завдань, як-от генерування тексту, переклад, розпізнавання зображень тощо.
* **Datasets:** Велика **колекція наборів даних**, які використовують для навчання й оцінювання моделей. Вона забезпечує легкий доступ до різноманітних джерел даних, допомагаючи користувачам знаходити й використовувати дані для власних проєктів машинного навчання.
* **Spaces:** Платформа для розміщення та поширення **інтерактивних застосунків і демонстрацій машинного навчання**. Вона дає змогу розробникам **демонструвати** роботу своїх моделей, створювати зручні інтерфейси та співпрацювати з іншими, поширюючи інтерактивні демонстрації.

#### Перевірка загальнодоступних журналів виконання Space

Код репозиторію загальнодоступного Space може показати, які вхідні дані й змінні середовища журналює його застосунок. Під час авторизованої оцінки перевірте потік журналу **run** як окрему поверхню, відмінну від інтерфейсу застосунку. Hugging Face документує кінцеву точку SSE для журналів Space; дослідження показало, що інші користувачі Hub могли читати журнали загальнодоступних Space, у яких іноді містилися API-ключі, запити користувачів або токен доступу Dev Mode, записаний у URL запиту. Токен у журналі становить загрозу лише тоді, коли відповідний привілейований режим іще ввімкнений, а сам токен досі дійсний.<sup>[[13]](#references)[[14]](#references)</sup>

```bash
SPACE='owner/space-name'
curl -NsS -H "Authorization: Bearer $HF_TOKEN" \
  "https://huggingface.co/api/spaces/$SPACE/logs/run?tail=100"
```

Використовуйте токен свого авторизованого облікового запису Hub; це **не** запит на секрет власника Space. Відповідь — це потік SSE (рядки `data:`). Зіставляйте розкриті значення з кодом Space і поточним середовищем виконання, а не припускайте, що назва змінної доводить витік її значення. Для [самостійно розміщеної кінцевої точки Gradio або model-runner](AI-Exposed-Self-Hosted-AI-Services.md) перегляньте відповідну сторінку.<sup>[[13]](#references)[[14]](#references)</sup>

## [**TensorFlow Hub**](https://www.tensorflow.org/hub) **і** [**Kaggle**](https://www.kaggle.com/)

**TensorFlow Hub** — це репозиторій і бібліотека повторно використовуваних навчених компонентів моделей, особливо модулів, що використовуються через TensorFlow/Keras. **Kaggle** окремо надає ноутбуки, набори даних, змагання та моделі.<sup>[[7]](#references)[[9]](#references)</sup>

* **Модулі:** Величезна колекція попередньо навчених моделей і компонентів моделей, які користувачі можуть переглядати, завантажувати й інтегрувати для таких завдань, як класифікація зображень, вбудовування тексту тощо.
* **Посібники:** Покрокові інструкції та приклади, що допомагають користувачам реалізовувати й тонко налаштовувати моделі за допомогою TensorFlow Hub.
* **Документація:** Вичерпні посібники та довідники з API, які допомагають розробникам ефективно використовувати ресурси репозиторію.

## [**Replicate**](https://replicate.com/home)

**Replicate** — це хостингова платформа для запуску упакованих моделей машинного навчання через вебінтерфейс або API.<sup>[[8]](#references)</sup>

* **Моделі:** Репозиторій моделей машинного навчання, створених спільнотою. Користувачі можуть переглядати й тестувати моделі та з мінімальними зусиллями інтегрувати їх у свої застосунки.
* **Доступ до API:** API для виклику моделей із застосунків без потреби керувати базовою інфраструктурою інференсу.
