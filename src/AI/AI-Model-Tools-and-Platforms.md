## Executar e treinar modelos localmente

### [**Hugging Face Transformers**](https://github.com/huggingface/transformers)

Hugging Face Transformers é uma biblioteca de código aberto para carregar, treinar e disponibilizar modelos pré-treinados em tarefas de texto, visão, áudio, vídeo e multimodais. A hospedagem de modelos e conjuntos de dados é fornecida separadamente pelo Hugging Face Hub.<sup>[[1]](#references)</sup>

### [**LangChain**](https://github.com/langchain-ai/langchain)

LangChain é um framework para criar aplicações e agentes orientados por modelos, com construção de prompts, gerenciamento do histórico e estado de conversas, ferramentas, recuperação e integrações com modelos, APIs e bancos de dados.<sup>[[2]](#references)</sup>

### [**LitGPT**](https://github.com/Lightning-AI/litgpt)

LitGPT oferece implementações legíveis e fluxos de trabalho pela linha de comando para pré-treinar, ajustar, avaliar e implantar modelos de linguagem compatíveis.<sup>[[3]](#references)</sup>

### [**LitServe**](https://github.com/Lightning-AI/LitServe)

**Descrição:**\
LitServe é um framework de serving de modelos da Lightning AI para disponibilizar APIs de inferência com recursos de batching, streaming, aceleração e escalabilidade.<sup>[[4]](#references)</sup>

### [**Axolotl**](https://github.com/axolotl-ai-cloud/axolotl)

Axolotl é um framework de código aberto para pós-treinamento e fine-tuning, configurado por meio de YAML. Ele oferece suporte a técnicas como fine-tuning completo, LoRA/QLoRA, otimização de preferências e treinamento com várias GPUs; não é, por si só, uma plataforma de implantação na nuvem.<sup>[[5]](#references)</sup>

## Experimentar modelos online

### [**Hugging Face**](https://huggingface.co/)

**Hugging Face** é uma plataforma e comunidade de destaque em machine learning, conhecida particularmente por seu trabalho em processamento de linguagem natural (NLP). Ela oferece ferramentas, bibliotecas e recursos que facilitam o desenvolvimento, o compartilhamento e a implantação de modelos de machine learning.\
O Hub oferece várias seções relevantes:<sup>[[6]](#references)</sup>

* **Models**: Um vasto repositório de **modelos de machine learning pré-treinados** que os usuários podem explorar, baixar e integrar em diversas tarefas, como geração de texto, tradução, reconhecimento de imagens e outras.
* **Datasets:** Uma **coleção abrangente de conjuntos de dados** usados para treinar e avaliar modelos. Ela facilita o acesso a diversas fontes de dados, permitindo que os usuários encontrem e utilizem dados em seus projetos específicos de machine learning.
* **Spaces:** Uma plataforma para hospedar e compartilhar **aplicações interativas de machine learning** e demonstrações. Ela permite que os desenvolvedores **demonstrem** seus modelos em ação, criem interfaces fáceis de usar e colaborem com outras pessoas compartilhando demonstrações ao vivo.

## [**TensorFlow Hub**](https://www.tensorflow.org/hub) **e** [**Kaggle**](https://www.kaggle.com/)

**TensorFlow Hub** é um repositório e uma biblioteca de componentes de modelos treinados reutilizáveis, especialmente módulos usados por meio de TensorFlow/Keras. **Kaggle**, separadamente, oferece notebooks, conjuntos de dados, competições e modelos.<sup>[[7]](#references)[[9]](#references)</sup>

* **Modules:** Uma vasta coleção de modelos e componentes de modelos pré-treinados que os usuários podem explorar, baixar e integrar em tarefas como classificação de imagens, incorporação de texto e outras.
* **Tutoriais:** Guias passo a passo e exemplos que ajudam os usuários a implementar e ajustar modelos usando o TensorFlow Hub.
* **Documentação:** Guias abrangentes e referências da API que ajudam os desenvolvedores a utilizar os recursos do repositório de forma eficaz.

## [**Replicate**](https://replicate.com/home)

**Replicate** é uma plataforma hospedada para executar modelos de machine learning empacotados por meio de uma interface web ou API.<sup>[[8]](#references)</sup>

* **Models:** Um repositório de modelos de machine learning enviados pela comunidade, que os usuários podem explorar, experimentar e integrar em suas aplicações com o mínimo de esforço.
* **Acesso à API:** APIs para invocar modelos a partir de aplicações sem operar a infraestrutura de inferência subjacente.
