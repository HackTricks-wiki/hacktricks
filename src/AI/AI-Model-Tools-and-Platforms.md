## Запуск і навчання моделей локально

### [**Hugging Face Transformers**](https://github.com/huggingface/transformers)

Hugging Face Transformers — це бібліотека з відкритим кодом для завантаження, навчання та розгортання попередньо навчених моделей для роботи з текстом, зображеннями, аудіо, відео та мультимодальними завданнями. Розміщення моделей і наборів даних забезпечує окремо Hugging Face Hub.<sup>[[1]](#references)</sup>

### [**LangChain**](https://github.com/langchain-ai/langchain)

LangChain — це фреймворк для створення застосунків і агентів на основі моделей із засобами для формування промптів, керування історією розмов і станом, роботи з інструментами, пошуку інформації, а також інтеграції моделей, API і баз даних.<sup>[[2]](#references)</sup>

### [**LitGPT**](https://github.com/Lightning-AI/litgpt)

LitGPT надає зрозумілі реалізації та інструменти командного рядка для попереднього навчання, донавчання, оцінювання та розгортання підтримуваних мовних моделей.<sup>[[3]](#references)</sup>

### [**LitServe**](https://github.com/Lightning-AI/LitServe)

**Опис:**\
LitServe — це фреймворк від Lightning AI для розгортання моделей через API інференсу з підтримкою пакетної обробки, потокової передачі, прискорення та масштабування.<sup>[[4]](#references)</sup>

### [**Axolotl**](https://github.com/axolotl-ai-cloud/axolotl)

Axolotl — це фреймворк із відкритим кодом для постнавчання та донавчання, керований конфігурацією YAML. Він підтримує такі методи, як повне донавчання, LoRA/QLoRA, оптимізація переваг і навчання на кількох GPU; сам по собі він не є хмарною платформою розгортання.<sup>[[5]](#references)</sup>

## Спробувати моделі онлайн

### [**Hugging Face**](https://huggingface.co/)

**Hugging Face** — провідна платформа та спільнота у сфері машинного навчання, особливо відома своїми напрацюваннями в обробці природної мови (NLP). Вона надає інструменти, бібліотеки та ресурси, які спрощують розробку, обмін і розгортання моделей машинного навчання.\
Hub містить кілька відповідних розділів:<sup>[[6]](#references)</sup>

* **Models**: велике сховище **попередньо навчених моделей машинного навчання**, де користувачі можуть переглядати, завантажувати й інтегрувати моделі для різних завдань, як-от генерація тексту, переклад, розпізнавання зображень тощо.
* **Datasets:** велика **колекція наборів даних**, які використовують для навчання й оцінювання моделей. Вона спрощує доступ до різноманітних джерел даних, допомагаючи користувачам знаходити й використовувати дані для своїх проєктів машинного навчання.
* **Spaces:** платформа для розміщення й поширення **інтерактивних застосунків і демонстрацій машинного навчання**. Вона дає розробникам змогу **демонструвати** роботу своїх моделей, створювати зручні інтерфейси та співпрацювати з іншими, поширюючи інтерактивні демонстрації.

## [**TensorFlow Hub**](https://www.tensorflow.org/hub) **і** [**Kaggle**](https://www.kaggle.com/)

**TensorFlow Hub** — це сховище та бібліотека компонентів навчених моделей для повторного використання, зокрема модулів, які використовуються через TensorFlow/Keras. **Kaggle** окремо надає ноутбуки, набори даних, змагання та моделі.<sup>[[7]](#references)[[9]](#references)</sup>

* **Modules:** велика колекція попередньо навчених моделей і компонентів моделей, де користувачі можуть переглядати, завантажувати й інтегрувати модулі для таких завдань, як класифікація зображень, векторизація тексту тощо.
* **Tutorials:** покрокові посібники та приклади, які допомагають користувачам реалізовувати й донавчати моделі за допомогою TensorFlow Hub.
* **Documentation:** докладні посібники та довідники API, що допомагають розробникам ефективно використовувати ресурси сховища.

## [**Replicate**](https://replicate.com/home)

**Replicate** — це хостингова платформа для запуску упакованих моделей машинного навчання через вебінтерфейс або API.<sup>[[8]](#references)</sup>

* **Models:** сховище моделей машинного навчання, створених спільнотою. Користувачі можуть переглядати й випробовувати їх, а також із мінімальними зусиллями інтегрувати моделі у свої застосунки.
* **API access:** API для виклику моделей із застосунків без необхідності керувати базовою інфраструктурою інференсу.
