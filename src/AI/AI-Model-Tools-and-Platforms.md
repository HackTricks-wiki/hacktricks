## Запуск і навчання моделей локально

### [**Hugging Face Transformers**](https://github.com/huggingface/transformers)

Hugging Face Transformers — це бібліотека з відкритим вихідним кодом для завантаження, навчання та обслуговування попередньо навчених моделей для роботи з текстом, зображеннями, аудіо, відео та мультимодальними завданнями. Моделі й набори даних розміщуються окремо на Hugging Face Hub.<sup>[[1]](#references)</sup>

### [**LangChain**](https://github.com/langchain-ai/langchain)

LangChain — це фреймворк для створення застосунків і агентів на основі моделей із засобами формування промптів, керування історією розмов і станом, інструментами, пошуком, а також інтеграціями з моделями, API та базами даних.<sup>[[2]](#references)</sup>

### [**LitGPT**](https://github.com/Lightning-AI/litgpt)

LitGPT надає зрозумілі реалізації та інструменти командного рядка для попереднього навчання, донавчання, оцінювання та розгортання підтримуваних мовних моделей.<sup>[[3]](#references)</sup>

### [**LitServe**](https://github.com/Lightning-AI/LitServe)

**Опис:**\
LitServe — це фреймворк від Lightning AI для обслуговування моделей, який дає змогу надавати API для інференсу з підтримкою пакетної обробки, потокової передачі, прискорення та масштабування.<sup>[[4]](#references)</sup>

### [**Axolotl**](https://github.com/axolotl-ai-cloud/axolotl)

Axolotl — це фреймворк із відкритим вихідним кодом для постнавчання та донавчання, керований конфігурацією YAML. Він підтримує такі методи, як повне донавчання, LoRA/QLoRA, оптимізація за уподобаннями та навчання на кількох GPU; сам по собі це не платформа для хмарного розгортання.<sup>[[5]](#references)</sup>

## Спробуйте моделі онлайн

### [**Hugging Face**](https://huggingface.co/)

**Hugging Face** — це провідна платформа й спільнота у сфері машинного навчання, відома насамперед своєю роботою з обробки природної мови (NLP). Вона надає інструменти, бібліотеки й ресурси, які спрощують розробку, поширення та розгортання моделей машинного навчання.\
Hub містить кілька важливих розділів:<sup>[[6]](#references)</sup>

* **Моделі**: великий репозиторій **попередньо навчених моделей машинного навчання**, у якому користувачі можуть переглядати, завантажувати й інтегрувати моделі для різних завдань, зокрема генерації тексту, перекладу, розпізнавання зображень тощо.
* **Набори даних:** велика **колекція наборів даних**, які використовують для навчання й оцінювання моделей. Вона забезпечує зручний доступ до різноманітних джерел даних, допомагаючи користувачам знаходити й використовувати дані для власних проєктів машинного навчання.
* **Spaces:** платформа для розміщення та поширення **інтерактивних застосунків і демонстрацій машинного навчання**. Вона дає розробникам змогу **демонструвати** роботу моделей, створювати зручні інтерфейси та співпрацювати з іншими, ділячись інтерактивними демонстраціями.

## [**TensorFlow Hub**](https://www.tensorflow.org/hub) **і** [**Kaggle**](https://www.kaggle.com/)

**TensorFlow Hub** — це репозиторій і бібліотека повторно використовуваних навчених компонентів моделей, зокрема модулів, які використовуються через TensorFlow/Keras. **Kaggle** окремо надає ноутбуки, набори даних, змагання та моделі.<sup>[[7]](#references)[[9]](#references)</sup>

* **Модулі:** велика колекція попередньо навчених моделей і компонентів моделей, у якій користувачі можуть переглядати, завантажувати й інтегрувати модулі для таких завдань, як класифікація зображень, векторизація тексту тощо.
* **Посібники:** покрокові інструкції та приклади, що допомагають користувачам реалізовувати й донавчати моделі за допомогою TensorFlow Hub.
* **Документація:** докладні посібники та довідник з API, які допомагають розробникам ефективно використовувати ресурси репозиторію.

## [**Replicate**](https://replicate.com/home)

**Replicate** — це хостингова платформа для запуску упакованих моделей машинного навчання через вебінтерфейс або API.<sup>[[8]](#references)</sup>

* **Моделі:** репозиторій моделей машинного навчання, доданих спільнотою. Користувачі можуть переглядати й випробовувати їх, а також із мінімальними зусиллями інтегрувати моделі у свої застосунки.
* **Доступ до API:** API для виклику моделей із застосунків без необхідності керувати базовою інфраструктурою інференсу.
