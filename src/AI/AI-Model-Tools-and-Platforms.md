## Εκτέλεση και εκπαίδευση μοντέλων τοπικά

### [**Hugging Face Transformers**](https://github.com/huggingface/transformers)

Το Hugging Face Transformers είναι μια βιβλιοθήκη ανοιχτού κώδικα για τη φόρτωση, την εκπαίδευση και την παροχή προεκπαιδευμένων μοντέλων για εργασίες κειμένου, όρασης, ήχου, βίντεο και πολυτροπικών δεδομένων. Η φιλοξενία μοντέλων και συνόλων δεδομένων παρέχεται ξεχωριστά από το Hugging Face Hub.<sup>[[1]](#references)</sup>

### [**LangChain**](https://github.com/langchain-ai/langchain)

Το LangChain είναι ένα framework για τη δημιουργία εφαρμογών και agents που βασίζονται σε μοντέλα, με δυνατότητες κατασκευής prompt, διαχείρισης ιστορικού συνομιλίας/κατάστασης, εργαλείων, ανάκτησης και ενσωματώσεων με μοντέλα, API και βάσεις δεδομένων.<sup>[[2]](#references)</sup>

### [**LitGPT**](https://github.com/Lightning-AI/litgpt)

Το LitGPT παρέχει ευανάγνωστες υλοποιήσεις και ροές εργασιών μέσω γραμμής εντολών για την προεκπαίδευση, το fine-tuning, την αξιολόγηση και την ανάπτυξη υποστηριζόμενων γλωσσικών μοντέλων.<sup>[[3]](#references)</sup>

### [**LitServe**](https://github.com/Lightning-AI/LitServe)

**Περιγραφή:**\
Το LitServe είναι ένα framework εξυπηρέτησης μοντέλων από την Lightning AI, για την έκθεση API inference με δυνατότητες batching, streaming, επιτάχυνσης και κλιμάκωσης.<sup>[[4]](#references)</sup>

### [**Axolotl**](https://github.com/axolotl-ai-cloud/axolotl)

Το Axolotl είναι ένα framework ανοιχτού κώδικα για post-training και fine-tuning, το οποίο βασίζεται σε ρυθμίσεις YAML. Υποστηρίζει τεχνικές όπως full fine-tuning, LoRA/QLoRA, βελτιστοποίηση προτιμήσεων και εκπαίδευση με πολλαπλές GPU· δεν είναι από μόνο του πλατφόρμα ανάπτυξης στο cloud.<sup>[[5]](#references)</sup>

## Δοκιμή μοντέλων online

### [**Hugging Face**](https://huggingface.co/)

Το **Hugging Face** είναι μια κορυφαία πλατφόρμα και κοινότητα για τη μηχανική μάθηση, γνωστή κυρίως για το έργο της στην επεξεργασία φυσικής γλώσσας (NLP). Παρέχει εργαλεία, βιβλιοθήκες και πόρους που διευκολύνουν την ανάπτυξη, την κοινή χρήση και την ανάπτυξη μοντέλων μηχανικής μάθησης.\
Το Hub διαθέτει αρκετές σχετικές ενότητες:<sup>[[6]](#references)</sup>

* **Models**: Ένα τεράστιο αποθετήριο **προεκπαιδευμένων μοντέλων μηχανικής μάθησης**, όπου οι χρήστες μπορούν να περιηγηθούν, να κατεβάσουν και να ενσωματώσουν μοντέλα για διάφορες εργασίες, όπως παραγωγή κειμένου, μετάφραση, αναγνώριση εικόνων και άλλες.
* **Datasets:** Μια ολοκληρωμένη **συλλογή συνόλων δεδομένων** που χρησιμοποιούνται για την εκπαίδευση και την αξιολόγηση μοντέλων. Διευκολύνει την πρόσβαση σε ποικίλες πηγές δεδομένων, επιτρέποντας στους χρήστες να βρίσκουν και να αξιοποιούν δεδομένα για τα συγκεκριμένα έργα μηχανικής μάθησης που αναπτύσσουν.
* **Spaces:** Μια πλατφόρμα φιλοξενίας και κοινής χρήσης **διαδραστικών εφαρμογών μηχανικής μάθησης** και demos. Επιτρέπει στους προγραμματιστές να **παρουσιάζουν** τα μοντέλα τους σε λειτουργία, να δημιουργούν φιλικές προς τον χρήστη διεπαφές και να συνεργάζονται με άλλους, κοινοποιώντας ζωντανά demos.

## [**TensorFlow Hub**](https://www.tensorflow.org/hub) **&** [**Kaggle**](https://www.kaggle.com/)

Το **TensorFlow Hub** είναι ένα αποθετήριο και μια βιβλιοθήκη επαναχρησιμοποιήσιμων εκπαιδευμένων στοιχείων μοντέλων, ιδιαίτερα αρθρωτών μονάδων που χρησιμοποιούνται μέσω TensorFlow/Keras. Το **Kaggle** παρέχει ξεχωριστά notebooks, σύνολα δεδομένων, διαγωνισμούς και μοντέλα.<sup>[[7]](#references)[[9]](#references)</sup>

* **Modules:** Μια τεράστια συλλογή προεκπαιδευμένων μοντέλων και στοιχείων μοντέλων, όπου οι χρήστες μπορούν να περιηγηθούν, να κατεβάσουν και να ενσωματώσουν modules για εργασίες όπως ταξινόμηση εικόνων, ενσωμάτωση κειμένου και άλλες.
* **Tutorials:** Οδηγοί βήμα προς βήμα και παραδείγματα που βοηθούν τους χρήστες να υλοποιούν και να κάνουν fine-tuning μοντέλων χρησιμοποιώντας το TensorFlow Hub.
* **Documentation:** Πλήρεις οδηγοί και αναφορές API που βοηθούν τους προγραμματιστές να αξιοποιούν αποτελεσματικά τους πόρους του αποθετηρίου.

## [**Replicate**](https://replicate.com/home)

Το **Replicate** είναι μια φιλοξενούμενη πλατφόρμα για την εκτέλεση πακεταρισμένων μοντέλων μηχανικής μάθησης μέσω web interface ή API.<sup>[[8]](#references)</sup>

* **Models:** Ένα αποθετήριο μοντέλων μηχανικής μάθησης που συνεισφέρει η κοινότητα, στο οποίο οι χρήστες μπορούν να περιηγηθούν και να δοκιμάσουν μοντέλα, καθώς και να τα ενσωματώσουν στις εφαρμογές τους με ελάχιστη προσπάθεια.
* **API access:** API για την κλήση μοντέλων από εφαρμογές χωρίς να χρειάζεται η λειτουργία της υποδομής inference.
