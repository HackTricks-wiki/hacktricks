## Η υπέρθεση ως επιφάνεια επίθεσης

Ένας υποπαραμετροποιημένος χώρος ενεργοποιήσεων μπορεί να κωδικοποιεί περισσότερα σημασιολογικά χαρακτηριστικά από όσα έχει διαστάσεις, αντιστοιχίζοντας χαρακτηριστικά σε μη ορθογώνια διανύσματα. Κατά συνέπεια, ένα ενεργοποιημένο χαρακτηριστικό προβάλλεται επίσης στις κατευθύνσεις άλλων χαρακτηριστικών. Η εκπαίδευση μπορεί να αντισταθμίσει συνδυασμούς που εμφανίζονται στην κατανομή δεδομένων, αλλά ένας ασυνήθιστος συνδυασμός κατά τα άλλα έγκυρων χαρακτηριστικών μπορεί να ενισχύσει την προβολή του προς την κατεύθυνση ενός χαρακτηριστικού-στόχου που απουσιάζει από την είσοδο.<sup>[[1]](#references)[[2]](#references)</sup>

Για διανύσματα χαρακτηριστικών `v_i ∈ R^D`, ενεργοποιήσεις `a_i` και στόχο `t`, το ακόλουθο μέγεθος είναι χρήσιμο για τον εντοπισμό υποψήφιων συνδυασμών:<sup>[[1]](#references)</sup>

```text
I_t = Σ_i≠t |a_i (v_i · v_t) / ||v_t|| |
candidate condition: I_t > max(a)
```

Αυτό είναι μόνο μια ευρετική μέθοδος αρχικής αξιολόγησης. Ένα exploit πρέπει να διατηρεί τα πρόσημα και τα μεγέθη και να αξιολογεί τον πραγματικό αποκωδικοποιητή, για παράδειγμα `h_hat[t] = ReLU(b_t + Σ_i a_i(v_i · v_t))` σε έναν γραμμικό αποκωδικοποιητή με κοινά βάρη. Οι αρνητικοί όροι μπορούν να ακυρώσουν την επίθεση, ενώ η μεροληψία του αποκωδικοποιητή, τα νόρμα των διανυσμάτων χαρακτηριστικών, τα κατώφλια ενεργοποίησης και το ReLU gating μπορούν να εμποδίσουν μια μεγάλη απόλυτη τιμή cosine score να προκαλέσει την ενεργοποίηση του στόχου.<sup>[[1]](#references)</sup>

## Ροή εργασίας επίθεσης White-box

Μια πρακτική αξιολόγηση μπορεί να χρησιμοποιήσει ένα bottleneck μοντέλου, έναν sparse autoencoder (SAE) ή κάποιο άλλο ερμηνεύσιμο λεξικό χαρακτηριστικών. Ο στόχος δεν είναι απλώς να αλλάξει η τελική κλάση, αλλά η ανακατασκευή να εισαγάγει ένα επιλεγμένο εσωτερικό χαρακτηριστικό που δεν ήταν ενεργό πριν από τη συμπίεση. Η προτεινόμενη ροή εργασίας είναι:<sup>[[1]](#references)</sup>

1. **Ανάκτηση κατευθύνσεων χαρακτηριστικών:** εξαγάγετε τα σχετικά διανύσματα encoder/decoder, αφαιρέστε τα ανενεργά χαρακτηριστικά και αντιστοιχίστε τις ενεργές κατευθύνσεις σε έννοιες, χρησιμοποιώντας δείγματα που ενεργοποιούν τα χαρακτηριστικά στο μέγιστο ή ανάλυση κυκλωμάτων χαρακτηριστικών.
2. **Κατάταξη παρεμβολών:** κανονικοποιήστε ένα αντίγραφο των διανυσμάτων, υπολογίστε τον πίνακα cosine similarity, μηδενίστε τη διαγώνιο και εξετάστε τους ισχυρότερους γειτονικούς όρους εκτός διαγωνίου του στόχου. Επαναϋπολογίστε τις υποψήφιες επιλογές χρησιμοποιώντας τα πραγματικά μεγέθη ενεργοποίησης και τα προσημασμένα ακατέργαστα dot products.
3. **Επιβολή συν-ενεργοποίησης:** κρατήστε ένα μικρό σύνολο χαρακτηριστικών με θετική συνεισφορά, τα οποία μπορούν να ενεργοποιηθούν στο ίδιο layer ή στο residual stream. Προτιμήστε συνδυασμούς που είναι σπάνιοι ή απουσιάζουν από τα δεδομένα εκπαίδευσης· οι συνηθισμένοι συσχετισμένοι συνδυασμοί είναι πιθανότερο να έχουν αντισταθμιστεί κατά την εκπαίδευση.
4. **Σύνθεση της εισόδου:** συνδυάστε παραδείγματα από το dataset ή μοτίβα που μεγιστοποιούν τις ενεργοποιήσεις για τους επιλεγμένους συνεισφέροντες. Για έναν γραμμικό ανιχνευτή pixel με περιορισμένο εύρος τιμών, ορίστε ένα pixel σε υψηλή τιμή για θετικό βάρος και σε χαμηλή για αρνητικό, και έπειτα επικαλύψτε τα μοτίβα που προκύπτουν. Η χειροκίνητη διατήρηση δομής εντός της κατανομής και του ανασταλτικού **αρνητικού χώρου** μπορεί να καταστείλει άσχετα χαρακτηριστικά.
5. **Επαλήθευση του μηχανισμού:** καταγράψτε τις ενεργοποιήσεις πριν από τη συμπίεση, τις συμπιεσμένες συντεταγμένες, τις ανακατασκευασμένες ενεργοποιήσεις και την έξοδο downstream σε ένα forward pass. Μια επιτυχημένη δοκιμή δείχνει ότι ο στόχος είναι ανενεργός πριν από την ανακατασκευή αλλά ενεργός μετά, και ότι η προβλεπόμενη αλλαγή εξαφανίζεται όταν αφαιρούνται οι συνεισφέροντες μέσω ablation.

Η παρακάτω ελάχιστη διαλογή κατατάσσει τους συνεισφέροντες για έναν αποκωδικοποιητή με κοινά βάρη, όπου τα **rows** είναι διανύσματα χαρακτηριστικών (κάντε πρώτα transpose αν τα χαρακτηριστικά είναι στήλες). Χρησιμοποιήστε τα ακατέργαστα βάρη για το προσημασμένο score και τα κανονικοποιημένα βάρη μόνο για την κατάταξη βάσει cosine similarity.<sup>[[1]](#references)</sup>

```python
import numpy as np

norm = np.linalg.norm(W_dec, axis=1, keepdims=True)
unit = W_dec / np.clip(norm, 1e-12, None)
cosine = unit @ unit.T
np.fill_diagonal(cosine, 0.0)

target = 42
signed = activations * (W_dec @ W_dec[target])
signed[target] = -np.inf
order = np.argsort(signed)[::-1]
print([(int(i), float(signed[i]), float(cosine[i, target]))
       for i in order[:20] if signed[i] > 0])
```

Μην συμπεραίνετε ότι κάτι είναι εκμεταλλεύσιμο μόνο από την ομοιότητα συνημιτόνου. Δοκιμάστε ολόκληρο τον decoder, μαζί με το bias και τη μη γραμμικότητά του, επιβεβαιώστε ότι οι συνεισφέροντες μπορούν πράγματι να συνυπάρχουν και συγκρίνετε με αντίστοιχους συνδυασμούς εντός της κατανομής. Παρόμοιες κατευθύνσεις μπορεί να κωδικοποιούν μια θεμιτή σημασιολογική σχέση, αντί για εκμεταλλεύσιμη παρεμβολή λόγω packing.<sup>[[1]](#references)</sup>

## Επίθεση σε απλοποιημένο μοντέλο που παρουσιάστηκε

Το proof of concept χρησιμοποίησε έναν σκόπιμα ερμηνεύσιμο ταξινομητή MNIST με δύο κλάδους. Ένα αραιό διάνυσμα χαρακτηριστικών 128 διαστάσεων ταξινομούνταν απευθείας στον έναν κλάδο και συμπιεζόταν σε έναν δισδιάστατο χώρο υπέρθεσης στον άλλον· ο ίδιος ταξινομητής επεξεργαζόταν τόσο τα αρχικά όσο και τα ανακατασκευασμένα χαρακτηριστικά.<sup>[[1]](#references)</sup>

```text
h       = ReLU(MLP(x))
z       = W_enc h
h_hat   = ReLU(W_enc^T z + b)
y_plain = C(h)
y_super = C(h_hat)
```

Δύο κατευθύνσεις χαρακτηριστικών που σχετίζονταν με σχήματα τύπου 3/0 περικλείονταν γεωμετρικά από κατευθύνσεις κλάσης 5. Η πρόσθεση των εικόνων που ενεργοποιούσαν στο μέγιστο αυτά τα χαρακτηριστικά-συνεισφέροντες τα έκανε ισχυρότερα πριν από τη συμπίεση, αλλά η ανακατασκευή ενεργοποίησε αρκετά χαρακτηριστικά κλάσης 5 και ο κλάδος της υπέρθεσης προέβλεψε 5. Μια είσοδος σχεδιασμένη με το χέρι, που χρησιμοποιούσε μόνο τις ελάχιστες/μέγιστες τιμές pixel, αναπαρήγαγε το αποτέλεσμα, δείχνοντας ότι σε αυτό το απλοϊκό περιβάλλον δεν απαιτούνταν ακριβείς διαταραχές pixel βελτιστοποιημένες με βάση τη βαθμίδα.<sup>[[1]](#references)</sup>

## Γεωμετρική διαλογή σε μεγαλύτερα μοντέλα

Η εργασία εξέτασε επίσης το SAE του Gemma Scope `layer 20 / width 65k / average L0 20`. Πολλαπλασίασε τον κανονικοποιημένο ως προς τη μοναδιαία νόρμα πίνακα αποκωδικοποιητή με τον ανάστροφό του, μηδένισε τη διαγώνιο, ταξινόμησε τους γείτονες κάθε χαρακτηριστικού και υπολόγισε τον μέσο όρο ανά βαθμίδα. Η μέση συνημίτονη ομοιότητα του ισχυρότερου γείτονα ήταν `0.49`, ενώ η μέση ομοιότητα του 27ου γείτονα ήταν `0.25`· γεωμετρικά, τέσσερις τέτοιες κατευθύνσεις θα μπορούσαν να αντιστοιχούν στην προβολή ενός μοναδιαίου στόχου. Αυτά τα μεγέθη απλώς εντοπίζουν υποψήφια χαρακτηριστικά—δεν αποδεικνύουν ότι τέσσερα κατάλληλα χαρακτηριστικά μπορούν να ενεργοποιηθούν ταυτόχρονα ή ότι ο στόχος υπερβαίνει το κατώφλι του αποκωδικοποιητή.<sup>[[1]](#references)</sup>

## Πεδίο εφαρμογής και περιορισμοί

Πρόκειται για τεχνική **white-box** σε ερευνητικό στάδιο, όχι για αποδεδειγμένη επίθεση εναντίον ενός ανεπτυγμένου CNN ή ενός LLM αιχμής. Απαιτεί υπέρθεση, χρήσιμες μη ορθογώνιες κατευθύνσεις, ερμηνεύσιμη πρόσβαση σε εσωτερικά χαρακτηριστικά, δυνατότητα ελεγχόμενης ενεργοποίησης των χαρακτηριστικών-συνεισφερόντων και συγκέντρωσή τους στο ίδιο επίπεδο κατά τη διάρκεια ενός forward pass.<sup>[[1]](#references)</sup>

Τα MLP εικόνας καθιστούν τη σύνθεση χαρακτηριστικών ασυνήθιστα άμεση. Ένας transformer είναι δυσκολότερος, επειδή το attention πρέπει να συγκεντρώσει τις επιλεγμένες ενεργοποιήσεις χαρακτηριστικών στην ίδια residual stream· η εργασία δεν δείχνει πώς μπορεί να επιβληθεί αυτό για έναν συνδυασμό εκτός κατανομής. Επομένως, οι ισχυρισμοί σχετικά με τη χειραγώγηση κατευθύνσεων συμπεριφοράς ή άρνησης, φυσικών συστημάτων όρασης ή μοντέλων αιχμής παραμένουν υποθέσεις.<sup>[[1]](#references)</sup>
