### Model Context Protocol для ШІ

MCP (Model Context Protocol) — це відкритий протокол для підключення застосунків ШІ до інструментів і джерел даних. Оскільки сервери MCP можуть надавати доступ до даних і дій, під час оцінювання потрібно перевіряти авторизацію, згоду, валідацію введених даних для інструментів і межі довіри.<sup>[[3]](#references)</sup>
