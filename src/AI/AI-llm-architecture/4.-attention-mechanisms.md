## Mehanizmi pažnje i samopažnja u neuronskim mrežama

Mehanizmi pažnje omogućavaju neuronskim mrežama da se us**redsrede na određene delove ulaza prilikom generisanja svakog dela izlaza**. Oni dodeljuju različite težine različitim ulazima, pomažući modelu da odluči koji su ulazi najrelevantniji za dati zadatak. Ovo je ključno u zadacima kao što je mašinsko prevođenje, gde je razumevanje konteksta cele rečenice neophodno za precizan prevod.<sup>[[1]](#references)</sup>

> [!TIP]
> Cilj ove četvrte faze je veoma jednostavan: **Primena nekih mehanizama pažnje**. Oni će se sastojati od mnogo **ponovljenih slojeva** koji će **uhvatiti odnos reči u rečniku sa njenim susedima u trenutnoj rečenici koja se koristi za treniranje LLM-a**.\
> Za ovo se koristi mnogo slojeva, pa će veliki broj parametara koji se mogu trenirati prikupljati ove informacije.

### Razumevanje mehanizama pažnje

U tradicionalnim modelima sekvenca-u-sekvencu koji se koriste za prevođenje jezika, model kodira ulaznu sekvencu u vektor konteksta fiksne veličine. Međutim, ovaj pristup ima poteškoća sa dugim rečenicama zato što vektor konteksta fiksne veličine možda neće obuhvatiti sve neophodne informacije. Mehanizmi pažnje rešavaju ovo ograničenje tako što modelu omogućavaju da razmatra sve ulazne tokene prilikom generisanja svakog izlaznog tokena.

#### Primer: Mašinsko prevođenje

Razmotrimo prevođenje nemačke rečenice "Kannst du mir helfen diesen Satz zu übersetzen" na engleski. Prevođenje reč po reč ne bi proizvelo gramatički ispravnu rečenicu na engleskom zbog razlika u gramatičkim strukturama između jezika. Mehanizam pažnje omogućava modelu da se usredsredi na relevantne delove ulazne rečenice prilikom generisanja svake reči izlazne rečenice, što dovodi do preciznijeg i smislenijeg prevoda.

### Uvod u samopažnju

Samopažnja, odnosno intra-pažnja, jeste mehanizam u kojem se pažnja primenjuje unutar jedne sekvence kako bi se izračunala reprezentacija te sekvence. Ona omogućava svakom tokenu u sekvenci da obrati pažnju na sve ostale tokene, pomažući modelu da uhvati zavisnosti između tokena bez obzira na njihovu udaljenost u sekvenci.

#### Ključni koncepti

- **Tokeni**: Pojedinačni elementi ulazne sekvence (npr. reči u rečenici).
- **Embedding-ovi**: Vektorske reprezentacije tokena koje obuhvataju semantičke informacije.
- **Težine pažnje**: Vrednosti koje određuju važnost svakog tokena u odnosu na ostale.

### Sažetak procesa

1. **Izračunavanje rezultata pažnje**: Koristite skalarni proizvod između embedding-a ciljne reči i embedding-ova svih reči u sekvenci.
2. **Normalizacija rezultata radi dobijanja težina pažnje**: Primenite funkciju softmax na rezultate pažnje da biste dobili težine čiji je zbir 1.
3. **Izračunavanje vektora konteksta**: Pomnožite embedding svake reči njenom težinom pažnje i saberite rezultate.

## Samopažnja sa težinama koje se mogu trenirati

U praksi, mehanizmi samopažnje koriste **težine koje se mogu trenirati** kako bi naučili najbolje reprezentacije za upite, ključeve i vrednosti. Ovo podrazumeva uvođenje tri matrice težina:<sup>[[1]](#references)</sup>

Upit predstavlja podatke koji se koriste kao i ranije, dok su matrice ključeva i vrednosti samo nasumične matrice čije se težine mogu trenirati.

#### Korak 1: Izračunavanje upita, ključeva i vrednosti

Svaki token će imati sopstvenu matricu upita, ključa i vrednosti tako što će se njegove vrednosti dimenzija pomnožiti sa definisanim matricama:

<figure><img src="../../images/image (11).png" alt="" width="253"><figcaption></figcaption></figure>

Ove matrice transformišu originalne embedding-ove u novi prostor pogodan za izračunavanje pažnje.

**Primer**

Pretpostavimo:

- Ulazna dimenzija `din=3` (veličina embedding-a)
- Izlazna dimenzija `dout=2` (željena dimenzija za upite, ključeve i vrednosti)

Inicijalizujte matrice težina:
```python
import torch.nn as nn

d_in = 3
d_out = 2

W_query = nn.Parameter(torch.rand(d_in, d_out))
W_key = nn.Parameter(torch.rand(d_in, d_out))
W_value = nn.Parameter(torch.rand(d_in, d_out))
```
Računanje upita, ključeva i vrednosti:
```python
queries = torch.matmul(inputs, W_query)
keys = torch.matmul(inputs, W_key)
values = torch.matmul(inputs, W_value)
```

### Primer koda

Preuzimanjem primera sa [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb) možete proveriti ovu klasu koja implementira self-attention funkcionalnost o kojoj smo govorili:<sup>[[2]](#references)</sup>
```python
import torch

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

import torch.nn as nn
class SelfAttention_v2(nn.Module):

def __init__(self, d_in, d_out, qkv_bias=False):
super().__init__()
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)

def forward(self, x):
keys = self.W_key(x)
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.T
attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)

context_vec = attn_weights @ values
return context_vec

d_in=3
d_out=2
torch.manual_seed(789)
sa_v2 = SelfAttention_v2(d_in, d_out)
print(sa_v2(inputs))
```
> [!TIP]
> Imajte na umu da se, umesto inicijalizacije matrica nasumičnim vrednostima, koristi `nn.Linear` kako bi se sve težine označile kao parametri za treniranje.

## Causal Attention: Sakrivanje budućih reči

Kod LLMs želimo da model uzima u obzir samo tokene koji se pojavljuju pre trenutne pozicije kako bi **predvideo sledeći token**. **Causal attention**, poznat i kao **masked attention**, to postiže izmenom mehanizma attention kako bi se sprečio pristup budućim tokenima.<sup>[[1]](#references)</sup>

### Primena Causal Attention maske

Da bismo implementirali causal attention, primenjujemo masku na attention scores **pre softmax operacije**, tako da preostale vrednosti i dalje daju zbir 1. Ova maska postavlja attention scores budućih tokena na negativnu beskonačnost, čime se obezbeđuje da njihove attention weights nakon softmax operacije budu nula.

**Koraci**

1. **Izračunavanje Attention Scores**: Isto kao ranije.
2. **Primena maske**: Koristite gornju trougaonu matricu popunjenu negativnom beskonačnošću iznad dijagonale.

```python
mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1) * float('-inf')
masked_scores = attention_scores + mask
```

3. **Primena Softmax-a**: Izračunajte attention weights koristeći maskirane scores.

```python
attention_weights = torch.softmax(masked_scores, dim=-1)
```

### Maskiranje dodatnih Attention Weights pomoću Dropout-a

Kako bismo **sprečili overfitting**, možemo primeniti **dropout** na attention weights nakon softmax operacije. Dropout tokom treniranja **nasumično postavlja neke attention weights na nulu**.
```python
dropout = nn.Dropout(p=0.5)
attention_weights = dropout(attention_weights)
```
Uobičajeni dropout iznosi oko 10–20%.

### Primer koda

Primer koda sa [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb):<sup>[[2]](#references)</sup>
```python
import torch
import torch.nn as nn

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

batch = torch.stack((inputs, inputs), dim=0)
print(batch.shape)

class CausalAttention(nn.Module):

def __init__(self, d_in, d_out, context_length,
dropout, qkv_bias=False):
super().__init__()
self.d_out = d_out
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.dropout = nn.Dropout(dropout)
self.register_buffer('mask', torch.triu(torch.ones(context_length, context_length), diagonal=1)) # New

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # This generates the keys of the tokens
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.transpose(1, 2) # Moves the third dimension to the second one and the second one to the third one to be able to multiply
attn_scores.masked_fill_(  # New, _ ops are in-place
self.mask.bool()[:num_tokens, :num_tokens], -torch.inf)  # `:num_tokens` to account for cases where the number of tokens in the batch is smaller than the supported context_size
attn_weights = torch.softmax(
attn_scores / keys.shape[-1]**0.5, dim=-1
)
attn_weights = self.dropout(attn_weights)

context_vec = attn_weights @ values
return context_vec

torch.manual_seed(123)

context_length = batch.shape[1]
d_in = 3
d_out = 2
ca = CausalAttention(d_in, d_out, context_length, 0.0)

context_vecs = ca(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)
```
## Proširivanje Single-Head Attention na Multi-Head Attention

**Multi-head attention** u praktičnom smislu podrazumeva izvršavanje **više instanci** funkcije self-attention, pri čemu svaka od njih ima **sopstvene težine**, tako da se izračunavaju različiti finalni vektori.<sup>[[1]](#references)</sup>

### Primer koda

Moguće je ponovo koristiti prethodni kod i samo dodati omotač koji ga pokreće više puta, ali ovo je optimizovanija verzija preuzeta sa [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb), koja obrađuje sve glave istovremeno, čime se smanjuje broj skupih `for` petlji. Kao što možete videti u kodu, dimenzije svakog tokena dele se na različite dimenzije u skladu sa brojem glava. Na ovaj način, ako token ima 8 dimenzija, a želimo da koristimo 3 glave, dimenzije će biti podeljene u 2 niza od po 4 dimenzije, a svaka glava će koristiti jedan od njih:<sup>[[2]](#references)</sup>
```python
class MultiHeadAttention(nn.Module):
def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
super().__init__()
assert (d_out % num_heads == 0), \
"d_out must be divisible by num_heads"

self.d_out = d_out
self.num_heads = num_heads
self.head_dim = d_out // num_heads # Reduce the projection dim to match desired output dim

self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.out_proj = nn.Linear(d_out, d_out)  # Linear layer to combine head outputs
self.dropout = nn.Dropout(dropout)
self.register_buffer(
"mask",
torch.triu(torch.ones(context_length, context_length),
diagonal=1)
)

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # Shape: (b, num_tokens, d_out)
queries = self.W_query(x)
values = self.W_value(x)

# We implicitly split the matrix by adding a `num_heads` dimension
# Unroll last dim: (b, num_tokens, d_out) -> (b, num_tokens, num_heads, head_dim)
keys = keys.view(b, num_tokens, self.num_heads, self.head_dim)
values = values.view(b, num_tokens, self.num_heads, self.head_dim)
queries = queries.view(b, num_tokens, self.num_heads, self.head_dim)

# Transpose: (b, num_tokens, num_heads, head_dim) -> (b, num_heads, num_tokens, head_dim)
keys = keys.transpose(1, 2)
queries = queries.transpose(1, 2)
values = values.transpose(1, 2)

# Compute scaled dot-product attention (aka self-attention) with a causal mask
attn_scores = queries @ keys.transpose(2, 3)  # Dot product for each head

# Original mask truncated to the number of tokens and converted to boolean
mask_bool = self.mask.bool()[:num_tokens, :num_tokens]

# Use the mask to fill attention scores
attn_scores.masked_fill_(mask_bool, -torch.inf)

attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)
attn_weights = self.dropout(attn_weights)

# Shape: (b, num_tokens, num_heads, head_dim)
context_vec = (attn_weights @ values).transpose(1, 2)

# Combine heads, where self.d_out = self.num_heads * self.head_dim
context_vec = context_vec.contiguous().view(b, num_tokens, self.d_out)
context_vec = self.out_proj(context_vec) # optional projection

return context_vec

torch.manual_seed(123)

batch_size, context_length, d_in = batch.shape
d_out = 2
mha = MultiHeadAttention(d_in, d_out, context_length, 0.0, num_heads=2)

context_vecs = mha(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)

```
Za još jednu kompaktnu i efikasnu implementaciju možete koristiti klasu [`torch.nn.MultiheadAttention`](https://pytorch.org/docs/stable/generated/torch.nn.MultiheadAttention.html) u okviru PyTorch-a.

> [!TIP]
> Kratak odgovor ChatGPT-a o tome zašto je bolje podeliti dimenzije tokena među glavama umesto da svaka glava proverava sve dimenzije svih tokena:
>
> Iako može delovati korisno omogućiti svakoj glavi da obrađuje sve embedding dimenzije, jer bi svaka glava imala pristup potpunim informacijama, standardna praksa je **podeliti embedding dimenzije među glavama**. Ovaj pristup uspostavlja ravnotežu između računarske efikasnosti i performansi modela i podstiče svaku glavu da nauči raznovrsne reprezentacije. Zbog toga se podela embedding dimenzija generalno daje prednost u odnosu na to da svaka glava proverava sve dimenzije.
