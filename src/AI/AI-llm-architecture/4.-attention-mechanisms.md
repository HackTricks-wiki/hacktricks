## Neural Networks में Attention Mechanisms और Self-Attention

Attention mechanisms neural networks को **आउटपुट के प्रत्येक भाग को generate करते समय इनपुट के विशेष भागों पर ध्यान केंद्रित करने** की अनुमति देते हैं। ये अलग-अलग इनपुट को अलग-अलग weights प्रदान करते हैं, जिससे model यह तय कर पाता है कि वर्तमान task के लिए कौन-से inputs सबसे अधिक relevant हैं। यह machine translation जैसे tasks में महत्वपूर्ण है, जहाँ accurate translation के लिए पूरे sentence के context को समझना आवश्यक होता है।<sup>[[1]](#references)</sup>

> [!TIP]
> इस चौथे phase का लक्ष्य बहुत सरल है: **कुछ attention mechanisms लागू करना**। इनमें कई **repeated layers** होंगी, जो **vocabulary में किसी word और LLM को train करने के लिए उपयोग किए जा रहे current sentence में उसके neighbours के बीच relation को capture करेंगी**।\
> इसके लिए बहुत सारी layers का उपयोग किया जाता है, इसलिए बहुत सारे trainable parameters इस information को capture करेंगे।

### Attention Mechanisms को समझना

Language translation के लिए उपयोग किए जाने वाले traditional sequence-to-sequence models में model एक input sequence को fixed-size context vector में encode करता है। हालांकि, लंबे sentences के साथ यह approach कठिनाई का सामना करती है, क्योंकि fixed-size context vector सभी आवश्यक information को capture नहीं कर सकता। Attention mechanisms इस limitation को दूर करते हैं, क्योंकि वे model को प्रत्येक output token को generate करते समय सभी input tokens पर विचार करने की अनुमति देते हैं।

#### Example: Machine Translation

German sentence "Kannst du mir helfen diesen Satz zu übersetzen" को English में translate करने पर विचार करें। Word-by-word translation से grammatically correct English sentence नहीं बनेगा, क्योंकि languages की grammatical structures अलग होती हैं। Attention mechanism model को output sentence के प्रत्येक word को generate करते समय input sentence के relevant parts पर ध्यान केंद्रित करने में सक्षम बनाता है, जिससे अधिक accurate और coherent translation प्राप्त होती है।

### Self-Attention का परिचय

Self-attention, या intra-attention, एक ऐसा mechanism है जिसमें किसी sequence की representation compute करने के लिए उसी single sequence के भीतर attention लागू किया जाता है। यह sequence के प्रत्येक token को अन्य सभी tokens पर attend करने की अनुमति देता है, जिससे model sequence में उनकी दूरी की परवाह किए बिना tokens के बीच dependencies को capture कर पाता है।

#### मुख्य Concepts

- **Tokens**: Input sequence के individual elements (जैसे, sentence में words)।
- **Embeddings**: Tokens की vector representations, जो semantic information को capture करती हैं।
- **Attention Weights**: वे values जो अन्य tokens की तुलना में प्रत्येक token का importance निर्धारित करती हैं।

1. **Attention Scores Compute करें**: Target word की embedding और sequence के सभी words की embeddings के बीच dot product का उपयोग करें।
2. **Weights प्राप्त करने के लिए Scores को Normalize करें**: Attention scores पर softmax function लागू करके ऐसे weights प्राप्त करें जिनका sum 1 हो।

### Code Example

[https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb) से एक उदाहरण लेते हुए, आप इस class को देख सकते हैं जो उस self-attendant functionality को implement करती है जिसके बारे में हमने चर्चा की थी:<sup>[[2]](#references)</sup>
```python
import torch

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

import torch.nn as nn
class SelfAttention_v2(nn.Module):

def __init__(self, d_in, d_out, qkv_bias=False):
super().__init__()
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)

def forward(self, x):
keys = self.W_key(x)
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.T
attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)

context_vec = attn_weights @ values
return context_vec

d_in=3
d_out=2
torch.manual_seed(789)
sa_v2 = SelfAttention_v2(d_in, d_out)
print(sa_v2(inputs))
```
> [!TIP]
> ध्यान दें कि matrices को random values से initialize करने के बजाय, सभी weights को train किए जाने वाले parameters के रूप में चिह्नित करने के लिए `nn.Linear` का उपयोग किया जाता है।

## Causal Attention: Future Words को छिपाना

LLMs के लिए हम चाहते हैं कि model **next token को predict** करने के लिए केवल उन tokens पर विचार करे जो current position से पहले दिखाई देते हैं। **Causal attention**, जिसे **masked attention** के रूप में भी जाना जाता है, future tokens तक access को रोकने के लिए attention mechanism को modify करके इसे प्राप्त करता है।<sup>[[1]](#references)</sup>

### Causal Attention Mask लागू करना

Causal attention को implement करने के लिए, हम **softmax operation से पहले** attention scores पर एक mask लागू करते हैं, ताकि बचे हुए scores का योग 1 ही रहे। यह mask future tokens के attention scores को negative infinity पर set करता है, जिससे softmax के बाद उनके attention weights zero हो जाते हैं।

**Steps**

1. **Attention Scores compute करें**: पहले की तरह।
2. **Mask लागू करें**: diagonal के ऊपर negative infinity से भरी upper triangular matrix का उपयोग करें।

```python
mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1) * float('-inf')
masked_scores = attention_scores + mask
```

3. **Softmax लागू करें**: masked scores का उपयोग करके attention weights compute करें।

```python
attention_weights = torch.softmax(masked_scores, dim=-1)
```

### Dropout के साथ Additional Attention Weights को Mask करना

**overfitting को रोकने** के लिए, हम softmax operation के बाद attention weights पर **dropout** लागू कर सकते हैं। Training के दौरान dropout **कुछ attention weights को randomly zero कर देता है**।
```python
dropout = nn.Dropout(p=0.5)
attention_weights = dropout(attention_weights)
```
एक सामान्य dropout लगभग 10-20% होता है।

### Code Example

[https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb) से Code example:<sup>[[2]](#references)</sup>
```python
import torch
import torch.nn as nn

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

batch = torch.stack((inputs, inputs), dim=0)
print(batch.shape)

class CausalAttention(nn.Module):

def __init__(self, d_in, d_out, context_length,
dropout, qkv_bias=False):
super().__init__()
self.d_out = d_out
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.dropout = nn.Dropout(dropout)
self.register_buffer('mask', torch.triu(torch.ones(context_length, context_length), diagonal=1)) # New

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # This generates the keys of the tokens
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.transpose(1, 2) # Moves the third dimension to the second one and the second one to the third one to be able to multiply
attn_scores.masked_fill_(  # New, _ ops are in-place
self.mask.bool()[:num_tokens, :num_tokens], -torch.inf)  # `:num_tokens` to account for cases where the number of tokens in the batch is smaller than the supported context_size
attn_weights = torch.softmax(
attn_scores / keys.shape[-1]**0.5, dim=-1
)
attn_weights = self.dropout(attn_weights)

context_vec = attn_weights @ values
return context_vec

torch.manual_seed(123)

context_length = batch.shape[1]
d_in = 3
d_out = 2
ca = CausalAttention(d_in, d_out, context_length, 0.0)

context_vecs = ca(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)
```
## Single-Head Attention को Multi-Head Attention तक विस्तारित करना

व्यावहारिक रूप से, **multi-head attention** कई self-attention heads को execute करता है, जिनमें से प्रत्येक के पास **अपने स्वयं के learned projections** होते हैं, और उनके outputs को संयोजित करता है।<sup>[[1]](#references)</sup>

### Code Example

पिछले implementation को wrap करके प्रत्येक head के लिए एक बार invoke किया जा सकता था, लेकिन निम्नलिखित optimized version सभी heads को एक साथ process करता है और महंगे Python loops से बचता है। Embedding dimension को heads के बीच समान रूप से विभाजित किया जाता है: उदाहरण के लिए, दो heads वाला eight-dimensional token embedding प्रत्येक head को चार dimensions देता है। इसलिए, `d_out` को `num_heads` से विभाज्य होना आवश्यक है।<sup>[[2]](#references)</sup>
```python
class MultiHeadAttention(nn.Module):
def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
super().__init__()
assert (d_out % num_heads == 0), \
"d_out must be divisible by num_heads"

self.d_out = d_out
self.num_heads = num_heads
self.head_dim = d_out // num_heads # Reduce the projection dim to match desired output dim

self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.out_proj = nn.Linear(d_out, d_out)  # Linear layer to combine head outputs
self.dropout = nn.Dropout(dropout)
self.register_buffer(
"mask",
torch.triu(torch.ones(context_length, context_length),
diagonal=1)
)

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # Shape: (b, num_tokens, d_out)
queries = self.W_query(x)
values = self.W_value(x)

# We implicitly split the matrix by adding a `num_heads` dimension
# Unroll last dim: (b, num_tokens, d_out) -> (b, num_tokens, num_heads, head_dim)
keys = keys.view(b, num_tokens, self.num_heads, self.head_dim)
values = values.view(b, num_tokens, self.num_heads, self.head_dim)
queries = queries.view(b, num_tokens, self.num_heads, self.head_dim)

# Transpose: (b, num_tokens, num_heads, head_dim) -> (b, num_heads, num_tokens, head_dim)
keys = keys.transpose(1, 2)
queries = queries.transpose(1, 2)
values = values.transpose(1, 2)

# Compute scaled dot-product attention (aka self-attention) with a causal mask
attn_scores = queries @ keys.transpose(2, 3)  # Dot product for each head

# Original mask truncated to the number of tokens and converted to boolean
mask_bool = self.mask.bool()[:num_tokens, :num_tokens]

# Use the mask to fill attention scores
attn_scores.masked_fill_(mask_bool, -torch.inf)

attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)
attn_weights = self.dropout(attn_weights)

# Shape: (b, num_tokens, num_heads, head_dim)
context_vec = (attn_weights @ values).transpose(1, 2)

# Combine heads, where self.d_out = self.num_heads * self.head_dim
context_vec = context_vec.contiguous().view(b, num_tokens, self.d_out)
context_vec = self.out_proj(context_vec) # optional projection

return context_vec

torch.manual_seed(123)

batch_size, context_length, d_in = batch.shape
d_out = 2
mha = MultiHeadAttention(d_in, d_out, context_length, 0.0, num_heads=2)

context_vecs = mha(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)

```
एक और compact और efficient implementation के लिए आप PyTorch में [`torch.nn.MultiheadAttention`](https://pytorch.org/docs/stable/generated/torch.nn.MultiheadAttention.html) class का उपयोग कर सकते हैं।

> [!TIP]
> प्रत्येक head को सभी tokens के सभी dimensions जाँचने देने के बजाय, tokens के dimensions को heads के बीच बाँटना बेहतर क्यों है, इस बारे में ChatGPT का संक्षिप्त उत्तर:
>
> हालांकि प्रत्येक head को सभी embedding dimensions पर process करने की अनुमति देना लाभदायक लग सकता है, क्योंकि तब प्रत्येक head को पूरी information तक पहुँच मिलती, standard practice **embedding dimensions को heads के बीच बाँटना** है। यह तरीका computational efficiency और model performance के बीच संतुलन बनाता है और प्रत्येक head को diverse representations सीखने के लिए प्रोत्साहित करता है। इसलिए, प्रत्येक head से सभी dimensions की जाँच करवाने की तुलना में embedding dimensions को split करना सामान्यतः बेहतर माना जाता है।
