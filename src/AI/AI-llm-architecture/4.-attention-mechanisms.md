## Μηχανισμοί Attention και Self-Attention σε Νευρωνικά Δίκτυα

Οι μηχανισμοί Attention επιτρέπουν στα νευρωνικά δίκτυα να **εστιάζουν σε συγκεκριμένα μέρη της εισόδου κατά τη δημιουργία κάθε μέρους της εξόδου**. Αποδίδουν διαφορετικά βάρη σε διαφορετικές εισόδους, βοηθώντας το μοντέλο να αποφασίσει ποιες είσοδοι είναι πιο σχετικές με την εκάστοτε εργασία. Αυτό είναι κρίσιμο σε εργασίες όπως η μηχανική μετάφραση, όπου η κατανόηση του πλαισίου ολόκληρης της πρότασης είναι απαραίτητη για ακριβή μετάφραση.<sup>[[1]](#references)</sup>

> [!TIP]
> Ο στόχος αυτής της τέταρτης φάσης είναι πολύ απλός: **Εφαρμογή ορισμένων μηχανισμών attention**. Πρόκειται να χρησιμοποιηθούν πολλές **επαναλαμβανόμενες στρώσεις**, οι οποίες θα **καταγράφουν τη σχέση μιας λέξης στο λεξιλόγιο με τους γείτονές της στην τρέχουσα πρόταση που χρησιμοποιείται για την εκπαίδευση του LLM**.\
> Για αυτό χρησιμοποιούνται πολλές στρώσεις, επομένως πολλά trainable parameters θα καταγράφουν αυτές τις πληροφορίες.

### Κατανόηση των Μηχανισμών Attention

Στα παραδοσιακά μοντέλα sequence-to-sequence που χρησιμοποιούνται για γλωσσική μετάφραση, το μοντέλο κωδικοποιεί μια sequence εισόδου σε ένα context vector σταθερού μεγέθους. Ωστόσο, αυτή η προσέγγιση δυσκολεύεται με μεγάλες προτάσεις, επειδή το context vector σταθερού μεγέθους ενδέχεται να μην καταγράφει όλες τις απαραίτητες πληροφορίες. Οι μηχανισμοί Attention αντιμετωπίζουν αυτόν τον περιορισμό επιτρέποντας στο μοντέλο να εξετάζει όλα τα tokens εισόδου κατά τη δημιουργία κάθε token εξόδου.

#### Παράδειγμα: Μηχανική Μετάφραση

Ας εξετάσουμε τη μετάφραση της γερμανικής πρότασης "Kannst du mir helfen diesen Satz zu übersetzen" στα αγγλικά. Μια μετάφραση λέξη προς λέξη δεν θα παρήγαγε γραμματικά σωστή αγγλική πρόταση, λόγω των διαφορών στη γραμματική δομή μεταξύ των γλωσσών. Ένας μηχανισμός attention επιτρέπει στο μοντέλο να εστιάζει στα σχετικά μέρη της πρότασης εισόδου κατά τη δημιουργία κάθε λέξης της πρότασης εξόδου, οδηγώντας σε πιο ακριβή και συνεκτική μετάφραση.

### Εισαγωγή στο Self-Attention

Το self-attention, ή intra-attention, είναι ένας μηχανισμός όπου το attention εφαρμόζεται μέσα σε μία sequence για τον υπολογισμό μιας αναπαράστασης αυτής της sequence. Επιτρέπει σε κάθε token της sequence να προσέχει όλα τα υπόλοιπα tokens, βοηθώντας το μοντέλο να καταγράφει εξαρτήσεις μεταξύ tokens ανεξάρτητα από την απόστασή τους στη sequence.

#### Βασικές Έννοιες

- **Tokens**: Μεμονωμένα στοιχεία της sequence εισόδου (π.χ. λέξεις σε μια πρόταση).
- **Embeddings**: Διανυσματικές αναπαραστάσεις των tokens, οι οποίες καταγράφουν σημασιολογικές πληροφορίες.
- **Attention Weights**: Τιμές που καθορίζουν τη σημασία κάθε token σε σχέση με τα υπόλοιπα.

Παίρνοντας ένα παράδειγμα από το [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb), μπορείτε να δείτε αυτήν την κλάση που υλοποιεί τη λειτουργικότητα self-attention για την οποία μιλήσαμε:<sup>[[2]](#references)</sup>
```python
import torch

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

import torch.nn as nn
class SelfAttention_v2(nn.Module):

def __init__(self, d_in, d_out, qkv_bias=False):
super().__init__()
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)

def forward(self, x):
keys = self.W_key(x)
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.T
attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)

context_vec = attn_weights @ values
return context_vec

d_in=3
d_out=2
torch.manual_seed(789)
sa_v2 = SelfAttention_v2(d_in, d_out)
print(sa_v2(inputs))
```

## Causal Attention: Απόκρυψη μελλοντικών λέξεων

Για τα LLMs, θέλουμε το μοντέλο να λαμβάνει υπόψη μόνο τα tokens που εμφανίζονται πριν από την τρέχουσα θέση, ώστε να **προβλέπει το επόμενο token**. Το **Causal attention**, γνωστό και ως **masked attention**, το επιτυγχάνει τροποποιώντας τον μηχανισμό attention, ώστε να αποτρέπει την πρόσβαση σε μελλοντικά tokens.<sup>[[1]](#references)</sup>

### Εφαρμογή μάσκας Causal Attention

Για την υλοποίηση του causal attention, εφαρμόζουμε μια μάσκα στα attention scores **πριν από τη λειτουργία softmax**, ώστε τα εναπομείναντα scores να έχουν άθροισμα 1. Αυτή η μάσκα θέτει τα attention scores των μελλοντικών tokens σε αρνητικό άπειρο, διασφαλίζοντας ότι μετά το softmax τα αντίστοιχα attention weights είναι μηδενικά.

**Βήματα**

1. **Υπολογισμός Attention Scores**: Όπως και πριν.
2. **Εφαρμογή μάσκας**: Χρησιμοποιήστε έναν άνω τριγωνικό πίνακα, συμπληρωμένο με αρνητικό άπειρο πάνω από τη διαγώνιο.

```python
mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1) * float('-inf')
masked_scores = attention_scores + mask
```

3. **Εφαρμογή Softmax**: Υπολογίστε τα attention weights χρησιμοποιώντας τα masked scores.

```python
attention_weights = torch.softmax(masked_scores, dim=-1)
```

### Masking επιπλέον Attention Weights με Dropout

Για να **αποτρέψουμε το overfitting**, μπορούμε να εφαρμόσουμε **dropout** στα attention weights μετά τη λειτουργία softmax. Το Dropout **μηδενίζει τυχαία ορισμένα από τα attention weights** κατά την εκπαίδευση.
```python
dropout = nn.Dropout(p=0.5)
attention_weights = dropout(attention_weights)
```
Ένα τυπικό dropout είναι περίπου 10-20%.

### Παράδειγμα κώδικα

Παράδειγμα κώδικα από [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb):<sup>[[2]](#references)</sup>
```python
import torch
import torch.nn as nn

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

batch = torch.stack((inputs, inputs), dim=0)
print(batch.shape)

class CausalAttention(nn.Module):

def __init__(self, d_in, d_out, context_length,
dropout, qkv_bias=False):
super().__init__()
self.d_out = d_out
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.dropout = nn.Dropout(dropout)
self.register_buffer('mask', torch.triu(torch.ones(context_length, context_length), diagonal=1)) # New

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # This generates the keys of the tokens
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.transpose(1, 2) # Moves the third dimension to the second one and the second one to the third one to be able to multiply
attn_scores.masked_fill_(  # New, _ ops are in-place
self.mask.bool()[:num_tokens, :num_tokens], -torch.inf)  # `:num_tokens` to account for cases where the number of tokens in the batch is smaller than the supported context_size
attn_weights = torch.softmax(
attn_scores / keys.shape[-1]**0.5, dim=-1
)
attn_weights = self.dropout(attn_weights)

context_vec = attn_weights @ values
return context_vec

torch.manual_seed(123)

context_length = batch.shape[1]
d_in = 3
d_out = 2
ca = CausalAttention(d_in, d_out, context_length, 0.0)

context_vecs = ca(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)
```
## Επέκταση του Single-Head Attention σε Multi-Head Attention

Σε πρακτικούς όρους, το **multi-head attention** εκτελεί πολλαπλά self-attention heads, καθένα με **τις δικές του εκπαιδευμένες προβολές**, και συνδυάζει τις εξόδους τους.<sup>[[1]](#references)</sup>

### Παράδειγμα κώδικα

Η προηγούμενη υλοποίηση θα μπορούσε να τυλιχτεί και να κληθεί μία φορά ανά head, όμως η ακόλουθη βελτιστοποιημένη έκδοση επεξεργάζεται όλα τα heads μαζί και αποφεύγει τους δαπανηρούς βρόχους Python. Η διάσταση του embedding διαιρείται ισόποσα μεταξύ των heads: για παράδειγμα, ένα token embedding οκτώ διαστάσεων με δύο heads δίνει σε κάθε head τέσσερις διαστάσεις. Κατά συνέπεια, το `d_out` πρέπει να διαιρείται ακριβώς με το `num_heads`.<sup>[[2]](#references)</sup>
```python
class MultiHeadAttention(nn.Module):
def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
super().__init__()
assert (d_out % num_heads == 0), \
"d_out must be divisible by num_heads"

self.d_out = d_out
self.num_heads = num_heads
self.head_dim = d_out // num_heads # Reduce the projection dim to match desired output dim

self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.out_proj = nn.Linear(d_out, d_out)  # Linear layer to combine head outputs
self.dropout = nn.Dropout(dropout)
self.register_buffer(
"mask",
torch.triu(torch.ones(context_length, context_length),
diagonal=1)
)

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # Shape: (b, num_tokens, d_out)
queries = self.W_query(x)
values = self.W_value(x)

# We implicitly split the matrix by adding a `num_heads` dimension
# Unroll last dim: (b, num_tokens, d_out) -> (b, num_tokens, num_heads, head_dim)
keys = keys.view(b, num_tokens, self.num_heads, self.head_dim)
values = values.view(b, num_tokens, self.num_heads, self.head_dim)
queries = queries.view(b, num_tokens, self.num_heads, self.head_dim)

# Transpose: (b, num_tokens, num_heads, head_dim) -> (b, num_heads, num_tokens, head_dim)
keys = keys.transpose(1, 2)
queries = queries.transpose(1, 2)
values = values.transpose(1, 2)

# Compute scaled dot-product attention (aka self-attention) with a causal mask
attn_scores = queries @ keys.transpose(2, 3)  # Dot product for each head

# Original mask truncated to the number of tokens and converted to boolean
mask_bool = self.mask.bool()[:num_tokens, :num_tokens]

# Use the mask to fill attention scores
attn_scores.masked_fill_(mask_bool, -torch.inf)

attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)
attn_weights = self.dropout(attn_weights)

# Shape: (b, num_tokens, num_heads, head_dim)
context_vec = (attn_weights @ values).transpose(1, 2)

# Combine heads, where self.d_out = self.num_heads * self.head_dim
context_vec = context_vec.contiguous().view(b, num_tokens, self.d_out)
context_vec = self.out_proj(context_vec) # optional projection

return context_vec

torch.manual_seed(123)

batch_size, context_length, d_in = batch.shape
d_out = 2
mha = MultiHeadAttention(d_in, d_out, context_length, 0.0, num_heads=2)

context_vecs = mha(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)

```
Για μια ακόμη συμπαγή και αποδοτική υλοποίηση, θα μπορούσατε να χρησιμοποιήσετε την κλάση [`torch.nn.MultiheadAttention`](https://pytorch.org/docs/stable/generated/torch.nn.MultiheadAttention.html) στο PyTorch.

> [!TIP]
> Σύντομη απάντηση του ChatGPT σχετικά με το γιατί είναι καλύτερο να διαιρούνται οι διαστάσεις των tokens μεταξύ των heads αντί κάθε head να ελέγχει όλες τις διαστάσεις όλων των tokens:
>
> Παρόλο που το να επιτρέπεται σε κάθε head να επεξεργάζεται όλες τις διαστάσεις των embeddings μπορεί να φαίνεται πλεονεκτικό, επειδή κάθε head θα είχε πρόσβαση σε ολόκληρη την πληροφορία, η συνήθης πρακτική είναι να **διαιρούνται οι διαστάσεις των embeddings μεταξύ των heads**. Αυτή η προσέγγιση εξισορροπεί την υπολογιστική αποδοτικότητα με την απόδοση του μοντέλου και ενθαρρύνει κάθε head να μαθαίνει διαφορετικές αναπαραστάσεις. Επομένως, ο διαχωρισμός των διαστάσεων των embeddings προτιμάται γενικά από το να ελέγχει κάθε head όλες τις διαστάσεις.
