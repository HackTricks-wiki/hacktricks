## 神经网络中的注意力机制与 Self-Attention

注意力机制允许神经网络在生成输出的**每一部分时，聚**焦于输入的特定部分。它们会为不同的输入分配不同的权重，帮助模型判断哪些输入与当前任务最相关。这对于机器翻译等任务至关重要，因为要实现准确翻译，就必须理解整个句子的上下文。<sup>[[1]](#references)</sup>

> [!TIP]
> 第四阶段的目标非常简单：**应用一些注意力机制**。这些机制将由大量**重复层**组成，用于**捕获词汇中的某个词与当前用于训练 LLM 的句子中其邻近词之间的关系**。\
> 这需要使用大量层，因此会有大量可训练参数用于捕获这些信息。

### 理解注意力机制

在用于语言翻译的传统序列到序列模型中，模型会将输入序列编码为固定大小的上下文向量。然而，这种方法在处理长句子时会遇到困难，因为固定大小的上下文向量可能无法捕获所有必要信息。注意力机制通过允许模型在生成每个输出 token 时考虑所有输入 token，解决了这一限制。

#### 示例：机器翻译

考虑将德语句子 "Kannst du mir helfen diesen Satz zu übersetzen" 翻译成英语。由于不同语言之间的语法结构存在差异，逐词翻译无法生成语法正确的英语句子。注意力机制允许模型在生成输出句子的每个单词时，聚焦于输入句子中相关的部分，从而得到更准确、更连贯的翻译。

### Self-Attention 简介

Self-Attention 或 intra-attention 是一种在单个序列内部应用注意力机制，以计算该序列表示的方法。它允许序列中的每个 token 关注所有其他 token，帮助模型捕获 token 之间的依赖关系，而不受它们在序列中距离的影响。

#### 核心概念

- **Tokens**：输入序列中的单个元素（例如句子中的单词）。
- **Embeddings**：token 的向量表示，用于捕获语义信息。
- **Attention Weights**：用于确定每个 token 相对于其他 token 的重要性的值。

1. **计算注意力分数**：使用目标单词的 embedding 与序列中所有单词 embedding 之间的点积。
2. **将分数归一化以获得注意力权重**：对注意力分数应用 softmax 函数，得到总和为 1 的权重。
3. **计算上下文向量**：将每个单词的 embedding 乘以其注意力权重，然后将结果相加。

## 使用可训练权重的 Self-Attention

在实际应用中，self-attention 机制会使用**可训练权重**，以学习 query、key 和 value 的最佳表示。这涉及引入三个权重矩阵：<sup>[[1]](#references)</sup>

<figure><img src="../../images/image (10) (1) (1).png" alt="" width="239"><figcaption></figcaption></figure>

query 是像之前一样要使用的数据，而 key 和 value 矩阵只是随机的可训练矩阵。

#### 第 1 步：计算 Queries、Keys 和 Values

每个 token 都会拥有自己的 query、key 和 value 矩阵，方法是将其维度值与定义好的矩阵相乘：

<figure><img src="../../images/image (11).png" alt="" width="253"><figcaption></figcaption></figure>

这些矩阵会将原始 embedding 转换到一个适合计算注意力的新空间中。

**示例**

假设：

- 输入维度 `din=3`（embedding 大小）
- 输出维度 `dout=2`（query、key 和 value 所需的维度）

初始化权重矩阵：
```python
import torch.nn as nn

d_in = 3
d_out = 2

W_query = nn.Parameter(torch.rand(d_in, d_out))
W_key = nn.Parameter(torch.rand(d_in, d_out))
W_value = nn.Parameter(torch.rand(d_in, d_out))
```
计算查询、键和值：
```python
queries = torch.matmul(inputs, W_query)
keys = torch.matmul(inputs, W_key)
values = torch.matmul(inputs, W_value)
```
#### 步骤 2：计算缩放点积注意力

**计算注意力分数**

与前面的示例类似，但这一次，我们不使用 token 各维度的值，而是使用 token 的 key 矩阵（已通过这些维度计算得出）：因此，对于每个 query `qi`​ 和 key `kj​`：

**缩放分数**

为了防止点积变得过大，将其除以 key 维度 `dk`​ 的平方根进行缩放：

<figure><img src="../../images/image (13).png" alt="" width="295"><figcaption></figcaption></figure>

> [!TIP]
> 将分数除以维度的平方根，是因为点积可能会变得非常大，而这样可以帮助调节它们。

**应用 Softmax 以获得注意力权重：** 与最初的示例一样，将所有值归一化，使它们的总和为 1。

### 代码示例

以下示例来自 [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb)，你可以查看这个实现了我们所讨论的 self-attention 功能的类：<sup>[[2]](#references)</sup>
```python
import torch

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

import torch.nn as nn
class SelfAttention_v2(nn.Module):

def __init__(self, d_in, d_out, qkv_bias=False):
super().__init__()
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)

def forward(self, x):
keys = self.W_key(x)
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.T
attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)

context_vec = attn_weights @ values
return context_vec

d_in=3
d_out=2
torch.manual_seed(789)
sa_v2 = SelfAttention_v2(d_in, d_out)
print(sa_v2(inputs))
```
> [!TIP]
> 注意，与其使用随机值初始化矩阵，不如使用 `nn.Linear` 将所有权重标记为可训练参数。

## Causal Attention：隐藏未来词元

对于 LLMs，我们希望模型仅考虑当前⁠位置之前出现的 tokens，以便**预测下一个 token**。**Causal attention** 也称为 **masked attention**，它通过修改 attention 机制来阻止访问未来 tokens，从而实现这一点。<sup>[[1]](#references)</sup>

### 应用 Causal Attention Mask

要实现 causal attention，我们会在 **softmax 操作之前**对 attention scores 应用 mask，这样剩余的 attention weights 仍会总和为 1。该 mask 会将未来 tokens 的 attention scores 设置为负无穷，确保经过 softmax 后，它们的 attention weights 为零。

**步骤**

1. **计算 Attention Scores**：与之前相同。
2. **应用 Mask**：使用一个上三角矩阵，将对角线以上的值填充为负无穷。

```python
mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1) * float('-inf')
masked_scores = attention_scores + mask
```

3. **应用 Softmax**：使用 masked scores 计算 attention weights。

```python
attention_weights = torch.softmax(masked_scores, dim=-1)
```

### 使用 Dropout Masking 额外的 Attention Weights

为了**防止过拟合**，我们可以在 softmax 操作之后对 attention weights 应用 **dropout**。Dropout 会在训练期间**随机将部分 attention weights 置零**。
```python
dropout = nn.Dropout(p=0.5)
attention_weights = dropout(attention_weights)
```
常规 dropout 约为 10-20%。

### 代码示例

代码示例来自 [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb)：<sup>[[2]](#references)</sup>
```python
import torch
import torch.nn as nn

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

batch = torch.stack((inputs, inputs), dim=0)
print(batch.shape)

class CausalAttention(nn.Module):

def __init__(self, d_in, d_out, context_length,
dropout, qkv_bias=False):
super().__init__()
self.d_out = d_out
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.dropout = nn.Dropout(dropout)
self.register_buffer('mask', torch.triu(torch.ones(context_length, context_length), diagonal=1)) # New

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # This generates the keys of the tokens
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.transpose(1, 2) # Moves the third dimension to the second one and the second one to the third one to be able to multiply
attn_scores.masked_fill_(  # New, _ ops are in-place
self.mask.bool()[:num_tokens, :num_tokens], -torch.inf)  # `:num_tokens` to account for cases where the number of tokens in the batch is smaller than the supported context_size
attn_weights = torch.softmax(
attn_scores / keys.shape[-1]**0.5, dim=-1
)
attn_weights = self.dropout(attn_weights)

context_vec = attn_weights @ values
return context_vec

torch.manual_seed(123)

context_length = batch.shape[1]
d_in = 3
d_out = 2
ca = CausalAttention(d_in, d_out, context_length, 0.0)

context_vecs = ca(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)
```
## 将单头注意力扩展为多头注意力

**多头注意力**在实际中是指执行**自注意力**函数的**多个实例**，每个实例都使用**各自的权重**，从而计算出不同的最终向量。<sup>[[1]](#references)</sup>

### 代码示例

可以复用之前的代码，只需添加一个 wrapper 来多次启动它；不过，下面是一个来自 [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb) 的优化版本，它会同时处理所有 head（减少开销较大的 for loops 数量）。如你在代码中所见，每个 token 的维度会根据 head 的数量被划分为不同的维度。这样，如果 token 有 8 个维度，而我们希望使用 3 个 head，这些维度将被划分为 2 个包含 4 个维度的数组，每个 head 使用其中一个：<sup>[[2]](#references)</sup>
```python
class MultiHeadAttention(nn.Module):
def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
super().__init__()
assert (d_out % num_heads == 0), \
"d_out must be divisible by num_heads"

self.d_out = d_out
self.num_heads = num_heads
self.head_dim = d_out // num_heads # Reduce the projection dim to match desired output dim

self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.out_proj = nn.Linear(d_out, d_out)  # Linear layer to combine head outputs
self.dropout = nn.Dropout(dropout)
self.register_buffer(
"mask",
torch.triu(torch.ones(context_length, context_length),
diagonal=1)
)

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # Shape: (b, num_tokens, d_out)
queries = self.W_query(x)
values = self.W_value(x)

# We implicitly split the matrix by adding a `num_heads` dimension
# Unroll last dim: (b, num_tokens, d_out) -> (b, num_tokens, num_heads, head_dim)
keys = keys.view(b, num_tokens, self.num_heads, self.head_dim)
values = values.view(b, num_tokens, self.num_heads, self.head_dim)
queries = queries.view(b, num_tokens, self.num_heads, self.head_dim)

# Transpose: (b, num_tokens, num_heads, head_dim) -> (b, num_heads, num_tokens, head_dim)
keys = keys.transpose(1, 2)
queries = queries.transpose(1, 2)
values = values.transpose(1, 2)

# Compute scaled dot-product attention (aka self-attention) with a causal mask
attn_scores = queries @ keys.transpose(2, 3)  # Dot product for each head

# Original mask truncated to the number of tokens and converted to boolean
mask_bool = self.mask.bool()[:num_tokens, :num_tokens]

# Use the mask to fill attention scores
attn_scores.masked_fill_(mask_bool, -torch.inf)

attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)
attn_weights = self.dropout(attn_weights)

# Shape: (b, num_tokens, num_heads, head_dim)
context_vec = (attn_weights @ values).transpose(1, 2)

# Combine heads, where self.d_out = self.num_heads * self.head_dim
context_vec = context_vec.contiguous().view(b, num_tokens, self.d_out)
context_vec = self.out_proj(context_vec) # optional projection

return context_vec

torch.manual_seed(123)

batch_size, context_length, d_in = batch.shape
d_out = 2
mha = MultiHeadAttention(d_in, d_out, context_length, 0.0, num_heads=2)

context_vecs = mha(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)

```
对于另一种紧凑且高效的实现，你可以在 PyTorch 中使用 [`torch.nn.MultiheadAttention`](https://pytorch.org/docs/stable/generated/torch.nn.MultiheadAttention.html) 类。

> [!TIP]
> ChatGPT 关于为什么应该将 token 的维度分配给各个 head，而不是让每个 head 检查所有 token 的全部维度的简短回答：
>
> 虽然让每个 head 处理所有 embedding 维度看起来可能更有优势，因为每个 head 都能访问完整信息，但标准做法是**将 embedding 维度分配给各个 head**。这种方法在计算效率与模型性能之间取得了平衡，并鼓励每个 head 学习多样化的表示。因此，与让每个 head 检查所有维度相比，拆分 embedding 维度通常是更优的选择。
