## Mifumo ya Attention na Self-Attention katika Neural Networks

Mifumo ya attention huruhusu neural networks **kuzingatia sehemu mahususi za input wakati wa kuzalisha kila sehemu ya output**. Huweka uzito tofauti kwa inputs tofauti, na kusaidia model kuamua ni inputs zipi zina umuhimu zaidi kwa kazi inayofanywa. Hili ni muhimu katika kazi kama machine translation, ambapo kuelewa muktadha wa sentensi nzima ni muhimu ili kupata tafsiri sahihi.<sup>[[1]](#references)</sup>

> [!TIP]
> Lengo la awamu hii ya nne ni rahisi sana: **Tumia baadhi ya mifumo ya attention**. Hii itakuwa seti ya **layers zinazojirudia** ambazo zitaenda **kunasa uhusiano wa neno katika vocabulary na majirani zake katika sentensi ya sasa inayotumika kufunza LLM**.\
> Layers nyingi hutumika kwa hili, kwa hiyo trainable parameters nyingi zitanasa taarifa hii.

### Kuelewa Mifumo ya Attention

Katika traditional sequence-to-sequence models zinazotumika kwa language translation, model husimba input sequence kuwa context vector yenye ukubwa usiobadilika. Hata hivyo, mbinu hii hukumbwa na changamoto katika sentensi ndefu kwa sababu context vector yenye ukubwa usiobadilika huenda isinaswe taarifa zote zinazohitajika. Mifumo ya attention hushughulikia kikomo hiki kwa kuruhusu model kuzingatia input tokens zote wakati wa kuzalisha kila output token.

#### Mfano: Machine Translation

Fikiria kutafsiri sentensi ya Kijerumani "Kannst du mir helfen diesen Satz zu übersetzen" kwenda Kiingereza. Tafsiri ya neno kwa neno haitazalisha sentensi ya Kiingereza yenye sarufi sahihi kutokana na tofauti za miundo ya kisarufi kati ya lugha. Mfumo wa attention huwezesha model kuzingatia sehemu husika za input sentence wakati wa kuzalisha kila neno la output sentence, hivyo kupata tafsiri sahihi na yenye mtiririko mzuri zaidi.

### Utangulizi wa Self-Attention

Self-attention, au intra-attention, ni mfumo ambapo attention hutumika ndani ya sequence moja ili kukokotoa representation ya sequence hiyo. Huwezesha kila token katika sequence kuzingatia tokens nyingine zote, na kusaidia model kunasa dependencies kati ya tokens bila kujali umbali wao katika sequence.

#### Dhana Muhimu

- **Tokens**: Vipengele binafsi vya input sequence (kwa mfano, maneno katika sentensi).
- **Embeddings**: Vector representations za tokens, zinazonasa taarifa za kisemantiki.
- **Attention Weights**: Thamani zinazoamua umuhimu wa kila token ikilinganishwa na nyingine.

```python
import torch.nn as nn

d_in = 3
d_out = 2

W_query = nn.Parameter(torch.rand(d_in, d_out))
W_key = nn.Parameter(torch.rand(d_in, d_out))
W_value = nn.Parameter(torch.rand(d_in, d_out))
```
Kokotoa queries, keys, na values:
```python
queries = torch.matmul(inputs, W_query)
keys = torch.matmul(inputs, W_key)
values = torch.matmul(inputs, W_value)
```

### Mfano wa Code

Tukichukua mfano kutoka [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb), unaweza kuangalia class hii inayotekeleza utendaji wa self-attention tuliozungumzia:<sup>[[2]](#references)</sup>
```python
import torch

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

import torch.nn as nn
class SelfAttention_v2(nn.Module):

def __init__(self, d_in, d_out, qkv_bias=False):
super().__init__()
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)

def forward(self, x):
keys = self.W_key(x)
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.T
attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)

context_vec = attn_weights @ values
return context_vec

d_in=3
d_out=2
torch.manual_seed(789)
sa_v2 = SelfAttention_v2(d_in, d_out)
print(sa_v2(inputs))
```
> [!TIP]
> Kumbuka kwamba badala ya kuanzisha matrices kwa values za random, `nn.Linear` inatumika kuashiria kwamba weights zote ni parameters za train.

## Causal Attention: Kuficha Maneno ya Baadaye

Kwa LLMs tunataka model izingatie tokens zinazoonekana kabla ya position ya sasa pekee ili **kutabiri token inayofuata**. **Causal attention**, pia inajulikana kama **masked attention**, hutimiza hili kwa kurekebisha attention mechanism ili kuzuia ufikiaji wa tokens za baadaye.<sup>[[1]](#references)</sup>

### Kutumia Causal Attention Mask

Ili kutekeleza causal attention, tunatumia mask kwenye attention scores **kabla ya operesheni ya softmax** ili zilizosalia bado zijumlishe 1. Mask hii huweka attention scores za tokens za baadaye kuwa negative infinity, na kuhakikisha kwamba baada ya softmax, attention weights zake zinakuwa zero.

**Hatua**

1. **Kokotoa Attention Scores**: Sawa na hapo awali.
2. **Tumia Mask**: Tumia upper triangular matrix iliyojaa negative infinity juu ya diagonal.

```python
mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1) * float('-inf')
masked_scores = attention_scores + mask
```

3. **Tumia Softmax**: Kokotoa attention weights kwa kutumia masked scores.

```python
attention_weights = torch.softmax(masked_scores, dim=-1)
```

### Kumask Attention Weights za Ziada kwa Dropout

Ili **kuzuia overfitting**, tunaweza kutumia **dropout** kwenye attention weights baada ya operesheni ya softmax. Dropout **huweka baadhi ya attention weights kuwa zero kwa random** wakati wa training.
```python
dropout = nn.Dropout(p=0.5)
attention_weights = dropout(attention_weights)
```
Dropout ya kawaida huwa takriban 10–20%.

### Mfano wa Code

Mfano wa code kutoka [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb):<sup>[[2]](#references)</sup>
```python
import torch
import torch.nn as nn

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

batch = torch.stack((inputs, inputs), dim=0)
print(batch.shape)

class CausalAttention(nn.Module):

def __init__(self, d_in, d_out, context_length,
dropout, qkv_bias=False):
super().__init__()
self.d_out = d_out
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.dropout = nn.Dropout(dropout)
self.register_buffer('mask', torch.triu(torch.ones(context_length, context_length), diagonal=1)) # New

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # This generates the keys of the tokens
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.transpose(1, 2) # Moves the third dimension to the second one and the second one to the third one to be able to multiply
attn_scores.masked_fill_(  # New, _ ops are in-place
self.mask.bool()[:num_tokens, :num_tokens], -torch.inf)  # `:num_tokens` to account for cases where the number of tokens in the batch is smaller than the supported context_size
attn_weights = torch.softmax(
attn_scores / keys.shape[-1]**0.5, dim=-1
)
attn_weights = self.dropout(attn_weights)

context_vec = attn_weights @ values
return context_vec

torch.manual_seed(123)

context_length = batch.shape[1]
d_in = 3
d_out = 2
ca = CausalAttention(d_in, d_out, context_length, 0.0)

context_vecs = ca(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)
```
## Kupanua Single-Head Attention kuwa Multi-Head Attention

Kwa maneno ya kiutendaji, **multi-head attention** hutekeleza vichwa vingi vya self-attention, kila kimoja kikiwa na **projections zake zilizojifunza**, kisha huunganisha matokeo yake.<sup>[[1]](#references)</sup>

### Mfano wa Code

Utekelezaji wa awali ungeweza kufungwa na kuitwa mara moja kwa kila head, lakini toleo hili lililoboreshwa hushughulikia heads zote pamoja na kuepuka mizunguko ya gharama kubwa ya Python. Dimension ya embedding hugawanywa kwa usawa kati ya heads: kwa mfano, token embedding yenye dimensions nane na heads mbili huipa kila head dimensions nne. Kwa hiyo, `d_out` lazima igawanyike bila baki kwa `num_heads`.<sup>[[2]](#references)</sup>
```python
class MultiHeadAttention(nn.Module):
def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
super().__init__()
assert (d_out % num_heads == 0), \
"d_out must be divisible by num_heads"

self.d_out = d_out
self.num_heads = num_heads
self.head_dim = d_out // num_heads # Reduce the projection dim to match desired output dim

self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.out_proj = nn.Linear(d_out, d_out)  # Linear layer to combine head outputs
self.dropout = nn.Dropout(dropout)
self.register_buffer(
"mask",
torch.triu(torch.ones(context_length, context_length),
diagonal=1)
)

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # Shape: (b, num_tokens, d_out)
queries = self.W_query(x)
values = self.W_value(x)

# We implicitly split the matrix by adding a `num_heads` dimension
# Unroll last dim: (b, num_tokens, d_out) -> (b, num_tokens, num_heads, head_dim)
keys = keys.view(b, num_tokens, self.num_heads, self.head_dim)
values = values.view(b, num_tokens, self.num_heads, self.head_dim)
queries = queries.view(b, num_tokens, self.num_heads, self.head_dim)

# Transpose: (b, num_tokens, num_heads, head_dim) -> (b, num_heads, num_tokens, head_dim)
keys = keys.transpose(1, 2)
queries = queries.transpose(1, 2)
values = values.transpose(1, 2)

# Compute scaled dot-product attention (aka self-attention) with a causal mask
attn_scores = queries @ keys.transpose(2, 3)  # Dot product for each head

# Original mask truncated to the number of tokens and converted to boolean
mask_bool = self.mask.bool()[:num_tokens, :num_tokens]

# Use the mask to fill attention scores
attn_scores.masked_fill_(mask_bool, -torch.inf)

attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)
attn_weights = self.dropout(attn_weights)

# Shape: (b, num_tokens, num_heads, head_dim)
context_vec = (attn_weights @ values).transpose(1, 2)

# Combine heads, where self.d_out = self.num_heads * self.head_dim
context_vec = context_vec.contiguous().view(b, num_tokens, self.d_out)
context_vec = self.out_proj(context_vec) # optional projection

return context_vec

torch.manual_seed(123)

batch_size, context_length, d_in = batch.shape
d_out = 2
mha = MultiHeadAttention(d_in, d_out, context_length, 0.0, num_heads=2)

context_vecs = mha(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)

```
Kwa utekelezaji mwingine mfupi na wenye ufanisi, unaweza kutumia class ya [`torch.nn.MultiheadAttention`](https://pytorch.org/docs/stable/generated/torch.nn.MultiheadAttention.html) katika PyTorch.

> [!TIP]
> Jibu fupi la ChatGPT kuhusu kwa nini ni bora kugawa dimensions za tokens miongoni mwa heads badala ya kila head kukagua dimensions zote za tokens:
>
> Ingawa kuruhusu kila head kuchakata dimensions zote za embedding kunaweza kuonekana kuwa na faida kwa sababu kila head ingekuwa na ufikiaji wa taarifa kamili, utaratibu wa kawaida ni **kugawa dimensions za embedding miongoni mwa heads**. Mbinu hii husawazisha ufanisi wa computational na utendaji wa model, na kuhimiza kila head kujifunza representations tofauti. Kwa hivyo, kugawa dimensions za embedding kwa kawaida hupendelewa kuliko kufanya kila head ikague dimensions zote.
