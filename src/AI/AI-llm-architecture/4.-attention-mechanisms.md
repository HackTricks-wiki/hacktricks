## Neural Network'lerde Attention Mekanizmaları ve Self-Attention

Attention mekanizmaları, neural network'lerin çıktının her bir bölümünü oluştururken girdinin belirli bölümlerine **odaklanmasını** sağlar. Farklı girdilere farklı ağırlıklar atayarak modelin, ele alınan görev için hangi girdilerin en alakalı olduğuna karar vermesine yardımcı olurlar. Bu, doğru bir çeviri için tüm cümlenin bağlamını anlamanın gerekli olduğu machine translation gibi görevlerde kritik öneme sahiptir.<sup>[[1]](#references)</sup>

> [!TIP]
> Bu dördüncü aşamanın amacı oldukça basittir: **Bazı attention mekanizmalarını uygulamak**. Bunlar, **LLM'i eğitmek için kullanılan mevcut cümledeki bir kelimenin vocabulary'deki komşularıyla olan ilişkisini yakalayacak** çok sayıda **tekrarlanan katmandan** oluşacaktır.\
> Bunun için çok sayıda katman kullanılır; dolayısıyla çok sayıda trainable parameter bu bilgiyi yakalayacaktır.

### Attention Mekanizmalarını Anlamak

Language translation için kullanılan geleneksel sequence-to-sequence modellerinde model, bir input sequence'i sabit boyutlu bir context vector'e encode eder. Ancak sabit boyutlu context vector gerekli tüm bilgileri yakalayamayabileceğinden bu yaklaşım uzun cümlelerde zorlanır. Attention mekanizmaları, modelin her output token'ını oluştururken tüm input token'larını dikkate almasına izin vererek bu sınırlamayı giderir.

#### Örnek: Machine Translation

Almanca "Kannst du mir helfen diesen Satz zu übersetzen" cümlesini İngilizceye çevirdiğimizi düşünelim. Diller arasındaki grammatical structure farklılıkları nedeniyle kelime kelime çeviri grammatical olarak doğru bir İngilizce cümle oluşturmaz. Bir attention mekanizması, output cümlesindeki her kelimeyi oluştururken modelin input cümlesinin ilgili bölümlerine odaklanmasını sağlar ve böylece daha doğru ve tutarlı bir çeviri elde edilir.

### Self-Attention'a Giriş

Self-attention veya intra-attention, bir sequence'in temsilini hesaplamak için attention'ın tek bir sequence içinde uygulandığı bir mekanizmadır. Sequence'teki her token'ın diğer tüm token'lara attention uygulamasını sağlar ve modelin, sequence içindeki uzaklıklarından bağımsız olarak token'lar arasındaki bağımlılıkları yakalamasına yardımcı olur.

#### Temel Kavramlar

- **Token'lar**: Input sequence'in bireysel öğeleri (örneğin bir cümledeki kelimeler).
- **Embedding'ler**: Token'ların semantic bilgiyi yakalayan vector temsilleri.
- **Attention Weight'leri**: Her token'ın diğer token'lara göre önemini belirleyen değerler.

1. **Attention Score'larını Hesaplama**: Hedef kelimenin embedding'i ile sequence'teki tüm kelimelerin embedding'leri arasındaki dot product'ı kullanın.

3. **Context Vector'ü Hesaplama**: Her kelimenin embedding'ini attention weight'iyle çarpın ve sonuçları toplayın.

## Trainable Weight'lerle Self-Attention

Pratikte self-attention mekanizmaları, query, key ve value için en iyi temsilleri öğrenmek amacıyla **trainable weight'ler** kullanır. Bu işlem üç weight matrix'in tanıtılmasını içerir:<sup>[[1]](#references)</sup>

Query, öncekiyle aynı şekilde kullanılacak veridir; key ve value matrix'leri ise yalnızca random-trainable matrix'lerdir.

#### Adım 1: Query, Key ve Value'ları Hesaplama

Her token, boyut değerlerinin tanımlanmış matrix'lerle çarpılmasıyla kendine ait bir query, key ve value matrix'ine sahip olur:

<figure><img src="../../images/image (11).png" alt="" width="253"><figcaption></figcaption></figure>

Bu matrix'ler, orijinal embedding'leri attention hesaplamaya uygun yeni bir space'e dönüştürür.

**Örnek**

Şunların varsayıldığını düşünelim:

- Input dimension `din=3` (embedding size)
- Output dimension `dout=2` (query, key ve value'lar için istenen dimension)

Weight matrix'lerini initialize edin:
```python
import torch.nn as nn

d_in = 3
d_out = 2

W_query = nn.Parameter(torch.rand(d_in, d_out))
W_key = nn.Parameter(torch.rand(d_in, d_out))
W_value = nn.Parameter(torch.rand(d_in, d_out))
```
Sorguları, anahtarları ve değerleri hesaplama:
```python
queries = torch.matmul(inputs, W_query)
keys = torch.matmul(inputs, W_key)
values = torch.matmul(inputs, W_value)
```

### Code Example

[https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb) adresinden bir örnek alarak, bahsettiğimiz self-attention işlevselliğini uygulayan bu class'ı inceleyebilirsiniz:<sup>[[2]](#references)</sup>
```python
import torch

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

import torch.nn as nn
class SelfAttention_v2(nn.Module):

def __init__(self, d_in, d_out, qkv_bias=False):
super().__init__()
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)

def forward(self, x):
keys = self.W_key(x)
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.T
attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)

context_vec = attn_weights @ values
return context_vec

d_in=3
d_out=2
torch.manual_seed(789)
sa_v2 = SelfAttention_v2(d_in, d_out)
print(sa_v2(inputs))
```
> [!TIP]
> Matrisleri random değerlerle başlatmak yerine, tüm ağırlıkları train edilecek parametreler olarak işaretlemek için `nn.Linear` kullanıldığını unutmayın.

## Nedensel Attention: Gelecekteki Kelimeleri Gizleme

LLM'ler için modelin **bir sonraki token'ı tahmin edebilmesi** amacıyla yalnızca mevcut konumdan önce görünen token'ları dikkate almasını isteriz. **Nedensel attention**, **masked attention** olarak da bilinir ve gelecekteki token'lara erişimi engellemek için attention mekanizmasını değiştirerek bunu sağlar.<sup>[[1]](#references)</sup>

### Nedensel Attention Maskesi Uygulama

Nedensel attention'ı uygulamak için, kalan değerlerin toplamının yine 1 olması amacıyla attention skorlarına **softmax işleminden önce** bir maske uygularız. Bu maske, gelecekteki token'ların attention skorlarını negatif sonsuz olarak ayarlar ve böylece softmax sonrasında attention ağırlıkları sıfır olur.

**Adımlar**

1. **Attention Skorlarını Hesaplama**: Öncekiyle aynı.
2. **Maske Uygulama**: Köşegenin üstünde negatif sonsuz değerlerle doldurulmuş üst üçgensel bir matris kullanın.

```python
mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1) * float('-inf')
masked_scores = attention_scores + mask
```

3. **Softmax Uygulama**: Maskelenmiş skorları kullanarak attention ağırlıklarını hesaplayın.

```python
attention_weights = torch.softmax(masked_scores, dim=-1)
```

### Dropout ile Ek Attention Ağırlıklarını Maskeleme

**Overfitting'i önlemek** için softmax işleminden sonra attention ağırlıklarına **dropout** uygulayabiliriz. Dropout, training sırasında **attention ağırlıklarının bazılarını rastgele sıfırlar**.
```python
dropout = nn.Dropout(p=0.5)
attention_weights = dropout(attention_weights)
```
Düzenli dropout oranı yaklaşık %10-20'dir.

### Kod Örneği

[https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb) adresinden kod örneği:<sup>[[2]](#references)</sup>
```python
import torch
import torch.nn as nn

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

batch = torch.stack((inputs, inputs), dim=0)
print(batch.shape)

class CausalAttention(nn.Module):

def __init__(self, d_in, d_out, context_length,
dropout, qkv_bias=False):
super().__init__()
self.d_out = d_out
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.dropout = nn.Dropout(dropout)
self.register_buffer('mask', torch.triu(torch.ones(context_length, context_length), diagonal=1)) # New

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # This generates the keys of the tokens
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.transpose(1, 2) # Moves the third dimension to the second one and the second one to the third one to be able to multiply
attn_scores.masked_fill_(  # New, _ ops are in-place
self.mask.bool()[:num_tokens, :num_tokens], -torch.inf)  # `:num_tokens` to account for cases where the number of tokens in the batch is smaller than the supported context_size
attn_weights = torch.softmax(
attn_scores / keys.shape[-1]**0.5, dim=-1
)
attn_weights = self.dropout(attn_weights)

context_vec = attn_weights @ values
return context_vec

torch.manual_seed(123)

context_length = batch.shape[1]
d_in = 3
d_out = 2
ca = CausalAttention(d_in, d_out, context_length, 0.0)

context_vecs = ca(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)
```
## Single-Head Attention'ı Multi-Head Attention'a Genişletme

**Multi-head attention**, pratikte **self-attention** fonksiyonunun her biri **kendi ağırlıklarına** sahip olan birden fazla örneğini çalıştırarak farklı nihai vektörler hesaplamaktan oluşur.<sup>[[1]](#references)</sup>

### Kod Örneği

Önceki kodu yeniden kullanmak ve onu birkaç kez çalıştıran bir wrapper eklemek mümkün olurdu; ancak bu, tüm head'leri aynı anda işleyen (maliyetli `for` döngülerinin sayısını azaltan) [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb) kaynağından alınmış daha optimize bir versiyondur. Kodda görebileceğiniz gibi, her token'ın boyutları head sayısına göre farklı boyutlara bölünür. Bu şekilde, bir token 8 boyuta sahipse ve 3 head kullanmak istiyorsak boyutlar, 4 boyutlu 2 array'e bölünür ve her head bunlardan birini kullanır:<sup>[[2]](#references)</sup>
```python
class MultiHeadAttention(nn.Module):
def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
super().__init__()
assert (d_out % num_heads == 0), \
"d_out must be divisible by num_heads"

self.d_out = d_out
self.num_heads = num_heads
self.head_dim = d_out // num_heads # Reduce the projection dim to match desired output dim

self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.out_proj = nn.Linear(d_out, d_out)  # Linear layer to combine head outputs
self.dropout = nn.Dropout(dropout)
self.register_buffer(
"mask",
torch.triu(torch.ones(context_length, context_length),
diagonal=1)
)

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # Shape: (b, num_tokens, d_out)
queries = self.W_query(x)
values = self.W_value(x)

# We implicitly split the matrix by adding a `num_heads` dimension
# Unroll last dim: (b, num_tokens, d_out) -> (b, num_tokens, num_heads, head_dim)
keys = keys.view(b, num_tokens, self.num_heads, self.head_dim)
values = values.view(b, num_tokens, self.num_heads, self.head_dim)
queries = queries.view(b, num_tokens, self.num_heads, self.head_dim)

# Transpose: (b, num_tokens, num_heads, head_dim) -> (b, num_heads, num_tokens, head_dim)
keys = keys.transpose(1, 2)
queries = queries.transpose(1, 2)
values = values.transpose(1, 2)

# Compute scaled dot-product attention (aka self-attention) with a causal mask
attn_scores = queries @ keys.transpose(2, 3)  # Dot product for each head

# Original mask truncated to the number of tokens and converted to boolean
mask_bool = self.mask.bool()[:num_tokens, :num_tokens]

# Use the mask to fill attention scores
attn_scores.masked_fill_(mask_bool, -torch.inf)

attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)
attn_weights = self.dropout(attn_weights)

# Shape: (b, num_tokens, num_heads, head_dim)
context_vec = (attn_weights @ values).transpose(1, 2)

# Combine heads, where self.d_out = self.num_heads * self.head_dim
context_vec = context_vec.contiguous().view(b, num_tokens, self.d_out)
context_vec = self.out_proj(context_vec) # optional projection

return context_vec

torch.manual_seed(123)

batch_size, context_length, d_in = batch.shape
d_out = 2
mha = MultiHeadAttention(d_in, d_out, context_length, 0.0, num_heads=2)

context_vecs = mha(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)

```
Başka bir kompakt ve verimli uygulama için PyTorch'taki [`torch.nn.MultiheadAttention`](https://pytorch.org/docs/stable/generated/torch.nn.MultiheadAttention.html) sınıfını kullanabilirsiniz.

> [!TIP]
> Token boyutlarını, her head'in tüm token'ların tüm boyutlarını kontrol etmesini sağlamak yerine head'ler arasında bölmenin neden daha iyi olduğuna ilişkin ChatGPT'nin kısa yanıtı:
>
> Her head'in tüm embedding boyutlarını işlemesine izin vermek avantajlı görünebilir; çünkü her head tüm bilgilere erişebilecektir. Ancak standart uygulama, **embedding boyutlarını head'ler arasında bölmektir**. Bu yaklaşım, hesaplama verimliliği ile model performansını dengeler ve her head'in farklı temsiller öğrenmesini teşvik eder. Bu nedenle embedding boyutlarını bölmek, genellikle her head'in tüm boyutları kontrol etmesine izin vermeye kıyasla tercih edilir.
