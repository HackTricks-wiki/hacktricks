## Mechanisms za Attention na Self-Attention katika Neural Networks

Mechanisms za attention huruhusu neural networks **kuzingatia sehemu maalum za input wakati wa kutengeneza kila sehemu ya output**. Huzipa inputs tofauti weights tofauti, na kusaidia model kuamua ni inputs zipi zinazohusiana zaidi na task inayotekelezwa. Hili ni muhimu katika tasks kama machine translation, ambapo kuelewa context ya sentensi nzima ni muhimu kwa translation sahihi.<sup>[[1]](#references)</sup>

> [!TIP]
> Lengo la awamu hii ya nne ni rahisi sana: **Kutumia baadhi ya mechanisms za attention**. Hizi zitakuwa **layers nyingi zinazorudiwa** ambazo **zitanasa uhusiano wa neno katika vocabulary na majirani zake katika sentensi ya sasa inayotumika kufunza LLM**.\
> Layers nyingi zinatumika kwa hili, kwa hiyo trainable parameters nyingi zitanasa taarifa hii.

### Kuelewa Mechanisms za Attention

Katika models za jadi za sequence-to-sequence zinazotumika kwa language translation, model hu-encode input sequence kuwa context vector yenye size isiyobadilika. Hata hivyo, approach hii hupata changamoto katika sentensi ndefu kwa sababu context vector yenye size isiyobadilika huenda isinashe taarifa zote zinazohitajika. Mechanisms za attention hushughulikia kizuizi hiki kwa kuruhusu model kuzingatia input tokens zote wakati wa kutengeneza kila output token.

#### Mfano: Machine Translation

Fikiria kutafsiri sentensi ya Kijerumani "Kannst du mir helfen diesen Satz zu übersetzen" kwenda Kiingereza. Translation ya neno kwa neno haiwezi kutoa sentensi ya Kiingereza iliyo sahihi kisarufi kutokana na tofauti za grammatical structures kati ya lugha. Mechanism ya attention huwezesha model kuzingatia sehemu husika za input sentence wakati wa kutengeneza kila neno la output sentence, na hivyo kupata translation sahihi zaidi na yenye mtiririko mzuri.

### Utangulizi wa Self-Attention

Self-attention, au intra-attention, ni mechanism ambapo attention inatumika ndani ya sequence moja ili kukokotoa representation ya sequence hiyo. Huruhusu kila token katika sequence kuangalia tokens nyingine zote, na kusaidia model kunasa dependencies kati ya tokens bila kujali umbali wao katika sequence.

#### Dhana Muhimu

- **Tokens**: Vipengele binafsi vya input sequence (kwa mfano, maneno katika sentensi).
- **Embeddings**: Vector representations za tokens, zinazonasa taarifa ya semantic.
- **Attention Weights**: Values zinazoamua umuhimu wa kila token ikilinganishwa na nyingine.

Tukitumia mfano kutoka [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb), unaweza kuangalia class hii inayotekeleza utendaji wa self-attention tuliozungumzia:<sup>[[2]](#references)</sup>
```python
import torch

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

import torch.nn as nn
class SelfAttention_v2(nn.Module):

def __init__(self, d_in, d_out, qkv_bias=False):
super().__init__()
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)

def forward(self, x):
keys = self.W_key(x)
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.T
attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)

context_vec = attn_weights @ values
return context_vec

d_in=3
d_out=2
torch.manual_seed(789)
sa_v2 = SelfAttention_v2(d_in, d_out)
print(sa_v2(inputs))
```

> Kumbuka kwamba badala ya kuanzisha matrices kwa thamani za random, `nn.Linear` inatumika kuweka alama kwenye uzani wote kama parameters za kufunzwa.

## Causal Attention: Kuficha Maneno ya Baadaye

Kwa LLMs tunataka model izingatie tu tokens zinazoonekana kabla ya nafasi ya sasa ili **kutabiri token inayofuata**. **Causal attention**, pia inayojulikana kama **masked attention**, hutimiza hili kwa kurekebisha attention mechanism ili kuzuia ufikiaji wa tokens za baadaye.<sup>[[1]](#references)</sup>

### Kutumia Causal Attention Mask

Ili kutekeleza causal attention, tunaweka mask kwenye attention scores **kabla ya operesheni ya softmax** ili zilizosalia bado zijumlishe hadi 1. Mask hii huweka attention scores za tokens za baadaye kuwa negative infinity, na kuhakikisha kwamba baada ya softmax, attention weights zake zinakuwa sifuri.

**Hatua**

1. **Kokotoa Attention Scores**: Sawa na hapo awali.
2. **Tumia Mask**: Tumia upper triangular matrix iliyojazwa negative infinity juu ya diagonal.

```python
mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=1) * float('-inf')
masked_scores = attention_scores + mask
```

3. **Tumia Softmax**: Kokotoa attention weights kwa kutumia masked scores.

```python
attention_weights = torch.softmax(masked_scores, dim=-1)
```

### Kuficha Attention Weights za Ziada kwa Dropout

Ili **kuzuia overfitting**, tunaweza kutumia **dropout** kwenye attention weights baada ya operesheni ya softmax. Dropout **huweka baadhi ya attention weights kuwa sifuri kwa random** wakati wa training.
```python
dropout = nn.Dropout(p=0.5)
attention_weights = dropout(attention_weights)
```
Dropout ya kawaida huwa takribani 10-20%.

### Mfano wa Code

Mfano wa Code kutoka [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb):<sup>[[2]](#references)</sup>
```python
import torch
import torch.nn as nn

inputs = torch.tensor(
[[0.43, 0.15, 0.89], # Your     (x^1)
[0.55, 0.87, 0.66], # journey  (x^2)
[0.57, 0.85, 0.64], # starts   (x^3)
[0.22, 0.58, 0.33], # with     (x^4)
[0.77, 0.25, 0.10], # one      (x^5)
[0.05, 0.80, 0.55]] # step     (x^6)
)

batch = torch.stack((inputs, inputs), dim=0)
print(batch.shape)

class CausalAttention(nn.Module):

def __init__(self, d_in, d_out, context_length,
dropout, qkv_bias=False):
super().__init__()
self.d_out = d_out
self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key   = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.dropout = nn.Dropout(dropout)
self.register_buffer('mask', torch.triu(torch.ones(context_length, context_length), diagonal=1)) # New

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # This generates the keys of the tokens
queries = self.W_query(x)
values = self.W_value(x)

attn_scores = queries @ keys.transpose(1, 2) # Moves the third dimension to the second one and the second one to the third one to be able to multiply
attn_scores.masked_fill_(  # New, _ ops are in-place
self.mask.bool()[:num_tokens, :num_tokens], -torch.inf)  # `:num_tokens` to account for cases where the number of tokens in the batch is smaller than the supported context_size
attn_weights = torch.softmax(
attn_scores / keys.shape[-1]**0.5, dim=-1
)
attn_weights = self.dropout(attn_weights)

context_vec = attn_weights @ values
return context_vec

torch.manual_seed(123)

context_length = batch.shape[1]
d_in = 3
d_out = 2
ca = CausalAttention(d_in, d_out, context_length, 0.0)

context_vecs = ca(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)
```
## Kupanua Single-Head Attention kuwa Multi-Head Attention

**Multi-head attention** kwa maana ya kiutendaji inahusisha kutekeleza **instances** nyingi za function ya self-attention, kila moja ikiwa na **weights** zake, ili vekta tofauti za mwisho zihesabiwe.<sup>[[1]](#references)</sup>

### Mfano wa Code

Inawezekana kutumia tena code ya awali na kuongeza wrapper inayoiendesha mara kadhaa, lakini hili ni toleo lililoboreshwa zaidi kutoka [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch03/01_main-chapter-code/ch03.ipynb) ambalo huchakata heads zote kwa wakati mmoja (hivyo kupunguza idadi ya **for loops** zenye gharama kubwa). Kama unavyoona kwenye code, dimensions za kila token hugawanywa katika dimensions tofauti kulingana na idadi ya heads. Kwa njia hii, ikiwa token ina dimensions 8 na tunataka kutumia heads 3, dimensions zitagawanywa katika arrays 2 zenye dimensions 4, na kila head itatumia moja kati ya hizo:<sup>[[2]](#references)</sup>
```python
class MultiHeadAttention(nn.Module):
def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
super().__init__()
assert (d_out % num_heads == 0), \
"d_out must be divisible by num_heads"

self.d_out = d_out
self.num_heads = num_heads
self.head_dim = d_out // num_heads # Reduce the projection dim to match desired output dim

self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.out_proj = nn.Linear(d_out, d_out)  # Linear layer to combine head outputs
self.dropout = nn.Dropout(dropout)
self.register_buffer(
"mask",
torch.triu(torch.ones(context_length, context_length),
diagonal=1)
)

def forward(self, x):
b, num_tokens, d_in = x.shape
# b is the num of batches
# num_tokens is the number of tokens per batch
# d_in is the dimensions er token

keys = self.W_key(x) # Shape: (b, num_tokens, d_out)
queries = self.W_query(x)
values = self.W_value(x)

# We implicitly split the matrix by adding a `num_heads` dimension
# Unroll last dim: (b, num_tokens, d_out) -> (b, num_tokens, num_heads, head_dim)
keys = keys.view(b, num_tokens, self.num_heads, self.head_dim)
values = values.view(b, num_tokens, self.num_heads, self.head_dim)
queries = queries.view(b, num_tokens, self.num_heads, self.head_dim)

# Transpose: (b, num_tokens, num_heads, head_dim) -> (b, num_heads, num_tokens, head_dim)
keys = keys.transpose(1, 2)
queries = queries.transpose(1, 2)
values = values.transpose(1, 2)

# Compute scaled dot-product attention (aka self-attention) with a causal mask
attn_scores = queries @ keys.transpose(2, 3)  # Dot product for each head

# Original mask truncated to the number of tokens and converted to boolean
mask_bool = self.mask.bool()[:num_tokens, :num_tokens]

# Use the mask to fill attention scores
attn_scores.masked_fill_(mask_bool, -torch.inf)

attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)
attn_weights = self.dropout(attn_weights)

# Shape: (b, num_tokens, num_heads, head_dim)
context_vec = (attn_weights @ values).transpose(1, 2)

# Combine heads, where self.d_out = self.num_heads * self.head_dim
context_vec = context_vec.contiguous().view(b, num_tokens, self.d_out)
context_vec = self.out_proj(context_vec) # optional projection

return context_vec

torch.manual_seed(123)

batch_size, context_length, d_in = batch.shape
d_out = 2
mha = MultiHeadAttention(d_in, d_out, context_length, 0.0, num_heads=2)

context_vecs = mha(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)

```
Kwa utekelezaji mwingine mfupi na wenye ufanisi, unaweza kutumia class ya [`torch.nn.MultiheadAttention`](https://pytorch.org/docs/stable/generated/torch.nn.MultiheadAttention.html) katika PyTorch.

> [!TIP]
> Jibu fupi la ChatGPT kuhusu kwa nini ni bora kugawanya dimensions za tokens kati ya heads badala ya kila head kuchunguza dimensions zote za tokens zote:
>
> Ingawa kuruhusu kila head kuchakata dimensions zote za embedding kunaweza kuonekana kuwa na faida kwa sababu kila head ingekuwa na ufikiaji wa taarifa kamili, desturi ya kawaida ni **kugawanya dimensions za embedding kati ya heads**. Mbinu hii husawazisha ufanisi wa computational na utendaji wa model, na huhimiza kila head kujifunza representations tofauti. Kwa hiyo, kugawanya dimensions za embedding kwa ujumla hupendelewa kuliko kuruhusu kila head kuchunguza dimensions zote.
