## Pretraining

Pretraining, büyük bir dil modelinin (LLM) geliştirilmesinde modelin çok büyük ve çeşitli miktarlarda metin verisine maruz bırakıldığı temel aşamadır. Bu aşamada, **LLM dilin temel yapılarını, kalıplarını ve inceliklerini**; dil bilgisi, kelime dağarcığı, sözdizimi ve bağlamsal ilişkiler dahil olmak üzere öğrenir. Model, bu kapsamlı veriyi işleyerek dil hakkında geniş bir anlayış ve genel dünya bilgisi edinir. Bu kapsamlı temel, LLM'nin tutarlı ve bağlamsal olarak ilgili metinler üretmesini sağlar. Daha sonra bu pretrained model, belirli görev veya alanlara yönelik yeteneklerini uyarlamak, hedeflenen uygulamalardaki performansını ve uygunluğunu artırmak amacıyla özel veri kümeleri üzerinde ek olarak eğitildiği fine-tuning sürecinden geçirilebilir.<sup>[[1]](#references)</sup>

## Temel LLM bileşenleri

Bir LLM genellikle mimarisi ve eğitim yapılandırmasıyla karakterize edilir. Bir LLM'nin eğitiminde yer alan yaygın bileşenler şunlardır:<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Parameters**: Parameters, sinir ağındaki **öğrenilebilir ağırlıklar ve bias'lar**dır. Bunlar, loss function'ı en aza indirmek ve modelin görev üzerindeki performansını artırmak için training sürecinin ayarladığı sayılardır. LLM'ler genellikle milyonlarca parameter kullanır.
- **Context Length**: LLM'yi pre-training için kullanılan her bir cümlenin maksimum uzunluğudur.
- **Embedding Dimension**: Her token'ı veya kelimeyi temsil etmek için kullanılan vector'ün boyutudur. LLM'ler genellikle milyarlarca dimension kullanır.
- **Hidden Dimension**: Sinir ağındaki hidden layer'ların boyutudur.
- **Number of Layers (Depth)**: Modelin sahip olduğu layer sayısıdır. LLM'ler genellikle onlarca layer kullanır.
- **Number of Attention Heads**: Transformer model'lerinde her layer'da kullanılan ayrı attention mechanism'lerinin sayısıdır. LLM'ler genellikle onlarca head kullanır.
- **Dropout**: Dropout, **overfitting'i önlemek** amacıyla training sırasında verilerin belirli bir yüzdesinin kaldırılmasına (probability değerlerinin 0'a dönüştürülmesine) benzer. LLM'ler genellikle %0-20 arasında kullanır.

GPT-2 modelinin yapılandırması:
```json
GPT_CONFIG_124M = {
"vocab_size": 50257,  // Vocabulary size of the BPE tokenizer
"context_length": 1024, // Context length

"n_layers": 12,       // Number of layers
"drop_rate": 0.1,     // Dropout rate: 10%
"qkv_bias": False     // Query-Key-Value bias
}
```
## PyTorch'ta Tensors

PyTorch'ta bir **tensor**, scalar, vector ve matrix gibi kavramları potansiyel olarak daha yüksek boyutlara genelleyen, çok boyutlu bir array olarak görev yapan temel bir veri yapısıdır. Tensors, özellikle deep learning ve neural network bağlamında, verilerin PyTorch'ta temsil edilip işlenmesinin başlıca yoludur.<sup>[[1]](#references)</sup>

### Tensors'ın Matematiksel Kavramı

- **Scalars**: Tek bir sayıyı temsil eden (sıfır boyutlu) rank 0 tensors. Örneğin: 5
- **Vectors**: Tek boyutlu bir sayı array'ini temsil eden rank 1 tensors. Örneğin: \[5,1]
- **Matrices**: Satır ve sütunlara sahip iki boyutlu array'leri temsil eden rank 2 tensors. Örneğin: \[\[1,3], \[5,2]]
- **Higher-Rank Tensors**: Daha yüksek boyutlardaki verileri temsil eden rank 3 veya daha yüksek tensors (örneğin, color images için 3D tensors).

### Veri Container'ları Olarak Tensors

Computational açıdan tensors, çok boyutlu veriler için container'lar olarak görev yapar; her boyut, verilerin farklı feature'larını veya yönlerini temsil edebilir. Bu durum, tensors'ı machine learning görevlerindeki karmaşık dataset'leri işlemek için son derece uygun hale getirir.

### PyTorch Tensors ve NumPy Arrays Karşılaştırması

PyTorch tensors, numerical verileri depolama ve işleme yetenekleri bakımından NumPy arrays'e benzer; ancak deep learning için kritik olan ek işlevler sunar:

- **Automatic Differentiation**: PyTorch tensors, gradient'lerin automatic olarak hesaplanmasını (autograd) destekler; bu da neural network'leri train etmek için gereken derivative'ları hesaplama sürecini basitleştirir.
- **GPU Acceleration**: PyTorch'taki tensors GPU'lara taşınabilir ve GPU'lar üzerinde hesaplanabilir; bu da large-scale computation'ları önemli ölçüde hızlandırır.

### Tensor Data Types

PyTorch tensor'ları integer ve floating-point sayılar gibi çeşitli türlerde veri depolayabilir.

Bir tensor'ün veri türünü `.dtype` attribute'u kullanarak kontrol edebilirsiniz:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Python tam sayılarından oluşturulan Tensors, `torch.int64` türündedir.
- Python kayan noktalı sayılarından oluşturulan Tensors, `torch.float32` türündedir.

Bir tensor'ün veri türünü değiştirmek için `.to()` metodunu kullanın:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Yaygın Tensor İşlemleri

PyTorch, tensor'ları değiştirmek için çeşitli işlemler sağlar:


- **Tensor'ları Transpoze Etme**: 2D bir tensor'ı transpoze etmek için `.T` kullanın.

- **Matrix Çarpımı**: `.matmul()` veya `@` operatörünü kullanın.

```python

```

## Automatic Differentiation

Automatic differentiation (AD), fonksiyonların **türevlerini (gradient'lerini)** verimli ve doğru bir şekilde **değerlendirmek** için kullanılan bir computational technique'tir. Neural network'ler bağlamında AD, **gradient descent gibi optimization algoritmaları** için gereken gradient'lerin hesaplanmasını sağlar. PyTorch, bu süreci basitleştiren **autograd** adlı bir automatic differentiation engine sağlar.<sup>[[1]](#references)</sup>

### Automatic Differentiation'ın Matematiksel Açıklaması

**1. Chain Rule**

Automatic differentiation'ın temelinde calculus'tan gelen **chain rule** bulunur. Chain rule, fonksiyonların bileşiminden oluşan bir durumda, composite function'ın türevinin bileşime dahil olan fonksiyonların türevlerinin çarpımı olduğunu belirtir.

### PyTorch'ta Automatic Differentiation Uygulama

Şimdi PyTorch'un bu süreci nasıl otomatikleştirdiğine bakalım.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Daha Büyük Neural Network'lerde Backpropagation

### **1. Multilayer Network'lere Genişletme**

Birden fazla katmana sahip daha büyük neural network'lerde, artan parametre ve işlem sayısı nedeniyle gradient'leri hesaplama süreci daha karmaşık hale gelir. Ancak temel prensipler aynı kalır:<sup>[[1]](#references)</sup>

- **Forward Pass:** Input'ları her katmandan geçirerek network'ün output'unu hesaplayın.
- **Loss'u Hesaplama:** Network'ün output'unu ve hedef label'ları kullanarak loss function'ı değerlendirin.
- **Backward Pass (Backpropagation):** Chain rule'u output layer'dan input layer'a doğru recursive olarak uygulayarak loss'un network'teki her parametreye göre gradient'lerini hesaplayın.

### **2. Backpropagation Algorithm**

- **Step 1:** Network parametrelerini (weight'ler ve bias'lar) initialize edin.
- **Step 2:** Her training example için output'ları hesaplamak üzere bir forward pass gerçekleştirin.
- **Step 3:** Loss'u hesaplayın.
- **Step 4:** Chain rule'u kullanarak loss'un her parametreye göre gradient'lerini hesaplayın.
- **Step 5:** Bir optimization algorithm'i (ör. gradient descent) kullanarak parametreleri update edin.

### **4. PyTorch Implementation**

PyTorch, autograd engine'i ile bu süreci basitleştirir.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
Bu kodda:

- **İleri Geçiş:** Ağın çıktılarını hesaplar.
- **Geri Geçiş:** `loss.backward()`, kaybın tüm parametrelere göre gradyanlarını hesaplar.
- **Parametre Güncelleme:** `optimizer.step()`, hesaplanan gradyanlara göre parametreleri günceller.

### **5. Geri Geçişi Anlama**

Geri geçiş sırasında:

- PyTorch, hesaplama grafiğini ters sırayla dolaşır.
- Her işlem için gradyanları hesaplamak üzere zincir kuralını uygular.
- Gradyanlar, her parametre tensörünün `.grad` niteliğinde biriktirilir.

### **6. Otomatik Türev Almanın Avantajları**

- **Verimlilik:** Ara sonuçları yeniden kullanarak gereksiz hesaplamaları önler.
- **Doğruluk:** Makine hassasiyetine kadar kesin türevler sağlar.
- **Kullanım Kolaylığı:** Türevlerin manuel olarak hesaplanmasını ortadan kaldırır.
