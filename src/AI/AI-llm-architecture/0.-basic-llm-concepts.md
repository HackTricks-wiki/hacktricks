## Pretraining

Pretraining, büyük bir dil modelinin (LLM) geliştirilmesindeki temel aşamadır ve model bu aşamada çok büyük ve çeşitli miktarlarda metin verisine maruz bırakılır. Bu aşama sırasında **LLM, dilin temel yapılarını, kalıplarını ve inceliklerini**; dil bilgisi, kelime dağarcığı, söz dizimi ve bağlamsal ilişkiler dahil olmak üzere öğrenir. Model, bu kapsamlı veriyi işleyerek dil hakkında geniş bir anlayış ve genel dünya bilgisi edinir. Bu kapsamlı temel, LLM'nin tutarlı ve bağlama uygun metinler oluşturmasını sağlar. Daha sonra bu pretrained model, belirli görevler veya alanlar için yeteneklerini uyarlamak ve hedeflenen uygulamalardaki performansını ve uygunluğunu artırmak amacıyla özel veri kümeleri üzerinde ek olarak eğitildiği fine-tuning işleminden geçirilebilir.<sup>[[1]](#references)</sup>

## Temel LLM bileşenleri

Genellikle bir LLM, onu eğitmek için kullanılan yapılandırmayla tanımlanır. Bir LLM eğitilirken kullanılan yaygın bileşenler şunlardır:<sup>[[1]](#references)[[2]](#references)</sup>

- **Parameters**: Parameters, neural network içindeki **öğrenilebilir ağırlıklar ve bias değerleridir**. Bunlar, loss function'ı en aza indirmek ve modelin görev üzerindeki performansını artırmak için training process tarafından ayarlanan sayılardır. LLM'ler genellikle milyonlarca parameter kullanır.
- **Context Length**: Bu, LLM'yi pre-train etmek için kullanılan her bir cümlenin maksimum uzunluğudur.
- **Embedding Dimension**: Her bir token'ı veya kelimeyi temsil etmek için kullanılan vector'ün boyutudur. LLM'ler genellikle milyarlarca dimension kullanır.
- **Hidden Dimension**: Neural network içindeki hidden layer'ların boyutudur.
- **Number of Layers (Depth)**: Modelin sahip olduğu layer sayısıdır. LLM'ler genellikle onlarca layer kullanır.
- **Number of Attention Heads**: Transformer model'lerinde bu, her layer'da kullanılan ayrı attention mechanism'lerinin sayısıdır. LLM'ler genellikle onlarca head kullanır.
- **Dropout**: Dropout, **overfitting'i önlemek** için training sırasında verilerin belirli bir yüzdesinin kaldırılmasına (probability değerlerinin 0'a dönüştürülmesine) benzer bir işlemdir. LLM'ler genellikle %0-20 arasında kullanır.

GPT-2 modelinin yapılandırması:
```json
GPT_CONFIG_124M = {
"vocab_size": 50257,  // Vocabulary size of the BPE tokenizer
"context_length": 1024, // Context length
"emb_dim": 768,       // Embedding dimension
"n_heads": 12,        // Number of attention heads
"n_layers": 12,       // Number of layers
"drop_rate": 0.1,     // Dropout rate: 10%
"qkv_bias": False     // Query-Key-Value bias
}
```
## PyTorch'ta Tensors

PyTorch'ta **tensor**, scalar, vector ve matrix gibi kavramları potansiyel olarak daha yüksek boyutlara genelleyen, çok boyutlu bir array olarak görev yapan temel bir veri yapısıdır. Tensors, özellikle deep learning ve neural networks bağlamında, verilerin PyTorch'ta temsil edilmesinin ve işlenmesinin birincil yoludur.<sup>[[1]](#references)</sup>

### Tensors'ın Matematiksel Kavramı

- **Scalars**: Tek bir sayıyı (sıfır boyutlu) temsil eden, rank 0 tensors. Örneğin: 5
- **Vectors**: Tek boyutlu bir sayı array'ini temsil eden, rank 1 tensors. Örneğin: \[5,1]
- **Matrices**: Satır ve sütunlara sahip iki boyutlu array'leri temsil eden, rank 2 tensors. Örneğin: \[\[1,3], \[5,2]]
- **Higher-Rank Tensors**: Daha yüksek boyutlardaki verileri temsil eden, rank 3 veya daha yüksek tensors (örneğin, color images için 3D tensors).

### Veri Container'ları Olarak Tensors

Computational açıdan tensors, çok boyutlu veriler için container görevi görür; burada her boyut, verilerin farklı özelliklerini veya yönlerini temsil edebilir. Bu, tensors'ı machine learning görevlerindeki karmaşık datasets'leri işlemek için oldukça uygun hale getirir.

### PyTorch Tensors ve NumPy Arrays Karşılaştırması

PyTorch tensors, numerical verileri depolama ve işleme yetenekleri bakımından NumPy arrays'e benzer olsa da deep learning için kritik olan ek işlevler sunar:

- **Automatic Differentiation**: PyTorch tensors, gradients'ların otomatik olarak hesaplanmasını (autograd) destekler. Bu, neural networks'ü eğitmek için gereken derivatives'ların hesaplanması sürecini basitleştirir.
- **GPU Acceleration**: PyTorch'taki tensors, GPUs'a taşınabilir ve GPUs üzerinde hesaplanabilir; bu da büyük ölçekli hesaplamaları önemli ölçüde hızlandırır.

### Tensor Veri Türleri

PyTorch tensorları, integer ve floating-point sayılar gibi çeşitli türlerde veriler depolayabilir.

Bir tensorun veri türünü `.dtype` attribute'unu kullanarak kontrol edebilirsiniz:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Python integer'larından oluşturulan tensor'lerin türü `torch.int64` olur.
- Python float'larından oluşturulan tensor'lerin türü `torch.float32` olur.

Bir tensor'ün veri türünü değiştirmek için `.to()` metodunu kullanın:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Yaygın Tensor İşlemleri

PyTorch, tensor'ları işlemek için çeşitli işlemler sağlar:

- **Shape'e Erişme**: Bir tensor'ın boyutlarını almak için `.shape` kullanın.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Tensor'ları Yeniden Şekillendirme**: Shape'i değiştirmek için `.reshape()` veya `.view()` kullanın.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Tensor'ların Transpoze Edilmesi**: 2D bir tensor'ı transpoze etmek için `.T` kullanın.

```python

```

- **Matrix Multiplication**: `.matmul()` veya `@` operatörünü kullanın.

```python
result = tensor2d @ tensor2d.T
```

## Automatic Differentiation

Automatic differentiation (AD), functions'ların **derivatives (gradients)** değerlerini verimli ve doğru bir şekilde **hesaplamak** için kullanılan bir computational technique'tir. Neural network'ler bağlamında AD, **gradient descent gibi optimization algorithms** için gereken gradient'lerin hesaplanmasını sağlar. PyTorch, bu süreci basitleştiren **autograd** adlı bir automatic differentiation engine sağlar.<sup>[[1]](#references)</sup>

### Automatic Differentiation'ın Matematiksel Açıklaması

**1. Chain Rule**

Automatic differentiation'ın temelinde calculus'tan gelen **chain rule** bulunur. Chain rule, bir function composition'ına sahipseniz composite function'ın derivative'ının, composed functions'ın derivative'larının çarpımı olduğunu belirtir.

Matematiksel olarak, `y=f(u)` ve `u=g(x)` ise `y`'nin `x`'e göre derivative'ı şöyledir:

### PyTorch'ta Automatic Differentiation'ın Uygulanması

Şimdi PyTorch'un bu süreci nasıl otomatikleştirdiğine bakalım.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Daha Büyük Neural Network'lerde Backpropagation

### **1. Çok Katmanlı Network'lere Genişletme**

Birden fazla layer içeren daha büyük neural network'lerde gradient'leri hesaplama süreci, artan parametre ve operation sayısı nedeniyle daha karmaşık hale gelir. Ancak temel prensipler aynı kalır:<sup>[[1]](#references)</sup>

- **Forward Pass:** Input'ları her layer'dan geçirerek network'ün output'unu hesaplayın.
- **Loss'u Hesaplama:** Network'ün output'unu ve hedef label'larını kullanarak loss function'ı değerlendirin.
- **Backward Pass (Backpropagation):** Chain rule'u output layer'dan input layer'a doğru recursive olarak uygulayarak loss'un network'teki her parametreye göre gradient'lerini hesaplayın.

### **2. Backpropagation Algorithm**

- **Step 1:** Network parametrelerini (weight'ler ve bias'lar) initialize edin.
- **Step 2:** Her training example için output'ları hesaplamak üzere bir forward pass gerçekleştirin.
- **Step 3:** Loss'u hesaplayın.
- **Step 4:** Chain rule'u kullanarak loss'un her parametreye göre gradient'lerini hesaplayın.
- **Step 5:** Bir optimization algorithm'i (ör. gradient descent) kullanarak parametreleri update edin.

### **4. PyTorch Implementation**

PyTorch, autograd engine'i sayesinde bu süreci basitleştirir.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
Bu kodda:

- **İleri Geçiş:** Network çıktısını hesaplar.
- **Geri Geçiş:** `loss.backward()` loss değerinin tüm parametrelere göre gradient'lerini hesaplar.
- **Parametre Güncellemesi:** `optimizer.step()` hesaplanan gradient'lere göre parametreleri günceller.

### **5. Geri Geçişi Anlama**

Geri geçiş sırasında:

- PyTorch computational graph'ı ters sırayla dolaşır.
- Her işlem için gradient'leri hesaplamak üzere chain rule'u uygular.
- Gradient'ler her parametre tensor'ünün `.grad` attribute'unda biriktirilir.

### **6. Automatic Differentiation'ın Avantajları**

- **Verimlilik:** Intermediate result'ları yeniden kullanarak redundant hesaplamaları önler.
- **Doğruluk:** Machine precision'a kadar exact derivative'ler sağlar.
- **Kullanım Kolaylığı:** Derivative'lerin manuel olarak hesaplanmasını ortadan kaldırır.
