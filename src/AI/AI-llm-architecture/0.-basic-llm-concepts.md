## Pretraining

Pretrainingは、大規模言語モデル（LLM）の開発における基礎的な段階であり、モデルに膨大かつ多様なテキストデータを与えます。この段階で、**LLMは文法、語彙、構文、文脈上の関係性など、言語の基本的な構造、パターン、ニュアンスを学習します**。この広範なデータを処理することで、モデルは言語に対する幅広い理解と、一般的な世界知識を獲得します。この包括的な基盤により、LLMは一貫性があり、文脈に適したテキストを生成できるようになります。その後、このpretrainedモデルはfine-tuningを受けることができます。fine-tuningでは、特定のタスクや分野に対応できるよう、専門的なデータセットを使ってさらに訓練し、対象となる用途での性能と関連性を高めます。<sup>[[1]](#references)</sup>

## LLMの主なコンポーネント

通常、LLMは訓練に使用された構成によって特徴づけられます。LLMの訓練時に使用される一般的なコンポーネントは次のとおりです。<sup>[[1]](#references)[[2]](#references)</sup>

- **Parameters**: Parametersは、ニューラルネットワークにおける**学習可能な重みとバイアス**です。これらは、損失関数を最小化し、タスクに対するモデルの性能を向上させるために、訓練プロセスで調整される数値です。LLMは通常、数百万のparametersを使用します。
- **Context Length**: これは、LLMのpre-trainingに使用される各文の最大長です。
- **Embedding Dimension**: 各tokenまたは単語を表現するために使用されるvectorのサイズです。LLMは通常、数十億のdimensionを使用します。
- **Hidden Dimension**: ニューラルネットワークのhidden layerのサイズです。
- **Number of Layers (Depth)**: モデルが持つlayerの数です。LLMは通常、数十のlayerを使用します。
- **Number of Attention Heads**: transformer modelでは、各layerで使用される独立したattention mechanismの数です。LLMは通常、数十のheadを使用します。
- **Dropout**: Dropoutは、**overfittingを防止するために**訓練中に削除されるデータの割合（probabilityが0になる）に相当するものです。LLMでは通常、0～20%が使用されます。

## PyTorchにおけるテンソル

PyTorchでは、**テンソル**は多次元配列として機能する基本的なデータ構造であり、スカラー、ベクトル、行列といった概念を、より高い次元へと一般化したものです。テンソルは、特にdeep learningやneural networksのコンテキストにおいて、PyTorchでデータを表現・操作する主要な方法です。<sup>[[1]](#references)</sup>

### テンソルの数学的概念

- **スカラー**: rank 0のテンソルで、単一の数値（0次元）を表します。例: 5
- **ベクトル**: rank 1のテンソルで、数値の1次元配列を表します。例: \[5,1]
- **行列**: rank 2のテンソルで、行と列を持つ2次元配列を表します。例: \[\[1,3], \[5,2]]
- **高rankテンソル**: rank 3以上のテンソルで、高次元のデータを表します（例: カラー画像用の3Dテンソル）。

### データコンテナとしてのテンソル

計算の観点では、テンソルは多次元データのコンテナとして機能し、各次元はデータの異なる特徴や側面を表します。このため、テンソルはmachine learningのタスクで複雑なデータセットを扱うのに非常に適しています。

### PyTorchテンソルとNumPy配列の比較

PyTorchテンソルは、数値データの保存および操作能力においてNumPy配列と似ていますが、deep learningに不可欠な追加機能を提供します。

- **Automatic Differentiation**: PyTorchテンソルは勾配の自動計算（autograd）をサポートしており、neural networksのtrainingに必要な導関数の計算プロセスを簡略化します。
- **GPU Acceleration**: PyTorchのテンソルはGPUへ移動してGPU上で計算できるため、大規模な計算を大幅に高速化できます。

### PyTorchでのテンソルの作成

### Tensorデータ型

PyTorchテンソルは、整数や浮動小数点数など、さまざまな型のデータを格納できます。

`.dtype`属性を使用して、テンソルのデータ型を確認できます。
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Python の整数から作成された Tensor の型は `torch.int64` です。
- Python の浮動小数点数から作成された Tensor の型は `torch.float32` です。

Tensor のデータ型を変更するには、`.to()` メソッドを使用します。
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Tensorの一般的な操作

PyTorchには、tensorを操作するためのさまざまな演算が用意されています。

- **Shapeへのアクセス**: `.shape`を使用して、tensorの次元を取得します。

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Tensorのreshape**: `.reshape()`または`.view()`を使用して、shapeを変更します。

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Tensorの転置**: `.T`を使用して、2D tensorを転置します。

```python
transposed = tensor2d.T
```

- **行列乗算**: `.matmul()`または`@`演算子を使用します。

```python
result = tensor2d @ tensor2d.T
```

### Deep Learningにおける重要性

Tensorは、PyTorchでneural networkを構築およびtrainingするために不可欠です。

- 入力データ、weights、biasesを格納します。
- training algorithmのforward passおよびbackward passに必要な演算を実行できます。
- autogradにより、tensorはgradientの自動計算を可能にし、optimization processを効率化します。

## Automatic Differentiation

Automatic differentiation（AD）は、関数の**derivative（gradient）**を効率的かつ正確に**計算する**ために使用される計算技術です。neural networkの文脈では、ADによって**gradient descentなどのoptimization algorithm**に必要なgradientを計算できます。PyTorchには、このprocessを簡略化するautomatic differentiation engineである**autograd**が用意されています。<sup>[[1]](#references)</sup>

### Automatic Differentiationの数学的説明

**1. Chain Rule**

automatic differentiationの中心にあるのは、calculusにおける**chain rule**です。chain ruleは、複数の関数の合成について、合成関数のderivativeが、構成する各関数のderivativeの積になることを示します。

### PyTorchでAutomatic Differentiationを実装する

ここでは、PyTorchがこのprocessをどのように自動化するかを見ていきます。
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## より大規模なニューラルネットワークにおけるバックプロパゲーション

### **1.多層ネットワークへの拡張**

複数の層を持つ大規模なニューラルネットワークでは、パラメータと演算の数が増えるため、勾配の計算プロセスはより複雑になります。しかし、基本的な原則は同じです:<sup>[[1]](#references)</sup>

- **Forward Pass:** 各層に入力を通してネットワークの出力を計算します。
- **損失の計算:** ネットワークの出力と正解ラベルを使用して損失関数を評価します。
- **Backward Pass (Backpropagation):** 出力層から入力層に向かって連鎖律を再帰的に適用し、ネットワーク内の各パラメータに対する損失の勾配を計算します。

### **2. Backpropagationアルゴリズム**

- **Step 1:** ネットワークのパラメータ（重みとバイアス）を初期化します。
- **Step 2:** 各訓練例について、Forward Passを実行して出力を計算します。
- **Step 3:** 損失を計算します。
- **Step 4:** 連鎖律を使用して、各パラメータに対する損失の勾配を計算します。
- **Step 5:** 最適化アルゴリズム（例: 勾配降下法）を使用してパラメータを更新します。

### **4. PyTorchによる実装**

PyTorchは、autogradエンジンによってこのプロセスを簡略化します。
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
このコードでは:

- **Forward Pass:** ネットワークの出力を計算します。
- **Backward Pass:** `loss.backward()` は、すべてのパラメータに対する損失の勾配を計算します。
- **Parameter Update:** `optimizer.step()` は、計算された勾配に基づいてパラメータを更新します。

### **5. Backward Pass の理解**

Backward Pass の間:

- PyTorch は計算グラフを逆順にたどります。
- 各演算に対して連鎖律を適用し、勾配を計算します。
- 勾配は各パラメータテンソルの `.grad` 属性に蓄積されます。

### **6. Automatic Differentiation の利点**

- **Efficiency:** 中間結果を再利用することで、冗長な計算を回避します。
- **Accuracy:** 機械精度の範囲内で正確な導関数を提供します。
- **Ease of Use:** 導関数の手動計算が不要になります。
