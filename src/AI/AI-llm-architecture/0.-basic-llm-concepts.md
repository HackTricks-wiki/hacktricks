## Préentraînement

Le préentraînement est la phase fondamentale du développement d'un large language model (LLM), au cours de laquelle le modèle est exposé à des quantités vastes et diversifiées de données textuelles. Au cours de cette étape, **le LLM apprend les structures fondamentales, les modèles et les nuances du langage**, notamment la grammaire, le vocabulaire, la syntaxe et les relations contextuelles. En traitant ces nombreuses données, le modèle acquiert une compréhension générale du langage et des connaissances générales sur le monde. Cette base complète permet au LLM de générer du texte cohérent et pertinent sur le plan contextuel. Par la suite, ce modèle préentraîné peut faire l'objet d'un fine-tuning, au cours duquel il est entraîné davantage sur des jeux de données spécialisés afin d'adapter ses capacités à des tâches ou domaines spécifiques, améliorant ainsi ses performances et sa pertinence dans des applications ciblées.<sup>[[1]](#references)</sup>

## Principaux composants d'un LLM

Un LLM est généralement caractérisé par son architecture et sa configuration d'entraînement. Voici les composants couramment impliqués dans l'entraînement d'un modèle :<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Paramètres** : Les paramètres sont les **poids et biais pouvant être appris** dans le réseau neuronal. Il s'agit des nombres que le processus d'entraînement ajuste afin de minimiser la fonction de perte et d'améliorer les performances du modèle pour la tâche concernée. Les LLM utilisent généralement des millions de paramètres.
- **Longueur du contexte** : Il s'agit de la longueur maximale de chaque phrase utilisée pour le préentraînement du LLM.
- **Dimension des embeddings** : La taille du vecteur utilisé pour représenter chaque token ou mot. Les LLM utilisent généralement des milliards de dimensions.
- **Dimension cachée** : La taille des couches cachées du réseau neuronal.
- **Nombre de couches (profondeur)** : Le nombre de couches du modèle. Les LLM utilisent généralement des dizaines de couches.
- **Nombre de têtes d'attention** : Dans les modèles transformer, il s'agit du nombre de mécanismes d'attention distincts utilisés dans chaque couche. Les LLM utilisent généralement des dizaines de têtes.
- **Dropout** : Le dropout correspond à un pourcentage de données supprimées (les probabilités sont mises à 0) pendant l'entraînement afin de **prévenir le surapprentissage**. Les LLM utilisent généralement une valeur comprise entre 0 et 20 %.

## Tenseurs dans PyTorch

Dans PyTorch, un **tenseur** est une structure de données fondamentale qui sert de tableau multidimensionnel, généralisant des concepts tels que les scalaires, les vecteurs et les matrices à des dimensions potentiellement supérieures. Les tenseurs constituent le principal moyen de représenter et de manipuler les données dans PyTorch, en particulier dans le contexte du deep learning et des réseaux neuronaux.<sup>[[1]](#references)</sup>

### Concept mathématique des tenseurs

- **Scalaires** : tenseurs de rang 0, représentant un nombre unique (zéro dimension). Exemple : 5
- **Vecteurs** : tenseurs de rang 1, représentant un tableau unidimensionnel de nombres. Exemple : \[5,1]
- **Matrices** : tenseurs de rang 2, représentant des tableaux bidimensionnels avec des lignes et des colonnes. Exemple : \[\[1,3], \[5,2]]
- **Tenseurs de rang supérieur** : tenseurs de rang 3 ou plus, représentant des données dans des dimensions supérieures (par exemple, des tenseurs 3D pour les images en couleur).

### Les tenseurs comme conteneurs de données

D'un point de vue computationnel, les tenseurs servent de conteneurs pour des données multidimensionnelles, où chaque dimension peut représenter différentes caractéristiques ou différents aspects des données. Cela rend les tenseurs particulièrement adaptés au traitement de jeux de données complexes dans les tâches de machine learning.

### Tenseurs PyTorch vs tableaux NumPy

Bien que les tenseurs PyTorch soient similaires aux tableaux NumPy dans leur capacité à stocker et manipuler des données numériques, ils offrent des fonctionnalités supplémentaires essentielles au deep learning :

- **Différentiation automatique** : les tenseurs PyTorch prennent en charge le calcul automatique des gradients (autograd), ce qui simplifie le calcul des dérivées nécessaires à l'entraînement des réseaux neuronaux.
- **Accélération GPU** : les tenseurs dans PyTorch peuvent être transférés vers des GPU et utilisés pour les calculs sur ceux-ci, ce qui accélère considérablement les calculs à grande échelle.

### Création de tenseurs dans PyTorch

Vous pouvez créer des tenseurs à l'aide de la fonction `torch.tensor` :
```python
pythonCopy codeimport torch

# Scalar (0D tensor)
tensor0d = torch.tensor(1)

# Vector (1D tensor)
tensor1d = torch.tensor([1, 2, 3])

# Matrix (2D tensor)
tensor2d = torch.tensor([[1, 2],
[3, 4]])

# 3D Tensor
tensor3d = torch.tensor([[[1, 2], [3, 4]],
```

### Types de données des tenseurs

Les tenseurs PyTorch peuvent stocker des données de différents types, tels que des entiers et des nombres à virgule flottante.

Vous pouvez vérifier le type de données d’un tenseur à l’aide de l’attribut `.dtype` :
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Les tenseurs créés à partir d'entiers Python sont de type `torch.int64`.
- Les tenseurs créés à partir de nombres flottants Python sont de type `torch.float32`.

Pour modifier le type de données d'un tenseur, utilisez la méthode `.to()` :
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Opérations courantes sur les tenseurs

PyTorch fournit diverses opérations pour manipuler les tenseurs :

- **Accéder à la forme** : utilisez `.shape` pour obtenir les dimensions d’un tenseur.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Redimensionner les tenseurs** : utilisez `.reshape()` ou `.view()` pour modifier la forme.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Transposer les tenseurs** : utilisez `.T` pour transposer un tenseur 2D.

```python
transposed = tensor2d.T
```

- **Multiplication matricielle** : utilisez `.matmul()` ou l’opérateur `@`.

```python
result = tensor2d @ tensor2d.T
```

### Importance dans le deep learning

Les tenseurs sont essentiels dans PyTorch pour construire et entraîner des réseaux neuronaux :

- Ils stockent les données d’entrée, les poids et les biais.
- Ils facilitent les opérations nécessaires aux passes forward et backward des algorithmes d’entraînement.
- Avec autograd, les tenseurs permettent le calcul automatique des gradients, ce qui simplifie le processus d’optimisation.

## Différentiation automatique

La différentiation automatique (AD) est une technique de calcul utilisée pour **évaluer efficacement et précisément les dérivées (gradients)** des fonctions. Dans le contexte des réseaux neuronaux, l’AD permet de calculer les gradients nécessaires aux **algorithmes d’optimisation comme la descente de gradient**. PyTorch fournit un moteur de différentiation automatique appelé **autograd** qui simplifie ce processus.<sup>[[1]](#references)</sup>

**1. La règle de la chaîne**

### Implémentation de la différentiation automatique dans PyTorch

Voyons maintenant comment PyTorch automatise ce processus.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Rétropropagation dans les réseaux neuronaux plus grands

### **1. Extension aux réseaux multicouches**

Dans les réseaux neuronaux plus grands comportant plusieurs couches, le processus de calcul des gradients devient plus complexe en raison du nombre accru de paramètres et d'opérations. Toutefois, les principes fondamentaux restent les mêmes :<sup>[[1]](#references)</sup>

- **Propagation avant :** Calculer la sortie du réseau en faisant passer les entrées à travers chaque couche.
- **Calcul de la perte :** Évaluer la fonction de perte à l'aide de la sortie du réseau et des labels cibles.
- **Propagation arrière (Backpropagation) :** Calculer les gradients de la perte par rapport à chaque paramètre du réseau en appliquant récursivement la règle de la chaîne, de la couche de sortie vers la couche d'entrée.

### **2. Algorithme de rétropropagation**

- **Étape 1 :** Initialiser les paramètres du réseau (poids et biais).
- **Étape 2 :** Pour chaque exemple d'entraînement, effectuer une propagation avant afin de calculer les sorties.
- **Étape 3 :** Calculer la perte.
- **Étape 4 :** Calculer les gradients de la perte par rapport à chaque paramètre en utilisant la règle de la chaîne.
- **Étape 5 :** Mettre à jour les paramètres à l'aide d'un algorithme d'optimisation (par exemple, la descente de gradient).

### **4. Implémentation avec PyTorch**

PyTorch simplifie ce processus grâce à son moteur autograd.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
Dans ce code :

- **Propagation avant :** Calcule les sorties du réseau.
- **Rétropropagation :** `loss.backward()` calcule les gradients de la perte par rapport à tous les paramètres.
- **Mise à jour des paramètres :** `optimizer.step()` met à jour les paramètres en fonction des gradients calculés.

### **5. Comprendre la rétropropagation**

Pendant la rétropropagation :

- PyTorch parcourt le graphe de calcul dans l'ordre inverse.
- Pour chaque opération, il applique la règle de la chaîne pour calculer les gradients.
- Les gradients sont accumulés dans l'attribut `.grad` de chaque tenseur de paramètres.

### **6. Avantages de la différentiation automatique**

- **Efficacité :** Évite les calculs redondants en réutilisant les résultats intermédiaires.
- **Précision :** Fournit des dérivées exactes jusqu'à la précision machine.
- **Facilité d'utilisation :** Élimine le calcul manuel des dérivées.
