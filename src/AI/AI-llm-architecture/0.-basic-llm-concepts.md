## Pretraining

Pretraining je temeljna faza u razvoju velikog jezičkog modela (LLM), tokom koje se model izlaže ogromnim i raznovrsnim količinama tekstualnih podataka. Tokom ove faze, **LLM uči osnovne strukture, obrasce i nijanse jezika**, uključujući gramatiku, vokabular, sintaksu i kontekstualne odnose. Obradom ovih obimnih podataka, model stiče široko razumevanje jezika i opšte znanje o svetu. Ova sveobuhvatna osnova omogućava LLM-u da generiše koherentan i kontekstualno relevantan tekst. Nakon toga, ovaj pretrained model može proći kroz fine-tuning, tokom kojeg se dodatno trenira na specijalizovanim skupovima podataka kako bi se njegove sposobnosti prilagodile određenim zadacima ili domenima, čime se poboljšavaju njegove performanse i relevantnost u ciljanim primenama.<sup>[[1]](#references)</sup>

## Glavne komponente LLM-a

LLM se obično karakteriše konfiguracijom koja se koristi za njegovo treniranje. Ovo su uobičajene komponente prilikom treniranja LLM-a:<sup>[[1]](#references)[[2]](#references)</sup>

- **Parametri**: Parametri su **težine i bias vrednosti koje neuronska mreža može da uči**. To su brojevi koje proces treniranja prilagođava kako bi minimizovao funkciju gubitka i poboljšao performanse modela na zadatku. LLM-ovi obično koriste milione parametara.
- **Dužina konteksta**: Ovo je maksimalna dužina svake rečenice koja se koristi za pretraining LLM-a.
- **Dimenzija embedding-a**: Veličina vektora koji se koristi za predstavljanje svakog tokena ili reči. LLM-ovi obično koriste milijarde dimenzija.
- **Skrivena dimenzija**: Veličina skrivenih slojeva u neuronskoj mreži.
- **Broj slojeva (dubina)**: Broj slojeva koje model ima. LLM-ovi obično koriste desetine slojeva.
- **Broj attention head-ova**: Kod transformer modela, ovo predstavlja broj odvojenih attention mehanizama koji se koriste u svakom sloju. LLM-ovi obično koriste desetine head-ova.
- **Dropout**: Dropout je nešto poput procenta podataka koji se uklanja (verovatnoće se postavljaju na 0) tokom treniranja, a koristi se za **sprečavanje overfitting-a.** LLM-ovi obično koriste između 0 i 20%.

Konfiguracija GPT-2 modela:
```json

```
## Tenzori u PyTorch-u

U PyTorch-u, **tenzor** je osnovna struktura podataka koja služi kao višedimenzionalni niz, proširujući koncepte kao što su skalari, vektori i matrice na potencijalno više dimenzija. Tenzori su primarni način predstavljanja i manipulisanja podacima u PyTorch-u, naročito u kontekstu deep learning-a i neuronskih mreža.<sup>[[1]](#references)</sup>

### Matematički koncept tenzora

- **Skalari**: Tenzori ranga 0, koji predstavljaju jedan broj (nulte dimenzije). Na primer: 5
- **Vektori**: Tenzori ranga 1, koji predstavljaju jednodimenzionalni niz brojeva. Na primer: \[5,1]
- **Matrice**: Tenzori ranga 2, koji predstavljaju dvodimenzionalne nizove sa vrstama i kolonama. Na primer: \[\[1,3], \[5,2]]
- **Tenzori višeg ranga**: Tenzori ranga 3 ili višeg, koji predstavljaju podatke u višim dimenzijama (npr. 3D tenzori za slike u boji).

### Tenzori kao kontejneri podataka

Iz računarske perspektive, tenzori deluju kao kontejneri za višedimenzionalne podatke, pri čemu svaka dimenzija može predstavljati različite karakteristike ili aspekte podataka. To čini tenzore veoma pogodnim za rad sa složenim skupovima podataka u zadacima machine learning-a.

### PyTorch tenzori naspram NumPy nizova

Iako su PyTorch tenzori slični NumPy nizovima po mogućnosti skladištenja i manipulisanja numeričkim podacima, oni nude dodatne funkcionalnosti ključne za deep learning:

- **Automatska diferencijacija**: PyTorch tenzori podržavaju automatsko izračunavanje gradijenata (autograd), što pojednostavljuje proces izračunavanja izvoda potrebnih za obučavanje neuronskih mreža.
- **GPU ubrzanje**: Tenzori u PyTorch-u mogu se prebaciti na GPU i obrađivati na njemu, što značajno ubrzava proračune velikih razmera.

### Kreiranje tenzora u PyTorch-u

Tenzore možete kreirati pomoću funkcije `torch.tensor`:

### Tipovi podataka tenzora

PyTorch tenzori mogu skladištiti podatke različitih tipova, kao što su celi brojevi i brojevi s pokretnim zarezom.

Tip podataka tenzora možete proveriti pomoću atributa `.dtype`:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Tenzori kreirani iz Python celih brojeva su tipa `torch.int64`.
- Tenzori kreirani iz Python decimalnih brojeva su tipa `torch.float32`.

Da biste promenili tip podataka tenzora, koristite metodu `.to()`:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Uobičajene Tensor operacije

PyTorch pruža različite operacije za manipulisanje tensorima:

- **Pristupanje obliku**: Koristite `.shape` da biste dobili dimenzije tensora.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Promena oblika tensora**: Koristite `.reshape()` ili `.view()` da biste promenili oblik.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Transponovanje tensora**: Koristite `.T` da biste transponovali 2D tensor.

```python
transposed = tensor2d.T
```

- **Množenje matrica**: Koristite `.matmul()` ili operator `@`.

```python
result = tensor2d @ tensor2d.T
```

### Važnost u Deep Learning-u

Tensori su neophodni u PyTorch-u za izgradnju i treniranje neuralnih mreža:

- U njima se čuvaju ulazni podaci, težine i bias vrednosti.
- Omogućavaju operacije potrebne za forward i backward prolaze u algoritmima treniranja.
- Uz autograd, tensori omogućavaju automatsko izračunavanje gradijenata, čime se pojednostavljuje proces optimizacije.

## Automatsko diferenciranje

Automatsko diferenciranje (AD) je računarska tehnika koja se koristi za **efikasno i precizno izračunavanje izvoda (gradijenata)** funkcija. U kontekstu neuralnih mreža, AD omogućava izračunavanje gradijenata potrebnih za **algoritme optimizacije poput gradijentnog spusta**. PyTorch pruža engine za automatsko diferenciranje pod nazivom **autograd**, koji pojednostavljuje ovaj proces.<sup>[[1]](#references)</sup>

### Matematičko objašnjenje automatskog diferenciranja

### Implementacija automatskog diferenciranja u PyTorch-u

Sada pogledajmo kako PyTorch automatizuje ovaj proces.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Backpropagation u većim neuronskim mrežama

### **1.Proširivanje na višeslojne mreže**

U većim neuronskim mrežama sa više slojeva, proces izračunavanja gradijenata postaje složeniji zbog povećanog broja parametara i operacija. Međutim, osnovni principi ostaju isti:<sup>[[1]](#references)</sup>

- **Prolaz unapred:** Izračunajte izlaz mreže prosleđivanjem ulaza kroz svaki sloj.
- **Izračunavanje gubitka:** Izračunajte funkciju gubitka koristeći izlaz mreže i ciljne oznake.
- **Prolaz unazad (Backpropagation):** Izračunajte gradijente gubitka u odnosu na svaki parametar u mreži rekurzivnom primenom lančanog pravila, počevši od izlaznog sloja i krećući se ka ulaznom sloju.

### **2. Algoritam za Backpropagation**

- **Korak 1:** Inicijalizujte parametre mreže (težine i bias vrednosti).
- **Korak 2:** Za svaki primer za obuku izvršite prolaz unapred da biste izračunali izlaze.
- **Korak 3:** Izračunajte gubitak.
- **Korak 4:** Izračunajte gradijente gubitka u odnosu na svaki parametar koristeći lančano pravilo.
- **Korak 5:** Ažurirajte parametre pomoću algoritma za optimizaciju (npr. gradient descent).

### **4. PyTorch implementacija**

PyTorch pojednostavljuje ovaj proces pomoću svog autograd mehanizma.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
U ovom kodu:

- **Prosledni prolaz:** Izračunava izlaze mreže.
- **Povratni prolaz:** `loss.backward()` izračunava gradijente gubitka u odnosu na sve parametre.
- **Ažuriranje parametara:** `optimizer.step()` ažurira parametre na osnovu izračunatih gradijenata.

### **5. Razumevanje povratnog prolaza**

Tokom povratnog prolaza:

- PyTorch prolazi kroz računarski graf obrnutim redosledom.
- Za svaku operaciju primenjuje lančano pravilo kako bi izračunao gradijente.
- Gradijenti se akumuliraju u atributu `.grad` svakog tenzora parametra.

### **6. Prednosti automatskog diferenciranja**

- **Efikasnost:** Izbegava suvišna izračunavanja ponovnim korišćenjem međurezultata.
- **Preciznost:** Obezbeđuje tačne izvode do preciznosti mašine.
- **Jednostavnost upotrebe:** Uklanja potrebu za ručnim izračunavanjem izvoda.
