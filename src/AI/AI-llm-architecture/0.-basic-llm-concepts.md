## Попереднє навчання

Попереднє навчання — це фундаментальний етап розробки великої мовної моделі (LLM), під час якого модель отримує величезні та різноманітні обсяги текстових даних. На цьому етапі **LLM вивчає фундаментальні структури, закономірності та нюанси мови**, зокрема граматику, словниковий запас, синтаксис і контекстні взаємозв’язки. Обробляючи ці великі обсяги даних, модель набуває широкого розуміння мови та загальних знань про світ. Ця комплексна база дає змогу LLM генерувати зв’язний і контекстно релевантний текст. Надалі цю попередньо навчену модель можна піддати fine-tuning, під час якого вона додатково навчається на спеціалізованих наборах даних для адаптації своїх можливостей до конкретних завдань або сфер, що підвищує її продуктивність і релевантність у цільових застосуваннях.<sup>[[1]](#references)</sup>

## Основні компоненти LLM

LLM зазвичай характеризується своєю архітектурою та конфігурацією навчання. Нижче наведено поширені компоненти, задіяні в її навчанні:<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Параметри**: Параметри — це **навчувані ваги та зміщення** у нейронній мережі. Це числа, які процес навчання коригує для мінімізації функції втрат і покращення продуктивності моделі під час виконання завдання. LLM зазвичай використовують мільйони параметрів.
- **Довжина контексту**: Максимальна довжина кожного речення, що використовується для попереднього навчання LLM.
- **Розмірність embedding**: Розмір вектора, що використовується для представлення кожного токена або слова. LLM зазвичай використовують мільярди вимірів.
- **Прихована розмірність**: Розмір прихованих шарів у нейронній мережі.
- **Кількість шарів (глибина)**: Кількість шарів у моделі. LLM зазвичай використовують десятки шарів.
- **Кількість attention heads**: У моделях-трансформерах це кількість окремих механізмів attention, що використовуються в кожному шарі. LLM зазвичай використовують десятки heads.
- **Dropout**: Dropout — це приблизно відсоток даних, які видаляються (ймовірності перетворюються на 0) під час навчання для **запобігання перенавчанню**. LLM зазвичай використовують від 0 до 20%.

## Тензори в PyTorch

У PyTorch **тензор** — це фундаментальна структура даних, яка функціонує як багатовимірний масив, узагальнюючи такі поняття, як скаляри, вектори та матриці, до потенційно вищих вимірностей. Тензори є основним способом представлення та обробки даних у PyTorch, особливо в контексті deep learning і нейронних мереж.<sup>[[1]](#references)</sup>

### Математичне поняття тензорів

- **Скалярі**: тензори рангу 0, що представляють одне число (нульовимірні). Наприклад: 5
- **Вектори**: тензори рангу 1, що представляють одновимірний масив чисел. Наприклад: \[5,1]
- **Матриці**: тензори рангу 2, що представляють двовимірні масиви з рядками та стовпцями. Наприклад: \[\[1,3], \[5,2]]
- **Тензори вищого рангу**: тензори рангу 3 або вище, що представляють дані у вищих вимірах (наприклад, 3D-тензори для кольорових зображень).

### Тензори як контейнери даних

З обчислювальної перспективи тензори функціонують як контейнери для багатовимірних даних, де кожен вимір може представляти різні характеристики або аспекти даних. Це робить тензори дуже придатними для роботи зі складними наборами даних у завданнях machine learning.

### Тензори PyTorch проти масивів NumPy

Хоча тензори PyTorch подібні до масивів NumPy за здатністю зберігати та обробляти числові дані, вони пропонують додаткові функціональні можливості, важливі для deep learning:

- **Автоматичне диференціювання**: тензори PyTorch підтримують автоматичне обчислення градієнтів (autograd), що спрощує процес обчислення похідних, необхідних для навчання нейронних мереж.
- **GPU-прискорення**: тензори в PyTorch можна переміщувати на GPU та виконувати на них обчислення, що значно пришвидшує масштабні обчислення.

### Створення тензорів у PyTorch

Ви можете створювати тензори за допомогою функції `torch.tensor`:
```python
pythonCopy codeimport torch

# Scalar (0D tensor)
tensor0d = torch.tensor(1)

# Vector (1D tensor)
tensor1d = torch.tensor([1, 2, 3])

# Matrix (2D tensor)
```

### Типи даних Tensor

Tensor PyTorch можуть зберігати дані різних типів, як-от цілі числа та числа з плаваючою комою.

Перевірити тип даних tensor можна за допомогою атрибута `.dtype`:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Тензори, створені з цілих чисел Python, мають тип `torch.int64`.
- Тензори, створені з чисел з плаваючою комою Python, мають тип `torch.float32`.

Щоб змінити тип даних тензора, використовуйте метод `.to()`:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Поширені операції з Tensor

PyTorch надає різноманітні операції для роботи з tensors:

- **Отримання форми**: використовуйте `.shape`, щоб отримати розмірності tensor.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Зміна форми tensors**: використовуйте `.reshape()` або `.view()`, щоб змінити форму.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Транспонування tensors**: використовуйте `.T`, щоб транспонувати 2D tensor.

```python
transposed = tensor2d.T
```

- **Матричне множення**: використовуйте `.matmul()` або оператор `@`.

```python
result = tensor2d @ tensor2d.T
```

### Важливість у Deep Learning

Tensors мають важливе значення в PyTorch для створення та training neural networks:

- Вони зберігають вхідні дані, ваги та bias.
- Вони забезпечують виконання операцій, необхідних для прямого та зворотного проходів у training algorithms.
- Разом із autograd tensors забезпечують автоматичне обчислення gradients, спрощуючи процес optimization.

## Автоматичне диференціювання

Automatic differentiation (AD) — це обчислювальна техніка, що використовується для ефективного й точного **обчислення похідних (gradients)** функцій. У контексті neural networks AD дає змогу обчислювати gradients, необхідні для **optimization algorithms, як-от gradient descent**. PyTorch надає engine automatic differentiation під назвою **autograd**, який спрощує цей процес.<sup>[[1]](#references)</sup>

### Математичне пояснення Automatic Differentiation

### Реалізація Automatic Differentiation у PyTorch

Тепер розглянемо, як PyTorch автоматизує цей процес.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Зворотне поширення помилки у більших нейронних мережах

### **1. Розширення до багатошарових мереж**

У більших нейронних мережах із кількома шарами процес обчислення градієнтів стає складнішим через збільшення кількості параметрів і операцій. Однак фундаментальні принципи залишаються незмінними:<sup>[[1]](#references)</sup>

- **Прямий прохід:** Обчислити вихід мережі, передаючи вхідні дані через кожен шар.
- **Обчислення функції втрат:** Обчислити значення функції втрат, використовуючи вихід мережі та цільові мітки.
- **Зворотний прохід (Backpropagation):** Обчислити градієнти функції втрат відносно кожного параметра мережі, рекурсивно застосовуючи chain rule від вихідного шару до вхідного.

### **2. Алгоритм Backpropagation**

- **Крок 1:** Ініціалізувати параметри мережі (ваги та зміщення).
- **Крок 2:** Для кожного навчального прикладу виконати прямий прохід, щоб обчислити вихідні значення.
- **Крок 3:** Обчислити функцію втрат.
- **Крок 4:** Обчислити градієнти функції втрат відносно кожного параметра, використовуючи chain rule.
- **Крок 5:** Оновити параметри за допомогою алгоритму оптимізації (наприклад, gradient descent).

### **4. Реалізація в PyTorch**

PyTorch спрощує цей процес за допомогою свого механізму autograd.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
У цьому коді:

- **Forward Pass:** Обчислює вихідні дані мережі.
- **Backward Pass:** `loss.backward()` обчислює градієнти функції втрат відносно всіх параметрів.
- **Parameter Update:** `optimizer.step()` оновлює параметри на основі обчислених градієнтів.

### **5. Розуміння Backward Pass**

Під час backward pass:

- PyTorch проходить обчислювальний граф у зворотному порядку.
- Для кожної операції застосовується правило ланцюга для обчислення градієнтів.
- Градієнти накопичуються в атрибуті `.grad` кожного тензора параметрів.

### **6. Переваги автоматичного диференціювання**

- **Ефективність:** Уникає надлишкових обчислень, повторно використовуючи проміжні результати.
- **Точність:** Забезпечує точні похідні з точністю до машинної.
- **Простота використання:** Усуває необхідність ручного обчислення похідних.
