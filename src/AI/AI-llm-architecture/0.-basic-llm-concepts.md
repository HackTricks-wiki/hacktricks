## Preentrenamiento

El preentrenamiento es la fase fundamental en el desarrollo de un modelo de lenguaje grande (LLM), en la que el modelo se expone a cantidades enormes y diversas de datos de texto. Durante esta etapa, **el LLM aprende las estructuras, los patrones y los matices fundamentales del lenguaje**, incluidos la gramática, el vocabulario, la sintaxis y las relaciones contextuales. Al procesar estos datos extensos, el modelo adquiere una comprensión amplia del lenguaje y conocimientos generales sobre el mundo. Esta base integral permite al LLM generar texto coherente y relevante desde el punto de vista contextual. Posteriormente, este modelo preentrenado puede someterse a un fine-tuning, durante el cual se entrena con conjuntos de datos especializados para adaptar sus capacidades a tareas o dominios específicos, mejorando su rendimiento y relevancia en aplicaciones concretas.<sup>[[1]](#references)</sup>

## Componentes principales de los LLM

Un LLM suele caracterizarse por su arquitectura y configuración de entrenamiento. Estos son los componentes comunes implicados en el entrenamiento de uno:<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Parámetros**: Los parámetros son los **pesos y sesgos ajustables** de la red neuronal. Son los números que el proceso de entrenamiento ajusta para minimizar la función de pérdida y mejorar el rendimiento del modelo en la tarea. Los LLM suelen utilizar millones de parámetros.
- **Longitud del contexto**: Es la longitud máxima de cada oración utilizada para preentrenar el LLM.
- **Dimensión de embedding**: Es el tamaño del vector utilizado para representar cada token o palabra. Los LLM suelen utilizar miles de millones de dimensiones.
- **Dimensión oculta**: Es el tamaño de las capas ocultas de la red neuronal.
- **Número de capas (profundidad)**: Es el número de capas que tiene el modelo. Los LLM suelen utilizar decenas de capas.
- **Número de cabezales de atención**: En los modelos transformer, es el número de mecanismos de atención independientes utilizados en cada capa. Los LLM suelen utilizar decenas de cabezales.
- **Dropout**: El dropout es algo parecido al porcentaje de datos que se elimina (las probabilidades se convierten en 0) durante el entrenamiento, utilizado para **evitar el sobreajuste.** Los LLM suelen utilizar entre un 0 y un 20 %.

## Tensors en PyTorch

En PyTorch, un **tensor** es una estructura de datos fundamental que funciona como un array multidimensional y generaliza conceptos como escalares, vectores y matrices a dimensiones potencialmente superiores. Los tensors son la forma principal de representar y manipular datos en PyTorch, especialmente en el contexto del deep learning y las redes neuronales.<sup>[[1]](#references)</sup>

### Concepto matemático de los Tensors

- **Escalares**: Tensors de rango 0, que representan un único número (cero dimensiones). Como: 5
- **Vectores**: Tensors de rango 1, que representan un array unidimensional de números. Como: \[5,1]
- **Matrices**: Tensors de rango 2, que representan arrays bidimensionales con filas y columnas. Como: \[\[1,3], \[5,2]]
- **Tensors de rango superior**: Tensors de rango 3 o superior, que representan datos en dimensiones superiores (por ejemplo, tensors 3D para imágenes en color).

### Tensors como contenedores de datos

Desde una perspectiva computacional, los tensors actúan como contenedores para datos multidimensionales, donde cada dimensión puede representar distintas características o aspectos de los datos. Esto hace que los tensors sean muy adecuados para gestionar datasets complejos en tareas de machine learning.

### Tensors de PyTorch frente a arrays de NumPy

Aunque los tensors de PyTorch son similares a los arrays de NumPy en su capacidad para almacenar y manipular datos numéricos, ofrecen funcionalidades adicionales cruciales para el deep learning:

- **Diferenciación automática**: Los tensors de PyTorch permiten el cálculo automático de gradientes (autograd), lo que simplifica el proceso de calcular las derivadas necesarias para entrenar redes neuronales.
- **Aceleración mediante GPU**: Los tensors en PyTorch pueden transferirse a GPU y utilizarse para realizar cálculos en ellas, acelerando significativamente los cálculos a gran escala.

### Creación de Tensors en PyTorch

Puedes crear tensors utilizando la función `torch.tensor`:

### Tipos de datos de los tensores

Los tensores de PyTorch pueden almacenar datos de varios tipos, como números enteros y de punto flotante.

Puedes comprobar el tipo de datos de un tensor mediante el atributo `.dtype`:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Los tensores creados a partir de enteros de Python son de tipo `torch.int64`.
- Los tensores creados a partir de números de punto flotante de Python son de tipo `torch.float32`.

Para cambiar el tipo de datos de un tensor, usa el método `.to()`:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Operaciones comunes con tensores

PyTorch proporciona una variedad de operaciones para manipular tensores:

- **Acceder a la forma**: Usa `.shape` para obtener las dimensiones de un tensor.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Cambiar la forma de los tensores**: Usa `.reshape()` o `.view()` para cambiar la forma.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Transponer tensores**: Usa `.T` para transponer un tensor 2D.

```python
transposed = tensor2d.T
```

- **Multiplicación de matrices**: Usa `.matmul()` o el operador `@`.

```python
result = tensor2d @ tensor2d.T
```

### Importancia en Deep Learning

Los tensores son esenciales en PyTorch para crear y entrenar redes neuronales:

- Almacenan datos de entrada, pesos y sesgos.
- Facilitan las operaciones necesarias para los pases forward y backward en los algoritmos de entrenamiento.
- Con autograd, los tensores permiten el cálculo automático de gradientes, simplificando el proceso de optimización.

## Diferenciación automática

La diferenciación automática (AD) es una técnica computacional utilizada para **evaluar las derivadas (gradientes)** de funciones de manera eficiente y precisa. En el contexto de las redes neuronales, AD permite calcular los gradientes necesarios para **algoritmos de optimización como el descenso de gradiente**. PyTorch proporciona un motor de diferenciación automática llamado **autograd** que simplifica este proceso.<sup>[[1]](#references)</sup>

### Implementación de la diferenciación automática en PyTorch

Ahora, veamos cómo PyTorch automatiza este proceso.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Backpropagation en Redes Neuronales Más Grandes

### **1. Extensión a Redes Multicapa**

En las redes neuronales más grandes con múltiples capas, el proceso de cálculo de gradientes se vuelve más complejo debido al mayor número de parámetros y operaciones. Sin embargo, los principios fundamentales siguen siendo los mismos:<sup>[[1]](#references)</sup>

- **Forward Pass:** Calcular la salida de la red pasando las entradas por cada capa.
- **Calcular la Pérdida:** Evaluar la función de pérdida utilizando la salida de la red y las etiquetas objetivo.
- **Backward Pass (Backpropagation):** Calcular los gradientes de la pérdida con respecto a cada parámetro de la red aplicando la regla de la cadena de forma recursiva desde la capa de salida hasta la capa de entrada.

### **2. Algoritmo de Backpropagation**

- **Paso 1:** Inicializar los parámetros de la red (pesos y sesgos).
- **Paso 2:** Para cada ejemplo de entrenamiento, realizar un forward pass para calcular las salidas.
- **Paso 3:** Calcular la pérdida.
- **Paso 4:** Calcular los gradientes de la pérdida con respecto a cada parámetro utilizando la regla de la cadena.
- **Paso 5:** Actualizar los parámetros utilizando un algoritmo de optimización (por ejemplo, descenso de gradiente).

### **4. Implementación en PyTorch**

PyTorch simplifica este proceso con su motor autograd.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
En este código:

- **Pasada hacia adelante:** Calcula las salidas de la red.
- **Pasada hacia atrás:** `loss.backward()` calcula los gradientes de la pérdida con respecto a todos los parámetros.
- **Actualización de parámetros:** `optimizer.step()` actualiza los parámetros basándose en los gradientes calculados.

### **5. Comprender la pasada hacia atrás**

Durante la pasada hacia atrás:

- PyTorch recorre el grafo computacional en orden inverso.
- Para cada operación, aplica la regla de la cadena para calcular los gradientes.
- Los gradientes se acumulan en el atributo `.grad` de cada tensor de parámetros.

### **6. Ventajas de la diferenciación automática**

- **Eficiencia:** Evita cálculos redundantes al reutilizar resultados intermedios.
- **Precisión:** Proporciona derivadas exactas hasta la precisión de la máquina.
- **Facilidad de uso:** Elimina la necesidad de calcular manualmente las derivadas.
