## Pretraining

Pretrainingは、大規模言語モデル（LLM）の開発における基盤段階であり、モデルに膨大かつ多様なテキストデータを与えます。この段階で、**LLMは文法、語彙、構文、文脈上の関係性など、言語の基本的な構造、パターン、ニュアンスを学習します**。この広範なデータを処理することで、モデルは言語に対する幅広い理解と、一般的な世界知識を獲得します。この包括的な基盤により、LLMは一貫性があり、文脈に即したテキストを生成できるようになります。その後、このPretraining済みモデルに対してFine-tuningを行い、特定のタスクや分野に対応できるよう、専門的なデータセットで追加学習することで、対象となる用途での性能と適合性を高めることができます。<sup>[[1]](#references)</sup>

## LLMの主なコンポーネント

LLMは通常、そのアーキテクチャとtraining configurationによって特徴づけられます。以下は、LLMのtrainingに関わる一般的なコンポーネントです。<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Parameters**: Parametersは、neural network内の**学習可能なweights and biases**です。これらは、loss functionを最小化し、タスクにおけるモデルの性能を向上させるために、training processで調整される数値です。LLMでは通常、数百万個のparametersが使用されます。
- **Context Length**: LLMのpre-trainingに使用される各文の最大長です。
- **Embedding Dimension**: 各tokenまたは単語を表現するために使用されるvectorのサイズです。LLMでは通常、数十億個のdimensionsが使用されます。
- **Hidden Dimension**: neural network内のhidden layersのサイズです。
- **Number of Layers (Depth)**: モデルが持つlayersの数です。LLMでは通常、数十個のlayersが使用されます。
- **Number of Attention Heads**: transformer modelsでは、各layerで使用される独立したattention mechanismsの数です。LLMでは通常、数十個のheadsが使用されます。
- **Dropout**: Dropoutは、**overfittingを防止するために**、training中に削除されるデータの割合（probabilitiesが0になる）のようなものです。LLMでは通常、0～20%が使用されます。

## PyTorchにおけるテンソル

PyTorchでは、**テンソル**は多次元配列として機能する基本的なデータ構造であり、スカラー、ベクトル、行列などの概念を、場合によってはさらに高い次元へ一般化したものです。テンソルは、特に deep learning や neural networks の文脈において、PyTorchでデータを表現・操作する主要な方法です。<sup>[[1]](#references)</sup>

### テンソルの数学的概念

- **スカラー**: rank 0 のテンソルで、単一の数値（0次元）を表します。例: 5
- **ベクトル**: rank 1 のテンソルで、数値の1次元配列を表します。例: \[5,1]
- **行列**: rank 2 のテンソルで、行と列を持つ2次元配列を表します。例: \[\[1,3], \[5,2]]
- **高ランクテンソル**: rank 3 以上のテンソルで、高次元のデータを表します（例: color images 用の3Dテンソル）。

### データコンテナとしてのテンソル

計算の観点では、テンソルは多次元データのコンテナとして機能し、各次元はデータの異なる特徴や側面を表すことができます。このため、テンソルは machine learning のタスクにおける複雑なデータセットの処理に非常に適しています。

### PyTorchテンソルとNumPy配列

PyTorchテンソルは、数値データを保存・操作できる点でNumPy配列と似ていますが、deep learning に不可欠な追加機能を提供します。

- **自動微分**: PyTorchテンソルは勾配の自動計算（autograd）をサポートしており、neural networks のトレーニングに必要な導関数の計算プロセスを簡略化します。
- **GPUアクセラレーション**: PyTorchのテンソルはGPUに移動してGPU上で計算できるため、大規模な計算を大幅に高速化できます。

### Tensor Data Types

PyTorch tensorsは、整数や浮動小数点数など、さまざまな型のデータを格納できます。

`.dtype`属性を使用して、tensorのデータ型を確認できます：
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Python の整数から作成された Tensor の型は `torch.int64` です。
- Python の浮動小数点数から作成された Tensor の型は `torch.float32` です。

Tensor のデータ型を変更するには、`.to()` メソッドを使用します。
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```

PyTorch には、tensor を操作するためのさまざまな操作が用意されています。

```python

```

- **Tensor の reshape**: `.reshape()` または `.view()` を使用して、shape を変更します。


- **Tensor の転置**: `.T` を使用して、2D tensor を転置します。

```python

```

- **行列の乗算**: `.matmul()` または `@` operator を使用します。

```python
result = tensor2d @ tensor2d.T
```

### Deep Learning における重要性

Tensor は、neural network の構築と training において PyTorch に不可欠です。

- input data、weights、biases を格納します。
- training algorithm における forward pass と backward pass に必要な操作を実行できます。
- autograd により、tensor は gradients の自動計算を可能にし、optimization process を効率化します。

## Automatic Differentiation

Automatic differentiation（AD）は、関数の **derivatives（gradients）を効率的かつ正確に評価する**ために使用される computational technique です。neural network の context では、AD により **gradient descent などの optimization algorithm** に必要な gradients を計算できます。PyTorch には、この process を簡略化する automatic differentiation engine である **autograd** が用意されています。<sup>[[1]](#references)</sup>

### Automatic Differentiation の数学的説明

**1. Chain Rule**

automatic differentiation の中心にあるのは、calculus における **chain rule** です。chain rule は、複数の関数の composition がある場合、composite function の derivative は、構成要素となる関数の derivatives の積であると示します。

数学的には、`y=f(u)` および `u=g(x)` の場合、`y` の `x` に対する derivative は次のようになります。

### PyTorch における Automatic Differentiation の実装

それでは、PyTorch がこの process をどのように自動化するかを見てみましょう。

```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
```

## より大規模なニューラルネットワークにおけるバックプロパゲーション

### **1. 多層ネットワークへの拡張**

複数の層を持つ大規模なニューラルネットワークでは、パラメータと演算の数が増えるため、勾配を計算するプロセスはより複雑になります。ただし、基本原理は同じです。<sup>[[1]](#references)</sup>

- **Forward Pass:** 各層に入力を通して、ネットワークの出力を計算します。
- **Compute Loss:** ネットワークの出力と正解ラベルを使用して、損失関数を評価します。
- **Backward Pass (Backpropagation):** 出力層から入力層に向かって連鎖律を再帰的に適用し、ネットワーク内の各パラメータに対する損失の勾配を計算します。

### **2. Backpropagation Algorithm**

- **Step 1:** ネットワークのパラメータ（重みとバイアス）を初期化します。
- **Step 2:** 各訓練例について、Forward Passを実行して出力を計算します。
- **Step 3:** 損失を計算します。
- **Step 4:** 連鎖律を使用して、各パラメータに対する損失の勾配を計算します。
- **Step 5:** 最適化アルゴリズム（例：gradient descent）を使用してパラメータを更新します。

### **4. PyTorch Implementation**

PyTorchのautograd engineによって、このプロセスを簡単に実行できます。
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
このコードでは：

- **Forward Pass:** ネットワークの出力を計算します。
- **Backward Pass:** `loss.backward()` は、すべてのパラメータに対する損失の勾配を計算します。
- **Parameter Update:** `optimizer.step()` は、計算された勾配に基づいてパラメータを更新します。

### **5. Backward Pass の理解**

Backward Pass では：

- PyTorch は computational graph を逆順にたどります。
- 各操作に対して chain rule を適用し、勾配を計算します。
- 勾配は各パラメータテンソルの `.grad` 属性に蓄積されます。

### **6. Automatic Differentiation の利点**

- **Efficiency:** 中間結果を再利用することで、冗長な計算を回避します。
- **Accuracy:** machine precision の範囲内で正確な導関数を提供します。
- **Ease of Use:** 導関数の手動計算が不要になります。
