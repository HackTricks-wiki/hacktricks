## 预训练

预训练是开发大型语言模型（LLM）的基础阶段，在此阶段，模型会接触数量庞大且多样化的文本数据。在这一阶段，**LLM 学习语言的基本结构、模式和细微差别**，包括语法、词汇、句法和上下文关系。通过处理这些海量数据，模型获得对语言和一般世界知识的广泛理解。这一全面的基础使 LLM 能够生成连贯且符合上下文的文本。随后，这个预训练模型可以进行微调，即使用专门的数据集对其进一步训练，使其能力适应特定任务或领域，从而提升其在目标应用中的性能和相关性。<sup>[[1]](#references)</sup>

## LLM 的主要组件

通常，LLM 的特征由训练时使用的配置决定。以下是训练 LLM 时的常见组件：<sup>[[1]](#references)[[2]](#references)</sup>

- **参数（Parameters）**：参数是神经网络中的**可学习权重和偏置**。训练过程会调整这些数值，以最小化损失函数并提升模型在任务上的性能。LLM 通常使用数百万个参数。
- **上下文长度（Context Length）**：这是用于预训练 LLM 的每个句子的最大长度。
- **嵌入维度（Embedding Dimension）**：用于表示每个 token 或单词的向量大小。LLM 通常使用数十亿个维度。
- **隐藏维度（Hidden Dimension）**：神经网络中隐藏层的大小。
- **层数（深度）（Number of Layers (Depth)）**：模型包含的层数。LLM 通常使用几十层。
- **注意力头数量（Number of Attention Heads）**：在 transformer 模型中，这是每层使用的独立注意力机制的数量。LLM 通常使用几十个注意力头。
- **Dropout**：Dropout 类似于训练期间被移除的数据百分比（概率变为 0），用于**防止过拟合。**LLM 通常使用 0-20% 的 Dropout。

GPT-2 模型的配置：

## PyTorch 中的张量

在 PyTorch 中，**张量**是一种基础数据结构，充当多维数组，将标量、向量和矩阵等概念推广到更高维度。张量是 PyTorch 中表示和操作数据的主要方式，尤其是在深度学习和神经网络环境中。<sup>[[1]](#references)</sup>

### 张量的数学概念

- **标量**：秩为 0 的张量，表示单个数字（零维）。例如：5
- **向量**：秩为 1 的张量，表示一维数字数组。例如：\[5,1]
- **矩阵**：秩为 2 的张量，表示包含行和列的二维数组。例如：\[\[1,3], \[5,2]]
- **高阶张量**：秩为 3 或更高的张量，表示更高维度的数据（例如，用于彩色图像的 3D 张量）。

### 作为数据容器的张量

从计算角度来看，张量充当多维数据的容器，其中每个维度都可以表示数据的不同特征或方面。这使张量非常适合处理机器学习任务中的复杂数据集。

### PyTorch 张量与 NumPy 数组

虽然 PyTorch 张量在存储和操作数值数据方面与 NumPy 数组相似，但它们还提供了对深度学习至关重要的额外功能：

- **自动微分**：PyTorch 张量支持自动计算梯度（autograd），从而简化计算训练神经网络所需导数的过程。
- **GPU 加速**：PyTorch 中的张量可以移动到 GPU 上并在 GPU 上进行计算，从而显著加快大规模计算。

### Tensor Data Types

PyTorch tensors can store data of various types, such as integers and floating-point numbers.

You can check a tensor's data type using the `.dtype` attribute:
```python
tensor1d = torch.tensor([1, 2, 3])
```

- 从 Python 整数创建的张量类型为 `torch.int64`。
- 从 Python 浮点数创建的张量类型为 `torch.float32`。

要更改张量的数据类型，请使用 `.to()` 方法：
```python
float_tensor = tensor1d.to(torch.float32)
```

### 在深度学习中的重要性

Tensor 在 PyTorch 中对于构建和训练神经网络至关重要：

- 它们存储输入数据、权重和偏置。
- 它们支持训练算法前向传播和反向传播所需的操作。
- 借助 autograd，Tensor 可以自动计算梯度，从而简化优化过程。

## 自动微分

自动微分（AD）是一种用于高效、准确地**计算函数导数（梯度）**的计算技术。在神经网络中，AD 可以计算**梯度下降等优化算法**所需的梯度。PyTorch 提供了名为 **autograd** 的自动微分引擎来简化这一过程。<sup>[[1]](#references)</sup>

### 自动微分的数学解释

**1. 链式法则**

自动微分的核心是微积分中的**链式法则**。链式法则指出，如果一个函数由多个函数复合而成，那么复合函数的导数等于各个组成函数导数的乘积。

### 在 PyTorch 中实现自动微分

现在，让我们看看 PyTorch 如何自动完成这一过程。
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## 更大规模神经网络中的反向传播

### **1.扩展到多层网络**

在包含多个层的较大规模神经网络中，由于参数和运算数量增加，计算梯度的过程会变得更加复杂。但是，基本原理仍然相同：<sup>[[1]](#references)</sup>

- **前向传播：** 将输入依次传递ผ่าน每一层，计算网络的输出。
- **计算损失：** 使用网络输出和目标标签评估损失函数。
- **反向传播（Backpropagation）：** 应用链式法则，从输出层递归地向输入层计算损失相对于网络中每个参数的梯度。

### **2. 反向传播算法**

- **步骤 1：** 初始化网络参数（权重和偏置）。
- **步骤 2：** 对每个训练样本执行前向传播，计算输出。
- **步骤 3：** 计算损失。
- **步骤 4：** 使用链式法则计算损失相对于每个参数的梯度。
- **步骤 5：** 使用优化算法（例如梯度下降）更新参数。

### **4. PyTorch 实现**

PyTorch 通过其 autograd 引擎简化了这一过程。
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
在此代码中：

- **前向传播：**计算网络的输出。
- **反向传播：**`loss.backward()`计算损失相对于所有参数的梯度。
- **参数更新：**`optimizer.step()`根据计算出的梯度更新参数。

### **5. 理解反向传播**

在反向传播过程中：

- PyTorch 按逆序遍历计算图。
- 对于每个操作，它应用链式法则来计算梯度。
- 梯度会累积到每个参数张量的`.grad`属性中。

### **6. 自动微分的优势**

- **效率：**通过复用中间结果，避免冗余计算。
- **准确性：**提供达到机器精度的精确导数。
- **易用性：**无需手动计算导数。
