## Pretraining

Το Pretraining είναι η θεμελιώδης φάση ανάπτυξης ενός large language model (LLM), κατά την οποία το μοντέλο εκτίθεται σε τεράστιες και ποικίλες ποσότητες δεδομένων κειμένου. Σε αυτό το στάδιο, **το LLM μαθαίνει τις θεμελιώδεις δομές, τα μοτίβα και τις αποχρώσεις της γλώσσας**, συμπεριλαμβανομένων της γραμματικής, του λεξιλογίου, της σύνταξης και των σχέσεων με βάση τα συμφραζόμενα. Επεξεργαζόμενο αυτά τα εκτενή δεδομένα, το μοντέλο αποκτά ευρεία κατανόηση της γλώσσας και γενικές γνώσεις για τον κόσμο. Αυτή η ολοκληρωμένη βάση επιτρέπει στο LLM να παράγει συνεκτικό και σχετικό με τα συμφραζόμενα κείμενο. Στη συνέχεια, αυτό το pretrained μοντέλο μπορεί να υποβληθεί σε fine-tuning, κατά το οποίο εκπαιδεύεται περαιτέρω με εξειδικευμένα datasets, ώστε να προσαρμόσει τις δυνατότητές του σε συγκεκριμένες εργασίες ή τομείς, βελτιώνοντας την απόδοσή του και τη συνάφειά του σε στοχευμένες εφαρμογές.<sup>[[1]](#references)</sup>

## Κύρια στοιχεία των LLM

Ένα LLM χαρακτηρίζεται συνήθως από την αρχιτεκτονική και τη διαμόρφωση εκπαίδευσής του. Αυτά είναι τα συνηθισμένα στοιχεία που συμμετέχουν στην εκπαίδευση ενός τέτοιου μοντέλου:<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Parameters**: Οι Parameters είναι τα **βάρη και οι μεροληψίες που μπορούν να μαθευτούν** στο neural network. Πρόκειται για τους αριθμούς που προσαρμόζει η διαδικασία εκπαίδευσης, ώστε να ελαχιστοποιήσει τη loss function και να βελτιώσει την απόδοση του μοντέλου στην εργασία. Τα LLM χρησιμοποιούν συνήθως εκατομμύρια parameters.
- **Context Length**: Πρόκειται για το μέγιστο μήκος κάθε πρότασης που χρησιμοποιείται για το pre-training του LLM.
- **Embedding Dimension**: Το μέγεθος του vector που χρησιμοποιείται για την αναπαράσταση κάθε token ή λέξης. Τα LLM συνήθως χρησιμοποιούν δισεκατομμύρια dimensions.
- **Hidden Dimension**: Το μέγεθος των hidden layers στο neural network.
- **Number of Layers (Depth)**: Πόσα layers διαθέτει το μοντέλο. Τα LLM χρησιμοποιούν συνήθως δεκάδες layers.
- **Number of Attention Heads**: Στα transformer models, πρόκειται για τον αριθμό των ξεχωριστών attention mechanisms που χρησιμοποιούνται σε κάθε layer. Τα LLM χρησιμοποιούν συνήθως δεκάδες heads.
- **Dropout**: Το Dropout είναι κάτι σαν το ποσοστό των δεδομένων που αφαιρείται (οι πιθανότητες μετατρέπονται σε 0) κατά την εκπαίδευση, με σκοπό την **αποτροπή του overfitting.** Τα LLM χρησιμοποιούν συνήθως ποσοστό μεταξύ 0-20%.

Διαμόρφωση του μοντέλου GPT-2:
```json
GPT_CONFIG_124M = {
"vocab_size": 50257,  // Vocabulary size of the BPE tokenizer
"context_length": 1024, // Context length
"emb_dim": 768,       // Embedding dimension
"n_heads": 12,        // Number of attention heads
"n_layers": 12,       // Number of layers
"drop_rate": 0.1,     // Dropout rate: 10%
"qkv_bias": False     // Query-Key-Value bias
}
```
## Tensors στο PyTorch

Στο PyTorch, ένα **tensor** είναι μια θεμελιώδης δομή δεδομένων που λειτουργεί ως πολυδιάστατος πίνακας, γενικεύοντας έννοιες όπως οι βαθμωτές ποσότητες, τα διανύσματα και οι πίνακες σε δυνητικά υψηλότερες διαστάσεις. Τα tensors είναι ο κύριος τρόπος αναπαράστασης και διαχείρισης δεδομένων στο PyTorch, ιδιαίτερα στο πλαίσιο του deep learning και των neural networks.<sup>[[1]](#references)</sup>

### Μαθηματική έννοια των Tensors

- **Scalars**: Tensors τάξης 0, που αναπαριστούν έναν μόνο αριθμό (μηδενικής διάστασης). Όπως: 5
- **Vectors**: Tensors τάξης 1, που αναπαριστούν έναν μονοδιάστατο πίνακα αριθμών. Όπως: \[5,1]
- **Matrices**: Tensors τάξης 2, που αναπαριστούν δισδιάστατους πίνακες με γραμμές και στήλες. Όπως: \[\[1,3], \[5,2]]
- **Higher-Rank Tensors**: Tensors τάξης 3 ή μεγαλύτερης, που αναπαριστούν δεδομένα σε υψηλότερες διαστάσεις (π.χ. 3D tensors για έγχρωμες εικόνες).

### Tensors ως Containers δεδομένων

Από υπολογιστική άποψη, τα tensors λειτουργούν ως containers για πολυδιάστατα δεδομένα, όπου κάθε διάσταση μπορεί να αναπαριστά διαφορετικά χαρακτηριστικά ή πτυχές των δεδομένων. Αυτό καθιστά τα tensors ιδιαίτερα κατάλληλα για τη διαχείριση σύνθετων datasets σε εργασίες machine learning.

### PyTorch Tensors έναντι NumPy Arrays

Παρότι τα PyTorch tensors είναι παρόμοια με τα NumPy arrays ως προς την ικανότητά τους να αποθηκεύουν και να διαχειρίζονται αριθμητικά δεδομένα, προσφέρουν επιπλέον λειτουργίες που είναι κρίσιμες για το deep learning:

- **Automatic Differentiation**: Τα PyTorch tensors υποστηρίζουν τον αυτόματο υπολογισμό gradients (autograd), γεγονός που απλοποιεί τη διαδικασία υπολογισμού των παραγώγων που απαιτούνται για την εκπαίδευση neural networks.
- **GPU Acceleration**: Τα tensors στο PyTorch μπορούν να μεταφερθούν σε GPUs και να υπολογιστούν σε αυτές, επιταχύνοντας σημαντικά τους υπολογισμούς μεγάλης κλίμακας.

### Δημιουργία Tensors στο PyTorch

### Τύποι Δεδομένων Tensor

Τα tensors του PyTorch μπορούν να αποθηκεύουν δεδομένα διαφόρων τύπων, όπως ακέραιους και αριθμούς κινητής υποδιαστολής.

Μπορείτε να ελέγξετε τον τύπο δεδομένων ενός tensor χρησιμοποιώντας το attribute `.dtype`:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Τα Tensors που δημιουργούνται από Python ακέραιους είναι τύπου `torch.int64`.
- Τα Tensors που δημιουργούνται από Python αριθμούς κινητής υποδιαστολής είναι τύπου `torch.float32`.

Για να αλλάξετε τον τύπο δεδομένων ενός Tensor, χρησιμοποιήστε τη μέθοδο `.to()`:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```

Το PyTorch παρέχει μια ποικιλία λειτουργιών για τον χειρισμό τανυστών:

- **Μετάθεση τανυστών**: Χρησιμοποιήστε το `.T` για να κάνετε μετάθεση ενός δισδιάστατου τανυστή.

- **Πολλαπλασιασμός πινάκων**: Χρησιμοποιήστε το `.matmul()` ή τον τελεστή `@`.

### Σημασία στο Deep Learning

Οι τανυστές είναι απαραίτητοι στο PyTorch για τη δημιουργία και την εκπαίδευση neural networks:

- Αποθηκεύουν δεδομένα εισόδου, weights και biases.
- Διευκολύνουν τις λειτουργίες που απαιτούνται για τα forward και backward passes στους αλγόριθμους εκπαίδευσης.
- Με το autograd, οι τανυστές επιτρέπουν τον αυτόματο υπολογισμό gradients, απλοποιώντας τη διαδικασία optimization.

## Automatic Differentiation

Το Automatic differentiation (AD) είναι μια υπολογιστική τεχνική που χρησιμοποιείται για την **αποτελεσματική και ακριβή αξιολόγηση των παραγώγων (gradients)** συναρτήσεων. Στο πλαίσιο των neural networks, το AD επιτρέπει τον υπολογισμό των gradients που απαιτούνται για **αλγορίθμους optimization όπως το gradient descent**. Το PyTorch παρέχει έναν μηχανισμό automatic differentiation που ονομάζεται **autograd** και απλοποιεί αυτήν τη διαδικασία.<sup>[[1]](#references)</sup>

### Υλοποίηση του Automatic Differentiation στο PyTorch

Τώρα, ας δούμε πώς το PyTorch αυτοματοποιεί αυτήν τη διαδικασία.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Backpropagation σε μεγαλύτερα νευρωνικά δίκτυα

### **1. Επέκταση σε δίκτυα πολλαπλών επιπέδων**

Σε μεγαλύτερα νευρωνικά δίκτυα με πολλαπλά επίπεδα, η διαδικασία υπολογισμού των gradients γίνεται πιο σύνθετη λόγω του αυξημένου αριθμού παραμέτρων και πράξεων. Ωστόσο, οι θεμελιώδεις αρχές παραμένουν ίδιες:<sup>[[1]](#references)</sup>

- **Forward Pass:** Υπολογίστε την έξοδο του δικτύου περνώντας τις εισόδους από κάθε επίπεδο.
- **Υπολογισμός Loss:** Αξιολογήστε τη συνάρτηση loss χρησιμοποιώντας την έξοδο του δικτύου και τις ετικέτες-στόχους.
- **Backward Pass (Backpropagation):** Υπολογίστε τα gradients του loss ως προς κάθε παράμετρο του δικτύου εφαρμόζοντας επαναληπτικά τον κανόνα της αλυσίδας, από το επίπεδο εξόδου προς το επίπεδο εισόδου.

### **2. Αλγόριθμος Backpropagation**

- **Βήμα 1:** Αρχικοποιήστε τις παραμέτρους του δικτύου (weights και biases).
- **Βήμα 2:** Για κάθε δείγμα εκπαίδευσης, εκτελέστε ένα forward pass για να υπολογίσετε τις εξόδους.
- **Βήμα 3:** Υπολογίστε το loss.
- **Βήμα 4:** Υπολογίστε τα gradients του loss ως προς κάθε παράμετρο χρησιμοποιώντας τον κανόνα της αλυσίδας.
- **Βήμα 5:** Ενημερώστε τις παραμέτρους χρησιμοποιώντας έναν αλγόριθμο βελτιστοποίησης (π.χ. gradient descent).

### **4. Υλοποίηση σε PyTorch**

Το PyTorch απλοποιεί αυτήν τη διαδικασία με τον μηχανισμό autograd.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
Σε αυτόν τον κώδικα:

- **Forward Pass:** Υπολογίζει τις εξόδους του δικτύου.
- **Backward Pass:** Η `loss.backward()` υπολογίζει τις κλίσεις της loss ως προς όλες τις παραμέτρους.
- **Parameter Update:** Η `optimizer.step()` ενημερώνει τις παραμέτρους με βάση τις υπολογισμένες κλίσεις.

### **5. Κατανόηση του Backward Pass**

Κατά τη διάρκεια του backward pass:

- Το PyTorch διασχίζει το computational graph με αντίστροφη σειρά.
- Για κάθε πράξη, εφαρμόζει τον κανόνα αλυσίδας για να υπολογίσει τις κλίσεις.
- Οι κλίσεις συσσωρεύονται στο attribute `.grad` κάθε tensor παραμέτρου.

### **6. Πλεονεκτήματα του Automatic Differentiation**

- **Αποδοτικότητα:** Αποφεύγει τους περιττούς υπολογισμούς επαναχρησιμοποιώντας ενδιάμεσα αποτελέσματα.
- **Ακρίβεια:** Παρέχει ακριβείς παραγώγους έως την ακρίβεια της μηχανής.
- **Ευκολία χρήσης:** Εξαλείφει την ανάγκη χειροκίνητου υπολογισμού των παραγώγων.
