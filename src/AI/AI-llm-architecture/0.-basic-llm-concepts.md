## Pretraining

Pretraining ist die grundlegende Phase bei der Entwicklung eines Large Language Model (LLM), in der das Modell riesigen und vielfältigen Mengen an Textdaten ausgesetzt wird. In dieser Phase **lernt das LLM die grundlegenden Strukturen, Muster und Feinheiten der Sprache**, einschließlich Grammatik, Vokabular, Syntax und kontextueller Beziehungen. Durch die Verarbeitung dieser umfangreichen Daten erlangt das Modell ein umfassendes Verständnis der Sprache und allgemeines Weltwissen. Diese umfassende Grundlage ermöglicht es dem LLM, kohärenten und kontextuell relevanten Text zu generieren. Anschließend kann dieses vortrainierte Modell einem Fine-Tuning unterzogen werden, bei dem es mit spezialisierten Datensätzen weiter trainiert wird, um seine Fähigkeiten an bestimmte Aufgaben oder Domänen anzupassen und dadurch seine Leistung und Relevanz in zielgerichteten Anwendungen zu verbessern.<sup>[[1]](#references)</sup>

## Hauptkomponenten von LLMs

Ein LLM wird normalerweise durch seine Architektur und Trainingskonfiguration charakterisiert. Dies sind die üblichen Komponenten, die beim Training eines solchen Modells beteiligt sind:<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Parameter**: Parameter sind die **lernbaren Gewichte und Bias-Werte** im neuronalen Netzwerk. Dies sind die Zahlen, die der Trainingsprozess anpasst, um die Loss-Funktion zu minimieren und die Leistung des Modells bei der jeweiligen Aufgabe zu verbessern. LLMs verwenden normalerweise Millionen von Parametern.
- **Kontextlänge**: Dies ist die maximale Länge jedes Satzes, der zum Pretraining des LLM verwendet wird.
- **Embedding-Dimension**: Die Größe des Vektors, der zur Darstellung jedes Tokens oder Wortes verwendet wird. LLMs verwenden normalerweise Milliarden von Dimensionen.
- **Verborgene Dimension**: Die Größe der verborgenen Schichten im neuronalen Netzwerk.
- **Anzahl der Schichten (Tiefe)**: Wie viele Schichten das Modell besitzt. LLMs verwenden normalerweise Dutzende von Schichten.
- **Anzahl der Attention-Heads**: Bei Transformer-Modellen gibt dies an, wie viele separate Attention-Mechanismen in jeder Schicht verwendet werden. LLMs verwenden normalerweise Dutzende von Heads.
- **Dropout**: Dropout bezeichnet ungefähr den Prozentsatz der Daten, die während des Trainings entfernt werden (Wahrscheinlichkeiten werden auf 0 gesetzt), um **Overfitting zu verhindern.** LLMs verwenden normalerweise zwischen 0 und 20 %.

## Tensoren in PyTorch

In PyTorch ist ein **Tensor** eine grundlegende Datenstruktur, die als mehrdimensionales Array dient und Konzepte wie Skalare, Vektoren und Matrizen auf potenziell höhere Dimensionen verallgemeinert. Tensoren sind die primäre Möglichkeit, Daten in PyTorch darzustellen und zu verarbeiten, insbesondere im Kontext von Deep Learning und neuronalen Netzwerken.<sup>[[1]](#references)</sup>

### Mathematisches Konzept von Tensoren

- **Skalare**: Tensoren vom Rang 0, die eine einzelne Zahl darstellen (nulldimensional). Beispiel: 5
- **Vektoren**: Tensoren vom Rang 1, die ein eindimensionales Array aus Zahlen darstellen. Beispiel: \[5,1]
- **Matrizen**: Tensoren vom Rang 2, die zweidimensionale Arrays mit Zeilen und Spalten darstellen. Beispiel: \[\[1,3], \[5,2]]
- **Tensoren höherer Ränge**: Tensoren vom Rang 3 oder höher, die Daten in höheren Dimensionen darstellen (z. B. 3D-Tensoren für Farbbilder).

### Tensoren als Datencontainer

Aus rechnerischer Sicht fungieren Tensoren als Container für mehrdimensionale Daten, wobei jede Dimension unterschiedliche Merkmale oder Aspekte der Daten darstellen kann. Dadurch eignen sich Tensoren besonders gut für die Verarbeitung komplexer Datensätze in Machine-Learning-Aufgaben.

### PyTorch-Tensoren im Vergleich zu NumPy-Arrays

Obwohl PyTorch-Tensoren NumPy-Arrays hinsichtlich ihrer Fähigkeit ähneln, numerische Daten zu speichern und zu verarbeiten, bieten sie zusätzliche Funktionen, die für Deep Learning entscheidend sind:

- **Automatische Differenzierung**: PyTorch-Tensoren unterstützen die automatische Berechnung von Gradienten (autograd), was den Prozess der Berechnung von Ableitungen vereinfacht, die für das Training neuronaler Netzwerke erforderlich sind.
- **GPU-Beschleunigung**: Tensoren in PyTorch können auf GPUs verschoben und dort verarbeitet werden, wodurch umfangreiche Berechnungen erheblich beschleunigt werden.

### Erstellen von Tensoren in PyTorch

Du kannst Tensoren mit der Funktion `torch.tensor` erstellen:
```python
pythonCopy codeimport torch

# Scalar (0D tensor)
tensor0d = torch.tensor(1)

# Vector (1D tensor)
tensor1d = torch.tensor([1, 2, 3])

# Matrix (2D tensor)
tensor2d = torch.tensor([[1, 2],
[3, 4]])

# 3D Tensor
tensor3d = torch.tensor([[[1, 2], [3, 4]],
[[5, 6], [7, 8]]])
```
### Tensor-Datentypen

PyTorch-Tensoren können Daten verschiedener Typen speichern, z. B. Ganzzahlen und Gleitkommazahlen.

Du kannst den Datentyp eines Tensors mithilfe des Attributs `.dtype` überprüfen:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Aus Python-Ganzzahlen erstellte Tensoren sind vom Typ `torch.int64`.
- Aus Python-Gleitkommazahlen erstellte Tensoren sind vom Typ `torch.float32`.

Um den Datentyp eines Tensors zu ändern, verwende die Methode `.to()`:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Häufige Tensor-Operationen

PyTorch bietet eine Vielzahl von Operationen zur Manipulation von Tensoren:

- **Zugriff auf die Form**: Verwende `.shape`, um die Dimensionen eines Tensors abzurufen.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Tensoren umformen**: Verwende `.reshape()` oder `.view()`, um die Form zu ändern.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Tensoren transponieren**: Verwende `.T`, um einen 2D-Tensor zu transponieren.

```python
transposed = tensor2d.T
```

- **Matrixmultiplikation**: Verwende `.matmul()` oder den Operator `@`.

```python
result = tensor2d @ tensor2d.T
```

### Bedeutung im Deep Learning

Tensoren sind in PyTorch für die Erstellung und das Training neuronaler Netzwerke unerlässlich:

- Sie speichern Eingabedaten, Gewichte und Biases.
- Sie ermöglichen die für Forward- und Backward-Pass in Trainingsalgorithmen erforderlichen Operationen.
- Mit autograd ermöglichen Tensoren die automatische Berechnung von Gradienten und vereinfachen dadurch den Optimierungsprozess.

## Automatische Differentiation

Automatische Differentiation (AD) ist eine Rechentechnik, die verwendet wird, um die **Ableitungen (Gradienten)** von Funktionen effizient und präzise zu **berechnen**. Im Kontext neuronaler Netzwerke ermöglicht AD die Berechnung von Gradienten, die für **Optimierungsalgorithmen wie Gradient Descent** erforderlich sind. PyTorch bietet eine Engine zur automatischen Differentiation namens **autograd**, die diesen Prozess vereinfacht.<sup>[[1]](#references)</sup>

### Mathematische Erklärung der automatischen Differentiation

**1. Die Kettenregel**

Das Herzstück der automatischen Differentiation ist die **Kettenregel** aus der Analysis. Die Kettenregel besagt, dass bei einer Verkettung von Funktionen die Ableitung der zusammengesetzten Funktion das Produkt der Ableitungen der verketteten Funktionen ist.

### Implementieren der automatischen Differentiation in PyTorch

Sehen wir uns nun an, wie PyTorch diesen Prozess automatisiert.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Backpropagation in größeren neuronalen Netzwerken

### **1. Erweiterung auf mehrschichtige Netzwerke**

In größeren neuronalen Netzwerken mit mehreren Schichten wird der Prozess der Gradientenberechnung aufgrund der erhöhten Anzahl an Parametern und Operationen komplexer. Die grundlegenden Prinzipien bleiben jedoch gleich:<sup>[[1]](#references)</sup>

- **Forward Pass:** Berechnung der Ausgabe des Netzwerks, indem die Eingaben durch jede Schicht geleitet werden.
- **Loss berechnen:** Auswertung der Loss-Funktion anhand der Ausgabe des Netzwerks und der Ziellabels.
- **Backward Pass (Backpropagation):** Berechnung der Gradienten des Loss bezüglich jedes Parameters im Netzwerk durch rekursive Anwendung der chain rule von der Ausgabeschicht zurück zur Eingabeschicht.

### **2. Backpropagation-Algorithmus**

- **Schritt 1:** Initialisierung der Netzwerkparameter (Gewichte und Biases).
- **Schritt 2:** Durchführung eines Forward Pass für jedes Trainingsbeispiel, um die Ausgaben zu berechnen.
- **Schritt 3:** Berechnung des Loss.
- **Schritt 4:** Berechnung der Gradienten des Loss bezüglich jedes Parameters mithilfe der chain rule.
- **Schritt 5:** Aktualisierung der Parameter mithilfe eines Optimierungsalgorithmus (z. B. gradient descent).

### **4. PyTorch-Implementierung**

PyTorch vereinfacht diesen Prozess durch seine autograd engine.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
In diesem Code:

- **Forward Pass:** Berechnet die Ausgaben des Netzwerks.
- **Backward Pass:** `loss.backward()` berechnet die Gradienten des Loss bezüglich aller Parameter.
- **Parameter Update:** `optimizer.step()` aktualisiert die Parameter auf Grundlage der berechneten Gradienten.

### **5. Verständnis des Backward Pass**

Während des Backward Pass:

- Durchläuft PyTorch den Computational Graph in umgekehrter Reihenfolge.
- Wendet es für jede Operation die Kettenregel an, um die Gradienten zu berechnen.
- Werden die Gradienten im `.grad`-Attribut jedes Parameter-Tensors akkumuliert.

### **6. Vorteile der automatischen Differentiation**

- **Effizienz:** Vermeidet redundante Berechnungen, indem Zwischenergebnisse wiederverwendet werden.
- **Genauigkeit:** Liefert exakte Ableitungen bis zur Maschinenpräzision.
- **Benutzerfreundlichkeit:** Macht die manuelle Berechnung von Ableitungen überflüssig.
