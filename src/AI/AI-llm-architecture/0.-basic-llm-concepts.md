## Pretraining

Pretraining, एक large language model (LLM) विकसित करने का मूलभूत चरण है, जिसमें model को विशाल और विविध text data के संपर्क में लाया जाता है। इस चरण के दौरान, **LLM language की मूलभूत संरचनाएँ, patterns और सूक्ष्मताओं** को सीखता है, जिनमें grammar, vocabulary, syntax और contextual relationships शामिल हैं। इस व्यापक data को process करके, model language और सामान्य world knowledge की व्यापक समझ प्राप्त करता है। यह व्यापक आधार LLM को सुसंगत और contextually relevant text generate करने में सक्षम बनाता है। इसके बाद, इस pretrained model को fine-tuning से गुजारा जा सकता है, जिसमें specific tasks या domains के लिए इसकी capabilities को अनुकूलित करने हेतु इसे specialized datasets पर आगे train किया जाता है, जिससे targeted applications में इसका performance और relevance बेहतर होता है।<sup>[[1]](#references)</sup>

## मुख्य LLM components

आमतौर पर किसी LLM की विशेषता उसे train करने के लिए उपयोग की गई configuration से निर्धारित होती है। LLM को train करते समय ये सामान्य components होते हैं:<sup>[[1]](#references)[[2]](#references)</sup>

- **Parameters**: Parameters neural network में मौजूद **learnable weights और biases** होते हैं। ये वे numbers हैं जिन्हें training process loss function को minimize करने और task पर model के performance को बेहतर बनाने के लिए adjust करती है। LLMs आमतौर पर millions of parameters का उपयोग करते हैं।
- **Context Length**: यह LLM को pre-train करने के लिए उपयोग किए गए प्रत्येक sentence की maximum length होती है।
- **Embedding Dimension**: प्रत्येक token या word को represent करने के लिए उपयोग किए गए vector का size। LLMs आमतौर पर billions of dimensions का उपयोग करते हैं।
- **Hidden Dimension**: neural network में hidden layers का size।
- **Number of Layers (Depth)**: model में कितनी layers हैं। LLMs आमतौर पर tens of layers का उपयोग करते हैं।
- **Number of Attention Heads**: transformer models में, यह बताता है कि प्रत्येक layer में कितने separate attention mechanisms उपयोग किए जाते हैं। LLMs आमतौर पर tens of heads का उपयोग करते हैं।
- **Dropout**: Dropout training के दौरान हटाए जाने वाले data के percentage जैसा होता है (probabilities 0 में बदल जाती हैं), जिसका उपयोग **overfitting को रोकने के लिए** किया जाता है। LLMs आमतौर पर 0-20% के बीच का उपयोग करते हैं।

## PyTorch में Tensors

PyTorch में, एक **tensor** एक मूलभूत data structure है, जो multi-dimensional array के रूप में कार्य करता है और scalars, vectors तथा matrices जैसी अवधारणाओं को संभावित रूप से अधिक dimensions तक सामान्यीकृत करता है। Tensors PyTorch में data को represent और manipulate करने का प्राथमिक माध्यम हैं, विशेष रूप से deep learning और neural networks के संदर्भ में।<sup>[[1]](#references)</sup>

### Tensors की Mathematical Concept

- **Scalars**: rank 0 के Tensors, जो एक single number (zero-dimensional) को represent करते हैं। उदाहरण: 5
- **Vectors**: rank 1 के Tensors, जो numbers के one-dimensional array को represent करते हैं। उदाहरण: \[5,1]
- **Matrices**: rank 2 के Tensors, जो rows और columns वाले two-dimensional arrays को represent करते हैं। उदाहरण: \[\[1,3], \[5,2]]
- **Higher-Rank Tensors**: rank 3 या उससे अधिक के Tensors, जो higher dimensions में data को represent करते हैं (जैसे, color images के लिए 3D tensors)।

### Data Containers के रूप में Tensors

Computational perspective से, tensors multi-dimensional data के containers के रूप में कार्य करते हैं, जहाँ प्रत्येक dimension data की अलग-अलग features या aspects को represent कर सकता है। इससे machine learning tasks में complex datasets को handle करने के लिए tensors अत्यंत उपयुक्त बन जाते हैं।

### PyTorch Tensors बनाम NumPy Arrays

हालाँकि PyTorch tensors, numerical data को store और manipulate करने की क्षमता में NumPy arrays के समान होते हैं, लेकिन वे deep learning के लिए महत्वपूर्ण अतिरिक्त functionalities प्रदान करते हैं:

- **Automatic Differentiation**: PyTorch tensors gradients (autograd) की automatic calculation को support करते हैं, जिससे neural networks की training के लिए आवश्यक derivatives को compute करने की प्रक्रिया सरल हो जाती है।
- **GPU Acceleration**: PyTorch में tensors को GPUs पर move करके वहीं compute किया जा सकता है, जिससे large-scale computations काफी तेज हो जाती हैं।

### Tensor के Data Types

PyTorch tensors विभिन्न प्रकार के data, जैसे integers और floating-point numbers, store कर सकते हैं।

आप `.dtype` attribute का उपयोग करके tensor का data type check कर सकते हैं:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Python integers से बनाए गए Tensors का प्रकार `torch.int64` होता है।
- Python floats से बनाए गए Tensors का प्रकार `torch.float32` होता है।

किसी Tensor का data type बदलने के लिए `.to()` method का उपयोग करें:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Common Tensor Operations

PyTorch tensors को manipulate करने के लिए विभिन्न operations प्रदान करता है:

- **Reshaping Tensors**: shape बदलने के लिए `.reshape()` या `.view()` का उपयोग करें।

Neural networks बनाने और train करने के लिए PyTorch में tensors आवश्यक हैं:

- वे input data, weights और biases को store करते हैं।

## Automatic Differentiation

Automatic differentiation (AD) एक computational technique है जिसका उपयोग functions के **derivatives (gradients)** को efficiently और accurately **evaluate** करने के लिए किया जाता है। Neural networks के context में, AD **gradient descent जैसे optimization algorithms** के लिए आवश्यक gradients की calculation enable करता है। PyTorch एक automatic differentiation engine प्रदान करता है जिसे **autograd** कहा जाता है, जो इस process को सरल बनाता है।<sup>[[1]](#references)</sup>

### Mathematical Explanation of Automatic Differentiation

**1. The Chain Rule**

Automatic differentiation के केंद्र में calculus का **chain rule** होता है। Chain rule के अनुसार, यदि आपके पास functions का composition है, तो composite function का derivative, composed functions के derivatives का product होता है।

Mathematically, यदि `y=f(u)` और `u=g(x)` हैं, तो `x` के respect में `y` का derivative है:

### Implementing Automatic Differentiation in PyTorch

अब देखते हैं कि PyTorch इस process को कैसे automate करता है।
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## बड़े Neural Networks में Backpropagation

### **1. Multilayer Networks तक विस्तार**

कई layers वाले बड़े Neural Networks में gradients compute करने की प्रक्रिया अधिक complex हो जाती है, क्योंकि parameters और operations की संख्या बढ़ जाती है। हालांकि, मूल सिद्धांत वही रहते हैं:<sup>[[1]](#references)</sup>

- **Forward Pass:** प्रत्येक layer से inputs गुज़ारकर network का output compute करें।
- **Loss Compute करें:** Network के output और target labels का उपयोग करके loss function का मूल्यांकन करें।
- **Backward Pass (Backpropagation):** Output layer से input layer तक chain rule को recursively लागू करके network के प्रत्येक parameter के संबंध में loss के gradients compute करें।

### **2. Backpropagation Algorithm**

- **Step 1:** Network parameters (weights और biases) initialize करें।
- **Step 2:** प्रत्येक training example के लिए outputs compute करने हेतु forward pass करें।
- **Step 3:** Loss compute करें।
- **Step 4:** Chain rule का उपयोग करके प्रत्येक parameter के संबंध में loss के gradients compute करें।
- **Step 5:** Optimization algorithm (जैसे, gradient descent) का उपयोग करके parameters update करें।

### **4. PyTorch Implementation**

PyTorch अपने autograd engine के साथ इस प्रक्रिया को सरल बनाता है।
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
इस code में:

- **Forward Pass:** network के outputs की गणना करता है।
- **Backward Pass:** `loss.backward()` सभी parameters के संबंध में loss के gradients की गणना करता है।
- **Parameter Update:** `optimizer.step()` computed gradients के आधार पर parameters को update करता है।

### **5. Backward Pass को समझना**

Backward pass के दौरान:

- PyTorch computational graph को reverse order में traverse करता है।
- प्रत्येक operation के लिए, gradients की गणना करने हेतु chain rule लागू करता है।
- Gradients प्रत्येक parameter tensor के `.grad` attribute में accumulate किए जाते हैं।

### **6. Automatic Differentiation के लाभ**

- **Efficiency:** intermediate results का पुनः उपयोग करके redundant calculations से बचता है।
- **Accuracy:** machine precision तक exact derivatives प्रदान करता है।
- **Ease of Use:** derivatives की manual computation की आवश्यकता समाप्त करता है।
