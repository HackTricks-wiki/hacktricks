## Pretraining

Pretraining ni awamu ya msingi katika kuunda large language model (LLM), ambapo model hupewa kiasi kikubwa na mseto wa data za maandishi. Katika hatua hii, **LLM hujifunza miundo, mifumo na nuances za msingi za lugha**, ikijumuisha sarufi, msamiati, sintaksia na uhusiano wa kimuktadha. Kwa kuchakata data hii pana, model hupata uelewa mpana wa lugha na maarifa ya jumla kuhusu ulimwengu. Msingi huu wa kina huwezesha LLM kuzalisha maandishi yenye mshikamano na yanayohusiana kimuktadha. Baadaye, model hii iliyofanyiwa pretraining inaweza kufanyiwa fine-tuning, ambapo hufunzwa zaidi kwa kutumia datasets maalum ili kurekebisha uwezo wake kwa ajili ya kazi au maeneo mahususi, na hivyo kuboresha utendaji na umuhimu wake katika matumizi yaliyolengwa.<sup>[[1]](#references)</sup>

## Vipengele Vikuu vya LLM

LLM kwa kawaida hutambuliwa kulingana na architecture yake na configuration ya training. Hivi ni vipengele vya kawaida vinavyohusika katika kuifundisha:<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Parameters**: Parameters ni **weights na biases zinazoweza kujifunzwa** katika neural network. Hizi ni namba ambazo mchakato wa training hurekebisha ili kupunguza loss function na kuboresha utendaji wa model kwenye task. LLM kwa kawaida hutumia mamilioni ya parameters.
- **Context Length**: Huu ni urefu wa juu zaidi wa kila sentensi inayotumiwa kufanya pre-train ya LLM.
- **Embedding Dimension**: Ukubwa wa vector unaotumiwa kuwakilisha kila token au neno. LLM kwa kawaida hutumia mabilioni ya dimensions.
- **Hidden Dimension**: Ukubwa wa hidden layers katika neural network.
- **Number of Layers (Depth)**: Idadi ya layers ambazo model inazo. LLM kwa kawaida hutumia makumi ya layers.
- **Number of Attention Heads**: Katika transformer models, hii ni idadi ya mechanisms huru za attention zinazotumiwa katika kila layer. LLM kwa kawaida hutumia makumi ya heads.
- **Dropout**: Dropout ni kitu kinachofanana na asilimia ya data inayotolewa (probabilities hubadilishwa kuwa 0) wakati wa training, kwa lengo la **kuzuia overfitting.** LLM kwa kawaida hutumia kati ya 0-20%.

Configuration ya GPT-2 model:
```json
GPT_CONFIG_124M = {
"vocab_size": 50257,  // Vocabulary size of the BPE tokenizer
"context_length": 1024, // Context length

"n_layers": 12,       // Number of layers
"drop_rate": 0.1,     // Dropout rate: 10%
"qkv_bias": False     // Query-Key-Value bias
}
```
## Tensors katika PyTorch

Katika PyTorch, **tensor** ni muundo msingi wa data unaotumika kama safu ya vipengele yenye vipimo vingi, ukipanua dhana kama scalars, vectors, na matrices hadi vipimo vya juu zaidi vinavyowezekana. Tensors ndiyo njia kuu ya kuwakilisha na kudhibiti data katika PyTorch, hasa katika muktadha wa deep learning na neural networks.<sup>[[1]](#references)</sup>

### Dhana ya Kihisabati ya Tensors

- **Scalars**: Tensors za rank 0, zinazowakilisha nambari moja (zenye kipimo sifuri). Mfano: 5
- **Vectors**: Tensors za rank 1, zinazowakilisha safu ya nambari yenye kipimo kimoja. Mfano: \[5,1]
- **Matrices**: Tensors za rank 2, zinazowakilisha safu za vipimo viwili zenye mistari na safu wima. Mfano: \[\[1,3], \[5,2]]
- **Higher-Rank Tensors**: Tensors za rank 3 au zaidi, zinazowakilisha data katika vipimo vya juu zaidi (kwa mfano, tensors za 3D kwa picha za rangi).

### Tensors kama Vihifadhi vya Data

Kwa mtazamo wa computational, tensors hufanya kazi kama vihifadhi vya data yenye vipimo vingi, ambapo kila kipimo kinaweza kuwakilisha features au vipengele tofauti vya data. Hii hufanya tensors zifae sana kwa kushughulikia datasets changamano katika machine learning tasks.

### Tensors za PyTorch dhidi ya NumPy Arrays

Ingawa tensors za PyTorch zinafanana na NumPy arrays katika uwezo wao wa kuhifadhi na kudhibiti data ya nambari, hutoa functionalities za ziada zilizo muhimu kwa deep learning:

- **Automatic Differentiation**: Tensors za PyTorch zinaunga mkono ukokotoaji wa kiotomatiki wa gradients (autograd), unaorahisisha mchakato wa kukokotoa derivatives zinazohitajika kwa ajili ya training ya neural networks.
- **GPU Acceleration**: Tensors katika PyTorch zinaweza kuhamishwa hadi kwenye GPUs na kufanyiwa computations humo, jambo linaloharakisha kwa kiasi kikubwa computations za kiwango kikubwa.

### Kuunda Tensors katika PyTorch

Unaweza kuunda tensors kwa kutumia function ya `torch.tensor`:

### Aina za Data za Tensor

PyTorch tensors zinaweza kuhifadhi data za aina mbalimbali, kama vile integers na floating-point numbers.

Unaweza kuangalia aina ya data ya tensor kwa kutumia attribute ya `.dtype`:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Tensors zilizoundwa kutoka kwa integers za Python zina aina ya `torch.int64`.
- Tensors zilizoundwa kutoka kwa floats za Python zina aina ya `torch.float32`.

Ili kubadilisha aina ya data ya tensor, tumia method ya `.to()`:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Operesheni za Kawaida za Tensor

PyTorch hutoa aina mbalimbali za operesheni za kudhibiti tensors:

- **Kufikia Shape**: Tumia `.shape` kupata vipimo vya tensor.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Kubadilisha Shape za Tensors**: Tumia `.reshape()` au `.view()` kubadilisha shape.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Kutranspose Tensors**: Tumia `.T` kufanya transpose ya tensor ya 2D.

```python
transposed = tensor2d.T
```

- **Kuzidisha Matrix**: Tumia `.matmul()` au operator ya `@`.

```python
result = tensor2d @ tensor2d.T
```

## Automatic Differentiation

Automatic differentiation (AD) ni mbinu ya computational inayotumika **kutathmini derivatives (gradients)** za functions kwa ufanisi na usahihi. Katika muktadha wa neural networks, AD huwezesha ukokotoaji wa gradients unaohitajika kwa **algorithms za optimization kama gradient descent**. PyTorch hutoa engine ya automatic differentiation inayoitwa **autograd**, ambayo hurahisisha mchakato huu.<sup>[[1]](#references)</sup>

### Kutekeleza Automatic Differentiation katika PyTorch

Sasa, hebu tuone jinsi PyTorch inavyofanya mchakato huu kiotomatiki.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Backpropagation katika Neural Networks Kubwa

### **1. Kupanua hadi Multilayer Networks**

Katika neural networks kubwa zilizo na layers nyingi, mchakato wa kukokotoa gradients huwa changamano zaidi kutokana na kuongezeka kwa idadi ya parameters na operations. Hata hivyo, kanuni za msingi hubaki zilezile:<sup>[[1]](#references)</sup>

- **Forward Pass:** Kokotoa output ya network kwa kupitisha inputs katika kila layer.
- **Compute Loss:** Tathmini loss function kwa kutumia output ya network na target labels.
- **Backward Pass (Backpropagation):** Kokotoa gradients za loss kuhusiana na kila parameter katika network kwa kutumia chain rule kwa kurudia, kuanzia output layer hadi input layer.

### **2. Backpropagation Algorithm**

- **Hatua ya 1:** Anzisha parameters za network (weights na biases).
- **Hatua ya 2:** Kwa kila training example, tekeleza forward pass ili kukokotoa outputs.
- **Hatua ya 3:** Kokotoa loss.
- **Hatua ya 4:** Kokotoa gradients za loss kuhusiana na kila parameter kwa kutumia chain rule.
- **Hatua ya 5:** Sasisha parameters kwa kutumia optimization algorithm (kwa mfano, gradient descent).

### **4. PyTorch Implementation**

PyTorch hurahisisha mchakato huu kwa kutumia autograd engine.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
Katika msimbo huu:

- **Forward Pass:** Hukokotoa matokeo ya mtandao.
- **Backward Pass:** `loss.backward()` hukokotoa gradients za loss kuhusiana na parameters zote.
- **Parameter Update:** `optimizer.step()` husasisha parameters kulingana na gradients zilizokokotolewa.

### **5. Kuelewa Backward Pass**

Wakati wa backward pass:

- PyTorch hupitia computational graph kwa mpangilio wa kinyume.
- Kwa kila operesheni, hutumia chain rule kukokotoa gradients.
- Gradients hukusanywa katika attribute ya `.grad` ya kila parameter tensor.

### **6. Faida za Automatic Differentiation**

- **Efficiency:** Huepuka hesabu zinazorudiwa kwa kutumia tena matokeo ya kati.
- **Accuracy:** Hutoa derivatives sahihi hadi kiwango cha usahihi wa mashine.
- **Ease of Use:** Huondoa hitaji la kukokotoa derivatives kwa mikono.
