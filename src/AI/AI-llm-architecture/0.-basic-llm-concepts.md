## Pretraining

Pretraining एक large language model (LLM) विकसित करने का मूलभूत चरण है, जिसमें model को बहुत बड़ी और विविध मात्रा में text data से परिचित कराया जाता है। इस चरण के दौरान, **LLM language की मूलभूत संरचनाएं, patterns और बारीकियां सीखता है**, जिनमें grammar, vocabulary, syntax और contextual relationships शामिल हैं। इस व्यापक data को process करके, model language और सामान्य world knowledge की व्यापक समझ प्राप्त करता है। यह व्यापक आधार LLM को सुसंगत और contextually relevant text generate करने में सक्षम बनाता है। इसके बाद, इस pretrained model की fine-tuning की जा सकती है, जिसमें इसे specialized datasets पर आगे train किया जाता है ताकि इसकी capabilities को specific tasks या domains के लिए अनुकूलित किया जा सके और targeted applications में इसके performance और relevance को बेहतर बनाया जा सके।<sup>[[1]](#references)</sup>

## Main LLM components

LLM को आमतौर पर उसके architecture और training configuration द्वारा परिभाषित किया जाता है। किसी LLM को train करने में शामिल सामान्य components ये हैं:<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Parameters**: Parameters neural network में मौजूद **learnable weights और biases** होते हैं। ये वे numbers हैं जिन्हें training process loss function को minimize करने और task पर model के performance को बेहतर बनाने के लिए adjust करता है। LLMs आमतौर पर millions of parameters का उपयोग करते हैं।
- **Context Length**: यह प्रत्येक sentence की अधिकतम length होती है, जिसका उपयोग LLM को pre-train करने के लिए किया जाता है।
- **Embedding Dimension**: प्रत्येक token या word को represent करने के लिए उपयोग किए जाने वाले vector का size। LLMs आमतौर पर billions of dimensions का उपयोग करते हैं।
- **Hidden Dimension**: neural network में hidden layers का size।
- **Number of Layers (Depth)**: model में मौजूद layers की संख्या। LLMs आमतौर पर tens of layers का उपयोग करते हैं।
- **Number of Attention Heads**: transformer models में, यह प्रत्येक layer में उपयोग किए जाने वाले अलग-अलग attention mechanisms की संख्या होती है। LLMs आमतौर पर tens of heads का उपयोग करते हैं।
- **Dropout**: Dropout training के दौरान हटाए जाने वाले data के percentage जैसा होता है (probabilities 0 में बदल जाती हैं), और इसका उपयोग **overfitting को रोकने के लिए** किया जाता है। LLMs आमतौर पर 0-20% के बीच Dropout का उपयोग करते हैं।

## PyTorch में Tensors

PyTorch में, **tensor** एक मौलिक data structure है जो multi-dimensional array के रूप में कार्य करता है और scalars, vectors तथा matrices जैसी अवधारणाओं को संभावित रूप से उच्च dimensions तक सामान्यीकृत करता है। Tensors PyTorch में data को represent और manipulate करने का प्राथमिक माध्यम हैं, विशेष रूप से deep learning और neural networks के संदर्भ में।<sup>[[1]](#references)</sup>

### Tensors की Mathematical अवधारणा

- **Scalars**: rank 0 के Tensors, जो एक संख्या (zero-dimensional) को दर्शाते हैं। उदाहरण: 5
- **Vectors**: rank 1 के Tensors, जो numbers के one-dimensional array को दर्शाते हैं। उदाहरण: \[5,1]
- **Matrices**: rank 2 के Tensors, जो rows और columns वाले two-dimensional arrays को दर्शाते हैं। उदाहरण: \[\[1,3], \[5,2]]
- **Higher-Rank Tensors**: rank 3 या उससे अधिक के Tensors, जो higher dimensions में data को दर्शाते हैं (जैसे, color images के लिए 3D tensors)।

### Data Containers के रूप में Tensors

Computational perspective से, tensors multi-dimensional data के containers के रूप में कार्य करते हैं, जहाँ प्रत्येक dimension data की अलग-अलग features या aspects को दर्शा सकता है। इससे tensors machine learning tasks में complex datasets को handle करने के लिए अत्यंत उपयुक्त बन जाते हैं।

### PyTorch Tensors बनाम NumPy Arrays

हालाँकि PyTorch tensors numerical data को store और manipulate करने की क्षमता में NumPy arrays के समान होते हैं, लेकिन वे deep learning के लिए महत्वपूर्ण अतिरिक्त functionalities प्रदान करते हैं:

- **Automatic Differentiation**: PyTorch tensors gradients की automatic calculation (autograd) का समर्थन करते हैं, जिससे neural networks की training के लिए आवश्यक derivatives compute करने की प्रक्रिया सरल हो जाती है।
- **GPU Acceleration**: PyTorch में tensors को GPUs पर move और compute किया जा सकता है, जिससे large-scale computations की गति काफी बढ़ जाती है।

### Tensor Data Types

PyTorch tensors विभिन्न प्रकार के data store कर सकते हैं, जैसे integers और floating-point numbers।

आप `.dtype` attribute का उपयोग करके tensor का data type check कर सकते हैं:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Python integers से बनाए गए Tensors का type `torch.int64` होता है।
- Python floats से बनाए गए Tensors का type `torch.float32` होता है।

किसी Tensor का data type बदलने के लिए `.to()` method का उपयोग करें:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Common Tensor Operations

PyTorch tensors को manipulate करने के लिए विभिन्न operations प्रदान करता है:

- **Shape प्राप्त करना**: Tensor के dimensions प्राप्त करने के लिए `.shape` का उपयोग करें।

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Tensors का Reshaping**: Shape बदलने के लिए `.reshape()` या `.view()` का उपयोग करें।

```python

```

- **Tensors को Transpose करना**: 2D tensor को transpose करने के लिए `.T` का उपयोग करें।

```python
transposed = tensor2d.T
```

- **Matrix Multiplication**: `.matmul()` या `@` operator का उपयोग करें।

```python

```

### Deep Learning में महत्व

Neural networks बनाने और train करने के लिए PyTorch में tensors आवश्यक हैं:

- वे input data, weights और biases को store करते हैं।
- वे training algorithms में forward और backward passes के लिए आवश्यक operations को support करते हैं।
- autograd के साथ, tensors gradients की automatic computation को सक्षम करते हैं, जिससे optimization process सरल हो जाती है।

## Automatic Differentiation

Automatic differentiation (AD) एक computational technique है जिसका उपयोग functions के **derivatives (gradients)** को कुशलतापूर्वक और सटीक रूप से **evaluate** करने के लिए किया जाता है। Neural networks के संदर्भ में, AD **gradient descent जैसे optimization algorithms** के लिए आवश्यक gradients की calculation को सक्षम करता है। PyTorch एक automatic differentiation engine प्रदान करता है जिसे **autograd** कहा जाता है, जो इस process को सरल बनाता है।<sup>[[1]](#references)</sup>

### Automatic Differentiation की Mathematical Explanation

**1. Chain Rule**

Automatic differentiation के केंद्र में calculus का **chain rule** होता है। Chain rule के अनुसार, यदि आपके पास functions का composition है, तो composite function का derivative, composed functions के derivatives का product होता है।

Mathematically, यदि `y=f(u)` और `u=g(x)` हैं, तो `y` का `x` के respect में derivative है:

### PyTorch में Automatic Differentiation Implement करना

अब देखते हैं कि PyTorch इस process को कैसे automate करता है।
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## बड़े Neural Networks में Backpropagation

### **1. Multilayer Networks तक विस्तार**

कई layers वाले बड़े neural networks में gradients की गणना करने की प्रक्रिया parameters और operations की बढ़ी हुई संख्या के कारण अधिक जटिल हो जाती है। हालांकि, मूल सिद्धांत समान रहते हैं:<sup>[[1]](#references)</sup>

- **Forward Pass:** प्रत्येक layer के माध्यम से inputs पास करके network के output की गणना करें।
- **Compute Loss:** network के output और target labels का उपयोग करके loss function का मूल्यांकन करें।
- **Backward Pass (Backpropagation):** output layer से input layer तक chain rule को बार-बार लागू करके network के प्रत्येक parameter के संबंध में loss के gradients की गणना करें।

### **2. Backpropagation Algorithm**

- **Step 1:** Network parameters (weights और biases) को initialize करें।
- **Step 2:** प्रत्येक training example के लिए outputs की गणना करने हेतु forward pass करें।
- **Step 3:** Loss की गणना करें।
- **Step 4:** Chain rule का उपयोग करके प्रत्येक parameter के संबंध में loss के gradients की गणना करें।
- **Step 5:** Optimization algorithm (जैसे, gradient descent) का उपयोग करके parameters को update करें।

### **4. PyTorch Implementation**

PyTorch अपने autograd engine के साथ इस प्रक्रिया को सरल बनाता है।
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
इस code में:

- **Forward Pass:** network के outputs की गणना करता है।
- **Backward Pass:** `loss.backward()` सभी parameters के संबंध में loss के gradients की गणना करता है।
- **Parameter Update:** `optimizer.step()` computed gradients के आधार पर parameters को अपडेट करता है।

### **5. Backward Pass को समझना**

Backward pass के दौरान:

- PyTorch computational graph को reverse order में traverse करता है।
- प्रत्येक operation के लिए, यह gradients की गणना करने हेतु chain rule लागू करता है।
- Gradients प्रत्येक parameter tensor के `.grad` attribute में accumulate होते हैं।

### **6. Automatic Differentiation के लाभ**

- **Efficiency:** intermediate results का पुनः उपयोग करके redundant calculations से बचता है।
- **Accuracy:** machine precision तक exact derivatives प्रदान करता है।
- **Ease of Use:** derivatives की manual computation की आवश्यकता समाप्त करता है।
