## Pretraining

Pretraining là giai đoạn nền tảng trong quá trình phát triển mô hình ngôn ngữ lớn (LLM), khi mô hình được tiếp xúc với lượng dữ liệu văn bản khổng lồ và đa dạng. Trong giai đoạn này, **LLM học các cấu trúc, quy luật và sắc thái cơ bản của ngôn ngữ**, bao gồm ngữ pháp, từ vựng, cú pháp và các mối quan hệ theo ngữ cảnh. Bằng cách xử lý lượng dữ liệu phong phú này, mô hình có được sự hiểu biết rộng về ngôn ngữ và kiến thức tổng quát về thế giới. Nền tảng toàn diện này giúp LLM tạo ra văn bản mạch lạc và phù hợp với ngữ cảnh. Sau đó, mô hình đã pretrain này có thể được fine-tune bằng cách tiếp tục huấn luyện trên các tập dữ liệu chuyên biệt để điều chỉnh khả năng cho những tác vụ hoặc lĩnh vực cụ thể, qua đó cải thiện hiệu suất và mức độ phù hợp trong các ứng dụng mục tiêu.<sup>[[1]](#references)</sup>

## Các thành phần chính của LLM

LLM thường được đặc trưng bởi kiến trúc và cấu hình huấn luyện. Sau đây là các thành phần thường có trong quá trình huấn luyện LLM:<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Parameters**: Parameters là các **trọng số và độ lệch có thể học được** trong mạng neural. Đây là những con số được điều chỉnh trong quá trình huấn luyện để giảm thiểu hàm loss và cải thiện hiệu suất của mô hình đối với tác vụ. LLM thường sử dụng hàng triệu parameters.
- **Độ dài ngữ cảnh**: Đây là độ dài tối đa của mỗi câu được dùng để pretrain LLM.
- **Chiều embedding**: Kích thước của vector dùng để biểu diễn mỗi token hoặc từ. LLM thường sử dụng hàng tỷ chiều.
- **Chiều ẩn**: Kích thước của các lớp ẩn trong mạng neural.
- **Số lớp (độ sâu)**: Số lượng lớp mà mô hình có. LLM thường sử dụng hàng chục lớp.
- **Số attention head**: Trong các mô hình transformer, đây là số lượng cơ chế attention riêng biệt được sử dụng trong mỗi lớp. LLM thường sử dụng hàng chục head.
- **Dropout**: Dropout là một tỷ lệ dữ liệu bị loại bỏ (xác suất được chuyển thành 0) trong quá trình huấn luyện, nhằm **ngăn overfitting.** LLM thường sử dụng tỷ lệ từ 0-20%.

Cấu hình của mô hình GPT-2:

```json
GPT_CONFIG_124M = {
    "vocab_size": 50257,  // Vocabulary size of the BPE tokenizer
    "context_length": 1024, // Context length
    "emb_dim": 768,       // Embedding dimension
    "n_heads": 12,        // Number of attention heads
    "n_layers": 12,       // Number of layers
    "drop_rate": 0.1,     // Dropout rate: 10%
    "qkv_bias": False     // Query-Key-Value bias
}
```

## Tensors trong PyTorch

Trong PyTorch, **tensor** là cấu trúc dữ liệu cơ bản, đóng vai trò như một mảng đa chiều và khái quát hóa các khái niệm như scalar, vector và matrix lên các số chiều cao hơn. Tensor là cách chính để biểu diễn và thao tác với dữ liệu trong PyTorch, đặc biệt trong deep learning và mạng neural.<sup>[[1]](#references)</sup>

### Khái niệm toán học về tensor

- **Scalars**: Tensor hạng 0, biểu diễn một số đơn lẻ (không chiều). Ví dụ: 5
- **Vectors**: Tensor hạng 1, biểu diễn một mảng số một chiều. Ví dụ: \[5,1]
- **Matrices**: Tensor hạng 2, biểu diễn các mảng hai chiều gồm hàng và cột. Ví dụ: \[\[1,3], \[5,2]]
- **Higher-Rank Tensors**: Tensor hạng 3 trở lên, biểu diễn dữ liệu ở các chiều cao hơn (ví dụ: tensor 3D dùng cho ảnh màu).

### Tensor làm vùng chứa dữ liệu

Từ góc độ tính toán, tensor đóng vai trò là vùng chứa dữ liệu đa chiều, trong đó mỗi chiều có thể biểu thị các đặc trưng hoặc khía cạnh khác nhau của dữ liệu. Điều này khiến tensor rất phù hợp để xử lý các tập dữ liệu phức tạp trong những tác vụ machine learning.

### Tensor PyTorch và mảng NumPy

Tensor PyTorch tương tự mảng NumPy về khả năng lưu trữ và thao tác với dữ liệu số, nhưng có thêm các chức năng quan trọng cho deep learning:

- **Automatic Differentiation**: Tensor PyTorch hỗ trợ tính gradient tự động (autograd), giúp đơn giản hóa việc tính đạo hàm cần thiết để huấn luyện mạng neural.
- **GPU Acceleration**: Có thể chuyển tensor PyTorch sang GPU và thực hiện tính toán trên đó, giúp tăng tốc đáng kể các phép tính quy mô lớn.

### Tạo tensor trong PyTorch

Bạn có thể tạo tensor bằng hàm `torch.tensor`:

```python
pythonCopy codeimport torch

# Scalar (0D tensor)
tensor0d = torch.tensor(1)

# Vector (1D tensor)
tensor1d = torch.tensor([1, 2, 3])

# Matrix (2D tensor)
tensor2d = torch.tensor([[1, 2],
                         [3, 4]])

# 3D Tensor
tensor3d = torch.tensor([[[1, 2], [3, 4]],
                         [[5, 6], [7, 8]]])
```

### Các kiểu dữ liệu tensor

Tensor trong PyTorch có thể lưu trữ dữ liệu thuộc nhiều kiểu khác nhau, chẳng hạn như số nguyên và số dấu phẩy động.

Bạn có thể kiểm tra kiểu dữ liệu của tensor bằng thuộc tính `.dtype`:

```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```

- Tensor được tạo từ số nguyên Python có kiểu `torch.int64`.
- Tensor được tạo từ số thực Python có kiểu `torch.float32`.

Để thay đổi kiểu dữ liệu của tensor, hãy dùng phương thức `.to()`:

```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```

### Các phép toán Tensor phổ biến

PyTorch cung cấp nhiều phép toán để thao tác với tensor:

- **Truy cập hình dạng**: Dùng `.shape` để lấy kích thước của tensor.

  ```python
  print(tensor2d.shape)  # Output: torch.Size([2, 2])
  ```

- **Định hình lại Tensor**: Dùng `.reshape()` hoặc `.view()` để thay đổi hình dạng.

  ```python
  reshaped = tensor2d.reshape(4, 1)
  ```

- **Chuyển vị Tensor**: Dùng `.T` để chuyển vị tensor 2D.

  ```python
  transposed = tensor2d.T
  ```

- **Phép nhân ma trận**: Sử dụng `.matmul()` hoặc toán tử `@`.

  ```python
  result = tensor2d @ tensor2d.T
  ```

### Tầm quan trọng trong Deep Learning

Tensor rất cần thiết trong PyTorch để xây dựng và huấn luyện neural network:

- Chúng lưu trữ dữ liệu đầu vào, trọng số và bias.
- Chúng hỗ trợ các phép toán cần thiết cho lượt truyền xuôi và lượt truyền ngược trong các thuật toán huấn luyện.
- Với autograd, tensor cho phép tự động tính gradient, giúp đơn giản hóa quá trình tối ưu hóa.

## Tính vi phân tự động

Tính vi phân tự động (AD) là một kỹ thuật tính toán được dùng để **tính toán đạo hàm (gradient)** của các hàm một cách hiệu quả và chính xác. Trong neural network, AD cho phép tính gradient cần thiết cho **các thuật toán tối ưu hóa như gradient descent**. PyTorch cung cấp một engine tính vi phân tự động có tên **autograd** để đơn giản hóa quá trình này.<sup>[[1]](#references)</sup>

### Giải thích toán học về tính vi phân tự động

### Triển khai tính vi phân tự động trong PyTorch

Bây giờ, hãy xem PyTorch tự động hóa quá trình này như thế nào.

```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Lan truyền ngược trong các mạng nơ-ron lớn hơn

### **1. Mở rộng sang mạng nhiều lớp**

Trong các mạng nơ-ron lớn hơn có nhiều lớp, quá trình tính gradient trở nên phức tạp hơn do số lượng tham số và phép toán tăng lên. Tuy nhiên, các nguyên tắc cơ bản vẫn không đổi:<sup>[[1]](#references)</sup>

- **Lượt truyền tiến:** Tính đầu ra của mạng bằng cách truyền đầu vào qua từng lớp.
- **Tính loss:** Đánh giá hàm loss bằng đầu ra của mạng và các nhãn mục tiêu.
- **Lượt truyền ngược (lan truyền ngược):** Tính gradient của loss theo từng tham số trong mạng bằng cách áp dụng đệ quy quy tắc dây chuyền, từ lớp đầu ra ngược về lớp đầu vào.

### **2. Thuật toán lan truyền ngược**

- **Bước 1:** Khởi tạo các tham số của mạng (weights và biases).
- **Bước 2:** Với mỗi mẫu huấn luyện, thực hiện lượt truyền tiến để tính đầu ra.
- **Bước 3:** Tính loss.
- **Bước 4:** Dùng quy tắc dây chuyền để tính gradient của loss theo từng tham số.
- **Bước 5:** Cập nhật các tham số bằng thuật toán tối ưu hóa (ví dụ: gradient descent).

### **4. Triển khai bằng PyTorch**

PyTorch đơn giản hóa quá trình này bằng engine autograd của nó.

```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
    def __init__(self):
        super(SimpleNet, self).__init__()
        self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):
        h = self.relu(self.fc1(x))
        y_hat = self.sigmoid(self.fc2(h))
        return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
    if param.requires_grad:
        print(f"Gradient of {name}: {param.grad}")
```

Trong đoạn code này:

- **Lượt lan truyền xuôi:** Tính toán đầu ra của mạng.
- **Lượt lan truyền ngược:** `loss.backward()` tính gradient của hàm loss theo tất cả các tham số.
- **Cập nhật tham số:** `optimizer.step()` cập nhật các tham số dựa trên gradient đã tính.

### **5. Tìm hiểu về lượt lan truyền ngược**

Trong lượt lan truyền ngược:

- PyTorch duyệt đồ thị tính toán theo thứ tự ngược.
- Với mỗi phép toán, nó áp dụng quy tắc chuỗi để tính gradient.
- Gradient được tích lũy trong thuộc tính `.grad` của từng tensor tham số.

### **6. Ưu điểm của tính vi phân tự động**

- **Hiệu quả:** Tránh các phép tính dư thừa bằng cách tái sử dụng kết quả trung gian.
- **Độ chính xác:** Tính đạo hàm chính xác đến độ chính xác của máy.
- **Dễ sử dụng:** Không cần tính đạo hàm thủ công.
