## Pretraining

Pretraining to podstawowy etap tworzenia dużego modelu językowego (LLM), podczas którego model jest wystawiany na ogromne i zróżnicowane ilości danych tekstowych. Na tym etapie **LLM uczy się podstawowych struktur, wzorców i niuansów języka**, w tym gramatyki, słownictwa, składni oraz zależności kontekstowych. Dzięki przetwarzaniu tak obszernych danych model zdobywa ogólne rozumienie języka i wiedzę o świecie. Ta kompleksowa baza umożliwia LLM generowanie spójnego i odpowiedniego kontekstowo tekstu. Następnie ten pretrained model może przejść fine-tuning, podczas którego jest dalej trenowany na wyspecjalizowanych zbiorach danych w celu dostosowania jego możliwości do konkretnych zadań lub dziedzin, co zwiększa jego wydajność i przydatność w docelowych zastosowaniach.<sup>[[1]](#references)</sup>

## Główne komponenty LLM

LLM jest zazwyczaj charakteryzowany przez swoją architekturę i konfigurację treningu. Poniżej przedstawiono typowe komponenty wykorzystywane podczas jego trenowania:<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Parameters**: Parameters to **uczalne wagi i biasy** w sieci neuronowej. Są to liczby, które proces treningowy dostosowuje w celu minimalizacji funkcji straty i poprawy wydajności modelu w danym zadaniu. LLM zwykle wykorzystują miliony parametrów.
- **Context Length**: Jest to maksymalna długość każdego zdania używanego do pre-trainowania LLM.
- **Embedding Dimension**: Rozmiar wektora używanego do reprezentowania każdego tokena lub słowa. LLM zwykle wykorzystują miliardy wymiarów.
- **Hidden Dimension**: Rozmiar warstw ukrytych w sieci neuronowej.
- **Number of Layers (Depth)**: Liczba warstw modelu. LLM zwykle wykorzystują dziesiątki warstw.
- **Number of Attention Heads**: W modelach transformerowych jest to liczba oddzielnych mechanizmów attention używanych w każdej warstwie. LLM zwykle wykorzystują dziesiątki heads.
- **Dropout**: Dropout to coś w rodzaju odsetka danych, które są usuwane (prawdopodobieństwa są ustawiane na 0) podczas treningu w celu **zapobiegania overfittingowi.** LLM zwykle wykorzystują wartość od 0 do 20%.

Konfiguracja modelu GPT-2:
```json
GPT_CONFIG_124M = {
"vocab_size": 50257,  // Vocabulary size of the BPE tokenizer
"context_length": 1024, // Context length
"emb_dim": 768,       // Embedding dimension
"n_heads": 12,        // Number of attention heads
"n_layers": 12,       // Number of layers
"drop_rate": 0.1,     // Dropout rate: 10%
"qkv_bias": False     // Query-Key-Value bias
}
```
## Tensory w PyTorch

W PyTorch **tensor** to podstawowa struktura danych pełniąca funkcję tablicy wielowymiarowej, uogólniająca pojęcia takie jak skalary, wektory i macierze na potencjalnie wyższe wymiary. Tensory są podstawowym sposobem reprezentowania i przetwarzania danych w PyTorch, szczególnie w kontekście deep learningu i sieci neuronowych.<sup>[[1]](#references)</sup>

### Matematyczna koncepcja tensorów

- **Skalary**: tensory rzędu 0 reprezentujące pojedynczą liczbę (zero-wymiarowe). Przykład: 5
- **Wektory**: tensory rzędu 1 reprezentujące jednowymiarową tablicę liczb. Przykład: \[5,1]
- **Macierze**: tensory rzędu 2 reprezentujące dwuwymiarowe tablice z wierszami i kolumnami. Przykład: \[\[1,3], \[5,2]]
- **Tensory wyższego rzędu**: tensory rzędu 3 lub wyższego reprezentujące dane w większej liczbie wymiarów (np. tensory 3D dla obrazów kolorowych).

### Tensory jako kontenery danych

Z perspektywy obliczeniowej tensory działają jak kontenery dla danych wielowymiarowych, w których każdy wymiar może reprezentować różne cechy lub aspekty danych. Dzięki temu tensory doskonale nadają się do obsługi złożonych zbiorów danych w zadaniach machine learning.

### Tensory PyTorch a tablice NumPy

Chociaż tensory PyTorch są podobne do tablic NumPy pod względem możliwości przechowywania i przetwarzania danych numerycznych, oferują dodatkowe funkcje kluczowe dla deep learningu:

- **Automatyczne różniczkowanie**: tensory PyTorch obsługują automatyczne obliczanie gradientów (autograd), co upraszcza proces obliczania pochodnych wymaganych do trenowania sieci neuronowych.
- **Akceleracja GPU**: tensory w PyTorch można przenosić na GPU i wykonywać na nich obliczenia, co znacznie przyspiesza obliczenia na dużą skalę.

### Tworzenie tensorów w PyTorch

Tensory można tworzyć za pomocą funkcji `torch.tensor`:

### Typy danych tensorów

Tensory PyTorch mogą przechowywać dane różnych typów, takich jak liczby całkowite i zmiennoprzecinkowe.

Typ danych tensora można sprawdzić za pomocą atrybutu `.dtype`:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Tensory utworzone z liczb całkowitych Pythona mają typ `torch.int64`.
- Tensory utworzone z liczb zmiennoprzecinkowych Pythona mają typ `torch.float32`.

Aby zmienić typ danych tensora, użyj metody `.to()`:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Typowe operacje na tensorach

PyTorch udostępnia różnorodne operacje umożliwiające manipulowanie tensorami:

- **Uzyskiwanie kształtu**: Użyj `.shape`, aby uzyskać wymiary tensora.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Zmiana kształtu tensorów**: Użyj `.reshape()` lub `.view()`, aby zmienić kształt.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Transponowanie tensorów**: Użyj `.T`, aby transponować tensor 2D.

```python
transposed = tensor2d.T
```

- **Mnożenie macierzy**: Użyj `.matmul()` lub operatora `@`.

```python
result = tensor2d @ tensor2d.T
```

### Znaczenie w deep learningu

Tensory są niezbędne w PyTorch do tworzenia i trenowania sieci neuronowych:

- Przechowują dane wejściowe, wagi i biasy.
- Umożliwiają wykonywanie operacji wymaganych podczas przebiegów w przód i wstecz w algorytmach treningowych.
- Dzięki autograd tensory umożliwiają automatyczne obliczanie gradientów, usprawniając proces optymalizacji.

## Automatyczne różniczkowanie

Automatyczne różniczkowanie (AD) to technika obliczeniowa używana do **wydajnego i dokładnego wyznaczania pochodnych (gradientów)** funkcji. W kontekście sieci neuronowych AD umożliwia obliczanie gradientów wymaganych przez **algorytmy optymalizacji, takie jak gradient descent**. PyTorch udostępnia silnik automatycznego różniczkowania o nazwie **autograd**, który upraszcza ten proces.<sup>[[1]](#references)</sup>

### Implementacja automatycznego różniczkowania w PyTorch

Zobaczmy teraz, jak PyTorch automatyzuje ten proces.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Propagacja wsteczna w większych sieciach neuronowych

### **1. Rozszerzenie do sieci wielowarstwowych**

W większych sieciach neuronowych z wieloma warstwami proces obliczania gradientów staje się bardziej złożony ze względu na większą liczbę parametrów i operacji. Jednak podstawowe zasady pozostają takie same:<sup>[[1]](#references)</sup>

- **Przejście w przód:** Oblicz wyjście sieci, przekazując dane wejściowe przez każdą warstwę.
- **Oblicz stratę:** Oceń funkcję straty na podstawie wyjścia sieci i etykiet docelowych.
- **Przejście wstecz (Backpropagation):** Oblicz gradienty straty względem każdego parametru w sieci, stosując rekurencyjnie regułę łańcuchową od warstwy wyjściowej do warstwy wejściowej.

### **2. Algorytm Backpropagation**

- **Krok 1:** Zainicjalizuj parametry sieci (wagi i biasy).
- **Krok 2:** Dla każdego przykładu treningowego wykonaj przejście w przód, aby obliczyć wyniki.
- **Krok 3:** Oblicz stratę.
- **Krok 4:** Oblicz gradienty straty względem każdego parametru, korzystając z reguły łańcuchowej.
- **Krok 5:** Zaktualizuj parametry za pomocą algorytmu optymalizacji (np. spadku gradientowego).

### **4. Implementacja w PyTorch**

PyTorch upraszcza ten proces dzięki mechanizmowi autograd.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
W tym kodzie:

- **Forward Pass:** Oblicza wyniki sieci.
- **Backward Pass:** `loss.backward()` oblicza gradienty funkcji straty względem wszystkich parametrów.
- **Parameter Update:** `optimizer.step()` aktualizuje parametry na podstawie obliczonych gradientów.

### **5. Zrozumienie Backward Pass**

Podczas Backward Pass:

- PyTorch przechodzi przez graf obliczeniowy w odwrotnej kolejności.
- Dla każdej operacji stosuje regułę łańcuchową w celu obliczenia gradientów.
- Gradienty są akumulowane w atrybucie `.grad` każdego tensora parametru.

### **6. Zalety automatycznego różniczkowania**

- **Wydajność:** Unika zbędnych obliczeń, ponownie wykorzystując wyniki pośrednie.
- **Dokładność:** Zapewnia dokładne pochodne z precyzją maszynową.
- **Łatwość użycia:** Eliminuje konieczność ręcznego obliczania pochodnych.
