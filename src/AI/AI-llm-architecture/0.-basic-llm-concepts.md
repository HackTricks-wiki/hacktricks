## Pretraining

Το Pretraining είναι η θεμελιώδης φάση ανάπτυξης ενός large language model (LLM), κατά την οποία το model εκτίθεται σε τεράστιες και ποικίλες ποσότητες δεδομένων κειμένου. Σε αυτό το στάδιο, **το LLM μαθαίνει τις θεμελιώδεις δομές, τα μοτίβα και τις αποχρώσεις της γλώσσας**, συμπεριλαμβανομένων της γραμματικής, του λεξιλογίου, της σύνταξης και των σχέσεων που εξαρτώνται από το context. Με την επεξεργασία αυτών των εκτεταμένων δεδομένων, το model αποκτά ευρεία κατανόηση της γλώσσας και γενικές γνώσεις για τον κόσμο. Αυτή η ολοκληρωμένη βάση επιτρέπει στο LLM να παράγει συνεκτικό και συναφές με το context κείμενο. Στη συνέχεια, αυτό το pretrained model μπορεί να υποβληθεί σε fine-tuning, κατά το οποίο εκπαιδεύεται περαιτέρω σε εξειδικευμένα datasets, ώστε να προσαρμόσει τις δυνατότητές του για συγκεκριμένες εργασίες ή domains, βελτιώνοντας την απόδοσή του και τη συνάφειά του σε στοχευμένες εφαρμογές.<sup>[[1]](#references)</sup>

## Κύρια στοιχεία των LLM

Συνήθως, ένα LLM χαρακτηρίζεται από τη configuration που χρησιμοποιείται για την εκπαίδευσή του. Αυτά είναι τα κοινά components κατά την εκπαίδευση ενός LLM:<sup>[[1]](#references)[[2]](#references)</sup>

- **Parameters**: Τα Parameters είναι τα **learnable weights και biases** στο neural network. Πρόκειται για τους αριθμούς που προσαρμόζει η διαδικασία εκπαίδευσης, ώστε να ελαχιστοποιήσει τη loss function και να βελτιώσει την απόδοση του model στην εργασία. Τα LLM χρησιμοποιούν συνήθως εκατομμύρια parameters.
- **Context Length**: Είναι το μέγιστο μήκος κάθε sentence που χρησιμοποιείται για το pre-training του LLM.
- **Embedding Dimension**: Το μέγεθος του vector που χρησιμοποιείται για την αναπαράσταση κάθε token ή word. Τα LLM συνήθως χρησιμοποιούν δισεκατομμύρια dimensions.
- **Hidden Dimension**: Το μέγεθος των hidden layers στο neural network.
- **Number of Layers (Depth)**: Πόσα layers έχει το model. Τα LLM συνήθως χρησιμοποιούν δεκάδες layers.
- **Number of Attention Heads**: Στα transformer models, πρόκειται για τον αριθμό των ξεχωριστών attention mechanisms που χρησιμοποιούνται σε κάθε layer. Τα LLM συνήθως χρησιμοποιούν δεκάδες heads.
- **Dropout**: Το Dropout είναι κάτι σαν το ποσοστό των δεδομένων που αφαιρείται (οι probabilities μετατρέπονται σε 0) κατά την εκπαίδευση, με σκοπό την **αποτροπή του overfitting.** Τα LLM συνήθως χρησιμοποιούν ποσοστό μεταξύ 0-20%.

Configuration του model GPT-2:
```json
GPT_CONFIG_124M = {
"vocab_size": 50257,  // Vocabulary size of the BPE tokenizer
"context_length": 1024, // Context length
"emb_dim": 768,       // Embedding dimension
"n_heads": 12,        // Number of attention heads
"n_layers": 12,       // Number of layers
"drop_rate": 0.1,     // Dropout rate: 10%
"qkv_bias": False     // Query-Key-Value bias
}
```
## Tensors στο PyTorch

Στο PyTorch, ένα **tensor** είναι μια θεμελιώδης δομή δεδομένων που λειτουργεί ως πολυδιάστατος πίνακας, γενικεύοντας έννοιες όπως οι scalars, τα vectors και οι matrices σε δυνητικά περισσότερες διαστάσεις. Τα tensors είναι ο κύριος τρόπος αναπαράστασης και χειρισμού δεδομένων στο PyTorch, ιδιαίτερα στο πλαίσιο της βαθιάς μάθησης και των neural networks.<sup>[[1]](#references)</sup>

### Μαθηματική έννοια των Tensors

- **Scalars**: Tensors rank 0, που αναπαριστούν έναν μόνο αριθμό (μηδενικών διαστάσεων). Για παράδειγμα: 5
- **Vectors**: Tensors rank 1, που αναπαριστούν έναν μονοδιάστατο πίνακα αριθμών. Για παράδειγμα: \[5,1]
- **Matrices**: Tensors rank 2, που αναπαριστούν δισδιάστατους πίνακες με γραμμές και στήλες. Για παράδειγμα: \[\[1,3], \[5,2]]
- **Tensors υψηλότερου rank**: Tensors rank 3 ή μεγαλύτερου, που αναπαριστούν δεδομένα σε υψηλότερες διαστάσεις (π.χ. 3D tensors για έγχρωμες εικόνες).

### Tensors ως Containers δεδομένων

Από υπολογιστική άποψη, τα tensors λειτουργούν ως containers για πολυδιάστατα δεδομένα, όπου κάθε διάσταση μπορεί να αναπαριστά διαφορετικά χαρακτηριστικά ή πτυχές των δεδομένων. Αυτό καθιστά τα tensors ιδιαίτερα κατάλληλα για τον χειρισμό σύνθετων datasets σε εργασίες machine learning.

### Tensors του PyTorch έναντι NumPy Arrays

Παρόλο που τα tensors του PyTorch είναι παρόμοια με τα NumPy arrays ως προς τη δυνατότητα αποθήκευσης και χειρισμού αριθμητικών δεδομένων, προσφέρουν επιπλέον λειτουργίες που είναι κρίσιμες για τη βαθιά μάθηση:

- **Automatic Differentiation**: Τα tensors του PyTorch υποστηρίζουν τον αυτόματο υπολογισμό gradients (autograd), απλοποιώντας τη διαδικασία υπολογισμού των παραγώγων που απαιτούνται για την εκπαίδευση neural networks.
- **GPU Acceleration**: Τα tensors στο PyTorch μπορούν να μεταφερθούν σε GPUs και οι υπολογισμοί να εκτελεστούν σε αυτές, επιταχύνοντας σημαντικά τους υπολογισμούς μεγάλης κλίμακας.

Τα tensors του PyTorch μπορούν να αποθηκεύουν δεδομένα διαφόρων τύπων, όπως ακέραιους και αριθμούς κινητής υποδιαστολής.

Για να αλλάξετε τον τύπο δεδομένων ενός τανυστή, χρησιμοποιήστε τη μέθοδο `.to()`:

### Σημασία στο Deep Learning

Τα tensors είναι απαραίτητα στο PyTorch για τη δημιουργία και την εκπαίδευση neural networks:

- Αποθηκεύουν input data, weights και biases.
- Διευκολύνουν τα operations που απαιτούνται για τα forward και backward passes στους training algorithms.
- Με το autograd, τα tensors επιτρέπουν τον αυτόματο υπολογισμό gradients, απλοποιώντας τη διαδικασία optimization.

## Automatic Differentiation

Το Automatic differentiation (AD) είναι μια υπολογιστική τεχνική που χρησιμοποιείται για την **αποτελεσματική και ακριβή αξιολόγηση των derivatives (gradients)** των functions. Στο πλαίσιο των neural networks, το AD επιτρέπει τον υπολογισμό των gradients που απαιτούνται για **optimization algorithms όπως το gradient descent**. Το PyTorch παρέχει ένα engine automatic differentiation που ονομάζεται **autograd** και απλοποιεί αυτή τη διαδικασία.<sup>[[1]](#references)</sup>

### Μαθηματική Επεξήγηση του Automatic Differentiation

### Υλοποίηση του Automatic Differentiation στο PyTorch

Τώρα, ας δούμε πώς το PyTorch αυτοματοποιεί αυτή τη διαδικασία.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Backpropagation σε Μεγαλύτερα Νευρωνικά Δίκτυα

### **1.Επέκταση σε Δικτύωση Πολλαπλών Επιπέδων**

Σε μεγαλύτερα νευρωνικά δίκτυα με πολλαπλά επίπεδα, η διαδικασία υπολογισμού των gradients γίνεται πιο σύνθετη λόγω του αυξημένου αριθμού παραμέτρων και λειτουργιών. Ωστόσο, οι θεμελιώδεις αρχές παραμένουν ίδιες:<sup>[[1]](#references)</sup>

- **Forward Pass:** Υπολογισμός της εξόδου του δικτύου μέσω της διέλευσης των εισόδων από κάθε επίπεδο.
- **Υπολογισμός Loss:** Αξιολόγηση της συνάρτησης loss χρησιμοποιώντας την έξοδο του δικτύου και τις ετικέτες-στόχους.
- **Backward Pass (Backpropagation):** Υπολογισμός των gradients του loss ως προς κάθε παράμετρο του δικτύου με εφαρμογή του chain rule αναδρομικά, από το επίπεδο εξόδου προς το επίπεδο εισόδου.

### **2. Αλγόριθμος Backpropagation**

- **Βήμα 1:** Αρχικοποίηση των παραμέτρων του δικτύου (weights και biases).
- **Βήμα 2:** Για κάθε training example, εκτέλεση ενός forward pass για τον υπολογισμό των outputs.
- **Βήμα 3:** Υπολογισμός του loss.
- **Βήμα 4:** Υπολογισμός των gradients του loss ως προς κάθε παράμετρο με χρήση του chain rule.
- **Βήμα 5:** Ενημέρωση των παραμέτρων με χρήση ενός optimization algorithm (π.χ. gradient descent).

### **4. Υλοποίηση σε PyTorch**

Το PyTorch απλοποιεί αυτήν τη διαδικασία με τη μηχανή autograd.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
Σε αυτόν τον κώδικα:

- **Forward Pass:** Υπολογίζει τις εξόδους του δικτύου.
- **Backward Pass:** Το `loss.backward()` υπολογίζει τις κλίσεις της συνάρτησης απώλειας ως προς όλες τις παραμέτρους.
- **Parameter Update:** Το `optimizer.step()` ενημερώνει τις παραμέτρους με βάση τις υπολογισμένες κλίσεις.

### **5. Κατανόηση του Backward Pass**

Κατά τη διάρκεια του backward pass:

- Το PyTorch διασχίζει το υπολογιστικό γράφημα με αντίστροφη σειρά.
- Για κάθε πράξη, εφαρμόζει τον κανόνα της αλυσίδας για να υπολογίσει τις κλίσεις.
- Οι κλίσεις συσσωρεύονται στο attribute `.grad` κάθε tensor παραμέτρου.

### **6. Πλεονεκτήματα του Automatic Differentiation**

- **Αποδοτικότητα:** Αποφεύγει τους περιττούς υπολογισμούς επαναχρησιμοποιώντας ενδιάμεσα αποτελέσματα.
- **Ακρίβεια:** Παρέχει ακριβείς παραγώγους έως την ακρίβεια της μηχανής.
- **Ευκολία χρήσης:** Εξαλείφει την ανάγκη χειροκίνητου υπολογισμού των παραγώγων.
