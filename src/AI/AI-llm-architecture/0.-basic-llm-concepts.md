## Pretraining

Pretraining은 large language model (LLM) 개발의 기반이 되는 단계로, 이 단계에서 model은 방대하고 다양한 양의 text data에 노출됩니다. 이 단계에서 **LLM은 grammar, vocabulary, syntax, contextual relationships를 포함한 language의 fundamental structures, patterns, nuances를 학습합니다.** 이러한 광범위한 data를 처리함으로써 model은 language와 일반적인 world knowledge에 대한 폭넓은 이해를 습득합니다. 이러한 포괄적인 기반을 통해 LLM은 일관되고 contextually relevant한 text를 생성할 수 있습니다. 이후 이 pretrained model은 fine-tuning을 거칠 수 있으며, 이 과정에서 특정 task 또는 domain에 맞게 capability를 조정하기 위해 specialized dataset으로 추가 training을 수행하여 targeted application에서의 performance와 relevance를 향상합니다.<sup>[[1]](#references)</sup>

## 주요 LLM components

일반적으로 LLM은 training에 사용된 configuration으로 특징지어집니다. 다음은 LLM을 training할 때 사용되는 common components입니다:<sup>[[1]](#references)[[2]](#references)</sup>

- **Parameters**: Parameters는 neural network의 **learnable weights와 biases**입니다. 이는 loss function을 최소화하고 task에서 model의 performance를 향상하기 위해 training process가 조정하는 숫자입니다. LLM은 일반적으로 수백만 개의 parameters를 사용합니다.
- **Context Length**: 이는 LLM을 pre-train하는 데 사용되는 각 sentence의 최대 length입니다.
- **Embedding Dimension**: 각 token 또는 word를 나타내는 데 사용되는 vector의 크기입니다. LLM은 일반적으로 수십억 개의 dimensions를 사용합니다.
- **Hidden Dimension**: neural network의 hidden layers 크기입니다.
- **Number of Layers (Depth)**: model이 보유한 layers의 수입니다. LLM은 일반적으로 수십 개의 layers를 사용합니다.
- **Number of Attention Heads**: transformer models에서 각 layer에 사용되는 별도의 attention mechanisms 수입니다. LLM은 일반적으로 수십 개의 heads를 사용합니다.
- **Dropout**: Dropout은 **overfitting을 방지하기 위해** training 중 제거되는 data의 비율(확률이 0으로 변환됨)과 같은 것입니다. LLM은 일반적으로 0~20%를 사용합니다.

GPT-2 model의 Configuration:
```json
GPT_CONFIG_124M = {
"vocab_size": 50257,  // Vocabulary size of the BPE tokenizer
"context_length": 1024, // Context length
"emb_dim": 768,       // Embedding dimension
"n_heads": 12,        // Number of attention heads
"n_layers": 12,       // Number of layers
"drop_rate": 0.1,     // Dropout rate: 10%
"qkv_bias": False     // Query-Key-Value bias
}
```
## PyTorch의 Tensors

PyTorch에서 **tensor**는 다차원 배열 역할을 하는 기본 데이터 구조로, 스칼라, 벡터, 행렬과 같은 개념을 더 높은 차원으로 일반화한 것입니다. Tensors는 특히 deep learning과 neural networks에서 데이터를 표현하고 조작하는 주요 방식입니다.<sup>[[1]](#references)</sup>

### Tensors의 수학적 개념

- **Scalars**: rank 0인 Tensors로, 단일 숫자(0차원)를 나타냅니다. 예: 5
- **Vectors**: rank 1인 Tensors로, 숫자의 1차원 배열을 나타냅니다. 예: \[5,1]
- **Matrices**: rank 2인 Tensors로, 행과 열이 있는 2차원 배열을 나타냅니다. 예: \[\[1,3], \[5,2]]
- **Higher-Rank Tensors**: rank 3 이상인 Tensors로, 고차원 데이터를 나타냅니다(예: color images를 위한 3D tensors).

### Data Container로서의 Tensors

계산 관점에서 tensors는 다차원 데이터의 container 역할을 하며, 각 차원은 데이터의 서로 다른 feature 또는 측면을 나타낼 수 있습니다. 따라서 tensors는 machine learning 작업에서 복잡한 datasets를 처리하는 데 매우 적합합니다.

### PyTorch Tensors와 NumPy Arrays 비교

PyTorch tensors는 numerical data를 저장하고 조작하는 기능 면에서 NumPy arrays와 유사하지만, deep learning에 중요한 추가 기능을 제공합니다.

- **Automatic Differentiation**: PyTorch tensors는 gradients의 자동 계산(autograd)을 지원하므로, neural networks 학습에 필요한 derivatives 계산 과정을 단순화합니다.
- **GPU Acceleration**: PyTorch의 Tensors는 GPUs로 이동하여 GPU에서 계산할 수 있으므로, 대규모 계산을 크게 가속할 수 있습니다.

### Tensor Data Types

PyTorch 텐서는 정수와 부동 소수점 수와 같은 다양한 유형의 데이터를 저장할 수 있습니다.

`.dtype` attribute를 사용하여 텐서의 데이터 유형을 확인할 수 있습니다:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Python 정수로 생성된 Tensor의 타입은 `torch.int64`입니다.
- Python 실수로 생성된 Tensor의 타입은 `torch.float32`입니다.

Tensor의 데이터 타입을 변경하려면 `.to()` 메서드를 사용합니다:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### 일반적인 Tensor 연산

PyTorch는 Tensor를 조작하기 위한 다양한 연산을 제공합니다:

- **Shape 확인**: `.shape`을 사용하여 Tensor의 차원을 확인합니다.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Tensor 형태 변경**: `.reshape()` 또는 `.view()`를 사용하여 형태를 변경합니다.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Tensor Transpose**: `.T`를 사용하여 2D Tensor를 transpose합니다.

```python
transposed = tensor2d.T
```

- **Matrix Multiplication**: `.matmul()` 또는 `@` 연산자를 사용합니다.

```python
result = tensor2d @ tensor2d.T
```

### Deep Learning에서의 중요성

Tensor는 PyTorch에서 neural network를 구축하고 학습시키는 데 필수적입니다:

- 입력 데이터, weight, bias를 저장합니다.
- 학습 알고리즘의 forward 및 backward pass에 필요한 연산을 지원합니다.
- autograd를 통해 Tensor는 gradient를 자동으로 계산할 수 있게 하여 optimization 과정을 간소화합니다.

## Automatic Differentiation

Automatic differentiation (AD)은 함수의 **derivative (gradient)**를 효율적이고 정확하게 **계산**하는 데 사용되는 computational technique입니다. neural network의 맥락에서 AD는 **gradient descent와 같은 optimization algorithm**에 필요한 gradient를 계산할 수 있게 합니다. PyTorch는 이 과정을 단순화하는 automatic differentiation engine인 **autograd**를 제공합니다.<sup>[[1]](#references)</sup>

### Automatic Differentiation의 수학적 설명

**1. Chain Rule**

Automatic differentiation의 핵심에는 calculus의 **chain rule**이 있습니다. chain rule은 함수의 합성(composition)이 주어졌을 때 composite function의 derivative가 구성 함수들의 derivative 곱이라고 설명합니다.

### PyTorch에서 Automatic Differentiation 구현

이제 PyTorch가 이 과정을 어떻게 자동화하는지 살펴보겠습니다.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## 더 큰 Neural Networks에서의 Backpropagation

### **1.다층 Networks로 확장**

여러 레이어로 구성된 더 큰 Neural Networks에서는 파라미터와 연산의 수가 증가하므로 gradient를 계산하는 과정이 더 복잡해집니다. 그러나 기본 원칙은 동일합니다:<sup>[[1]](#references)</sup>

- **Forward Pass:** 각 레이어를 통해 입력을 전달하여 Network의 출력을 계산합니다.
- **손실 계산:** Network의 출력과 target labels를 사용하여 loss function을 평가합니다.
- **Backward Pass (Backpropagation):** 출력 레이어에서 입력 레이어까지 chain rule을 재귀적으로 적용하여 Network의 각 파라미터에 대한 loss의 gradient를 계산합니다.

### **2. Backpropagation Algorithm**

- **Step 1:** Network 파라미터(weights와 biases)를 초기화합니다.
- **Step 2:** 각 training example에 대해 Forward Pass를 수행하여 출력을 계산합니다.
- **Step 3:** loss를 계산합니다.
- **Step 4:** chain rule을 사용하여 각 파라미터에 대한 loss의 gradient를 계산합니다.
- **Step 5:** optimization algorithm(예: gradient descent)을 사용하여 파라미터를 업데이트합니다.

### **4. PyTorch Implementation**

PyTorch는 autograd engine을 통해 이 과정을 간소화합니다.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
이 코드에서:

- **Forward Pass:** 네트워크의 출력을 계산합니다.
- **Backward Pass:** `loss.backward()`는 모든 매개변수에 대한 loss의 gradient를 계산합니다.
- **Parameter Update:** `optimizer.step()`은 계산된 gradient를 기반으로 매개변수를 업데이트합니다.

### **5. Backward Pass 이해하기**

Backward Pass 중에는 다음이 수행됩니다.

- PyTorch는 computational graph를 역순으로 탐색합니다.
- 각 연산에 대해 chain rule을 적용하여 gradient를 계산합니다.
- Gradient는 각 parameter tensor의 `.grad` attribute에 누적됩니다.

### **6. Automatic Differentiation의 장점**

- **효율성:** 중간 결과를 재사용하여 중복 계산을 방지합니다.
- **정확성:** machine precision까지 정확한 derivative를 제공합니다.
- **사용 편의성:** derivative를 수동으로 계산할 필요가 없습니다.
