## Pretraining

Il pretraining è la fase fondamentale nello sviluppo di un large language model (LLM), durante la quale il modello viene esposto a quantità vaste e diversificate di dati testuali. Durante questa fase, **l'LLM apprende le strutture fondamentali, i pattern e le sfumature del linguaggio**, inclusi grammatica, vocabolario, sintassi e relazioni contestuali. Elaborando questi dati estesi, il modello acquisisce una comprensione generale del linguaggio e una conoscenza generale del mondo. Questa base completa consente all'LLM di generare testo coerente e contestualmente rilevante. Successivamente, questo modello sottoposto a pretraining può essere sottoposto a fine-tuning, durante il quale viene ulteriormente addestrato su dataset specializzati per adattare le proprie capacità a task o domini specifici, migliorandone le prestazioni e la rilevanza nelle applicazioni mirate.<sup>[[1]](#references)</sup>

## Componenti principali degli LLM

Un LLM è generalmente caratterizzato dalla propria architettura e dalla configurazione di training. Questi sono i componenti comuni coinvolti nel training:<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Parameters**: i parameters sono i **pesi e i bias apprendibili** nella rete neurale. Sono i numeri che il processo di training modifica per minimizzare la loss function e migliorare le prestazioni del modello sul task. Gli LLM utilizzano generalmente milioni di parameters.
- **Context Length**: è la lunghezza massima di ogni frase utilizzata per il pretraining dell'LLM.
- **Embedding Dimension**: la dimensione del vettore utilizzato per rappresentare ogni token o parola. Gli LLM utilizzano generalmente miliardi di dimensioni.
- **Hidden Dimension**: la dimensione degli hidden layer nella rete neurale.
- **Number of Layers (Depth)**: il numero di layer presenti nel modello. Gli LLM utilizzano generalmente decine di layer.
- **Number of Attention Heads**: nei modelli transformer, indica quanti meccanismi di attention separati vengono utilizzati in ogni layer. Gli LLM utilizzano generalmente decine di heads.
- **Dropout**: il dropout è qualcosa di simile alla percentuale di dati rimossi (le probabilità diventano 0) durante il training, utilizzata per **prevenire l'overfitting.** Gli LLM utilizzano generalmente valori compresi tra 0 e 20%.

## I tensori in PyTorch

In PyTorch, un **tensor** è una struttura dati fondamentale che funge da array multidimensionale, generalizzando concetti come scalari, vettori e matrici a dimensioni potenzialmente superiori. I tensor sono il modo principale in cui i dati vengono rappresentati e manipolati in PyTorch, soprattutto nel contesto del deep learning e delle reti neurali.<sup>[[1]](#references)</sup>

### Concetto matematico dei tensor

- **Scalari**: tensor di rango 0, che rappresentano un singolo numero (zero-dimensionale). Ad esempio: 5
- **Vettori**: tensor di rango 1, che rappresentano un array di numeri unidimensionale. Ad esempio: \[5,1]
- **Matrici**: tensor di rango 2, che rappresentano array bidimensionali con righe e colonne. Ad esempio: \[\[1,3], \[5,2]]
- **Tensor di rango superiore**: tensor di rango 3 o superiore, che rappresentano dati in dimensioni superiori (ad esempio, tensor 3D per immagini a colori).

### I tensor come contenitori di dati

Dal punto di vista computazionale, i tensor fungono da contenitori per dati multidimensionali, in cui ogni dimensione può rappresentare caratteristiche o aspetti diversi dei dati. Questo rende i tensor particolarmente adatti alla gestione di dataset complessi nelle attività di machine learning.

### Tensor di PyTorch vs. array NumPy

Sebbene i tensor di PyTorch siano simili agli array NumPy nella capacità di archiviare e manipolare dati numerici, offrono funzionalità aggiuntive fondamentali per il deep learning:

- **Differenziazione automatica**: i tensor di PyTorch supportano il calcolo automatico dei gradienti (autograd), semplificando il calcolo delle derivate necessarie per l'addestramento delle reti neurali.
- **Accelerazione GPU**: i tensor in PyTorch possono essere trasferiti alle GPU e utilizzati per i calcoli su di esse, velocizzando significativamente i calcoli su larga scala.

### Creazione di tensor in PyTorch

È possibile creare tensor utilizzando la funzione `torch.tensor`:

# Scalar (0D tensor)
tensor0d = torch.tensor(1)

### Tipi di dati dei tensori

I tensori PyTorch possono memorizzare dati di vari tipi, come numeri interi e numeri in virgola mobile.

Puoi controllare il tipo di dati di un tensore usando l'attributo `.dtype`:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- I tensori creati da interi Python sono di tipo `torch.int64`.
- I tensori creati da numeri a virgola mobile Python sono di tipo `torch.float32`.

Per modificare il tipo di dati di un tensore, usa il metodo `.to()`:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Operazioni comuni sui tensori

PyTorch fornisce una varietà di operazioni per manipolare i tensori:

- **Accesso alla forma**: usa `.shape` per ottenere le dimensioni di un tensore.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Ridimensionamento dei tensori**: usa `.reshape()` o `.view()` per modificare la forma.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Trasposizione dei tensori**: usa `.T` per trasporre un tensore 2D.

```python
transposed = tensor2d.T
```

- **Moltiplicazione tra matrici**: usa `.matmul()` o l'operatore `@`.

```python
result = tensor2d @ tensor2d.T
```

### Importanza nel Deep Learning

I tensori sono essenziali in PyTorch per creare e addestrare le reti neurali:

- Memorizzano i dati di input, i pesi e i bias.
- Facilitano le operazioni necessarie per i passaggi forward e backward negli algoritmi di addestramento.
- Con autograd, i tensori consentono il calcolo automatico dei gradienti, semplificando il processo di ottimizzazione.

## Differenziazione automatica

La differenziazione automatica (AD) è una tecnica computazionale utilizzata per **valutare le derivate (gradienti)** delle funzioni in modo efficiente e preciso. Nel contesto delle reti neurali, l'AD consente di calcolare i gradienti necessari per gli **algoritmi di ottimizzazione come la discesa del gradiente**. PyTorch fornisce un motore di differenziazione automatica chiamato **autograd** che semplifica questo processo.<sup>[[1]](#references)</sup>

### Spiegazione matematica della differenziazione automatica

**1. La regola della catena**

Alla base della differenziazione automatica si trova la **regola della catena** del calcolo differenziale. La regola della catena stabilisce che, se si dispone di una composizione di funzioni, la derivata della funzione composta è il prodotto delle derivate delle funzioni che la compongono.

### Implementazione della differenziazione automatica in PyTorch

Ora vediamo come PyTorch automatizza questo processo.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Backpropagation nelle reti neurali più grandi

### **1. Estensione alle reti multilivello**

Nelle reti neurali più grandi con più livelli, il processo di calcolo dei gradienti diventa più complesso a causa dell'aumento del numero di parametri e operazioni. Tuttavia, i principi fondamentali rimangono gli stessi:<sup>[[1]](#references)</sup>

- **Forward Pass:** Calcolare l'output della rete passando gli input attraverso ogni livello.
- **Calcolo della Loss:** Valutare la funzione di loss utilizzando l'output della rete e le etichette target.
- **Backward Pass (Backpropagation):** Calcolare i gradienti della loss rispetto a ciascun parametro della rete applicando ricorsivamente la chain rule dal livello di output fino al livello di input.

### **2. Algoritmo di Backpropagation**

- **Passaggio 1:** Inizializzare i parametri della rete (pesi e bias).
- **Passaggio 2:** Per ogni esempio di training, eseguire un forward pass per calcolare gli output.
- **Passaggio 3:** Calcolare la loss.
- **Passaggio 4:** Calcolare i gradienti della loss rispetto a ciascun parametro utilizzando la chain rule.
- **Passaggio 5:** Aggiornare i parametri utilizzando un algoritmo di ottimizzazione (ad esempio, gradient descent).

### **4. Implementazione in PyTorch**

PyTorch semplifica questo processo con il suo motore autograd.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
In questo codice:

- **Passaggio in avanti:** calcola gli output della rete.
- **Passaggio all'indietro:** `loss.backward()` calcola i gradienti della loss rispetto a tutti i parametri.
- **Aggiornamento dei parametri:** `optimizer.step()` aggiorna i parametri in base ai gradienti calcolati.

### **5. Comprendere il passaggio all'indietro**

Durante il passaggio all'indietro:

- PyTorch attraversa il grafo computazionale in ordine inverso.
- Per ogni operazione, applica la chain rule per calcolare i gradienti.
- I gradienti vengono accumulati nell'attributo `.grad` di ogni tensore dei parametri.

### **6. Vantaggi della differenziazione automatica**

- **Efficienza:** evita calcoli ridondanti riutilizzando i risultati intermedi.
- **Accuratezza:** fornisce derivate esatte fino alla precisione della macchina.
- **Facilità d'uso:** elimina il calcolo manuale delle derivate.
