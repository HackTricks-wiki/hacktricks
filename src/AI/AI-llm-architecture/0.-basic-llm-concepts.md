## Pretraining

Pretraining ni awamu ya msingi katika kutengeneza large language model (LLM), ambapo model huonyeshwa kiasi kikubwa na tofauti-tofauti cha data ya maandishi. Katika hatua hii, **LLM hujifunza miundo, mifumo na nuances za msingi za lugha**, ikijumuisha sarufi, msamiati, sintaksia na uhusiano wa kimuktadha. Kwa kuchakata data hii pana, model hupata uelewa mpana wa lugha na maarifa ya jumla kuhusu ulimwengu. Msingi huu mpana huwezesha LLM kuzalisha maandishi yenye mshikamano na yanayohusiana na muktadha. Baadaye, model hii iliyofanyiwa pretraining inaweza kufanyiwa fine-tuning, ambapo hufunzwa zaidi kwa kutumia datasets maalum ili kurekebisha uwezo wake kwa ajili ya tasks au domains mahususi, hivyo kuboresha utendaji na umuhimu wake katika matumizi lengwa.<sup>[[1]](#references)</sup>

## Vipengele Vikuu vya LLM

Kwa kawaida, LLM hutofautishwa kulingana na configuration iliyotumika kuifundisha. Hivi ni vipengele vya kawaida vinavyotumika wakati wa kufundisha LLM:<sup>[[1]](#references)[[2]](#references)</sup>

- **Parameters**: Parameters ni **weights na biases zinazoweza kujifunzwa** katika neural network. Hizi ni namba ambazo mchakato wa training hurekebisha ili kupunguza loss function na kuboresha utendaji wa model kwenye task. LLM kwa kawaida hutumia mamilioni ya parameters.
- **Context Length**: Huu ni urefu wa juu kabisa wa kila sentensi inayotumika kufanya pre-train ya LLM.
- **Embedding Dimension**: Ukubwa wa vector unaotumika kuwakilisha kila token au neno. LLM kwa kawaida hutumia mabilioni ya dimensions.
- **Hidden Dimension**: Ukubwa wa hidden layers katika neural network.
- **Number of Layers (Depth)**: Idadi ya layers ambazo model inazo. LLM kwa kawaida hutumia makumi ya layers.
- **Number of Attention Heads**: Katika transformer models, hii ni idadi ya attention mechanisms tofauti zinazotumika katika kila layer. LLM kwa kawaida hutumia makumi ya heads.
- **Dropout**: Dropout ni kama asilimia ya data inayoondolewa (probabilities hubadilishwa kuwa 0) wakati wa training ili **kuzuia overfitting.** LLM kwa kawaida hutumia kati ya 0-20%.

Configuration ya GPT-2 model:
```json
GPT_CONFIG_124M = {

"context_length": 1024, // Context length

"n_layers": 12,       // Number of layers
"drop_rate": 0.1,     // Dropout rate: 10%

```
## Tensors katika PyTorch

Katika PyTorch, **tensor** ni muundo msingi wa data unaotumika kama array yenye vipimo vingi, ukipanua dhana kama scalars, vectors, na matrices hadi vipimo vya juu zaidi. Tensors ndiyo njia kuu ya kuwakilisha na kuchakata data katika PyTorch, hasa katika muktadha wa deep learning na neural networks.<sup>[[1]](#references)</sup>

### Dhana ya Kihisabati ya Tensors

- **Scalars**: Tensors zenye rank ya 0, zinazowakilisha namba moja (zenye kipimo sifuri). Mfano: 5
- **Vectors**: Tensors zenye rank ya 1, zinazowakilisha array ya namba yenye kipimo kimoja. Mfano: \[5,1]
- **Matrices**: Tensors zenye rank ya 2, zinazowakilisha arrays zenye vipimo viwili na safu mlalo pamoja na safu wima. Mfano: \[\[1,3], \[5,2]]
- **Higher-Rank Tensors**: Tensors zenye rank ya 3 au zaidi, zinazowakilisha data katika vipimo vya juu (kwa mfano, tensors za 3D za picha za rangi).

### Tensors kama Vihifadhi vya Data

Kwa mtazamo wa kimahesabu, tensors hufanya kazi kama vihifadhi vya data yenye vipimo vingi, ambapo kila kipimo kinaweza kuwakilisha sifa au kipengele tofauti cha data. Hii huzifanya tensors zifae sana kwa kushughulikia datasets changamano katika kazi za machine learning.

### Tensors za PyTorch dhidi ya Arrays za NumPy

Ingawa tensors za PyTorch zinafanana na arrays za NumPy katika uwezo wake wa kuhifadhi na kuchakata data za namba, hutoa utendaji wa ziada muhimu kwa deep learning:

- **Automatic Differentiation**: Tensors za PyTorch zinaunga mkono ukokotoaji wa gradients kiotomatiki (autograd), unaorahisisha mchakato wa kukokotoa derivatives zinazohitajika kwa ajili ya kufundisha neural networks.
- **GPU Acceleration**: Tensors katika PyTorch zinaweza kuhamishiwa kwenye GPUs na kufanyiwa ukokotoaji humo, jambo linaloharakisha kwa kiasi kikubwa ukokotoaji wa kiwango kikubwa.

### Aina za Data za Tensor

Tensor za PyTorch zinaweza kuhifadhi data za aina mbalimbali, kama vile nambari kamili na nambari za desimali.

Unaweza kuangalia aina ya data ya tensor kwa kutumia attribute ya `.dtype`:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Tensors zilizoundwa kutoka kwa integers za Python ni za aina `torch.int64`.
- Tensors zilizoundwa kutoka kwa floats za Python ni za aina `torch.float32`.

Ili kubadilisha aina ya data ya tensor, tumia method ya `.to()`:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Operesheni za Kawaida za Tensor

PyTorch hutoa operesheni mbalimbali za kudhibiti tensor:

- **Kubadilisha Shape za Tensor**: Tumia `.reshape()` au `.view()` kubadilisha shape.


## Automatic Differentiation

Automatic differentiation (AD) ni mbinu ya computational inayotumiwa **kutathmini derivatives (gradients)** za functions kwa ufanisi na usahihi. Katika muktadha wa neural networks, AD huwezesha ukokotoaji wa gradients unaohitajika kwa **optimization algorithms kama gradient descent**. PyTorch hutoa engine ya automatic differentiation inayoitwa **autograd**, ambayo hurahisisha mchakato huu.<sup>[[1]](#references)</sup>

### Kutekeleza Automatic Differentiation katika PyTorch

Sasa, tuone jinsi PyTorch inavyofanya mchakato huu kiotomatiki.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Backpropagation katika Neural Networks Kubwa

### **1.Kupanua hadi Multilayer Networks**

Katika neural networks kubwa zilizo na layers nyingi, mchakato wa kukokotoa gradients huwa tata zaidi kutokana na kuongezeka kwa idadi ya parameters na operations. Hata hivyo, kanuni za msingi hubaki zilezile:<sup>[[1]](#references)</sup>

- **Forward Pass:** Kokotoa output ya network kwa kupitisha inputs kupitia kila layer.
- **Compute Loss:** Tathmini loss function kwa kutumia output ya network na target labels.
- **Backward Pass (Backpropagation):** Kokotoa gradients za loss kwa heshima ya kila parameter katika network kwa kutumia chain rule kwa kurudia kutoka output layer kurudi input layer.

### **2. Algorithm ya Backpropagation**

- **Step 1:** Anzisha parameters za network (weights na biases).
- **Step 2:** Kwa kila training example, tekeleza forward pass ili kukokotoa outputs.
- **Step 3:** Kokotoa loss.
- **Step 4:** Kokotoa gradients za loss kwa heshima ya kila parameter kwa kutumia chain rule.
- **Step 5:** Sasisha parameters kwa kutumia optimization algorithm (kwa mfano, gradient descent).

### **4. Utekelezaji wa PyTorch**

PyTorch hurahisisha mchakato huu kwa kutumia autograd engine.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
Katika code hii:

- **Forward Pass:** Hukokotoa matokeo ya network.
- **Backward Pass:** `loss.backward()` hukokotoa gradients za loss kuhusiana na parameters zote.
- **Parameter Update:** `optimizer.step()` husasisha parameters kulingana na gradients zilizokokotolewa.

### **5. Kuelewa Backward Pass**

Wakati wa backward pass:

- PyTorch hupitia computational graph kwa mpangilio wa kinyume.
- Kwa kila operation, hutumia chain rule kukokotoa gradients.
- Gradients hukusanywa katika attribute ya `.grad` ya kila parameter tensor.

### **6. Faida za Automatic Differentiation**

- **Ufanisi:** Huepuka calculations zinazorudiwa kwa kutumia tena matokeo ya kati.
- **Usahihi:** Hutoa derivatives sahihi hadi kufikia machine precision.
- **Urahisi wa Kutumia:** Huondoa hitaji la kukokotoa derivatives manually.
