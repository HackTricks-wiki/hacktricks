## Pretraining

Pretraining je osnovna faza u razvoju velikog jezičkog modela (LLM), tokom koje se model izlaže ogromnim i raznovrsnim količinama tekstualnih podataka. Tokom ove faze, **LLM uči osnovne strukture, obrasce i nijanse jezika**, uključujući gramatiku, vokabular, sintaksu i kontekstualne odnose. Obradom ovih obimnih podataka, model stiče široko razumevanje jezika i opšte znanje o svetu. Ova sveobuhvatna osnova omogućava LLM-u da generiše koherentan tekst relevantan za dati kontekst. Nakon toga, ovaj prethodno obučen model može proći kroz fino podešavanje, tokom kojeg se dodatno obučava na specijalizovanim skupovima podataka kako bi se njegove mogućnosti prilagodile određenim zadacima ili domenima, čime se poboljšavaju njegove performanse i relevantnost u ciljnim primenama.<sup>[[1]](#references)</sup>

## Glavne komponente LLM-a

LLM se obično opisuje svojom arhitekturom i konfiguracijom obuke. Ovo su uobičajene komponente uključene u obuku jednog takvog modela:<sup>[[1]](#references)</sup><sup>[[2]](#references)</sup>

- **Parameters**: Parametri su **težine i bias vrednosti koje neuronska mreža može da nauči**. To su brojevi koje proces obuke prilagođava kako bi minimizovao funkciju gubitka i poboljšao performanse modela na zadatku. LLM-ovi obično koriste milione parametara.
- **Context Length**: Ovo je maksimalna dužina svake rečenice koja se koristi za pretraining LLM-a.
- **Embedding Dimension**: Veličina vektora koji se koristi za predstavljanje svakog tokena ili reči. LLM-ovi obično koriste milijarde dimenzija.
- **Hidden Dimension**: Veličina skrivenih slojeva u neuronskoj mreži.
- **Number of Layers (Depth)**: Broj slojeva koje model ima. LLM-ovi obično koriste desetine slojeva.
- **Number of Attention Heads**: U transformer modelima, ovo predstavlja broj zasebnih mehanizama pažnje koji se koriste u svakom sloju. LLM-ovi obično koriste desetine attention head-ova.
- **Dropout**: Dropout predstavlja nešto poput procenta podataka koji se uklanja (verovatnoće se postavljaju na 0) tokom obuke, a koristi se za **sprečavanje overfitting-a.** LLM-ovi obično koriste između 0 i 20%.

Konfiguracija GPT-2 modela:
```json
GPT_CONFIG_124M = {
"vocab_size": 50257,  // Vocabulary size of the BPE tokenizer
"context_length": 1024, // Context length
"emb_dim": 768,       // Embedding dimension
"n_heads": 12,        // Number of attention heads
"n_layers": 12,       // Number of layers
"drop_rate": 0.1,     // Dropout rate: 10%
"qkv_bias": False     // Query-Key-Value bias
}
```
## Tensori u PyTorch-u

U PyTorch-u, **tensor** je osnovna struktura podataka koja služi kao višedimenzionalni niz, generalizujući koncepte kao što su skalari, vektori i matrice na potencijalno više dimenzija. Tensori su primarni način predstavljanja podataka i manipulisanja njima u PyTorch-u, naročito u kontekstu deep learning-a i neuronskih mreža.<sup>[[1]](#references)</sup>

### Matematički koncept tensor-a

- **Skalari**: Tensori ranga 0, koji predstavljaju jedan broj (nultodimenzionalni). Na primer: 5
- **Vektori**: Tensori ranga 1, koji predstavljaju jednodimenzionalni niz brojeva. Na primer: \[5,1]
- **Matrice**: Tensori ranga 2, koji predstavljaju dvodimenzionalne nizove sa redovima i kolonama. Na primer: \[\[1,3], \[5,2]]
- **Tensori višeg ranga**: Tensori ranga 3 ili višeg, koji predstavljaju podatke u višim dimenzijama (npr. 3D tensori za slike u boji).

### Tensori kao kontejneri podataka

Iz računarske perspektive, tensor-i deluju kao kontejneri za višedimenzionalne podatke, pri čemu svaka dimenzija može predstavljati različite karakteristike ili aspekte podataka. Zbog toga su tensor-i veoma pogodni za rad sa složenim skupovima podataka u zadacima machine learning-a.

### PyTorch tensor-i u odnosu na NumPy nizove

Iako su PyTorch tensor-i slični NumPy nizovima po mogućnosti skladištenja i manipulisanja numeričkim podacima, oni nude dodatne funkcionalnosti ključne za deep learning:

- **Automatska diferencijacija**: PyTorch tensor-i podržavaju automatsko izračunavanje gradijenata (autograd), što pojednostavljuje proces izračunavanja izvoda potrebnih za treniranje neuronskih mreža.
- **GPU ubrzanje**: Tensor-i u PyTorch-u mogu se prebaciti na GPU i na njemu obrađivati, čime se značajno ubrzavaju računanja velikih razmera.

### Kreiranje tensor-a u PyTorch-u

Tensor-e možete kreirati pomoću funkcije `torch.tensor`:

### Tipovi podataka tenzora

PyTorch tenzori mogu da čuvaju podatke različitih tipova, kao što su celi brojevi i brojevi sa pokretnim zarezom.

Tip podataka tenzora možete proveriti pomoću atributa `.dtype`:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- Tenzori kreirani iz Python celih brojeva su tipa `torch.int64`.
- Tenzori kreirani iz Python brojeva sa pokretnim zarezom su tipa `torch.float32`.

Da biste promenili tip podataka tenzora, koristite metodu `.to()`:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Uobičajene operacije nad tenzorima

PyTorch pruža različite operacije za manipulisanje tenzorima:

- **Pristup obliku**: Koristite `.shape` da biste dobili dimenzije tenzora.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Promena oblika tenzora**: Koristite `.reshape()` ili `.view()` da biste promenili oblik.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Transponovanje tenzora**: Koristite `.T` da biste transponovali 2D tenzor.

```python
transposed = tensor2d.T
```

- **Množenje matrica**: Koristite `.matmul()` ili operator `@`.

```python
result = tensor2d @ tensor2d.T
```

### Važnost u dubokom učenju

Tenzori su ključni u PyTorch-u za izgradnju i obučavanje neuronskih mreža:

- Čuvaju ulazne podatke, težine i bias vrednosti.
- Omogućavaju operacije potrebne za prolaz unapred i unazad u algoritmima obučavanja.
- Uz autograd, tenzori omogućavaju automatsko izračunavanje gradijenata, čime se pojednostavljuje proces optimizacije.

## Automatsko diferenciranje

Automatsko diferenciranje (AD) je računska tehnika koja se koristi za **efikasno i precizno izračunavanje izvoda (gradijenata)** funkcija. U kontekstu neuronskih mreža, AD omogućava izračunavanje gradijenata potrebnih za **algoritme optimizacije kao što je gradient descent**. PyTorch pruža engine za automatsko diferenciranje pod nazivom **autograd**, koji pojednostavljuje ovaj proces.<sup>[[1]](#references)</sup>

### Implementacija automatskog diferenciranja u PyTorch-u

Sada pogledajmo kako PyTorch automatizuje ovaj proces.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Propagacija unazad u većim neuronskim mrežama

### **1. Proširivanje na višeslojne mreže**

U većim neuronskim mrežama sa više slojeva, proces izračunavanja gradijenata postaje složeniji zbog povećanog broja parametara i operacija. Međutim, osnovni principi ostaju isti:<sup>[[1]](#references)</sup>

- **Prolaz unapred:** Izračunajte izlaz mreže prosleđivanjem ulaza kroz svaki sloj.
- **Izračunavanje gubitka:** Procenite funkciju gubitka koristeći izlaz mreže i ciljne oznake.
- **Prolaz unazad (backpropagation):** Izračunajte gradijente gubitka u odnosu na svaki parametar u mreži rekurzivnom primenom pravila lanca, počevši od izlaznog sloja i krećući se ka ulaznom sloju.

### **2. Algorithm za backpropagation**

- **Korak 1:** Inicijalizujte parametre mreže (težine i bias vrednosti).
- **Korak 2:** Za svaki primer za obuku izvršite prolaz unapred da biste izračunali izlaze.
- **Korak 3:** Izračunajte gubitak.
- **Korak 4:** Izračunajte gradijente gubitka u odnosu na svaki parametar koristeći pravilo lanca.
- **Korak 5:** Ažurirajte parametre pomoću optimization algorithm-a (npr. gradient descent-a).

### **4. Implementacija u PyTorch-u**

PyTorch pojednostavljuje ovaj proces pomoću svog autograd engine-a.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
U ovom kodu:

- **Prosleđivanje unapred:** Izračunava izlaze mreže.
- **Prosleđivanje unazad:** `loss.backward()` izračunava gradijente gubitka u odnosu na sve parametre.
- **Ažuriranje parametara:** `optimizer.step()` ažurira parametre na osnovu izračunatih gradijenata.

### **5. Razumevanje prosleđivanja unazad**

Tokom prosleđivanja unazad:

- PyTorch prolazi kroz računarski graf obrnutim redosledom.
- Za svaku operaciju primenjuje lančano pravilo kako bi izračunao gradijente.
- Gradijenti se akumuliraju u atributu `.grad` svakog tenzora parametra.

### **6. Prednosti automatskog diferenciranja**

- **Efikasnost:** Izbegava suvišna izračunavanja ponovnim korišćenjem međurezultata.
- **Preciznost:** Obezbeđuje tačne izvode do preciznosti mašine.
- **Jednostavnost korišćenja:** Uklanja potrebu za ručnim izračunavanjem izvoda.
