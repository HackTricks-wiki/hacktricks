## Pretraining

Il pretraining è la fase fondamentale nello sviluppo di un large language model (LLM), durante la quale il modello viene esposto a quantità vaste e diversificate di dati testuali. Durante questa fase, **l'LLM apprende le strutture fondamentali, gli schemi e le sfumature del linguaggio**, inclusi grammatica, vocabolario, sintassi e relazioni contestuali. Elaborando questi dati estesi, il modello acquisisce una comprensione generale del linguaggio e una conoscenza generale del mondo. Questa base completa consente all'LLM di generare testo coerente e rilevante dal punto di vista contestuale. Successivamente, questo modello sottoposto a pretraining può essere sottoposto a fine-tuning, durante il quale viene ulteriormente addestrato su dataset specializzati per adattare le sue capacità a compiti o domini specifici, migliorandone le prestazioni e la rilevanza nelle applicazioni mirate.<sup>[[1]](#references)</sup>

## Componenti principali degli LLM

Solitamente un LLM è caratterizzato dalla configurazione utilizzata per addestrarlo. Questi sono i componenti comuni durante l'addestramento di un LLM:<sup>[[1]](#references)[[2]](#references)</sup>

- **Parametri**: I parametri sono i **pesi e i bias apprendibili** nella rete neurale. Sono i numeri che il processo di addestramento modifica per minimizzare la funzione di perdita e migliorare le prestazioni del modello sul compito. Gli LLM utilizzano solitamente milioni di parametri.
- **Lunghezza del contesto**: È la lunghezza massima di ogni frase utilizzata per il pretraining dell'LLM.
- **Dimensione dell'embedding**: La dimensione del vettore utilizzato per rappresentare ogni token o parola. Gli LLM utilizzano solitamente miliardi di dimensioni.
- **Dimensione nascosta**: La dimensione dei livelli nascosti nella rete neurale.
- **Numero di livelli (profondità)**: Il numero di livelli presenti nel modello. Gli LLM utilizzano solitamente decine di livelli.
- **Numero di attention heads**: Nei modelli transformer, indica quanti meccanismi di attention separati vengono utilizzati in ogni livello. Gli LLM utilizzano solitamente decine di heads.
- **Dropout**: Il dropout è qualcosa di simile alla percentuale di dati rimossi (le probabilità vengono impostate a 0) durante l'addestramento, utilizzata per **prevenire l'overfitting.** Gli LLM utilizzano solitamente valori compresi tra 0 e 20%.

## Tensori in PyTorch

In PyTorch, un **tensor** è una struttura dati fondamentale che funge da array multidimensionale, generalizzando concetti come scalari, vettori e matrici a dimensioni potenzialmente superiori. I tensori sono il modo principale in cui i dati vengono rappresentati e manipolati in PyTorch, soprattutto nel contesto del deep learning e delle reti neurali.<sup>[[1]](#references)</sup>

### Concetto matematico dei tensori

- **Scalari**: tensori di rango 0, che rappresentano un singolo numero (zero-dimensionali). Ad esempio: 5
- **Vettori**: tensori di rango 1, che rappresentano un array di numeri unidimensionale. Ad esempio: \[5,1]
- **Matrici**: tensori di rango 2, che rappresentano array bidimensionali con righe e colonne. Ad esempio: \[\[1,3], \[5,2]]
- **Tensori di rango superiore**: tensori di rango 3 o superiore, che rappresentano dati in dimensioni superiori (ad esempio, tensori 3D per immagini a colori).

### I tensori come contenitori di dati

Dal punto di vista computazionale, i tensori fungono da contenitori per dati multidimensionali, in cui ogni dimensione può rappresentare caratteristiche o aspetti diversi dei dati. Questo rende i tensori particolarmente adatti alla gestione di dataset complessi nelle attività di machine learning.

### Tensori PyTorch vs. array NumPy

Sebbene i tensori PyTorch siano simili agli array NumPy per la capacità di memorizzare e manipolare dati numerici, offrono funzionalità aggiuntive fondamentali per il deep learning:

- **Differenziazione automatica**: i tensori PyTorch supportano il calcolo automatico dei gradienti (autograd), semplificando il processo di calcolo delle derivate necessarie per l'addestramento delle reti neurali.
- **Accelerazione GPU**: i tensori in PyTorch possono essere trasferiti ed elaborati sulle GPU, velocizzando significativamente i calcoli su larga scala.

### Creazione di tensori in PyTorch

Puoi creare tensori usando la funzione `torch.tensor`:
```python

# Scalar (0D tensor)
tensor0d = torch.tensor(1)

# Vector (1D tensor)
```

### Tipi di dati dei tensori

I tensori PyTorch possono memorizzare dati di vari tipi, come numeri interi e numeri in virgola mobile.

Puoi verificare il tipo di dati di un tensore usando l'attributo `.dtype`:
```python
tensor1d = torch.tensor([1, 2, 3])
print(tensor1d.dtype)  # Output: torch.int64
```
- I tensori creati da interi Python sono di tipo `torch.int64`.
- I tensori creati da numeri floating-point Python sono di tipo `torch.float32`.

Per modificare il tipo di dati di un tensore, usa il metodo `.to()`:
```python
float_tensor = tensor1d.to(torch.float32)
print(float_tensor.dtype)  # Output: torch.float32
```
### Operazioni comuni sui tensori

PyTorch fornisce una varietà di operazioni per manipolare i tensori:

- **Accesso alla shape**: usa `.shape` per ottenere le dimensioni di un tensore.

```python
print(tensor2d.shape)  # Output: torch.Size([2, 2])
```

- **Modifica della shape dei tensori**: usa `.reshape()` o `.view()` per modificare la shape.

```python
reshaped = tensor2d.reshape(4, 1)
```

- **Trasposizione dei tensori**: usa `.T` per trasporre un tensore 2D.

```python
transposed = tensor2d.T
```

- **Moltiplicazione tra matrici**: usa `.matmul()` o l'operatore `@`.

```python
result = tensor2d @ tensor2d.T
```

### Importanza nel Deep Learning

I tensori sono essenziali in PyTorch per creare e addestrare le reti neurali:

- Memorizzano i dati di input, i pesi e i bias.
- Facilitano le operazioni necessarie per i passaggi forward e backward negli algoritmi di addestramento.
- Con autograd, i tensori consentono il calcolo automatico dei gradienti, semplificando il processo di ottimizzazione.

## Differenziazione automatica

La differenziazione automatica (AD) è una tecnica computazionale utilizzata per **calcolare le derivate (gradienti)** delle funzioni in modo efficiente e accurato. Nel contesto delle reti neurali, l'AD consente di calcolare i gradienti necessari per gli **algoritmi di ottimizzazione come la discesa del gradiente**. PyTorch fornisce un motore di differenziazione automatica chiamato **autograd** che semplifica questo processo.<sup>[[1]](#references)</sup>

### Spiegazione matematica della differenziazione automatica

**1. La regola della catena**

Al centro della differenziazione automatica si trova la **regola della catena** del calcolo differenziale. La regola della catena stabilisce che, se si ha una composizione di funzioni, la derivata della funzione composta è il prodotto delle derivate delle funzioni componenti.

### Implementazione della differenziazione automatica in PyTorch

Ora vediamo come PyTorch automatizza questo processo.
```python
pythonCopy codeimport torch
import torch.nn.functional as F

# Define input and target
x = torch.tensor([1.1])
y = torch.tensor([1.0])

# Initialize weights with requires_grad=True to track computations
w = torch.tensor([2.2], requires_grad=True)
b = torch.tensor([0.0], requires_grad=True)

# Forward pass
z = x * w + b
a = torch.sigmoid(z)
loss = F.binary_cross_entropy(a, y)

# Backward pass
loss.backward()

# Gradients
print("Gradient w.r.t w:", w.grad)
print("Gradient w.r.t b:", b.grad)
```

## Backpropagation nelle reti neurali più grandi

### **1.Estensione alle reti multilayer**

Nelle reti neurali più grandi con più layer, il processo di calcolo dei gradienti diventa più complesso a causa dell'aumento del numero di parametri e operazioni. Tuttavia, i principi fondamentali rimangono gli stessi:<sup>[[1]](#references)</sup>

- **Forward Pass:** Calcolare l'output della rete passando gli input attraverso ogni layer.
- **Calcolo della loss:** Valutare la funzione di loss utilizzando l'output della rete e le label target.
- **Backward Pass (Backpropagation):** Calcolare i gradienti della loss rispetto a ogni parametro della rete applicando ricorsivamente la chain rule dal layer di output fino al layer di input.

### **2. Algoritmo di Backpropagation**

- **Passaggio 1:** Inizializzare i parametri della rete (pesi e bias).
- **Passaggio 2:** Per ogni esempio di training, eseguire un forward pass per calcolare gli output.
- **Passaggio 3:** Calcolare la loss.
- **Passaggio 4:** Calcolare i gradienti della loss rispetto a ogni parametro utilizzando la chain rule.
- **Passaggio 5:** Aggiornare i parametri utilizzando un algoritmo di ottimizzazione (ad esempio, gradient descent).

### **4. Implementazione in PyTorch**

PyTorch semplifica questo processo con il suo motore autograd.
```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define a simple neural network
class SimpleNet(nn.Module):
def __init__(self):
super(SimpleNet, self).__init__()
self.fc1 = nn.Linear(10, 5)  # Input layer to hidden layer
self.relu = nn.ReLU()
self.fc2 = nn.Linear(5, 1)   # Hidden layer to output layer
self.sigmoid = nn.Sigmoid()

def forward(self, x):
h = self.relu(self.fc1(x))
y_hat = self.sigmoid(self.fc2(h))
return y_hat

# Instantiate the network
net = SimpleNet()

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.SGD(net.parameters(), lr=0.01)

# Sample data
inputs = torch.randn(1, 10)
labels = torch.tensor([1.0])

# Training loop
optimizer.zero_grad()          # Clear gradients
outputs = net(inputs)          # Forward pass
loss = criterion(outputs, labels)  # Compute loss
loss.backward()                # Backward pass (compute gradients)
optimizer.step()               # Update parameters

# Accessing gradients
for name, param in net.named_parameters():
if param.requires_grad:
print(f"Gradient of {name}: {param.grad}")
```
In questo codice:

- **Forward Pass:** calcola gli output della rete.
- **Backward Pass:** `loss.backward()` calcola i gradienti della loss rispetto a tutti i parametri.
- **Aggiornamento dei parametri:** `optimizer.step()` aggiorna i parametri in base ai gradienti calcolati.

### **5. Comprendere il Backward Pass**

Durante il backward pass:

- PyTorch attraversa il grafo computazionale in ordine inverso.
- Per ogni operazione, applica la regola della catena per calcolare i gradienti.
- I gradienti vengono accumulati nell'attributo `.grad` di ciascun tensore dei parametri.

### **6. Vantaggi della differenziazione automatica**

- **Efficienza:** evita calcoli ridondanti riutilizzando i risultati intermedi.
- **Precisione:** fornisce derivate esatte fino alla precisione macchina.
- **Semplicità d'uso:** elimina il calcolo manuale delle derivate.
