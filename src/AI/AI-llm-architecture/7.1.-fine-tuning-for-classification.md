# 7.1. 用于分类的微调

{{#include ../../banners/hacktricks-training.md}}

## 什么是

微调是指获取一个已经从海量数据中学习了**通用语言模式**的**预训练模型**，并对其进行**适配**，使其执行某项**特定任务**或理解特定领域的语言。这是通过在较小的、特定于任务的数据集上继续训练模型来实现的，使其能够调整参数，从而更好地适应新数据的细微特征，同时利用已经获得的广泛知识。微调使模型无需从头训练新模型，即可在专业应用中提供更准确、更相关的结果。

> [!TIP]
> 由于预训练一个能够“理解”文本的 LLM 成本非常高，因此对开源预训练模型进行微调，使其执行我们所需的特定任务，通常更加容易且成本更低。

> [!TIP]
> 本节的目标是展示如何对一个已经预训练的模型进行微调，使 LLM 不再生成新文本，而是选择给出**给定文本被归类到每个给定类别中的概率**（例如判断一段文本是否为垃圾邮件）。

## 准备数据集

### 数据集大小

当然，要微调模型，你需要一些结构化数据来专门化你的 LLM。在 [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch06/01_main-chapter-code/ch06.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch06/01_main-chapter-code/ch06.ipynb) 中给出的示例里，GPT2 使用 [https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip](https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip)_._ 中的数据来检测电子邮件是否为垃圾邮件。

该数据集包含的“非垃圾邮件”示例远多于“垃圾邮件”示例，因此书中建议**只使用与“垃圾邮件”示例数量相同的“非垃圾邮件”示例**（也就是从训练数据中移除所有多余的示例）。在本例中，每类有 747 个示例。<sup>[[1]](#references)</sup>

随后，数据集的 **70%** 用于**训练**，**10%** 用于**验证**，**20%** 用于**测试**。

- **验证集**在训练阶段用于微调模型的**超参数**并对模型架构作出决策，通过提供模型在未见数据上的表现反馈，有效帮助防止过拟合。它允许进行迭代改进，同时不会对最终评估造成偏差。
- 这意味着，尽管该数据集中的数据不会直接用于训练，但它们会被用于调整最佳**超参数**，因此不能像测试集那样使用此数据集来评估模型性能。
- 相比之下，**测试集**仅在模型完成全部训练且所有调整结束后使用；它能够无偏地评估模型对新的、未见数据的泛化能力。通过在测试集上进行最终评估，可以真实反映模型预计在实际应用中的表现。

### 条目长度

由于训练示例要求条目（本例中为电子邮件文本）具有相同长度，因此决定通过添加 `<|endoftext|>` 的 ids 作为填充，将每个条目扩展到与最长条目相同的大小。<sup>[[1]](#references)</sup>

### 初始化模型

使用开源预训练权重初始化要训练的模型。我们之前已经完成过此操作，按照 [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch06/01_main-chapter-code/ch06.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch06/01_main-chapter-code/ch06.ipynb) 中的说明即可轻松完成。

## 分类头

在这个具体示例中（预测文本是否为垃圾邮件），我们并不关心根据 GPT2 的完整词汇表进行微调，而只希望新模型判断电子邮件是否为垃圾邮件：是则为（1），否则为（0）。因此，我们将要**修改最终层**：将其从为词汇表中的每个 token 给出概率，修改为仅给出是垃圾邮件或不是垃圾邮件的概率（类似于包含 2 个单词的词汇表）。<sup>[[1]](#references)</sup>
```python
# This code modified the final layer with a Linear one with 2 outs
num_classes = 2
model.out_head = torch.nn.Linear(

in_features=BASE_CONFIG["emb_dim"],

out_features=num_classes
)
```
## 要调优的参数

为了快速进行 fine-tuning，最好不要调整所有参数，而只调整最后几层。这是因为已知较低层通常会捕获通用的基本语言结构和语义。因此，**通常只 fine-tuning 最后几层就足够了，而且速度更快**。<sup>[[1]](#references)</sup>
```python
# This code makes all the parameters of the model unrtainable
for param in model.parameters():
param.requires_grad = False

# Allow to fine tune the last layer in the transformer block
for param in model.trf_blocks[-1].parameters():
param.requires_grad = True

# Allow to fine tune the final layer norm
for param in model.final_norm.parameters():

param.requires_grad = True
```
## 用于训练的条目

在前面的章节中，LLM 通过降低每个预测 token 的 loss 进行训练，尽管几乎所有预测的 token 都已经存在于输入句子中（实际上只有末尾的 1 个 token 是真正预测出来的），以便模型更好地理解语言。

在本例中，我们只关心模型能否预测该模型是否为 spam，因此只关心最后一个预测的 token。因此，需要修改之前的训练 loss 函数，使其只考虑该 token。<sup>[[1]](#references)</sup>

这在 [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch06/01_main-chapter-code/ch06.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch06/01_main-chapter-code/ch06.ipynb) 中实现如下：
```python
def calc_accuracy_loader(data_loader, model, device, num_batches=None):
model.eval()
correct_predictions, num_examples = 0, 0

if num_batches is None:
num_batches = len(data_loader)
else:
num_batches = min(num_batches, len(data_loader))
for i, (input_batch, target_batch) in enumerate(data_loader):
if i < num_batches:
input_batch, target_batch = input_batch.to(device), target_batch.to(device)

with torch.no_grad():
logits = model(input_batch)[:, -1, :]  # Logits of last output token
predicted_labels = torch.argmax(logits, dim=-1)

num_examples += predicted_labels.shape[0]
correct_predictions += (predicted_labels == target_batch).sum().item()
else:
break
return correct_predictions / num_examples


def calc_loss_batch(input_batch, target_batch, model, device):
input_batch, target_batch = input_batch.to(device), target_batch.to(device)
logits = model(input_batch)[:, -1, :]  # Logits of last output token
loss = torch.nn.functional.cross_entropy(logits, target_batch)
return loss
```
请注意，对于每个 batch，我们只关注**预测的最后一个 token 的 logits**。
