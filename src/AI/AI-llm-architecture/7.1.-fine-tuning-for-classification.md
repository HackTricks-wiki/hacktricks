## Fine-Tuning ni Nini?

Fine-tuning ni mchakato wa kuchukua **pre-trained model** ambayo imejifunza **mifumo ya jumla ya lugha** kutoka kwa kiasi kikubwa cha data na **kuibadilisha** ili ifanye **kazi maalum** au ielewe lugha ya domain maalum. Hili hufikiwa kwa kuendelea ku-train model kwenye dataset ndogo inayolenga kazi maalum, na kuiwezesha kurekebisha parameters zake ili iendane vizuri na nuances za data mpya huku ikitumia maarifa mapana ambayo tayari imeyapata. Fine-tuning huiwezesha model kutoa matokeo sahihi na yanayohusiana zaidi katika matumizi maalum bila kuhitaji ku-train model mpya kutoka mwanzo.

> [!TIP]
> Ku-pre-train LLM ni ghali, hivyo kwa kawaida ni rahisi na nafuu zaidi kufanya fine-tune ya open-source pretrained model kwa ajili ya kazi maalum.

> [!TIP]
> Sehemu hii inaonyesha jinsi ya kufanya fine-tune ya pretrained model kwa ajili ya classification. Badala ya kuzalisha text mpya, model inarudisha **logits za categories zilizosanidiwa**, kama vile spam na not spam.<sup>[[1]](#references)[[2]](#references)</sup>

## Kuandaa data set

### Ukubwa wa data set

Bila shaka, ili kufanya fine-tune ya model unahitaji data iliyopangwa ya kutumia ili ku-specialise LLM yako. Katika mfano uliopendekezwa kwenye [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch06/01_main-chapter-code/ch06.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch06/01_main-chapter-code/ch06.ipynb), GPT2 inafanyiwa fine-tune ili kubaini ikiwa email ni spam au si spam kwa kutumia data kutoka [https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip](https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip)_._<sup>[[2]](#references)[[3]](#references)</sup>

Dataset hii ina mifano mingi zaidi ya "not spam" kuliko mifano ya "spam". Mfano huu unasawazisha classes kwa kubakiza idadi sawa kutoka kwa kila class: mifano 747 ya kila class.<sup>[[1]](#references)[[2]](#references)</sup>

Kisha mfano huu unatumia **70%** ya dataset iliyosawazishwa kwa ajili ya **training**, **10%** kwa ajili ya **validation**, na **20%** kwa ajili ya **testing**.<sup>[[2]](#references)</sup>

- **Validation set** hutumiwa wakati wa training ili kufanya fine-tune ya **hyperparameters** za model na kufanya maamuzi kuhusu architecture ya model, na hivyo kusaidia kuzuia overfitting kwa kutoa feedback kuhusu jinsi model inavyofanya kazi kwenye data ambayo haijaonekana. Huruhusu maboresho ya hatua kwa hatua bila kuathiri tathmini ya mwisho.
- Hii inamaanisha kwamba ingawa data iliyojumuishwa kwenye data set hii haitumiki moja kwa moja kwa training, hutumiwa kuweka **hyperparameters** bora, hivyo seti hii haiwezi kutumiwa kutathmini utendaji wa model kama testing set.
- Kinyume chake, **test set** hutumiwa **baada tu ya** model ku-trainiwa kikamilifu na marekebisho yote kukamilika; hutoa tathmini isiyo na upendeleo ya uwezo wa model wa ku-generalize kwenye data mpya ambayo haijaonekana. Tathmini hii ya mwisho kwenye test set hutoa picha halisi ya jinsi model inavyotarajiwa kufanya kazi katika matumizi ya ulimwengu halisi.

## Kichwa cha Classification

Kwa binary spam classification, model haihitaji tena output logits zenye ukubwa wa vocabulary. Badilisha output head ya mwisho na linear layer inayotoa class logits mbili: not spam (`0`) na spam (`1`).<sup>[[2]](#references)</sup>
```python
# Replace the final layer with a linear layer that has two outputs
num_classes = 2
model.out_head = torch.nn.Linear(
in_features=BASE_CONFIG["emb_dim"],
out_features=num_classes,
)
```
## Vigezo vya kurekebisha

Ili kupunguza gharama ya training katika mfano huu, freeze vigezo vingi vya model na fanya fine-tune kwenye transformer block ya mwisho pekee, layer ya mwisho ya normalization, na output head iliyoanzishwa upya. Hii hutumia tena representations za jumla zilizojifunzwa na layers za awali na hupunguza kwa kiasi kikubwa idadi ya vigezo vinavyoweza kufanyiwa training; kufungua layers zaidi kunaweza kuwezesha task adaptation kubwa zaidi, lakini kwa gharama ya juu ya compute na overfitting.<sup>[[1]](#references)[[2]](#references)</sup>
```python
# Freeze all existing model parameters
for param in model.parameters():
param.requires_grad = False

# Allow to fine tune the last layer in the transformer block
for param in model.trf_blocks[-1].parameters():
param.requires_grad = True

# Allow to fine tune the final layer norm
for param in model.final_norm.parameters():
param.requires_grad = True
```
## Maingizo ya kutumia kwa training

Katika sehemu zilizotangulia, pretraining ya language model ilikokotoa loss ya token inayofuata katika mfuatano mzima ili model iweze kujifunza muundo wa lugha.

Kwa sequence classification, mfano huu hutumia output ya model katika nafasi ya mwisho ya input kama representation inayopitishwa kwenye classification head. Loss hulinganisha class logits hizo mbili na label ya ujumbe; haitabiri ikiwa token ya mwisho yenyewe ni spam.<sup>[[2]](#references)</sup>

Hii imetekelezwa katika [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch06/01_main-chapter-code/ch06.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch06/01_main-chapter-code/ch06.ipynb) kama:<sup>[[2]](#references)</sup>
```python
def calc_accuracy_loader(data_loader, model, device, num_batches=None):
model.eval()
correct_predictions, num_examples = 0, 0

if num_batches is None:
num_batches = len(data_loader)
else:
num_batches = min(num_batches, len(data_loader))
for i, (input_batch, target_batch) in enumerate(data_loader):
if i < num_batches:
input_batch, target_batch = input_batch.to(device), target_batch.to(device)

with torch.no_grad():
logits = model(input_batch)[:, -1, :]  # Logits of last output token
predicted_labels = torch.argmax(logits, dim=-1)

num_examples += predicted_labels.shape[0]
correct_predictions += (predicted_labels == target_batch).sum().item()
else:
break
return correct_predictions / num_examples


def calc_loss_batch(input_batch, target_batch, model, device):
input_batch, target_batch = input_batch.to(device), target_batch.to(device)
logits = model(input_batch)[:, -1, :]  # Logits of last output token
loss = torch.nn.functional.cross_entropy(logits, target_batch)
return loss
```
Kwa kila batch, ni **class logits zilizo kwenye input position ya mwisho** pekee zinazotumika.
