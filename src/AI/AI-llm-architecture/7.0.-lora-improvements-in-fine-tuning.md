## Poboljšanja LoRA

> [!TIP]
> Korišćenje **LoRA značajno smanjuje računanje** potrebno za **fine-tune** već obučenih modela.

LoRA omogućava efikasan fine-tuning **velikih modela** tako što menja samo **mali deo** modela. Smanjuje broj parametara koje je potrebno obučavati, čime štedi **memoriju** i **računarske resurse**. Razlog za to je sledeći:<sup>[[1]](#references)</sup>

1. **Smanjuje broj parametara koji se obučavaju**: Umesto ažuriranja cele matrice težina u modelu, LoRA **deli** matricu težina na dve manje matrice (koje se nazivaju **A** i **B**). To čini obučavanje **bržim** i zahteva **manje memorije**, jer je potrebno ažurirati manje parametara.<sup>[[3]](#references)</sup>

1. To je zato što se, umesto izračunavanja potpunog ažuriranja težina sloja (matrice), ono aproksimira proizvodom 2 manje matrice, čime se smanjuje ažuriranje koje treba izračunati:\

2. **Zadržava nepromenjene težine originalnog modela**: LoRA omogućava da težine originalnog modela ostanu iste i ažurira samo **nove male matrice** (A i B). Ovo je korisno jer znači da se originalno znanje modela čuva i da se menja samo ono što je neophodno.
3. **Efikasan fine-tuning specifičan za zadatak**: Kada želite da prilagodite model **novom zadatku**, možete obučavati samo **male LoRA matrice** (A i B), dok ostatak modela ostaje nepromenjen. Ovo je **mnogo efikasnije** od ponovnog obučavanja celog modela.
4. **Efikasnost skladištenja**: Nakon fine-tuninga, umesto čuvanja **potpuno novog modela** za svaki zadatak, potrebno je čuvati samo **LoRA matrice**, koje su veoma male u poređenju sa celim modelom. To olakšava prilagođavanje modela mnogim zadacima bez korišćenja previše prostora za skladištenje.

Da bi se tokom fine-tuninga koristili LoraLayers umesto Linear slojeva, ovde je predložen ovaj kod [https://github.com/rasbt/LLMs-from-scratch/blob/main/appendix-E/01_main-chapter-code/appendix-E.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/appendix-E/01_main-chapter-code/appendix-E.ipynb):<sup>[[2]](#references)</sup>
```python
import math

# Create the LoRA layer with the 2 matrices and the alpha
class LoRALayer(torch.nn.Module):
def __init__(self, in_dim, out_dim, rank, alpha):
super().__init__()
self.A = torch.nn.Parameter(torch.empty(in_dim, rank))
torch.nn.init.kaiming_uniform_(self.A, a=math.sqrt(5))  # similar to standard weight initialization
self.B = torch.nn.Parameter(torch.zeros(rank, out_dim))
self.alpha = alpha

def forward(self, x):
x = self.alpha * (x @ self.A @ self.B)
return x

# Combine it with the linear layer
class LinearWithLoRA(torch.nn.Module):
def __init__(self, linear, rank, alpha):
super().__init__()
self.linear = linear
self.lora = LoRALayer(
linear.in_features, linear.out_features, rank, alpha
)

def forward(self, x):
return self.linear(x) + self.lora(x)

# Replace linear layers with LoRA ones
def replace_linear_with_lora(model, rank, alpha):
for name, module in model.named_children():
if isinstance(module, torch.nn.Linear):
# Replace the Linear layer with LinearWithLoRA
setattr(model, name, LinearWithLoRA(module, rank, alpha))
else:
# Recursively apply the same function to child modules
replace_linear_with_lora(module, rank, alpha)
```
