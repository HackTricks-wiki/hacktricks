## LoRA 개선

> [!TIP]
> **LoRA를 사용하면** 이미 학습된 모델을 **fine-tune**하는 데 필요한 **계산량을 크게 줄일 수 있습니다**.

LoRA를 사용하면 모델의 **작은 부분**만 변경하여 **large models**를 효율적으로 fine-tune할 수 있습니다. 학습해야 하는 파라미터 수를 줄여 **메모리**와 **계산 리소스**를 절약합니다. 그 이유는 다음과 같습니다:<sup>[[1]](#references)</sup>

1. **학습 가능한 파라미터 수 감소**: 모델의 전체 weight matrix를 업데이트하는 대신, LoRA는 weight matrix를 두 개의 더 작은 matrix(**A**와 **B**)로 **분할**합니다. 업데이트해야 하는 파라미터가 더 적기 때문에 학습이 **더 빠르고** **메모리를 덜 사용합니다**.<sup>[[3]](#references)</sup>

1. 이는 layer(matrix)의 전체 weight update를 계산하는 대신, 이를 더 작은 matrix 2개의 곱으로 근사하여 계산해야 할 update를 줄이기 때문입니다:\

<figure><img src="../../images/image (9) (1).png" alt=""><figcaption></figcaption></figure>

2. **기존 모델 weight를 변경하지 않음**: LoRA를 사용하면 기존 모델 weight를 그대로 유지하고, **새로운 작은 matrix**(A와 B)만 업데이트할 수 있습니다. 이는 모델의 기존 지식이 보존되고 필요한 부분만 조정할 수 있다는 점에서 유용합니다.
3. **효율적인 task-specific fine-tuning**: 모델을 **새로운 task**에 맞게 조정하려는 경우, 모델의 나머지 부분은 그대로 둔 채 **작은 LoRA matrix**(A와 B)만 학습하면 됩니다. 이는 모델 전체를 다시 학습하는 것보다 **훨씬 효율적입니다**.
4. **Storage 효율성**: fine-tuning 후 각 task마다 **전체 새 모델**을 저장하는 대신, 전체 모델에 비해 매우 작은 **LoRA matrix**만 저장하면 됩니다. 따라서 storage를 과도하게 사용하지 않고도 모델을 여러 task에 맞게 더 쉽게 조정할 수 있습니다.

fine-tuning 중 Linear 대신 LoraLayers를 구현하기 위해 다음 코드가 제안되어 있습니다 [https://github.com/rasbt/LLMs-from-scratch/blob/main/appendix-E/01_main-chapter-code/appendix-E.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/appendix-E/01_main-chapter-code/appendix-E.ipynb):<sup>[[2]](#references)</sup>
```python
import math

# Create the LoRA layer with the 2 matrices and the alpha
class LoRALayer(torch.nn.Module):
def __init__(self, in_dim, out_dim, rank, alpha):
super().__init__()
self.A = torch.nn.Parameter(torch.empty(in_dim, rank))
torch.nn.init.kaiming_uniform_(self.A, a=math.sqrt(5))  # similar to standard weight initialization
self.B = torch.nn.Parameter(torch.zeros(rank, out_dim))
self.alpha = alpha

def forward(self, x):
x = self.alpha * (x @ self.A @ self.B)
return x

# Combine it with the linear layer
class LinearWithLoRA(torch.nn.Module):
def __init__(self, linear, rank, alpha):
super().__init__()
self.linear = linear
self.lora = LoRALayer(
linear.in_features, linear.out_features, rank, alpha
)

def forward(self, x):
return self.linear(x) + self.lora(x)

# Replace linear layers with LoRA ones
def replace_linear_with_lora(model, rank, alpha):
for name, module in model.named_children():
if isinstance(module, torch.nn.Linear):
# Replace the Linear layer with LinearWithLoRA
setattr(model, name, LinearWithLoRA(module, rank, alpha))
else:
# Recursively apply the same function to child modules
replace_linear_with_lora(module, rank, alpha)
```
