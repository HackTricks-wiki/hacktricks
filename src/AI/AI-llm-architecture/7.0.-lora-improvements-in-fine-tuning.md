## LoRA 改进

> [!TIP]
> 使用 **LoRA 可以大幅减少** 对已训练模型进行 **fine tune** 所需的计算量。

LoRA 通过仅修改模型的**一小部分**，使高效地对**大型模型**进行微调成为可能。它减少了需要训练的参数数量，从而节省**内存**和**计算资源**。原因如下：<sup>[[1]](#references)</sup>

1. **减少可训练参数的数量**：LoRA 不会更新模型中的整个权重矩阵，而是将权重矩阵**拆分**为两个较小的矩阵（称为 **A** 和 **B**）。由于需要更新的参数更少，这使训练**更快**，并且需要**更少的内存**。<sup>[[3]](#references)</sup>

1. 这是因为，它不再计算某一层（矩阵）的完整权重更新，而是将其近似为两个较小矩阵的乘积，从而减少需要计算的更新量：\

<figure><img src="../../images/image (9) (1).png" alt=""><figcaption></figcaption></figure>

2. **保持原始模型权重不变**：LoRA 允许保持原始模型权重不变，只更新**新的小型矩阵**（A 和 B）。这很有帮助，因为这意味着模型原有的知识得以保留，而你只需调整必要的部分。
3. **高效地进行特定任务微调**：当你希望让模型适应**新任务**时，只需训练**较小的 LoRA 矩阵**（A 和 B），而保持模型的其余部分不变。这比重新训练整个模型**高效得多**。
4. **存储效率**：微调完成后，无需为每个任务保存一个**完整的新模型**，只需存储**LoRA 矩阵**即可。与整个模型相比，这些矩阵非常小，因此可以在不占用过多存储空间的情况下，更轻松地让模型适应多个任务。

为了在 fine tuning 期间使用 LoraLayers 代替 Linear，这里提供了以下代码 [https://github.com/rasbt/LLMs-from-scratch/blob/main/appendix-E/01_main-chapter-code/appendix-E.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/appendix-E/01_main-chapter-code/appendix-E.ipynb)：<sup>[[2]](#references)</sup>
```python
import math

# Create the LoRA layer with the 2 matrices and the alpha
class LoRALayer(torch.nn.Module):
def __init__(self, in_dim, out_dim, rank, alpha):
super().__init__()
self.A = torch.nn.Parameter(torch.empty(in_dim, rank))
torch.nn.init.kaiming_uniform_(self.A, a=math.sqrt(5))  # similar to standard weight initialization
self.B = torch.nn.Parameter(torch.zeros(rank, out_dim))
self.alpha = alpha

def forward(self, x):
x = self.alpha * (x @ self.A @ self.B)
return x

# Combine it with the linear layer
class LinearWithLoRA(torch.nn.Module):
def __init__(self, linear, rank, alpha):
super().__init__()
self.linear = linear
self.lora = LoRALayer(
linear.in_features, linear.out_features, rank, alpha
)

def forward(self, x):
return self.linear(x) + self.lora(x)

# Replace linear layers with LoRA ones
def replace_linear_with_lora(model, rank, alpha):
for name, module in model.named_children():
if isinstance(module, torch.nn.Linear):
# Replace the Linear layer with LinearWithLoRA
setattr(model, name, LinearWithLoRA(module, rank, alpha))
else:
# Recursively apply the same function to child modules
replace_linear_with_lora(module, rank, alpha)
```
