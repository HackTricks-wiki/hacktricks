## LoRA 改进

> [!TIP]
> LoRA 可以显著减少对预训练模型进行 fine-tuning 所需的可训练参数数量和 optimizer memory。

LoRA 通过只更改模型的**一小部分**，使得对**大型模型**进行高效 fine-tuning 成为可能。它减少了需要训练的参数数量，从而节省**内存**和**计算资源**。这是因为：<sup>[[1]](#references)</sup>

1. **减少可训练参数的数量**：LoRA 冻结原始权重 `W`，并将 additive update 表示为两个可训练 low-rank 矩阵的乘积，通常为 `ΔW = B A`，其中 rank `r` 远小于输入/输出维度。<sup>[[3]](#references)</sup>

1. 这是因为，它不再计算某一层（矩阵）的完整权重更新，而是将其近似为两个更小矩阵的乘积，从而减少需要计算的更新量：\

<figure><img src="../../images/image (9) (1).png" alt=""><figcaption></figcaption></figure>

2. **保持原始模型权重不变**：只有 adapter 矩阵会被优化。冻结权重可以防止直接修改基础 checkpoint，但在 inference 时，adapter 的行为仍可能覆盖或削弱模型已有的知识。
3. **高效的特定任务 Fine-Tuning**：当你希望让模型适应**新任务**时，只需训练**较小的 LoRA 矩阵**（A 和 B），而让模型的其余部分保持不变。这比重新训练整个模型要**高效得多**。
4. **存储效率**：完成 fine-tuning 后，无需为每个任务保存一个**完整的新模型**，只需存储与整个模型相比非常小的 **LoRA 矩阵**即可。这样可以在不占用过多存储空间的情况下，更容易地让模型适应多个任务。

以下最小实现改编自所引用的 notebook。它将 `B` 初始化为零，使 adapter 从 no-op 状态开始，并使用 LoRA 中标准的 `alpha / rank` scaling。代码以 input-major shapes 存储这些 factors（`A` 为 `in_dim x rank`，`B` 为 `rank x out_dim`），因此其 forward path 写作 `xAB`；这等价于论文中 `BA` 表示法的转置形状版本。<sup>[[2]](#references)[[3]](#references)</sup>
```python
import math
import torch

# Create the LoRA layer with the 2 matrices and the alpha
class LoRALayer(torch.nn.Module):
def __init__(self, in_dim, out_dim, rank, alpha):
super().__init__()
self.A = torch.nn.Parameter(torch.empty(in_dim, rank))
torch.nn.init.kaiming_uniform_(self.A, a=math.sqrt(5))  # similar to standard weight initialization
self.B = torch.nn.Parameter(torch.zeros(rank, out_dim))
self.scaling = alpha / rank

def forward(self, x):
x = self.scaling * (x @ self.A @ self.B)
return x

# Combine it with the linear layer
class LinearWithLoRA(torch.nn.Module):
def __init__(self, linear, rank, alpha):
super().__init__()
self.linear = linear
self.lora = LoRALayer(
linear.in_features, linear.out_features, rank, alpha
)

def forward(self, x):
return self.linear(x) + self.lora(x)

# Replace linear layers with LoRA ones
def replace_linear_with_lora(model, rank, alpha):
for name, module in model.named_children():
if isinstance(module, torch.nn.Linear):
# Replace the Linear layer with LinearWithLoRA
setattr(model, name, LinearWithLoRA(module, rank, alpha))
else:
# Recursively apply the same function to child modules
replace_linear_with_lora(module, rank, alpha)
```
