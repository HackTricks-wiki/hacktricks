## LoRAの改善

> [!TIP]
> **LoRAを使用すると、**すでにトレーニングされたモデルを**fine tune**するために必要な**計算量を大幅に削減できます**。

LoRAを使用すると、モデルの**小さな部分**だけを変更することで、**大規模モデル**を効率的にfine-tuningできます。トレーニングが必要なパラメータ数を削減し、**メモリ**と**計算リソース**を節約できます。これは、次の理由によるものです。<sup>[[1]](#references)</sup>

1. **トレーニング可能なパラメータ数を削減**: モデル内の重み行列全体を更新する代わりに、LoRAは重み行列を2つの小さな行列（**A**と**B**）に**分割**します。これにより、更新が必要なパラメータが少なくなるため、トレーニングが**高速**になり、必要な**メモリも少なく**なります。<sup>[[3]](#references)</sup>

1. これは、レイヤー（行列）の完全な重み更新を計算する代わりに、2つの小さな行列の積として近似することで、計算する更新量を削減できるためです:\

<figure><img src="../../images/image (9) (1).png" alt=""><figcaption></figcaption></figure>

2. **元のモデルの重みを変更しない**: LoRAでは、元のモデルの重みをそのまま維持し、**新しい小さな行列**（AとB）のみを更新できます。これにより、モデルが持つ元の知識を保持し、必要な部分だけを調整できます。
3. **タスクに特化した効率的なfine-tuning**: モデルを**新しいタスク**に適応させたい場合、モデルの残りの部分をそのままにして、**小さなLoRA行列**（AとB）だけをトレーニングできます。これは、モデル全体を再トレーニングするよりも**はるかに効率的**です。
4. **ストレージ効率**: fine-tuning後は、タスクごとに**モデル全体**を新しく保存する代わりに、モデル全体と比較して非常に小さい**LoRA行列**だけを保存すれば済みます。これにより、ストレージを使いすぎることなく、モデルを多くのタスクに適応させやすくなります。

fine-tuning中にLinearレイヤーの代わりにLoraLayersを実装するには、次のコードが提案されています [https://github.com/rasbt/LLMs-from-scratch/blob/main/appendix-E/01_main-chapter-code/appendix-E.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/appendix-E/01_main-chapter-code/appendix-E.ipynb):<sup>[[2]](#references)</sup>
```python
import math

# Create the LoRA layer with the 2 matrices and the alpha
class LoRALayer(torch.nn.Module):
def __init__(self, in_dim, out_dim, rank, alpha):
super().__init__()
self.A = torch.nn.Parameter(torch.empty(in_dim, rank))
torch.nn.init.kaiming_uniform_(self.A, a=math.sqrt(5))  # similar to standard weight initialization
self.B = torch.nn.Parameter(torch.zeros(rank, out_dim))
self.alpha = alpha

def forward(self, x):
x = self.alpha * (x @ self.A @ self.B)
return x

# Combine it with the linear layer
class LinearWithLoRA(torch.nn.Module):
def __init__(self, linear, rank, alpha):
super().__init__()
self.linear = linear
self.lora = LoRALayer(
linear.in_features, linear.out_features, rank, alpha
)

def forward(self, x):
return self.linear(x) + self.lora(x)

# Replace linear layers with LoRA ones
def replace_linear_with_lora(model, rank, alpha):
for name, module in model.named_children():
if isinstance(module, torch.nn.Linear):
# Replace the Linear layer with LinearWithLoRA
setattr(model, name, LinearWithLoRA(module, rank, alpha))
else:
# Recursively apply the same function to child modules
replace_linear_with_lora(module, rank, alpha)
```
