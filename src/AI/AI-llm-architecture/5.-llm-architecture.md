1. **Girdi (Token'lara Ayrılmış Metin)**: Süreç, sayısal gösterimlere dönüştürülen token'lara ayrılmış metinle başlar.
2. **Token Embedding ve Positional Embedding Katmanı**: Token'lara ayrılmış metin, bir **token embedding** katmanından ve bir dizideki token'ların konumunu yakalayan, kelime sırasını anlamak için kritik olan bir **positional embedding** katmanından geçirilir.
3. **Transformer Blokları**: Model, her biri birden fazla katmana sahip **12 transformer bloğu** içerir. Bu bloklarda aşağıdaki sıra tekrarlanır:
- **Masked Multi-Head Attention**: Modelin aynı anda giriş metninin farklı bölümlerine odaklanmasını sağlar.
- **Layer Normalization**: Training'i stabilize etmek ve iyileştirmek için kullanılan bir normalizasyon adımıdır.
- **Feed Forward Layer**: Attention katmanındaki bilgileri işlemekten ve bir sonraki token hakkında tahminlerde bulunmaktan sorumludur.
- **Dropout Layers**: Bu katmanlar, training sırasında birimleri rastgele devre dışı bırakarak overfitting'i önler.
4. **Final Output Layer**: Model, **50.257** değerinin vocabulary boyutunu temsil ettiği **4x50.257 boyutlu bir tensor** çıktısı üretir. Bu tensor'deki her satır, modelin dizideki bir sonraki kelimeyi tahmin etmek için kullandığı bir vektöre karşılık gelir.
5. **Amaç**: Amaç, bu embedding'leri alıp tekrar metne dönüştürmektir. Özellikle çıktının son satırı, bu diyagramda "forward" olarak gösterilen bir sonraki kelimeyi oluşturmak için kullanılır.

### Code representation
```python
import torch
import torch.nn as nn
import tiktoken

class GELU(nn.Module):
def __init__(self):
super().__init__()

def forward(self, x):
return 0.5 * x * (1 + torch.tanh(
torch.sqrt(torch.tensor(2.0 / torch.pi)) *
(x + 0.044715 * torch.pow(x, 3))
))

class FeedForward(nn.Module):
def __init__(self, cfg):
super().__init__()
self.layers = nn.Sequential(
nn.Linear(cfg["emb_dim"], 4 * cfg["emb_dim"]),
GELU(),
nn.Linear(4 * cfg["emb_dim"], cfg["emb_dim"]),
)

def forward(self, x):
return self.layers(x)

class MultiHeadAttention(nn.Module):
def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
super().__init__()
assert d_out % num_heads == 0, "d_out must be divisible by num_heads"

self.d_out = d_out
self.num_heads = num_heads
self.head_dim = d_out // num_heads # Reduce the projection dim to match desired output dim

self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_key = nn.Linear(d_in, d_out, bias=qkv_bias)
self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
self.out_proj = nn.Linear(d_out, d_out)  # Linear layer to combine head outputs
self.dropout = nn.Dropout(dropout)
self.register_buffer('mask', torch.triu(torch.ones(context_length, context_length), diagonal=1))

def forward(self, x):
b, num_tokens, d_in = x.shape

keys = self.W_key(x) # Shape: (b, num_tokens, d_out)
queries = self.W_query(x)
values = self.W_value(x)

# We implicitly split the matrix by adding a `num_heads` dimension
# Unroll last dim: (b, num_tokens, d_out) -> (b, num_tokens, num_heads, head_dim)
keys = keys.view(b, num_tokens, self.num_heads, self.head_dim)
values = values.view(b, num_tokens, self.num_heads, self.head_dim)
queries = queries.view(b, num_tokens, self.num_heads, self.head_dim)

# Transpose: (b, num_tokens, num_heads, head_dim) -> (b, num_heads, num_tokens, head_dim)
keys = keys.transpose(1, 2)
queries = queries.transpose(1, 2)
values = values.transpose(1, 2)

# Compute scaled dot-product attention (aka self-attention) with a causal mask
attn_scores = queries @ keys.transpose(2, 3)  # Dot product for each head

# Original mask truncated to the number of tokens and converted to boolean
mask_bool = self.mask.bool()[:num_tokens, :num_tokens]

# Use the mask to fill attention scores
attn_scores.masked_fill_(mask_bool, -torch.inf)

attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)
attn_weights = self.dropout(attn_weights)

# Shape: (b, num_tokens, num_heads, head_dim)
context_vec = (attn_weights @ values).transpose(1, 2)

# Combine heads, where self.d_out = self.num_heads * self.head_dim
context_vec = context_vec.contiguous().view(b, num_tokens, self.d_out)
context_vec = self.out_proj(context_vec) # optional projection

return context_vec

class LayerNorm(nn.Module):
def __init__(self, emb_dim):
super().__init__()
self.eps = 1e-5
self.scale = nn.Parameter(torch.ones(emb_dim))
self.shift = nn.Parameter(torch.zeros(emb_dim))

def forward(self, x):
mean = x.mean(dim=-1, keepdim=True)
var = x.var(dim=-1, keepdim=True, unbiased=False)
norm_x = (x - mean) / torch.sqrt(var + self.eps)
return self.scale * norm_x + self.shift

class TransformerBlock(nn.Module):
def __init__(self, cfg):
super().__init__()
self.att = MultiHeadAttention(
d_in=cfg["emb_dim"],
d_out=cfg["emb_dim"],
context_length=cfg["context_length"],
num_heads=cfg["n_heads"],
dropout=cfg["drop_rate"],
qkv_bias=cfg["qkv_bias"])
self.ff = FeedForward(cfg)
self.norm1 = LayerNorm(cfg["emb_dim"])
self.norm2 = LayerNorm(cfg["emb_dim"])
self.drop_shortcut = nn.Dropout(cfg["drop_rate"])

def forward(self, x):
# Shortcut connection for attention block
shortcut = x
x = self.norm1(x)
x = self.att(x)  # Shape [batch_size, num_tokens, emb_size]
x = self.drop_shortcut(x)
x = x + shortcut  # Add the original input back

# Shortcut connection for feed forward block
shortcut = x
x = self.norm2(x)
x = self.ff(x)
x = self.drop_shortcut(x)
x = x + shortcut  # Add the original input back

return x


class GPTModel(nn.Module):
def __init__(self, cfg):
super().__init__()
self.tok_emb = nn.Embedding(cfg["vocab_size"], cfg["emb_dim"])
self.pos_emb = nn.Embedding(cfg["context_length"], cfg["emb_dim"])
self.drop_emb = nn.Dropout(cfg["drop_rate"])

self.trf_blocks = nn.Sequential(
*[TransformerBlock(cfg) for _ in range(cfg["n_layers"])])

self.final_norm = LayerNorm(cfg["emb_dim"])
self.out_head = nn.Linear(
cfg["emb_dim"], cfg["vocab_size"], bias=False
)

def forward(self, in_idx):
batch_size, seq_len = in_idx.shape
tok_embeds = self.tok_emb(in_idx)
pos_embeds = self.pos_emb(torch.arange(seq_len, device=in_idx.device))
x = tok_embeds + pos_embeds  # Shape [batch_size, num_tokens, emb_size]
x = self.drop_emb(x)
x = self.trf_blocks(x)
x = self.final_norm(x)
logits = self.out_head(x)
return logits

GPT_CONFIG_124M = {
"vocab_size": 50257,    # Vocabulary size

"n_heads": 12,          # Number of attention heads
"n_layers": 12,         # Number of layers
"drop_rate": 0.1,       # Dropout rate
"qkv_bias": False       # Query-Key-Value bias
}

torch.manual_seed(123)
model = GPTModel(GPT_CONFIG_124M)
out = model(batch)
print("Input batch:\n", batch)
print("\nOutput shape:", out.shape)
print(out)
```

```python
# From https://github.com/rasbt/LLMs-from-scratch/tree/main/ch04
class FeedForward(nn.Module):
def __init__(self, cfg):
super().__init__()
self.layers = nn.Sequential(
nn.Linear(cfg["emb_dim"], 4 * cfg["emb_dim"]),
GELU(),
nn.Linear(4 * cfg["emb_dim"], cfg["emb_dim"]),
)

def forward(self, x):
# x shape: (batch_size, seq_len, emb_dim)

x = self.layers[0](x)# x shape: (batch_size, seq_len, 4 * emb_dim)
x = self.layers[1](x) # x shape remains: (batch_size, seq_len, 4 * emb_dim)
x = self.layers[2](x) # x shape: (batch_size, seq_len, emb_dim)
return x  # Output shape: (batch_size, seq_len, emb_dim)
```
#### **Amaç ve İşlevsellik**

- **Position-wise FeedForward Network:** Her konuma ayrı ayrı ve aynı şekilde iki katmanlı, fully connected bir network uygular.
- **Katman Ayrıntıları:**
- **First Linear Layer:** Boyutluluğu `emb_dim` değerinden `4 * emb_dim` değerine genişletir.
- **GELU Activation:** Doğrusal olmayanlık uygular.
- **Second Linear Layer:** Boyutluluğu tekrar `emb_dim` değerine düşürür.

> [!TIP]
> Gördüğünüz gibi, Feed Forward network 3 katman kullanır. İlki, model içinde eğitilecek parametreler olan linear weights kullanarak boyutları 4 ile çarpan bir linear layer'dır. Ardından, daha zengin temsilleri yakalamak için doğrusal olmayan değişimler uygulamak üzere tüm bu boyutlarda GELU function kullanılır ve son olarak boyutları başlangıçtaki boyut sayısına döndürmek için başka bir linear layer kullanılır.

### **Multi-Head Attention Mechanism**

Bu konu daha önceki bir bölümde açıklanmıştı.

#### **Amaç ve İşlevsellik**

- **Multi-Head Self-Attention:** Modelin bir token'ı encode ederken input sequence içindeki farklı konumlara odaklanmasını sağlar.
- **Key Components:**
- **Queries, Keys, Values:** Attention scores hesaplamak için kullanılan input'un linear projections'larıdır.
- **Heads:** Her biri daha düşük bir boyuta (`head_dim`) sahip olan ve paralel çalışan birden fazla attention mechanism (`num_heads`).
- **Attention Scores:** Queries ve keys'in dot product işlemiyle hesaplanır, ölçeklendirilir ve maskelenir.
- **Masking:** Modelin gelecekteki token'lara attention uygulamasını önlemek için causal mask uygulanır (GPT gibi autoregressive modeller için önemlidir).
- **Attention Weights:** Maskelenmiş ve ölçeklendirilmiş attention scores değerlerinin Softmax sonucudur.
- **Context Vector:** Attention weights değerlerine göre values'ın weighted sum'ıdır.
- **Output Projection:** Tüm heads çıktısını birleştiren linear layer'dır.

> [!TIP]
> Bu network'ün amacı, aynı context içindeki token'lar arasındaki ilişkileri bulmaktır. Ayrıca, overfitting'i önlemek için token'lar farklı heads'e ayrılır; ancak her head tarafından bulunan nihai ilişkiler bu network'ün sonunda birleştirilir.
>
> Ayrıca training sırasında, belirli bir token'a ait ilişkiler incelenirken daha sonraki token'ların hesaba katılmaması için bir **causal mask** uygulanır ve **overfitting'i önlemek** için bazı **dropout** işlemleri de gerçekleştirilir.

### **Layer** Normalization
```python
# From https://github.com/rasbt/LLMs-from-scratch/tree/main/ch04
class LayerNorm(nn.Module):
def __init__(self, emb_dim):
super().__init__()
self.eps = 1e-5 # Prevent division by zero during normalization.
self.scale = nn.Parameter(torch.ones(emb_dim))
self.shift = nn.Parameter(torch.zeros(emb_dim))

def forward(self, x):
mean = x.mean(dim=-1, keepdim=True)
var = x.var(dim=-1, keepdim=True, unbiased=False)
norm_x = (x - mean) / torch.sqrt(var + self.eps)
return self.scale * norm_x + self.shift
```
#### **Amaç ve İşlevsellik**

- **Layer Normalization:** Bir batch içindeki her bir örnek için girdileri özellikler (embedding boyutları) boyunca normalize etmek amacıyla kullanılan bir tekniktir.
- **Bileşenler:**
- **`eps`:** Normalizasyon sırasında sıfıra bölmeyi önlemek için varyansa eklenen küçük bir sabit (`1e-5`).
- **`scale` ve `shift`:** Modelin normalize edilmiş çıktıyı ölçeklendirmesine ve kaydırmasına olanak tanıyan öğrenilebilir parametrelerdir (`nn.Parameter`). Sırasıyla birler ve sıfırlar olarak başlatılırlar.
- **Normalizasyon Süreci:**
- **Ortalamanın Hesaplanması (`mean`):** Girdinin `x` embedding boyutu (`dim=-1`) üzerindeki ortalamasını hesaplar ve broadcasting için boyutu korur (`keepdim=True`).
- **Varyansın Hesaplanması (`var`):** `x` değerinin embedding boyutu üzerindeki varyansını hesaplar ve boyutu korur. `unbiased=False` parametresi, varyansın yanlı tahmin edici kullanılarak (`N-1` yerine `N` değerine bölünerek) hesaplanmasını sağlar. Bu, örnekler yerine özellikler üzerinde normalizasyon yapılırken uygundur.
- **Normalize Etme (`norm_x`):** Ortalamayı `x` değerinden çıkarır ve varyans artı `eps` değerinin kareköküne böler.
- **Ölçeklendirme ve Kaydırma:** Öğrenilebilir `scale` ve `shift` parametrelerini normalize edilmiş çıktıya uygular.

> [!TIP]
> Amaç, aynı token'ın tüm boyutları boyunca ortalamanın 0 ve varyansın 1 olmasını sağlamaktır. Bunun amacı, eğitim sırasında parametrelerin güncellenmesi nedeniyle ağ aktivasyonlarının dağılımında meydana gelen değişimleri ifade eden internal covariate shift'i azaltarak **derin neural network'lerin eğitimini stabilize etmektir**.

### **Transformer Bloğu**

_Matrislerin şekillerini daha iyi anlamak için yorum olarak şekiller eklenmiştir:_
```python
# From https://github.com/rasbt/LLMs-from-scratch/tree/main/ch04

class TransformerBlock(nn.Module):
def __init__(self, cfg):
super().__init__()
self.att = MultiHeadAttention(
d_in=cfg["emb_dim"],
d_out=cfg["emb_dim"],
context_length=cfg["context_length"],
num_heads=cfg["n_heads"],
dropout=cfg["drop_rate"],
qkv_bias=cfg["qkv_bias"]
)
self.ff = FeedForward(cfg)
self.norm1 = LayerNorm(cfg["emb_dim"])
self.norm2 = LayerNorm(cfg["emb_dim"])
self.drop_shortcut = nn.Dropout(cfg["drop_rate"])

def forward(self, x):
# x shape: (batch_size, seq_len, emb_dim)

# Shortcut connection for attention block
shortcut = x  # shape: (batch_size, seq_len, emb_dim)
x = self.norm1(x)  # shape remains (batch_size, seq_len, emb_dim)
x = self.att(x)    # shape: (batch_size, seq_len, emb_dim)
x = self.drop_shortcut(x)  # shape remains (batch_size, seq_len, emb_dim)
x = x + shortcut   # shape: (batch_size, seq_len, emb_dim)

# Shortcut connection for feedforward block
shortcut = x       # shape: (batch_size, seq_len, emb_dim)
x = self.norm2(x)  # shape remains (batch_size, seq_len, emb_dim)
x = self.ff(x)     # shape: (batch_size, seq_len, emb_dim)
x = self.drop_shortcut(x)  # shape remains (batch_size, seq_len, emb_dim)
x = x + shortcut   # shape: (batch_size, seq_len, emb_dim)

return x  # Output shape: (batch_size, seq_len, emb_dim)

```
#### **Amaç ve İşlevsellik**

- **Katmanların Birleştirilmesi:** Multi-head attention, feedforward network, layer normalization ve residual connections bileşenlerini birleştirir.
- **Layer Normalization:** Stable training sağlamak için attention ve feedforward katmanlarından önce uygulanır.
- **Residual Connections (Shortcuts):** Gradient flow'u iyileştirmek ve deep networks eğitimini mümkün kılmak için bir katmanın input'unu output'una ekler.
- **Dropout:** Regularization amacıyla attention ve feedforward katmanlarından sonra uygulanır.

#### **Adım Adım İşlevsellik**

1. **İlk Residual Path (Self-Attention):**
- **Input (`shortcut`):** Residual connection için original input'u kaydeder.
- **Layer Norm (`norm1`):** Input'u normalize eder.
- **Multi-Head Attention (`att`):** Self-attention uygular.
- **Dropout (`drop_shortcut`):** Regularization için dropout uygular.
- **Residual Ekleme (`x + shortcut`):** Original input ile birleştirir.
2. **İkinci Residual Path (FeedForward):**
- **Input (`shortcut`):** Sonraki residual connection için güncellenmiş input'u kaydeder.
- **Layer Norm (`norm2`):** Input'u normalize eder.
- **FeedForward Network (`ff`):** Feedforward dönüşümünü uygular.
- **Dropout (`drop_shortcut`):** Dropout uygular.
- **Residual Ekleme (`x + shortcut`):** İlk residual path'ten gelen input ile birleştirir.

> [!TIP]
> Transformer block, tüm network'leri bir araya getirir ve training stability ile sonuçları iyileştirmek için bazı **normalization** ve **dropouts** uygular.\
> Her network'ün kullanımından sonra dropouts uygulandığına, normalization'ın ise önce uygulandığına dikkat edin.
>
> Ayrıca, bir network'ün output'unu input'una **eklemekten** oluşan shortcuts kullanır. Bu, initial layers'ın last ones kadar "fazla" katkıda bulunmasını sağlayarak vanishing gradient problemini önlemeye yardımcı olur.

### **GPTModel**

_Matrix'lerin shapes'lerini daha iyi anlamak için comments olarak eklendi:_
```python
# From https://github.com/rasbt/LLMs-from-scratch/tree/main/ch04
class GPTModel(nn.Module):
def __init__(self, cfg):
super().__init__()
self.tok_emb = nn.Embedding(cfg["vocab_size"], cfg["emb_dim"])
# shape: (vocab_size, emb_dim)

self.pos_emb = nn.Embedding(cfg["context_length"], cfg["emb_dim"])
# shape: (context_length, emb_dim)

self.drop_emb = nn.Dropout(cfg["drop_rate"])

self.trf_blocks = nn.Sequential(
*[TransformerBlock(cfg) for _ in range(cfg["n_layers"])]
)
# Stack of TransformerBlocks

self.final_norm = LayerNorm(cfg["emb_dim"])
self.out_head = nn.Linear(cfg["emb_dim"], cfg["vocab_size"], bias=False)
# shape: (emb_dim, vocab_size)

def forward(self, in_idx):
# in_idx shape: (batch_size, seq_len)
batch_size, seq_len = in_idx.shape

# Token embeddings
tok_embeds = self.tok_emb(in_idx)
# shape: (batch_size, seq_len, emb_dim)

# Positional embeddings
pos_indices = torch.arange(seq_len, device=in_idx.device)
# shape: (seq_len,)
pos_embeds = self.pos_emb(pos_indices)
# shape: (seq_len, emb_dim)

# Add token and positional embeddings
x = tok_embeds + pos_embeds  # Broadcasting over batch dimension
# x shape: (batch_size, seq_len, emb_dim)

x = self.drop_emb(x)  # Dropout applied
# x shape remains: (batch_size, seq_len, emb_dim)

x = self.trf_blocks(x)  # Pass through Transformer blocks
# x shape remains: (batch_size, seq_len, emb_dim)

x = self.final_norm(x)  # Final LayerNorm
# x shape remains: (batch_size, seq_len, emb_dim)

logits = self.out_head(x)  # Project to vocabulary size
# logits shape: (batch_size, seq_len, vocab_size)

return logits  # Output shape: (batch_size, seq_len, vocab_size)
```
#### **Amaç ve İşlevsellik**

- **Embedding Katmanları:**
- **Token Embeddings (`tok_emb`):** Token indekslerini embedding'lere dönüştürür. Hatırlatma olarak, bunlar vocabulary'deki her token'ın her boyutuna verilen ağırlıklardır.
- **Positional Embeddings (`pos_emb`):** Token'ların sırasını yakalamak için embedding'lere konumsal bilgi ekler. Hatırlatma olarak, bunlar metindeki konumuna göre token'a verilen ağırlıklardır.
- **Dropout (`drop_emb`):** Regularisation amacıyla embedding'lere uygulanır.
- **Transformer Blocks (`trf_blocks`):** Embedding'leri işlemek için `n_layers` adet transformer block'tan oluşan yığın.
- **Final Normalization (`final_norm`):** Output layer'dan önce uygulanan layer normalization.
- **Output Layer (`out_head`):** Tahmin için logits üretmek üzere final hidden state'leri vocabulary boyutuna projekte eder.

> [!TIP]
> Bu class'ın amacı, belirtilen diğer tüm network'leri kullanarak **bir sequence içindeki bir sonraki token'ı tahmin etmektir**; bu, text generation gibi görevler için temeldir.
>
> **Belirtilen sayıda transformer block kullanacağına** ve her transformer block'un bir multi-head attestation net, bir feed forward net ve birkaç normalization kullandığına dikkat edin. Yani 12 transformer block kullanılıyorsa bunu 12 ile çarpın.
>
> Ayrıca, **output'tan önce** bir **normalization** layer eklenir ve sonuçları doğru boyutlarda elde etmek için en sonda bir final linear layer uygulanır. Her final vector'ün kullanılan vocabulary boyutunda olduğuna dikkat edin. Bunun nedeni, vocabulary içindeki her olası token için bir olasılık elde etmeye çalışmasıdır.

## Metin Oluşturma

Bir önceki gibi sonraki token'ı tahmin eden bir model olduğunda, çıktının yalnızca son token değerlerini almak yeterlidir (bunlar tahmin edilen token'a ait olacaktır); bu değerler **vocabulary'deki her öğe için bir değer** şeklinde olur. Ardından boyutları toplamı 1 olan olasılıklara normalize etmek için `softmax` işlevi kullanılır ve sonrasında en büyük öğenin indeksi alınır; bu indeks, vocabulary içindeki kelimenin indeksidir.

Kod: [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch04/01_main-chapter-code/ch04.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch04/01_main-chapter-code/ch04.ipynb):<sup>[[1]](#references)</sup>
```python
def generate_text_simple(model, idx, max_new_tokens, context_size):
# idx is (batch, n_tokens) array of indices in the current context
for _ in range(max_new_tokens):

# Crop current context if it exceeds the supported context size
# E.g., if LLM supports only 5 tokens, and the context size is 10
# then only the last 5 tokens are used as context
idx_cond = idx[:, -context_size:]

# Get the predictions
with torch.no_grad():
logits = model(idx_cond)

# Focus only on the last time step
# (batch, n_tokens, vocab_size) becomes (batch, vocab_size)
logits = logits[:, -1, :]

# Apply softmax to get probabilities
probas = torch.softmax(logits, dim=-1)  # (batch, vocab_size)

# Get the idx of the vocab entry with the highest probability value
idx_next = torch.argmax(probas, dim=-1, keepdim=True)  # (batch, 1)

# Append sampled index to the running sequence
idx = torch.cat((idx, idx_next), dim=1)  # (batch, n_tokens+1)

return idx


start_context = "Hello, I am"

encoded = tokenizer.encode(start_context)
print("encoded:", encoded)

encoded_tensor = torch.tensor(encoded).unsqueeze(0)
print("encoded_tensor.shape:", encoded_tensor.shape)

model.eval() # disable dropout

out = generate_text_simple(
model=model,
idx=encoded_tensor,
max_new_tokens=6,
context_size=GPT_CONFIG_124M["context_length"]
)

print("Output:", out)
print("Output length:", len(out[0]))
```
