## Token Embeddings

Μετά το tokenizing των δεδομένων κειμένου, το επόμενο κρίσιμο βήμα στην προετοιμασία δεδομένων για την εκπαίδευση μεγάλων γλωσσικών μοντέλων (LLMs), όπως το GPT, είναι η δημιουργία **token embeddings**. Τα token embeddings μετατρέπουν τα διακριτά tokens (όπως λέξεις ή υπολέξεις) σε συνεχείς αριθμητικά διανύσματα, τα οποία το μοντέλο μπορεί να επεξεργαστεί και από τα οποία μπορεί να μάθει. Αυτή η εξήγηση αναλύει τα token embeddings, την αρχικοποίησή τους, τη χρήση τους και τον ρόλο των positional embeddings στη βελτίωση της κατανόησης ακολουθιών tokens από το μοντέλο.<sup>[[1]](#references)</sup>

> [!TIP]
> Ο στόχος αυτής της τρίτης φάσης είναι πολύ απλός: **Να αντιστοιχιστεί σε κάθε προηγούμενο token του λεξιλογίου ένα διάνυσμα των επιθυμητών διαστάσεων, ώστε να εκπαιδευτεί το μοντέλο.** Κάθε λέξη του λεξιλογίου θα είναι ένα σημείο σε έναν χώρο X διαστάσεων.\
> Σημειώστε ότι αρχικά η θέση κάθε λέξης στον χώρο αρχικοποιείται απλώς «τυχαία» και αυτές οι θέσεις είναι trainable parameters (θα βελτιωθούν κατά την εκπαίδευση).
>
> Επιπλέον, κατά τη διαδικασία του token embedding **δημιουργείται ένα ακόμη layer embeddings**, το οποίο αναπαριστά (σε αυτήν την περίπτωση) την **απόλυτη θέση της λέξης στην πρόταση εκπαίδευσης**. Έτσι, μια λέξη σε διαφορετικές θέσεις της πρότασης θα έχει διαφορετική αναπαράσταση (σημασία).

### **Τι είναι τα Token Embeddings;**

Τα **Token Embeddings** είναι αριθμητικές αναπαραστάσεις των tokens σε έναν συνεχή διανυσματικό χώρο. Κάθε token του λεξιλογίου συσχετίζεται με ένα μοναδικό διάνυσμα σταθερών διαστάσεων. Αυτά τα διανύσματα αποτυπώνουν σημασιολογικές και συντακτικές πληροφορίες σχετικά με τα tokens, επιτρέποντας στο μοντέλο να κατανοεί σχέσεις και μοτίβα στα δεδομένα.

- **Μέγεθος λεξιλογίου:** Ο συνολικός αριθμός μοναδικών tokens (π.χ. λέξεων, υπολέξεων) στο λεξιλόγιο του μοντέλου.
- **Διαστάσεις embedding:** Ο αριθμός των αριθμητικών τιμών (διαστάσεων) στο διάνυσμα κάθε token. Οι περισσότερες διαστάσεις μπορούν να αποτυπώσουν πιο λεπτομερείς πληροφορίες, αλλά απαιτούν περισσότερους υπολογιστικούς πόρους.

**Παράδειγμα:**

- **Μέγεθος λεξιλογίου:** 6 tokens \[1, 2, 3, 4, 5, 6]
- **Διαστάσεις embedding:** 3 (x, y, z)

### **Αρχικοποίηση των Token Embeddings**

Στην αρχή της εκπαίδευσης, τα token embeddings αρχικοποιούνται συνήθως με μικρές τυχαίες τιμές. Αυτές οι αρχικές τιμές προσαρμόζονται (fine-tuned) κατά την εκπαίδευση, ώστε να αναπαριστούν καλύτερα τις σημασίες των tokens με βάση τα δεδομένα εκπαίδευσης.

**Παράδειγμα PyTorch:**
```python
import torch

# Set a random seed for reproducibility
torch.manual_seed(123)

# Create an embedding layer with 6 tokens and 3 dimensions
embedding_layer = torch.nn.Embedding(6, 3)

# Display the initial weights (embeddings)
print(embedding_layer.weight)
```

### **Πώς λειτουργούν τα Token Embeddings κατά το Training**

Κατά τη διάρκεια του training, κάθε token στα input δεδομένα μετατρέπεται στο αντίστοιχο embedding vector του. Αυτά τα διανύσματα χρησιμοποιούνται στη συνέχεια σε διάφορους υπολογισμούς μέσα στο μοντέλο, όπως mechanisms attention και neural network layers.

**Παράδειγμα:**

- **Batch Size:** 8 (αριθμός των samples που υποβάλλονται σε επεξεργασία ταυτόχρονα)
- **Max Sequence Length:** 4 (αριθμός των tokens ανά sample)
- **Embedding Dimensions:** 256

**Δομή δεδομένων:**

- Κάθε batch αναπαρίσταται από ένα 3D tensor με shape `(batch_size, max_length, embedding_dim)`.
- Για το παράδειγμά μας, το shape θα ήταν `(8, 4, 256)`.

**Οπτικοποίηση:**

- Το μοντέλο επεξεργάζεται αυτά τα embeddings για να μάθει γλωσσικά μοτίβα και να παράγει προβλέψεις.

## **Positional Embeddings: Προσθήκη context στα Token Embeddings**

Ενώ τα token embeddings αποτυπώνουν το νόημα μεμονωμένων tokens, δεν κωδικοποιούν εγγενώς τη θέση των tokens μέσα σε μια sequence. Η κατανόηση της σειράς των tokens είναι κρίσιμη για τη γλωσσική κατανόηση. Εδώ έρχονται να παίξουν ρόλο τα **positional embeddings**.

### **Γιατί χρειάζονται τα Positional Embeddings:**

- **Η σειρά των Tokens έχει σημασία:** Στις προτάσεις, το νόημα συχνά εξαρτάται από τη σειρά των λέξεων. Για παράδειγμα, "The cat sat on the mat" έναντι του "The mat sat on the cat."
- **Περιορισμός των Embeddings:** Χωρίς πληροφορίες θέσης, το μοντέλο αντιμετωπίζει τα tokens ως "bag of words", αγνοώντας τη sequence τους.

### **Τύποι Positional Embeddings:**

1. **Absolute Positional Embeddings:**
- Αντιστοιχίζουν ένα μοναδικό position vector σε κάθε θέση της sequence.
- **Παράδειγμα:** Το πρώτο token σε οποιαδήποτε sequence έχει το ίδιο positional embedding, το δεύτερο token έχει ένα άλλο και ούτω καθεξής.
- **Χρησιμοποιούνται από:** Τα GPT models της OpenAI.
2. **Relative Positional Embeddings:**
- Κωδικοποιούν τη σχετική απόσταση μεταξύ των tokens αντί για τις απόλυτες θέσεις τους.
- **Παράδειγμα:** Δείχνουν πόσο απέχουν μεταξύ τους δύο tokens, ανεξάρτητα από τις απόλυτες θέσεις τους στη sequence.
- **Χρησιμοποιούνται από:** Models όπως τα Transformer-XL και ορισμένες παραλλαγές του BERT.

### **Πώς ενσωματώνονται τα Positional Embeddings:**

- **Ίδιες διαστάσεις:** Τα positional embeddings έχουν την ίδια dimensionality με τα token embeddings.
- **Πρόσθεση:** Προστίθενται στα token embeddings, συνδυάζοντας την ταυτότητα του token με τις πληροφορίες θέσης χωρίς να αυξάνουν τη συνολική dimensionality.

**Παράδειγμα πρόσθεσης Positional Embeddings:**

Ας υποθέσουμε ότι ένα token embedding vector είναι το `[0.5, -0.2, 0.1]` και το positional embedding vector του είναι το `[0.1, 0.3, -0.1]`. Το συνδυασμένο embedding που χρησιμοποιείται από το μοντέλο θα είναι:
```css
Combined Embedding = Token Embedding + Positional Embedding
= [0.5 + 0.1, -0.2 + 0.3, 0.1 + (-0.1)]
= [0.6, 0.1, 0.0]
```
**Οφέλη των Positional Embeddings:**

- **Επίγνωση Συμφραζομένων:** Το μοντέλο μπορεί να διακρίνει μεταξύ tokens με βάση τις θέσεις τους.
- **Κατανόηση Ακολουθιών:** Επιτρέπει στο μοντέλο να κατανοεί τη γραμματική, τη σύνταξη και τις σημασίες που εξαρτώνται από τα συμφραζόμενα.

## **Positional Embeddings στα Σύγχρονα LLMs**

### **Rotary Positional Embeddings (RoPE)**

Το RoPE κωδικοποιεί τη θέση εφαρμόζοντας μια περιστροφή που εξαρτάται από τη θέση σε ζεύγη διαστάσεων των query/key vectors, μετατρέποντας τις απόλυτες θέσεις σε σχετικές διαφορές φάσης. Αυτό παρέχει πληροφορίες σχετικής θέσης, διατηρώντας παράλληλα αμετάβλητη τη dimensionality των embeddings, και χρησιμοποιείται ευρέως σε πρόσφατα decoder-only LLMs.<sup>[[2]](#references)</sup>

Για τον τρόπο με τον οποίο συνδυάζονται τα token και positional embeddings στο εσωτερικό του μοντέλου, δείτε [τη σελίδα για την αρχιτεκτονική των LLMs](5.-llm-architecture.md).

### **Επέκταση των Context Windows σε Μοντέλα που Βασίζονται στο RoPE**

Πρόσφατη έρευνα δείχνει ότι το μήκος των συμφραζομένων περιορίζεται συχνά από το positional encoding scheme και όχι από το ίδιο το token embedding matrix.

- **Position Interpolation (PI):** Επανακλιμακώνει τους δείκτες θέσης, ώστε οι μεγαλύτερες ακολουθίες να αντιστοιχούν στο εύρος που χρησιμοποιήθηκε κατά την εκπαίδευση, επιτρέποντας την επέκταση με ελάχιστο fine-tuning.<sup>[[3]](#references)</sup> Παράδειγμα:
```python
# Position Interpolation (PI) intuition
orig_ctx = 2048
new_ctx = 8192
scaled_pos = pos * (orig_ctx / new_ctx)
```
- **YaRN:** Μια compute-efficient στρατηγική επέκτασης του RoPE που τροποποιεί το scaling/interpolation του RoPE, ώστε να κάνει extrapolation σε μεγαλύτερα context με λιγότερα επιπλέον training steps.<sup>[[4]](#references)</sup>

## Παράδειγμα Κώδικα

Ακολουθεί το παράδειγμα κώδικα από το [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch02/01_main-chapter-code/ch02.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch02/01_main-chapter-code/ch02.ipynb):<sup>[[5]](#references)</sup>
```python
# Use previous code...

# Create token embeddings
"""
BPE uses a vocabulary of 50257 words
Let's supose we want to use 256 dimensions (instead of the millions used by LLMs)
"""

vocab_size = 50257
output_dim = 256
token_embedding_layer = torch.nn.Embedding(vocab_size, output_dim)

## Generate the dataloader like before
max_length = 4
dataloader = create_dataloader_v1(
raw_text, batch_size=8, max_length=max_length,
stride=max_length, shuffle=False
)
data_iter = iter(dataloader)
inputs, targets = next(data_iter)

# Apply embeddings
token_embeddings = token_embedding_layer(inputs)
print(token_embeddings.shape)
torch.Size([8, 4, 256]) # 8 x 4 x 256

# Generate absolute embeddings
context_length = max_length
pos_embedding_layer = torch.nn.Embedding(context_length, output_dim)

pos_embeddings = pos_embedding_layer(torch.arange(max_length))

input_embeddings = token_embeddings + pos_embeddings
print(input_embeddings.shape) # torch.Size([8, 4, 256])
```
