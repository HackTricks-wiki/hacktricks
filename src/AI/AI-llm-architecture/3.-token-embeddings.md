## Token Embeddings

Text data को tokenize करने के बाद, GPT जैसे large language models (LLMs) के लिए data तैयार करने का अगला महत्वपूर्ण चरण **token embeddings** बनाना है। Token embeddings discrete tokens (जैसे words या subwords) को continuous numerical vectors में बदलते हैं, जिन्हें model process और learn कर सकता है। यह विवरण token embeddings, उनके initialization, उपयोग और token sequences की model understanding को बेहतर बनाने में positional embeddings की भूमिका को समझाता है।<sup>[[1]](#references)</sup>

> [!TIP]
> इस तीसरे phase का लक्ष्य बहुत सरल है: **vocabulary में मौजूद प्रत्येक token को model को train करने के लिए इच्छित dimensions का एक vector देना।** Vocabulary का प्रत्येक word X dimensions वाले space में एक point होगा।\
> ध्यान दें कि शुरुआत में space में प्रत्येक word की position केवल "randomly" initialize की जाती है और ये positions trainable parameters होती हैं (training के दौरान इनमें सुधार किया जाएगा)।
>
> इसके अलावा, token embedding के दौरान **embeddings की एक और layer बनाई जाती है**, जो (इस मामले में) training sentence में **word की absolute position** को दर्शाती है। इस तरह sentence में अलग-अलग positions पर मौजूद word का representation (meaning) अलग होगा।

### **Token Embeddings क्या हैं?**

**Token Embeddings**, continuous vector space में tokens के numerical representations होते हैं। Vocabulary में प्रत्येक token एक निश्चित dimensions वाले unique vector से जुड़ा होता है। ये vectors tokens से संबंधित semantic और syntactic information को capture करते हैं, जिससे model data में relationships और patterns को समझ पाता है।

- **Vocabulary Size:** Model की vocabulary में unique tokens (जैसे words, subwords) की कुल संख्या।
- **Embedding Dimensions:** प्रत्येक token के vector में numerical values (dimensions) की संख्या। अधिक dimensions अधिक सूक्ष्म information को capture कर सकती हैं, लेकिन इनके लिए अधिक computational resources की आवश्यकता होती है।

**उदाहरण:**

- **Vocabulary Size:** 6 tokens \[1, 2, 3, 4, 5, 6]
- **Embedding Dimensions:** 3 (x, y, z)

### **Token Embeddings को Initialize करना**

Training की शुरुआत में token embeddings को आमतौर पर छोटी random values के साथ initialize किया जाता है। Training के दौरान इन initial values को adjust (fine-tune) किया जाता है, ताकि वे training data के आधार पर tokens के meanings को बेहतर ढंग से represent कर सकें।

**PyTorch Example:**
```python
import torch

# Set a random seed for reproducibility
torch.manual_seed(123)

# Create an embedding layer with 6 tokens and 3 dimensions
embedding_layer = torch.nn.Embedding(6, 3)

# Display the initial weights (embeddings)
print(embedding_layer.weight)
```

### **Training के दौरान Token Embeddings कैसे काम करते हैं**

Training के दौरान, input data में मौजूद प्रत्येक token को उसके corresponding embedding vector में convert किया जाता है। फिर इन vectors का उपयोग model के भीतर विभिन्न computations में किया जाता है, जैसे attention mechanisms और neural network layers।

**उदाहरण:**

- **Batch Size:** 8 (एक साथ process किए जाने वाले samples की संख्या)
- **Max Sequence Length:** 4 (प्रत्येक sample में tokens की संख्या)
- **Embedding Dimensions:** 256

**Data Structure:**

- प्रत्येक batch को `(batch_size, max_length, embedding_dim)` shape वाले 3D tensor के रूप में represent किया जाता है।
- हमारे example के लिए, shape `(8, 4, 256)` होगी।

## **Positional Embeddings: Token Embeddings में Context जोड़ना**

जहाँ token embeddings अलग-अलग tokens का अर्थ capture करती हैं, वहीं वे sequence में tokens की position को स्वाभाविक रूप से encode नहीं करतीं। Language comprehension के लिए tokens के order को समझना महत्वपूर्ण है। यहीं **positional embeddings** उपयोगी होती हैं।

### **Positional Embeddings की आवश्यकता क्यों है:**

- **Token Order Matters:** Sentences में meaning अक्सर words के order पर निर्भर करता है। उदाहरण के लिए, "The cat sat on the mat" बनाम "The mat sat on the cat."
- **Embedding Limitation:** Positional information के बिना, model tokens को "bag of words" की तरह treat करता है और उनके sequence को ignore करता है।

### **Positional Embeddings के प्रकार:**

1. **Absolute Positional Embeddings:**
- Sequence में प्रत्येक position को एक unique position vector assign करता है।
- **Example:** किसी भी sequence में पहला token समान positional embedding रखता है, दूसरे token की positional embedding अलग होती है, और इसी तरह आगे।
- **Used By:** OpenAI’s GPT models।
2. **Relative Positional Embeddings:**
- Tokens की absolute positions के बजाय उनके बीच की relative distance को encode करता है।
- **Example:** यह बताता है कि sequence में दो tokens एक-दूसरे से कितनी दूरी पर हैं, चाहे उनकी absolute positions कुछ भी हों।
- **Used By:** Transformer-XL जैसे models और BERT के कुछ variants।

### **Positional Embeddings को कैसे Integrated किया जाता है:**

- **Same Dimensions:** Positional embeddings की dimensionality token embeddings के समान होती है।
- **Addition:** इन्हें token embeddings में add किया जाता है, जिससे overall dimensionality बढ़ाए बिना token identity और positional information combine हो जाती है।

**Positional Embeddings जोड़ने का Example:**

मान लें कि token embedding vector `[0.5, -0.2, 0.1]` है और इसका positional embedding vector `[0.1, 0.3, -0.1]` है। Model द्वारा उपयोग किया जाने वाला combined embedding होगा:
```css
Combined Embedding = Token Embedding + Positional Embedding
= [0.5 + 0.1, -0.2 + 0.3, 0.1 + (-0.1)]
= [0.6, 0.1, 0.0]
```
**Positional Embeddings के लाभ:**

- **Contextual Awareness:** मॉडल tokens के बीच उनकी positions के आधार पर अंतर कर सकता है।
- **Sequence Understanding:** मॉडल को grammar, syntax और context-dependent meanings समझने में सक्षम बनाता है।

## **Modern LLMs में Positional Embeddings**

### **Rotary Positional Embeddings (RoPE)**

RoPE, query/key vectors में dimensions के pairs पर position-dependent rotation लागू करके position को encode करता है, जिससे absolute positions relative phase differences में बदल जाते हैं। यह embedding dimensionality को अपरिवर्तित रखते हुए relative position information प्रदान करता है और हाल के decoder-only LLMs में व्यापक रूप से उपयोग किया जाता है।<sup>[[2]](#references)</sup>

मॉडल के अंदर token और positional embeddings को कैसे combine किया जाता है, इसके लिए [LLM architecture page](5.-llm-architecture.md) देखें।

### **RoPE-Based Models में Context Windows को बढ़ाना**

हाल के कार्यों से पता चलता है कि context length अक्सर token embedding matrix के बजाय positional encoding scheme द्वारा सीमित होती है।

- **Position Interpolation (PI):** Position indices को rescale करता है ताकि लंबी sequences training के दौरान देखी गई range में map हो जाएँ, जिससे minimal fine-tuning के साथ विस्तार संभव होता है।<sup>[[3]](#references)</sup> उदाहरण:
```python
# Position Interpolation (PI) intuition
orig_ctx = 2048
new_ctx = 8192
scaled_pos = pos * (orig_ctx / new_ctx)
```
- **YaRN:** एक compute-efficient RoPE extension strategy, जो RoPE scaling/interpolation को संशोधित करके कम अतिरिक्त training steps के साथ लंबे contexts तक extrapolate करती है।<sup>[[4]](#references)</sup>

## Code Example

[https://github.com/rasbt/LLMs-from-scratch/blob/main/ch02/01_main-chapter-code/ch02.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch02/01_main-chapter-code/ch02.ipynb) के code example को आगे देखते हैं:<sup>[[5]](#references)</sup>
```python
# Use previous code...

# Create token embeddings
"""
BPE uses a vocabulary of 50257 words
Let's supose we want to use 256 dimensions (instead of the millions used by LLMs)
"""

vocab_size = 50257
output_dim = 256
token_embedding_layer = torch.nn.Embedding(vocab_size, output_dim)

## Generate the dataloader like before
max_length = 4
dataloader = create_dataloader_v1(
raw_text, batch_size=8, max_length=max_length,
stride=max_length, shuffle=False
)
data_iter = iter(dataloader)
inputs, targets = next(data_iter)

# Apply embeddings
token_embeddings = token_embedding_layer(inputs)
print(token_embeddings.shape)
torch.Size([8, 4, 256]) # 8 x 4 x 256

# Generate absolute embeddings
context_length = max_length
pos_embedding_layer = torch.nn.Embedding(context_length, output_dim)

pos_embeddings = pos_embedding_layer(torch.arange(max_length))

input_embeddings = token_embeddings + pos_embeddings
print(input_embeddings.shape) # torch.Size([8, 4, 256])
```
