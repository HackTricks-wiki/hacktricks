## Vektorska ugrađivanja tokena

Nakon tokenizacije tekstualnih podataka, sledeći ključni korak u pripremi podataka za obuku velikih jezičkih modela (LLM-ova), kao što je GPT, jeste kreiranje **vektorskih ugrađivanja tokena**. Vektorska ugrađivanja tokena pretvaraju diskretne tokene (kao što su reči ili podreči) u neprekidne numeričke vektore koje model može da obrađuje i iz kojih može da uči. Ovo objašnjenje raščlanjuje vektorska ugrađivanja tokena, njihovu inicijalizaciju i upotrebu, kao i ulogu pozicionih ugrađivanja u boljem razumevanju nizova tokena.<sup>[[1]](#references)</sup>

> [!TIP]
> Cilj ove treće faze je veoma jednostavan: **Dodeliti svakom prethodnom tokenu u rečniku vektor željenih dimenzija za obuku modela.** Svaka reč u rečniku biće tačka u prostoru od X dimenzija.\
> Imajte na umu da je u početku položaj svake reči u prostoru samo inicijalizovan „nasumično“, a ti položaji su parametri koji se mogu obučavati (poboljšavaju se tokom obuke).
>
> Pored toga, tokom vektorskog ugrađivanja tokena **kreira se još jedan sloj ugrađivanja** koji predstavlja (u ovom slučaju) **apsolutni položaj reči u rečenici za obuku**. Tako će reč na različitim mestima u rečenici imati različitu reprezentaciju (značenje).

### **Šta su vektorska ugrađivanja tokena?**

**Vektorska ugrađivanja tokena** su numeričke reprezentacije tokena u neprekidnom vektorskom prostoru. Svakom tokenu u rečniku dodeljen je jedinstveni vektor fiksnih dimenzija. Ovi vektori obuhvataju semantičke i sintaksičke informacije o tokenima, što modelu omogućava da razume odnose i obrasce u podacima.

- **Veličina rečnika:** Ukupan broj jedinstvenih tokena (npr. reči, podreči) u rečniku modela.
- **Dimenzije ugrađivanja:** Broj numeričkih vrednosti (dimenzija) u vektoru svakog tokena. Veći broj dimenzija može da obuhvati nijansiranije informacije, ali zahteva više računarskih resursa.

**Primer:**

- **Veličina rečnika:** 6 tokena \[1, 2, 3, 4, 5, 6]
- **Dimenzije ugrađivanja:** 3 (x, y, z)

### **Inicijalizacija vektorskih ugrađivanja tokena**

Na početku obuke, vektorska ugrađivanja tokena obično se inicijalizuju malim nasumičnim vrednostima. Ove početne vrednosti se prilagođavaju (fino podešavaju) tokom obuke kako bi bolje predstavljale značenja tokena na osnovu podataka za obuku.

**Primer u PyTorch-u:**

```python
import torch

# Set a random seed for reproducibility
torch.manual_seed(123)

# Create an embedding layer with 6 tokens and 3 dimensions
embedding_layer = torch.nn.Embedding(6, 3)

# Display the initial weights (embeddings)
print(embedding_layer.weight)
```

**Izlaz:**

**Objašnjenje:**

- Svaka kolona predstavlja dimenziju u embedding vektoru.
- Na primer, token na indeksu `3` ima embedding vektor `[-0.4015, 0.9666, -1.1481]`.

**Pristupanje embeddingu tokena:**

```python
# Retrieve the embedding for the token at index 3
token_index = torch.tensor([3])
print(embedding_layer(token_index))
```

**Tumačenje:**

- Token na indeksu `3` predstavljen je vektorom `[-0.4015, 0.9666, -1.1481]`.
- Ove vrednosti su parametri koji se mogu trenirati i koje će model prilagođavati tokom treniranja kako bi bolje predstavio kontekst i značenje tokena.

### **Kako funkcionišu embedding-i tokena tokom treniranja**

Tokom treniranja, svaki token u ulaznim podacima pretvara se u odgovarajući embedding vektor. Ti vektori se zatim koriste u različitim proračunima unutar modela, kao što su mehanizmi pažnje i slojevi neuronske mreže.

**Primer:**

- **Veličina batch-a:** 8 (broj uzoraka koji se obrađuju istovremeno)
- **Maksimalna dužina sekvence:** 4 (broj tokena po uzorku)
- **Dimenzije embedding-a:** 256

**Struktura podataka:**

- Svaki batch predstavljen je 3D tenzorom oblika `(batch_size, max_length, embedding_dim)`.
- U našem primeru, oblik bi bio `(8, 4, 256)`.

**Vizualizacija:**

## **Pozicioni embeddingi: dodavanje konteksta embeddingima tokena**

Embeddingi tokena obuhvataju značenje pojedinačnih tokena, ali ne kodiraju sami po sebi položaj tokena u nizu. Razumevanje redosleda tokena ključno je za razumevanje jezika. Tu na scenu stupaju **pozicioni embeddingi**.

### **Zašto su potrebni pozicioni embeddingi:**

- **Redosled tokena je važan:** U rečenicama značenje često zavisi od redosleda reči. Na primer, „Mačka je sedela na prostirci“ naspram „Prostirka je sedela na mački.“
- **Ograničenje embeddinga:** Bez pozicionih informacija, model tretira tokene kao „vreću reči“, zanemarujući njihov redosled.

### **Vrste pozicionih embeddinga:**

1. **Apsolutni pozicioni embeddingi:**
   - Svakom položaju u nizu dodeljuju jedinstveni pozicioni vektor.
   - **Primer:** Prvi token u svakom nizu ima isti pozicioni embedding, drugi token ima drugi, i tako dalje.
   - **Koriste ih:** OpenAI-jevi GPT modeli.
2. **Relativni pozicioni embeddingi:**
   - Kodiraju relativnu udaljenost između tokena, a ne njihove apsolutne položaje.
   - **Primer:** Označavaju koliko su dva tokena udaljena jedan od drugog, bez obzira na njihove apsolutne položaje u nizu.
   - **Koriste ih:** Modeli poput Transformer-XL-a i neke varijante modela BERT.

### **Kako se integrišu pozicioni embeddingi:**

- **Iste dimenzije:** Pozicioni embeddingi imaju istu dimenzionalnost kao embeddingi tokena.
- **Sabiranje:** Dodaju se embeddingima tokena, čime se identitet tokena kombinuje s pozicionim informacijama bez povećanja ukupne dimenzionalnosti.

**Primer sabiranja pozicionih embeddinga:**

Pretpostavimo da je embedding vektor tokena `[0.5, -0.2, 0.1]`, a njegov pozicioni embedding vektor `[0.1, 0.3, -0.1]`. Kombinovani embedding koji model koristi bio bi:

```css
Combined Embedding = Token Embedding + Positional Embedding
                   = [0.5 + 0.1, -0.2 + 0.3, 0.1 + (-0.1)]
                   = [0.6, 0.1, 0.0]
```

**Prednosti pozicionih embeddinga:**

- **Kontekstualna svest:** Model može da razlikuje tokene na osnovu njihovih pozicija.
- **Razumevanje sekvence:** Omogućava modelu da razume gramatiku, sintaksu i značenja koja zavise od konteksta.

## **Pozicioni embeddingi u modernim LLM-ovima**

### **Rotacioni pozicioni embeddingi (RoPE)**

RoPE kodira poziciju primenom rotacije koja zavisi od pozicije na parove dimenzija u query/key vektorima, pretvarajući apsolutne pozicije u relativne fazne razlike. Time pruža informacije o relativnim pozicijama bez promene dimenzionalnosti embeddinga i široko se koristi u novijim LLM-ovima koji koriste samo decoder.<sup>[[2]](#references)</sup>

Više o tome kako se token i pozicioni embeddingi kombinuju unutar modela potražite na [stranici o arhitekturi LLM-a](5.-llm-architecture.md).

### **Proširivanje kontekstualnih prozora u modelima zasnovanim na RoPE-u**

Novija istraživanja pokazuju da je dužina konteksta često ograničena šemom pozicionog kodiranja, a ne samom matricom token embeddinga.

- **Position Interpolation (PI):** Skalira indekse pozicija tako da se duže sekvence preslikavaju u opseg viđen tokom treniranja, čime omogućava proširenje uz minimalno fino podešavanje.<sup>[[3]](#references)</sup> Primer:

```python
# Position Interpolation (PI) intuition
orig_ctx = 2048
new_ctx = 8192
scaled_pos = pos * (orig_ctx / new_ctx)
```

- **YaRN:** Računarski efikasna strategija za proširenje RoPE-a koja menja skaliranje/interpolaciju RoPE-a kako bi omogućila ekstrapolaciju na duže kontekste uz manje dodatnih koraka obuke.<sup>[[4]](#references)</sup>

```python
# Use previous code...

# Create token embeddings
"""
BPE uses a vocabulary of 50257 words
Let's supose we want to use 256 dimensions (instead of the millions used by LLMs)
"""

vocab_size = 50257
output_dim = 256
token_embedding_layer = torch.nn.Embedding(vocab_size, output_dim)

## Generate the dataloader like before
max_length = 4
dataloader = create_dataloader_v1(
    raw_text, batch_size=8, max_length=max_length,
    stride=max_length, shuffle=False
)
data_iter = iter(dataloader)
inputs, targets = next(data_iter)

# Apply embeddings
token_embeddings = token_embedding_layer(inputs)
print(token_embeddings.shape)
torch.Size([8, 4, 256]) # 8 x 4 x 256

# Generate absolute embeddings
context_length = max_length
pos_embedding_layer = torch.nn.Embedding(context_length, output_dim)

pos_embeddings = pos_embedding_layer(torch.arange(max_length))

input_embeddings = token_embeddings + pos_embeddings
print(input_embeddings.shape) # torch.Size([8, 4, 256])
```
