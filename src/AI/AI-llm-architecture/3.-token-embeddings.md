## Embedding za Tokeni

Baada ya kutengeneza tokeni za data ya maandishi, hatua muhimu inayofuata katika kuandaa data ya kufundishia large language models (LLMs) kama GPT ni kuunda **embedding za tokeni**. Embedding za tokeni hubadilisha tokeni zisizo endelevu (kama maneno au vipande vya maneno) kuwa vekta za nambari endelevu ambazo modeli inaweza kuchakata na kujifunza kutoka kwazo. Maelezo haya yanafafanua embedding za tokeni, uanzishaji wake, matumizi yake, na jukumu la embedding za nafasi katika kuboresha uelewa wa modeli kuhusu mfuatano wa tokeni.<sup>[[1]](#references)</sup>

> [!TIP]
> Lengo la awamu hii ya tatu ni rahisi sana: **Kukabidhi kila tokeni ya awali katika vocabulary vekta yenye vipimo vinavyohitajika ili kufundisha modeli.** Kila neno katika vocabulary litakuwa nukta katika nafasi yenye vipimo X.\
> Kumbuka kuwa mwanzoni, nafasi ya kila neno katika nafasi hiyo huanzishwa kwa "nasibu" tu, na nafasi hizi ni vigezo vinavyoweza kufundishwa (vitaboreshwa wakati wa mafunzo).
>
> Zaidi ya hayo, wakati wa kuunda embedding ya tokeni, **tabaka jingine la embedding huundwa** ambalo linawakilisha (katika hali hii) **nafasi kamili ya neno katika sentensi ya mafunzo**. Kwa njia hii, neno lililo katika nafasi tofauti katika sentensi litakuwa na uwakilishi (maana) tofauti.

### **Embedding za Tokeni Ni Nini?**

**Embedding za Tokeni** ni uwakilishi wa nambari wa tokeni katika nafasi ya vekta endelevu. Kila tokeni katika vocabulary inahusishwa na vekta ya kipekee yenye vipimo vilivyowekwa. Vekta hizi hunasa taarifa za kisemantiki na kisintaksia kuhusu tokeni, hivyo kuiwezesha modeli kuelewa uhusiano na mifumo katika data.

- **Ukubwa wa Vocabulary:** Jumla ya tokeni za kipekee (kwa mfano, maneno au vipande vya maneno) katika vocabulary ya modeli.
- **Vipimo vya Embedding:** Idadi ya thamani za nambari (vipimo) katika vekta ya kila tokeni. Vipimo vya juu vinaweza kunasa taarifa zenye tofauti ndogo zaidi, lakini vinahitaji rasilimali zaidi za computational.

**Mfano:**

- **Ukubwa wa Vocabulary:** tokeni 6 \[1, 2, 3, 4, 5, 6]
- **Vipimo vya Embedding:** 3 (x, y, z)

### **Kuanzisha Embedding za Tokeni**

Mwanzoni mwa mafunzo, embedding za tokeni kwa kawaida huanzishwa kwa thamani ndogo za nasibu. Thamani hizi za mwanzo hubadilishwa (kurekebishwa) wakati wa mafunzo ili kuwakilisha vizuri zaidi maana za tokeni kulingana na data ya mafunzo.

**Mfano wa PyTorch:**
```python
import torch

# Set a random seed for reproducibility
torch.manual_seed(123)

# Create an embedding layer with 6 tokens and 3 dimensions
embedding_layer = torch.nn.Embedding(6, 3)

# Display the initial weights (embeddings)
print(embedding_layer.weight)
```

### **Jinsi Token Embeddings Zinavyofanya Kazi Wakati wa Training**

Wakati wa training, kila token katika input data hubadilishwa kuwa embedding vector yake inayolingana. Vector hizi hutumika katika computations mbalimbali ndani ya model, kama vile attention mechanisms na neural network layers.

**Mfano wa Hali:**

- **Batch Size:** 8 (idadi ya samples zinazochakatwa kwa wakati mmoja)
- **Max Sequence Length:** 4 (idadi ya tokens kwa kila sample)
- **Embedding Dimensions:** 256

**Muundo wa Data:**

- Kila batch inawakilishwa na 3D tensor yenye shape `(batch_size, max_length, embedding_dim)`.
- Kwa mfano wetu, shape itakuwa `(8, 4, 256)`.

## **Positional Embeddings: Kuongeza Muktadha kwenye Token Embeddings**

Ingawa token embeddings hunasa maana ya token binafsi, kwa asili hazisimbii nafasi za token ndani ya mfuatano. Kuelewa mpangilio wa token ni muhimu kwa uelewa wa lugha. Hapa ndipo **positional embeddings** hutumika.

### **Kwa Nini Positional Embeddings Zinahitajika:**

- **Mpangilio wa Token ni Muhimu:** Katika sentensi, maana mara nyingi hutegemea mpangilio wa maneno. Kwa mfano, "The cat sat on the mat" dhidi ya "The mat sat on the cat."
- **Kikomo cha Embedding:** Bila taarifa ya nafasi, model huchukulia token kama "bag of words," na kupuuza mfuatano wake.

### **Aina za Positional Embeddings:**

1. **Absolute Positional Embeddings:**
- Hupeana vekta ya kipekee ya nafasi kwa kila nafasi katika mfuatano.
- **Mfano:** Token ya kwanza katika mfuatano wowote huwa na positional embedding ileile, token ya pili huwa na nyingine, na kadhalika.
- **Hutumika na:** OpenAI’s GPT models.
2. **Relative Positional Embeddings:**
- Husimba umbali wa kulinganisha kati ya token badala ya nafasi zao kamili.
- **Mfano:** Huonyesha umbali kati ya token mbili, bila kujali nafasi zao kamili katika mfuatano.
- **Hutumika na:** Models kama Transformer-XL na baadhi ya variants za BERT.

### **Jinsi Positional Embeddings Zinavyounganishwa:**

- **Vipimo Sawa:** Positional embeddings zina dimensionality sawa na token embeddings.
- **Kujumlisha:** Huongezwa kwenye token embeddings, hivyo kuchanganya utambulisho wa token na taarifa ya nafasi bila kuongeza dimensionality ya jumla.

**Mfano wa Kuongeza Positional Embeddings:**

Tuseme token embedding vector ni `[0.5, -0.2, 0.1]` na positional embedding vector yake ni `[0.1, 0.3, -0.1]`. Embedding iliyounganishwa inayotumiwa na model itakuwa:
```css
Combined Embedding = Token Embedding + Positional Embedding
= [0.5 + 0.1, -0.2 + 0.3, 0.1 + (-0.1)]
= [0.6, 0.1, 0.0]
```
**Faida za Positional Embeddings:**

- **Uelewa wa Muktadha:** Modeli inaweza kutofautisha kati ya tokens kulingana na nafasi zao.
- **Uelewa wa Mfuatano:** Huwawezesha modeli kuelewa sarufi, sintaksia na maana zinazotegemea muktadha.

## **Positional Embeddings katika LLMs za Kisasa**

### **Rotary Positional Embeddings (RoPE)**

RoPE husimba nafasi kwa kutumia mzunguko unaotegemea nafasi kwenye jozi za vipimo katika query/key vectors, na kubadilisha nafasi kamili kuwa tofauti za awamu za nafasi husika. Hii hutoa taarifa ya nafasi husika huku ikihifadhi dimensionality ya embedding bila mabadiliko, na hutumiwa sana katika LLMs za hivi karibuni za decoder-only.<sup>[[2]](#references)</sup>

Kwa maelezo kuhusu jinsi token na positional embeddings zinavyounganishwa ndani ya modeli, angalia [ukurasa wa usanifu wa LLM](5.-llm-architecture.md).

### **Kupanua Context Windows katika Models Zinazotumia RoPE**

Utafiti wa hivi karibuni unaonyesha kuwa urefu wa context mara nyingi huzuiwa na scheme ya positional encoding badala ya token embedding matrix yenyewe.

- **Position Interpolation (PI):** Hurekebisha upya position indices ili sequences ndefu ziingie katika range iliyotumika wakati wa training, na kuwezesha upanuzi kwa fine-tuning ndogo.<sup>[[3]](#references)</sup> Mfano:
```python
# Position Interpolation (PI) intuition
orig_ctx = 2048
new_ctx = 8192
scaled_pos = pos * (orig_ctx / new_ctx)
```
- **YaRN:** Mkakati wa kuongeza RoPE unaotumia compute kwa ufanisi, unaorekebisha scaling/interpolation ya RoPE ili kuongeza muktadha hadi urefu zaidi kwa hatua chache za ziada za training.<sup>[[4]](#references)</sup>

```python
# Use previous code...

# Create dimensional emdeddings
"""
BPE uses a vocabulary of 50257 words
Let's supose we want to use 256 dimensions (instead of the millions used by LLMs)
"""

vocab_size = 50257
output_dim = 256
token_embedding_layer = torch.nn.Embedding(vocab_size, output_dim)

## Generate the dataloader like before
max_length = 4
dataloader = create_dataloader_v1(
raw_text, batch_size=8, max_length=max_length,
stride=max_length, shuffle=False
)
data_iter = iter(dataloader)
inputs, targets = next(data_iter)

# Apply embeddings
token_embeddings = token_embedding_layer(inputs)
print(token_embeddings.shape)
torch.Size([8, 4, 256]) # 8 x 4 x 256

# Generate absolute embeddings
context_length = max_length
pos_embedding_layer = torch.nn.Embedding(context_length, output_dim)

pos_embeddings = pos_embedding_layer(torch.arange(max_length))

input_embeddings = token_embeddings + pos_embeddings
print(input_embeddings.shape) # torch.Size([8, 4, 256])
```
