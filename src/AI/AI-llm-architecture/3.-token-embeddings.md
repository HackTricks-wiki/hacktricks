## Ενσωματώσεις Token

Μετά την τοκενικοποίηση των δεδομένων κειμένου, το επόμενο κρίσιμο βήμα στην προετοιμασία των δεδομένων για την εκπαίδευση μεγάλων γλωσσικών μοντέλων (LLM) όπως το GPT είναι η δημιουργία **ενσωματώσεων token**. Οι ενσωματώσεις token μετατρέπουν τα διακριτά token (όπως λέξεις ή υπολέξεις) σε συνεχείς αριθμητικά διανύσματα, τα οποία μπορεί να επεξεργαστεί και από τα οποία μπορεί να μάθει το μοντέλο. Αυτή η εξήγηση αναλύει τις ενσωματώσεις token, την αρχικοποίησή τους, τη χρήση τους και τον ρόλο των ενσωματώσεων θέσης στην ενίσχυση της κατανόησης ακολουθιών token από το μοντέλο.<sup>[[1]](#references)</sup>

> [!TIP]
> Ο στόχος αυτής της τρίτης φάσης είναι πολύ απλός: **Να αντιστοιχιστεί σε καθένα από τα προηγούμενα token στο λεξιλόγιο ένα διάνυσμα με τις επιθυμητές διαστάσεις, ώστε να εκπαιδευτεί το μοντέλο.** Κάθε λέξη στο λεξιλόγιο θα είναι ένα σημείο σε έναν χώρο X διαστάσεων.\
> Σημειώστε ότι αρχικά, η θέση κάθε λέξης στον χώρο αρχικοποιείται απλώς «τυχαία» και ότι αυτές οι θέσεις είναι εκπαιδεύσιμες παράμετροι (θα βελτιωθούν κατά την εκπαίδευση).
>
> Επιπλέον, κατά τη δημιουργία των ενσωματώσεων token **δημιουργείται ένα ακόμη επίπεδο ενσωματώσεων**, το οποίο αναπαριστά (σε αυτήν την περίπτωση) την **απόλυτη θέση της λέξης στην πρόταση εκπαίδευσης**. Έτσι, μια λέξη σε διαφορετικές θέσεις της πρότασης θα έχει διαφορετική αναπαράσταση (σημασία).

### **Τι είναι οι ενσωματώσεις token;**

Οι **ενσωματώσεις token** είναι αριθμητικές αναπαραστάσεις των token σε έναν συνεχή διανυσματικό χώρο. Κάθε token στο λεξιλόγιο αντιστοιχεί σε ένα μοναδικό διάνυσμα σταθερών διαστάσεων. Αυτά τα διανύσματα αποτυπώνουν σημασιολογικές και συντακτικές πληροφορίες για τα token, επιτρέποντας στο μοντέλο να κατανοεί σχέσεις και μοτίβα στα δεδομένα.

- **Μέγεθος λεξιλογίου:** Ο συνολικός αριθμός των μοναδικών token (π.χ. λέξεων, υπολέξεων) στο λεξιλόγιο του μοντέλου.
- **Διαστάσεις ενσωμάτωσης:** Ο αριθμός των αριθμητικών τιμών (διαστάσεων) στο διάνυσμα κάθε token. Οι περισσότερες διαστάσεις μπορούν να αποτυπώσουν λεπτομερέστερες πληροφορίες, αλλά απαιτούν περισσότερους υπολογιστικούς πόρους.

**Παράδειγμα:**

- **Μέγεθος λεξιλογίου:** 6 token \[1, 2, 3, 4, 5, 6]
- **Διαστάσεις ενσωμάτωσης:** 3 (x, y, z)

### **Αρχικοποίηση ενσωματώσεων token**

Στην αρχή της εκπαίδευσης, οι ενσωματώσεις token αρχικοποιούνται συνήθως με μικρές τυχαίες τιμές. Αυτές οι αρχικές τιμές προσαρμόζονται (βελτιστοποιούνται περαιτέρω) κατά την εκπαίδευση, ώστε να αναπαριστούν καλύτερα τις σημασίες των token με βάση τα δεδομένα εκπαίδευσης.

**Παράδειγμα PyTorch:**

```python
import torch

# Set a random seed for reproducibility
torch.manual_seed(123)

# Create an embedding layer with 6 tokens and 3 dimensions
embedding_layer = torch.nn.Embedding(6, 3)

# Display the initial weights (embeddings)
print(embedding_layer.weight)
```

**Έξοδος:**


**Εξήγηση:**

- Κάθε γραμμή αντιστοιχεί σε ένα token του λεξιλογίου.
- Κάθε στήλη αντιπροσωπεύει μια διάσταση στο διάνυσμα ενσωμάτωσης.
- Για παράδειγμα, το token στη θέση `3` έχει διάνυσμα ενσωμάτωσης `[-0.4015, 0.9666, -1.1481]`.

**Πρόσβαση στην ενσωμάτωση ενός token:**

```python
# Retrieve the embedding for the token at index 3
token_index = torch.tensor([3])
print(embedding_layer(token_index))
```

**Έξοδος:**

```lua

```

**Ερμηνεία:**

- Το token στη θέση `3` αναπαρίσταται από το διάνυσμα `[-0.4015, 0.9666, -1.1481]`.
- Αυτές οι τιμές είναι εκπαιδεύσιμες παράμετροι, τις οποίες το μοντέλο θα προσαρμόσει κατά την εκπαίδευση, ώστε να αναπαριστά καλύτερα το πλαίσιο και το νόημα του token.

### **Πώς λειτουργούν τα Embeddings των Token κατά την Εκπαίδευση**

Κατά την εκπαίδευση, κάθε token στα δεδομένα εισόδου μετατρέπεται στο αντίστοιχο διάνυσμα embedding. Στη συνέχεια, αυτά τα διανύσματα χρησιμοποιούνται σε διάφορους υπολογισμούς μέσα στο μοντέλο, όπως στους μηχανισμούς attention και στα επίπεδα νευρωνικού δικτύου.

**Παράδειγμα:**

- **Μέγεθος Batch:** 8 (αριθμός δειγμάτων που υποβάλλονται σε επεξεργασία ταυτόχρονα)
- **Μέγιστο Μήκος Ακολουθίας:** 4 (αριθμός token ανά δείγμα)
- **Διαστάσεις Embedding:** 256

**Δομή Δεδομένων:**

- Κάθε batch αναπαρίσταται ως τρισδιάστατος tensor με σχήμα `(batch_size, max_length, embedding_dim)`.
- Για το παράδειγμά μας, το σχήμα θα ήταν `(8, 4, 256)`.

**Οπτικοποίηση:**

- Το μοντέλο επεξεργάζεται αυτές τις ενσωματώσεις για να μάθει γλωσσικά μοτίβα και να δημιουργεί προβλέψεις.

## **Ενσωματώσεις θέσης: Προσθήκη πλαισίου στις ενσωματώσεις token**

Παρότι οι ενσωματώσεις token αποτυπώνουν τη σημασία μεμονωμένων token, δεν κωδικοποιούν από μόνες τους τη θέση των token μέσα σε μια ακολουθία. Η κατανόηση της σειράς των token είναι κρίσιμη για την κατανόηση της γλώσσας. Εδώ υπεισέρχονται οι **ενσωματώσεις θέσης**.

### **Γιατί χρειάζονται οι ενσωματώσεις θέσης:**

- **Η σειρά των token έχει σημασία:** Στις προτάσεις, το νόημα συχνά εξαρτάται από τη σειρά των λέξεων. Για παράδειγμα, «Η γάτα κάθισε πάνω στο χαλάκι» έναντι «Το χαλάκι κάθισε πάνω στη γάτα».
- **Περιορισμός των ενσωματώσεων:** Χωρίς πληροφορίες θέσης, το μοντέλο αντιμετωπίζει τα token σαν ένα «σύνολο λέξεων», αγνοώντας τη σειρά τους.

### **Τύποι ενσωματώσεων θέσης:**

1. **Απόλυτες ενσωματώσεις θέσης:**
   - Αντιστοιχίζουν ένα μοναδικό διάνυσμα θέσης σε κάθε θέση της ακολουθίας.
   - **Παράδειγμα:** Το πρώτο token σε οποιαδήποτε ακολουθία έχει την ίδια ενσωμάτωση θέσης, το δεύτερο token έχει μια άλλη, και ούτω καθεξής.
   - **Χρησιμοποιούνται από:** Τα μοντέλα GPT της OpenAI.
2. **Σχετικές ενσωματώσεις θέσης:**
   - Κωδικοποιούν τη σχετική απόσταση μεταξύ token αντί για τις απόλυτες θέσεις τους.
   - **Παράδειγμα:** Υποδεικνύουν πόσο απέχουν μεταξύ τους δύο token, ανεξάρτητα από τις απόλυτες θέσεις τους στην ακολουθία.
   - **Χρησιμοποιούνται από:** Μοντέλα όπως τα Transformer-XL και ορισμένες παραλλαγές του BERT.

### **Πώς ενσωματώνονται οι ενσωματώσεις θέσης:**

- **Ίδιες διαστάσεις:** Οι ενσωματώσεις θέσης έχουν τις ίδιες διαστάσεις με τις ενσωματώσεις token.
- **Πρόσθεση:** Προστίθενται στις ενσωματώσεις token, συνδυάζοντας την ταυτότητα του token με τις πληροφορίες θέσης χωρίς να αυξάνουν τη συνολική διαστατικότητα.

**Παράδειγμα πρόσθεσης ενσωματώσεων θέσης:**

Ας υποθέσουμε ότι ένα διάνυσμα ενσωμάτωσης token είναι `[0.5, -0.2, 0.1]` και το διάνυσμα ενσωμάτωσης θέσης του είναι `[0.1, 0.3, -0.1]`. Η συνδυασμένη ενσωμάτωση που θα χρησιμοποιήσει το μοντέλο θα είναι:

```css
Combined Embedding = Token Embedding + Positional Embedding
                   = [0.5 + 0.1, -0.2 + 0.3, 0.1 + (-0.1)]
                   = [0.6, 0.1, 0.0]
```

**Οφέλη των Positional Embeddings:**

- **Επίγνωση συμφραζομένων:** Το μοντέλο μπορεί να διακρίνει τα tokens με βάση τη θέση τους.
- **Κατανόηση ακολουθιών:** Επιτρέπει στο μοντέλο να κατανοεί τη γραμματική, τη σύνταξη και τις σημασίες που εξαρτώνται από τα συμφραζόμενα.

## **Positional Embeddings σε σύγχρονα LLMs**

### **Rotary Positional Embeddings (RoPE)**

Το RoPE κωδικοποιεί τη θέση εφαρμόζοντας μια εξαρτώμενη από τη θέση περιστροφή σε ζεύγη διαστάσεων των διανυσμάτων query/key, μετατρέποντας τις απόλυτες θέσεις σε σχετικές διαφορές φάσης. Αυτό παρέχει πληροφορίες σχετικής θέσης, διατηρώντας αμετάβλητη τη διαστατικότητα των embeddings, και χρησιμοποιείται ευρέως σε πρόσφατα decoder-only LLMs.<sup>[[2]](#references)</sup>

Για να δείτε πώς συνδυάζονται τα token και positional embeddings μέσα στο μοντέλο, ανατρέξτε στη [σελίδα αρχιτεκτονικής LLM](5.-llm-architecture.md).

### **Επέκταση των παραθύρων συμφραζομένων σε μοντέλα βασισμένα στο RoPE**

Πρόσφατες εργασίες δείχνουν ότι το μήκος συμφραζομένων συχνά περιορίζεται από το σχήμα positional encoding και όχι από τον ίδιο τον πίνακα token embeddings.

- **Position Interpolation (PI):** Επανακλιμακώνει τους δείκτες θέσης, ώστε οι μεγαλύτερες ακολουθίες να αντιστοιχούν στο εύρος που παρατηρήθηκε κατά την εκπαίδευση, επιτρέποντας την επέκταση με ελάχιστο fine-tuning.<sup>[[3]](#references)</sup> Παράδειγμα:

```python
# Position Interpolation (PI) intuition
orig_ctx = 2048
new_ctx = 8192
scaled_pos = pos * (orig_ctx / new_ctx)
```

- **YaRN:** Μια υπολογιστικά αποδοτική στρατηγική επέκτασης του RoPE, η οποία τροποποιεί την κλιμάκωση/παρεμβολή του RoPE για να επεκτείνει το μήκος περιβάλλοντος με λιγότερα πρόσθετα βήματα εκπαίδευσης.<sup>[[4]](#references)</sup>

## Παράδειγμα κώδικα

Ακολουθεί το παράδειγμα κώδικα από [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch02/01_main-chapter-code/ch02.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch02/01_main-chapter-code/ch02.ipynb):<sup>[[5]](#references)</sup>

```python
# Use previous code...

# Create token embeddings
"""
BPE uses a vocabulary of 50257 words
Let's supose we want to use 256 dimensions (instead of the millions used by LLMs)
"""

vocab_size = 50257
output_dim = 256
token_embedding_layer = torch.nn.Embedding(vocab_size, output_dim)

## Generate the dataloader like before
max_length = 4
dataloader = create_dataloader_v1(
    raw_text, batch_size=8, max_length=max_length,
    stride=max_length, shuffle=False
)
data_iter = iter(dataloader)
inputs, targets = next(data_iter)

# Apply embeddings
token_embeddings = token_embedding_layer(inputs)
print(token_embeddings.shape)
torch.Size([8, 4, 256]) # 8 x 4 x 256

# Generate absolute embeddings
context_length = max_length
pos_embedding_layer = torch.nn.Embedding(context_length, output_dim)

pos_embeddings = pos_embedding_layer(torch.arange(max_length))

input_embeddings = token_embeddings + pos_embeddings
print(input_embeddings.shape) # torch.Size([8, 4, 256])
```
