## 3. Token Embeddings

> [!TIP]
> Ο στόχος αυτής της τρίτης φάσης είναι πολύ απλός: **Να αντιστοιχιστεί σε καθένα από τα προηγούμενα tokens στο vocabulary ένα vector των επιθυμητών διαστάσεων για την εκπαίδευση του model.** Κάθε λέξη στο vocabulary θα αποτελεί ένα σημείο σε έναν χώρο X διαστάσεων.\
> Σημειώστε ότι αρχικά η θέση κάθε λέξης στον χώρο αρχικοποιείται απλώς «τυχαία» και αυτές οι θέσεις είναι trainable parameters (θα βελτιωθούν κατά την εκπαίδευση).
>
> Επιπλέον, κατά το token embedding, **δημιουργείται ένα ακόμη embedding layer** που αναπαριστά (σε αυτήν την περίπτωση) την **απόλυτη θέση της λέξης στην πρόταση εκπαίδευσης**. Με αυτόν τον τρόπο, μια λέξη σε διαφορετικές θέσεις της πρότασης έχει διαφορετική αναπαράσταση.


{{#ref}}
3.-token-embeddings.md
{{#endref}}

## 4. Μηχανισμοί Attention

> [!TIP]
> Ο στόχος αυτής της τέταρτης φάσης είναι πολύ απλός: **Να εφαρμοστούν ορισμένοι μηχανισμοί attention**. Αυτοί θα αποτελούνται από πολλές **επαναλαμβανόμενες layers** που θα **καταγράφουν τη σχέση μιας λέξης στο vocabulary με τους γείτονές της στην τρέχουσα πρόταση που χρησιμοποιείται για την εκπαίδευση του LLM**.\
> Χρησιμοποιούνται πολλά layers για αυτόν τον σκοπό, επομένως πολλά trainable parameters θα καταγράφουν αυτές τις πληροφορίες.


{{#ref}}
4.-attention-mechanisms.md
{{#endref}}

## 5. Αρχιτεκτονική LLM

> [!TIP]
> Ο στόχος αυτής της πέμπτης φάσης είναι πολύ απλός: **Να αναπτυχθεί η αρχιτεκτονική ολόκληρου του LLM**. Να συνδυαστούν όλα, να εφαρμοστούν όλα τα layers και να δημιουργηθούν όλες οι functions για τη δημιουργία κειμένου ή τη μετατροπή κειμένου σε IDs και αντίστροφα.
>
> Αυτή η αρχιτεκτονική θα χρησιμοποιείται τόσο για την εκπαίδευση όσο και για την πρόβλεψη κειμένου μετά την εκπαίδευσή του.

5.-llm-architecture.md
