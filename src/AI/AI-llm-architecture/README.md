## 3. Token Embeddings

> [!TIP]
> Ο στόχος αυτής της τρίτης φάσης είναι πολύ απλός: **Να αντιστοιχιστεί σε καθένα από τα προηγούμενα tokens του vocabulary ένα διάνυσμα των επιθυμητών διαστάσεων για την εκπαίδευση του μοντέλου.** Κάθε λέξη του vocabulary θα είναι ένα σημείο σε χώρο X διαστάσεων.\
> Σημειώστε ότι αρχικά η θέση κάθε λέξης στον χώρο αρχικοποιείται «τυχαία» και αυτές οι θέσεις είναι trainable parameters (θα βελτιωθούν κατά την εκπαίδευση).
>
> Επιπλέον, κατά τη διαδικασία των token embeddings **δημιουργείται ένα ακόμη layer embeddings**, το οποίο αναπαριστά (σε αυτήν την περίπτωση) την **απόλυτη θέση της λέξης στην πρόταση εκπαίδευσης**. Με αυτόν τον τρόπο, μια λέξη σε διαφορετικές θέσεις της πρότασης θα έχει διαφορετική αναπαράσταση (σημασία).


{{#ref}}
3.-token-embeddings.md
{{#endref}}

## 4. Attention Mechanisms

> [!TIP]
> Ο στόχος αυτής της τέταρτης φάσης είναι πολύ απλός: **Να εφαρμοστούν ορισμένοι attention mechanisms**. Αυτοί θα αποτελούνται από πολλά **επαναλαμβανόμενα layers**, τα οποία θα **εντοπίζουν τη σχέση μιας λέξης του vocabulary με τους γείτονές της στην τρέχουσα πρόταση που χρησιμοποιείται για την εκπαίδευση του LLM**.\
> Για αυτό χρησιμοποιούνται πολλά layers, επομένως πολλά trainable parameters θα καταγράφουν αυτές τις πληροφορίες.


{{#ref}}
4.-attention-mechanisms.md
{{#endref}}

## 5. Αρχιτεκτονική LLM

> [!TIP]
> Ο στόχος αυτής της πέμπτης φάσης είναι πολύ απλός: **Να αναπτυχθεί η αρχιτεκτονική του πλήρους LLM**. Να συνδυαστούν όλα, να εφαρμοστούν όλα τα layers και να δημιουργηθούν όλες οι functions για τη生成 κειμένου ή τη μετατροπή κειμένου σε IDs και αντίστροφα.
>
> Αυτή η αρχιτεκτονική θα χρησιμοποιηθεί τόσο για την εκπαίδευση όσο και για την πρόβλεψη κειμένου μετά την εκπαίδευσή της.


{{#ref}}
