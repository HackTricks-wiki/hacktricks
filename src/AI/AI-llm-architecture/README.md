## 3. Вбудовування токенів

> [!TIP]
> Мета цього третього етапу дуже проста: **призначити кожному з попередніх токенів у словнику вектор потрібної розмірності для навчання моделі.** Кожне слово у словнику буде точкою у просторі з X вимірами.\
> Зверніть увагу, що спочатку позиція кожного слова у просторі просто ініціалізується «випадково», і ці позиції є параметрами, що навчаються (вони будуть покращені під час навчання).
>
> Крім того, під час вбудовування токенів **створюється ще один шар вбудовувань**, який (у цьому випадку) представляє **абсолютну позицію слова в реченні, що використовується для навчання**. Таким чином, слово на різних позиціях у реченні матиме різне представлення (значення).


{{#ref}}
3.-token-embeddings.md
{{#endref}}

## 4. Механізми уваги

> [!TIP]
> Мета цього четвертого етапу дуже проста: **застосувати певні механізми уваги**. Це будуть численні **повторювані шари**, які **фіксуватимуть зв’язок слова у словнику з його сусідами в поточному реченні, що використовується для навчання LLM**.\
> Для цього використовується багато шарів, тому значна кількість параметрів, що навчаються, фіксуватиме цю інформацію.


{{#ref}}
4.-attention-mechanisms.md
{{#endref}}

## 5. Архітектура LLM

> [!TIP]
> Мета цього п’ятого етапу дуже проста: **розробити архітектуру повної LLM**. Об’єднати все разом, застосувати всі шари та створити всі функції для генерування тексту або перетворення тексту на ідентифікатори й навпаки.
>
> Ця архітектура використовуватиметься як для навчання, так і для прогнозування тексту після завершення навчання.


{{#ref}}
5.-llm-architecture.md
{{#endref}}
