## 3. Вбудовування токенів

> [!TIP]
> Мета цього третього етапу дуже проста: **призначити кожному з попередніх токенів у словнику вектор бажаних розмірностей для навчання моделі.** Кожне слово у словнику буде точкою у просторі з X вимірами.\
> Зауважте, що спочатку позиція кожного слова у просторі просто ініціалізується «випадково», і ці позиції є параметрами, які можна навчати (вони покращуватимуться під час навчання).
>
> Крім того, під час вбудовування токенів **створюється ще один шар вбудовування**, який представляє (у цьому випадку) **абсолютну позицію слова в навчальному реченні**. Таким чином, слово на різних позиціях у реченні має різне представлення.

3.-token-embeddings.md
{{#endref}}

## 4. Механізми уваги

> [!TIP]
> Мета цього четвертого етапу дуже проста: **застосувати певні механізми уваги**. Це будуть численні **повторювані шари**, призначені **вловлювати зв’язок слова у словнику з його сусідами в поточному реченні, що використовується для навчання LLM**.\
> Для цього використовується багато шарів, тому велика кількість параметрів, які можна навчати, захоплюватиме цю інформацію.


{{#ref}}
4.-attention-mechanisms.md
{{#endref}}

## 5. Архітектура LLM

> [!TIP]
> Мета цього п’ятого етапу дуже проста: **розробити архітектуру повної LLM**. Об’єднати все разом, застосувати всі шари та створити всі функції для генерування тексту або перетворення тексту на ID і навпаки.
>
> Ця архітектура використовуватиметься і для навчання, і для передбачення тексту після завершення навчання.


{{#ref}}
5.-llm-architecture.md
{{#endref}}
