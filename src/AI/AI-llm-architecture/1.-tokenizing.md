## Tokenizing

**Tokenizing** ni mchakato wa kugawanya data, kama vile maandishi, kuwa vipande vidogo vinavyoweza kudhibitiwa vinavyoitwa _tokens_. Kila token hupewa kitambulisho cha kipekee cha nambari (ID). Hii ni hatua ya msingi katika kuandaa maandishi kwa ajili ya kuchakatwa na machine learning models, hasa katika natural language processing (NLP).<sup>[[1]](#references)</sup>

> [!TIP]
> Lengo la awamu hii ya awali ni rahisi: **gawanya ingizo kuwa tokens (IDs) kwa njia yenye manufaa**.

### **Jinsi Tokenizing Inavyofanya Kazi**

1. **Kugawanya Maandishi:**
- **Basic Tokenizer:** tokenizer rahisi inaweza kugawanya maandishi kuwa maneno binafsi na alama za uakifishaji, huku ikiondoa nafasi.
- _Mfano:_\
Maandishi: `"Hello, world!"`\
Tokens: `["Hello", ",", "world", "!"]`
2. **Kuunda Vocabulary:**
- Ili kubadilisha tokens kuwa IDs za nambari, **vocabulary** huundwa. Vocabulary hii huorodhesha tokens zote za kipekee (maneno na alama) na kuipa kila moja ID maalum.
- **Special Tokens:** Hizi ni alama maalum zinazoongezwa kwenye vocabulary ili kushughulikia hali mbalimbali:
- `[BOS]` (Beginning of Sequence): Huashiria mwanzo wa maandishi.
- `[EOS]` (End of Sequence): Huashiria mwisho wa maandishi.
- `[PAD]` (Padding): Hutumiwa kufanya sequences zote katika batch ziwe na urefu sawa.
- `[UNK]` (Unknown): Huenda ikawasilisha tokens ambazo hazipo kwenye vocabulary.
- _Mfano:_\
Ikiwa `"Hello"` imepewa ID `64`, `","` ni `455`, `"world"` ni `78`, na `"!"` ni `467`, basi:\
`"Hello, world!"` → `[64, 455, 78, 467]`
- **Kushughulikia Maneno Yasiyojulikana:**\
Ikiwa neno kama `"Bye"` halipo kwenye vocabulary, hubadilishwa kuwa `[UNK]`.\
`"Bye, world!"` → `["[UNK]", ",", "world", "!"]` → `[987, 455, 78, 467]`\
_(Kwa kudhani kuwa `[UNK]` ina ID `987`)_

### **Advanced Tokenizing Methods**

Ingawa basic tokenizer hufanya kazi vizuri kwa maandishi rahisi, ina vikwazo, hasa inaposhughulikia vocabularies kubwa na maneno mapya au adimu. Advanced tokenizing methods hushughulikia masuala haya kwa kugawanya maandishi kuwa subunits ndogo au kuboresha mchakato wa tokenization.

1. **Byte Pair Encoding (BPE):**
- **Madhumuni:** Hupunguza ukubwa wa vocabulary na hushughulikia maneno adimu au yasiyojulikana kwa kuyagawa kuwa byte pairs zinazotokea mara kwa mara.
- **Jinsi Inavyofanya Kazi:**
- Huanzia na herufi binafsi kama tokens.
- Huunganisha kwa kurudiarudia jozi za tokens zinazotokea mara nyingi zaidi kuwa token moja.
- Huendelea hadi hakuna jozi nyingine zinazotokea mara kwa mara zinazoweza kuunganishwa.
- **Faida:**
- Byte-level BPE tokenizer yenye byte alphabet kamili inaweza kuwakilisha ingizo lolote bila token ya `[UNK]`; variants zinazotegemea herufi bado hutegemea base alphabet yao.
- Vocabulary yenye ufanisi na unyumbufu zaidi.
- _Mfano:_\
`"playing"` inaweza kutengenezwa tokens kama `["play", "ing"]` ikiwa `"play"` na `"ing"` ni subwords zinazotokea mara kwa mara.
2. **WordPiece:**
- **Inatumiwa na:** Models kama BERT.
- **Madhumuni:** Sawa na BPE, hugawanya maneno kuwa subword units ili kushughulikia maneno yasiyojulikana na kupunguza ukubwa wa vocabulary.
- **Jinsi Inavyofanya Kazi:**
- Huanzia na base vocabulary ya herufi binafsi.
- Huongeza kwa kurudiarudia subword inayotokea mara nyingi zaidi na inayoongeza uwezekano wa training data kwa kiwango cha juu zaidi.
- Hutumia probabilistic model kuamua ni subwords zipi ziunganishwe.
- **Faida:**
- Huweka uwiano kati ya kuwa na vocabulary yenye ukubwa unaoweza kudhibitiwa na kuwakilisha maneno kwa ufanisi.
- Hushughulikia kwa ufanisi maneno adimu na yenye mchanganyiko.
- _Mfano:_\
`"unhappiness"` inaweza kutengenezwa tokens kama `["un", "happiness"]` au `["un", "happy", "ness"]` kulingana na vocabulary.
3. **Unigram Language Model:**
- **Inatumiwa na:** Models kama SentencePiece.
- **Madhumuni:** Hutumia probabilistic model kubaini seti inayowezekana zaidi ya subword tokens.
- **Jinsi Inavyofanya Kazi:**
- Huanzia na seti kubwa ya tokens zinazowezekana.
- Huondoa kwa kurudiarudia tokens zinazoboresha kwa kiwango kidogo zaidi uwezekano wa model wa training data.
- Hukamilisha vocabulary ambapo kila neno huwakilishwa na subword units zenye uwezekano mkubwa zaidi.
- **Faida:**
- Ni yenye unyumbufu na inaweza kuiga lugha kwa njia ya asili zaidi.
- Mara nyingi husababisha tokenizations zenye ufanisi na compact zaidi.
- _Mfano:_\
`"internationalization"` inaweza kugawanywa kuwa subwords ndogo zenye maana kama `["international", "ization"]`.

## Code Example

Hebu tuelewe hili vizuri zaidi kupitia code example kutoka [https://github.com/rasbt/LLMs-from-scratch/blob/main/ch02/01_main-chapter-code/ch02.ipynb](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch02/01_main-chapter-code/ch02.ipynb):<sup>[[2]](#references)</sup>
```python
# Download a text to pre-train the model
import urllib.request
url = ("https://raw.githubusercontent.com/rasbt/LLMs-from-scratch/main/ch02/01_main-chapter-code/the-verdict.txt")
file_path = "the-verdict.txt"
urllib.request.urlretrieve(url, file_path)

with open("the-verdict.txt", "r", encoding="utf-8") as f:
raw_text = f.read()

# Tokenize the code using GPT2 tokenizer version
import tiktoken
token_ids = tiktoken.get_encoding("gpt2").encode(raw_text)

# Print first 50 tokens
print(token_ids[:50])
#[40, 367, 2885, 1464, 1807, 3619, 402, 271, 10899, 2138, 257, 7026, 15632, 438, 2016, 257, 922, 5891, 1576, 438, 568, 340, 373, 645, 1049, 5975, 284, 502, 284, 3285, 326, 11, 287, 262, 6001, 286, 465, 13476, 11, 339, 550, 5710, 465, 12036, 11, 6405, 257, 5527, 27075, 11]
```
