## 分词

**分词（Tokenizing）**是将数据（例如文本）拆分成较小、易于处理的片段（称为 _tokens_）的过程。随后，每个 token 都会被分配一个唯一的数字标识符（ID）。这是准备文本以供 machine learning models 处理的基础步骤，尤其是在 natural language processing（NLP）中。<sup>[[1]](#references)</sup>

> [!TIP]
> 此初始阶段的目标非常简单：**以某种合理的方式将输入拆分为 tokens（ids）**。

### **分词的工作原理**

1. **拆分文本：**
- **Basic Tokenizer：**简单的 tokenizer 可能会将文本拆分成单独的单词和标点符号，并移除空格。
- _示例：_\
文本：`"Hello, world!"`\
Tokens：`["Hello", ",", "world", "!"]`
2. **创建词汇表：**
- 为了将 tokens 转换为数字 ID，需要创建一个**词汇表**。该词汇表列出所有唯一的 tokens（单词和符号），并为每个 token 分配特定的 ID。
- **特殊 Tokens：**这些是添加到词汇表中的特殊符号，用于处理各种情况：
- `[BOS]`（Beginning of Sequence）：表示文本的开头。
- `[EOS]`（End of Sequence）：表示文本的结尾。
- `[PAD]`（Padding）：用于使 batch 中的所有序列长度相同。
- `[UNK]`（Unknown）：表示不在词汇表中的 tokens。
- _示例：_\
如果为 `"Hello"` 分配的 ID 是 `64`，为 `","` 分配的是 `455`，为 `"world"` 分配的是 `78`，为 `"!"` 分配的是 `467`，那么：\
`"Hello, world!"` → `[64, 455, 78, 467]`
- **处理未知单词：**\
如果 `"Bye"` 这样的单词不在词汇表中，则会被替换为 `[UNK]`。\
`"Bye, world!"` → `["[UNK]", ",", "world", "!"]` → `[987, 455, 78, 467]`\
_（假设 `[UNK]` 的 ID 为 `987`）_

### **高级分词方法**

虽然 basic tokenizer 对简单文本效果良好，但它存在局限性，尤其是在处理大型词汇表以及新词或罕见单词时。高级分词方法通过将文本拆分成更小的子单元，或优化分词过程，来解决这些问题。

1. **Byte Pair Encoding（BPE）：**
- **目的：**通过将罕见或未知单词拆分为频繁出现的 byte pairs，减少词汇表的大小并处理这些单词。
- **工作原理：**
- 从将单个字符作为 tokens 开始。
- 迭代地将出现频率最高的 token 对合并为单个 token。
- 持续进行，直到没有更多高频 token 对可以合并。
- **优点：**
- 不需要 `[UNK]` token，因为所有单词都可以通过组合现有的 subword tokens 来表示。
- 词汇表更加高效和灵活。
- _示例：_\
如果 `"play"` 和 `"ing"` 是常见的 subwords，`"playing"` 可能会被分词为 `["play", "ing"]`。
2. **WordPiece：**
- **使用者：**BERT 等 models。
- **目的：**与 BPE 类似，它将单词拆分为 subword units，以处理未知单词并减少词汇表大小。
- **工作原理：**
- 从由单个字符组成的基础词汇表开始。
- 迭代地添加能够最大化 training data 似然的最高频 subword。
- 使用 probabilistic model 决定应合并哪些 subwords。
- **优点：**
- 在可管理的词汇表大小与有效表示单词之间取得平衡。
- 能够高效处理罕见单词和复合词。
- _示例：_\
根据词汇表的不同，`"unhappiness"` 可能会被分词为 `["un", "happiness"]` 或 `["un", "happy", "ness"]`。
3. **Unigram Language Model：**
- **使用者：**SentencePiece 等 models。
- **目的：**使用 probabilistic model 确定最可能的 subword tokens 集合。
- **工作原理：**
- 从一组大量潜在 tokens 开始。
- 迭代地移除对 training data 概率提升最小的 tokens。
- 最终确定一个词汇表，其中每个单词都由概率最高的 subword units 表示。
- **优点：**
- 灵活，能够更自然地建模语言。
- 通常可以生成更高效、更紧凑的 tokenizations。
- _示例：_\
`"internationalization"` 可能会被分词为更小且有意义的 subwords，例如 `["international", "ization"]`。
