# 저자 소개

### 안녕하세요!!

다른 연구자들이 기여한 Techniques는 원래 저자에게 계속 귀속됩니다. 인터넷 보안을 향상하기 위해 지식을 공유하는 모든 분께 감사드립니다.

Carlos는 HackTricks를 이끌고 있습니다. 이 프로젝트는 실용적인 보안 Techniques를 수집하고 기여를 환영하는 커뮤니티 유지형 cybersecurity wiki입니다. 누락되었거나 오래된 내용을 발견하면 프로젝트 repository에 pull request를 열어 주세요.<sup>[[1]](#references)</sup>

HackTricks는 연구자들이 새로운 findings를 공유할 공간도 제공하여, 독자들이 최신 security techniques를 계속 파악할 수 있도록 돕습니다.
