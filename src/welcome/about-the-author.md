# Про автора

### Привіт!!

Методики, додані іншими дослідниками, залишаються приписаними їхнім оригінальним авторам. Подяка всім, хто ділиться знаннями задля підвищення безпеки в інтернеті.

Carlos очолює HackTricks. Проєкт є вікі з кібербезпеки, яку підтримує спільнота; вона збирає практичні методики безпеки та вітає внески. Якщо ви знайшли щось відсутнє або застаріле, будь ласка, створіть pull request у репозиторії проєкту.<sup>[[1]](#references)</sup>

HackTricks також надає дослідникам місце для публікації нових знахідок, допомагаючи читачам стежити за сучасними методиками безпеки.
