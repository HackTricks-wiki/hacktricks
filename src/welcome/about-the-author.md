### नमस्कार!!

अन्य researchers द्वारा योगदान की गई Techniques का श्रेय उनके मूल authors को ही दिया जाता है। Internet security को बेहतर बनाने के लिए knowledge साझा करने वाले सभी लोगों को धन्यवाद।

Carlos HackTricks का नेतृत्व करते हैं। यह project community-maintained cybersecurity wiki है, जो practical security techniques एकत्र करता है और contributions का स्वागत करता है; यदि आपको कुछ missing या outdated मिले, तो कृपया project repository में pull request खोलें।<sup>[[1]](#references)</sup>

HackTricks researchers को new findings साझा करने के लिए भी एक स्थान देता है, जिससे readers current security techniques से updated रह सकें।
