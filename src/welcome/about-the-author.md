# Sobre o autor

### Olá!!

As técnicas contribuídas por outros pesquisadores continuam creditadas aos seus autores originais. Agradecimentos a todos que compartilham conhecimento para melhorar a segurança da internet.

Carlos lidera o HackTricks. O projeto é uma wiki de cybersecurity mantida pela comunidade, que reúne técnicas práticas de segurança e aceita contribuições; se você encontrar algo ausente ou desatualizado, abra um pull request no repositório do projeto.<sup>[[1]](#references)</sup>

O HackTricks também oferece aos pesquisadores um lugar para compartilhar novas descobertas, ajudando os leitores a acompanhar as técnicas de segurança atuais.
