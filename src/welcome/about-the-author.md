### Γεια σας!!

Οι τεχνικές που έχουν συνεισφέρει άλλοι ερευνητές εξακολουθούν να αποδίδονται στους αρχικούς τους συγγραφείς. Ευχαριστούμε όλους όσοι μοιράζονται γνώσεις για τη βελτίωση της ασφάλειας στο διαδίκτυο.

Ο Carlos ηγείται του HackTricks. Το project είναι ένα wiki κυβερνοασφάλειας που συντηρείται από την κοινότητα, συλλέγει πρακτικές τεχνικές ασφάλειας και καλωσορίζει συνεισφορές. Αν βρείτε κάτι που λείπει ή είναι παρωχημένο, παρακαλούμε ανοίξτε ένα pull request στο repository του project.<sup>[[1]](#references)</sup>

Το HackTricks προσφέρει επίσης στους ερευνητές έναν χώρο για να μοιράζονται νέα ευρήματα, βοηθώντας τους αναγνώστες να παραμένουν ενημερωμένοι για τις σύγχρονες τεχνικές ασφάλειας.
