## HackTricks Values

> [!TIP]
> 以下是 **HackTricks Project** 的**价值观**：
>
> - 向**所有** Internet 用户提供**免费**的**教育性 hacking**资源。
>  - Hacking 的核心是学习，而学习应当尽可能免费。
>  - 本书旨在作为一份全面的**教育资源**。
> - **存储**社区发布的优秀 **hacking** 技术，并将所有**荣誉**归于**原作者**。
>  - **我们不想窃取他人的功劳**，我们只是希望为所有人存储酷炫的 tricks。
>  - 我们也会在 HackTricks 中撰写**自己的研究成果**。
>  - 在一些情况下，我们只会在 **HackTricks 中编写技术重要部分的摘要**，并**鼓励读者访问原始文章**以了解更多详情。
> - **组织**书中的所有 hacking 技术，使其**更易访问**
>  - HackTricks 团队投入了数千小时，**仅为组织内容**，让人们能够**更快地学习**

## HackTricks faq

> [!TIP]
>
> - **非常感谢这些资源，我该如何表示感谢？**

你可以在 tweet 中提及 [**@hacktricks_live**](https://twitter.com/hacktricks_live)，公开感谢 HackTricks 团队将所有这些资源整理并公开发布。\
如果你特别感激，也可以[**在此赞助该项目**](https://github.com/sponsors/carlospolop)。\
另外别忘了**给 Github 项目点个 star！**（请在下方查找链接）。

> [!TIP]
>
> - **我该如何为项目做贡献？**

你可以**与社区分享新的 tips 和 tricks，或修复你在书中发现的 bug**，向相应的 Github 页面提交 **Pull Request**：

- [https://github.com/carlospolop/hacktricks](https://github.com/carlospolop/hacktricks)
- [https://github.com/carlospolop/hacktricks-cloud](https://github.com/carlospolop/hacktricks-cloud)

别忘了**给 Github 项目点个 star！**

> [!TIP]
>
> - **我可以复制 HackTricks 中的一些内容并放到我的博客里吗？**

可以，但**别忘了注明内容来源的具体链接**。

> [!TIP]
>
> - **我该如何引用 HackTricks 的页面？**

只要显示你获取信息的页面**链接**就足够了。\
如果你需要 bibtex，可以使用类似以下的格式：
```latex
@misc{hacktricks-bibtexing,
author = {"HackTricks Team" or the Authors name of the specific page/trick},
title = {Title of the Specific Page},
year = {Year of Last Update (check it at the end of the page)},
url = {\url{https://book.hacktricks.wiki/specific-page}},
}
```
> [!WARNING]
>
> - **我可以把所有 HackTricks 复制到我的博客中吗？**

**我更希望不要这样做**。这**不会让任何人受益**，因为所有**内容都已经免费公开在官方 HackTricks books 中**。

如果你担心它会消失，只需在 Github 上 fork 或下载即可，正如我所说，它已经是免费的。

> [!WARNING]
>
> - **你们为什么有 sponsors？HackTricks books 是出于商业目的吗？**

第一个 **HackTricks** **价值**是为全世界**所有人**提供**免费的** hacking 教育资源。HackTricks team 已经**投入数千小时**来提供这些内容，而且再次强调，是**免费**的。

如果你认为 HackTricks books 是出于**商业目的**制作的，那么你就**完全错了**。

我们有 sponsors，是因为即使所有内容都是免费的，我们仍希望**为 community 提供一个表达对我们工作的认可的机会**，如果他们愿意的话。因此，我们为人们提供通过 [**Github sponsors**](https://github.com/sponsors/carlospolop) 向 HackTricks 捐赠的选项，也允许**相关的 cybersecurity companies** sponsor HackTricks，并在书中**投放一些 ads**。这些**ads**始终放置在能够让它们**可见**、但在读者专注于内容时**不会干扰学习过程**的位置。

你不会看到 HackTricks 像其他内容远少于 HackTricks 的 blogs 一样充满令人烦恼的 ads，因为 HackTricks 并不是出于商业目的制作的。

> [!CAUTION]
>
> - **如果某个 HackTricks 页面基于我的博客文章，但没有引用来源，我该怎么办？**

**对此我们深表歉意。这本不应该发生**。请通过 Github issues、Twitter、Discord……告知我们包含相关内容的 HackTricks 页面链接以及你的博客链接，**我们会检查并尽快添加引用**。

> [!CAUTION]
>
> - **如果 HackTricks 中有来自我的博客的内容，而我不希望这些内容出现在那里，我该怎么办？**

请注意，在 HackTricks 中添加指向你页面的 links 可以：

- 改善你的 **SEO**
- 让内容被**翻译成超过 15 种语言**，使更多人能够访问这些内容
- **HackTricks 鼓励**人们**查看你的页面**（有几个人曾告诉我们，自从他们的某些页面出现在 HackTricks 中后，他们获得了更多访问量）

但是，如果你仍希望从 HackTricks 中删除你博客的内容，只需告诉我们，我们一定会**删除所有指向你博客的 links**以及任何基于该博客的内容。

> [!CAUTION]
>
> - **如果我在 HackTricks 中发现了复制粘贴的内容，我该怎么办？**

我们始终**向原作者提供完整的 credit**。如果你发现某个页面包含复制粘贴的内容，却没有引用原始来源，请告知我们；我们会**删除它**、**在文本前添加 link**，或**添加 link 后重写内容**。
