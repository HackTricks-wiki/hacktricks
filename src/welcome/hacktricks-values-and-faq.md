## HackTricks 价值观

> [!TIP]
> 以下是 **HackTricks 项目的价值观**：
>
> - 为全世界提供**免费**的**教育性 hacking**资源。
>  - Hacking 关乎学习，而学习应该尽可能免费。
>  - 本书旨在成为全面的**教育资源**。
> - **收录**社区发布的优秀 **hacking** 技术，并将所有**荣誉**归于**原作者**。
>  - **我们不想抢别人的功劳**，只想收录酷炫技巧，供所有人参考。
>  - 我们也会在 HackTricks 中撰写**自己的研究成果**。
>  - 在某些情况下，我们只会在 HackTricks 中**总结该技术的重要内容**，并**鼓励读者访问原帖**了解更多详情。
> - **整理**本书中的所有 hacking 技术，让内容**更易于获取**
>  - HackTricks 团队投入了数千小时，只为免费**整理内容**，让大家能够**更快地学习**

## HackTricks 常见问题

> [!TIP]
>
> - **非常感谢这些资源，我该如何表达谢意？**

你可以发推文公开感谢 HackTricks 团队整理这些资源，并提及 [**@hacktricks_live**](https://twitter.com/hacktricks_live)。\
如果你特别感激，也可以通过 GitHub Sponsors 赞助该项目。<sup>[[3]](#references)</sup>\
别忘了给 **GitHub 项目点星**。<sup>[[1]](#references)[[2]](#references)</sup>

> [!TIP]
>
> - **我该如何为这个项目做贡献？**

你可以通过向相应的 GitHub 仓库提交 **pull request**，与社区**分享新的技巧，或修复你在书中发现的 bug**。<sup>[[1]](#references)[[2]](#references)</sup>

- [HackTricks 仓库](https://github.com/HackTricks-wiki/hacktricks)
- [HackTricks Cloud 仓库](https://github.com/HackTricks-wiki/hacktricks-cloud)

> [!TIP]
>
> - **我可以复制 HackTricks 的部分内容放到自己的博客里吗？**

可以，但**别忘了注明内容来源的具体链接**。

> [!TIP]
>
> - **我该如何引用 HackTricks 的页面？**

只要包含你获取信息的页面**链接**即可。\
如果你需要 bibtex，可以使用类似下面的格式：

```latex
@misc{hacktricks-bibtexing,
  author = {"HackTricks Team" or the Authors name of the specific page/trick},
  title = {Title of the Specific Page},
  year = {Year of Last Update (check it at the end of the page)},
  url = {\url{https://book.hacktricks.wiki/specific-page}},
}
```

> [!WARNING]
>
> - **我可以把所有 HackTricks 内容复制到我的博客吗？**

**我不太建议这么做**。这**对任何人都没有好处**，因为所有**内容都已在官方 HackTricks 书籍中免费公开**。

如果你担心内容会消失，可以在 Github 上 fork，或者下载下来；正如我所说，这些内容本来就是免费的。

> [!WARNING]
>
> - **你们为什么有赞助商？HackTricks 书籍是用于商业目的吗？**

HackTricks 的首要**价值**是为**全世界所有人**提供**免费**的 hacking 教育资源。HackTricks 团队**投入了数千个小时**来提供这些内容，再说一次，**完全免费**。

如果你认为 HackTricks 书籍是为了**商业目的**而制作的，那你就**大错特错**了。

我们有赞助商，是因为即使所有内容都是免费的，我们也希望**让社区有机会表达对我们工作的认可**，前提是他们愿意。大家可以通过 **GitHub Sponsors** 向 HackTricks 捐款。<sup>[[3]](#references)</sup> **相关的网络安全公司**也可以赞助 HackTricks，并在书中投放广告；广告的位置始终会确保醒目，同时不影响学习过程。

你不会发现 HackTricks 充斥着令人厌烦的广告，不像其他内容远少于 HackTricks 的博客那样，因为 HackTricks 并非为了商业目的而制作。

> [!CAUTION]
>
> - **如果 HackTricks 的某个页面基于我的博客文章，却没有注明出处，我该怎么办？**

**我们深表歉意。这种情况本不应该发生**。请通过 Github issues、Twitter、Discord 等渠道告诉我们 HackTricks 中相关页面的链接以及你的博客链接，**我们会尽快核实并添加出处**。

> [!CAUTION]
>
> - **如果 HackTricks 中有来自我博客的内容，而我不希望这些内容出现在这里，该怎么办？**

请注意，在 HackTricks 中添加指向你页面的链接可以：

- 改善你的 **SEO**
- 让内容被**翻译成 15 种以上语言**，使更多人能够访问这些内容
- **HackTricks 会鼓励**大家**查看你的页面**（有几个人告诉我们，由于他们的某些页面收录在 HackTricks 中，他们获得了更多访问量）

不过，如果你仍希望从 HackTricks 中移除你博客的内容，只需告诉我们，我们一定会**移除所有指向你博客的链接**以及任何基于该博客的内容。

> [!CAUTION]
>
> - **如果我在 HackTricks 中发现复制粘贴的内容，该怎么办？**

我们始终会**注明原作者并致谢**。如果你发现某个页面有复制粘贴的内容，却没有注明原始来源，请告诉我们，我们会**将其移除**、**在文本前添加链接**，或**改写内容并添加链接**。
