# Αξίες και FAQ του HackTricks

## Αξίες του HackTricks

> [!TIP]
> Αυτές είναι οι **αξίες του HackTricks Project**:
>
> - Παρέχει **ΔΩΡΕΑΝ** πρόσβαση σε **ΕΚΠΑΙΔΕΥΤΙΚΟΥΣ** πόρους για hacking σε **ΟΛΟ** το Internet.
>  - Το hacking αφορά τη μάθηση και η μάθηση θα πρέπει να είναι όσο το δυνατόν πιο δωρεάν.
>  - Σκοπός αυτού του βιβλίου είναι να λειτουργεί ως μια ολοκληρωμένη **εκπαιδευτική πηγή**.
> - **ΑΠΟΘΗΚΕΥΕΙ** εκπληκτικές τεχνικές **hacking** που δημοσιεύει η κοινότητα, δίνοντας στους **ΑΡΧΙΚΟΥΣ** **ΣΥΓΓΡΑΦΕΙΣ** όλα τα **credits**.
>  - **Δεν θέλουμε τα credits άλλων ανθρώπων**, θέλουμε απλώς να αποθηκεύουμε cool tricks για όλους.
>  - Γράφουμε επίσης **τις δικές μας έρευνες** στο HackTricks.
>  - Σε αρκετές περιπτώσεις θα γράψουμε απλώς **στο HackTricks μια σύνοψη των σημαντικών σημείων** της τεχνικής και θα **ενθαρρύνουμε τον αναγνώστη να επισκεφθεί την αρχική δημοσίευση** για περισσότερες λεπτομέρειες.
> - **ΟΡΓΑΝΩΝΕΙ** όλες τις τεχνικές hacking στο βιβλίο ώστε να είναι **ΠΙΟ ΠΡΟΣΒΑΣΙΜΕΣ**
>  - Η ομάδα του HackTricks έχει αφιερώσει χιλιάδες ώρες δωρεάν **μόνο στην οργάνωση του περιεχομένου**, ώστε οι άνθρωποι να μπορούν να **μαθαίνουν γρηγορότερα**

## FAQ του HackTricks

> [!TIP]
>
> - **Σας ευχαριστώ πολύ για αυτούς τους πόρους, πώς μπορώ να σας ευχαριστήσω;**

Μπορείτε να ευχαριστήσετε δημόσια την ομάδα του HackTricks για τη δημιουργία αυτών των πόρων σε ένα tweet που θα αναφέρει το [**@hacktricks_live**](https://twitter.com/hacktricks_live).\
Αν είστε ιδιαίτερα ευγνώμονες, μπορείτε να υποστηρίξετε το project μέσω του GitHub Sponsors.<sup>[[3]](#references)</sup>\
Και μην ξεχάσετε να κάνετε **star στα GitHub projects**.<sup>[[1]](#references)[[2]](#references)</sup>

> [!TIP]
>
> - **Πώς μπορώ να συνεισφέρω στο project;**

Μπορείτε να **μοιραστείτε νέα tips και tricks με την κοινότητα ή να διορθώσετε bugs** που βρίσκετε στα βιβλία, στέλνοντας ένα **pull request** στα αντίστοιχα GitHub repositories.<sup>[[1]](#references)[[2]](#references)</sup>

- [HackTricks repository](https://github.com/HackTricks-wiki/hacktricks)
- [HackTricks Cloud repository](https://github.com/HackTricks-wiki/hacktricks-cloud)

> [!TIP]
>
> - **Μπορώ να αντιγράψω κάποιο περιεχόμενο από το HackTricks και να το βάλω στο blog μου;**

Ναι, μπορείτε, αλλά **μην ξεχάσετε να αναφέρετε τον συγκεκριμένο σύνδεσμο ή τους συγκεκριμένους συνδέσμους** από όπου προήλθε το περιεχόμενο.

> [!TIP]
>
> - **Πώς μπορώ να αναφέρω μια σελίδα του HackTricks;**

Αρκεί να εμφανίζεται ο **σύνδεσμος** της σελίδας ή των σελίδων από όπου πήρατε τις πληροφορίες.\
Αν χρειάζεστε ένα bibtex, μπορείτε να χρησιμοποιήσετε κάτι σαν:
```latex
@misc{hacktricks-bibtexing,
author = {"HackTricks Team" or the Authors name of the specific page/trick},
title = {Title of the Specific Page},
year = {Year of Last Update (check it at the end of the page)},
url = {\url{https://book.hacktricks.wiki/specific-page}},
}
```
> [!WARNING]
>
> - **Μπορώ να αντιγράψω όλο το HackTricks στο blog μου;**

**Θα προτιμούσα να μην το κάνετε**. Αυτό **δεν πρόκειται να ωφελήσει κανέναν**, καθώς όλο το **περιεχόμενο είναι ήδη δημόσια διαθέσιμο** στα επίσημα βιβλία του HackTricks δωρεάν.

Αν φοβάστε ότι θα εξαφανιστεί, απλώς κάντε fork στο Github ή κατεβάστε το· όπως είπα, είναι ήδη δωρεάν.

> [!WARNING]
>
> - **Γιατί έχετε sponsors; Τα βιβλία του HackTricks προορίζονται για εμπορικούς σκοπούς;**

Η πρώτη **αξία** του **HackTricks** είναι να προσφέρει **ΔΩΡΕΑΝ** εκπαιδευτικούς πόρους για hacking σε **ΟΛΟ** τον κόσμο. Η ομάδα του HackTricks έχει **αφιερώσει χιλιάδες ώρες** για να προσφέρει αυτό το περιεχόμενο, ξανά, **ΔΩΡΕΑΝ**.

Αν πιστεύετε ότι τα βιβλία του HackTricks δημιουργήθηκαν για **εμπορικούς σκοπούς**, κάνετε **ΕΝΤΕΛΩΣ ΛΑΘΟΣ**.

Έχουμε sponsors επειδή, παρόλο που όλο το περιεχόμενο είναι ΔΩΡΕΑΝ, θέλουμε να **προσφέρουμε στην κοινότητα τη δυνατότητα να εκτιμήσει τη δουλειά μας** αν το επιθυμεί. Οι χρήστες μπορούν να κάνουν δωρεά στο HackTricks μέσω των **GitHub Sponsors**.<sup>[[3]](#references)</sup> **Σχετικές εταιρείες κυβερνοασφάλειας** μπορούν επίσης να κάνουν sponsor στο HackTricks και να τοποθετούν διαφημίσεις στο βιβλίο, πάντα σε θέση που τις καθιστά ορατές χωρίς να διαταράσσεται η διαδικασία μάθησης.

Δεν θα βρείτε το HackTricks γεμάτο με ενοχλητικές διαφημίσεις όπως άλλα blogs με πολύ λιγότερο περιεχόμενο από το HackTricks, επειδή το HackTricks δεν δημιουργήθηκε για εμπορικούς σκοπούς.

> [!CAUTION]
>
> - **Τι πρέπει να κάνω αν κάποια σελίδα του HackTricks βασίζεται σε ανάρτηση του blog μου, αλλά δεν αναφέρεται η πηγή;**

**Λυπούμαστε πολύ. Αυτό δεν θα έπρεπε να έχει συμβεί**. Παρακαλούμε ενημερώστε μας μέσω Github issues, Twitter, Discord... στείλτε μας τον σύνδεσμο της σελίδας του HackTricks με το περιεχόμενο και τον σύνδεσμο του blog σας και **θα το ελέγξουμε και θα το προσθέσουμε το συντομότερο δυνατό**.

> [!CAUTION]
>
> - **Τι πρέπει να κάνω αν υπάρχει περιεχόμενο από το blog μου στο HackTricks και δεν θέλω να βρίσκεται εκεί;**

Σημειώστε ότι η ύπαρξη συνδέσμων προς τη σελίδα σας στο HackTricks:

- Βελτιώνει το **SEO** σας
- Το περιεχόμενο **μεταφράζεται σε περισσότερες από 15 γλώσσες**, επιτρέποντας σε περισσότερους ανθρώπους να έχουν πρόσβαση σε αυτό
- Το **HackTricks ενθαρρύνει** τους ανθρώπους να **επισκέπτονται τη σελίδα σας** (αρκετοί άνθρωποι μας έχουν αναφέρει ότι, από τότε που κάποια σελίδα τους βρίσκεται στο HackTricks, δέχονται περισσότερες επισκέψεις)

Ωστόσο, αν εξακολουθείτε να θέλετε να αφαιρεθεί το περιεχόμενο του blog σας από το HackTricks, απλώς ενημερώστε μας και σίγουρα θα **αφαιρέσουμε κάθε σύνδεσμο προς το blog σας**, καθώς και οποιοδήποτε περιεχόμενο βασίζεται σε αυτό.

> [!CAUTION]
>
> - **Τι πρέπει να κάνω αν βρω περιεχόμενο αντιγραμμένο και επικολλημένο στο HackTricks;**

Πάντα **αναγνωρίζουμε πλήρως τους αρχικούς δημιουργούς**. Αν βρείτε σελίδα με περιεχόμενο αντιγραμμένο και επικολλημένο χωρίς αναφορά στην αρχική πηγή, ενημερώστε μας και είτε θα **το αφαιρέσουμε**, είτε θα **προσθέσουμε τον σύνδεσμο πριν από το κείμενο**, είτε θα **το ξαναγράψουμε προσθέτοντας τον σύνδεσμο**.

## ΑΔΕΙΑ

Πνευματικά δικαιώματα © Με την επιφύλαξη παντός δικαιώματος, εκτός αν ορίζεται διαφορετικά.

#### Περίληψη άδειας:

- Αναφορά δημιουργού: Έχετε το δικαίωμα να:
- Μοιράζεστε — να αντιγράφετε και να αναδιανέμετε το υλικό σε οποιοδήποτε μέσο ή μορφή.
- Προσαρμόζετε — να αναμειγνύετε, να μετασχηματίζετε και να βασίζεστε στο υλικό για τη δημιουργία νέου έργου.

#### Πρόσθετοι όροι:

- Περιεχόμενο τρίτων: Ορισμένα τμήματα αυτού του blog/βιβλίου ενδέχεται να περιλαμβάνουν περιεχόμενο από άλλες πηγές, όπως αποσπάσματα από άλλα blogs ή δημοσιεύσεις. Η χρήση αυτού του περιεχομένου γίνεται σύμφωνα με τις αρχές της θεμιτής χρήσης ή με ρητή άδεια των αντίστοιχων κατόχων των πνευματικών δικαιωμάτων. Ανατρέξτε στις αρχικές πηγές για συγκεκριμένες πληροφορίες αδειοδότησης σχετικά με περιεχόμενο τρίτων.
- Συγγραφή: Το αρχικό περιεχόμενο που έχει δημιουργηθεί από το HackTricks υπόκειται στους όρους αυτής της άδειας. Σας ενθαρρύνουμε να αναφέρετε το έργο στον δημιουργό όταν το μοιράζεστε ή το προσαρμόζετε.

#### Εξαιρέσεις:

- Εμπορική χρήση: Για ερωτήσεις σχετικά με την εμπορική χρήση αυτού του περιεχομένου, επικοινωνήστε μαζί μου.

Η παρούσα άδεια δεν παραχωρεί δικαιώματα σε εμπορικά σήματα ή branding σε σχέση με το περιεχόμενο. Όλα τα εμπορικά σήματα και το branding που εμφανίζονται σε αυτό το blog/βιβλίο αποτελούν ιδιοκτησία των αντίστοιχων κατόχων τους.

**Με την πρόσβαση ή τη χρήση του HackTricks, συμφωνείτε να τηρείτε τους όρους αυτής της άδειας. Αν δεν συμφωνείτε με αυτούς τους όρους, παρακαλούμε μην αποκτήσετε πρόσβαση σε αυτόν τον ιστότοπο.**
