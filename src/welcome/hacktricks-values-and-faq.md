## HackTricks 价值观

> [!TIP]
> 以下是 **HackTricks Project 的价值观**：
>
> - 向互联网上的**所有人**免费提供**教育类 hacking**资源。
>  - Hacking 关乎学习，而学习应该尽可能免费。
>  - 本书旨在作为一份全面的**教育资源**。
> - **收录**社区发布的优秀 **hacking** 技术，并将所有**荣誉**归于**原作者**。
>  - **我们不想抢别人的功劳**，只想为大家收录实用技巧。
>  - 我们也会在 HackTricks 中撰写**自己的研究成果**。
>  - 在某些情况下，我们只会在 HackTricks 中**总结技术的重要内容**，并**鼓励读者访问原始文章**了解更多详情。
> - **整理**本书中的所有 hacking 技术，让内容**更易于获取**
>  - HackTricks 团队无偿投入了数千小时，**只为整理内容**，让大家能够**更快地学习**

## HackTricks 常见问题

> [!TIP]
>
> - **非常感谢这些资源，我该如何表达谢意？**

你可以在推文中提及 [**@hacktricks_live**](https://twitter.com/hacktricks_live)，公开感谢 HackTricks 团队整理这些资源。\
如果你特别感激，可以通过 GitHub Sponsors 赞助这个项目。<sup>[[3]](#references)</sup>\
也别忘了给 **GitHub 项目点星**。<sup>[[1]](#references)[[2]](#references)</sup>

> [!TIP]
>
> - **我该如何为这个项目做贡献？**

你可以通过向相应的 GitHub 仓库提交 **pull request**，与社区**分享新的技巧，或修复**你在书中发现的 bug。<sup>[[1]](#references)[[2]](#references)</sup>

- [HackTricks repository](https://github.com/HackTricks-wiki/hacktricks)
- [HackTricks Cloud repository](https://github.com/HackTricks-wiki/hacktricks-cloud)

> [!TIP]
>
> - **我可以复制 HackTricks 中的内容并发布到自己的博客上吗？**

HackTricks 原创文本可根据 [CC BY-NC 4.0](../LICENSE.md) 用于**非商业用途**。<sup>[[4]](#references)</sup> 请注明适当的出处，链接至来源和许可证，并说明所做的任何更改。<sup>[[5]](#references)</sup> 单独标注出处的第三方材料可能适用不同条款。<sup>[[4]](#references)</sup>

> [!TIP]
>
> - **我该如何引用 HackTricks 中的页面？**

引用时，请链接到具体页面。转载或改编文本则不同：请遵循[许可证](../LICENSE.md)的要求，包括注明出处、提供许可证链接和说明更改内容。<sup>[[4]](#references)[[5]](#references)</sup>\
如果你需要 bibtex，可以使用类似这样的内容：

```latex
@misc{hacktricks-bibtexing,
  author = {"HackTricks Team" or the Authors name of the specific page/trick},
  title = {Title of the Specific Page},
  year = {Year of Last Update (check it at the end of the page)},
  url = {\url{https://book.hacktricks.wiki/specific-page}},
}
```

> [!WARNING]
>
> - **我可以把所有 HackTricks 内容都复制到我的博客吗？**

**我不太建议这样做**。这**对任何人都没有好处**，因为所有**内容都已在官方 HackTricks 书籍中免费公开**。

如果你担心内容会消失，只需在 Github 上 fork 或下载即可，正如我所说，这些内容已经免费提供。

> [!WARNING]
>
> - **你们为什么有赞助商？HackTricks 书籍是用于商业目的吗？**

**HackTricks** 的首要**价值**是为**全世界所有人**提供**免费**的 hacking 教育资源。HackTricks 团队已经**投入数千小时**提供这些内容，而且再次强调，**完全免费**。

如果你认为 HackTricks 书籍是为了**商业目的**而制作的，那你就**大错特错了**。

我们有赞助商，是因为即使所有内容都是免费的，我们也希望**让社区有机会表达对我们工作的认可**，如果他们愿意的话。大家可以通过 **GitHub Sponsors** 向 HackTricks 捐赠。<sup>[[3]](#references)</sup> **相关的网络安全公司**也可以赞助 HackTricks，并在书中投放广告；广告始终会放在醒目但不影响学习的位置。

你不会看到 HackTricks 像其他内容少得多的博客那样充斥着令人讨厌的广告，因为 HackTricks 并非为了商业目的而制作。

> [!CAUTION]
>
> - **如果 HackTricks 的某个页面基于我的博客文章，但没有注明出处，我该怎么办？**

**我们深感抱歉。这种情况本不应该发生**。请通过 Github issues、Twitter、Discord 等方式告知我们，提供包含相关内容的 HackTricks 页面链接和你的博客链接，**我们会尽快核查并补上出处**。

> [!CAUTION]
>
> - **如果 HackTricks 中有我博客的内容，而我不希望这些内容出现在其中，该怎么办？**

请注意，在 HackTricks 中放置指向你页面的链接可以：

- 提升你的 **SEO**
- 让内容**翻译成 15 种以上的语言**，使更多人能够访问这些内容
- **HackTricks 会鼓励**读者**查看你的页面**（有几个人告诉我们，自从他们的某个页面被收录在 HackTricks 中后，访问量就增加了）

不过，如果你仍然希望从 HackTricks 中删除你博客的内容，只需告知我们，我们一定会**删除所有指向你博客的链接**，以及任何基于该博客的内容。

> [!CAUTION]
>
> - **如果我在 HackTricks 中发现了复制粘贴的内容，该怎么办？**

我们始终会**注明原作者并给予完整致谢**。如果你发现某个页面包含复制粘贴的内容，却没有注明原始来源，请告知我们，我们会选择**删除内容**、**在文本前添加链接**，或**改写内容并添加链接**。
