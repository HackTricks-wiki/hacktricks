## HackTricks Values

> [!TIP]
> 以下是 **HackTricks Project** 的**价值观**：
>
> - 向**所有** Internet 用户提供**免费**的**教育性 hacking**资源。
>  - Hacking 关乎学习，而学习应该尽可能免费。
>  - 本书旨在作为一份全面的**教育资源**。
> - **存储**社区发布的优秀 **hacking** 技术，并将所有**荣誉**归于**原始作者**。
>  - **我们不想获得他人的荣誉**，我们只想为所有人存储酷炫的技巧。
>  - 我们也会在 HackTricks 中撰写**自己的研究**。
>  - 在某些情况下，我们只会在 HackTricks 中撰写该技术**重要部分的摘要**，并**鼓励读者访问原始文章**以了解更多详情。
> - **组织**书中的所有 hacking 技术，使其**更易于访问**
>  - HackTricks 团队投入了数千小时的免费时间，**仅用于组织内容**，让人们能够**更快地学习**

## HackTricks 常见问题

> [!TIP]
>
> - **非常感谢这些资源，我该如何表达谢意？**

你可以在 tweet 中提及 [**@hacktricks_live**](https://twitter.com/hacktricks_live)，公开感谢 HackTricks 团队整理这些资源。\
如果你特别感激，也可以通过 GitHub Sponsors 赞助该项目。<sup>[[3]](#references)</sup>\
另外别忘了给 **GitHub 项目点 star**。<sup>[[1]](#references)[[2]](#references)</sup>

> [!TIP]
>
> - **我该如何为项目做贡献？**

你可以通过向相应的 GitHub repositories 提交 **pull request**，与社区**分享新的提示和技巧，或修复你在书中发现的 bug**。<sup>[[1]](#references)[[2]](#references)</sup>

- [HackTricks repository](https://github.com/HackTricks-wiki/hacktricks)
- [HackTricks Cloud repository](https://github.com/HackTricks-wiki/hacktricks-cloud)

> [!TIP]
>
> - **我可以复制 HackTricks 中的部分内容并放到自己的 blog 中吗？**

可以，但**别忘了注明获取内容的具体链接**。

> [!TIP]
>
> - **我该如何引用 HackTricks 的页面？**

只要出现你获取信息的页面**链接**，就足够了。\
如果你需要 bibtex，可以使用类似以下的内容：
```latex
@misc{hacktricks-bibtexing,
author = {"HackTricks Team" or the Authors name of the specific page/trick},
title = {Title of the Specific Page},
year = {Year of Last Update (check it at the end of the page)},
url = {\url{https://book.hacktricks.wiki/specific-page}},
}
```
> [!WARNING]
>
> - **我可以把所有 HackTricks 复制到我的博客中吗？**

**我更希望你不要这样做**。这**不会让任何人受益**，因为所有**内容已经免费公开发布在官方 HackTricks books 中**。

如果你担心它会消失，只需在 Github 上 fork 或下载即可，因为正如我所说，它本来就是免费的。

> [!WARNING]
>
> - **你们为什么有 sponsors？HackTricks books 是用于商业目的吗？**

第一个 **HackTricks** **价值**是为**全世界所有人**提供**免费**的 hacking 教育资源。HackTricks 团队已经**投入了数千小时**来提供这些内容，而且仍然是**免费**的。

如果你认为 HackTricks books 是为**商业目的**制作的，那你就**完全错了**。

我们有 sponsors，是因为即使所有内容都是免费的，我们仍希望**让 community 有机会在他们愿意的情况下认可我们的工作**。用户可以通过 **GitHub Sponsors** 向 HackTricks 捐赠。<sup>[[3]](#references)</sup> **相关的 cybersecurity companies**也可以 sponsor HackTricks，并在 book 中投放广告；广告始终会放置在可见但不会干扰学习过程的位置。

你不会看到 HackTricks 像其他内容远少于 HackTricks 的 blogs 一样充斥着恼人的广告，因为 HackTricks 并不是为商业目的而制作的。

> [!CAUTION]
>
> - **如果某个 HackTricks 页面基于我的 blog post，但没有引用来源，我该怎么办？**

**我们对此深表歉意。这本不应该发生**。请通过 Github issues、Twitter、Discord... 告诉我们包含相关内容的 HackTricks 页面链接以及你的 blog 链接，**我们会检查并尽快添加引用**。

> [!CAUTION]
>
> - **如果 HackTricks 中有来自我 blog 的内容，而我不希望这些内容出现在其中，我该怎么办？**

请注意，在 HackTricks 中添加指向你页面的链接可以：

- 改善你的 **SEO**
- 内容会被**翻译成 15 种以上的语言**，让更多人能够访问这些内容
- **HackTricks 会鼓励**用户**查看你的页面**（有几个人告诉我们，自从他们的某个页面被收录到 HackTricks 后，他们获得了更多访问量）

但是，如果你仍希望从 HackTricks 中删除你 blog 的内容，只需告诉我们，我们一定会**删除所有指向你 blog 的链接**以及任何基于该 blog 的内容。

> [!CAUTION]
>
> - **如果我在 HackTricks 中发现 copy-pasted content，该怎么办？**

我们始终会**向原作者提供完整的 credit**。如果你发现某个页面包含 copy-pasted content，但没有引用原始来源，请告诉我们，我们会**删除它**、**在文本前添加链接**，或**添加链接并重写内容**。
