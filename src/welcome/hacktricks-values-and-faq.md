## Αξίες του HackTricks

> [!TIP]
> Αυτές είναι οι **αξίες του HackTricks Project**:
>
> - Παρέχουμε **ΔΩΡΕΑΝ** πρόσβαση σε **ΕΚΠΑΙΔΕΥΤΙΚΟΥΣ πόρους hacking** σε **ΟΛΟ** το Internet.
>  - Το hacking αφορά τη μάθηση και η μάθηση πρέπει να είναι όσο το δυνατόν πιο ελεύθερη.
>  - Σκοπός αυτού του βιβλίου είναι να αποτελέσει έναν ολοκληρωμένο **εκπαιδευτικό πόρο**.
> - **ΑΠΟΘΗΚΕΥΟΥΜΕ** εξαιρετικές τεχνικές **hacking** που δημοσιεύει η κοινότητα, αποδίδοντας στους **ΑΡΧΙΚΟΥΣ ΔΗΜΙΟΥΡΓΟΥΣ** όλα τα **εύσημα**.
>  - **Δεν θέλουμε τα εύσημα άλλων ανθρώπων**· θέλουμε απλώς να αποθηκεύουμε εξαιρετικά κόλπα για όλους.
>  - Γράφουμε επίσης **τις δικές μας έρευνες** στο HackTricks.
>  - Σε αρκετές περιπτώσεις, θα γράφουμε απλώς **μια σύνοψη των σημαντικών σημείων** της τεχνικής στο HackTricks και θα **ενθαρρύνουμε τον αναγνώστη να επισκεφτεί την αρχική ανάρτηση** για περισσότερες λεπτομέρειες.
> - **ΟΡΓΑΝΩΝΟΥΜΕ** όλες τις τεχνικές hacking στο βιβλίο, ώστε να είναι **ΠΙΟ ΠΡΟΣΙΤΕΣ**
>  - Η ομάδα του HackTricks έχει αφιερώσει χιλιάδες ώρες δωρεάν **μόνο στην οργάνωση του περιεχομένου**, ώστε οι άνθρωποι να μπορούν να **μαθαίνουν γρηγορότερα**

## Συχνές ερωτήσεις για το HackTricks

> [!TIP]
>
> - **Σας ευχαριστώ πολύ για αυτούς τους πόρους. Πώς μπορώ να σας ευχαριστήσω;**

Μπορείτε να ευχαριστήσετε δημόσια την ομάδα του HackTricks για τη συγκέντρωση αυτών των πόρων με ένα tweet που αναφέρει το [**@hacktricks_live**](https://twitter.com/hacktricks_live).\
Αν είστε ιδιαίτερα ευγνώμονες, μπορείτε να στηρίξετε το project μέσω του GitHub Sponsors.<sup>[[3]](#references)</sup>\
Και μην ξεχάσετε να κάνετε **star στα GitHub projects**.<sup>[[1]](#references)[[2]](#references)</sup>

> [!TIP]
>
> - **Πώς μπορώ να συνεισφέρω στο project;**

Μπορείτε να **μοιραστείτε νέα tips και κόλπα με την κοινότητα ή να διορθώσετε σφάλματα** που εντοπίζετε στα βιβλία, στέλνοντας ένα **pull request** στα αντίστοιχα GitHub repositories.<sup>[[1]](#references)[[2]](#references)</sup>

- [HackTricks repository](https://github.com/HackTricks-wiki/hacktricks)
- [HackTricks Cloud repository](https://github.com/HackTricks-wiki/hacktricks-cloud)

> [!TIP]
>
> - **Μπορώ να αντιγράψω κάποιο περιεχόμενο από το HackTricks και να το δημοσιεύσω στο blog μου;**

Το πρωτότυπο κείμενο του HackTricks μπορεί να επαναχρησιμοποιηθεί για **μη εμπορικούς σκοπούς** βάσει της άδειας [CC BY-NC 4.0](../LICENSE.md).<sup>[[4]](#references)</sup> Αποδώστε την κατάλληλη αναγνώριση, προσθέστε σύνδεσμο προς την πηγή και την άδεια και επισημάνετε τυχόν αλλαγές.<sup>[[5]](#references)</sup> Το υλικό τρίτων που αποδίδεται χωριστά μπορεί να υπόκειται σε διαφορετικούς όρους.<sup>[[4]](#references)</sup>

> [!TIP]
>
> - **Πώς μπορώ να παραπέμψω σε μια σελίδα του HackTricks;**

Για παραπομπή, προσθέστε σύνδεσμο προς τη συγκεκριμένη σελίδα. Η αναπαραγωγή ή προσαρμογή κειμένου είναι διαφορετική: ακολουθήστε την [άδεια](../LICENSE.md), συμπεριλαμβανομένων των απαιτήσεων για αναγνώριση, σύνδεσμο προς την άδεια και επισήμανση αλλαγών.<sup>[[4]](#references)[[5]](#references)</sup>\
Αν χρειάζεστε bibtex, μπορείτε να χρησιμοποιήσετε κάτι σαν το εξής:

```latex
@misc{hacktricks-bibtexing,
  author = {"HackTricks Team" or the Authors name of the specific page/trick},
  title = {Title of the Specific Page},
  year = {Year of Last Update (check it at the end of the page)},
  url = {\url{https://book.hacktricks.wiki/specific-page}},
}
```

> [!WARNING]
>
> - **Μπορώ να αντιγράψω όλο το HackTricks στο blog μου;**

**Θα προτιμούσα να μην το κάνετε**. Αυτό **δεν θα ωφελήσει κανέναν**, καθώς όλο το **περιεχόμενο είναι ήδη διαθέσιμο δημόσια** στα επίσημα βιβλία HackTricks, δωρεάν.

Αν φοβάστε ότι θα εξαφανιστεί, απλώς κάντε fork στο Github ή κατεβάστε το· όπως είπα, είναι ήδη δωρεάν.

> [!WARNING]
>
> - **Γιατί έχετε χορηγούς; Τα βιβλία HackTricks προορίζονται για εμπορική χρήση;**

Η πρώτη **αξία** του **HackTricks** είναι να προσφέρει **ΔΩΡΕΑΝ** εκπαιδευτικούς πόρους hacking σε **ΟΛΟΝ** τον κόσμο. Η ομάδα HackTricks έχει **αφιερώσει χιλιάδες ώρες** για να προσφέρει αυτό το περιεχόμενο, και πάλι, **ΔΩΡΕΑΝ**.

Αν πιστεύετε ότι τα βιβλία HackTricks δημιουργήθηκαν για **εμπορική χρήση**, κάνετε **ΕΝΤΕΛΩΣ ΛΑΘΟΣ**.

Έχουμε χορηγούς επειδή, παρότι όλο το περιεχόμενο είναι ΔΩΡΕΑΝ, θέλουμε να **δώσουμε στην κοινότητα τη δυνατότητα να εκτιμήσει τη δουλειά μας**, αν το επιθυμεί. Ο κόσμος μπορεί να κάνει δωρεές στο HackTricks μέσω του **GitHub Sponsors**.<sup>[[3]](#references)</sup> **Σχετικές εταιρείες κυβερνοασφάλειας** μπορούν επίσης να γίνουν χορηγοί του HackTricks και να τοποθετήσουν διαφημίσεις στο βιβλίο, πάντα σε σημεία όπου είναι ορατές χωρίς να διαταράσσουν τη μαθησιακή διαδικασία.

Δεν θα βρείτε το HackTricks γεμάτο με ενοχλητικές διαφημίσεις, όπως άλλα blog με πολύ λιγότερο περιεχόμενο από το HackTricks, επειδή το HackTricks δεν δημιουργήθηκε για εμπορική χρήση.

> [!CAUTION]
>
> - **Τι πρέπει να κάνω αν κάποια σελίδα του HackTricks βασίζεται σε ανάρτηση του blog μου, αλλά δεν αναφέρεται η πηγή;**

**Λυπούμαστε πολύ. Αυτό δεν θα έπρεπε να έχει συμβεί**. Ενημερώστε μας μέσω Github issues, Twitter, Discord... στέλνοντάς μας τον σύνδεσμο της σελίδας του HackTricks με το περιεχόμενο και τον σύνδεσμο του blog σας και **θα το ελέγξουμε και θα προσθέσουμε την αναφορά το συντομότερο δυνατό**.

> [!CAUTION]
>
> - **Τι πρέπει να κάνω αν υπάρχει περιεχόμενο από το blog μου στο HackTricks και δεν θέλω να βρίσκεται εκεί;**

Λάβετε υπόψη ότι η ύπαρξη συνδέσμων προς τη σελίδα σας στο HackTricks:

- Βελτιώνει το **SEO** σας
- Το περιεχόμενο **μεταφράζεται σε περισσότερες από 15 γλώσσες**, διευκολύνοντας την πρόσβαση περισσότερων ανθρώπων σε αυτό
- Το **HackTricks ενθαρρύνει** τον κόσμο να **επισκεφθεί τη σελίδα σας** (αρκετοί μας έχουν αναφέρει ότι, από τότε που κάποια σελίδα τους συμπεριλήφθηκε στο HackTricks, δέχονται περισσότερες επισκέψεις)

Ωστόσο, αν εξακολουθείτε να θέλετε να αφαιρεθεί το περιεχόμενο του blog σας από το HackTricks, απλώς ενημερώστε μας και θα **αφαιρέσουμε οπωσδήποτε κάθε σύνδεσμο προς το blog σας**, καθώς και οποιοδήποτε περιεχόμενο βασίζεται σε αυτό.

> [!CAUTION]
>
> - **Τι πρέπει να κάνω αν εντοπίσω περιεχόμενο αντιγραμμένο αυτούσιο στο HackTricks;**

Πάντα **αποδίδουμε τα εύσημα στους αρχικούς συγγραφείς**. Αν εντοπίσετε σελίδα με περιεχόμενο αντιγραμμένο αυτούσιο χωρίς αναφορά στην αρχική πηγή, ενημερώστε μας και είτε θα **το αφαιρέσουμε**, είτε θα **προσθέσουμε τον σύνδεσμο πριν από το κείμενο**, είτε θα **το ξαναγράψουμε προσθέτοντας τον σύνδεσμο**.
